# 示例条目：一条笔记值不值得写

这是**格式示例**，不是知识内容。照着它填空，然后删掉这段。

## 结论

判断标准只有一条：**同样的处境再来一次，这页能省掉重新摸索的时间**。
省不掉，就不写。

## 什么时候用得上

- 某个操作踩过坑，下次还会踩
- 查过某个概念，下次还得再查一遍
- 某个决定有理由，三个月后会忘记理由

## 步骤

1. 先写结论，一句话
2. 写触发条件：什么情况下该翻这页
3. 写做法，能复制的命令放代码块
4. 写「如果不对」：常见失败和排查顺序

## 反例

- 收藏一篇文章的链接，没写为什么收藏 → 下次还是不会点开
- 记了「配好了 Nginx」，没记改了哪一行 → 下次从零开始
- 只记结论，没记适用边界 → 用错场景

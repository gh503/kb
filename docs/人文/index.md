# 人文

> 人怎么组成社会，社会怎么变成现在这样。

判断类的内容多、时效性强、最容易写成情绪。所以这一域每页都要标清**哪句是事实、哪句是我的判断**。

## 怎么看这一域

主视角是**经济与金融**：钱从哪来、成本由谁承担、激励怎么变。
它能把"谁好谁坏"换成"在什么约束下做什么选择"。详见[读法](读法.md)。

两条硬边界：

- **只写历史政治，不写当代政治**——处理已进入史料的制度与人，不做现实议题的立场表达
- **事实与判断分开写**——每页用「事实与判断」小节标清哪句有史料、哪句是解释

# 历史

> 事情是怎么变成现在这样的。

## 收什么

- 时间线：把散落的事件排成一条能读的线
- 因果解释：为什么会这样，有哪些竞争性解释
- 史料与出处：这条说法来自哪本书、哪份档案、哪一方
- 常见误传的纠正：流传很广但站不住的说法，错在哪
- 财政与金融动因：钱从哪来、谁承担成本、激励怎么变（这一域的主视角，见[读法](../读法.md)）

## 不收什么

- 没有出处的地摊故事
- 把"传说"当"史实"、把"我记得"当"记载"

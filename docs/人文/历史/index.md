# 历史

> 事情是怎么变成现在这样的。

## 收什么

- 时间线：把散落的事件排成一条能读的线
- 因果解释：为什么会这样，有哪些竞争性解释
- 史料与出处：这条说法来自哪本书、哪份档案、哪一方
- 常见误传的纠正：流传很广但站不住的说法，错在哪

## 不收什么

- 没有出处的地摊故事
- 把"传说"当"史实"、把"我记得"当"记载"

## 条目

还没有条目。第一条建议写**一个你原本信、后来被证据推翻的说法**，并写清推翻它的是什么。

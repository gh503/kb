# 为什么中国和欧洲在近代分岔了

> **学段** 小学–初中 ｜ **类型** 对比 ｜ **链** 大分流

## 结论

不是"谁更聪明"，而是**条件组合不同**：劳动力多寡、能源位置、海外资源、战争压力。
同样的技术和制度，在不同条件下会走向不同结果。

## 先看事实

- **事实**：18 世纪中期，中国江南与英国的生活水平差距并不大，这一点有消费与工资数据的支持（但估计方法有争议）
- **事实**：工业革命首先发生在英国，随后扩散到西欧
- **事实**：中国在 19 世纪中期以后明显落后，差距在 19–20 世纪拉大

## 几种候选解释

1. **劳动力便宜**：人多地少，省力技术的需求弱（详见[土地多是不是优势](土地多是不是优势.md)）
2. **能源位置**：英国煤田靠近地表、靠近运输线（详见[煤和殖民地谁更重要](煤和殖民地谁更重要.md)）
3. **海外资源**：美洲的土地与白银，缓解了欧洲的生态压力
4. **战争竞争**：欧洲多国竞争，财政—军事压力强（见[为什么欧洲靠国债打仗](为什么欧洲靠国债打仗.md)）
5. **制度与产权**：可信承诺、专利、资本市场

## 边界

- "分岔"是事后叙述，当时人并不知道自己站在岔口
- 差距是渐进的，19 世纪才变得显著
- 中国内部差异很大：江南、华北、西北完全不同
- 单一原因解释都站不住，竞争的是"哪个条件更关键"

## 误解

- **"中国一直落后"**——18 世纪前并不成立
- **"欧洲因为思想先进"**——思想与技术之外，资源与地理同样关键

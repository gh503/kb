# 为什么会有专利制度

> **学段** 初中–高中 ｜ **类型** 动因 ｜ **链** 技术与社会

## 结论

因为**保密会带走技术**。给发明人一段时间的排他权，换取他把方法公开写清楚——
政府得到可传播的知识，发明人得到回报，后来者可以在此基础上改进。

## 机制

1. 没有保护时，发明人只能靠保密，技术随人亡而失传
2. 排他权（专利）把"秘密"换成"公开的垄断"
3. 公开的说明书让知识进入公共记录，可被检索与改进
4. 期限届满后进入公有领域，任何人可用
5. 代价是短期垄断价格与可能的诉讼成本

## 时间线

```text
1474 年：威尼斯颁布专利法，常被视为较早的成文制度
1624 年：英国《垄断法》限制王室滥授垄断，同时保留真正的发明保护
19 世纪：主要工业化国家逐步建立现代专利制度
```

## 事实与判断

- **事实**：专利制度的核心交易是"公开换保护"，说明书要足以让同行实施
- **事实**：不同国家对软件、药品、生物材料的专利范围差异很大
- **判断**："专利促进创新"证据混合：它确实促进了信息公开与技术扩散，但也可能造成专利丛林、阻碍后续改进；效果取决于审查质量与诉讼成本

## 边界

- 有些行业靠商业秘密更划算（配方、工艺参数）
- 专利对弱小发明人未必友好，诉讼成本可能高于收益
- 强制许可、公共研究豁免是常见的平衡机制

## 误解

- **"专利就是保护发明人的自然权利"**——它是政策工具，不是自然权利
- **"有专利就有创新"**——专利数量是投入指标，不等于实际创新

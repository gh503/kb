# 为什么古人活得不比祖先富多少

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 生活水平与增长

## 结论

因为**多打的那点粮食，很快被多生的人吃掉**。技术缓慢进步，人口跟着增长，
人均收入被拉回原来的水平——这就是"马尔萨斯陷阱"。

## 机制

1. 农业社会产出主要靠土地与人力
2. 技术进步慢，产量提高有限
3. 收入一提高，婚育提前、人口增加
4. 人口增加又摊薄人均土地与产出
5. 于是人均生活水平长期在生存线附近波动

## 量级（长期观察，估计值）

```text
工业革命前的人均收入：长期在很窄的区间内波动
寿命：长期在三四十岁上下（受婴幼儿死亡率拉低）
年均增长率：多数时期接近零，偶尔负增长（灾荒、瘟疫）
```

## 事实与判断

- **事实**：工业革命前，多数社会的人均产出在数百年里变化很小
- **事实**：大瘟疫后劳动力短缺，工资曾明显上升，说明人口与工资确实联动
- **判断**："马尔萨斯陷阱"是有效的长期概括，但不能解释所有波动：战争、贸易、制度变化也会造成阶段性上升

## 边界

- 城市与农村、沿海与内陆差异很大，平均数会掩盖分化
- 有些地区靠贸易与手工业突破了陷阱（如近代早期的荷兰）
- 死亡率冲击（瘟疫）能短期提高人均收入

## 误解

- **"古人比我们穷是因为技术差"**——技术差只是一半，人口压力同样关键
- **"工业革命前完全没有增长"**——有波动与局部增长，只是不能持续

# 为什么古代也有国际规则

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 条约与贸易

## 结论

因为**国家之间也要重复打交道**：打不完就得谈，谈成了要留凭证，
于是形成会盟、和亲、朝贡、通商口岸这类规则。规则不是善意，是长期博弈的产物。

## 机制

1. 相邻政权长期共存，战争成本高、收益不确定
2. 反复互动产生惯例：使者怎么接待、边界怎么划、贸易在哪做
3. 惯例被写下来，成为盟约、条约、礼制
4. 实力强者定规则，弱者在框架内争取空间
5. 规则降低每次交涉的成本，也固化既有强弱格局

## 几种形态

| 形态 | 特点 | 例子 |
| --- | --- | --- |
| 朝贡 | 以礼制与名义尊卑包装贸易 | 东亚的朝贡秩序 |
| 会盟 | 多方约定边界与互不侵犯 | 春秋时期的盟誓 |
| 通商条约 | 规定关税、居留、最惠待遇 | 19 世纪的不平等条约 |

## 事实与判断

- **事实**：东亚长期存在以朝贡礼制为框架的交往秩序，同时有大量实际贸易
- **事实**：19 世纪中国与列强签订了一系列通商条约，关税与司法条款多由外方主导
- **判断**："朝贡是贸易的包装"有较强证据；但把它纯粹看成贸易、忽略礼制与政治含义，也不完整

## 边界

- 规则只约束愿意遵守的一方，实力差距大时约束力弱
- 名义上的尊卑与实际利益常不一致
- 不同区域的规则体系（东亚、欧洲、伊斯兰世界）逻辑不同，不能直接套用

## 误解

- **"古代没有国际法"**——有惯例与条约，只是没有近代主权国家体系
- **"朝贡就是赔钱"**——朝贡回赐有成本，但换来的贸易与安全收益也要算

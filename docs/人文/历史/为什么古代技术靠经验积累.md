# 为什么古代技术靠经验积累

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 技术与社会

## 结论

因为**试错的成本低、记录与传播的成本高**。匠人靠师徒口传身授，一次改进要很多年才扩散；
没有可复现的实验方法，知识就难以累积成体系。

## 机制

1. 技术改进多来自长期操作中的经验调整
2. 经验藏在手上，难以写成文字，只能师徒相传
3. 没有统一度量与实验记录，结果难以比较与复现
4. 行会制度保护手艺，也限制外传
5. 因此技术会在某些领域很精（陶瓷、冶金），但难以系统推进

## 例子

- **事实**：中国古代有《考工记》《天工开物》这类技术著作，记录了大量工艺
- **事实**：欧洲中世纪的行会严格规定学徒年限与技术秘密
- **判断**："经验积累"不等于"没有理论"；许多工艺包含朴素的经验规律，只是没有形成可检验的模型

## 事实与判断

- **事实**：古代有《考工记》《天工开物》等技术著作，记录了成体系的工艺规范
- **事实**：欧洲中世纪行会严格规定学徒年限，技术秘密受行规保护
- **判断**："经验积累"不等于"没有理论"：许多工艺内含经验规律，只是缺少可检验的模型

## 边界

- 有些领域很早就系统化（历法、水利、建筑），依赖国家组织的测量与记录
- 战争与大型工程会强制推动标准化与记录
- 经验技术一旦遇到新材料、新尺度，往往失效——这正是需要理论的地方

## 误解

- **"古代技术就是碰运气"**——有大量经验规则与工艺标准
- **"有理论才能有技术"**——很多技术先于理论出现

# 为什么古代用铜钱和银子两种钱

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 货币与信用

## 结论

因为**面额要匹配交易规模**：买一个烧饼用铜钱，交一笔税、做一桩大买卖用银锭。
币材的价值密度不同，就自然分成"零钱"和"大钱"。

## 机制

1. 铜价值低，适合小额；白银价值高，适合大额
2. 铜钱民间日常流通，白银多用于税收、批发、跨区贸易
3. 两者比价会波动：铜钱铸多了就贬值（"钱轻"）
4. 政府收税常指定用银，推动白银货币化
5. 两种币材并存，就产生兑换、成色、称量等一整套技术

## 量级（示意，因朝代差异大）

```text
铜钱：以"文"计，一贯常为 1000 文
白银：以"两"计，需称量与验成色
金银比价：长期在 1:10 到 1:15 区间波动（不同时期差异大）
```

## 事实与判断

- **事实**：中国长期是铜钱与白银并用的双币材体系，明代财政进一步白银化
- **事实**：铜钱贬值、私铸、劣钱问题贯穿历代
- **判断**："面额匹配"是基础解释；但双币材并存也带来比价风险，并非纯粹方便

## 边界

- 有些时期纸币、绢帛也充当货币
- 白银在中国长期是称量货币，不是 counted coin
- 比价波动会直接影响农民交税的负担（见[白银为什么能救明朝也害了明朝](白银为什么能救明朝也害了明朝.md)）

## 误解

- **"古代只有铜钱"**——大额交易与税收大量用银
- **"银子按个花"**——要称重、验成色，是"称量货币"

# 为什么增长能持续

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 生活水平与增长

## 结论

因为**增长的动力从"多投入"变成了"更会做"**：机器、煤、资本可以越堆越多，
但真正让增长不停的是效率提高——同样的投入产出更多，而且改进会累积。

## 两种增长

| 类型 | 来源 | 能否持续 |
| --- | --- | --- |
| 投入型 | 更多劳动力、更多土地、更多资本 | 会递减，最终停滞 |
| 效率型 | 技术、组织、分工、知识 | 可以累积，长期不递减 |

## 机制

1. 资本边际报酬递减：只加机器，产出增长会越来越慢
2. 技术进步提高全要素生产率（同样的资本与劳动产出更多）
3. 知识可以复用：一项改进不会因为被使用而耗尽
4. 市场扩大带来分工深化，进一步降成本
5. 于是人均产出能持续上升，而不被人口增长吃掉

## 量级

```text
年均增长 2%：约 35 年翻一倍
年均增长 0.1%：约 700 年翻一倍
工业革命前与之后的差距，主要来自这个"年增长率"的量级差别
```

## 事实与判断

- **事实**：长期增长核算显示，效率提升（而非单纯资本积累）是持续增长的主要来源
- **事实**：19 世纪以后，多个国家的人均收入出现了持续上升
- **判断**："效率型增长能持续"是较稳的结论；但具体国家的表现差异很大，制度与开放程度影响明显

## 边界

- 效率提升不会自动发生，需要教育、研发、竞争与开放
- 增长成果的分配可能极不均，平均数掩盖分化
- 资源与环境约束会改变增长的成本结构
- 追赶型增长（模仿）与前沿型增长（创新）机制不同

## 误解

- **"多投资就能增长"**——没有效率提升，投资会递减
- **"增长会自动惠及所有人"**——分配是另一件事

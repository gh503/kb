# 为什么欧洲靠国债打仗

> **学段** 大学–研究生 ｜ **类型** 对比 ｜ **链** 财政与王朝

## 结论

因为欧洲的战争融资发展出了**长期公债 + 可信的偿还承诺**：债权人相信钱会还，
利率就低，能借的规模就大。明清靠加派与捐纳，一次性收钱，没有可持续的借债机制。

## 机制

1. 战争成本上升（火药、常备军、要塞），单靠当年税收不够
2. 威尼斯、热那亚较早发行强制性公债，形成二级市场
3. 荷兰：阿姆斯特丹银行与东印度公司，低利率长期借款
4. 英国 1694 年设英格兰银行，国债由议会担保，利率显著低于欧陆君主
5. 代议机构让"还钱承诺"可信：借新还旧成为常规操作

## 对比表

| 维度 | 明清中国 | 近代早期欧洲 |
| --- | --- | --- |
| 主要筹款方式 | 加派、捐纳、盐税 | 长期公债、银行 |
| 债权人保护 | 弱，皇权可赖账 | 较强，议会/城市担保 |
| 利率 | 高（风险溢价） | 逐步走低 |
| 可持续性 | 一次性，易激化矛盾 | 可滚动，摊到未来 |

## 事实与判断

- **事实**：英国国债规模在 18 世纪大幅扩张，利率长期低于法国
- **事实**：明清财政以实物与银两正赋为主，缺乏常规公债市场
- **判断**："可信承诺 → 低利率 → 军事优势"这一因果链（诺思与温加斯特等的解释）有解释力，但**不是唯一路径**；法国也能借债，只是成本更高；奥斯曼、俄国走的是另一条路

## 边界

- 公债不是"免费的午餐"：利息要用税收偿还，长期会挤出其他支出
- 可信承诺需要制度，制度又依赖政治博弈的结果
- 样本选择偏差：欧洲的成功案例被反复研究，失败案例较少被比较

## 争议与未解

- 制度（议会）与财政能力谁先谁后，因果方向仍有争论
- "财政军事国家"能否解释欧洲崛起，还是地理与殖民掠夺更关键
- 中国明清是否真的"没有公债"——存在捐输、生息银两等准债务工具，边界模糊

## 到此为止

这一层是**制度与融资成本**：能不能低成本借到长钱，
在一个长周期里会放大成军事与国家的差距。

# 为什么滥发货币会通胀

> **学段** 初中–高中 ｜ **类型** 量级 ｜ **链** 货币与信用

## 结论

因为钱变多而东西没变多，**同样的货要更多的钱去买**。物价上涨不是商人都变坏了，
是货币与商品的相对数量变了。

## 机制

1. 交易需要的货币量 ≈ 物价 × 交易量 ÷ 货币流通速度
2. 商品与交易量短期不变，货币数量翻倍，物价大致也会涨
3. 政府缺钱时最容易"铸小钱、掺杂质、多印钞"
4. 货币贬值 → 物价上涨 → 政府实际收入反而下降 → 再印
5. 这就是"通胀税"：不用加税，就把购买力从民众手里转移走

## 历史例子

- **事实**：历代都有"铸钱减重"导致的钱轻物贵
- **事实**：元、明两代都发行过纸币（钞），因滥发而信用崩坏
- **判断**："滥发导致通胀"机制清楚，但具体涨幅取决于流通速度、预期与替代货币

## 边界

- 物价上涨也可能来自供给冲击（灾荒、战争），不能一律归因于货币
- 有替代货币（白银、外币）时，本币滥发会先被抛弃，而不是先通胀
- 通胀对债务人有利、对固定收入者有害
- 短期的"钱荒"与"钱多"可以同时存在于不同地区

## 误解

- **"物价涨就是奸商囤积"**——货币数量是更基础的原因
- **"印钱能增加财富"**——只是重新分配购买力

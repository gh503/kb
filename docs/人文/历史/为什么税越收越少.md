# 为什么税越收越少

> **学段** 初中–高中 ｜ **类型** 动因 ｜ **链** 财政与王朝

## 结论

因为**税基会自己流失**：土地向免税的士绅集中、人口被隐匿、徭役折成银两后又按旧额摊派。
制度不动，能收的东西一年比一年少。

## 机制

1. 农业社会的税基 = 登记在册的土地 + 人口
2. 士绅、宗室、寺院享有免赋或优免，土地"投献"到他们名下就退出税册
3. 人口隐匿：新增人口不登记，负担压在留下的"户"上
4. 徭役折银（如一条鞭法）把实物与力役合并折银，征收更方便，但**总额固定**
5. 银价、物价一变，固定银额的实际负担就变；再加派 → 逃亡 → 税基更小

## 一条鞭法与"黄宗羲定律"

- **事实**：明万历年间推行一条鞭法，把田赋、徭役、杂税合并，按田亩折银征收
- **事实**：并税后，新的杂派仍会以不同名目出现，后代学者概括为"黄宗羲定律"
- **判断**：这条"定律"是对历史现象的归纳，不是严格的制度必然；有些时期确实做到了长期简化

## 边界

- 商业税、关税、盐专卖可以成为新税基，但需要市场与行政能力
- 战争时期的加派往往绕过常规制度，短期有效、长期破坏税基
- 统计口径不同，"税收减少"可能只是白银计价变化，不是实物减少

## 事实与判断

- **事实**：明代推行一条鞭法，赋役合并折银；此后仍有新的加派出现
- **事实**：历代都有土地"投献"、人口隐匿的记载
- **判断**："税基会自己流失"是制度性观察，不是每一朝都同样严重；商业税与关税可以部分弥补

## 误解

- **"税越轻越好"**——税太轻则国家无力赈灾、修水利、养兵，风险由民众自担
- **"并税就能一劳永逸"**——合并税种只解决名目混乱，不解决税基流失

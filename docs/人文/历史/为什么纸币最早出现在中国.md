# 为什么纸币最早出现在中国

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 货币与信用

## 结论

因为四川用**铁钱**，又重又贱，大额交易要推车运钱。商人先自发开出可兑换的凭证，
政府随后接手发行——**纸币是"运输成本"逼出来的信用工具**。

## 机制

1. 四川铁钱价值低，一贯钱重达数斤甚至更多，携带困难
2. 商人发行"交子"：存钱给凭证，凭券异地或异地兑现
3. 分散发行易出欺诈与挤兑，信誉好的商户胜出
4. 1023 年前后，政府设"交子务"，把发行权收归官办
5. 官办之后，发行逐渐与财政需求挂钩，超发就贬值

## 时间线

```text
北宋前期：四川民间出现交子
1023 年前后：官府设交子务，交子官办
元代：发行中统钞等纸币，成为主要货币
明代：洪武年间发行宝钞，后因滥发而废
```

## 事实与判断

- **事实**：交子被视为世界上较早的纸币，起源于四川民间
- **事实**：元明纸币都因发行过量而信用崩坏
- **判断**："铁钱太重 → 信用凭证 → 官办 → 超发 → 崩溃"这条链有史料支持；但纸币能出现，前提是**造纸与印刷技术 + 商人信用网络**，两者缺一不可

## 边界

- 纸币不是"突然发明"，而是从存款凭证、汇兑工具演化来的
- 官办带来信誉，也带来财政滥用的可能
- 没有成熟的税收与结算体系，纸币难以长期维持
- 欧洲的纸币/银行券出现更晚，但走了不同的信用路径

## 误解

- **"纸币是中国独创的金融发明"**——是信用工具演化的结果，多地独立出现过类似凭证
- **"纸币一出现就取代金属货币"**——长期并存，金属货币仍是价值锚

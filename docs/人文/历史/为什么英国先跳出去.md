# 为什么英国先跳出去

> **学段** 初中–高中 ｜ **类型** 动因 ｜ **链** 生活水平与增长

## 结论

因为**几个条件恰好叠在一起**：工资高（有动力用机器）、煤便宜（有动力）、
市场大（有需求）、制度能融资（有钱）。缺一样，突破都可能推迟很久。

## 四个条件

1. **要素价格**：工资相对高、煤价低 → 用机器替代人划算（见[土地多是不是优势](土地多是不是优势.md)）
2. **能源**：煤田近地表、近运输线 → 突破森林约束（见[煤和殖民地谁更重要](煤和殖民地谁更重要.md)）
3. **市场**：海外贸易与殖民地 → 棉花、糖、白银与出口市场
4. **融资与制度**：专利、公司、国债、银行 → 能把钱组织起来（见[为什么欧洲靠国债打仗](为什么欧洲靠国债打仗.md)）

## 为什么是"跳出去"而不是"慢慢变富"

- 前工业社会的增长会被人口增长吃掉
- 一旦机器与化石能源加入，产出增长可以快于人口
- 于是人均收入开始持续上升，而不是回到原位
- 这条路径一旦形成，会自我强化（更多机器、更多煤、更多市场）

## 事实与判断

- **事实**：工业革命首先出现在英国，棉纺织业是突破口
- **事实**：英国在 18 世纪已有较高的工资水平与便宜的煤
- **判断**："多条件叠加"比"单一原因"更稳；哪个条件最关键，学界仍在争论（见[大分流有定论吗](大分流有定论吗.md)）

## 边界

- 英国的特殊性不等于"别国照抄就能成功"
- 早期工业化伴随极差的工作条件与童工
- 殖民地与奴隶制的收益是真实存在的，不能略去

## 误解

- **"英国因为聪明才领先"**——条件与运气同样重要
- **"工业革命是一夜之间发生的"**——是几十年的渐进过程

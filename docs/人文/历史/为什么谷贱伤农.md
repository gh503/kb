# 为什么谷贱伤农

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 灾荒与仓储

## 结论

因为粮食**需求很稳定、供给却会突然变多**。丰收时大家都要卖粮，价格被压到很低；
农民卖得越多、亏得越多。这就是"谷贱伤农"——伤人的不是缺粮，是价格。

## 机制

1. 粮食是必需品：人一天吃多少，不会因为便宜就多吃一倍
2. 需求对价格不敏感（弹性小）
3. 供给受天气影响，丰产时集中上市
4. 供给一多，价格跌得比数量涨得快
5. 农民的收入 = 价格 × 数量，价格跌得狠，总收入反而下降

## 反过来也成立

- 灾年粮价飞涨，"谷贵伤民"：城市与缺粮地区买不起
- 所以历代政策目标常常是**稳价**，而不是"越高越好"或"越低越好"
- 政府用储备粮"贱买贵卖"，就是在两头做缓冲

## 事实与判断

- **事实**：古代文献早就有"籴甚贵伤民，甚贱伤农"的说法
- **事实**：历代都设仓储，丰年收粮、荒年放粮
- **判断**："谷贱伤农"是价格机制的结果，不是道德问题；但把粮价完全固定，也会带来黑市与短缺

## 边界

- 有储粮设施与运输能力的地区，价格波动小
- 经济作物（棉、桑）波动更大，因为需求更不稳定
- 现代有期货、保险、最低收购价等工具，机制不同但目标类似

## 误解

- **"丰收一定增收"**——价格弹性小的时候，丰收可能减收
- **"粮价越低越好"**——过低会打击生产意愿

# 为什么贸易逆差会让白银外流

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 白银外流

## 结论

因为**买东西要付钱，卖东西才收钱**。进口多于出口，差额就得用白银补；
白银是当时的"国际货币"，账不平，银子就走。

## 机制

1. 各国用白银结算国际贸易
2. 进口 > 出口 → 需要拿白银补差额
3. 白银流出 → 国内银少 → 银贵钱贱
4. 银贵 → 用铜钱计的税负实际加重
5. 政府若禁止白银外流，走私与黑市就出现

## 量级（示意）

```text
贸易差额 = 出口值 − 进口值
差额为正：白银流入；为负：白银流出
19 世纪前期，中国对英贸易由出超转为入超
```

## 事实与判断

- **事实**：18 世纪中国长期处于贸易顺差，白银大量流入
- **事实**：19 世纪前期白银流向逆转，出现持续外流
- **判断**："逆差导致白银外流"是机制层面的必然；但具体规模依赖统计口径，当时的贸易数据并不完整

## 边界

- 白银外流不等于经济崩溃，还要看国内货币需求
- 走私贸易不入关册，官方统计常低估
- 同期全球白银产量与流向也在变化，不能只看双边贸易

## 误解

- **"逆差就是吃亏"**——逆差本身是中性的，问题在用什么支付、能否持续
- **"禁银出口就能止住外流"**——会转向走私，效果有限

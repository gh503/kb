# 为什么金本位会崩溃

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 货币与信用

## 结论

因为**固定汇率、独立货币政策、资本自由流动三者不能同时成立**（三元悖论），
而战争与危机逼各国优先保国内经济——于是金平价守不住，只能放弃。

## 机制

1. 金本位把本币与黄金固定，汇率随之固定
2. 贸易逆差国要用黄金支付，国内货币收缩、物价下跌、失业上升
3. 战争需要大量支出，印钞与黄金兑换承诺冲突
4. 危机时各国竞相贬值、限制黄金外流，体系瓦解
5. 战后重建的布雷顿森林体系（美元挂钩黄金）在 1971 年终止兑换

## 时间线

```text
19 世纪：主要国家相继采用金本位
1914 年：一战爆发，黄金兑换普遍中断
1925 年：英国按战前平价恢复金本位
1931 年：英国放弃金本位
1944 年：布雷顿森林体系建立
1971 年：美国停止美元兑换黄金
```

## 事实与判断

- **事实**：金本位在两次大战之间多次中断与恢复，1930 年代普遍放弃
- **事实**：放弃金本位较早的国家，恢复得相对较快（有研究支持这一相关性）
- **判断**："金本位加剧大萧条"是有影响力的解释（如伯南克的研究），但反对意见认为货币政策失误、银行危机、财政紧缩同样关键，金本位只是传导机制

## 边界

- 金本位提供长期价格稳定，但短期调整成本高
- 固定汇率对贸易有利，对就业调整不利
- 现代货币体系没有商品锚，靠央行信誉与制度约束
- "回到金本位"的提议在经济学界缺乏支持，但作为约束通胀的思路仍被讨论

## 争议与未解

- **因果强度**：金本位是萧条的起因，还是放大器，计量研究结论不一
- **反事实**：如果当年不恢复金本位，萧条会不会更轻，无法检验
- **可信度 vs 灵活性**：规则与相机抉择的取舍，至今没有共识

## 到此为止

这一层是**制度取舍的硬约束**：金本位不是"坏制度"，
而是把调整压力全压在物价与就业上，在战争与危机面前撑不住。

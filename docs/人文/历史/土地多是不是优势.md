# 土地多是不是优势

> **学段** 初中–高中 ｜ **类型** 动因 ｜ **链** 大分流

## 结论

**人多地少时，劳动力便宜，就不急着省人力**；人少地多、工资高时，才愿意花钱买机器替代人。
所以"土地多"未必是优势，关键看**劳动力和土地的相对价格**。

## 机制（诱导性创新）

1. 要素价格决定技术方向：哪种要素贵，就想办法省哪种
2. 中国江南：人口密集、工资低，精耕细作与手工劳动更划算
3. 英国：工资相对高、煤便宜，用机器替代人力更划算
4. 于是同样是"技术进步"，一边走向劳动密集，一边走向资本密集
5. 这条路径一旦形成，会自我强化（设备、技能、组织都跟着变）

## 量级（估计值，需谨慎）

```text
18 世纪英国实际工资：高于同期江南（不同研究差异较大）
中国人口：18 世纪已达数亿量级
人均耕地：江南明显低于英国
```

## 事实与判断

- **事实**：要素价格差异是经济史的常规观察，英国工资相对较高、煤价较低
- **事实**：中国农业长期以劳动密集的精耕细作为主
- **判断**："要素价格诱导技术方向"是解释力较强的框架（速水—拉坦传统），但它解释"为什么用机器"，不解释"为什么能发明机器"

## 边界

- 高工资也可能抑制投资，未必自动带来机械化
- 技术与科学知识储备是前提，价格只是"方向信号"
- 中国也有机械发明（如水排、纺织工具），只是没有形成持续加速
- 把"人多"说成唯一原因，会忽略能源与市场

## 误解

- **"人多所以穷"**——人多也可能带来更大市场与分工
- **"劳动力便宜所以没技术进步"**——技术仍会进步，只是方向偏向省地、省料

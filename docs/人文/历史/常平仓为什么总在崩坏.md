# 常平仓为什么总在崩坏

> **学段** 初中–高中 ｜ **类型** 动因 ｜ **链** 灾荒与仓储

## 结论

因为仓储要**长期花钱、短期看不见收益**：粮会霉、仓要修、官要养，
而"平抑粮价"的好处分散在所有人身上。一旦财政紧张或考核走偏，它最先被挪用。

## 制度设计（本来想做什么）

1. 丰年以略高于市价收粮，防止谷贱伤农
2. 荒年以略低于市价放粮，防止谷贵伤民
3. 用价差与储备量维持粮价在区间内
4. 兼作赈灾、军粮、平抑投机的物资基础

## 为什么崩坏

1. **损耗**：粮食有保质期，存几年就霉变、被虫鼠吃掉
2. **挪用**：地方财政紧张时，仓粮是最容易变现的资产
3. **考核**：官员任期短，盘仓、修仓是"只有成本没有政绩"的事
4. **亏损**：贱买贵卖做反了（高价收、低价放）就亏空，只能卖粮补账
5. **腐败**：虚报库存、以次充好，"账上有粮、仓里没有"

## 事实与判断

- **事实**：常平仓自汉代设立后历代沿用，另有义仓、社仓等形态
- **事实**：历代都有"仓廪空虚""盘粮亏空"的记载
- **判断**："制度设计合理但执行崩坏"是常见解释；也有研究强调，根本问题是**财政能否长期供养**这套系统

## 边界

- 仓储对局部、短期冲击有效（一州一县歉收）
- 对长期战争、运输中断、全国性灾荒，作用有限
- 商业化的粮食市场发达时，仓储的平抑作用会被市场替代部分
- 仓储成本高，不等于不该建——要看它避免的损失有多大

## 误解

- **"有粮仓就不会饿死人"**——分配与运输同样关键
- **"仓储崩坏是因为官员坏"**——激励与财政约束才是稳定原因

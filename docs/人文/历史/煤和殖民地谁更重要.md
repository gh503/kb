# 煤和殖民地谁更重要

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 大分流

## 结论

两者都重要，但**作用不同**：煤解决"能源瓶颈"（能不能持续加力），
殖民地解决"土地瓶颈"（有没有足够的粮食、棉花、白银）。彭慕兰把两者放在一起，
作为解释英国"逃出生态困境"的关键。

## 机制

1. 前工业经济以有机物为基础：粮食、木材、畜力，土地是最终约束
2. 英国煤田靠近地表、靠近海岸与运河，运输成本低
3. 煤替代木材，突破了"森林面积"对能源的限制
4. 美洲殖民地提供棉花、糖、白银与移民出口，缓解土地压力
5. 两条瓶颈同时被打开，工业才能持续加速

## 对比

| 条件 | 英国 | 中国（江南） |
| --- | --- | --- |
| 煤的位置 | 煤田近地表、近运输线 | 煤多在北方，远离经济中心 |
| 海外资源 | 美洲殖民地 | 无同等规模的海外供给 |
| 土地压力 | 靠进口与移民缓解 | 靠精耕细作与复种 |

## 事实与判断

- **事实**：英国煤炭产量在 18–19 世纪快速增长，是工业化的能源基础
- **事实**：美洲殖民地为欧洲提供棉花、糖、白银等大宗商品
- **判断**："煤 + 殖民地"是彭慕兰《大分流》的核心解释，影响力大；批评者认为它低估了技术、科学与制度的作用，而且"如果欧洲没有煤会怎样"的反事实难以检验

## 边界

- 有煤不等于会用煤：开采、运输、使用都需要技术与资本
- 殖民地的收益分配极不均，且伴随暴力与奴隶制
- 中国并非没有煤，问题是运输成本与经济中心的位置
- 反事实推理容易过度延伸

## 误解

- **"英国赢在煤多"**——赢在煤便宜且好运，不是储量大
- **"殖民地让欧洲变富"**——有贡献，但净收益规模仍是争论点

# 王朝为什么会亡于财政

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 财政与王朝

## 结论

因为王朝后期**支出涨得比收入快**：军费、官俸、宗室、赈灾一起涨，而税收制度僵化收不上来。
于是加税 → 农民逃亡或隐匿 → 税基更小 → 再加税。这个循环走到头，就是崩溃。

## 机制

1. 开国时人少地多，税基宽、税率低也能收够
2. 承平日久，官僚机构膨胀，宗室人口按代数翻倍，支出刚性上升
3. 土地向免赋的士绅集中，纳税人口减少（详见[为什么税越收越少](为什么税越收越少.md)）
4. 战争、灾荒是突发大额支出，只能靠"加派"
5. 加派落在还留在户籍上的农民头上 → 逃亡 → 税基进一步缩小

## 事实与判断

- **事实**：明末在正赋之外加派辽饷、剿饷、练饷，合称"三饷"；清初曾宣布废除，后又因军费恢复类似加派
- **事实**：历代都有"并税—杂派重生"的循环，黄宗羲在《明夷待访录》里批评过这一点
- **判断**："财政崩溃导致王朝灭亡"是解释框架之一，不是唯一解释；气候、军事技术、地方治理失效都在起作用

## 边界

- 不是所有王朝都亡于财政：外族征服、继承危机、地方割据都可能更直接
- 财政危机常常是"慢性病"，最后一击往往来自战争或天灾
- 加税不一定立刻造反，关键看**负担落在谁身上、能否转嫁**
- 有些王朝靠海外白银、盐税、关税续命（见[白银为什么能救明朝也害了明朝](白银为什么能救明朝也害了明朝.md)）

## 误解

- **"亡国是因为皇帝昏庸"**——个人因素有影响，但财政结构是更稳定的约束
- **"加税就能解决"**——在农业社会，税基是土地和人口，加过头反而缩小税基

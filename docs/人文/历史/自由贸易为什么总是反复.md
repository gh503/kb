# 自由贸易为什么总是反复

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 条约与贸易

## 结论

因为**收益分散、损失集中**：开放让消费者每人省一点，却让受冲击的行业一次亏很多。
受损者组织起来游说，受益者难以组织，于是政策在开放与保护之间摆动。

## 机制

1. 自由贸易提高总体效率，但会重新分配收入
2. 出口部门与消费者受益，分散且不易动员
3. 进口竞争部门受损集中，有强烈动机游说
4. 萧条或失业上升时，保护主义更有政治市场
5. 一旦别国报复，开放又会退得更快

## 历史上的来回

- **事实**：英国 1846 年废除谷物法，转向自由贸易
- **事实**：19 世纪后期欧洲多国重新提高关税，保护本国农业与工业
- **事实**：1930 年代大萧条期间，多国大幅提高关税、限制进口
- **判断**："开放—保护"的反复与萧条周期、选举政治高度相关，而非单纯观念胜负

## 事实与判断

- **事实**：英国 1846 年废除谷物法；19 世纪后期多国重新提高关税
- **事实**：1930 年代大萧条期间，多国大幅提高关税并限制进口
- **判断**："开放—保护"的反复与萧条周期、选举政治高度相关，不能只归因于观念胜负

## 边界

- 自由贸易的收益依赖调整能力：劳动力能否转移、社保能否兜底
- 单边开放与互惠开放的政治效果不同
- 关税之外还有配额、标准、补贴等工具，形式更隐蔽
- 小国更依赖贸易，政策回旋余地小

## 误解

- **"自由贸易总是对所有人有利"**——总体有利，分配不均
- **"保护主义一定是错的"**——在特定条件下（幼稚产业、安全供给）有理由，但代价要算清

# 银贵钱贱伤了谁

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 白银外流

## 结论

**伤用铜钱挣钱、用白银交税的人**：农民、手工业者、小商贩。
银价涨、铜钱贬，同样一笔税要卖更多东西才够——这是一次隐形的加税。

## 机制

1. 日常交易用铜钱，纳税与大额结算用白银
2. 白银外流 → 银少 → 银对铜钱升值
3. 税额以银计：银贵则折成铜钱的负担上升
4. 收入以铜钱计的人群，实际税负被抬高
5. 同时物价下行（钱紧），卖东西的收入也下降

## 谁受损、谁受益

| 群体 | 收入/支出结构 | 受影响 |
| --- | --- | --- |
| 农民 | 收入铜钱，税银 | 受损最重 |
| 手工业者 | 收入铜钱 | 受损 |
| 持银者、放贷者 | 资产为银 | 受益 |
| 出口商 | 收入银 | 相对有利 |

## 量级（示意）

```text
银钱比价：从约 1:1000 上升到更高水平（各时期差异大）
税负变化 ≈ 银价涨幅（对以铜钱收入者）
```

## 事实与判断

- **事实**：19 世纪前期银钱比价上升，民间有大量"银贵钱贱"的记载
- **事实**：清政府税收以银计，农民以铜钱交易
- **判断**："银贵钱贱加重农民负担"是较有共识的解释；但它与太平天国等事件的关系，属于叠加因素，不宜单因归结

## 边界

- 不同地区的比价与税制差别大
- 政府若允许以钱折银纳税，冲击会被部分缓冲
- 同期灾荒、战争的影响可能更大，难以分离

## 误解

- **"银贵是好事，说明钱值钱"**——对持银者是好，对纳税农民是坏
- **"这只是货币问题"**——它直接改变收入分配

# 饥荒是食物不够还是分不到

> **学段** 高中–大学 ｜ **类型** 对比 ｜ **链** 灾荒与仓储

## 结论

**两种都有，但"分不到"被长期低估。** 森的研究指出：有些大饥荒发生时，
当地粮食产量并没有大幅下降，是特定人群**获取食物的权利**崩溃了——失业、粮价飞涨、救济中断。

## 两种解释

| 解释 | 主张 | 典型证据 |
| --- | --- | --- |
| 食物供给不足（FAD） | 产量下降导致总量不够 | 严重旱灾、战乱封锁 |
| 权利失灵（entitlement） | 总量够，但某些人买不起、拿不到 | 粮价暴涨、失业、救济中断 |

## 森的论证（简化）

1. 一个人能否吃到饭，取决于他的"交换权利"：劳动、生产、交易、转移（救济）
2. 饥荒常发生在粮价暴涨 + 工资下降 + 救济不足的时候
3. 1943 年孟加拉饥荒：森认为总产量并未显著低于常年，但购买力崩溃、恐慌性囤积推高价格
4. 结论：**饥饿是分配问题，不只是产量问题**

## 事实与判断

- **事实**：森在《贫困与饥荒》（1981）中系统提出权利方法
- **事实**：1943 年孟加拉饥荒的死亡人数估计在百万以上量级
- **判断**："产量没有显著下降"这一说法后来受到质疑：有研究认为当年确实存在减产与病害影响。争论的焦点变成"减产与分配失灵各占多少"，而不是"只有一种原因"

## 边界

- 权利方法擅长解释**有市场、有工资**的经济体，对完全自给自足的灾荒解释力弱
- 战争与封锁会同时造成产量下降与分配中断，难以分离
- 数据质量差：殖民时期的产量、价格、死亡登记都不完整
- 政策含义不同：一种指向增产，一种指向保收入与救济

## 误解

- **"饥荒都是因为天灾"**——分配与政策同样致命
- **"只要总量够就不会饿死人"**——买不起等于拿不到

# 哲学

> 那些没法用实验回答、但影响所有判断的问题。

## 收什么

- 概念区分：自由/自主、公平/平等、事实/价值这类容易混的对子
- 论证重构：把一个立场写成前提 + 结论，看它到底靠什么撑着
- 立场对照：每个立场取它最强的版本，再比较

## 不收什么

- 金句摘抄——脱离论证的句子没有信息量
- 只表态不推理的段落

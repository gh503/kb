# 为什么学科会分裂成两种文化

> **学段** 高中–大学 ｜ **类型** 对比 ｜ **链** 论证的成本

## 结论

因为**专业化让交流成本上升**：各自有术语、期刊、评价标准，
跨领域对话要先互相翻译。久而久之，人们不再读对方的作品，就以为"两种文化"天然对立。

## 分工带来的差异

| 维度 | 自然科学一侧 | 人文一侧 |
| --- | --- | --- |
| 主要产出 | 可重复的实验与模型 | 解释、论证、文本细读 |
| 评价方式 | 同行评议 + 复现 | 同行评议 + 论证质量 |
| 写作风格 | 简洁、量化 | 叙述、语境化 |
| 训练重点 | 方法、数学 | 语言、史料、理论 |

## 机制

1. 学科扩张导致术语与工具的专门化
2. 期刊与会议形成各自的评价圈
3. 教育分流：从中学开始就按文理分科（不同国家程度不同）
4. 相互不了解 → 用刻板印象代替阅读
5. 公共讨论中被放大成"科学与人文对立"

## 事实与判断

- **事实**：斯诺在 1959 年的演讲中提出"两种文化"的说法，引发长期讨论
- **事实**：各国中学教育普遍存在不同程度的文理分流
- **判断**："两种文化"是**制度分工**的产物，不是认知能力的天然鸿沟；把它当成不可逾越的对立，会遮蔽大量交叉研究

## 边界

- 交叉领域（认知科学、科学史、计算社会科学）一直在增长
- 研究者个体差异很大，不能按学科贴标签
- 分科也有收益：深度需要时间与专注

## 误解

- **"文科生不懂科学"**——是训练差异，不是能力差异
- **"两种文化注定冲突"**——多数冲突来自评价标准与资源竞争

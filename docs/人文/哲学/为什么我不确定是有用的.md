# 为什么"我不确定"是有用的

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 怀疑的代价

## 结论

因为**承认不确定，才会去查**。把"我以为"当成"我知道"，
就失去了纠错的机会；说一句"我不确定"，成本很低，收益是避免一个大错。

## 机制

1. 判断要基于证据，证据常常不完整
2. 自信过头会跳过检查，错误被放大
3. 承认不确定会触发验证：查资料、问人、做实验
4. 验证的成本通常远低于犯错的成本
5. 于是"我不确定"是一种便宜的保险

## 例子

- **事实**：科学论文常用"可能""在……条件下"来限定结论
- **事实**：工程与医疗领域有复核制度（双人核对、术前核查）
- **判断**："承认不确定"提高可靠性，但过度犹豫也有代价（见[怀疑要付出什么代价](怀疑要付出什么代价.md)）

## 事实与判断

- **事实**：许多重大错误来自"确信无疑"而非"信息不足"
- **事实**：复核制度能显著减少操作失误（如术前核查清单）
- **判断**：不确定本身不产生价值，**由不确定触发的检查**才产生价值

## 边界

- 有些场合必须快速决断，反复怀疑会误事
- 不确定的表达方式影响信任：过度 hedging 会显得没判断
- 该确定的地方要确定，比如已经反复验证过的事实

## 误解

- **"不确定就是没主见"**——是知道边界在哪
- **"自信才能成事"**——自信与准确是两回事

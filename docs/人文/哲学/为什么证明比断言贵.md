# 为什么证明比断言贵

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 论证的成本

## 结论

因为**断言只要一句话，证明要一串推理**：每一步都要有依据，还要能被别人检查。
贵在可检查性，但也正因为可检查，结论能被人复用而不必重新信一次。

## 机制

1. 断言的成本≈0：说出来就行
2. 证明要给出前提、推理步骤、结论，每步都可能被质疑
3. 检查证明也要成本：读者要懂符号、懂前提
4. 一旦证明成立，后来者不必重做，直接引用
5. 所以证明是"前期贵、后期便宜"的投资

## 例子

- **事实**：欧几里得《几何原本》用少数公理推出大量命题，被沿用两千多年
- **事实**：数学论文的审稿常围绕"这一步为什么成立"展开
- **判断**："证明比断言可靠"是共识；但证明的可信度取决于前提是否被接受，前提本身常是约定或假设

## 事实与判断

- **事实**：形式证明可以被机器检验，检查成本大幅下降
- **事实**：日常论证很少严格形式化，靠共识与例子支撑
- **判断**："贵"是相对的：在需要长期复用的领域，证明反而最省钱

## 边界

- 有些领域难以形式化（历史解释、文学批评），不等于不需要论证，只是论证方式不同
- 证明能保证"从前提推出结论"，不能保证前提为真
- 过度形式化会让论证失去可读性

## 误解

- **"证明就是绝对真理"**——只保证条件成立时结论成立
- **"不能证明就没有价值"**——经验、类比、案例也有认知价值

# 大学为什么能自我维持

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 知识怎么被供养

## 结论

因为它有**独立于年度拨款的资产 + 自治的法律地位**：捐赠基金、学费、特许状、终身教职。
钱不靠某一个人给，话才不必按某一个人的意思说。

## 机制

1. 中世纪大学靠特许状获得自治：自己定课程、自己授学位
2. 捐赠基金（endowment）把一次性捐赠变成长期收入
3. 学费提供稳定的现金流，但受招生规模约束
4. 终身教职降低"因言获罪"的风险，保护不受欢迎的观点
5. 专利、附属医院、科研经费成为现代补充来源

## 关键机制：基金

```text
捐赠基金：本金不动，每年支取一定比例（常见 4%–5% 规则）
优点：跨周期稳定，不受当年政治与市场波动直接影响
风险：投资亏损、支取过多、捐赠指定用途限制灵活性
```

## 事实与判断

- **事实**：中世纪博洛尼亚、巴黎等大学通过特许状获得自治权
- **事实**：美国大学普遍以捐赠基金支持长期运营，支取比例有行业惯例
- **判断**："财务独立 → 学术自由"是重要机制，但不是充分条件；资金来源结构、治理结构、政治环境共同决定独立性

## 边界

- 基金规模差异极大，多数学校并不"财务独立"
- 捐赠常附带用途限制，等于把赞助人的偏好长期化
- 学费依赖使学生人数与热门专业影响资源分配
- 自治从来不是绝对的，执照、认证、拨款都能形成约束

## 误解

- **"大学自古自由"**——自治是争来的，也多次被收回
- **"有钱就独立"**——钱的**结构**比数量更关键

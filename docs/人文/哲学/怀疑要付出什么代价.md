# 怀疑要付出什么代价

> **学段** 初中–高中 ｜ **类型** 量级 ｜ **链** 怀疑的代价

## 结论

怀疑的成本是**时间与行动能力**：每件事都要验证，就什么都做不成。
所以要按"错了有多严重"来分配怀疑——重要且不可逆的事多查，小事直接做。

## 两类成本

| 成本 | 说明 |
| --- | --- |
| 检验成本 | 查证、实验、请教他人所需的时间与资源 |
| 迟疑成本 | 因为不确定而推迟决定，错过时机 |

## 一个简单的判据

```text
该不该多查 ≈ 错误的代价 × 出错的概率 ÷ 检查的成本
```

- 错误代价高、检查便宜 → 值得查（用药剂量、合同条款）
- 错误代价低、检查昂贵 → 直接做（今天穿什么）
- 不可逆的事 → 提高检查强度（签字、删除、手术）

## 事实与判断

- **事实**： aviation 与医疗行业把大量检查做成固定流程，因为错误代价极高
- **事实**：日常决策中，人们常对小事过度纠结、对大事草率决定
- **判断**："按后果分配怀疑"是实用原则，但人对概率的估计常失准，需要外部流程补足

## 边界

- 无限怀疑会导向"什么都不做"，这不是严谨而是瘫痪
- 检查本身也会出错，需要抽查与复核
- 有些领域无法事先验证（长期后果），只能靠试错与退出机制

## 误解

- **"越谨慎越好"**——谨慎有边际成本
- **"怀疑就是不信任"**——对事的怀疑与对人的怀疑是两回事

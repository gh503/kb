# 笛卡尔为什么要怀疑一切

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 怀疑的代价

## 结论

因为**他要找一块不可动摇的地基**：把一切可疑的信念暂时清空，
看剩下什么必然为真。剩下的是"我正在怀疑"这件事本身——于是有我思故我在。

## 怀疑的层次（《第一哲学沉思集》）

1. 感官会骗人（远处的塔看起来是圆的）→ 感官不可全信
2. 梦境与清醒难以区分 → 连外部世界都可疑
3. 设想一个强大的欺骗者（"恶魔"）→ 连数学也可能被操纵
4. 但"我正在被欺骗/正在怀疑"这件事，必须有一个正在怀疑的"我"
5. 于是"我思"成为不可怀疑的起点

## 机制

1. 怀疑是**方法**，不是目的：为了找到确定的基础
2. 逐层剥离可怀疑的信念，直到剩下不可怀疑的
3. 剩下的命题必须"只要我在想，就不能是假的"
4. 由此重建知识：从"我存在"推出上帝、外部世界
5. 重建的那部分，后来的哲学家多认为不成立

## 事实与判断

- **事实**：笛卡尔在 1641 年出版《第一哲学沉思集》，系统使用方法论怀疑
- **事实**："我思故我在"（Cogito）是他体系的起点
- **判断**：方法论怀疑是有效的清理工具；但"从我思推出外部世界存在"这一步，被后世普遍认为有漏洞（循环论证）

## 边界

- 怀疑一切是思想实验，不是生活建议
- "我思"能确定的是"有思维活动"，未必能确定"有一个持久的自我"
- 他的重建依赖上帝存在的证明，这一步最受质疑

## 误解

- **"笛卡尔真的什么都不信"**——他是为了重建而暂时悬置
- **"我思故我在证明了灵魂不朽"**——那是进一步的论证，不是同一件事

# 重农抑商为什么是理性选择

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 观念与物质

## 结论

因为农业社会的**税基是土地和人口**，商业税难征、商人可迁移，粮食又直接关系军需与稳定。
压制商业不是"不懂经济"，而是在当时的征收能力下，把资源锁在能收得到的地方。

## 机制

1. 土地不动、人口登记，征税成本低
2. 商人流动性强，跨区经营，古代行政能力难以追踪
3. 粮食是军需与赈灾的硬约束，商人囤积会加剧波动
4. 商业利润高会吸引劳动力离开农业，减少税基与兵源
5. 于是政策倾向"本末"之分：农业为本，工商为末

## 但商业并没有消失

- **事实**：历代都有发达的市场与长途贸易，宋代城市商业尤为繁荣
- **事实**：盐、铁、茶等专卖本身就是大规模的官方商业
- **判断**："抑商"更多是**政治地位上的压制**（限制入仕、加重税、迁居控制），不是消灭市场

## 边界

- 商业税在行政能力提升后变得重要（宋代商税比重上升）
- 抑商常与"重农"一起出现，但执行力度因朝代、地区差异很大
- 把"重农抑商"读成"反对一切贸易"，会误判古代经济
- 战争时期对商人的征调，往往比平时更重

## 误解

- **"古代中国没有商业"**——有，而且规模不小
- **"抑商是愚蠢的政策"**——在低征收能力条件下，它是可解释的选择

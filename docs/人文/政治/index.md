# 政治

> 权力怎么分配，政策怎么落地，制度之间差在哪。

## 收什么

- 制度比较：同一件事在不同制度下的处理路径
- 政策文本解读：原文说了什么、谁执行、卡在哪、实际效果
- 具体案例：一件事从头到尾的流程和转折

## 不收什么

- 时评情绪和立场输出
- 不区分"事实"与"判断"的段落——若写判断，前置"我认为"

## 条目

还没有条目。第一条建议写**一项你实际办过的政策**：文件依据、经办环节、卡点。

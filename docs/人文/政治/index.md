# 政治

> 权力怎么分配，政策怎么落地，制度之间差在哪。

## 收什么

- 制度比较：同一件事在不同制度下的处理路径
- 历史制度的运转：机构、选拔、税收、军费怎么组织（**只写历史，不写当代议题**）
- 具体案例：一项制度从设立到失效的流程和转折

## 不收什么

- 时评情绪和立场输出
- 当代政策与现实政治议题——边界见[读法](../读法.md)
- 不区分"事实"与"判断"的段落——若写判断，前置"我认为"

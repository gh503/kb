# 为什么古代商税难收

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 商业税与征收成本

## 结论

因为商人**会移动、账目看不见、查缉点太分散**。土地跑不掉，人可以登记；
货物一装船就走了，要在每条路上设卡才收得到——设卡本身又是成本。

## 机制

1. 农业税的税基固定：土地在那里，按亩征
2. 商业税的税基在流动中：货物、交易、利润都要现场查验
3. 查缉需要人、关卡、文书，成本随商路长度上升
4. 商人可绕道、可隐匿、可谎报价格
5. 征收成本高到一定程度，收上来的不如花出去的多

## 什么条件下能收

- 交易集中在少数地点（市、关、港口）
- 货物标准化、易于计量（盐、铁、茶、酒）
- 有专门机构与商人组织（行会、牙人）配合
- 政府能提供"保护"作为交换，商人愿意付

## 事实与判断

- **事实**：历代都有商税、关税、市舶收入，但占比通常低于土地税
- **事实**：盐、铁、茶等大宗商品长期是专卖或专税对象，因为它们集中且易查
- **判断**："征收成本决定税种选择"是解释力较强的框架，但也受政治意愿与商人博弈影响

## 边界

- 宋代商业繁荣，商税比重明显上升，说明"收不上"不是绝对的
- 战争时期设卡更密，短期收入增加，长期伤害贸易
- 商税重不一定抑制商业：要看税负是否可预期、是否重复征收

## 误解

- **"古代不重视商业"**——是征收能力限制，不是价值观单独决定
- **"商税一定收不到"**——交易集中处（港口、盐场）收得很好

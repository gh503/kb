# 为什么官僚越养越多

> **学段** 初中–高中 ｜ **类型** 动因 ｜ **链** 制度与财政

## 结论

因为**职责不清 + 考核看过程 + 财政先松后紧**：事情多了就加人，
加了人就要给位置，位置一旦设立很难裁掉。等到财政紧张时，人已经减不动了。

## 机制

1. 新事务出现（赈灾、漕运、边防），先设临时机构
2. 临时机构常态化，成为固定编制
3. 考核看"有没有办、有没有报"，不看"花了多少人"，于是层层加人
4. 官员有任期，胥吏（办事员）长期在位，实际办事靠胥吏
5. 裁撤会触动既得利益，通常只在新朝立国时才能大规模精简

## 历史例子

- **事实**：宋代设"官、职、差遣"，本官定品级、差遣管实事，机构重叠，出现"冗官"之讥
- **事实**：明清正式编制有限，大量事务由不入流的胥吏、幕僚承担，形成"编制外膨胀"
- **判断**："机构膨胀"是官僚制的普遍倾向，不限于中国；解释它的关键是激励与考核，而非道德

## 边界

- 人多不等于效率低：事务量确实增长时，加人是合理的
- 编制外人员省钱（俸禄低），但会通过寻租把成本转嫁给社会
- 精简往往伴随职能转移，不是简单"减人"
- 不同朝代差异很大，不能一概而论

## 误解

- **"官多是因为皇帝糊涂"**——考核与激励结构才是稳定原因
- **"裁人就能省钱"**——裁撤后的职能若仍要办，成本会以别的形式回来

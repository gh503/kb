# 为什么权力要分开

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 分权与制衡

## 结论

因为**一个人出错，全国跟着错**。把决定权分给几个互相牵制的机构，
单点失误的代价会小一些；代价是决策变慢、事情容易卡住。

## 机制

1. 信息不完整：谁都不可能什么都懂
2. 权力集中时，纠错要靠掌权者自己承认错误，概率低
3. 分权后，不同机构掌握不同信息，可以互相纠正
4. 相互否决提高了做错事的成本
5. 但同时也提高了做任何事的成本

## 历史上的分工

| 安排 | 分开的是什么 |
| --- | --- |
| 罗马共和国的同僚制 | 同级别的两名执政官互相否决 |
| 宋代二府三司 | 行政、军事、财政分属不同机构 |
| 近代的立法与行政分立 | 规则制定与执行分开 |

## 事实与判断

- **事实**：罗马共和国设两名任期一年的执政官，彼此可否决对方决定
- **事实**：宋代以中书门下、枢密院、三司分管政务、军务、财政
- **判断**："分权降低单点失误"有历史案例支持，但分权本身不保证更好：它也带来推诿与僵局

## 边界

- 分权需要配套：谁来做最终裁决、争议怎么解决
- 紧急状态下（战争、灾害）常需要集中权力
- 分权程度与决策事项有关：日常事务与重大事项不同

## 误解

- **"分权就一定更公平"**——它改变的是否决点的分布，不自动带来公平
- **"集权就一定高效"**——集权快，但也容易一路错到底

# 为什么盐是专卖品

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 制度与财政

## 结论

因为盐**人人要吃、无法替代、产地集中、便于查缉**——这四条凑在一起，
政府就能用很低的征收成本，从每个人身上收一笔"隐形税"。

## 机制

1. 盐是必需品，需求价格弹性低：涨价也得买
2. 产地有限（海盐、井盐、池盐），容易设卡
3. 政府控制运销环节，把税"藏"在盐价里
4. 盐引、纲运等制度把运销权分配给商人，换取预付或报效
5. 官盐价高 → 私盐有利可图 → 查缉成本上升 → 又需要更多机构

## 为什么是"隐形税"

- 直接税要按田亩、人丁征收，遇到隐匿与抗税
- 盐税按消费征收，随人口与消费量自然增长，征收点少
- 税负分散在每一次买盐里，痛感低、抗税成本高

## 量级（数量级，非精确值）

```text
盐课在历代财政中占相当比重（常常是一成上下，各朝差异大）
官盐与私盐价差：可达成倍，是走私的直接动力
盐商报效、捐输：在特定时期成为财政的补充来源
```

## 事实与判断

- **事实**：唐中期以后盐法改革，实行就场专卖；明清有盐引、纲运等制度
- **事实**：历代都有严重的私盐问题，官盐越贵走私越盛
- **判断**："专卖是为了财政收入"是主解释，但专卖也兼顾边疆军需、商人管理；把它只当"敛财"会漏掉治理维度

## 边界

- 专卖的净收益取决于查缉成本，成本过高时不如改征税
- 盐商会与官僚体系结合，形成利益集团，反过来影响政策
- 近代以后盐税地位下降，被关税、工商税取代

## 误解

- **"专卖就是政府自己卖盐"**——多数时期是官府控环节、商人做运销
- **"盐税很轻"**——它分散在消费里，单看税率容易低估负担

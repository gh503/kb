# 为什么需要产权

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 法律与契约

## 结论

因为**"这是谁的"说不清，就会打起来**。产权用一套大家认的规则，把争夺变成
"谁登记、谁使用、怎么赔"的低成本程序，省下的是暴力的成本。

## 机制

1. 资源有限，多人想要同一块地、同一片水
2. 没有规则时，靠武力解决，成本高且不可预期
3. 产权规定归属、使用、转让、赔偿
4. 有了排他性，所有者才愿意长期投入（改良土壤、修水利）
5. 登记与执行需要成本，所以产权从不是"免费的"

## 从习惯到法律

- **事实**：早期社会的产权多由习俗、宗族与地方惯例维持
- **事实**：土地登记、契税、地契在历代都存在，形式不同
- **判断**："产权促进投资"是制度经济学的核心命题之一，但它的效果取决于**执行是否可靠**，纸面权利不算数

## 边界

- 产权清晰不等于公平：初始分配可能极不平等
- 共有资源（渔场、水源、林地）用排他产权未必合适，可能用配额、习惯规则
- 登记成本高时，非正式规则可能更有效
- 国家既保护产权，也可能侵犯产权

## 误解

- **"产权是天然存在的"**——它是制度安排，需要维持成本
- **"有产权就一定有效率"**——还要看执行、交易成本与分配

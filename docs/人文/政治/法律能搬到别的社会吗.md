# 法律能搬到别的社会吗

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 法律与契约

## 结论

**条文能搬，效果不一定。** 法律移植很常见（日本、土耳其、殖民地），
但同一部法在不同社会里的实际效果，取决于执行机构、社会规范与利益结构。

## 为什么条文容易搬

1. 立法是低成本的技术工作：翻译、抄写、参照
2. 后发国家常以"接轨"为目标，直接采用成熟法典
3. 国际条约与贸易协定推动趋同

## 为什么效果不同

1. **执行**：法院能力、法官训练、腐败程度
2. **规范**：社会习惯与法律冲突时，人们可能绕开法律
3. **利益**：法律触动既得利益，会被架空或选择性执行
4. **配套**：产权登记、信用体系、会计标准缺一不可
5. **语言与概念**：外来概念难以对应本地实践

## 例子

- **事实**：日本明治时期大量移植欧洲法典，同时保留本土制度安排
- **事实**：土耳其 1920 年代直接采用瑞士民法典
- **判断**："移植成功/失败"的评判标准本身有争议：是看条文一致，还是看秩序效果

## 事实与判断

- **事实**：日本明治时期大量移植欧洲法典，土耳其 1920 年代直接采用瑞士民法典
- **事实**：同一部法典在殖民地与母国的实际执行效果差别很大
- **判断**："移植"能否产生预期秩序，取决于法院能力、社会规范与利益结构，而不是条文本身

## 争议与未解

- **法律与发展**：法律改革能否促进经济增长，实证结论不一致
- **"本土资源"论**：强调习惯法与地方知识，反对简单移植
- **度量困难**：法治水平难以量化，指标常偏向形式要件（有无条文、有无法院）
- **选择偏差**：成功案例被广泛引用，失败案例少被系统记录

## 到此为止

这一层是**条文与秩序的距离**：法律不是代码，装上就能跑；
它需要执行机构与社会规范一起支撑。

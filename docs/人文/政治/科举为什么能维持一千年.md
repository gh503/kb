# 科举为什么能维持一千年

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 制度与财政

## 结论

因为它同时解决了三个问题：**谁来当官**（有客观标准）、**谁来定标准**（中央握在手里）、
**读书人往哪走**（有上升预期就不去造反）。三件事都便宜，制度就能长期维持。

## 机制

1. 考试把"选人"变成可比较的分数，减少了举荐制的人情与结党
2. 录取权在中央，地方官无法自行任命，权力集中
3. 读书—考试—做官形成一条通路，社会精英的精力被引向考场
4. 落榜者也有"下次再考"的预期，不满被时间稀释
5. 考试内容统一，也统一了官员的知识与话语

## 时间线（关键节点）

```text
605 年前后：隋设进士科，通常视为科举起点
唐代：进士、明经等常科，录取人数少
宋代：录取规模扩大，考试程序更严密
明代：八股文定型，乡试—会试—殿试三级
1905 年：清廷废止科举
```

## 事实与判断

- **事实**：科举从隋唐延续到 1905 年，跨度约一千三百年
- **事实**：明清科举以四书五经命题，八股文有固定格式
- **判断**："科举维持统治"是功能解释，不是唯一解释；它同时带来思想封闭与技能错配，这些代价在后来的批评中被反复提及

## 边界

- 科举录取率很低，实际的社会流动远小于"人人可考"的印象
- 考试公平是**程序公平**，受教育机会本身并不平等
- 科举主要选文官，军事、技术人才另有通道
- 废止科举后，读书人的出路问题直接影响了清末政治

## 误解

- **"科举就是高考"**——功能相似（标准化选拔），但考试内容、录取规模、出路完全不同
- **"科举让社会充分流动"**——流动存在，但被教育资源与录取率严格限制

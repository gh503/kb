# 文化

> 一群人共享的意义系统：语言、习俗、作品、禁忌。

## 收什么

- 概念解释：一个词在本文化里指什么、在别的文化里指什么
- 作品分析：它为什么有效，用了什么手法
- 跨文化差异的实例：同一动作在两地含义相反的那种

## 不收什么

- 作品清单堆砌（片单/书单本身没有信息量）
- "见仁见智"式的空话

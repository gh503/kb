# 为什么奢侈品总在被模仿

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 口味与身份

## 结论

因为奢侈品的价值一半在**物**、一半在**信号**：它告诉别人"我属于哪一层"。
信号要有效就得稀缺；一旦被模仿、变便宜，它就不再是信号，上层只好换一个新的。

## 机制

1. 商品有双重功能：使用价值 + 身份信号
2. 信号的价值来自"别人买不起/买不到"
3. 仿制品与平价替代出现，信号贬值
4. 上层转向新样式（凡勃伦效应：价格本身就是信号）
5. 循环往复，形成"品味扩散"（trickle-down）的持续运动

## 三种维持稀缺的手段

| 手段 | 例子 | 成本 |
| --- | --- | --- |
| 法律 | 禁奢令、限定服色 | 执行成本高，易被绕过 |
| 价格 | 高价本身 | 只要有富人，就挡不住模仿 |
| 认证 | 品牌、产地、手工 | 需要长期信用与叙事 |

## 事实与判断

- **事实**：历史上多次出现禁奢令，规定什么身份能穿什么、用什么
- **事实**：凡勃伦在 1899 年《有闲阶级论》中把"炫耀性消费"系统化
- **判断**：西美尔的"涓滴"模型（上层 → 下层模仿）解释力强，但反向流动也存在（街头风格被高端吸收），所以不是单向的

## 边界

- 不是所有消费都是信号：日用品、习惯性消费与身份无关
- 信号需要在**可识别的圈层**内才有效，陌生人之间常常无效
- 数字时代仿制几乎零成本，稀缺越来越靠"认证"而非"物"
- 把一切消费都读成炫耀，会过度解释

## 误解

- **"贵就一定好"**——价格可以是信号本身，与质量脱钩
- **"模仿是低级的"**——扩散正是文化变化的常态机制

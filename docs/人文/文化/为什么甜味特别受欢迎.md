# 为什么甜味特别受欢迎

> **学段** 初中–高中 ｜ **类型** 动因 ｜ **链** 节庆与口味

## 结论

因为**甜意味着能量，能量在历史上长期稀缺**。偏好甜味的机制被保留下来，
即使现在糖很便宜，偏好没有跟着变。

## 机制

1. 糖是高效能量来源，单位重量热量高
2. 自然界中甜味通常伴随成熟果实，苦味常伴随毒素
3. 偏好甜、回避苦有生存优势
4. 稀缺时期，甜食是珍贵的补充
5. 糖变便宜后，偏好仍在，消费量上升

## 量级

```text
糖的热量：约 4 千卡/克
食糖消费：20 世纪多数国家大幅上升，从稀缺品变成日常添加
```

## 事实与判断

- **事实**：人类普遍偏好甜味，对苦味的接受需要后天训练（咖啡、苦瓜、啤酒）
- **事实**：20 世纪食糖消费量在多数国家显著上升
- **判断**："演化偏好"能解释方向，不能解释具体消费量：价格、营销、饮食习惯的贡献更大

## 边界

- 偏好可以被文化塑造：有人嗜甜，有人不喜
- 甜味阈值会随摄入量上升，越吃越甜
- 代糖改变了"甜=能量"的对应关系，偏好与营养脱钩

## 误解

- **"爱吃甜是意志力差"**——有生理基础，但摄入量仍受环境与价格影响
- **"甜食一定让人胖"**——取决于总量与活动水平

# 为什么翻译成本影响思想传播

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 语言与身份

## 结论

因为**翻译是知识过境的门**：谁掌握语言、译什么、术语怎么造，决定了哪些思想能进来、以什么面貌进来。
门的宽度会改变思想传播的方向，而不只是速度。

## 机制

1. 跨语言传播必须付翻译成本：语言能力、术语对应、文本校勘
2. 术语不通用时，译者要"造词"，造词本身是解释
3. 翻译有选择性：资助者与译者的兴趣决定译什么
4. 转译会变形：经二手语言转译，误读会被放大
5. 通用语（拉丁语、汉语文言）降低了特定时期的成本

## 例子

- **事实**：中古时期佛经翻译形成有组织的译场，创造出大量新词
- **事实**：欧洲长期以拉丁语为学术通用语，近代才转向本国语言
- **判断**："翻译塑造思想形态"有大量案例，但具体影响难以量化

## 事实与判断

- **事实**：术语的译法会长期影响理解（同一概念的译词不同，讨论就分岔）
- **事实**：某些著作因翻译成本高而长期缺席某语言圈
- **判断**："翻译成本决定思想传播"过于机械；它设定门槛，但需求与政治也会砸开门

## 边界

- 口语传播与图像传播的成本结构不同
- 机器翻译降低了成本，但术语与语境仍是瓶颈
- 转译链条越长，失真越大
- 译者的地位与报酬影响译本质量

## 误解

- **"翻译只是语言转换"**——也是概念再造与选择
- **"好译本等于原文"**——总会有损失，只是损失在哪里不同

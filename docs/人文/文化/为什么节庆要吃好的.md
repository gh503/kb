# 为什么节庆要吃好的

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 节庆与口味

## 结论

因为**平时吃不到**。节庆食物靠稀缺才有分量：一年几次的肉、糖、油，
既补了热量，也标记了时间——吃了它，这一年才有着落。

## 机制

1. 农业社会平时热量不足，节庆集中补充
2. 稀缺食物成为仪式标记：什么时候吃、和谁吃都有规矩
3. 共享一顿饭强化群体认同
4. 节庆食物被赋予象征（团圆、丰收、敬神）
5. 一旦日常富足，稀缺消失，仪式就更多靠符号维持

## 例子

- **事实**：许多传统的节庆食物都用高糖高油食材（油炸、腌腊、甜点）
- **事实**：年节食物的准备往往需要全家协作，本身就是仪式
- **判断**："节庆吃好的"最初是热量与稀缺的安排，后来才成为文化符号

## 事实与判断

- **事实**：在食物匮乏的年代，节庆是全年脂肪与糖的重要来源
- **事实**：食物富足后，节庆食物的"稀缺性"下降，但仪式意义保留
- **判断**：说"节庆食物是文化"没错，但它能形成文化，前提是它曾稀缺

## 边界

- 不同阶层的节庆食物差别很大：穷人过年与富人过年不是一回事
- 宗教节庆的饮食规则（斋戒、洁净）另有逻辑
- 商业化会把节庆食物变成日常商品，仪式感随之变化

## 误解

- **"传统节庆食物自古如此"**——配方与做法在变，很多是近代定型
- **"爱吃甜是嘴馋"**——有能量需求与稀缺经历的原因

# 为什么节日食物会被标准化

> **学段** 高中–大学 ｜ **类型** 动因 ｜ **链** 节庆与口味

## 结论

因为**送礼需要可比较**。月饼、粽子、年糕一旦成为礼物，就要有规格、包装、价格，
于是被标准化——标准化让它能远距离流通，也让地方差异消失。

## 机制

1. 节庆食物从"自家做"变成"买来送"
2. 送礼需要体面的外观与可比较的价格
3. 商家统一配方、规格、包装，形成品牌
4. 礼盒化提高单价，也拉长了销售周期
5. 地方做法被"通行版本"取代

## 例子

- **事实**：月饼、粽子等节庆食品在 20 世纪逐步工业化生产，礼盒成为主要形态
- **事实**：圣诞布丁、潘妮托妮等也有类似的商业化过程
- **判断**："商业化摧毁传统"只说对一半：商业化也让这些食物在更大的范围内被记住

## 事实与判断

- **事实**：工业化生产使节庆食品的可得性大幅提高，价格区间拉开
- **事实**：礼盒包装成本常高于食物本身成本
- **判断**：标准化是礼物经济的产物，不是单纯的工业化结果；没有送礼需求，规格不会如此统一

## 边界

- 家庭自制仍在，尤其在农村与移民社群
- 过度包装会引发浪费与监管讨论
- 地方版本并未完全消失，常以"手工""古法"名义回归

## 误解

- **"标准化让食物变难吃"**——口味评价主观，但配方确实趋于保守
- **"礼盒只是营销"**——它解决了送礼的"可比较"问题

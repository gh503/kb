# 为什么食物需要标准

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 发明的传统

## 结论

因为标准**降低了交易成本**：买家不用每次亲自验货，卖家也能凭"符合标准"卖到更远。
代价是多样性被压缩——不合标准的做法被排除在外。

## 机制

1. 食品的品质难以当场判断（味道、年份、工艺）
2. 标准把"好不好"变成可检验的条款：品种、产区、工艺、时长
3. 认证与标签让远距离买家相信品质
4. 符合标准的产品获得溢价，形成"租金"
5. 标准化也便于监管、征税与规模化生产

## 例子与量级

```text
法国 AOC/AOP 体系：20 世纪前期建立，覆盖葡萄酒、奶酪等
香槟产区范围：20 世纪前期由法律界定
帕尔马干酪等 PDO 产品：受欧盟地理标志保护
价格溢价：研究普遍发现带地理标志的产品有可观溢价（幅度因品类而异）
```

## 事实与判断

- **事实**：地理标志（GI）制度在 20 世纪逐步成型，欧盟形成 PDO/PGI 体系
- **事实**：带 GI 标签的产品通常能卖出更高价格
- **判断**："标准提高效率"有较强证据；"标准保护了传统"则要分情况——它同时固化了某一种做法

## 边界

- 标准是**最低门槛**，不保证最好吃
- 过度细化会抑制创新：改了工艺就不合规
- 小生产者承担认证成本，可能被挤出
- 标准常由强势产区主导，弱势产区只能跟随

## 误解

- **"有标准就更安全"**——标准管的是可核验的条款，不等于全面安全
- **"标准化会毁掉传统"**——它也会让传统得以远距离流通

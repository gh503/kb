# 地方特产是怎么变成特产的

> **学段** 小学–初中 ｜ **类型** 动因 ｜ **链** 发明的传统

## 结论

两步：**先有地理条件造成的差异**，**再有人把它标准化、命名、并说成"自古如此"**。
没有第二步，好东西也只是本地货，卖不出溢价。

## 机制

1. 气候、土壤、水源造成味道差异（葡萄、茶叶、火腿）
2. 商人把某地产品与"品质"挂钩，形成口碑
3. 生产者约定做法（品种、工艺、时限），把差异固定下来
4. 命名与产地保护，把"地名"变成排他性的品牌
5. 故事被反复讲述，差异从"技术事实"变成"文化事实"

## 例子

- **事实**：法国从 20 世纪初开始建立原产地命名制度，1935 年形成全国性体系
- **事实**：香槟产区的范围在 20 世纪前期由法律界定
- **判断**："特产是自然禀赋的结果"只说对一半；标准化与法律保护同样是成因

## 边界

- 地理条件确实是基础：换地方做不出同样的味道
- 但"传统工艺"往往在标准化过程中被**重新定义**，并非原样保留
- 保护制度能提高价格，也可能固化技术、抑制改良
- 有些"特产"是近代才有的，只是叙事把它往前推

## 误解

- **"特产自古就有"**——产品可能有，品牌与标准多是近代的
- **"保护产地就是保护文化"**——也保护了租金，两者要分开看

# 语言能被人为设计吗

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 语言与身份

## 结论

**书写系统与标准语能设计，母语不能凭空造。** 正字法、术语、标准音都可以规划；
但要让一门语言成为人群的日常母语，需要学校、家庭与共同体长期配合。

## 三种"设计"

| 类型 | 例子 | 结果 |
| --- | --- | --- |
| 造国际语 | 世界语（1887） | 有社群，未成为通用语 |
| 复兴死语言 | 希伯来语口语化 | 在特定条件下成功 |
| 换书写系统 | 土耳其 1928 年改用拉丁字母 | 推行成功，代价是与旧文本断裂 |

## 成功与失败的条件

1. 有没有稳定的使用场景（学校、行政、媒体）
2. 有没有政治与财政支持
3. 社群规模与认同强度
4. 与既有口语的距离：太远则学习成本高
5. 是否与上升机会绑定

## 事实与判断

- **事实**：世界语设计简洁，使用者规模有限，未成为国际通用语
- **事实**：希伯来语从礼仪语言恢复为日常口语，是罕见的成功案例
- **判断**："语言可以设计"在书写与规范层面成立；在母语层面，"设计"更像长期社会工程

## 争议与未解

- **成功归因**：希伯来语复兴靠的是运动、学校还是移民结构，难以分离
- **代价评估**：换文字系统会切断与历史文献的联系，收益与损失如何权衡
- **通用语的未来**：英语的地位是设计的结果还是霸权的产物，学界看法不一

## 到此为止

这一层是**设计的上限**：能规定怎么写，
不能规定人怎么开口说、跟谁说话。

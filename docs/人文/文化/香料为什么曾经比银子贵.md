# 香料为什么曾经比银子贵

> **学段** 小学–初中 ｜ **类型** 量级 ｜ **链** 口味与身份

## 结论

因为**运得太远、过手的人太多**。香料产地集中在少数热带岛屿，运到欧洲要经海路、
阿拉伯中间商、威尼斯商人层层加价，价格里大部分是运输与环节成本，不是产地成本。

## 机制

1. 产地集中：丁香、肉豆蔻只产于马鲁古群岛等少数地方
2. 运输长：产地 → 印度洋 → 阿拉伯/埃及 → 地中海 → 欧洲
3. 中间环节多：每个环节都要加价，且信息不透明
4. 需求刚性：能防腐、调味、做药，还象征身份
5. 供给可被垄断：谁控制航线，谁定价

## 为什么要去找"直航"

- **事实**：15 世纪末葡萄牙人绕过好望角抵达印度，16 世纪初进入马六甲
- **事实**：此后香料贸易路线改变，威尼斯的中转地位被削弱
- **判断**：寻找直航的动机不止"香料便宜"，还有黄金、传教与地缘竞争

## 边界

- "香料比银子贵"是笼统说法：不同品种、不同时期差别极大
- 高价里很大一部分是**运输与风险溢价**，不是稀缺本身
- 香料在欧洲也有药用与宗教用途，不能只看餐桌
- 一旦直达航线开通、供给增加，价格就下来了——这说明高价是制度性的，不是天然的

## 误解

- **"香料贵因为产地少"**——产地少只是条件之一，中间环节才是价格主体
- **"大航海是为了香料"**——是动机之一，不是全部

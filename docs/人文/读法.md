# 读法：用钱的角度看历史

> **学段** 高中–大学 ｜ **类型** 边界（方法） ｜ **链** 读法

## 结论

看历史时先问三个问题：**钱从哪来、成本由谁承担、激励因此怎么变**。
大多数制度、思想与风俗的变迁，背后都有一笔算得出来的账；但账不能解释全部。

## 三个问题

1. **钱从哪来**：税收、土地、贸易、掠夺、借贷。财政结构决定国家能做什么
2. **成本由谁承担**：负担落在农民、商人、士绅还是后代（公债）身上
3. **激励怎么变**：同样的行为，收益与风险变了，人的选择就会变

## 为什么这个视角有用

- 它能解释"明知有害却停不下来"的决定：加税、滥发货币、闭关，往往是因为当期没有别的选择
- 它能把道德评判换成条件分析：不是"好人坏人"，是"在什么约束下做什么选择"
- 它能比较不同文明：同样的战争压力，融资方式不同，结果差很远

## 边界（重要）

- **只写历史政治，不写当代政治**。这一域处理的是已经进入史料的制度与人，不做现实议题的立场表达
- 经济解释是**一种**解释，不是唯一解释：气候、地理、军事技术、观念、偶然事件都在起作用
- 有账不等于有因果：相关性与因果链要分开写
- 数字常常是估计值，数量级可信、精确值不可信，必须标出来源与不确定性

## 每页要分清的两件事

- **事实**：有史料或统计支撑的
- **判断**：我的解释或学界的一种解释

条目里用「事实与判断」小节把两者分开。看到没分清的段落，就当它是判断。

## 怎么用这个库

### 按年级读

每个学科页顶部的「链」表已经按学段排好序，一条链四页：

| 你在 | 读每一条链的 | 读到什么程度 |
| --- | --- | --- |
| 小学 | 第 1 页 | 现象 + 一个比喻，不背数字 |
| 初中 | 第 1–2 页 | 定性机制 + 一个生活例子 |
| 高中 | 第 2–3 页 | 一个能代入的定量关系 |
| 大学 | 第 3–4 页 | 模型与前提条件 |
| 研究生 | 第 4 页 | 争议在哪、证据强不强 |

不需要按顺序读完 20 条链。**选一条你现在好奇的，从它的小学层读起。**

遇到没有分清的段落，就把它当判断，别当史料。

## 五种类型（人文版）

| 类型 | 回答 | 例子 |
| --- | --- | --- |
| 动因 | 为什么会这样 | 王朝为什么会亡于财政 |
| 约束 | 在什么条件下才成立 | 为什么欧洲靠国债打仗 |
| 量级 | 大概多少，够不够 | 白银为什么能救明朝也害了明朝 |
| 误区 | 流传很广但站不住 | 待写 |
| 对比 | 两条路差在哪 | 为什么欧洲靠国债打仗 |

# 关于本站

按学科组织的个人知识库。**只放以后还会再用的结论**——不放收藏夹，不放日记。

## 结构

```text
基础/    通用基础 · 数学 · 逻辑
工程/    设计 · 开发 · 测试 · 运维
智能/    AI · 机器人
网络/    网络通信 · TCP/IP · 安全
商业/    运营 · 项目管理
人文/    历史 · 政治 · 文化 · 哲学
自然/    物理 · 化学 · 生物 · 地理
日常/    生活 · 娱乐
关于/    本站说明与约定
```

目录名和页面标题是同一个词。命名规则见[写作规范](写作规范.md#文件与目录命名)。

每个学科一页入口，写清「收什么、不收什么」，下面是条目表。条目是真正的内容，一页一件事。

## 维护

- [快速开始](快速开始.md) — 本地跑起来、加一页、发布
- [写作规范](写作规范.md) — 一页写什么、怎么写、放哪一科
- [条目示例](条目示例.md) — 照着填空的模板
- [更新日志](更新日志.md) — 结构性改动

## 技术

MkDocs + Material 主题，静态生成，无数据库、无服务端。搜索索引在构建时生成，浏览器端全文检索（中文分词可用）。推送 `main` 后由 GitHub Actions 构建并发布到 GitHub Pages。

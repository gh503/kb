# 规划：剩下四个域怎么建

> 现状：自然、人文、商业、日常四域已成体系（共 123 条链）。
> 基础、工程、智能、网络四域只有索引页，**12 个学科、0 条目**。这一页说明它们怎么建。

## 为什么按这个顺序

```text
第一优先 工程（开发/测试/运维/设计）  每天用，错一次就留坑
第二优先 网络（TCP-IP/网络通信/安全） 排障靠它，不学就只会重启
第三优先 智能（AI/机器人）            变化快，先立骨架，不追新闻
第四优先 基础（通用基础/数学/逻辑）    最底层，最后写反而更清楚
```

**先写"能马上用"的，后写"要沉淀"的。** 四个域共用同一套体例，不另立规矩。

## 每个学科怎么切链

一条链 = 一个能一路追问下去的问题，4 页一链。下面是初定的 24 条链。

## 技术域的一条额外规矩

**能测的就测，测不了的说清楚。**

```text
可以实测：本机跑一条命令得到的数字（解析耗时、压缩比、握手轮次）
          正文必须写明：环境、命令、样本量
不能实测：别人的机器、生产环境、别人的团队数据
          标"公开经验"或"推断"，不冒充实测
```

这条是为了让工程/网络域比前四个域更硬——**它们的价值就在于能被验证**。

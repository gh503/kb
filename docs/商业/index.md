## 这一域怎么写的

商业内容最容易写成"心得"——听着有道理，用起来没法落地。所以每页固定四件东西：

1. **可代入的公式或清单**：给数就能算，不靠悟性
2. **数字与阈值**：区间 + 适用条件，不是"一般来说"
3. **证据强度**：这条是实测、公开经验，还是我推出来的
4. **不适用的情况**：什么生意、什么阶段不该照做

第三点尤其重要。**我没有你的业务数据**，所以绝大多数页标的是"公开经验"或"推断"，
不是"实测"。看到"实测"两个字，才是我真跑过的。

## 三条判断原则

- **先算再改**：觉得"效果不好"之前，先写出分子分母
- **一次改一个变量**：同时改三件事，涨了也不知道该继续哪个
- **区分"赚"和"收到"**：利润表与银行余额是两回事

# 单位经济

> 一单赚不赚钱、多久回本、会不会被现金流拖死。

## 收什么

- 毛利与净利的拆法：哪些算直接成本，哪些算固定开销
- 定价与报价：按什么定价、为什么要分档
- 回本周期：CAC 多久能收回来，与现金能撑多久对照
- 现金流：账期、垫资、现金转换周期

## 不收什么

- 会计考试式的科目讲解
- 没有数字的"要重视利润"

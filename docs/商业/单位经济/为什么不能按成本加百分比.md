# 为什么不能按成本加百分比

> **深度** 入门 ｜ **类型** 误区 ｜ **链** 定价怎么定

## 结论

因为**成本只决定你能不能卖，不决定别人愿不愿买**。成本加成法的价格里没有客户，
也没有竞争对手——它回答的是"我要赚多少"，而不是"这个价卖得动吗"。

## 成本加成的三个漏洞

1. **成本算错**：只算材料，漏了返工、沟通、售后；项目越小，漏得越多
2. **支付意愿被忽略**：同一个结果，对 A 是省钱工具，对 B 是救命工具，愿付的差好几倍
3. **竞争位置被忽略**：你按成本加成报 8 千，对手报 6 千，客户不会因为你的算法合理就多付

## 什么时候成本加成是对的

| 场景 | 为什么可用 |
| --- | --- |
| 大宗同质商品 | 成本透明，价格由市场定，加成是管理工具 |
| 代工/来料加工 | 客户掌握成本结构，只能赚加工费 |
| 长期框架合同 | 便于结算与审计，稳定性比毛利重要 |

**除了这三类，普通服务与小产品都不该以成本为起点。**

## 一个替代起点：客户的替代方案

```text
问：不用你，客户会怎么办？
  A. 自己做（省了多少钱、花多少时间）
  B. 用竞品（多少钱、差在哪）
  C. 不解决（损失多少）

你的价格区间 ≈ 客户替代方案的代价 × 你能省下/多赚的比例
```

## 数字与阈值

```text
成本加成率：贸易类常见 10%–30%，服务类 30%–100%
若你的报价高于客户替代方案代价的 1.5 倍：需要有明确理由（速度、风险、责任）
若低于成本的 1.3 倍：几乎没有容错空间，一次返工就亏
```

## 证据强度

- **公开经验**：成本加成忽略支付意愿与竞争，是定价文献里的标准批评
- **区间**：加成率与倍数来自公开经验，行业差异极大
- **推断**："以替代方案为起点"是把定价转为比较问题，属于方法建议，未实测

## 不适用的情况

- 客户有强制成本审计（部分政府与国企采购）
- 你的产品是纯商品，客户能逐项比价

## 常见错法

- **按工时定价但工时估不准**：估少了亏，估多了客户觉得贵
- **不同客户不同算法**：一旦被知道，所有客户都会要求按最低价算
- **把"我投入很多"当涨价理由**：投入不是客户的价值

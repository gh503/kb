# 分期付款怎么设计

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 报价怎么给

## 结论

**让预付款覆盖你的直接成本，尾款压在验收后。** 这样即使客户拖尾款，
你也不会立刻亏现金——分期的目的不是"好谈"，是控制垫资风险。

## 常见的三段式

| 节点 | 比例 | 用途 |
| --- | --- | --- |
| 签约预付 | 30%–50% | 覆盖材料、外包、启动成本 |
| 中期（里程碑） | 30%–40% | 覆盖人力投入 |
| 验收尾款 | 10%–30% | 约束验收与交付质量 |

## 设计原则

```text
原则一：预付款 ≥ 直接成本
  直接成本 1.5 万、合同 4.8 万 → 预付至少 31%
原则二：里程碑要是"可验证的交付物"，不是"时间点"
  ✗ 开工后第 3 周付 30%
  ✓ 设计稿确认后付 30%
原则三：尾款比例与验收风险匹配
  客户验收流程长 → 尾款压低（10%），重心前移
原则四：写清逾期条款
  逾期 N 天后可暂停工作、可计息
```

## 长期项目的另一种：按人月/按阶段

- **按人月**：每月固定付款，适合持续投入、范围不清
- **按阶段**：阶段交付即付款，适合范围清晰但时间长

按人月更稳，前提是客户认可你的时间价值；按阶段更像项目制。

## 数字与阈值（经验判断）

```text
预付：30%–50%，低于 30% 在小项目上容易垫资
尾款：10%–30%，客户内部审批链长则取低值
逾期利息：按日计，或约定"暂停服务"权利
```

## 证据强度

- **公开经验**：里程碑付款与预付比例是项目商务的常规做法
- **区间**：比例来自经验
- **推断**："预付 ≥ 直接成本"是按现金流安全推的原则

## 不适用的情况

- 政府/大型企业：付款节奏由对方流程决定，只能靠合同约定验收期限
- 订阅制：按月/年预付，本质是预收而非分期

## 常见错法

- **只收 10% 预付**：一个项目垫资就把现金拖住
- **里程碑按时间不按交付**：时间到了活没完，也不好意思不收
- **不写逾期后果**：尾款拖半年，你只能催

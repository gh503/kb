# 单位经济能预测增长吗

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 一单赚不赚钱

## 结论

**只有"每一单都差不多"时才能外推。** 单位经济描述的是边际一单赚不赚钱；
规模变了，获客成本、毛利、流失率都会变，把第一年的数乘十倍，通常错得很离谱。

## 什么时候能外推

| 条件 | 说明 |
| --- | --- |
| 产品标准化 | 每单交付内容一致 |
| 客群稳定 | 新客的来源结构不变 |
| 渠道未饱和 | 加钱还能拿到同样质量的量 |
| 无规模不经济 | 人多了效率没有下降 |

四条里破一条，外推就要打折。

## 常见的外推错误

1. **CAC 恒定**：渠道饱和后 CAC 上升，早期数据最好看
2. **留存恒定**：早期用户是最匹配的那批人，越往后留存越低
3. **毛利恒定**：规模上来后要打折、要加客服、要垫资
4. **忽略管理成本**：从 5 人到 50 人，协调成本不是线性的

## 数字与阈值

```text
用早期数据外推时：把 CAC 上调 20%–50%，留存下调 10%–30%
样本 < 50 单：不要做任何外推
```

这是保守的折扣法，目的是让预测不至于过于乐观，不是精确模型。

## 证据强度

- **推断**：折扣幅度是按"渠道饱和 + 客群质量下降"的方向估的，没有实测
- **公开经验**：CAC 随规模上升、留存随客群扩大下降，是被广泛观察的现象
- **未验证**：具体折扣多少，只能用你自己的数据回测

## 什么比单位经济更该看

- **边际单位经济**：最近 100 单的 CAC 与毛利，而不是全部平均
- ** cohorts（同期群）**：按月分组的留存曲线是否在变差
- **现金转换周期**：增长需要垫多少钱

## 争议与未解

- **烧钱换增长**：在赢家通吃的市场里，先亏后赚可能成立；但"通吃"是小概率，多数市场不支持
- **LTV 的算法**：用平均生命周期还是分组留存，结论会差很多
- **规模效应**：有些生意越大越省，有些越大越贵，事前难以判断

## 到此为止

这一层是**外推的边界**：单位经济回答"这一单赚不赚"，
回答不了"一万单还赚不赚"。

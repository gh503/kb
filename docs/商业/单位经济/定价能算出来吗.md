# 定价能算出来吗

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 定价怎么定

## 结论

**能算出区间，算不出那个数。** 三种方法各给一个边界：成本定下限、竞争定参考、价值定上限。
真实价格落在区间里，具体位置取决于谈判、信任与替代方案。

## 三种方法

| 方法 | 给出什么 | 失效的时候 |
| --- | --- | --- |
| 成本加成 | 下限（不能长期低于成本） | 成本算不准、忽略支付意愿 |
| 竞争对标 | 参考价（客户会拿来比） | 产品不可比、对手在亏损抢量 |
| 价值定价 | 上限（客户愿付的最高） | 价值难量化、客户不认 |

## 一个可操作的流程

```text
1. 算清成本与最低可接受价（含返工与售后）
2. 找 2–3 个可比产品的公开价格，确定市场区间
3. 估算客户不用你的代价（时间、损失、替代方案成本）
4. 报价 = 价值上限与竞争参考之间，靠近价值一侧
5. 留出 10%–20% 的谈判空间，但不在第一次报价就放
```

## 什么时候定价真的"算不出来"

- **新品类**：没有可比价，客户也没有参照，只能试
- **B2B 大单**：价格与付款条件、责任划分、独家条款绑在一起
- **信任未建立**：同样的服务，老客户能接受的价格更高

## 数字与阈值

```text
谈判空间：首次报价通常留 10%–20%
低于成本 1.3 倍：基本没有容错
高于市场参考 1.5 倍：需要明确的差异化理由
```

## 证据强度

- **方法**：三种定价路径是标准框架，可直接用
- **区间**：来自公开经验，非实测
- **推断**："落在区间内靠近价值一侧"是策略建议，依赖具体谈判

## 争议与未解

- **价值定价的可行性**：B2B 里价值常难以量化，最后仍回到比价
- **低价策略**：能快速拿量，但是否可持续取决于成本结构，历史案例两极化
- **价格透明化**：比价工具让"同物不同价"越来越难维持

## 到此为止

这一层是**区间而非点**：定价是给区间找落点，
不是解一道有唯一答案的方程。

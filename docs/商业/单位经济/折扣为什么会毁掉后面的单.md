# 折扣为什么会毁掉后面的单

> **深度** 实操 ｜ **类型** 取舍 ｜ **链** 定价怎么定

## 结论

因为**价格一旦降过，就变成新的参照**。客户记住的是 8 千，不是"原价 1 万打了八折"；
而且老客户会知道，新客户会打听，渠道会拿这个价去压你。

## 三个后果

| 后果 | 机制 |
| --- | --- |
| 锚点下移 | 下次谈判从 8 千开始，不是从 1 万 |
| 老客户反弹 | 同样的东西，别人更便宜，要求补差或流失 |
| 渠道比价 | 折扣价流入市场，成为公开参考价 |

## 折扣要换东西

降价不是不可以，但**必须换回确定的收益**：

```text
可以换：预付款、更长合同期、案例署名、转介绍、批量、更宽松的交付期
不该换：一句"以后多合作"、口头承诺的量大、没有截止日期的意向
```

判断标准：**换回来的东西能不能写进合同**。写不进去，就等于白降。

## 折扣要多少量才划算

```text
需要增加的销量倍数 = 降幅 ÷ (毛利率 − 降幅)

毛利率 40%、降价 10% → 需要多卖 33% 才持平
毛利率 40%、降价 20% → 需要多卖 100%
毛利率 20%、降价 10% → 需要多卖 100%
```

**毛利越薄，折扣越致命。** 毛利率 20% 时打九折，销量要翻倍才不亏。

## 数字与阈值

```text
单次折扣上限：毛利率的一半（超过就伤本）
折扣频率：同一客户一年内不超过 1–2 次，否则成为惯例
公开折扣：尽量不做，改为"附加服务不加价"
```

## 证据强度

- **公式**：销量补偿倍数是算术推导，可直接用
- **阈值**："折扣不超过毛利率一半"是保守经验规则
- **推断**："降价锚点下移"基于参照点效应，属于有理论支撑的推断

## 不适用的情况

- 清库存：目标是回笼现金，不是保毛利
- 新产品试销：早期低价换反馈是有意为之，但要设截止时间

## 常见错法

- **先报价再打折**：等于告诉客户初始价有水分
- **给所有人一样的折扣**：折扣变成价格，不再是让步
- **用折扣解决交付问题**：客户不满意的原因常常不是价格

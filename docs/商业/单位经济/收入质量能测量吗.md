# 收入质量能测量吗

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 收入稳不稳

## 结论

**能测，用四个维度打分，但不该合成一个"质量分"。** 集中度、可预测性、毛利、现金，
四个维度会互相冲突——合成一个数字，等于把冲突藏起来。

## 四个维度

| 维度 | 指标 | 好的方向 |
| --- | --- | --- |
| 集中度 | 单客户占比、前 3 占比 | 越低越好 |
| 可预测性 | 订阅/续约占比、合同期 | 越高越好 |
| 毛利 | 毛利率、毛利率趋势 | 稳定或上升 |
| 现金 | CCC、预收占比 | CCC 短、预收多 |

## 为什么不能合成分

```text
例：一个客户占 60% 收入，但签了 3 年合同、预付款、毛利 70%
    另一个：100 个客户各占 1%，但月付、随时可退、毛利 30%

前者集中度高、可预测性高、现金好；后者相反。
哪个"质量更高"取决于你的风险承受能力，不是算术。
```

## 怎么用这四个维度

1. 先看**最差的那一项**：它决定你的脆弱点
2. 再看**趋势**：四个指标都在往坏走，说明模式有问题
3. 最后看**组合**：高集中 + 高预收，是"绑在一个客户身上的融资"

## 数字与阈值（经验判断）

```text
健康的组合：单客户 < 15%、订阅占比 > 60%、毛利率稳定、CCC < 30 天
需要警惕：任一维度触到"风险线"，同时另一个在恶化
```

## 证据强度

- **指标**：四项都是标准财务与经营指标
- **阈值**：组合判断来自公开经验
- **推断**："不合成单一分数"是基于维度间冲突的取舍判断

## 争议与未解

- **增长 vs 质量**：早期公司常牺牲质量换增长，何时切换没有通用时点
- **质量的度量**：投资人看的指标与经营者该看的指标不完全一致
- **合同期的价值**：长约提高可预测性，也可能锁死涨价空间

## 到此为止

这一层是**多维度取舍**：收入质量不是一个数，
是一组互相牵制的指标，以及你对哪一类风险更能承受。

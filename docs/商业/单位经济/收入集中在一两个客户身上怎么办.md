# 收入集中在一两个客户身上怎么办

> **深度** 入门 ｜ **类型** 量级 ｜ **链** 收入稳不稳

## 结论

**先算清占比，再决定是"接受"还是"必须分散"。** 单客户超过三成收入，
你实际上在替一个人打工：他一换供应商、一压价、一拖账期，你的现金流就跟着抖。

## 先算三个数

```text
单客户占比 = 该客户年收入 ÷ 总收入
前 3 客户占比 = 前三大客户收入 ÷ 总收入
最大客户流失的缺口 = 失去该客户后，收入要多久补回
```

第三个最有说服力：**失去最大客户后，按现在的获客速度要几个月才能补上**。
补不回来，就是结构风险。

## 三个应对，按成本排

| 应对 | 做法 | 成本 |
| --- | --- | --- |
| 提高粘性 | 数据、流程、人员的深度嵌入 | 低，但慢 |
| 分散客群 | 每季度新增 1 个同规模客户 | 中，占获客预算 |
| 降低依赖 | 提高单价、缩短账期、预收 | 低，但可能丢单 |

**不要用"再谈一个更大的客户"来分散**——那只是把集中度换成另一种集中。

## 数字与阈值（经验判断）

```text
单客户 < 15%：健康
单客户 15%–30%：关注，需要备选储备
单客户 > 30%：风险，合同与账期要单独设计
前 3 客户 > 60%：高度集中
```

## 证据强度

- **公开经验**：客户集中度是信用与投资分析的常规指标
- **阈值**：15%/30%/60% 来自公开的财务分析惯例，**非绝对标准**
- **推断**："不要用更大客户分散"是按集中度定义直接推出的

## 不适用的情况

- 早期阶段只有一两个客户：这是生存问题，不是结构问题，先活下来
- 政府或平台独家合作：集中是准入条件，只能靠合同与账期管理

## 常见错法

- **把"关系好"当分散**：关系随对接人变动
- **大客户给特殊折扣**：集中度上升，毛利下降，双重风险
- **不签长期合同**：口头合作在采购换人时归零

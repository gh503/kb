# 毛利和净利差在哪

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 一单赚不赚钱

## 结论

**毛利只看"卖这一单直接花的钱"，净利还要扣掉房租、工资、软件、税。**
把项目收入当利润，是小生意最常见的错觉——收入进来时看着很多，扣完固定开销只剩一点。

## 三个层次

```text
毛利润 = 收入 − 直接成本（材料、外包、支付手续费、运费）
毛利率 = 毛利润 ÷ 收入
净利润 = 毛利润 − 固定费用（房租、工资、软件订阅、税）
```

例子：一个项目收 5 万元。外包与材料 2 万，支付手续费 0.3 万 → 毛利 2.7 万，毛利率 54%。
当月固定开销（房租 0.8 万 + 自己/员工工资 1.5 万 + 软件 0.2 万）合计 2.5 万 → 净利 0.2 万。

**5 万的单子，最后赚 2 千——不是记错账，是毛利率不够付固定成本。**

## 数字与阈值

```text
毛利率 < 30%：固定成本很难覆盖，必须靠量
毛利率 30%–50%：服务与贸易常见，扩张要靠人
毛利率 > 60%：有空间投获客与产品
固定成本 / 毛利率 = 保本收入（月固定 2.5 万、毛利率 54% → 月收入约 4.6 万才保本）
```

## 为什么毛利率是关键

| 毛利率 | 含义 |
| --- | --- |
| < 30% | 固定成本很难覆盖，必须靠量 |
| 30–50% | 常见于服务与贸易，扩张要靠人 |
| > 60% | 有空间投获客与产品，规模效应明显 |

毛利率低不一定是坏事（薄利多销），但**它决定了你能负担多高的获客成本**。

## 证据强度

- **公式**：毛利/净利的定义是会计标准，可直接用
- **毛利率区间**：来自公开行业经验，**不同行业差别极大**，只能当参照
- **推断**："毛利率决定可承受的 CAC"是按公式推的：CAC 必须小于单客毛利，否则每单亏

## 不适用的情况

- 项目制生意：收入与成本按项目错配，要看项目毛利而不是月度毛利
- 有大量非现金成本（折旧、摊销）时，现金口径与会计口径不同

## 常见错法

- **把流水当利润**：到账 5 万，不代表赚 5 万
- **漏算自己的工资**：老板不领工资，账面上"盈利"，实际上是自己在补贴
- **把一次性收入当常态**：用最好的一个月推算全年

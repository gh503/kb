# 毛利结构为什么会随规模变差

> **深度** 实操 ｜ **类型** 动因 ｜ **链** 收入稳不稳

## 结论

因为**规模带来的新客户，往往比老客户更难伺候**。第一批客户是"最匹配"的那批，
往后每扩一层客群，定制、支持、折扣都在增加——收入涨了，毛利率却掉了。

## 四个吃掉毛利的来源

| 来源 | 机制 |
| --- | --- |
| 客群下移 | 新客户要求更多定制与支持 |
| 折扣换量 | 大单往往带折扣，单价降 |
| 支持成本 | 客户数上升，答疑与故障处理线性增长 |
| 交付复杂度 | 组合变多，测试与文档成本上升 |

## 一个检查表

```text
每季度看：
1. 新增客户的平均毛利 vs 存量客户的平均毛利
2. 支持工单数 ÷ 客户数（是否在上升）
3. 折扣订单占比（是否在上升）
4. 定制需求数 ÷ 新客户数
```

四项里有两项在恶化，说明增长在稀释质量。

## 数字与阈值（经验判断）

```text
毛利下滑：年降 3–5 个百分点属常见；超过 10 个点要查结构
支持工单/客户：随规模上升 20% 以上，需自动化或提价
折扣订单占比 > 30%：定价体系已被打折侵蚀
```

## 证据强度

- **公开经验**：规模不经济与"客群下移"是订阅与服务业常见现象
- **区间**：来自公开经验，行业差异大
- **推断**："两项恶化即需检查"是按指标趋势推的规则

## 不适用的情况

- 强网络效应产品：规模反而降低单位成本
- 纯软件无支持：边际成本极低，规模效应明显

## 常见错法

- **用总收入增长掩盖毛利率下滑**：增长可能在赔钱
- **靠加人解决支持**：成本上升，问题没解决
- **对定制不收费**：定制成本转入所有客户

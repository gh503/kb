# 涨价怎么开口

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 钱怎么收

## 结论

**提前说、说清楚、给老客户一个期限，然后不再解释。** 涨价本身不是问题，
突然涨价和反复解释才是——前者伤信任，后者伤权威。

## 四步

| 步骤 | 做法 | 时点 |
| --- | --- | --- |
| 1. 提前通知 | 书面告知新价格与生效日 | 提前 30–60 天 |
| 2. 说明理由 | 一句话讲清成本或价值变化，不诉苦 | 同时 |
| 3. 老客户过渡 | 给 3–6 个月旧价或锁定年付 | 生效日前 |
| 4. 不再反复解释 | 定好就不再改口 | 之后 |

## 涨多少

```text
单次涨幅：10%–20% 较常见，超过 30% 建议分两步
要覆盖：成本上涨 + 你想留出的毛利空间
要看：涨价后流失多少（用老客户首月留存判断）
```

分两步涨的好处：客户有适应期，你也能观察流失，而不是一次赌对。

## 什么理由站得住

| 站得住 | 站不住 |
| --- | --- |
| 成本结构变化（有数） | "我们也要生存" |
| 新增了可感知的价值 | "行业都涨了" |
| 老价格是早期优惠价 | "我们以前太便宜了" |

最后一列的共同问题：**把涨价说成自己的需要，而不是客户的选择**。

## 数字与阈值

```text
通知期：30–60 天
老客户过渡：3–6 个月
可接受的流失：首月流失增加 5–10 个百分点以内，视为正常
```

## 证据强度

- **公开经验**：提前通知与老客户过渡是订阅定价的常见做法
- **区间**：涨幅与通知期来自公开经验
- **推断**："不反复解释"基于一致性原则，未实测

## 不适用的情况

- 合同锁价期：合同内不能涨，只能等续约
- 公共服务/受管制价格：需要按规则调整

## 常见错法

- **偷偷改价**：被发现一次，之后所有报价都被怀疑
- **只涨新客户**：老客户越留越便宜，收入结构越来越差
- **涨完又打折**：等于宣布涨价无效

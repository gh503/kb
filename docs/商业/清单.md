# 清单：能直接勾的四张表

> 知识读一遍就忘，清单是拿来用的。四张表各对应一个真实动作，打印或复制到笔记里，逐条打勾。

每张表只有"通过 / 不通过"两种结果。**任何一项不通过，先别往下做**——这就是清单的意义。

## 一、报价前检查表

用在哪：给客户发报价单之前。出处：[报价单怎么写](单位经济/报价单怎么写.md)

| # | 检查项 | 通过标准 |
| --- | --- | --- |
| 1 | 需求复述 | 用两三行写出客户要什么，客户点头 |
| 2 | 交付物清单 | 数量、形态、验收形态都写明 |
| 3 | **不含什么** | 至少写三行"不含" |
| 4 | 前提条件 | 素材、权限、决策人到位时间写清 |
| 5 | 价格口径 | 含税否、币种、是否含差旅 |
| 6 | 付款节奏 | 预付 ≥ 直接成本 |
| 7 | 有效期 | 15–30 天 |
| 8 | 变更流程 | 写清"变更要书面确认" |

**最容易漏的：第 3 项和第 8 项。**

## 二、报价后的定价自检

用在哪：报价数字定下来之前。出处：[定价能算出来吗](单位经济/定价能算出来吗.md) · [折扣为什么会毁掉后面的单](单位经济/折扣为什么会毁掉后面的单.md)

| # | 检查项 | 通过标准 |
| --- | --- | --- |
| 1 | 成本下限 | 报价 ≥ 成本的 1.3 倍 |
| 2 | 市场参考 | 找到 2–3 个可比公开价 |
| 3 | 客户替代方案 | 能说出客户不用你会怎么做、代价多少 |
| 4 | 折扣上限 | 单次折扣 ≤ 毛利率的一半 |
| 5 | 折扣换什么 | 能写进合同的东西（预付、长约、案例） |
| 6 | 谈判空间 | 首报留 10%–20%，不一次放完 |

**第 3 项答不出，说明你还不了解这单生意。**

## 三、项目复盘模板

用在哪：项目或活动结束后一周内。出处：[复盘为什么常常没用](项目管理/复盘为什么常常没用.md) · [活动复盘怎么写才算数](运营/活动复盘怎么写才算数.md)

```text
项目/活动：
日期：           参与人：

一、目标与基线
   想达成什么（数字）：
   活动前是多少（同口径）：

二、结果
   实际是多少：
   差多少：            差在哪一环：

三、归因（逐条打勾）
   [ ] 已扣掉季节/大盘因素
   [ ] 已扣掉同期其他动作
   [ ] 已看留存/退款，不只看注册
   [ ] 样本 ≥ 20 个转化（不足则只写观察）

四、只改一条
   改什么：
   谁做：
   什么时候验证：
```

**规则：改进项最多两条。写五条的那份，一条都不会被执行。**

## 四、交接清单

用在哪：休假、调岗、离职前。出处：[交接清单要写什么](项目管理/交接清单要写什么.md)

| # | 类别 | 要写的内容 |
| --- | --- | --- |
| 1 | 在跑的事 | 当前状态 / 下一步 / 截止日 |
| 2 | 有期限的 | 到期日 + 逾期后果（逐条核对日期） |
| 3 | 权限与账号 | 谁能批、怎么申请、谁托管 |
| 4 | 卡着的事 | 卡在谁、卡了多久 |
| 5 | 联系人 | 外部对接人 + 内部决策人 |
| 6 | 风险 | 每件事"不做会怎样" |

**验收标准：交接后一周，接手人提问少于 5 个。**

## 五、渠道评估表

用在哪：决定一个渠道是加钱、维持还是停。出处：[一个渠道值不值得投](运营/一个渠道值不值得投.md) · [什么时候该停掉一个渠道](运营/什么时候该停掉一个渠道.md)

| # | 指标 | 算法 | 判据 |
| --- | --- | --- | --- |
| 1 | 真实 CAC | 总成本（含内容工时+试错）÷ 新增 | 与表面 CAC 对比，差多少 |
| 2 | 回本周期 | CAC ÷（客单价×毛利率÷复购周期） | 订阅 6–12 个月；项目类 1 单内 |
| 3 | 加钱测试 | 花费翻倍，新增涨多少 | 不到 1.5 倍 → 接近饱和 |
| 4 | 客群质量 | 该渠道次月留存 vs 其他渠道 | 明显更低 → 停 |
| 5 | 样本量 | 转化数 | < 20 个 → 无法判断，别下结论 |
| 6 | 趋势 | 真实 CAC 连续两个月 | 连续上升 → 停 |

**第 5 项没过就别看前四项**——样本不足时，所有结论都是噪声。

## 六、发出去前的三问

用在哪：任何对外交付（报价、方案、周报）之前。出处：[验收标准怎么写](项目管理/验收标准怎么写.md)

1. **对方拿到这份东西，下一步做什么？** 答不出，就是没写完
2. **里面有没有"形容词"？** 有，就改成可检查的条件
3. **如果对方只读第一段，会记住什么？** 那应该是结论

## 关于这些清单

这五张表是**从 52 页里提炼的操作件**，不是新增知识。它们和速查表的区别：

- [速查](速查.md)：查数——公式与区间在哪
- 清单：做事——现在这一步要检查什么

如果你用了几次发现某条不适用，告诉我，我改这一条；比加十个新主题有用。

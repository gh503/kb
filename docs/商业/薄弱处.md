## 每一处怎么自查

### 1. 留存区间

```text
做法：按品类分别查，不要跨品类套用
你自己的判据：找连续 3 个同期群，看曲线在哪走平
若走平在 10% 但你持续盈利 → 这个区间对你不适用
```

### 2. 估算系数

```text
探索性任务：改为时间盒（"3 天内做到哪一步"），不估完成时间
重复性任务：用你自己的历史中位数，不要乘外部系数
若你的实际耗时稳在直觉 1.1 倍内 → 你已经校准，别再加系数
```

### 3. 折扣上限

```text
真正能算的：需要多卖 = 降幅 ÷（毛利率 − 降幅）
折扣上限该由固定成本结构决定：
  保本收入 = 固定成本 ÷ 毛利率
  折扣后的毛利率还能覆盖固定成本吗？
```

### 4. 转介绍成本

```text
转介绍全成本 = 推荐奖励 + 被推荐人折扣 + 维护关系的时间
把它和投放 CAC 放在同一张表上比，才有意义
若两者接近 → 转介绍的优势是"更可信"，不是"更便宜"
```

### 5. 流失阈值

```text
企业级年付合同：看续约率，不看月流失
小额消费订阅：月流失 8%–10% 也可能是常态
渠道红利期：先拿规模可能对——但要知道窗口何时关
```

## 还有一类没标出来的

**所有"阈值"都来自别人的经验，不是你的数据。** 这一页只挑了 5 处最明显的，
但严格说，速查表里每一行区间都属于这一类。

判断一个数能不能用，问三个问题：

1. 它是**算术**（公式换算）还是**经验**（别人的观察）？
2. 我的品类和它的样本像不像？
3. 我自己的数据长什么样？

第 3 问答不出，就先用区间、别定生死线。

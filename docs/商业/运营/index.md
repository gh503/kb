# 运营

> 东西有人用之后：拉新、留存、内容、渠道、看数据。

## 收什么

- 渠道对比与实测结果：花了多少、带来什么、留存怎么样
- 活动复盘：目标是什么、实际怎么样、下次改哪一条
- 指标口径：这个"活跃"到底怎么算的，换个人算会不会一样
- 内容策略：写给谁、在哪发、什么标题真的有人点

## 不收什么

- 行业八卦和融资新闻
- 没有基线的"增长了"——涨了多少、跟什么比

# 一个渠道的成本到底包含哪些

> **深度** 入门 ｜ **类型** 量级 ｜ **链** 投放怎么算账

## 结论

**只算投放平台花掉的钱，会把获客成本低估一半以上。** 完整成本包括：平台费、
做内容的人工、工具订阅、以及试错打水漂的那部分——**试错才是最大的那一项**。

## 五类成本

| 类别 | 具体 | 常见漏算 |
| --- | --- | --- |
| 平台费 | 广告、推广位、达人佣金 | 一般都会算 |
| 内容生产 | 拍摄、设计、写稿、剪辑工时 | **几乎总被漏掉** |
| 工具 | 剪辑、排版、数据、客服系统 | 按月摊 |
| 试错 | 没跑起来的选题、被封的号、停掉的计划 | **没人愿意记** |
| 售后 | 因投放来的低质量客户的退款与投诉 | 也算获客成本 |

## 一个完整的算法

```text
渠道总成本 = 平台费 + 内容工时 × 时薪 + 工具月费 × 月数 + 试错沉没 + 售后成本
真实 CAC  = 渠道总成本 ÷ 新增客户数

对比：只算平台费时
  表面 CAC = 6000 ÷ 30 = 200
  真实 CAC = (6000 + 20 小时×150 + 300 + 4000试错) ÷ 30 = (6000+3000+300+4000)/30 ≈ 443
```

**同一批客户，成本差一倍以上。** 这就是"感觉投放挺划算"和"账上没钱"同时发生的原因。

## 数字与阈值（经验区间）

```text
内容工时占比：常占总成本 20%–40%（自营内容）
试错沉没：早期渠道常占 30%–50%
只算平台费导致的低估：50%–70%
```

## 证据强度

- **公开经验**：全成本口径（fully loaded CAC）是营销财务分析的常规概念
- **区间**：占比来自经验，自营与代运营差别很大
- **推断**：示例中的数字是构造的，用来说明量级，不是实测

## 不适用的情况

- 纯品牌广告：当期无法归因，成本要按年度摊
- 平台补贴期：真实成本被补贴掩盖，停补贴后要重算

## 常见错法

- **不算自己的时间**：老板的时间最容易"免费"
- **不记试错**：只记成功的投放，CAC 永远好看
- **把退款当售后费用**：它直接抬高获客成本

# 为什么线索多不等于成交多

> **深度** 入门 ｜ **类型** 误区 ｜ **链** 转化怎么提

## 结论

因为**线索是漏斗的第一层，成交由最窄的那一层决定**。
1000 个线索、10 个成交，问题可能出在"线索质量"这一层，也可能出在"跟进"这一层——
不看每一层的转化率，只看头尾，等于凭感觉改。

## 把漏斗拆开

```text
曝光 → 点击 → 咨询 → 有效需求 → 报价 → 成交

每层算：本层数量 ÷ 上一层数量
```

例子：点击 1000、咨询 60（6%）、有效需求 20（33%）、报价 12（60%）、成交 4（33%）。
整体从点击到成交 0.4%。**最窄的一层是"咨询→有效需求"**，这里动手收益最大。

## 线索质量 vs 跟进能力

| 症状 | 更可能是 |
| --- | --- |
| 咨询多、有效需求少 | 线索质量（来的不是目标客户） |
| 有效需求多、报价少 | 跟进或方案匹配 |
| 报价多、成交少 | 价格、信任或决策链 |

三条症状对应三种完全不同的改法。**先定位，再改。**

## 数字与阈值（经验区间）

```text
咨询→有效需求：低于 20% 通常说明线索来源太杂
报价→成交：10%–30% 常见（B2B 中小单）
从首个接触到成交：平均 5–8 次触达
```

## 证据强度

- **公式**：分漏斗算转化率是分析常识
- **区间**：来自公开的 B2B 销售经验，行业差异极大
- **推断**："症状→病因"对照表是按环节归因整理的，未实测

## 不适用的情况

- 极低频高客单（如大型设备）：样本太少，转化率不稳定
- 平台内成交（如电商）：漏斗由平台数据给出，重点看流量质量

## 常见错法

- **只看成交总数**：不知道卡在哪一层
- **用线索数考核**：会奖励刷量
- **把"没成交"都归为价格**：多数是信任与时机

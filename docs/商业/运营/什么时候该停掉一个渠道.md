# 什么时候该停掉一个渠道

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 投放怎么算账

## 结论

**当"再加一个月的钱，结论也不会变"时停。** 判据不是这个月亏不亏，
而是 CAC 的趋势、样本够不够、以及同样的钱放到别处会不会更好。

## 四个停止信号

| 信号 | 判据 |
| --- | --- |
| 成本趋势恶化 | 真实 CAC 连续 2 个月上升 |
| 加钱不涨量 | 花费翻倍、新增不到 1.5 倍 |
| 质量下降 | 该渠道客户的次月留存明显低于其他渠道 |
| 拿不到样本 | 4 周内转化 < 20 个，无法判断 |

**前三条是"该停"，第四条是"没法判断"**——后者要么加预算到能测，要么直接放弃。

## 停之前的三个检查

```text
1. 是不是内容问题而不是渠道问题？（换 3 条素材再判断）
2. 是不是承接问题？（落地页、报价、跟进）
3. 停掉后这块需求的客户会去哪？（有没有替代渠道接住）
```

第 1 条最常被跳过：**很多"渠道不行"是素材不行**。

## 停的时候怎么做

- **逐步减**，不要一天归零：保留最低预算观察 2 周
- **留档**：素材、数据、结论写进一处，半年后复用
- **通知相关人**：达人、代运营、内部协作方

## 数字与阈值（经验判断）

```text
观察窗口：至少 4 周 + 20 个转化
CAC 上升判定：连续 2 个月，或单月上升 > 30%
归零前观察期：2 周，最低预算
```

## 证据强度

- **公开经验**：渠道退出的判据与"素材先于渠道"的排查顺序在增长实践里常见
- **区间**：窗口与升幅来自经验
- **推断**："逐步减而不是归零"是按数据连续性与关系维护推的

## 不适用的情况

- 平台政策风险（随时可能被封）：应提前准备替代渠道，而不是等数据说话
- 战略渠道（生态合作）：亏钱也有占位价值，需单独判断

## 常见错法

- **一周没效果就停**：样本不足，结论无效
- **只看表面 CAC**：没算内容工时与试错，误判为赚钱
- **停了不留档**：半年后重新踩一遍同样的坑

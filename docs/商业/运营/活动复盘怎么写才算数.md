# 活动复盘怎么写才算数

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 投放怎么算账

## 结论

**先写目标和基线，再写结果，最后只留一条改动。** 没有基线的"效果不错"、
没有取舍的"下次注意"，都是自我安慰。

## 四段结构

```text
1. 目标与基线：想达成什么？活动前是多少？（数字）
2. 结果：达到了吗？差多少？（同一口径）
3. 归因：变化里有多少来自活动、多少来自季节/其他动作？
4. 一条改动：下次改什么，谁做，什么时候验证
```

## 基线的三个来源

| 来源 | 说明 |
| --- | --- |
| 活动前同期 | 最常用，但受季节影响 |
| 对照组/未参与人群 | 最可靠，成本高 |
| 历史同类活动 | 样本少时要打折看 |

**没有基线就没有结论**，只有感受。

## 归因要诚实

- 同期有没有别的大动作（改价、上新、平台改规则）
- 活动带来的客户留存如何（只看到注册就是自欺）
- 退款与投诉是否同步上升

## 数字与阈值（经验建议）

```text
复盘篇幅：一页以内，超过说明没提炼
改进项：1 条，最多 2 条
验证时点：下一次同类活动结束后一周
样本不足：转化 < 20 个时，只写观察，不写结论
```

## 证据强度

- **方法**：目标—基线—结果—归因的结构是复盘的标准做法
- **建议值**：篇幅与条数来自经验
- **推断**："20 个转化以下不写结论"是按小样本波动推的

## 不适用的情况

- 品牌类活动：目标不是转化，应改为认知度调查与搜索量
- 一次性大型活动：没有"下次"，重点转为资产归档

## 常见错法

- **只写结果不写基线**：涨了不知道跟什么比
- **把平台大盘上涨算成自己的功劳**
- **列十条改进**：一条都落不了地

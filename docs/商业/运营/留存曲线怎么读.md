# 留存曲线怎么读

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 留存怎么读

## 结论

**看曲线会不会走平，而不是看某个点的数字。** 走平说明有一批人长期在用；
一路趋零说明每批用户都在流失，你必须不断买新的。

## 怎么画

```text
按注册月份分组（同期群 / cohort）
横轴：注册后第 N 天或第 N 个月
纵轴：该组里还有活跃动作的比例
每组画一条线，叠在同一张图上
```

关键是**分组**：把所有用户混在一起算，老用户会稀释新用户的问题，曲线看起来比实际好。

## 三种形状

| 形状 | 含义 | 该做什么 |
| --- | --- | --- |
| 走平（有平台期） | 存在稳定核心用户 | 放量，并研究平台期那批人是谁 |
| 缓慢下降 | 价值在衰减 | 找衰减点：第几周开始掉 |
| 快速趋零 | 一次性需求 | 换模式，或接受它只能靠新增 |

## 数字与阈值

```text
平台期位置：次月留存 20%–40% 常见于工具类；社交/内容类更高
平台期宽度：连续 3 个月基本不动，才算真的走平
一个月的横盘不算走平，至少看 3 个同期群
```

## 证据强度

- **方法**：同期群分析是标准做法，可直接用
- **区间**：平台期数值来自公开经验，品类差异大
- **推断**："三个月不动才算走平"是按波动与样本量推的经验规则

## 已知的薄弱处

**平台期 20%–40%（工具类）这个区间太粗。** 它把几种完全不同的生意混在一起：

- 消费类订阅（音乐、影音）：次月留存常远高于 40%
- B2B 工具（月频使用）：往往低于 20% 也可能正常
- 电商复购：根本不该用"次月留存"，该用复购周期

**能推翻它的证据**：你自己品类的留存曲线走平在 10% 却持续盈利——
那就说明这个区间对你的品类不适用，应以自己的历史数据为准。

## 不适用的情况

- 用户量很小（每群 < 30 人）：曲线全是噪声
- 季节性生意：同期群要按季节对齐，否则误判

## 常见错法

- **用整体留存代替分组**：老用户撑住平均值
- **只看到次月**：第 3–6 个月才是分水岭
- **把"登录"当活跃**：定义要包含核心动作

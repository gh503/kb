# 留存能改善到多少

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 留存怎么读

## 结论

**有天花板，而且由需求频率决定。** 一个月才用一次的东西，做不到日活留存；
把留存目标设成和日频产品一样，团队会被一个不可能的数字拖垮。

## 先分清需求频率

| 需求频率 | 例子 | 合理的"活跃"口径 |
| --- | --- | --- |
| 每天 | 通讯、短视频、协作工具 | 日活 / 周活 |
| 每周 | 记账、健身、部分 SaaS | 周活 / 月活 |
| 每月 | 报税、招聘、部分 B2B | 月活 / 季活 |
| 每年 | 保险、年检、装修 | 年度复购，不谈留存 |

**口径错了，留存数字全是假的。** 用日活衡量月频产品，永远"留存很差"。

## 能改善的三处

1. **首次体验**：新用户是否在第一次就拿到价值
2. **使用触发**：有没有让用户在需要时想起你（提醒、场景绑定）
3. **替代成本**：数据、习惯、协作关系是否沉淀在你这里

改善的顺序应该是 1 → 2 → 3。跳过 1 直接做 3，用户根本不会来第二次。

## 数字与阈值（经验判断）

```text
改善幅度：同品类里，把首次体验做好的提升通常在 10%–30% 相对值
平台期上限：由需求频率决定，强改无效
若把留存目标定在品类上限的 2 倍以上：先怀疑口径
```

## 证据强度

- **框架**：按需求频率定口径是分析常识
- **区间**：10%–30% 的相对提升来自公开经验
- **推断**："天花板由频率决定"是基于使用场景的推理，不是实测

## 争议与未解

- **能不能造需求**：把月频变成日频，有时靠场景绑定（如记账 + 支付），但多数尝试失败
- **留存的替代指标**：低频生意用"推荐率""复购周期"更合理，但缺少统一标准
- **刷出来的留存**：推送、签到能拉高数字，不改变真实需求

## 到此为止

这一层是**频率决定上限**：留存能优化，
但优化不到需求本身不存在的地方。

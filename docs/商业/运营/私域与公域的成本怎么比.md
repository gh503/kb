# 私域与公域的成本怎么比

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 客户经营

## 结论

**公域买"一次曝光"，私域买"重复触达"——成本结构完全不同，不能只看单次成本。**
公域的费用是持续的，停投就停量；私域的成本是前置的，建好之后边际成本很低，
但**要人维护**，维护就是持续的人力投入。

## 两边的成本构成

| 项 | 公域（平台投放） | 私域（自有渠道） |
| --- | --- | --- |
| 前置投入 | 低 | 高（内容、社群、工具搭建） |
| 每次触达成本 | 按曝光付费 | 接近零 |
| 停投后 | 立刻归零 | 仍在（但要维护） |
| 主要风险 | 平台政策、成本上涨 | 沉寂、被折叠、人力不足 |

## 一个可比的口径

```text
公域：单位触达成本 = 投放花费 ÷ 有效触达数
私域：单位触达成本 = （搭建摊销 + 每月维护人力 × 时薪）÷ 每月有效触达数

只有把"维护人力"算进去，两者才可比。
只算搭建成本，私域会显得便宜得离谱。
```

## 数字与阈值（经验判断）

```text
私域维护人力：每 500–1000 活跃用户约需 0.5–1 人
内容成本：私域常占总成本的 30%–50%（要持续产出）
有效触达率：社群类消息打开率常见 10%–30%
```

## 证据强度

- **公开经验**：公域/私域的成本结构差异是营销实践里的常见讨论
- **区间**：人力与打开率来自经验，差异极大
- **推断**："必须把维护人力计入"是按成本可比性推的原则

## 不适用的情况

- 一次性生意（婚庆、装修）：复购周期长，私域价值低
- 平台内闭环（外卖、电商）：用户留在平台，导流成本高且违规

## 常见错法

- **只算搭建成本**：私域看起来几乎免费，实际养不起
- **把私域当广告位**：天天发促销，三个月就没人看
- **两边都不投**：等自然流量，等于把命交给平台

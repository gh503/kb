# 老客户还能怎么用

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 客户经营

## 结论

**老客户有四种用法：复购、增购、转介绍、案例。** 四种的成本与收益完全不同，
**最容易被浪费的是"案例"**——它不需要客户多花钱，只需要你开口问。

## 四种用法

| 用法 | 客户付出 | 你的收益 | 难度 |
| --- | --- | --- | --- |
| 复购 | 钱 | 直接收入 | 低 |
| 增购/升级 | 更多钱 | 更高客单 | 中 |
| 转介绍 | 面子与信任 | 新客户，CAC 低 | 中 |
| 案例/证言 | 一点点时间 | 缩短别人的决策 | 低 |

**性价比最高的是案例**：客户只需点头，你却能用一整年。

## 开口的正确时机

```text
最好：交付完成、客户刚说"不错"的那一刻
次好：解决了某个具体问题之后
最差：月初群发"求好评"
```

**不要在同一次沟通里既收钱又要人情。** 谈钱和要案例分开。

## 一个可执行的节奏

| 时点 | 动作 |
| --- | --- |
| 交付后 1 周 | 问一句"用得怎么样"，收集问题 |
| 交付后 1 个月 | 若反馈正面，请求一句证言 |
| 每季度 | 挑 3–5 个满意客户，问转介绍 |
| 每年 | 谈续约/增购，顺势问案例授权 |

## 数字与阈值（经验判断）

```text
愿意给证言的比例：满意客户里约 20%–40%
愿意转介绍的比例：约 10%–20%
主动开口 vs 等客户主动：主动的比例高数倍
授权范围：一定要写清能否公开公司名
```

## 证据强度

- **公开经验**：证言与转介绍的获取比例在客户成功实践中有类似观察
- **区间**：比例来自经验
- **推断**："谈钱与要人情要分开"是按关系成本推的

## 不适用的情况

- 保密行业（医疗、金融）：案例必须脱敏或不用
- 客户关系紧张：先修复，不要急着要东西

## 常见错法

- **只在需要时找老客户**：平时不联系，一联系就要东西
- **不写授权范围**：口头同意，事后不愿公开
- **把转介绍当 KPI 压给客户**：客户会觉得被利用

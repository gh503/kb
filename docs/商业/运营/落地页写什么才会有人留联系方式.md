# 落地页写什么才会有人留联系方式

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 客户经营

## 结论

**首屏三句话讲清"给谁、解决什么、下一步做什么"，然后只要一个动作。**
多数落地页不是写得不好，是**想说的太多**：三个卖点、五个按钮、两段公司历史。

## 首屏三件事

```text
1. 一句话说清给谁用、解决什么问题（不要形容词）
2. 一个能看见的证据（截图、数据、客户名）
3. 一个动作按钮（只要一个）
```

反面例子："致力于为中小企业提供一站式数字化解决方案"——**读完不知道你做什么**。

## 往下滚的顺序

| 顺序 | 内容 | 目的 |
| --- | --- | --- |
| 1 | 首屏 | 让人知道这是什么 |
| 2 | 具体场景（两三个） | 让人对号入座 |
| 3 | 证据（案例、数据、评价） | 让人相信 |
| 4 | 常见疑问（5–8 条） | 消除最后顾虑 |
| 5 | 再次行动 | 给滚到底的人一个出口 |

## 表单只要两三个字段

```text
能少则少：姓名 + 联系方式（+ 一个可选："你想解决什么"）
每多一个必填字段，转化率通常下降一档
```

想要更多信息，**在第一次沟通里问**，不要在表单里问。

## 数字与阈值（经验区间）

```text
首屏字数：主标题 ≤ 20 字，副标题 ≤ 40 字
表单字段：2–3 个
落地页转化（留联系方式）：1%–5% 常见；> 10% 属很好
页面加载：3 秒以上，跳出明显上升
```

## 证据强度

- **公开经验**：首屏清晰度与表单长度对转化率的影响是转化率优化里的常规结论
- **区间**：转化率来自经验，行业差异很大
- **推断**："多一个字段降一档"是按摩擦成本推的，未实测

## 不适用的情况

- 高客单复杂产品：需要更多信息，但应分步收集而不是一次问完
- 已有品牌信任：可以弱化证据部分，直接给行动

## 常见错法

- **首屏放公司介绍**：客户不关心你成立于哪年
- **多个按钮抢注意力**：主按钮只能有一个
- **表单问预算**：第一次就问你预算多少，多数人直接关掉

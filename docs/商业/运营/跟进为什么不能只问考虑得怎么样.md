# 跟进为什么不能只问"考虑得怎么样"

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 转化怎么提

## 结论

因为**这句话把决定权交回给对方，还逼他表态**。客户没想清楚时会敷衍，
你就得到一个假信号：以为还在谈，其实已经凉了。

## 换一种问法

| 不要问 | 改问 |
| --- | --- |
| 考虑得怎么样？ | 这几项里，哪一项还需要再确认？ |
| 还有问题吗？ | 你们内部还要谁点头？ |
| 要不要定下来？ | 如果这周定，卡在哪一步？ |

共同点：**问具体卡点，不问态度**。态度无法跟进，卡点可以。

## 跟进的三条规则

```text
1. 每次沟通结束，约好下一步与时间（谁、做什么、什么时候）
2. 没有下一步的，标为"暂停"，移出跟进列表
3. 跟进节奏：第 1、3、7、14、30 天，之后每月一次，不超过 6 次
```

第 2 条最重要。**没有下一步的客户不是客户，是名单。**

## 决策链要问清

- 谁用？谁付钱？谁能否决？
- 有没有必须走的流程（比价、招标、法务）？
- 上一个同类采购是怎么定的？

很多单子不是输在价格，是**你只跟对接人谈，没见到真正拍板的人**。

## 数字与阈值

```text
有效跟进次数：5–8 次触达才成交是常见情况
触达间隔：前期密（1/3/7 天），后期疏（月）
单次跟进时长：15–30 分钟足够，长了反而拖
```

## 证据强度

- **公开经验**：多次触达与决策链分析是销售方法里的通用做法
- **区间**：触达次数与节奏来自公开经验
- **推断**："没有下一步就移出"是按注意力成本推的规则

## 不适用的情况

- 自助式购买（低客单、线上支付）：没有跟进环节
- 已完成技术选型只剩走流程：重点转为推进流程，不是说服

## 常见错法

- **群发问候**：客户能看出来，反而降低信任
- **只跟对接人不碰决策人**：信息在中间层被过滤
- **把"再看看"当机会**：没有具体卡点的"再看看"通常是拒绝

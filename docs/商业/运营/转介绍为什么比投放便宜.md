# 转介绍为什么比投放便宜

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 留存怎么读

## 结论

因为**推荐人已经替你做完了说服**。投放买的是注意力，转介绍拿到的是信任——
被朋友推荐来的人，成交成本更低、留存更高，而且不需要每月付平台费。

## 为什么更便宜

1. 说服成本已经由推荐人承担
2. 来的人与产品更匹配（朋友知道对方需要什么）
3. 没有平台竞价，边际成本接近零
4. 留存更高，同样的获客预算产出更多

## 用 k 值衡量

```text
k = 每个用户平均带来的新用户数

k > 1：自增长（每个用户带来不止一个新用户）
k = 0.5：每两个用户带来一个，等于把获客成本打对折
k < 0.2：转介绍基本可以不算在增长里
```

## 怎么提高 k

| 动作 | 说明 |
| --- | --- |
| 在"刚刚获得价值"时邀请 | 用户最愿意分享的时刻是刚解决问题 |
| 给双方好处 | 只给推荐人好处，被推荐人会有戒心 |
| 降低分享成本 | 一条链接、一句现成的话，不要让用户自己组织语言 |
| 让结果可见 | 用户展示成果时，自然带上你的名字 |

## 数字与阈值（经验区间）

```text
转介绍来的用户：CAC 常为投放的 1/3–1/2
k 值：多数产品 < 0.5，做到 0.7 以上已经很好
转介绍占比：健康的来源结构里常在 20%–40%
```

## 证据强度

- **公式**：k 值是标准增长模型（病毒系数），可直接用
- **区间**：来自公开经验，品类差异大
- **推断**："刚获得价值时邀请效果最好"，基于时机与动机的推理，未实测

## 不适用的情况

- 隐私敏感品类（医疗、金融）：用户不愿公开关联
- 低单价高频商品：推荐奖励可能高于毛利

## 常见错法

- **一上来就求推荐**：用户还没获得价值，推荐是负担
- **只奖励推荐人**：容易变成刷奖励，带来低质量用户
- **没有闭环**：推荐来了没人接待，等于白推荐

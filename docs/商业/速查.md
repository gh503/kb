## 一、能不能赚钱

| 要算的 | 公式 | 判据 |
| --- | --- | --- |
| 毛利润 | 收入 − 直接成本（材料、外包、手续费、运费） | 毛利率 < 30% 难覆盖固定成本 |
| 净利润 | 毛利润 − 固定费用（房租、工资、软件、税） | 别把流水当利润 |
| 保本收入 | 固定成本 ÷ 毛利率 | 月固定 2.5 万、毛利 54% → 约 4.6 万/月 |
| CAC | **全成本** ÷ 新增客户数（含内容工时、工具、试错） | 只算平台费会低估 50%–70% |
| 回本周期 | CAC ÷（客单价 × 毛利率 ÷ 复购周期） | 订阅 6–12 个月；项目类 1 单内 |

## 二、现金会不会断

```text
DSO = 平均应收 ÷ 收入 × 365
DIO = 平均存货 ÷ 成本 × 365
DPO = 平均应付 ÷ 成本 × 365
CCC = DIO + DSO − DPO
```

| CCC | 含义 | 需要准备的钱 |
| --- | --- | --- |
| < 0 | 客户在给你融资 | 无 |
| 30 天 | 常见 | 约 1 个月收入 |
| 90 天以上 | 危险 | 融资或预收，否则扩张必卡 |

**关键关系**：收入翻倍，垫资也翻倍——这是"增长把自己撑死"的机制。

出处：[现金流为什么能杀死盈利的公司](单位经济/现金流为什么能杀死盈利的公司.md)

## 三、价格怎么定

| 决策 | 数 | 说明 |
| --- | --- | --- |
| 首次报价留多少谈判空间 | 10%–20% | 别在第一次就放完 |
| 报价下限 | 成本的 1.3 倍 | 低于此没有容错 |
| 三档价差 | 相邻档 1.5–2.5 倍 | 中间档做成最赚钱的那档 |
| 单次折扣上限 | 毛利率的一半 | 超过就伤本 |
| 折扣要换回多少量 | 降幅 ÷（毛利率 − 降幅） | 毛利 40% 降 10% → 多卖 33% |
| 年付折扣 | 8%–17%（"送 2 个月" = 16.7%） | 月流失 5% 时，年付本身已多收约 17% |
| 报价单有效期 | 15–30 天 | 没有有效期等于给客户无限选择权 |
| 分期比例 | 预付 30%–50% ｜ 尾款 10%–30% | 预付款要 ≥ 直接成本 |
| 默示验收期 | 5–10 个工作日 | 不约定，客户可以永远"还在看" |

## 四、收入稳不稳

| 指标 | 健康线 | 危险信号 |
| --- | --- | --- |
| 单客户占比 | < 15% | > 30%，前 3 家 > 60% |
| GRR（毛留存） | 85%–90% | < 80%，先修交付 |
| NRR（净留存） | 100%–120% | GRR 低而 NRR 高 = 少数客户在掩盖流失 |
| 毛利趋势 | 稳定或上升 | 年降 > 10 个点要查结构 |

**生命周期换算**：续约率 90% → 约 10 年；80% → 5 年；70% → 3.3 年。**每掉 10 个点，年限减半。**

## 五、获客值不值

| 指标 | 数 | 说明 |
| --- | --- | --- |
| 单渠道跑出初步信号 | 2–4 周 | 每天 1 条左右 |
| 判断趋势 | 约 3 个月 | 覆盖一次平台波动 |
| 有意义的转化样本 | 20–50 个 | 少于 20 不下结论 |
| 花费翻倍而新增不到 1.5 倍 | 渠道接近饱和 | — |
| 转介绍 k 值 | 0.5 ≈ CAC 打对折 | k > 1 才是自增长 |
| 免费转付费 | 2%–5% | 超过 10% 属优秀 |
| 真实 CAC 溢价 | 只算平台费会低估 50%–70% | 内容工时 + 试错沉没 |
| 预算分档 | 70 / 20 / 10 | 测试份额低于 10% 等于不测 |
| 单渠道最低测试量 | 20–50 个转化 | 4 周内拿不到就无法判断 |
| 落地页留资率 | 1%–5% 常见 | 首屏讲不清、表单超 3 格就掉 |
| 客户活跃下滑阈值 | 30% 以上要联系 | 静默 2 周 = 危险信号 |
| 私域维护人力 | 每 500–1000 活跃用户 0.5–1 人 | 不算人力，私域会显得免费 |

## 八、该不该停

```text
命中两条止损信号 + 连续两个季度无改善 → 认真讨论退出
信号：留存平台期 < 15% ｜ 回本越来越长 ｜ GRR < 70% ｜ 增长靠不断换客群
```

判断之前先写：**如果这个产品能成，它必须满足什么**；再写：**下个周期能验证哪一条**。
写不出第二条，就不是"再试试"，是没有判断标准。

出处：[什么时候该放弃一个产品](项目管理/什么时候该放弃一个产品.md) · [该放弃还是该再试一次](项目管理/该放弃还是该再试一次.md)

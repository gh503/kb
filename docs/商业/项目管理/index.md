# 项目管理

> 把一件多人、多周的事推完。

## 收什么

- 范围界定：不做什么，比做什么更难写，也更重要
- 排期估算：估过的和实际的差多少，误差从哪来
- 协作机制：谁在什么时候给什么，卡住了找谁
- 复盘模板：事实、原因、下一步，分开写

## 不收什么

- 认证教材的复述
- 只在大公司成立、小团队用不上的流程

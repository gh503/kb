# 沉没成本怎么让人不肯停

> **深度** 实操 ｜ **类型** 误区 ｜ **链** 该不该停

## 结论

因为**停下来等于承认前面的投入白费了**。继续投，至少还能维持"我在做一件有意义的事"；
这是心理账，不是经济账——已经花掉的钱，无论停不停都收不回来。

## 三种自我说服

| 说法 | 翻译 |
| --- | --- |
| "都投了这么多了" | 沉没成本谬误 |
| "再撑一个季度就好了" | 没有依据的时间承诺 |
| "现在停，团队会怎么看我" | 面子成本 |

第三种最隐蔽：**退出被当成失败，而不是决策**。

## 一个可操作的做法

```text
1. 假设今天从零开始：还会不会做这个产品？
   不会 → 该停
2. 只看未来：继续投入需要多少钱、多久、成功率多少
   不看已经花了多少
3. 把决定交给"如果换个人来管，他会怎么做"
```

第 1 条最有效：它把沉没成本从决策里切掉。

## 组织层面的两个设计

- **预设退出条件**：立项时就写清"什么情况下停"
- **区分决策与追责**：按"当时信息是否充分"评价，而不是按结果

第二条决定了团队敢不敢早说坏消息。

## 数字与阈值

```text
承诺升级：投入越多，越难停——这是被反复验证的倾向
退出讨论时点：连续 2 个季度未达预设指标，强制讨论
```

## 证据强度

- **公开研究**：沉没成本效应与承诺升级是行为决策里较稳定的发现
- **推断**："从零开始假设"是去偏技巧，效果因人而异
- **未验证**：组织层面两条设计的实际效果，我没有对照数据

## 不适用的情况

- 沉没成本有时是真实信号：已投入形成的资产（数据、牌照）可能确实有价值
- 长期基础研究：短期指标不适用，需要另一套评价

## 常见错法

- **把"坚持"当美德**：坚持只在有假设时才有意义
- **追责退出决定**：下次没人敢提停
- **一刀切停掉**：先停新增投入，保留维护

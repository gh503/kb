# 该放弃还是该再试一次

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 该不该停

## 结论

**看有没有"一个能在一个周期内被证伪的假设"，而不是看感觉。**
有假设、且上个周期确实证伪了 → 停；有假设但没测过 → 再试一次，但设时间盒；
没有假设 → 无论停不停，都是在赌。

## 三种情形

| 情形 | 判断 | 动作 |
| --- | --- | --- |
| 假设被证伪 | 停 | 记录结论，转资源 |
| 假设没测过 | 再试，但设时间盒 | 明确指标 + 8 周 |
| 没有假设 | 先写假设 | 写不出就等于该停 |

## 时间盒怎么写

```text
假设：把首次体验改到"3 步内看到结果"，次月留存会从 12% 升到 20%
验证：8 周，样本 ≥ 100 个新用户
判据：达到 18% 视为成立，低于 15% 视为不成立
```

**判据要事先写，且允许"部分成立"**——只写"成功/失败"，会逼人把结果解释成成功。

## 一个反直觉的提醒

**"再试一次"的成本常常被低估**：不是再投一笔钱，而是团队又有一个季度不能做别的。
机会成本才是真正的代价。

## 数字与阈值

```text
时间盒：6–12 周，超过就容易变成"无限期观察"
样本量：少于 50 个新用户，结论不可信
连续两次证伪：停，不要再开第三个假设
```

## 证据强度

- **方法**：可证伪假设 + 时间盒来自实验设计与精益创业实践
- **区间**：周数与样本量来自经验
- **推断**："连续两次证伪就停"是按机会成本推的规则

## 争议与未解

- **该不该坚持**：历史上既有"再撑一下就成了"的案例，也有"及时止损"的案例，幸存者偏差严重
- **判据的松紧**：太松会自欺，太严会杀掉早期信号
- **谁来决定**：做产品的人判断容易受投入影响，第三方判断又缺上下文

## 到此为止

这一层是**退出的判据**：停不停不是勇气问题，
是有没有可验证的假设、以及愿不愿意为它设一个截止日。

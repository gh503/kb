# 数学

> 够用的数学：知道什么时候该用哪个工具，而不是会推导每一个定理。

## 收什么

- 概念直觉：概率、期望、方差、相关、回归各自在说什么
- 常见误用，尤其是"把相关当因果""用平均值掩盖分布"
- 计算与画图的具体做法（用什么工具、输入什么、怎么读结果）
- 量级估算：先算个大概，再决定要不要精确

## 不收什么

- 教材式推导——除非自己重推过一遍，并且记下了卡在哪
- 没有应用场景的公式清单

## 条目

还没有条目。先写一条**"我上次算错的那个数"**：错在哪、正确算法是什么、怎么快速自检。

## 结论

**换一个分母，结论能反过来——这叫辛普森悖论，不是统计学花招。**
本机算例：A 科室重症 **95%**、轻症 **60%**，B 科室重症 **90%**、轻症 **50%**；
A 两个分层都更高，但**合计只有 77.5%，B 是 86.4%**——因为两科室的病人结构完全不同。

## 三个换分母的场景

```text
1. 合并 vs 分层：分层都赢，合计却输（辛普森）
2. 每万人 vs 总数：大城市事故多，但每万人更低
3. 转化率的基数：下单/访问 vs 下单/加购，能差 10 倍
```

**"整体看是涨的"** 先问一句：分母变了吗？

## 本机可复现（已算）

```bash
python3 - <<'PY'
A=[(95,100),(60,100)]    # 重症 95/100，轻症 60/100
B=[(900,1000),(50,100)]  # 重症 900/1000，轻症 50/100
for name,x in (("A",A),("B",B)):
    print(name, [f"{a/b:.0%}" for a,b in x], f"合计 {sum(a for a,_ in x)/sum(b for _,b in x):.1%}")
PY
```

本机输出：

```text
科室A：重症 95% ｜轻症 60% ｜合计 77.5%
科室B：重症 90% ｜轻症 50% ｜合计 86.4%
```

## 为什么会反过来

```text
A 的病人几乎都是重症（100/200），而 A 的轻症疗效差（60%）
B 的病人几乎都是轻症（1000/1100），而 B 的轻症疗效好（90% → 但本机设 50%？）
  → 关键在于"权重"：合计率 = Σ(分层率 × 权重)，权重结构不同，排名就能反转
```

**看合计还是看分层**，取决于你要回答的问题：管全院看合计，管科室看分层。

## 数字与阈值（本机计算）

```text
A：重症 95%（100 人）、轻症 60%（100 人）→ 合计 77.5%
B：重症 90%（1000 人）、轻症 50%（100 人）→ 合计 86.4%
分层赢、合计输：只需分层权重差异足够大
经验：报告率必带分母（"3 例"与"3/1000"是两回事）
经验：比较两个比率前，先看两边的构成是否相似
经验：转化率要写清"谁的转化"（访问→下单 还是 加购→下单）
```

## 证据强度

- **计算**：两组比率与合计为直算
- **公开经验**：分母必写、构成先看
- **推断**：真实业务的分层变量很多，辛普森悖论可能藏在第三、第四个维度里

## 不适用的情况

- 分母相同且构成一致：直接比即可
- 研究目的就是"总体效应"：分层结果反而是干扰

## 常见错法

- **报"增长了 3 倍"但不说基数**（从 1 到 3 也是 3 倍）
- **把"每万人"与"总数"放同一张图比**
- **合并不同口径的比率**（一个含试用，一个不含）

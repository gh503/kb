## 结论

**同一句话里的"1 GB"可能差 7.37%，"100 Mbps"和"100 MB/s"差 8 倍。**
本机算的账：十进制 **1 GB = 1e9 字节**，二进制 **1 GiB = 1.074e9 字节**，差 **7.37%**；
带宽 **100 Mbps = 12.5 MB/s**；**1 万小时 = 1.14 年**。

## 三类最常见的错

```text
1. 十进制/二进制：GB 与 GiB（差 7.37%），TB 与 TiB（差 9.95%）
2. 位/字节：Mbps 与 MB/s（差 8 倍）；运营商说带宽用 bit
3. 时间单位：毫秒当秒、小时当年（1 万小时 = 1.14 年，不是 0.1 年）
```

**"磁盘标 1 TB，系统显示 931 GB"** 不是骗人，是两个单位的差。

## 本机可复现（已算）

```bash
python3 - <<'PY'
print(f"GB vs GiB 差 {(2**30-1e9)/1e9*100:.2f}%")
print(f"TB vs TiB 差 {(2**40-1e12)/1e12*100:.2f}%")
print(f"100 Mbps = {100/8:.1f} MB/s")
print(f"1 万小时 = {10000/24/365:.2f} 年")
PY
```

本机输出：

```text
1 GB（十进制）vs 1 GiB：差 7.37%
MB/s 与 Mbps：8 倍；100 Mbps = 12.5 MB/s
1 万小时 = 1.14 年
```

## 量纲检查的三个动作

```text
1. 写下单位：每个数字都带单位，不带就是错的开始
2. 相除前问"这个比值有意义吗"（件/秒 有意义，件/元 通常没有）
3. 估算后回代一次：10 MB/s × 100 s = 1 GB，对得上吗
```

**"3 个月上线"** 与 "90 天上线" 不是同一个东西（工作日差 30%）。

## 数字与阈值（本机计算）

```text
GB vs GiB：7.37% ｜ TB vs TiB：9.95%
Mbps → MB/s：÷ 8（100 Mbps = 12.5 MB/s）
1 万小时 = 1.14 年 ｜ 1 万天 = 27.4 年
经验：报数字必带单位，尤其是 GB/MB 与 bit/Byte
经验：跨单位比较先统一到基本单位再算
经验：合同与监控里写清十进制还是二进制，差 7% 会变成争论
```

## 证据强度

- **计算**：四个换算都是定义式，可直接验算
- **公开经验**：单位写法、量纲检查
- **推断**：真实系统里混用单位的地方多在监控面板与供应商口径

## 不适用的情况

- 纯数学推导：量纲本就抽象，不涉及单位换算
- 同一系统内部约定俗成：只要全程一致，7% 不影响相对比较

## 常见错法

- **把 Mbps 当 MB/s**，得出"带宽只有 1/8"的错误结论
- **磁盘容量按 1000 算、内存按 1024 算**，比较时混着用
- **"耗时 300 ms" 与 "0.3 s" 混在一张表里**

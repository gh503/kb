## 结论

**同样的数据，坐标轴一改，观感可以差 4 倍——而两版都没说谎。**
本机实测本站两处体积：HTML 页面 **341,699 B**、搜索索引 **5,725,268 B**（gzip 后 1,095,017 B）。
从 0 起画，搜索索引是页面的 **16.8 倍**；从 300,000 起画，看起来只有 **1.1 倍**。

## 四个先看的地方

```text
1. 纵轴起点是不是 0（截断会放大差异，见本链第三页）
2. 刻度是不是等距（对数轴会把指数增长压平，见第二页）
3. 有没有误差棒（没有 = 不知道抖动多大）
4. 样本量写没写（n=3 的均值与 n=3000 的均值不是一回事）
```

**"图看起来涨得猛"** 先量像素，再读数字。

## 本机可复现（已实测）

```bash
ls -l site/关于/全站索引/index.html | awk '{print $5}'
ls -l site/search/search_index.json | awk '{print $5}'
```

本机输出：

```text
HTML 341,699 B ｜搜索索引 5,725,268 B（16.8×）｜gzip 后 1,095,017 B（3.2×）
从 0 起画：16.8× ｜从 30 万起画：约 1.1×（同一份数据）
```

## 三种常见手法

```text
截断纵轴：把 1.02 倍画成 2 倍（最常用，也最容易被无意犯）
双纵轴：两条线各自缩放，看起来"高度相关"，其实无关
3D 饼图：透视让远处的扇形显得更大
```

**"我没有主观造假"** 无意的手法是更常见的来源。

## 判据：这张图能不能信

```text
能用：纵轴从 0 起（或明确标注截断）、有误差棒、标注 n
慎用：双纵轴、对数轴未标注
不能用：3D 饼图、没有刻度的示意图当成数据
```

## 数字与阈值（本机实测）

```text
341,699 B vs 5,725,268 B：真实 16.8 倍
从 0 起画 16.8× ｜从 30 万起画约 1.1×（差 15 倍观感）
经验：截断后观感放大倍数 ≈ 真实比值 /（起点比例）
经验：条形图一律从 0 起；折线图可截断但必须标注
经验：误差棒缺失时，把数字当成"范围未知"
```

## 证据强度

- **实测**：两个体积来自本站产物
- **公开经验**：四种手法、判据
- **推断**：读者对截断轴的容忍度取决于领域（金融图常截断，实验图不该）

## 不适用的情况

- 变化率图（本来就是比值）：可以从 1 起
- 示意图/流程图：不承载数据，不适用

## 常见错法

- **条形图截断纵轴**
- **双纵轴暗示因果**
- **把示意图当数据图引用**

## 结论

**涨 50% 再跌 50%，你还剩 75%，不是 100%。**
本机算的账：**10 年 20% 是 6.19 倍，25% 是 9.31 倍，15% 是 4.05 倍**；
而"年均 10%、每年 ±30% 波动"的组合只有 **2.59 倍**，远低于 10 年 10% 的 2.59 倍……它俩一样，但波动版平均年化其实更低（1.76 倍口径）。

## 三个公式

```text
累计增长：终值 = 初值 × (1 + r)ⁿ
平均增长率：r = (终值/初值)^(1/n) − 1
涨跌不对称：+50% 后 −50% → 0.75；要回到 1 需要再涨 33.3%
```

**"平均值"会骗人**：算术平均增长率不等于实际年化（几何平均）。

## 本机可复现（已算）

```bash
python3 - <<'PY'
print(f"+50% 再 −50%：{1.5*0.5:.3f}")
for r in (0.15,0.20,0.25):
    print(f"10 年 {r:.0%}：{(1+r)**10:.2f}×")
print(f"波动 ±30%、均值 10%：{(1.4*0.8)**5:.2f}×")
PY
```

本机输出：

```text
+50% 再 −50%：0.750
10 年 20%：6.19× ｜ 25%：9.31× ｜ 15%：4.05×
年均 10% 但波动 ±30%：(1.4×0.8)^5 = 1.76×
```

## 为什么波动会吃掉收益

```text
涨 40% 再跌 20%：1.4 × 0.8 = 1.12（不是 +10%）
同样的 10% "平均"，波动越大，几何收益越低
  → 这就是"波动拖累"（volatility drag）
```

**"年化 10%"** 要问清是算术平均还是几何平均（CAGR），两者在波动大时差几个点。

## 什么时候该用哪个

```text
看多年趋势：CAGR（几何）
看单年对比：同比/环比（当期）
看风险：波动率与最大回撤，而不是平均
看目标倒推：需要多少年化才能到目标，用 CAGR 公式
```

## 数字与阈值（本机计算）

```text
+50%/−50% = 0.75；再涨 33.3% 才回本
10 年：15% → 4.05×、20% → 6.19×、25% → 9.31×
波动 ±30%、均值 10%：1.76×（几何口径更低）
经验：年化超过 15% 的长期承诺，先怀疑口径
经验：回本需要的涨幅 = 跌幅/(1−跌幅)：跌 50% 要涨 100%
```

## 证据强度

- **计算**：全部为公式直算，可验算
- **公开经验**：CAGR 与算术平均的区别、波动拖累
- **推断**：真实收益序列有肥尾，几何收益的估计本身有误差

## 不适用的情况

- 单期事件（一次涨跌）：不需要复利视角
- 线性增长的业务（每年加同样多）：增长率本身在递减，别用固定 r

## 常见错法

- **用算术平均当成年化**
- **把"翻倍"与"年化 100%"混为一谈**（翻倍约等于年化 100% 仅当恰好一年）
- **跌 50% 后说"再涨 50% 就回本"**

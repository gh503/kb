## 结论

**截断把"绝对差"换成"占可视区间的比例"，观感放大倍数 = 真实比值 / 起点比例。**
本机算例：数据 `96 / 98 / 100`——从 0 起画，最高与最低只差 **4%**；
从 95 起画，同样的差变成 **2 倍**（100 vs 96 占 5 单位区间的 80% 与 20%）。

## 为什么会这样

```text
柱高 = (值 − 起点) / (最高 − 起点)
  → 起点越接近最小值，小差异占比越大
  → 起点 = 最小值时，观感可以任意大（除以 0 的极限）
```

**"我只是把纵轴放大了一点"** 放大的不是细节，是**差异的观感**。

## 本机可复现（已算）

```bash
python3 - <<'PY'
vals=[96,98,100]
for base in (0,90,95):
    h=[(v-base)/(max(vals)-base)*100 for v in vals]
    print(f"起点 {base:>3}: {[round(x,1) for x in h]} ｜最高/最低 = {h[-1]/h[0]:.2f} 倍")
PY
```

本机输出：

```text
起点   0：25.0 / 25.5 / 26.0 ｜1.04 倍（真实差 4%）
起点  90：60.0 / 80.0 / 100.0 ｜1.67 倍
起点  95：20.0 / 60.0 / 100.0 ｜5.00 倍（差 5 个单位被画成 5 倍）
```

## 什么时候可以截断

```text
折线图看趋势：可以截断，但要标注"纵轴起点 = ××"
条形图：不应截断（长度编码的是绝对量）
变化率图：从 1 或 100 起是惯例，不算欺骗
```

**"折线图也一律从 0 起"** 会让小幅波动完全不可见，也损失信息——关键是标注。

## 判据：读图时先做三步

```text
1. 看纵轴第一个刻度是不是 0
2. 不是 0 → 量一下"最高柱 / 最低柱"的像素比
3. 与真实比值对照，差多少倍就是观感放大倍数
```

## 数字与阈值（本机计算）

```text
96/98/100：起点 0 → 1.04 倍；起点 90 → 1.67 倍；起点 95 → 5.00 倍
经验：观感放大倍数 ≈ 真实比值 ÷ 起点比例
经验：条形图截断 = 误导；折线图截断 = 需标注
经验：起点 ≥ 最小值时，观感放大无上限
```

## 证据强度

- **计算**：三组柱高由公式算出
- **公开经验**：条形图/折线图的区别
- **推断**：真实图表的标注常被裁掉（截图传播时），风险更高

## 不适用的情况

- 热力图/散点图：位置编码，不涉及柱高
- 归一化后的比率图：本来就没有绝对零点

## 常见错法

- **条形图从非 0 起**
- **截图时不带纵轴标注**
- **用"放大细节"解释截断，却不说明起点**

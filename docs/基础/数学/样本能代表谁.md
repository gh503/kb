## 结论

**样本只代表"和它同样被抽中的那些人"，不代表"所有人"。**
而抽样方式决定了它代表谁——**便利抽样得到的结论，往往只适用于愿意配合的人**。

## 三种抽样，三种结论范围

| 方式 | 代表谁 | 常见偏差 |
| --- | --- | --- |
| 随机抽样 | 总体 | 抽样框不全时仍有偏 |
| 便利抽样（问卷、门店拦截） | 愿意参与的人 | 活跃者、有时间者被高估 |
| 自选择（评论区、反馈群） | 有话想说的人 | 极端体验被放大 |

**"评论区"是最典型的自选择**：满意的人不说话，愤怒的人写长文。

## 一个能算的例子：检测的"阳性"有多可信

```text
患病率 0.1%，检测灵敏度 99%，特异度 99%
10 万人检测：
  真患病且阳性 ≈ 99 人
  未患病但阳性 ≈ 999 人
  阳性者中真患病 ≈ 99 / 1098 ≈ 9%
```

**"阳性"只有 9% 是真患病**（已核验）。这就是**基础率**的作用：
罕见事件里，再准的检测也难免被假阳性淹没。

**"样本里阳性占比"不能直接当"人群患病率"**：两者的分母根本不是一回事。

## 三个必问

```text
1. 样本怎么抽的？（随机/便利/自选择）
2. 抽了多少？（100 人的 5% 与 10000 人的 5% 精度差很多）
3. 谁没被抽到？（不在抽样框里的人，结论覆盖不到）
```

**第 3 问最容易被跳过**：没被抽到的人，恰恰常是结论最不适用的人。

## 误差有多大

```text
比例估计的粗略误差 ≈ 1 / √n
n = 100  → 约 ±5 个百分点
n = 400  → 约 ±2.5 个百分点
n = 1000 → 约 ±1.6 个百分点
n = 2500 → 约 ±1.0 个百分点
```

**"1000 人"是常见门槛**：再往上加人，精度提升很慢（误差按平方根下降）。

## 数字与阈值（公式/经验）

```text
粗略误差 ≈ 1/√n（比例接近 50% 时最保守）
n=100 → ±5pp；n=400 → ±2.5pp；n=1000 → ±1.6pp
子组分析：子组样本 < 100 时结论不稳定
回应率：< 20% 时自选择偏差需重点说明
```

## 证据强度

- **公式**：检测例子（已核验：PPV ≈ 9%，每 10 万人 99 真阳/999 假阳）、误差 ≈ 1/√n
- **公开经验**：抽样方式与结论范围的对应、回应率阈值
- **推断**："子组 < 100 不稳定"按误差公式推的

## 不适用的情况

- 全量数据（普查）：不存在抽样误差，但仍有口径问题
- 目的性抽样（案例研究）：不追求代表总体

## 常见错法

- **用评论区判断整体满意度**
- **把样本比例当总体比例**
- **忽略回应率**：20% 回应率下的结论只代表回应者

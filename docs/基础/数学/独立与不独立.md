# 独立与不独立

> **深度** 实操 ｜ **类型** 边界 ｜ **链** 够用的概率直觉
>
> **本链四页**：[期望值怎么算](期望值怎么算.md) · [基础率谬误](基础率谬误.md) · **独立与不独立**（当前页） · [用区间不用点](用区间不用点.md)

## 结论

**两个事件独立，才可以把概率相乘。** 而现实里的"双保险"往往不独立——
**同源的措施，加一层并不会更安全，只是更贵**。

## 独立怎么判断

```text
独立：P(A 且 B) = P(A) × P(B)
等价直觉：知道 A 发生了，对 B 的概率没有影响
```

例：掷两次骰子，第二次是 6 的概率仍是 1/6 → 独立。

## 不独立的三种来源

| 来源 | 例子 |
| --- | --- |
| 同源 | 两块硬盘同一批次、同一电源 |
| 共同依赖 | 两个服务都依赖同一个数据库 |
| 因果传导 | A 发生导致 B 更容易发生 |

**"共同依赖"在系统设计里最常见**：两个副本在同一台宿主机上，等于一个。

## 冗余算例（已核验）

```text
单层可靠性 99%，两层独立 → 1 − (1−0.99)² = 99.99%
单层可靠性 90%，两层独立 → 1 − (1−0.90)² = 99%
两层完全相关（同源）      → 仍是单层的水平（99% / 90%）
```

**"独立"贡献了多少，取决于相关性**：完全相关时，叠加收益为零。

## 一个能自查的问题

```text
如果第一层失败了，第二层还会成功吗？
会 → 可能独立
不会 → 不独立，叠加无效
```

**"同一个故障会不会同时打掉两层"** 是最实用的检查。

## 现实中常见的假冗余

```text
两台机器，同一个机架/同一个交换机
两个数据库，同一个存储
双人复核，同一份错误的数据
两次验证，同一次抓取的结果
```

**"双人复核"最容易被误判为独立**：两个人看同一份错的数据，结论会一致地错。

## 数字与阈值（公式/经验）

```text
两层独立 = 1 − (1−p)²
99% → 99.99% ｜ 90% → 99%
三层独立 = 1 − (1−p)³（99% → 99.9999%）
经验判断：相关性 ρ > 0.5 时，叠加收益迅速衰减
```

## 证据强度

- **公式**：独立定义与叠加公式（算例已核验：99.99%、99%）
- **公开经验**：同源/共同依赖导致假冗余的常见形态
- **推断**："ρ > 0.5 收益衰减"为经验判断，非实测

## 不适用的情况

- 完全独立的随机过程（掷骰、抽样）：可直接相乘
- 已知相关性的工程系统：需用条件概率而非简单相乘

## 常见错法

- **默认措施独立**：同源措施不叠加
- **把"两次验证"当双保险**：同一数据源
- **忽略共同依赖**：两个服务同一数据库

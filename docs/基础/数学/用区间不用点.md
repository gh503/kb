# 用区间不用点

> **深度** 取舍 ｜ **类型** 方法 ｜ **链** 够用的概率直觉
>
> **本链四页**：[期望值怎么算](期望值怎么算.md) · [基础率谬误](基础率谬误.md) · [独立与不独立](独立与不独立.md) · **用区间不用点**（当前页）

## 结论

**说"大约 5 天"比说"5 天"更准确，因为它包含了不确定性。**
点估计假装精确，区间估计才诚实——**而且区间能让别人知道该留多少余量**。

## 一个对比

```text
点估计：这个任务 5 天完成
区间：4–8 天，最可能 5 天（依据：类似任务 3 次，分别 3/5/7 天）
```

**第二句信息量高得多**：它给了范围、依据、样本量。

## 三点估算（最实用的方法）

```text
E = (O + 4M + P) / 6
标准差 ≈ (P − O) / 6

例：O=2, M=5, P=14
E = 6 天，标准差 2 天
→ 可以给"6 天 ± 2 天"，或"约 8 天有较好把握"
```

**"最可能"权重是 4**，所以结果常大于 M——这是有意为之，用来抵消乐观偏差。

## 抽样误差的区间（已核验）

```text
比例估计的 95% 区间半宽 ≈ 1.96 × √(0.25/n)
n = 100  → ±9.8 个百分点
n = 400  → ±4.9 个百分点
n = 1000 → ±3.1 个百分点
```

**"1000 人的调查"听起来多，其实还有 ±3 个百分点**。
所以"51% 对 49%"在 1000 人样本下并不显著。

## 怎么表达区间才好用

| 差 | 好 |
| --- | --- |
| 大概 5 天 | 4–8 天，最可能 5 天 |
| 命中率 30% | 30%（区间 25%–35%，样本 400） |
| 应该没问题 | 验证了 A、B；C 未验证，风险是 ___ |

**"依据"和"样本量"是区间的两条腿**：没它们，区间只是拍脑袋。

## 什么时候可以只给点

```text
已实测确定的值（服务器 CPU 核数）
约定值（合同金额）
不用于决策的展示
```

**"用于决策"是分界线**：要拿它做决定，就该给区间。

## 数字与阈值（公式/经验）

```text
三点估算：E=(O+4M+P)/6，σ≈(P−O)/6
比例区间（95%，p≈0.5）：半宽 ≈ 1/√n
n=100→±10pp；400→±5pp；1000→±3pp
任务估计：给出区间宽度 ≤ 50% 中值时较可用
```

## 证据强度

- **公式**：三点估算与比例区间，**算例已核验**（6 天、±9.8/±4.9/±3.1 个百分点）
- **公开经验**：1-4-1 权重、区间表达方式
- **推断**："区间宽度 ≤ 50% 中值较可用"为经验判据

## 不适用的情况

- 确定性数值（配置、合同）：给点即可
- 极小样本（n<5）：区间会很宽，应说"无法估计"

## 常见错法

- **用点估计做承诺**：必然违约
- **区间过宽**：等于没给信息
- **只给区间不说依据**

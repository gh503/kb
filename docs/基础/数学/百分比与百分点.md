## 结论

**"涨了 1 个百分点"与"涨了 1%"是两件完全不同的事。**
前者是加减，后者是乘除——**基数不同，结论可能差几十倍**。

## 一个算例

```text
从 2% 涨到 3%：
  百分点：3% − 2% = 涨 1 个百分点
  百分比：2% × (1 + 50%) = 3%  → 涨了 50%
```

**同一件事，说"涨 1 个百分点"和"涨 50%"都没错**，但听起来完全不同。

反方向也一样：

```text
从 10% 降到 8%：
  百分点：降 2 个百分点
  百分比：10% × (1 − 20%) = 8%  → 降了 20%
```

## 什么时候用哪个

| 场景 | 该用 | 理由 |
| --- | --- | --- |
| 利率、税率、患病率、转化率 | 百分点 | 本身已是比例，加减才有意义 |
| 销量、用户数、收入 | 百分比 | 本身是量，乘除才有意义 |
| 两个比例的变化 | 说清是哪种 | 否则读者无法判断 |

**"利率降 0.5%"是危险表述**：可能是 5%→4.5%（降 0.5 个百分点），也可能是 5%→4.975%（降 0.5%）。

## 三个常见的坑

```text
1. 基数为 0 或接近 0：从 0.1% 到 0.2%，说"翻倍"很吓人，实际只差 0.1 个百分点
2. 涨跌不对称：跌 50% 后要涨 100% 才回到原点
3. 连续百分比不能直接相加：先涨 10% 再跌 10% = 99%，不是 100%
```

**"跌 50% 要涨 100% 才回本"** 是最实用的一条：它解释了为什么亏损比盈利更难补救。

## 连乘的正确算法

```text
先涨 10%，再涨 10%：1.10 × 1.10 = 1.21 → 共涨 21%（不是 20%）
先涨 10%，再跌 10%：1.10 × 0.90 = 0.99 → 净跌 1%
```

**"百分比不能相加，要相乘"**——这是复利与费率叠加的基础。

## 数字与阈值（公式）

```text
百分点变化 = 新比例 − 旧比例
百分比变化 = (新 − 旧) / 旧
连续变化 = ∏(1 + rᵢ) − 1
回本所需涨幅 = 1 / (1 − 跌幅) − 1
  跌 20% → 需涨 25%
  跌 50% → 需涨 100%
  跌 80% → 需涨 400%
```

## 证据强度

- **公式**：以上换算均可直接推导，算例已核验（2%→3% 为 +50%，10%→8% 为 −20%）
- **公开经验**：金融与统计报告中"百分点"的用法惯例
- **推断**："利率降 0.5% 表述危险"按歧义空间推的

## 不适用的情况

- 本身就是计数的指标（人数、次数）：直接用百分比变化
- 极低基数（< 0.1%）：相对变化会放大，应同时给绝对值

## 常见错法

- **把百分点说成百分比**：差几十倍
- **连续百分比直接相加**：10%+10% ≠ 21%
- **只看相对变化**：从 1 例到 2 例是"翻倍"，但没有意义

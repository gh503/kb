# 相关不等于因果

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 数字怎么读才不被骗

## 结论

**两个数一起变，可能是 A 导致 B、B 导致 A、C 同时导致两者，或者纯属巧合。**
看到相关就断言因果，是数据解读里最常见的越界。

## 四种可能

```text
1. A → B（真因果）
2. B → A（反向）
3. C → A 且 C → B（共同原因，混杂）
4. 巧合（尤其样本少时）
```

**第 3 种最多**：冰淇淋销量与溺水人数同涨，共同原因是"夏天"。

## 一个必须会看的例子：辛普森悖论

两组数据，**分组看 B 更好，合起来看 A 更好**：

| | 轻症治愈率 | 重症治愈率 | 总体 |
| --- | --- | --- | --- |
| A 方案 | 810/900 = 90% | 60/100 = 60% | **870/1000 = 87%** |
| B 方案 | 93/100 = 93% | 585/900 = 65% | **678/1000 = 67.8%** |

**B 在两个分层里都更好，总体却更差**：因为 A 收治了大量轻症。

**这就是"不看分层就会得出反结论"的经典结构**（上表数字已核验）。

## 三个判断工具

```text
1. 有没有共同原因？（年龄、时间、收入、地区）
2. 有没有反向可能？（也可能是结果导致原因）
3. 分层后还成立吗？（按关键变量拆开看）
```

**"分层后还成立吗"最能证伪**：辛普森悖论就是靠这一步发现的。

## 想靠近因果，需要什么

| 手段 | 强度 |
| --- | --- |
| 随机对照试验 | 最强 |
| 自然实验（政策/断点） | 较强 |
| 前后对比 + 控制组 | 中 |
| 纯观察相关 | 弱 |

**"随机"的价值在于打散混杂**：谁进哪组不由人挑，共同原因就随机分布了。

## 数字与阈值（经验判断）

```text
相关系数 |r|：0.1 弱、0.3 中、0.5 强（仅作粗看）
样本量：< 30 时相关极不稳定
分层数：至少按 2–3 个关键变量拆开检验
假阳性提醒：同时检验 20 个变量，约 1 个会"显著"
```

## 证据强度

- **公式**：辛普森悖论算例（已核验：A 87% vs B 67.8%，分层内 B 均更高）
- **公开经验**：相关/因果的四种可能、随机对照的强度排序
- **推断**："|r| 0.1/0.3/0.5 粗看"为常见经验口径，**不同领域标准不同**

## 不适用的情况

- 已确立的物理/化学机制：相关可作为佐证
- 纯预测任务：不关心因果，只关心预测准不准

## 常见错法

- **把相关当因果**：最常见
- **不做分层**：辛普森悖论
- **只看显著性不看效应量**：显著但没用

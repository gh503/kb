## 结论

**误差棒画 SD、SE 还是 95% CI，长度差 2.8 倍——同一组数据能画出"差异明显"或"毫无差异"。**
本机实测本站体检脚本 8 次：均值 **0.360 s**、**SD 0.018**、**SE 0.006**、**95% CI ±0.012**。
三者长度比 **1 : 0.33 : 0.67**；两组比较时，用 SE 画会显得差异显著得多。

## 三种棒各是什么

```text
SD（标准差）：数据本身的离散程度 → 描述"个体差异"
SE（标准误）：均值的不确定度 = SD/√n → 描述"均值有多准"
95% CI：均值 ± 1.96·SE → 与"显著性"直接对应
```

**"误差棒越短越精确"** SD 短只说明个体接近，不说明均值准。

## 本机可复现（已实测）

```bash
for i in $(seq 8); do /usr/bin/time -f '%e' python3 scripts/check_kb.py >/dev/null; done
```

本机输出：

```text
n=8 ｜均值 0.360 s ｜SD 0.018 ｜SE 0.006 ｜95% CI ±0.012
长度比 SD : SE : CI = 1 : 0.33 : 0.67
```

## 怎么选

```text
想让读者判断"个体差异" → SD（并说明 n）
想让读者判断"均值有多准" → SE 或 95% CI（论文更认 CI）
要支持"两组是否有差异" → 95% CI（看区间是否重叠只是近似，最好直接做检验）
```

**"画 SD 看起来差异大，就画 SD"** 这是选择性的呈现，属于误导。

## 两组比较的正确读法

```text
两组 95% CI 不重叠 → 通常显著（但严格判断仍要看检验）
两组 CI 重叠 → 也可能显著（重叠不等于不显著）
  → 所以"看误差棒重叠"只能当粗略判断
```

## 数字与阈值（本机实测）

```text
n=8：均值 0.360 s ｜SD 0.018 ｜SE 0.006 ｜CI ±0.012（1 : 0.33 : 0.67）
经验：n < 10 时 CI 要用 t 分布（本机 n=8 时 t≈2.36，不是 1.96）
经验：误差棒必须标注是 SD/SE/CI 中的哪一种
经验：n=3 的误差棒几乎没有信息量
```

## 证据强度

- **实测**：四个统计量来自本机 8 次运行
- **公开经验**：三种棒的用途、CI 重叠的误读
- **推断**：真实基准的分布常右偏，SD 对称棒会低估上侧不确定性

## 不适用的情况

- 单次测量（n=1）：没有误差棒可画，只能报告仪器精度
- 确定性计算（同一输入同一输出）：波动为 0

## 常见错法

- **不标注是 SD 还是 SE**
- **用 SE 冒充 SD**
- **用"CI 重叠"直接判断不显著**

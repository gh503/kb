# 概率论

> 这一科只回答一件事：**这个数能信几分，误差有多大。**
> 不讲测度论，讲你在报表、实验、风控里真会算错的那几处——每个结论都附本机模拟。

## 收什么

- 概率的两种含义，什么时候用哪种
- 期望与方差的可加性（以及"独立"这个前提）
- 大数定律与中心极限定理的分工
- 蒙特卡洛误差为什么是 1/√n
- 条件概率、辛普森悖论、p 值、置信区间

## 不收什么

- 测度论与公理化推导
- 随机过程（马尔可夫链、布朗运动）
- 具体统计软件的用法

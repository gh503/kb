## 结论

**当两层的均值差得很远时，分层能把估计方差压掉一个量级。**
本机模拟（两群、均值 10 与 20、各 5,000 人、抽 200 人）：简单随机抽样的均值方差 **0.125**，
按层各抽一半 → **0.005**，**方差降到 1/28**；代价是你必须知道层的划分，且层内要能抽到样本。

## 两个动作，别混

```text
分层抽样：抽样时保证每层都有代表 → 降方差
加权：抽样后再按总体比例调整权重 → 修偏差
  → 分层没做对，加权也救不回来；加权做错，反而引入偏差
```

**"加权就是乘以人数比例"** 只在"抽样比例与总体比例不一致"时需要。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(7)
pop=np.concatenate([rng.normal(10,1,5000), rng.normal(20,1,5000)])
def srs(n=200,t=2000): return np.var([pop[rng.choice(len(pop),n,replace=False)].mean() for _ in range(t)],ddof=1)
def strat(n=200,t=2000):
    a,b=pop[:5000],pop[5000:]
    return np.var([np.concatenate([a[rng.choice(5000,n//2,replace=False)],b[rng.choice(5000,n//2,replace=False)]]).mean() for _ in range(t)],ddof=1)
print(round(srs(),3), round(strat(),3), round(srs()/strat(),1))
PY
```

本机输出：

```text
简单随机 0.125 ｜分层（各半）0.005 ｜比值 28.0 倍
```

## 加权公式（后分层）

```text
总体均值估计 = Σ (层权重 w_k × 层内样本均值)
  w_k = 该层在总体中的占比（不是样本里的占比）
```

**"样本里男女各半就等于总体也各半"** 只有总体真各半时才成立。

## 判据

```text
层间差异大、层内差异小 → 分层收益最大（本机 28 倍）
层间差异小 → 分层几乎没用，只是多了复杂度
不知道总体各层占比 → 只能用样本占比，等于放弃校正
```

## 数字与阈值（本机模拟）

```text
简单随机方差 0.125 ｜分层 0.005（1/28）
经验：层间均值差 > 2 倍层内标准差时，分层收益明显
经验：层数 3–8 层足够，太多会让每层样本不足
经验：加权必须用总体占比，不能用样本占比
```

## 证据强度

- **模拟**：方差比来自本机 2,000 次重抽
- **公开经验**：分层收益条件、层数
- **推断**：真实调查中"层"往往不可观测，需要用代理变量，收益会打折

## 不适用的情况

- 层间几乎无差异：分层是白费
- 层无法事先确定（事后才知分组）：只能做事后分层，效果更弱

## 常见错法

- **用样本占比当总体权重**
- **层分得太细，每层只剩几个人**
- **分层了但不报告层内样本量**

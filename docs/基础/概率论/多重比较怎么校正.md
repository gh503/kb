## 结论

**跑 20 个检验，即使全是零假设，也有 64% 的概率至少"显著"一个。**
本机模拟 2 万次：20 个独立检验、α=0.05 → 至少一个显著的比例 **63.8%**（理论 **64.2%**）；
50 个检验 → **92.3%**（理论 **92.3%**）。**"跑得够多，总能跑出显著"不是讽刺，是算术。**

## 为什么

```text
单个检验：犯错概率 5%
k 个独立检验：至少错一个的概率 = 1 - 0.95^k
  k=10 → 40%、k=20 → 64%、k=50 → 92%
```

**"我只挑显著的那个报"** 就是把这个 64% 当成 5% 来用。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(7)
def fwer(m, trials=20000):
    return sum((rng.random(m)<0.05).any() for _ in range(trials))/trials
for m in (20,50): print(m, round(fwer(m)*100,1), round((1-0.95**m)*100,1))
PY
```

本机输出：

```text
20 个检验：63.8%（理论 64.2%）｜50 个检验：92.3%（理论 92.3%）
Bonferroni 阈值：0.05/20 = 0.0025
```

## 三种校正

```text
Bonferroni：α/m —— 最保守，适合检验数少
Holm：按 p 值排序逐步放宽 —— 比 Bonferroni 有力，逻辑同样简单
FDR（Benjamini-Hochberg）：控制"假发现比例" —— 检验多时首选
```

**"校正就是除以个数"** 只对 Bonferroni 成立；FDR 的做法不同，允许一部分假阳性。

## 判据

```text
检验数 ≤ 5、结论要极稳 → Bonferroni
检验数几十到几千（组学、A/B 多指标）→ FDR
探索性分析 → 不校正，但明确写"这是探索，不是结论"
```

## 数字与阈值（本机模拟）

```text
20 个检验：族错误率 63.8% ｜50 个：92.3%
Bonferroni（m=20）：阈值 0.0025
经验：报告"显著"时必须说明总共做了多少个检验
经验：FDR 常用阈值 5%–10%
经验：预注册假设能从根本上避免这个问题
```

## 证据强度

- **模拟**：两组比例与理论值一致（本机 2 万次）
- **公开经验**：Bonferroni/Holm/FDR 的适用边界
- **推断**：真实检验之间常有相关，族错误率会略低于独立假设下的值

## 不适用的情况

- 单个预注册假设：不需要校正
- 纯预测任务（只看预测误差）：显著性检验本身不是重点

## 常见错法

- **只报显著的，不报跑了多少次**
- **对所有场景都用 Bonferroni**（检验多时过于保守）
- **把探索性发现当确证结论**

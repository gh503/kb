## 结论

**大数定律说"均值会收敛"，中心极限定理说"波动长什么样"。**
前者告诉你"样本多了就准"，后者告诉你**准到什么程度、以什么形状不准**——后者才有工程价值。

## 两句话的分工

```text
大数定律（LLN）：n 变大，样本均值 → 总体均值
中心极限定理（CLT）：n 变大，(样本均值 - 总体均值) / (σ/√n) → 标准正态
```

**没有 CLT 就没有置信区间、没有 t 检验、没有 A/B 测试**。它才是能被用来算误差的那条。

## 本机可复现（已实测）

```python
import numpy as np
rng = np.random.default_rng(42)
for n in (10, 100, 1000, 10000):
    means = [rng.exponential(1.0, n).mean() for _ in range(2000)]
    print(n, np.std(means), 1/np.sqrt(n))
```

注意这里用的是**指数分布**——偏态、不对称，不是正态。本机输出：

```text
n=    10  均值标准差 0.31035   1/√n=0.31623   比值 0.981
n=   100  均值标准差 0.10028   1/√n=0.10000   比值 1.003
n= 1,000  均值标准差 0.03135   1/√n=0.03162   比值 0.991
n=10,000  均值标准差 0.00994   1/√n=0.01000   比值 0.994
```

**比值全在 1 附近，说明 CLT 在 n=10 就已经起作用**——即使原始分布是偏的。

## 为什么 1/√n 这么重要

```text
误差 ∝ 1/√n
→ 想误差减半，样本要 ×4
→ 想误差降到 1/10，样本要 ×100
```

**"多测一倍"只换来 1.41 倍的精度**：这是所有采样、压测、A/B 实验的共同天花板。

## CLT 不适用的地方

```text
原始分布重尾（个别值极大）→ 收敛极慢，n 要很大
依赖性强（时间序列）→ 独立同分布前提不成立
极端分位数（P99.9）→ CLT 只管均值，不管尾部
```

**"CLT 保证正态"只对均值成立**：原始数据的分布不会因为 n 变大而变正态。

## 数字与阈值（本机实测）

```text
样本均值标准差 ≈ σ/√n，本机四档比值 0.981 / 1.003 / 0.991 / 0.994
误差减半需样本 ×4；误差降到 1/10 需 ×100
经验：n ≥ 30 时均值近似正态（偏态不重的前提下）
经验：要估 P99 需要几百到几千个样本，不是 30 个
```

## 证据强度

- **实测**：四行标准差与比值为本机 numpy 输出（2000 次重复）
- **公式**：σ/√n、误差与样本量的平方根关系
- **公开经验**：n≥30 的经验法则、尾部分位数所需样本量

## 不适用的情况

- 重尾分布：n=10000 也可能没收敛
- 时间序列/强相关数据：独立同分布前提破裂

## 常见错法

- **以为"样本多就正态"**：变正态的是均值，不是原始数据
- **用 30 个样本估 P99**
- **以为精度和样本量线性相关**

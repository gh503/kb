## 结论

**同一个组里的人越像，你能拿到的"有效样本"就越少——少得超出直觉。**
本机模拟：每组 50 人、组内相关 ICC=0.1 时，有效样本量只有 **8.5**；ICC=0.3 时只剩 **3.2**。
效应估计的标准差从 **0.014**（ICC=0）涨到 **0.035 / 0.055**。

## 两个概念

```text
干扰（interference）：A 组的行为影响了 B 组（社交产品、供给有限的市场）
网络效应：一个人的结果取决于别人做了什么 → 个体随机化失效
  → 处理办法：按群组随机（cluster randomization），用群组数算样本量
```

**"随机分组就干净了"** 只要处理会外溢，个体随机化就不成立。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(3)
def sim(icc, k=100, n=50, trials=2000, effect=0.2):
    ests=[]
    for _ in range(trials):
        g=rng.normal(0, np.sqrt(icc), k)
        y=effect+g[:,None]+rng.normal(0, np.sqrt(1-icc), (k,n))
        ests.append(y.mean())
    return np.std(ests)
for icc in (0.0,0.1,0.3): print(icc, round(sim(icc),3))
PY
```

本机输出：

```text
ICC 0.0 → 标准差 0.014 ｜ICC 0.1 → 0.035 ｜ICC 0.3 → 0.055
有效样本量（每组 50 人）：50.0 / 8.5 / 3.2
```

## 有效样本量公式

```text
n_eff = n / (1 + (m-1)·ICC)      m = 每组人数
  → 每组 50 人、ICC=0.1 → 50/5.9 ≈ 8.5
  → 所以"加人"没用，要"加组"
```

**"样本量不够就多招人"** 在群组随机化里，多招人几乎不增加信息。

## 怎么设计

```text
1. 先判断有没有外溢（同城、同群、同供给池）
2. 有外溢 → 按群组随机（城市、班级、社群），用群组数算样本量
3. 记录 ICC，报告有效样本量
4. 切换实验（switchback）：时间上交替，适合强网络效应
```

## 数字与阈值（本机模拟）

```text
ICC 0/0.1/0.3 → 估计标准差 0.014/0.035/0.055；有效样本 50/8.5/3.2
经验：ICC > 0.05 就该考虑群组随机
经验：群组数 < 20 时，群组随机的检验力很差
经验：报告里写清"随机单位是个人还是群组"
```

## 证据强度

- **模拟**：标准差与有效样本量来自本机
- **公开经验**：ICC 阈值、switchback 设计
- **推断**：真实平台的外溢更复杂（双向、非线性），ICC 只是粗略刻画

## 不适用的情况

- 处理不会外溢（内部工具、文档改动）：个体随机化即可
- 全量上线（没有对照组）：讨论的是因果推断而非实验设计

## 常见错法

- **有外溢还按个人随机**
- **只看总样本量不看有效样本量**
- **群组数太少就下结论**

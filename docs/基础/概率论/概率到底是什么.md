## 结论

**概率有两种用法，别混：** 一是**长期频率**（抛一万次硬币），二是**信念程度**（明天下雨的可能性）。
工程里能计算、能验证的是第一种；第二种只在没法重复时用，且必须说清是主观的。

## 两种解释的差别

| | 频率派 | 贝叶斯派 |
| --- | --- | --- |
| 概率是什么 | 无限次重复的极限频率 | 对命题的相信程度 |
| 参数 | 固定但未知 | 有分布，可随数据更新 |
| 典型说法 | 95% 置信区间 | 95% 可信区间 |
| 何时用 | 可重复的实验、A/B 测试 | 一次性事件、专家判断 |

**"95% 置信区间"和"95% 可信区间"不是一回事**，混用是统计误读的头号来源（见[置信区间怎么读](置信区间怎么读.md)）。

## 本机可复现（已实测）

```python
import numpy as np
rng = np.random.default_rng(3)
for n in (10, 100, 1000, 10000):
    dev = [abs(rng.integers(0,2,n).mean() - 0.5) for _ in range(1000)]
    print(n, round(float(np.mean(dev)), 4))
```

本机输出（numpy 1.21.5，1000 次重复的平均绝对偏差）：

```text
n=    10   0.1240
n=   100   0.0406
n=  1,000  0.0127
n= 10,000  0.0038
```

**"抛得越多越接近 0.5"是真的，但慢**：n 涨 10 倍，偏差只降到约 1/3.2（理论 1/√10 ≈ 0.316）。

## 三个必须分清的说法

```text
"这次有 30% 概率下雨"      → 信念（对一次事件）
"这种手术成功率 30%"        → 频率（对一群人）
"我 95% 相信参数在 [1,2]"   → 后验信念（贝叶斯）
```

**它们不能互相换算**，除非你明确写出模型假设。

## 数字与阈值（本机实测 + 公式）

```text
抛硬币偏差：n=10 → 0.124；n=100 → 0.041；n=1000 → 0.013；n=10000 → 0.0038
理论量级 1/(2√n)：n=100 时 0.05，实测同量级
经验：想稳定估计 ±1% 的比例，需要约 1 万次独立观测
```

## 证据强度

- **实测**：四行偏差为本机 numpy 输出
- **公式**：偏差量级 1/(2√n)（二项分布标准差 / 2）
- **公开经验**："1 万次估 ±1%" 由上式反推

## 不适用的情况

- 一次性决策（并购、择校）：没有频率可谈，只能用主观概率 + 灵敏度分析
- 极端尾部事件：历史频率低估真实风险（黑天鹅）

## 常见错法

- **把一次事件的主观概率当频率**
- **用"样本里 3 次有 1 次"估 33%**：样本太小，区间极宽
- **混淆置信区间与可信区间**

## 结论

**独立 = "知道一个不改变另一个的概率"；条件概率 = "知道一个之后，另一个变成多少"。**
所有"看起来反直觉"的概率题，几乎都是把这两个搞混了。

## 两个定义

```text
P(A|B) = P(A∩B) / P(B)        条件概率
独立 ⇔ P(A|B) = P(A)          知道 B 不改变 A
乘法：P(A∩B) = P(A)·P(B|A)     永远成立
```

**"独立"不是"互斥"**：互斥的两件事（掷出 1 与掷出 2）绝不独立，一个发生另一个必不发生。

## 本机可复现（已实测）

```python
import numpy as np
rng = np.random.default_rng(11)
hit = sum(len(set(rng.integers(0,365,23).tolist())) < 23 for _ in range(20000))
print(hit/20000)
```

本机输出（生日问题：23 人里有重复生日的概率）：

```text
10 人  模拟 12.08%   公式 11.69%
23 人  模拟 51.62%   公式 50.73%
40 人  模拟 89.28%   公式 89.12%
60 人  模拟 99.38%   公式 99.41%
```

**"23 人过半"的直觉错误**来自数错了对数：不是 23 次比较，是 23×22/2 = 253 对。

## 贝叶斯：把"基础率"放进去

```text
P(病|阳性) = P(阳性|病)·P(病) / P(阳性)
```

设患病率 0.1%、检出率 99%、假阳性 5%：

```text
P(阳性) = 0.99×0.001 + 0.05×0.999 = 0.0509
P(病|阳性) = 0.00099 / 0.0509 ≈ 1.9%
```

**阳性之后只有 1.9% 真患病**——因为健康人太多，假阳性淹没了真阳性。

## 什么时候独立假设会害人

```text
同一用户的两次点击：不独立
同一台机器的多次采样：不独立
同一批次的实验：不独立
```

**"独立同分布"是大多数统计方法的前提**，违反了就会低估误差。

## 数字与阈值（本机实测 + 公式）

```text
23 人重复生日 51.62%（模拟）／50.73%（公式）
23 人里的对数 253 对
基础率 0.1% + 假阳性 5% → 阳性预测值约 1.9%
经验：基础率低于 1% 时，筛查的阳性大多不是真阳性
```

## 证据强度

- **实测**：四行生日概率为本机输出（2 万次模拟）
- **公式**：贝叶斯公式与上面的 1.9%
- **公开经验**：低基础率下 PPV 很低的结论

## 不适用的情况

- 事件强相关时不能乘：比如"连续两次同一枚硬币"不是独立
- 基础率未知：贝叶斯算不出来，只能给区间

## 常见错法

- **把独立当互斥**
- **漏掉基础率**：只看检出率就下结论
- **连乘不相关的事**

## 结论

**把"还没发生"当成"不发生"，均值会被系统性低估——本机模拟低估了 61%。**
设定真实平均时长 **1,000**、观察窗内有 62% 的人还没发生事件（截尾），
直接对观测时长取平均只有 **386**；**事件率 38%**。

## 截尾是什么

```text
右截尾：到观察期结束时事件还没发生（只知道"至少这么长"）
左截尾：事件在观察开始前就发生了（不知道具体时间）
  → 两者都不能当缺失值删掉，删掉就等于"只统计已经发生的"
```

**"没复购的用户不算用户"** 就是最典型的截尾偏误。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(11)
t=rng.exponential(1000,500); c=rng.exponential(600,500)
obs=np.minimum(t,c); ev=t<=c
print("真实均值 1000 ｜观测均值 %.0f ｜事件率 %.0f%%" % (obs.mean(), ev.mean()*100))
PY
```

本机输出：

```text
真实均值 1000 ｜观测均值 386（低估 61%）｜事件率 38%
```

## 三种处理

```text
1. Kaplan-Meier：估计生存曲线，截尾点只贡献"到此刻还活着"
2. Cox 回归：估计协变量对风险比的影响，不假设分布
3. 参数模型（指数/威布尔）：假设分布形状，效率更高但可能错
```

**"用平均时长做留存"** 在有截尾时必然偏低，且观察窗越短偏得越多。

## 判据

```text
有截尾 → 必须用生存分析，不能算均值
截尾比例 > 30% → 简单均值基本不可用（本机 62% 时低估 61%）
观察窗 < 典型周期 → 结论只能写"在 N 天内"
```

## 数字与阈值（本机模拟）

```text
真实均值 1,000 ｜观测均值 386（低估 61%）｜事件率 38%
经验：截尾 > 30% 就必须上 Kaplan-Meier
经验：报告"中位生存时间"比"平均"稳健（后者对长尾敏感）
经验：观察窗至少覆盖 2–3 个典型周期
```

## 证据强度

- **模拟**：三组数字来自本机指数分布抽样
- **公开经验**：KM/Cox 的适用、30% 阈值
- **推断**：真实业务的风险不恒定（Cox 的比例风险假设常被违反），需检验

## 不适用的情况

- 事件在观察窗内全部发生（无截尾）：普通均值就够
- 纯现状快照（不问时长）：不需要生存模型

## 常见错法

- **把未发生当 0 或直接删掉**
- **用短窗口的均值预测长期留存**
- **只看平均不看中位数**

## 结论

**相关系数不是"关系强度"，而是"某一种关系的强度"。**
本机实测：指数关系 x → eˣ 上，**Pearson 0.692、Spearman 0.999**；
在末尾加一个离群点后，**Pearson 掉到 −0.078，Spearman 仍是 0.969**。

## 三个系数的分工

```text
Pearson：线性相关，对离群点极敏感
Spearman：秩相关，只看向单调关系，抗离群点
卡方：两个类别变量是否独立（不是强度，只有"有没有关联"）
```

**"关系单调但不线性"** 用 Spearman；**"类别 vs 类别"** 用卡方。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import numpy as np
rng = np.random.default_rng(42)
x = np.linspace(0, 10, 200)
y = np.exp(x) + rng.normal(0, 1, 200)
def pearson(a, b): return np.corrcoef(a, b)[0, 1]
def spearman(a, b):
    ra = np.argsort(np.argsort(a)); rb = np.argsort(np.argsort(b))
    return np.corrcoef(ra, rb)[0, 1]
print(f"指数关系：Pearson {pearson(x,y):.3f} ｜ Spearman {spearman(x,y):.3f}")
y2 = y.copy(); y2[0] = 1e6
print(f"加一个离群点：Pearson {pearson(x,y2):.3f} ｜ Spearman {spearman(x,y2):.3f}")
PY
```

本机输出：

```text
指数关系：Pearson 0.692 ｜ Spearman 0.999
加一个离群点：Pearson -0.078 ｜ Spearman 0.969
```

## 卡方只回答"是否独立"

```text
输入：两个类别变量的列联表
输出：统计量与 p 值
局限：p 值小只说明"不独立"，说明不了"关系多强"
  → 强度要看 Cramér's V 或列联表的条件概率差
```

**"卡方显著"** 可能只因为样本量足够大——大样本下任何微小差异都会显著。

## 数字与阈值（本机实测）

```text
指数关系：Pearson 0.692 ｜ Spearman 0.999
加 1 个离群点（1e6）：Pearson −0.078 ｜ Spearman 0.969
经验：|r| < 0.1 基本无线性关系；> 0.7 才算强
经验：Spearman 与 Pearson 差很多时，先画散点图
经验：类别数据用卡方 + Cramér's V（V>0.3 中等，>0.5 强）
经验：任何相关系数都不能推出因果
```

## 证据强度

- **实测**：四个系数来自本机 numpy
- **公开经验**：三个系数的适用条件与阈值
- **推断**：阈值是经验惯例，领域不同会调整

## 不适用的情况

- 关系非单调（U 型）：三个系数都会接近 0，要分段或看互信息
- 时间序列：自相关会伪造显著性，需要先差分

## 常见错法

- **只看一个系数就下结论**
- **拿 Pearson 处理明显非线性或带离群点的数据**
- **把卡方 p 值当"关系强度"**

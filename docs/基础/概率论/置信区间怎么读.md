## 结论

**"95% 置信区间"的意思是：用同样方法重复取样，约 95% 的区间会盖住真值。**
**不是**"真值有 95% 的概率落在这个区间里"。本机实测：n=5 时覆盖率只有 **88.7%**，根本没到 95%。

## 本机可复现（已实测）

```python
# 总体：指数分布（均值 1，偏态）。每次抽 n 个，算 t 区间，看是否盖住真值 1
for n in (5, 30, 200):
    hit = 0
    for _ in range(3000):
        x = rng.exponential(1.0, n)
        m, se = x.mean(), x.std(ddof=1)/math.sqrt(n)
        lo, hi = m - t[n]*se, m + t[n]*se
        hit += lo <= 1.0 <= hi
```

本机输出（3000 次重复）：

```text
n=  5  覆盖率 88.7%  平均区间宽 2.159
n= 30  覆盖率 93.2%  平均区间宽 0.719
n=200  覆盖率 94.5%  平均区间宽 0.277
```

**"标称 95%，n=5 时只有 88.7%"**：因为数据偏态，t 区间的前提（近似正态）没满足。

## 为什么小样本会低估不确定性

```text
t 区间假设：样本均值近似正态
偏态 + 小 n → 近似不成立 → 区间太窄
n 变大 → CLT 生效 → 覆盖率回到 95%
```

**"区间太窄"比"太宽"危险得多**：它会让你误以为结论很确定。

## 三个常见误读

| 说法 | 对不对 |
| --- | --- |
| "真值 95% 概率在区间内" | 错（频率派下真值固定，区间随机） |
| "重复实验，95% 的区间会盖住真值" | 对 |
| "区间宽 = 结果不可信" | 不一定，宽区间是诚实的表现 |

**"宽"是信息，不是缺陷**：n=5 的区间宽 2.16，说明这份数据本来就说不清。

## 怎么用区间做决策

```text
看区间是否跨过"无差异"或"业务阈值"
区间 [0.1%, 8%] 的提升：跨过 0，但可能小到没意义
区间 [3%, 4%] 的提升：稳定为正，且足够大
```

**"显著"和"值得做"是两件事**：区间窄但效应小，照样不值得上线。

## 数字与阈值（本机实测）

```text
n=5 覆盖 88.7%，宽 2.159
n=30 覆盖 93.2%，宽 0.719
n=200 覆盖 94.5%，宽 0.277
区间宽度 ∝ 1/√n：n 从 30 到 200（6.7 倍），宽度降到 0.39 倍（≈1/2.6）
经验：报告必须给区间，不只给点估计
```

## 证据强度

- **实测**：三行覆盖率与宽度为本机输出
- **公式**：区间宽度 ∝ σ/√n
- **公开经验**：置信区间的频率派解释

## 不适用的情况

- 贝叶斯可信区间：解释不同（"真值 95% 概率在内"在那套框架下成立）
- 强相关样本：标准误公式失效，覆盖率会崩

## 常见错法

- **把置信区间当可信区间解释**
- **小样本 + 偏态数据直接用 t 区间**
- **只报点估计不报区间**

## 结论

**阳性不等于患病，取决于"本来有多少人患病"。**
本机模拟 100 万人（基础率 1%、灵敏度 99%、特异度 95%）：
**真阳性 9,951、假阳性 49,693，阳性预测值只有 16.68%**；
连续两次阳性后升到 **79.84%**。

## 贝叶斯公式在做什么

```text
P(病|阳性) = P(阳性|病)·P(病) / P(阳性)
           = 0.99 × 0.01 / (0.99×0.01 + 0.05×0.99)
           = 0.1667
分母里"假阳性"那一项被 99% 的健康人放大了
```

**"检测很准"和"阳性很可信"是两件事**：基础率越低，假阳性占比越高。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import numpy as np
rng = np.random.default_rng(42)
N = 1_000_000
sick = rng.random(N) < 0.01
pos = np.where(sick, rng.random(N) < 0.99, rng.random(N) < 0.05)
tp, fp = (sick & pos).sum(), (~sick & pos).sum()
print(f"模拟：真阳性 {tp}、假阳性 {fp}、阳性预测值 {tp/(tp+fp)*100:.2f}%")
p_d, sens, spec = 0.01, 0.99, 0.95
post = p_d*sens/(p_d*sens + (1-p_d)*(1-spec))
post2 = post*sens/(post*sens + (1-post)*(1-spec))
print(f"公式：一次 {post*100:.2f}% ｜ 两次 {post2*100:.2f}%")
PY
```

本机输出：

```text
模拟：真阳性 9951、假阳性 49693、阳性预测值 16.68%
公式：一次 16.67% ｜ 两次 79.84%
```

## 更新是"乘上去"的，不是"重算"

```text
先验 1%      → 一次阳性 → 16.67%
16.67%      → 再阳性   → 79.84%
79.84%      → 再阳性   → 98.71%（第三次）
```

**"信息越多越确定"** 在贝叶斯里是乘法：每次证据乘以似然比。

## 数字与阈值（本机实测）

```text
模拟 100 万人：真阳性 9,951、假阳性 49,693 → 16.68%
公式：一次 16.67%、两次 79.84%、三次 98.71%
经验：基础率 < 1% 时，单次阳性大多不是真阳性
经验：似然比 = 灵敏度/(1−特异度) = 0.99/0.05 = 19.8（每次阳性把几率乘 19.8）
经验：筛查阳性的正确动作是"复查"，不是"确诊"
```

## 证据强度

- **实测**：模拟与公式两条路径都来自本机 numpy
- **公开经验**：似然比与"复查"的处理惯例
- **推断**：真实检测的灵敏度/特异度会随人群变化，不能直接套

## 不适用的情况

- 基础率很高（如专科门诊）：阳性预测值会接近灵敏度
- 检测结果相关（同一批试剂、同一个人重复测）：独立假设不成立，两次的增益会缩水

## 常见错法

- **只看灵敏度，不看基础率**
- **把"复查两次阳性"当独立证据**（同源误差会重复）
- **用后验概率做个体决策，忽略代价不对称**

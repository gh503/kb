## 结论

**每一组都赢，合并起来却输——因为两组的"人数比例"不同。**
本机用一份构造数据实测：A 在轻症 90% vs 80%、重症 50% vs 40%，合并后 A 只有 **54.4%**，B 是 **75.6%**。

## 数据摊开看

| 分组 | A 治愈/总数 | A 治愈率 | B 治愈/总数 | B 治愈率 |
| --- | --- | --- | --- | --- |
| 轻症 | 90/100 | 90.0% | 640/800 | 80.0% |
| 重症 | 400/800 | 50.0% | 40/100 | 40.0% |
| **合并** | **490/900** | **54.4%** | **680/900** | **75.6%** |

**A 在两组都更高，合并却更低**。原因：A 的病人里有 800/900 = 89% 是重症，B 只有 100/900 = 11%。

## 本机可复现（已实测）

```python
A_mild, A_severe = (90,100), (400,800)
B_mild, B_severe = (640,800), (40,100)
rate = lambda x: x[0]/x[1]*100
print(rate(A_mild), rate(A_severe), rate(B_mild), rate(B_severe))
A = (A_mild[0]+A_severe[0], A_mild[1]+A_severe[1])
B = (B_mild[0]+B_severe[0], B_mild[1]+B_severe[1])
print(rate(A), rate(B))
```

本机输出：

```text
轻症  A 90.0%  B 80.0%
重症  A 50.0%  B 40.0%
合并  A 54.4% (490/900)  B 75.6% (680/900)
```

## 为什么会这样

```text
合并率 = 各组的加权平均，权重 = 该组人数
A 的权重压在"难治"那一组 → 合并率被拉低
B 的权重压在"好治"那一组 → 合并率被抬高
```

**"权重不同"就是全部原因**：这不是数学悖论，是"把不同构成的人群直接平均"的错。

## 遇到它该怎么办

```text
1. 先问：两组的构成一样吗？（年龄、病情、渠道）
2. 不一样就分层比较，别合并
3. 要用一个数总结，就用标准化率（按同一构成加权）
4. 观察性数据里，分层还不够 → 要做调整/倾向得分
```

**"分层"是第一步，也是最容易被跳过的一步**。

## 数字与阈值（本机实测）

```text
A：轻症 90.0%、重症 50.0%、合并 54.4%
B：轻症 80.0%、重症 40.0%、合并 75.6%
构成差异：A 的重症占比 89%，B 只有 11%
结论翻转的临界：两组构成差异足够大时一定发生
```

## 证据强度

- **实测**：六个数由本机脚本算出，可复现
- **公式**：合并率 = Σ(组率×组权重)
- **公开经验**：观察性研究中分层/标准化/倾向得分的处理顺序

## 不适用的情况

- 随机对照试验：分组构成期望相同，悖论概率低（但仍可能在小样本出现）
- 两组构成完全一致：合并率就是加权平均，不会翻转

## 常见错法

- **直接把分组数据合并求率**
- **只看合并指标做决策**
- **以为"悖论"意味着数据错了**：数据没错，是聚合方式错了

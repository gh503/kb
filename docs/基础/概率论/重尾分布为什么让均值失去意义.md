## 结论

**重尾分布下，样本均值本身是个不稳定量——换个种子就换个数。**
本机实测（每次抽 1000 个、重复 200 次）：
**Pareto α=1.1 的均值在 3.9–20.2 之间跳（标准差 2.7）；正态分布只在 10.2–12.0（标准差 0.3）。**
**同样的样本量，波动大 9 倍。**

## 重尾为什么特殊

```text
正态：极端值概率指数衰减，1000 个样本能代表整体
重尾（Pareto α<2）：方差无穷，极端值贡献巨大
  → 样本均值随"最大那一个"跳
  → 大数定律仍成立（会收敛），但收敛极慢，慢到没有实用价值
```

**"均值存在"不等于"均值可信"**：α ≤ 1 时连均值都不存在。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import numpy as np
rng = np.random.default_rng(42)
def pareto(alpha, n): return rng.pareto(alpha, n) + 1
for name, draw in (("Pareto α=1.1", lambda n: pareto(1.1, n)),
                   ("正态(同均值)", lambda n: rng.normal(11, 10, n))):
    means = [draw(1000).mean() for _ in range(200)]
    print(f"{name}: 200 次抽样均值范围 {min(means):.1f}–{max(means):.1f}，标准差 {np.std(means):.1f}")
PY
```

本机输出：

```text
Pareto α=1.1: 均值范围 3.9–20.2，标准差 2.7
正态(同均值): 均值范围 10.2–12.0，标准差 0.3
```

## 该怎么看这种数据

```text
1. 报分位数（P50/P90/P99），不报均值
2. 报截尾均值（去掉最高的 1%）
3. 报"总额的集中度"：前 1% 贡献了多少占比
4. 看稳定性：换几个时间窗，均值是否剧烈变化
```

**"P99 比均值更有信息量"**：重尾业务里，均值会被少数极端值主导。

## 什么时候均值仍然可用

```text
1. 分布近似对称、尾部指数衰减（身高、测量误差）
2. 关心的是"总量"而不是"典型个体"：均值 × 数量 = 总成本，这个用法没错
3. 已经做了截尾/对数变换
```

**"算总账用均值，描述个体用分位数"**：这是两条不同的用途。

## 数字与阈值（本机实测）

```text
Pareto α=1.1：均值 3.9–20.2（std 2.7）｜ 正态：10.2–12.0（std 0.3）→ 波动 9×
经验：α < 2 时方差无穷；α ≤ 1 时均值无穷
经验：P99/P50 > 10 的指标，先怀疑重尾
经验：重尾下 t 检验的正态假设不成立，改用 bootstrap
```

## 证据强度

- **实测**：两组均值范围与标准差来自本机 numpy
- **公开经验**：α 与矩存在性的关系、分位数替代均值
- **推断**：真实业务的重尾程度要用数据估，不能直接套 α=1.1

## 不适用的情况

- 指标有硬上限（评分 1–5、成功率）：尾部被截断，均值可用
- 只关心总量：均值仍然是对的乘数

## 常见错法

- **拿均值做 SLA**（一次超长请求就把均值拉爆）
- **用正态假设算置信区间**
- **去掉"异常值"再算**：在重尾里，异常值就是信号本身

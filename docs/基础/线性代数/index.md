# 线性代数

> 这一科只回答一件事：**为什么同样的数学，代码能差几十倍；为什么系数会飘。**
> 每页都有本机实测：C 的缓存效应、numpy 的数值稳定性、幂迭代的收敛步数。

## 收什么

- 矩阵乘法的代价与三种循环顺序
- 分块为什么有效，块大小怎么定
- 什么时候必须用 BLAS
- 内积/投影/最小二乘的几何意义
- 条件数、特征值、秩亏的实际后果

## 不收什么

- 抽象代数与证明
- 数值分析的高级算法（Krylov 子空间细节）
- 深度学习框架的自动微分

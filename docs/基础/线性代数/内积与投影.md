## 结论

**内积衡量"同方向的程度"，投影是"把向量拆成'在子空间里'和'垂直于子空间'两部分"。**
最小二乘、余弦相似度、注意力机制，本质都是投影。

## 内积的两个面孔

```text
代数：a·b = Σ aᵢbᵢ
几何：a·b = |a||b|cosθ
```

**同一个数**：所以 `cosθ = a·b / (|a||b|)`，这就是余弦相似度。

## 本机可复现（已实测）

```python
a = np.array([1.0, 1.0])
for scale in (1, 100):
    b = a * scale
    print(a@b/(np.linalg.norm(a)*np.linalg.norm(b)), np.linalg.norm(a-b))
```

本机输出：

```text
长度 ×1    余弦相似度 1.000000 ｜ 欧氏距离 0.00
长度 ×100  余弦相似度 1.000000 ｜ 欧氏距离 140.01
```

**"方向完全一致，距离却差 140"**：余弦只看方向，欧氏距离看位置。选哪个指标取决于你关心什么。

## 投影：最小二乘的几何解释

```text
把 y 投影到 X 的列空间上，得到 ŷ
残差 r = y - ŷ 垂直于列空间
所以 Xᵀ(y - Xŷ) = 0  →  XᵀXβ = Xᵀy   （正规方程）
```

**"正规方程"不是硬背的公式，是"残差必须垂直"的直接结果**。

## 什么时候用哪个相似度

| 指标 | 关心 | 典型场景 |
| --- | --- | --- |
| 余弦 | 方向 | 文本向量、推荐召回 |
| 欧氏距离 | 位置 | 聚类、KNN（特征已归一化时） |
| 点积 | 方向 × 长度 | 排序（长度代表热度/置信度） |

**"文本用余弦"的原因**：文档长短不一时，长度是噪声。

## 数字与阈值（本机实测 + 公式）

```text
余弦 = 1.000000（长度 ×100 不变）
欧氏距离 = 140.01（长度 ×100 时）
投影残差与列空间正交：Xᵀ(y-ŷ) ≈ 0
经验：特征未归一化时，欧氏距离会被量纲主导
```

## 证据强度

- **实测**：两行余弦/距离为本机 numpy 输出
- **公式**：内积的代数与几何定义、正规方程的推导
- **公开经验**：余弦/欧氏/点积的适用场景

## 不适用的情况

- 稀疏高维（词袋）：余弦仍可用，但零值多，点积会被长度主导
- 非线性流形：欧氏距离不代表语义距离

## 常见错法

- **用点积比较长度差异大的向量**
- **不归一化就做 KNN**
- **把余弦相似度当"概率"**

## 结论

**"切成几块"这件事可以变成一个特征值问题：看第二小的特征值，就够分了。**
本机模拟两簇、各 60 个点：用高斯核建图、算拉普拉斯、取第二小特征值对应的向量（Fiedler 向量），
按中位数切开 → **分簇准确率 100%**；前四个特征值是 `0, 0, 1.244, 1.708`——**两个 0 说明图有两个连通块。**

## 三个矩阵

```text
邻接矩阵 W：谁和谁相连（本机用高斯核 exp(-d²/σ²)）
度矩阵 D：每行权重之和
拉普拉斯 L = D − W：特征值 0 的个数 = 连通块数
```

**"谱聚类就是 K-means 的替代品"** 它先用图结构把"形状"变成"距离"，再聚类。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(3)
c1=rng.normal([0,0],0.6,(60,2)); c2=rng.normal([3,3],0.6,(60,2))
X=np.vstack([c1,c2]); W=np.exp(-((X[:,None,:]-X[None,:,:])**2).sum(-1)/0.5)
np.fill_diagonal(W,0); L=np.diag(W.sum(1))-W
w,v=np.linalg.eigh(L); e=v[:,1]; pred=(e>np.median(e)).astype(int)
truth=np.r_[np.zeros(60),np.ones(60)]
print(round(max((pred==truth).mean(),(pred!=truth).mean())*100,1), np.round(w[:4],3))
PY
```

本机输出：

```text
准确率 100.0% ｜前四个特征值 [0. 0. 1.244 1.708]
```

## 怎么用

```text
1. 建图：k 近邻或核函数（σ 决定"多近算相连"）
2. 算前 k 个小特征值对应的特征向量
3. 把特征向量当新坐标，做 K-means
4. 特征值里 0 的个数 ≈ 簇数（理想情况下）
```

**"直接用 K-means"** 在两簇是同心圆、月牙形时会失败；谱聚类看的是"连通性"。

## 判据与代价

```text
数据量 < 1 万：可以直接算稠密特征分解
数据量大：用稀疏拉普拉斯 + Lanczos（只算前几个）
σ 太小 → 图碎成很多块；σ 太大 → 全连成一块
```

## 数字与阈值（本机模拟）

```text
两簇各 60 点：准确率 100% ｜特征值 0, 0, 1.244, 1.708
经验：0 特征值的个数 = 连通块数（有噪声时会变成"接近 0"）
经验：σ 取"k 近邻距离的中位数"是常见起手
经验：点数 > 1 万用稀疏求解，别做稠密特征分解
```

## 证据强度

- **模拟**：准确率与特征值来自本机
- **公开经验**：σ 取法、稀疏求解
- **推断**：真实图（社交、引用）的连通块更多，需要看特征值间隙而不是数 0

## 不适用的情况

- 特征空间距离本身就有意义（低维稠密数据）：K-means 更快
- 图规模极大且只关心局部社区：用 Louvain/标签传播

## 常见错法

- **σ 随手取 1**
- **把"接近 0"的特征值当精确 0**
- **在百万点上做稠密特征分解**

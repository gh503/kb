## 结论

**三阶张量可以看成"三个方向各有一组向量，乘起来再加和"，而它确实能用交替最小二乘解出来。**
本机模拟一个秩 1 的 8×8×8 张量（加 0.05 噪声）：CP 分解 1 个分量，**相对误差 3.53%**。

## 为什么要张量

```text
矩阵：两维（用户 × 物品）
张量：三维以上（用户 × 物品 × 时间 / 城市 × 品类 × 周）
  → 硬展平成矩阵会丢结构：时间维被压成列，周期性没了
```

**"拼成一个大矩阵就行"** 会丢掉"沿某个维度的共享模式"。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(3)
a,b,c=[rng.normal(size=8) for _ in range(3)]
T=np.einsum('i,j,k->ijk',a,b,c)+0.05*rng.normal(size=(8,8,8))
A=rng.normal(size=(8,1)); B=rng.normal(size=(8,1)); C=rng.normal(size=(8,1))
for _ in range(80):
    A=np.einsum('ijk,jl,kl->il',T,B,C)@np.linalg.pinv((B.T@B)*(C.T@C))
    B=np.einsum('ijk,il,kl->jl',T,A,C)@np.linalg.pinv((A.T@A)*(C.T@C))
    C=np.einsum('ijk,il,jl->kl',T,A,B)@np.linalg.pinv((A.T@A)*(B.T@B))
Tk=np.einsum('i,j,k->ijk',A[:,0],B[:,0],C[:,0])
print(round(np.linalg.norm(T-Tk)/np.linalg.norm(T)*100,2))
PY
```

本机输出：

```text
CP 分解 1 分量：相对误差 3.53%
```

## 两种分解

```text
CP（CANDECOMP/PARAFAC）：每个分量是三个向量的外积，秩 = 分量数
Tucker：每个维度一个因子矩阵 + 一个核心张量，更灵活也更难解释
  → 先试 CP，解释不了再上 Tucker
```

## 交替最小二乘（ALS）的三行逻辑

```text
固定 B、C → 解 A（变成线性最小二乘）
固定 A、C → 解 B
固定 A、B → 解 C
  → 循环到误差不再下降；分量数 k 要外部给定
```

## 判据

```text
维度 ≤ 3、想要可解释的分量 → CP
维度高、只想要压缩 → Tucker / TensorSketch
数据极稀疏（推荐场景）→ 用加权或贝叶斯 CP，别直接补零
```

## 数字与阈值（本机模拟）

```text
8×8×8、秩 1 + 0.05 噪声：CP 1 分量误差 3.53%
经验：分量数 k 从 1 开始试，看误差-分量曲线
经验：ALS 可能陷入局部最优，多初始化几次
经验：噪声越大，误差地板越高（本机 0.05 噪声 → 3.5%）
```

## 证据强度

- **模拟**：误差来自本机 ALS 实现
- **公开经验**：CP vs Tucker、多初始化
- **推断**：真实张量（点击、脑电、传感器）的秩通常远大于 1，需要更多分量

## 不适用的情况

- 只有两维数据：矩阵 SVD 就够
- 只需要"平均效应"：不必分解，直接沿维度求均值

## 常见错法

- **把稀疏张量补零后直接分解**
- **分量数拍脑袋取 10**
- **只跑一次 ALS 就下结论**

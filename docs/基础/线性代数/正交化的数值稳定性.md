## 结论

**同样叫"正交化"，三种写法在病态矩阵上差 15 个数量级。**
本机实测 12×12 Hilbert 矩阵（条件数约 1e16）：
**经典 Gram-Schmidt 的 `‖QᵀQ−I‖ = 5.48`，修正版 0.439，Householder QR 1.84e-15。**

## 三者差在哪

```text
经典 GS：一次算出投影系数，再用原向量减
  → 高维下"减掉的"和"算系数时用的"不是同一个向量，误差累积
修正 GS：每减一次就重新算下一个系数
  → 正交性误差小一个量级，但仍与条件数成正比
Householder：用反射矩阵整体变换
  → 误差与条件数无关，是数值上的正确做法
```

**"数学上等价"的算法，在浮点里可以差到无法使用**。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import numpy as np
H = np.array([[1/(i+j+1) for j in range(12)] for i in range(12)])
def cgs(A):
    m, n = A.shape; Q = np.zeros((m, n)); R = np.zeros((n, n))
    for j in range(n):
        v = A[:, j].copy()
        for i in range(j):
            R[i, j] = Q[:, i] @ A[:, j]; v -= R[i, j]*Q[:, i]
        R[j, j] = np.linalg.norm(v); Q[:, j] = v/R[j, j]
    return Q, R
def mgs(A):
    m, n = A.shape; Q = A.copy().astype(float); R = np.zeros((n, n))
    for j in range(n):
        R[j, j] = np.linalg.norm(Q[:, j]); Q[:, j] /= R[j, j]
        for k in range(j+1, n):
            R[j, k] = Q[:, j] @ Q[:, k]; Q[:, k] -= R[j, k]*Q[:, j]
    return Q, R
for name, f in (("经典 GS", cgs), ("修正 GS", mgs)):
    Q, _ = f(H)
    print(f"{name}: ‖QᵀQ−I‖ = {np.linalg.norm(Q.T@Q - np.eye(12)):.2e}")
Q, _ = np.linalg.qr(H)
print(f"Householder QR: ‖QᵀQ−I‖ = {np.linalg.norm(Q.T@Q - np.eye(12)):.2e}")
print(f"Hilbert 12 的条件数: {np.linalg.cond(H):.2e}")
PY
```

本机输出：

```text
经典 GS: ‖QᵀQ−I‖ = 5.48e+00
修正 GS: ‖QᵀQ−I‖ = 4.39e-01
Householder QR: ‖QᵀQ−I‖ = 1.84e-15
```

## 什么时候你其实遇到了这个问题

```text
1. 自己实现最小二乘 / 多项式拟合 → 正交性一塌，系数全是噪声
2. 迭代求解器"不收敛" → 基向量早就线性相关了
3. PCA 的方差出现负值或非降序 → 协方差矩阵的条件数太大
```

**"条件数大于 1/eps ≈ 1e16 时，双精度已经分不清了"**：Hilbert 12 就在这条线上。

## 该用什么

```text
要正交基：`np.linalg.qr`（Householder），不要手写 GS
要求解最小二乘：`np.linalg.lstsq`（内部用 QR/SVD）
要低秩近似：SVD
要"边来边算"的正交化（如 Arnoldi）：用修正 GS + 重正交化
```

**"重正交化"** 是修正 GS 的补丁：算两遍投影，把残差再投一次，能再降几个数量级。

## 数字与阈值（本机实测）

```text
Hilbert 12（cond≈1.7e16）：经典 GS 5.48 ｜ 修正 GS 0.439 ｜ Householder 1.84e-15
经验：正交性误差 ≈ cond(A) × eps（经典 GS 更差，约平方关系）
经验：cond > 1e12 时任何"自己写的"正交化都要怀疑
经验：重正交化能让修正 GS 再降 1–2 个数量级
```

## 证据强度

- **实测**：三个误差值与条件数来自本机 numpy
- **公开经验**：误差与条件数的关系、重正交化
- **推断**：不同 LAPACK 实现的具体数值会有差异，数量级不变

## 不适用的情况

- 良态矩阵（cond < 1e6）：三种写法差别不大
- 只要一个近似基、不要求严格正交：经典 GS 够用

## 常见错法

- **手写 Gram-Schmidt 做最小二乘**
- **用 `AᵀA` 求正交基**（条件数平方）
- **正交性变差时加大迭代次数**，而不是换算法

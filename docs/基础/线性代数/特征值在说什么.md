## 结论

**特征向量是"被矩阵变换后方向不变"的方向，特征值是它被拉长的倍数。**
幂迭代每步只能把"次特征方向"的占比乘以 λ₂/λ₁，所以**比值 0.99 时要 2,241 步，0.5 时只要 38 步**。

## 定义与直觉

```text
A·v = λ·v
v 方向不变，长度乘 λ
```

**"方向不变"是最有用的性质**：它把矩阵的作用拆成"几个固定方向 + 各自的缩放"。

## 本机可复现（已实测）

```python
# 构造主特征值 1、其余都等于 gap 的对称矩阵
d = np.array([1.0] + [gap]*(n-1))
M = Q @ np.diag(d) @ Q.T
# 幂迭代，直到变化 < 1e-10
```

本机输出（n=200，numpy 1.21.5）：

```text
次特征值/主特征值 = 0.5 :    38 步收敛到 1e-10
次特征值/主特征值 = 0.9 :   224 步
次特征值/主特征值 = 0.99:  2241 步
```

**步数 ≈ log(1e-10) / log(λ₂/λ₁)**：比值越接近 1，收敛越慢。

## 收敛速度的公式

```text
误差每步 × (λ₂/λ₁)
要到 ε 需要的步数 ≈ log(ε) / log(λ₂/λ₁)
λ₂/λ₁=0.99 → 约 2300 步；0.9 → 约 220 步
```

**"特征值间隔小 = 收敛慢"** 是 PCA、PageRank、谱聚类都要面对的问题。

## 三个工程含义

| 场景 | 特征值告诉你什么 |
| --- | --- |
| PCA | 前几个特征值占比 = 能压缩多少 |
| PageRank | 主特征向量 = 稳态分布；λ₂ 决定收敛速度 |
| 稳定性分析 | 特征值实部 > 0 就不稳定 |

**"λ₂ 决定收敛速度"是最实用的一条**：调参调不动时，先看谱 gap。

## 数字与阈值（本机实测 + 公式）

```text
gap 0.5 → 38 步；0.9 → 224 步；0.99 → 2241 步
步数 ≈ log(1e-10)/log(gap)
经验：gap > 0.9 时，纯幂迭代基本不可用，要加速（Lanczos/ARPACK）
经验：PCA 取累计解释 80%–95% 的主成分
```

## 证据强度

- **实测**：三档步数为本机输出
- **公式**：收敛步数 log(ε)/log(λ₂/λ₁)
- **公开经验**：PCA 的累计解释比例、ARPACK 的使用场景

## 不适用的情况

- 非对称矩阵：特征值可能是复数，幂迭代行为不同
- 重特征值：收敛分析要改（用块方法）

## 常见错法

- **用幂迭代求多个特征向量**（要先收缩）
- **忽略谱 gap 就说"算法不收敛"**
- **把特征值当"重要性"**：它只是方向的缩放倍数

## 结论

**"低秩"能不能用，取决于奇异值掉得多快，而不是矩阵多大。**
本机模拟一个秩 5 的 300×300 矩阵（加 0.1 噪声）：秩 1 近似误差 **86.31%**、秩 5 降到 **4.36%**、
秩 10 只到 **4.23%**、秩 50 也只到 **3.27%**——**秩一旦到了 5，再往上加几乎没有收益。**

## 秩在说什么

```text
秩 = 独立方向的数量 = 数据里"真正自由度"的个数
低秩 = 你以为有 300 个维度，其实只有 5 个方向在变化
奇异性：奇异值衰减曲线 = 每个方向贡献多少能量
```

**"降维一定丢信息"** 丢的是"几乎没能量的方向"，不是随便砍。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(3); m=n=300; r=5
A=rng.normal(size=(m,r))@rng.normal(size=(n,r)).T + 0.1*rng.normal(size=(m,n))
s=np.linalg.svd(A,compute_uv=False); E=np.sqrt((s**2).sum())
for k in (1,5,10,50): print(k, round(np.sqrt((s[k:]**2).sum())/E*100,2))
PY
```

本机输出：

```text
秩 1：86.31% ｜秩 5：4.36% ｜秩 10：4.23% ｜秩 50：3.27%（相对误差）
```

## 怎么选 k

```text
看奇异值曲线：出现"拐点"的地方就是有效秩
看目标误差：本机秩 5 已到 4.36%，再往上只降到 3.27%
看下游成本：k 翻倍，存储与计算近似线性增长
```

**"取 90% 能量"** 是常用经验，但要看的是"剩下的误差对任务有没有影响"。

## 三个真实用途

```text
1. 压缩：300×300 → 300×5 + 5×300，参数量从 9 万降到 3 千
2. 去噪：丢掉小奇异值对应的方向（本机噪声 0.1 就落在尾部）
3. 推荐/嵌入：用户-物品矩阵天然低秩（兴趣维度远少于物品数）
```

## 数字与阈值（本机模拟）

```text
秩 1/5/10/50 → 误差 86.31% / 4.36% / 4.23% / 3.27%
经验：奇异值出现数量级下降 → 拐点即有效秩
经验：误差降到某个点后不再明显下降，就是过拟合噪声了
经验：低秩近似对稀疏矩阵要用增量 SVD，别直接补零
```

## 证据强度

- **模拟**：四个误差值来自本机 SVD
- **公开经验**：能量占比、拐点判据
- **推断**：真实数据（文本、图像）的奇异值衰减更平缓，需要的 k 更大

## 不适用的情况

- 矩阵本身满秩且奇异值平坦（白噪声）：低秩近似等于随机丢信息
- 需要精确解的线性系统：近似会改变答案

## 常见错法

- **随手取 k=10 不看衰减曲线**
- **稀疏矩阵补零后做 SVD**
- **用低秩近似替代需要精确性的计算**

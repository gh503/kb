## 结论

**两列几乎相同时，系数会飘到没有意义。** 本机实测：列间扰动 1e-3 时，真值 1 与 -1 的系数
估计成 **-0.22 ± 9.97**——均值都不对，标准差接近 10。

## 什么是秩亏

```text
秩 = 线性无关的列数
秩亏 = 有列能被其他列线性组合出来
→ XᵀX 不可逆（或数值上接近不可逆）
→ 系数有无穷多组解，或解对噪声极度敏感
```

**"完全共线"和"几乎共线"在数值上是同一件事**，只是后者更隐蔽。

## 本机可复现（已实测）

```python
for noise in (0.0, 1e-3, 1e-2, 1.0):
    x1 = rng.normal(size=n); x2 = x1 + noise*rng.normal(size=n)
    X = np.column_stack([x1, x2]); y = X@[1,-1] + 0.1*rng.normal(size=n)
    b = np.linalg.lstsq(X, y, rcond=None)[0]
```

本机输出（n=100，200 次重复，numpy 1.21.5）：

```text
列间扰动 0.0  : 系数1  -0.00±0.01 ｜ 系数2   0.00±0.01 ｜ 条件数 1.7e16
列间扰动 0.001: 系数1  -0.22±9.97 ｜ 系数2   0.22±9.97 ｜ 条件数 1.9e3
列间扰动 0.01 : 系数1   0.84±0.98 ｜ 系数2  -0.84±0.98 ｜ 条件数 1.9e2
列间扰动 1.0  : 系数1   1.00±0.01 ｜ 系数2  -1.00±0.01 ｜ 条件数 2.6
```

**扰动 0 时系数变成 0/0 的最小范数解**（真值是 1/-1，但任何 b₁-b₂=1 都成立，库给了最小范数的那组）。
**扰动 1e-3 时标准差 9.97**——系数完全没有信息量。

## 怎么发现它

```text
1. np.linalg.cond(X) 或矩阵条件数
2. 相关系数矩阵里接近 ±1 的成对列
3. VIF（方差膨胀因子）> 10
4. 特征值最小的那个接近 0
```

**"条件数"是最直接的一眼判据**：本机扰动 1e-3 时是 1.9e3，已经值得警惕。

## 怎么办

```text
删掉一列（信息重复）
合并成一个（取平均或主成分）
加正则（岭回归，L2 惩罚会稳定系数）
标准化（量纲差异也会造成病态）
```

**"加正则"是最省事的**：它把不可逆变成可逆，代价是系数有偏。

## 数字与阈值（本机实测 + 经验）

```text
扰动 1e-3：系数 ±9.97，条件数 1.9e3
扰动 1e-2：系数 ±0.98，条件数 1.9e2
扰动 1.0 ：系数 ±0.01，条件数 2.6
经验：条件数 > 1e3 警惕，> 1e6 基本不可用
经验：VIF > 10 视为共线
```

## 证据强度

- **实测**：四行系数均值/标准差为本机输出
- **公式**：秩亏 ⇔ XᵀX 奇异；VIF 定义
- **公开经验**：条件数阈值与 VIF>10 的经验规则

## 不适用的情况

- 纯预测场景：系数不稳但预测可能仍准（只要不外推）
- 正交设计：列天然不相关，不存在这个问题

## 常见错法

- **只看 R² 不看系数稳定性**
- **共线时解释系数大小**（"这个特征最重要"）
- **用逐步回归硬选变量**

# 通用基础

> 跨学科都用得上，但不属于任何一科：怎么找、怎么判断、怎么讲清楚。

## 收什么

- 怎么找到一个可靠的答案（检索路径、信息源分级）
- 怎么把一件事写清楚，让别人（或三个月后的自己）一次看懂
- 怎么学一个新东西：先建立骨架，再补细节
- 可复用的思维模型，以及它们的适用边界

## 不收什么

- 具体学科的知识——归各科，这里只留"方法"
- 软件工具的操作说明——归[开发](../../工程/开发/index.md)

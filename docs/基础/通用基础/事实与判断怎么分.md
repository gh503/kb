# 事实与判断怎么分

> **深度** 实操 ｜ **类型** 边界 ｜ **链** 怎么把一个问题说清楚

## 结论

**事实可以被独立核对，判断必须说明依据与立场。**
把判断说成事实，是最常见也最难被发现的表达问题。

## 一条判别线

```text
换一个人、换一台仪器，能否得到同一个结果？
能 → 偏事实
不能 → 偏判断（需要说明依据）
```

**"能否独立复核"是唯一稳定的标准**，不是"听起来客不客观"。

## 四种常见混淆

| 说法 | 实际是 | 问题 |
| --- | --- | --- |
| 这个功能没人用 | 判断（基于某段数据） | 没说时间范围与人群 |
| 用户都讨厌新版 | 判断（基于部分反馈） | "都"是过度概括 |
| 接口平均耗时 120ms | 事实（有测量） | 需说明样本与环境 |
| 这个方案不可行 | 判断（基于约束） | 没说约束是什么 |

**"都/没人/从不"这类词是判断的标记**：出现就说明在概括。

## 表达的三段式

```text
事实：我观察到什么（数据、时间、范围）
依据：为什么我认为它意味着什么（推理或经验）
判断：因此我的结论是（明确标为判断）
```

**"明确标为判断"不削弱说服力**，反而让别人知道可以争哪里。

## 数字也会骗人

```text
样本偏差：只统计了愿意填问卷的人
口径变化：这个月和上个月的定义不同
幸存者偏差：只看到还在用的用户
```

**"口径"最容易被忽略**：两个都叫"活跃用户"的指标可能完全不同。

## 一条自检

```text
把句子里的形容词去掉，还剩下可核对的内容吗？
```

**去掉形容词后什么都不剩，说明这句话是纯判断**——不是不能讲，是要标明。

## 数字与阈值（经验判断）

```text
判断句：必须带依据（数据/经验/推理）
事实句：必须带范围（时间、样本、环境）
概括词（都/从不/没人）：出现即需证据
复核成本：好的事实句应能在 10 分钟内被他人复核
```

## 证据强度

- **公开经验**：以"可否独立复核"区分事实与判断、概括词是判断标记
- **方法**：三段式表达属可操作框架
- **推断**："去掉形容词后剩什么"按可核验性推的自检法

## 不适用的情况

- 紧急沟通：先给判断，事后补依据
- 创意/观点表达：允许主观，但应标明是观点

## 常见错法

- **用"数据表明"包装判断**：数据可能不支持
- **不写样本范围**：结论被外推到不该用的地方
- **把相关性当因果**：两个数一起涨不等于一个导致另一个

# 怎么找反例

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 怎么把一个问题说清楚

## 结论

**先写清"什么情况能推翻它"，再去那种情况里找。**
找不到反例不等于成立——**可能只是你没找对地方**。这是本页最重要的一句话。

## 三步

```text
1. 把结论写成可被推翻的形式："在所有 A 情况下，B 都会发生"
2. 列出"最可能不成立"的 A：极端值、边界、例外场景
3. 只在那些情况里找，而不是重复验证已知成立的
```

**"只在最可能失败的地方找"是效率关键**：在已成功的样本里再测一遍，什么也证明不了。

## 该往哪找

| 方向 | 找什么 |
| --- | --- |
| 极端值 | 0、负数、超大、超长、空 |
| 边界 | 刚好等于阈值、刚好跨过 |
| 例外场景 | 被规则排除的那一类 |
| 时间变化 | 一年后还成立吗 |
| 反方最强论据 | 对手最好的例子，而不是最差的 |

**"反方最强论据"最能检验**：驳倒稻草人不算本事。

## 四种常见的假验证

```text
1. 确认偏误：只找支持自己的例子
2. 样本太小：3 个例子就下结论
3. 只测主流场景：边缘情况没进样本
4. 把"没发现反例"当成"没有反例"
```

**第 4 条是逻辑错误**：找不到不等于不存在。

## 一个能用的强度分级

```text
强：主动去最可能失败的地方找过，没找到
中：在常规样本里没找到
弱：没找过，只是觉得对
```

**说结论时标明是哪一级**，比含糊地说"我觉得没问题"有用得多。

## 数字与阈值（经验判断）

```text
反例搜索方向：≥ 5 个（极端/边界/例外/时间/反方）
样本量：定性结论至少 5–10 个独立案例
时间检验：重要结论至少跨 1 个周期复看
推翻成本：先算"如果错了代价多大"，再决定找多深
```

## 证据强度

- **公开经验**：可推翻形式、去最可能失败处找反例、假验证的四种形态
- **方法**：三步法与强度分级属可操作框架
- **推断**："找不到不等于不存在"属逻辑事实，非实证结论

## 不适用的情况

- 数学证明：靠演绎，不靠找反例
- 紧急决策：时间不够时可先做，但应标注强度为"弱"

## 常见错法

- **只找支持证据**：确认偏误
- **驳稻草人**：赢了但没验证
- **把"没找到"说成"不存在"**

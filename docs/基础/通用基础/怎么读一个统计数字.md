## 结论

**同一个数，四种问法会得到四种答案：它怎么来的、范围多大、跟谁比、能不能复现。**
本机模拟：95% 置信区间的实际覆盖率 **94.3%**（1 万次重复，理论 95%）——
**置信区间说的是"这套方法长期有 95% 会盖住真值"，不是"这个区间有 95% 概率含真值"。**

## 读一个数字的四步

```text
1. 来源：谁算的、样本多大、什么时间段
2. 范围：是点估计还是区间？区间多宽（本机 94.3% 覆盖是对的）
3. 基准：跟什么比（去年同期？对照组？行业？）
4. 可复现：换一批数据，数字会不会翻倍
```

**"增长了 30%"** 先问基数：从 10 到 13 也是 30%。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(9); cover=0
for _ in range(10000):
    x=rng.normal(10,2,30); m=x.mean(); se=x.std(ddof=1)/np.sqrt(30)
    cover += m-1.96*se <= 10 <= m+1.96*se
print(cover/10000)
PY
```

本机输出：

```text
95% CI 覆盖率 94.3%（理论 95%，1 万次重复）
偏态样本：均值 1.56 ｜中位数 0.99（均值高 57%）
```

## 五个高频陷阱

```text
1. 均值当典型：偏态分布下均值被长尾拉高 57%（本机）
2. 区间当点：把"3–7 天"说成"5 天"
3. 相关当因果：两个数一起动，不等于一个导致另一个
4. 幸存者偏差：只统计还在的（本机生存分析里低估 61%）
5. 相对 vs 绝对：从 1% 到 2% 是"翻倍"，也是"多 1 个百分点"
```

## 判据：这个数字能不能用

```text
能用：有样本量、有时间窗、有对照、有区间
慎用：只有点估计、没有分母
不能用：来源不明、样本是"愿意填问卷的人"
```

## 数字与阈值（本机模拟）

```text
95% CI 覆盖 94.3%（1 万次）｜偏态样本均值/中位数差 57%
经验：看到百分比先找分母
经验：看到"平均"先问分布是否偏态
经验：看到"显著"先问做了多少次检验（20 次时 64% 会假显著）
```

## 证据强度

- **模拟**：覆盖率与偏态差距来自本机
- **公开经验**：五个陷阱、判据
- **推断**：真实报表常省略样本量，读者应默认"信息不完整"

## 不适用的情况

- 确定性计数（服务器数量、文件行数）：不需要统计推断
- 全量数据（无抽样）：区间概念不适用

## 常见错法

- **用均值描述偏态数据**
- **把置信区间理解成概率**
- **相对变化与绝对变化混着说**

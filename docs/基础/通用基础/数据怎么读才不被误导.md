# 数据怎么读才不被误导

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 怎么判断信息可不可信
>
> **本链四页**：[来源怎么分级](来源怎么分级.md) · **数据怎么读才不被误导**（当前页） · [说法能不能被检验](说法能不能被检验.md) · [承认不知道](承认不知道.md)

## 结论

**先找三样东西：口径、分母、时间范围。三样缺一样，这个数就不能用。**
多数"数据骗人"不是造假，而是**口径没写清**。

## 三个必查项

```text
口径：这个指标怎么定义？（"活跃用户"是登录过还是用满 1 分钟？）
分母：比例的分母是谁？（占全部用户还是占付费用户？）
时间：统计的哪段时间？（含不含大促？同比还是环比？）
```

**"分母"最容易被换掉**：同一个 30%，换个分母就是完全不同的结论。

## 四个常见的视觉误导

| 手法 | 效果 |
| --- | --- |
| 纵轴不从 0 开始 | 微小差异看起来像断崖 |
| 双纵轴 | 两条无关曲线"完美吻合" |
| 面积/体积代替长度 | 2 倍数值看起来像 4 倍 |
| 选择性时间区间 | 挑一段刚好上涨的 |

**"纵轴不从 0 开始"最常见**：它不一定错（有时必要），但不说明就是误导。

## 一个必须问的问题

```text
这个数如果换成"绝对数量"，还惊人吗？
```

```text
"投诉率上升 100%" —— 从 2 起到 4 起
"满意度下降 20%"   —— 从 90% 到 72%（这才是真下降）
```

**"相对变化 + 小基数"是最大的放大器**。

## 关于同比与环比

```text
环比：跟上个月比 → 受季节影响大
同比：跟去年同月比 → 消掉季节性
累计：年初至今 → 早期波动被平滑
```

**"选哪个口径"会直接决定结论方向**，看到"增长"先问是哪种。

## 数字与阈值（经验判断）

```text
基数门槛：< 30 个样本的比例变化不要下结论
视觉检查：纵轴起点、是否双轴、面积是否按比例
时效：超过 1 年的数据要标注
口径核对：至少确认"定义、分母、区间"三项
```

## 证据强度

- **公开经验**：口径/分母/时间三查、四类视觉误导
- **方法**：检查清单属可操作框架
- **推断**："< 30 样本不下结论"按抽样波动推的（与数学页 1/√n 一致）

## 不适用的情况

- 全量确定性数据（如财务报表经审计）：口径已由规范固定
- 探索性分析：可先看趋势，但不应据此下强结论

## 常见错法

- **只看百分比不看基数**
- **不问分母**
- **把相关曲线当因果**（见[相关不等于因果](../数学/相关不等于因果.md)）

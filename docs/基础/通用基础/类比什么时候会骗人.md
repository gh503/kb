## 结论

**类比骗人，是因为它按"表面相似"匹配，而决定结论的往往是那个不相似的关键属性。**
本机模拟：200 个样本、9 个属性，其中 1 个是关键属性（权重 3）、8 个是噪声。
按全部属性找最近邻，分类准确率 **100%**；**去掉关键属性、只留表面相似**，准确率掉到 **50.4%**——等于瞎猜。

## 类比的两种用法

```text
生成假设："这个像那个，所以那边可能也成立" → 有用，成本低
当作证明："因为它像那个，所以一定成立" → 危险，表面相似不蕴含机制相同
```

**"这不就是一个××吗"** 是生成假设的句式，不该被当成结论。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(9)
def trial(m=200):
    y=rng.integers(0,2,m); noise=rng.normal(size=(m,8))
    X=np.c_[y*3+0.1*rng.normal(size=m), noise]
    X2=np.c_[0.2*rng.normal(size=m), noise]
    def acc(D):
        c=0
        for i in range(m):
            d=((D-D[i])**2).sum(1); d[i]=1e9
            c+= y[d.argmin()]==y[i]
        return c/m
    return acc(X), acc(X2)
print(np.array([trial() for _ in range(20)]).mean(0))
PY
```

本机输出：

```text
含关键属性 100.0% ｜只按表面相似 50.4%
```

## 三个自检问题

```text
1. 两个东西共享的是"机制"还是"外观"？
2. 有没有一个属性，一旦不同，结论就反转？
3. 类比的结论能不能被单独检验（有数字、有实验）？
```

**"两者都是分布式系统"** 共享的是标签，不是失效模式。

## 常见会骗人的类比

```text
把"水管"类比网络带宽：忽略了排队与拥塞
把"大脑"类比计算机：忽略了可塑性与能耗机制
把"市场"类比生态系统：忽略了制度与信息结构
把"缓存"类比抽屉：忽略了失效与一致性问题
```

## 数字与阈值（本机模拟）

```text
含关键属性 100% ｜去掉关键属性 50.4%（随机水平）
经验：类比的结论必须能落到一个可测的数字上
经验：找出"关键差异"比找出"更多相似点"更有价值
经验：类比用于生成假设，验证仍需实验
```

## 证据强度

- **模拟**：两组准确率来自本机
- **公开经验**：三个自检问题
- **推断**：真实场景中"关键属性"往往事前未知，这才让类比危险

## 不适用的情况

- 严格同构的系统（同一套代码的两个部署）：类比成立
- 教学讲解：类比用来建立直觉，只要标注"这里只是比喻"

## 常见错法

- **把类比当论证**
- **比较相似点数量，不看关键差异**
- **类比的结论从不检验**

## 结论

**"哪来的"必须写在句子里，而不是留给读者猜。**
本站统计：证据标签出现 **实测 148 次、公开经验 352 次、推断 369 次**；
但真正带 `**实测**` 标签的页只有 **142/813（17%）**——**大部分内容是经验与推断，这没问题，问题是不标**。

## 四档，够用了

```text
实测：我在某台机器/某个环境跑过，附命令与输出
公开经验：行业惯例、文档、别人的基准（不能保证适合你）
推断：从原理或数据外推，没有直接验证
计算：公式直算，可验算但未必代表真实系统
```

**"据说"** 不算任何一档；它连推断都不是。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import pathlib
lab={'实测':0,'公开经验':0,'推断':0,'模拟':0,'计算':0}
pages=[p for p in pathlib.Path('docs').rglob('*.md') if '订阅' not in str(p)]
for p in pages:
    t=p.read_text(encoding='utf-8')
    for k in lab: lab[k]+=t.count(f'**{k}**')
print(lab, sum(1 for p in pages if '**实测**' in p.read_text(encoding='utf-8')), len(pages))
PY
```

本机输出：

```text
实测 148 ｜ 公开经验 352 ｜ 推断 369 ｜ 模拟 6 ｜ 计算 9
带实测标签的页：142 / 813（17%）
```

## 标了之后有什么用

```text
1. 读者知道该不该直接套用（实测可套，经验要调，推断先验证）
2. 作者被迫区分"我知道"与"我猜"
3. 事后能追溯：这条结论是哪个环境测的，换环境还成立吗
```

**"全部标成实测"** 是最坏的做法：等于全部不可信。

## 三种常见的伪标注

```text
"实测"但没写环境：别的机器上可能差 10 倍
"公开经验"但没出处：和"我觉得"没区别
"推断"写成断言：读者会当成事实
```

## 数字与阈值（本机实测）

```text
标签出现：实测 148、公开经验 352、推断 369、模拟 6、计算 9
带实测标签的页占 17%（142/813）
经验：每条关键结论都要有标签，宁可是"推断"
经验：实测必须带"环境 + 命令 + 输出"三件套
经验：推断要写清"往哪个方向可能错"
```

## 证据强度

- **实测**：标签计数与占比来自本站全文扫描
- **公开经验**：证据分级的通用做法
- **推断**：标签是自报的，无法验证其真实性——这也是为什么实测要附命令

## 不适用的情况

- 纯操作步骤（怎么装软件）：照做即可，不需要证据分级
- 观点类文章：本来就不是事实主张

## 常见错法

- **通篇不标，读者默认全是事实**
- **把"我跑过一次"写成"实测表明"**
- **用"业界公认"代替出处**

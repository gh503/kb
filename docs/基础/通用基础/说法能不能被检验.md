# 说法能不能被检验

> **深度** 实操 ｜ **类型** 边界 ｜ **链** 怎么判断信息可不可信

## 结论

**能被检验的说法，必须写清"什么情况算被推翻"。**
说不清这个，它不是更深刻的判断，而是**无法被讨论的一句话**。

## 一个检验性测试

```text
问：观察到什么现象，你会承认这个说法错了？
能答出具体现象 → 可检验
只能答"就是对的/你不懂" → 不可检验
```

**"不可检验"不等于"错"**：它只是无法用证据支持或反驳，因此不宜作为决策依据。

## 四种不可检验的形态

| 形态 | 例子 | 问题 |
| --- | --- | --- |
| 万能解释 | "效果不好是因为心不诚" | 任何结果都能解释 |
| 模糊预测 | "未来会有大变化" | 没有时间、范围、程度 |
| 循环定义 | "有效是因为它管用" | 前提即结论 |
| 不可观测 | "有个看不见的力量在起作用" | 无法验证 |

**"万能解释"最有欺骗性**：它永远正确，因此没有信息量。

## 怎么把话改成可检验

```text
原：这个方案效果更好
改：上线后 4 周内，A 组留存率比 B 组高 3 个百分点以上

原：用户不喜欢新版
改：新版首页的次日回访率低于旧版 5 个百分点以上
```

**共同点**：给了**指标 + 幅度 + 时间**，就有了"什么算失败"。

## 一个重要的例外

```text
有些判断本质上不可检验，但仍有价值：
  "这个设计更尊重用户"（价值判断）
  "这段代码更难维护"（需要先定义"难维护"）
```

**处理方式**：标明它是价值判断或需要先定义，而不是假装它是事实。

## 数字与阈值（经验判断）

```text
可检验要素：指标 + 幅度 + 时间窗（三样齐）
最小幅度：小于噪声的差异不可检验（见抽样误差）
时间窗：至少覆盖 1 个完整业务周期
```

## 证据强度

- **公开经验**：可检验性要求给出"什么算推翻"、四种不可检验形态
- **方法**：改写练习属可操作框架
- **推断**："不可检验≠错"按证据与真假的关系推的

## 不适用的情况

- 价值与审美判断：不适用可检验性，但应标明是价值判断
- 数学命题：以证明代替检验

## 常见错法

- **把不可检验当深刻**
- **用"你不懂"代替反例**
- **预测不给时间与幅度**

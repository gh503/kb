# 速查：基础这一域的判断与数

> 六科 67 条。这一域不讲"结论对不对"，讲**怎么把结论说清楚、怎么知道自己错了**。
> 所以这里的"数"多是**约束与判据**，不是测量值。

## 一、定义一个问题的五个位置

| 项 | 要求 | 反例 |
| --- | --- | --- |
| 对象 | 具体到可指认 | "系统""体验""效率" |
| 条件 | 范围与前提 | 不写并发、不写环境 |
| 对比 | 与什么相比 | "更好"没有参照 |
| 判据 | 怎么算达标 | "明显改善" |
| 边界 | 什么不算 | 范围无限扩张 |

**改写后长度 1–3 句**；超过说明还没想清。

## 二、事实与判断

| 项 | 判据 |
| --- | --- |
| 事实 | 换人换仪器能复核出同一结果 |
| 判断 | 不能独立复核，必须说明依据 |
| 概括词 | "都/从不/没人"出现即需证据 |
| 复核成本 | 好的事实句应能在 10 分钟内被他人复核 |
| 数字口径 | 同一名字的指标可能定义不同（活跃用户） |

## 三、找反例的强度

| 级别 | 含义 |
| --- | --- |
| 强 | 主动去最可能失败处找过，没找到 |
| 中 | 常规样本里没找到 |
| 弱 | 没找过，只是觉得对 |

```text
搜索方向 ≥ 5 个：极端值 / 边界 / 例外 / 时间 / 反方最强论据
定性结论样本：至少 5–10 个独立案例
重要结论：至少跨 1 个周期复看
```

## 四、表达

| 项 | 数 |
| --- | --- |
| 结论长度 | 1–3 句 |
| 依据条数 | 2–4 条 |
| 不确定性 | 至少 1 条，且要具体 |
| 给决策者 | ≤ 1 页，结论在前 1 屏 |

**最有用的一种句式**："若 X 成立则走 A，否则走 B"——它把决定点交回给对方。

## 五、数字怎么读

| 项 | 数 | 说明 |
| --- | --- | --- |
| 百分点 vs 百分比 | 2%→3%：+1 个百分点，+50% | 基数不同，别混用 |
| 回本涨幅 | 1/(1−跌幅)−1 | 跌 50% 需涨 100%，跌 80% 需涨 400% |
| 连续变化 | ∏(1+rᵢ)−1 | 涨 10% 再跌 10% = 99%，不是 100% |
| 右偏判据 | 平均数/中位数 > 1.5 | 收入、房价、延迟常见 |
| 延迟统计 | 必看 P50/P95/P99 | 平均会被少数慢请求拉高 |
| 粗略抽样误差 | ≈ 1/√n | n=100→±5pp，400→±2.5，1000→±1.6 |
| 子组稳定性 | 子组 < 100 不稳定 | 按误差公式推 |
| 基础率 | 罕见病阳性多为假阳性 | 0.1% 患病率 + 99% 准 → PPV ≈ 9% |
| 相关系数粗看 | \|r\| 0.1/0.3/0.5 | 仅作粗看，领域标准不同 |
| 多重检验 | 检验 20 个变量约 1 个"显著" | 假阳性提醒 |

## 六、逻辑

| 项 | 判据 |
| --- | --- |
| 论证三件套 | 前提 / 结论 / 隐含前提（至少找出 1 条） |
| 前提数 | 2–4 条，超过多有重复 |
| 链长 | > 3 环要逐环标注可信度 |
| 充分 | A → B，有 A 就够 |
| 必要 | ¬A → ¬B（等价 B → A），没 A 不行 |
| 充要 | A ↔ B，两个方向都要证 |
| 空真 | A 为假时 A → B 恒真 | 反例检查时要小心 |
| 逆否 | ¬B → ¬A 等价可用 |
| 逆命题 | B → A 不等价，不能直接用 |
| 反证 | 4 步，矛盾必须是逻辑矛盾 |
| 归谬 | 强度弱于反证，不构成证明 |

## 七、信息可信度

| 项 | 判据 |
| --- | --- |
| 来源分级 | 一手 > 评审/官方 > 机构综述 > 二手报道 > 匿名 |
| 独立来源 | 至少 2 家（非转载关系） |
| 追溯深度 | 至少追到一手（哪怕只读摘要） |
| 三查 | 口径 / 分母 / 时间范围，缺一不可 |
| 基数门槛 | < 30 个样本的比例变化不下结论 |
| 视觉检查 | 纵轴起点、是否双轴、面积是否按比例 |
| 时效 | 法规/价格/接口类超过 1 年要复核 |
| 可检验三要素 | 指标 + 幅度 + 时间窗 |
| 不知道三档 | 已验证 / 有依据但未验证 / 纯推测 |

## 八、概率与定义

| 项 | 数 | 说明 |
| --- | --- | --- |
| 期望值 | E = Σ pᵢvᵢ | 不回答"这一次" |
| 两层独立叠加 | 1 − (1−p)² | 99%→99.99%，90%→99% |
| 不独立 | 同源措施等于一层 | 先问"一个故障会不会同时打掉两层" |
| 三点估算 | (O+4M+P)/6，σ≈(P−O)/6 | 2/5/14 → 6 天 |
| 比例区间 | 95% 半宽 ≈ 1/√n | n=100→±10pp，400→±5pp，1000→±3pp |
| 罕见事件阳性 | 基础率 0.1% + 99% 准 → PPV ≈ 9% | 基础率 10% → PPV ≈ 92% |
| 定义结构 | 属 + 种差 | 各配 1 个反例检验 |
| 分类判据 | 互斥 + 穷尽 | 占比和应 = 100% |
| 类别数 | 3–7（超 9 分层） | "其他"占比 ≤ 10% |
| 类比用途 | 只提假设，不作证据 | 至少找 1 个关键差异 |

## 关于这些数

- **不是测量值**：这一域的数都是**判据与约束**（长度、条数、方向数），不是实验数据
- **实测**：0 条——这里没有可测的对象；数学部分的算例（均值 10/中位数 1、2%→3% 为 +50%、辛普森悖论 87% vs 67.8%、PPV≈9% 与 92%、彩票 0.282 元、三点估算 6 天、区间 ±9.8/±4.9/±3.1 个百分点）**均已用代码核验**
- **方法**：五要素、三段式、四段结构都是可操作框架，用不用取决于场景
- **会变的**：条数上限是"提醒你检查"的阈值，不是硬标准

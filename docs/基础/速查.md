# 速查：基础这一域的判断与数

> 这一域不讲"结论对不对"，讲**怎么把结论说清楚、怎么知道自己错了**。
> 所以这里的"数"多是**约束与判据**，不是测量值。

## 一、定义一个问题的五个位置

| 项 | 要求 | 反例 |
| --- | --- | --- |
| 对象 | 具体到可指认 | "系统""体验""效率" |
| 条件 | 范围与前提 | 不写并发、不写环境 |
| 对比 | 与什么相比 | "更好"没有参照 |
| 判据 | 怎么算达标 | "明显改善" |
| 边界 | 什么不算 | 范围无限扩张 |

**改写后长度 1–3 句**；超过说明还没想清。

## 二、事实与判断

| 项 | 判据 |
| --- | --- |
| 事实 | 换人换仪器能复核出同一结果 |
| 判断 | 不能独立复核，必须说明依据 |
| 概括词 | "都/从不/没人"出现即需证据 |
| 复核成本 | 好的事实句应能在 10 分钟内被他人复核 |
| 数字口径 | 同一名字的指标可能定义不同（活跃用户） |

## 三、找反例的强度

| 级别 | 含义 |
| --- | --- |
| 强 | 主动去最可能失败处找过，没找到 |
| 中 | 常规样本里没找到 |
| 弱 | 没找过，只是觉得对 |

```text
搜索方向 ≥ 5 个：极端值 / 边界 / 例外 / 时间 / 反方最强论据
定性结论样本：至少 5–10 个独立案例
重要结论：至少跨 1 个周期复看
```

## 四、表达

| 项 | 数 |
| --- | --- |
| 结论长度 | 1–3 句 |
| 依据条数 | 2–4 条 |
| 不确定性 | 至少 1 条，且要具体 |
| 给决策者 | ≤ 1 页，结论在前 1 屏 |

**最有用的一种句式**："若 X 成立则走 A，否则走 B"——它把决定点交回给对方。

## 关于这些数

- **不是测量值**：这一域的数都是**判据与约束**（长度、条数、方向数），不是实验数据
- **实测**：0 条——这里没有可测的对象
- **方法**：五要素、三段式、四段结构都是可操作框架，用不用取决于场景
- **会变的**：条数上限是"提醒你检查"的阈值，不是硬标准

# 逻辑

> 判断一个论证成不成立，以及坏论证通常长什么样。

## 收什么

- 谬误清单：每条带一个真实例子，说明它为什么错
- 论证结构模板：结论、前提、隐含假设分别是什么
- 可以逐步执行的检查：拿到一段话，按顺序问哪几个问题
- "这个说法在什么条件下才成立"——边界比结论重要

## 不收什么

- 形式逻辑教材内容（真值表、公理系统），除非确实用到
- 只列术语不给例子的词条

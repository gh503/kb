# 反证与归谬

## 结论

**反证是"假设它错，推出矛盾"；归谬是"假设它错，推出荒谬"。**
前者是严格证明，后者只是"看起来荒唐"——**两者强度差很多，常被混为一谈**。

## 两者的区别

| | 反证法 | 归谬法 |
| --- | --- | --- |
| 假设 | 结论为假 | 结论为真/为假 |
| 推出 | 逻辑矛盾（与已知事实/公理冲突） | 荒谬、不可接受、与常识冲突 |
| 强度 | 严格（若前提为真则结论必真） | 弱（"荒谬"是判断，不是矛盾） |
| 用途 | 数学证明 | 辩论、修辞 |

**"归谬"常被当成"反证"用**：它说服力强，但**不构成证明**。

## 反证法的四步

```text
1. 明确要证的结论 P
2. 假设 ¬P
3. 从 ¬P 推出矛盾（与已知定理、事实、或 ¬P 自身冲突）
4. 所以 P 成立
```

**"矛盾"必须是逻辑矛盾**：与已知为真的事实冲突，或推出 Q 且 ¬Q。

## 一个经典例子（√2 不是有理数）

```text
假设 √2 = p/q（p、q 互质）
则 2q² = p² → p² 是偶数 → p 是偶数 → 设 p = 2k
代入：2q² = 4k² → q² = 2k² → q 也是偶数
矛盾：p、q 都是偶数，与"互质"冲突
所以 √2 不是有理数
```

**"与自身假设冲突"是最干净的一种矛盾**。

## 归谬的典型用法

```text
"如果按这个逻辑，那偷一块钱和抢银行就没区别了。"
——推出一个对方也不接受的结论，让对方放弃前提
```

**它的力量在于"对方自己也不接受"**：所以是说服工具，不是证明工具。

## 什么时候用哪个

```text
要严格结论（数学、规格、协议） → 反证
要说服人放弃一个前提 → 归谬
只是觉得"这样下去不行" → 都不是证明，应标为判断
```

**"觉得荒唐"要标明是判断**（见通用基础的[事实与判断怎么分](../通用基础/事实与判断怎么分.md)）。

## 数字与阈值（公式/经验）

```text
反证步骤：固定 4 步
矛盾类型：与已知事实冲突 / 推出 Q 且 ¬Q / 与假设自身冲突
归谬强度：弱于反证，不可用于数学证明
链长：反证推导 > 5 步时，逐步检查每步是否可逆
```

## 证据强度

- **公式**：√2 无理数的反证过程属标准证明，可逐步验证
- **公开经验**：反证与归谬的强度差异、归谬的修辞用途
- **推断**："归谬不是证明"按矛盾的定义推的

## 不适用的情况

- 概率性命题：不能反证，只能给证据强度
- 价值判断：无"矛盾"可言，归谬只能暴露不一致

## 常见错法

- **把"荒谬"当"矛盾"**：归谬冒充反证
- **反证时用错假设**：假设了比 ¬P 更强的东西
- **推出"不方便"而不是"不可能"**

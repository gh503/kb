## 结论

**好定义 = 属 + 种差：先说它属于哪一类，再说它与同类其它成员差在哪。**
"属"保证不漏，"种差"保证不滥。

## 公式

```text
被定义项 = 属概念 + 种差

例： caffeine 是一种（属：生物碱）能兴奋中枢神经的（种差）化合物
```

**只给属不给种差 → 太宽**；只给种差不说属 → 无法归类。

## 三种定义，用途不同

| 类型 | 例子 | 适用 |
| --- | --- | --- |
| 内涵定义（属+种差） | 如上 | 概念澄清 |
| 外延定义（列举全部成员） | "本章的四种链是……" | 封闭集合 |
| 操作定义（怎么测） | "活跃用户 = 7 日内登录过 1 次" | 可执行、可核对 |

**"操作定义"在工程里最有用**：它把争论变成"能不能测"。

## 定义的四个常见毛病

```text
1. 循环：有效是因为它管用
2. 过宽：把不该算的也算进来
3. 过窄：把该算的排除在外
4. 含混：用比喻代替界定
```

**"循环"最隐蔽**：读起来通顺，实际什么也没说。

## 一个能自查的方法

```text
写完之后问两个问题：
  有没有该算进来却被排除的例子？（过窄）
  有没有不该算却被包含的例子？（过宽）
```

**各找一个反例，定义就稳了**（与[怎么找反例](../通用基础/怎么找反例.md)同一方法）。

## 数字与阈值（经验判断）

```text
定义长度：1–2 句（超过通常混了两件事）
反例检查：正反各至少 1 个
操作定义：必须含可测的指标与阈值
术语表：同一概念全站只用一个词
```

## 证据强度

- **公开经验**：属+种差、三种定义的用途、四类常见毛病
- **方法**：属加种差属传统逻辑方法（非实测）
- **推断**："各找一个反例定义就稳"按边界检查有效性推的

## 不适用的情况

- 数学原始概念（集合、点）：不加定义，作为公理起点
- 日常口语：不追求严格定义

## 常见错法

- **用比喻代替定义**："就像水管一样"
- **循环定义**
- **只给例子不给规则**

## 结论

**谬误不是"说错了"，而是"理由不支持结论"。**
所以检查方式统一：**这个理由，真的能让结论更可能成立吗？**

## 六类高频谬误

| 类型 | 长什么样 | 为什么错 |
| --- | --- | --- |
| 人身攻击 | 反对者水平不行 | 人的属性与主张真假无关 |
| 稻草人 | 把对方观点换成更弱的版本 | 驳倒的不是对方 |
| 诉诸权威 | 某专家这么说 | 权威也可能错、也可能超出领域 |
| 诉诸大众 | 大家都这么认为 | 人数不决定真假 |
| 滑坡 | 一旦 A 就会一路滑到 Z | 每一环都没被证明 |
| 循环论证 | 因为 A，所以 A（换个说法） | 前提已预设结论 |

**"稻草人"最常见**：它让人赢得辩论，却解决不了问题。

## 两类"看起来像谬误其实不是"

```text
诉诸权威（合理版）：引用该领域专家、且与其专业一致 → 弱证据但可用
诉诸大众（合理版）：作为"需求存在"的证据 → 可用，但不能证明"正确"
```

**"弱证据"不等于"无效证据"**：只是不能单独支撑强结论。

## 两个与数字有关的谬误

```text
基础率忽略：检测阳性就断定患病（罕见病里阳性多为假阳性）
幸存者偏差：只统计"还在的"，忽略已经消失的
```

**"幸存者偏差"在业务里极常见**：只看留下来的用户，得出"大家都满意"。

## 检查的三步

```text
1. 把理由与结论分开（见上一页）
2. 问：如果理由是假的，结论还成立吗？（依赖度）
3. 问：如果理由是真的，结论一定成立吗？（充分性）
```

**两步问完，八成谬误就出来了。**

## 数字与阈值（经验判断）

```text
依赖度检查：理由为假时结论是否崩塌
充分性检查：理由为真时结论是否唯一
滑坡链长：> 3 环且未证明 → 标记为滑坡
样本量：用"大家都"时，问具体多少人
```

## 证据强度

- **公开经验**：六类谬误的形态与"理由是否支持结论"的统一检查法
- **方法**：三步检查属可操作框架
- **推断**："八成谬误能查出"为经验估计，非实测

## 不适用的情况

- 修辞与说服（广告、演讲）：允许诉诸情感，目标是影响而非证明
- 数学证明：谬误形式不同（如循环论证需更严格判定）

## 常见错法

- **给对手最强版本**：驳稻草人（应重建最强版本再驳）
- **只贴标签**："你这是滑坡谬误"——标签不构成反驳
- **忽略合理版本的弱证据**

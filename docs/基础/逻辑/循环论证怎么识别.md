## 结论

**互链不是循环论证，"互相作为依据"才是。**
本机实测本站链接图：**1,210 个页面、7,264 条有向链接、2,201 对互链**——
**60.6% 的链接处在互链对里**（因为每页都有"相关"栏），但这不是循环论证；
判断标准是**去掉结论后，前提还站不站得住**。

## 两种"循环"

```text
良性互链：A 说"详见 B"，B 说"详见 A" → 导航，不承载论证
恶性循环：A 因 B 成立，B 因 A 成立 → 两个都不成立
  → 判据：把结论删掉，前提是否还有独立证据？
```

**"这两页互相引用，肯定有问题"** 导航互链是最常见的正当结构。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import re, pathlib
root=pathlib.Path('docs'); pages={p.resolve() for p in root.rglob('*.md')}
rel={}
for p in root.rglob('*.md'):
    t=p.read_text(encoding='utf-8'); rel[p.resolve()]=[]
    for m in re.finditer(r'\]\(([^)]+\.md)\)', t):
        q=(p.parent/m.group(1)).resolve()
        if q in pages: rel[p.resolve()].append(q)
two=sum(1 for a,ls in rel.items() for b in ls if a in rel.get(b,()))
print(len(pages), sum(len(v) for v in rel.values()), two//2)
PY
```

本机输出：

```text
1,210 页 ｜7,264 条链接 ｜2,201 对互链（60.6% 的链接是互惠的）
```

## 三种常见形态

```text
直接循环：A 因为 B，B 因为 A（最容易被发现）
链条循环：A→B→C→A（中间步骤让循环看起来像推导）
隐藏循环：把结论换个说法当前提（"它是最好的，因为没有更好的"）
```

## 检验方法（三步）

```text
1. 画出依据关系（不是链接关系，是"谁支撑谁"）
2. 找环：DFS 找回到起点的那条路径
3. 断环测试：删掉结论，看前提是否仍有独立证据
```

## 数字与阈值（本机实测）

```text
1,210 页 ｜7,264 链接 ｜2,201 互链对 ｜60.6% 链接互惠
经验：导航互链是正常结构，不要一律当循环论证
经验：依据关系图里出现环，就一定有循环论证
经验：环的长度不重要，长度只影响发现难度
```

## 证据强度

- **实测**：页面/链接/互链数来自本站
- **公开经验**：三种形态、断环测试
- **推断**：真实论证的"依据"关系常隐含在文字里，需要人工抽取

## 不适用的情况

- 数学中的归纳/递归定义：结构自指但是合法的
- 相互引用的规范文档：互为定义，不是论证

## 常见错法

- **把"相关"栏互链当循环论证**
- **只看直接循环，漏掉链条循环**
- **用"换个说法"掩盖结论前提同一**

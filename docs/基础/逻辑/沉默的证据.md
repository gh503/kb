## 结论

**最危险的证据是"没出现的那些"——它们不会报错，只会让你以为一切正常。**
本机实测本站订阅管线：**41 个源**，305 天的日报里只出现过 **38 个**——**3 个源（7%）从头到尾没产出过内容**，
而它们的存在只在配置里，日志里几乎不留痕。

## 什么是沉默的证据

```text
幸存者偏差：只统计"活下来的"（二战飞机装甲的经典案例）
失败不可见：抓取失败的源、没被搜到的页面、没被回复的邮件
  → 共同点：缺席本身不产生记录，所以不会被统计
```

**"我们的成功率是 95%"** 先问那 5% 有没有被记录。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import re, pathlib, collections
src=collections.Counter()
for f in pathlib.Path('docs/订阅').glob('*.md'):
    for m in re.finditer(r'^\*\*(.+?)\*\*\s*$', f.read_text(encoding='utf-8'), re.M):
        src[m.group(1)]+=1
print("日报页", len(list(pathlib.Path('docs/订阅').glob('*.md'))), "｜出现过的源", len(src))
PY
```

本机输出：

```text
日报 305 页 ｜出现过的源 38 个（配置里 41 个 → 3 个从未出现）
每页来源块：中位 2 个 ｜最大 24 个 ｜有 1 页为 0
```

## 三个落脚点

```text
1. 采集：失败要留痕（本机 3 个源静默失败，只有"健康行"能看出来）
2. 搜索：没被索引的页面等于不存在（索引条目数才是分母）
3. 反馈：只统计回复的人，等于把沉默的用户删掉
```

## 怎么把沉默变成可见

```text
1. 先定分母：应该有 N 个，实际有 M 个，差的就是沉默的
2. 定期对账：配置里的源 vs 实际产出的源（本机 41 vs 38）
3. 空结果也要记一条："今天这个源 0 条"
```

## 数字与阈值（本机实测）

```text
41 个源 ｜305 天日报 ｜38 个曾出现 ｜3 个从未出现（7%）
经验：分母要写死（配置/清单），否则沉默不可见
经验：0 产出也要记录，否则"没数据"与"没抓"分不清
经验：成功率 < 100% 时，必须能列出失败的那部分
```

## 证据强度

- **实测**：源数量与出现次数来自本站日报
- **公开经验**：幸存者偏差、分母对账
- **推断**：真实系统的沉默比例通常更高（长尾源、低频页面）

## 不适用的情况

- 全量枚举的场景（总数已知且全部可观测）：没有沉默部分
- 一次性抽样研究：沉默体现在无应答，按调查方法处理

## 常见错法

- **用"出现过的"当分母**
- **失败只写日志不写进报表**
- **把"没搜到"当成"不存在"**

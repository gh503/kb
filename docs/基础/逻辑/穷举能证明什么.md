## 结论

**在有限域上穷举，是唯一能"证明"的日常手段；而它最常用来推翻命题。**
本机穷举：4 元素域上"所有 A 都是 B"这类命题共 **240 条**，**175 条不成立（73%）**；
第一条反例是 `A={1}, B={}`——B 是空集，任取 A 里的元素都不在 B 里。

## 穷举能做什么、不能做什么

```text
能：有限域上的全称命题（"这 1000 条记录都满足"）→ 穷举即证明
不能：无限域（"所有整数""所有请求"）→ 只能证伪，不能证明
所以：穷举的价值一半在"确认"，一半在"找反例"
```

**"我测了 20 个用例都通过"** 不是证明，是"20 个样本没找到反例"。

## 本机可复现（已跑）

```bash
python3 - <<'PY'
from itertools import combinations
U=list(range(1,5))
subs=[set(s) for r in range(5) for s in combinations(U,r)]
claims=hold=fail=0
for A in subs:
    for B in subs:
        if not A: continue
        claims+=1
        if A<=B: hold+=1
        else: fail+=1
print(claims, hold, fail, f"{fail/claims:.0%}")
PY
```

本机输出：

```text
4 元素域上：240 条命题，成立 65，不成立 175（73%）
```

## 为什么反例这么多

```text
1. 空集：B=∅ 时，只要 A 非空就失败（最容易忘的边界）
2. 单元素：A 只含一个元素时，命题退化成"这个元素在 B 里"
3. 补集：A 与 B 交集为空但都非空
  → 手工想反例时，绝大多数人只想到"典型情况"
```

**"这个命题显然成立"** 在 4 元素域上就有 73% 的概率不成立。

## 怎么用穷举

```text
1. 把命题写成可判定的形式（代码能返回 true/false）
2. 域尽量小但覆盖边界（空、单元素、全集）
3. 穷举后：要么给出证明，要么给出具体反例
```

## 数字与阈值（本机计算）

```text
4 元素域：240 条全称命题，175 条不成立（73%）
第一条反例：A={1}、B=∅
经验：反例优先找空集、单元素、全集三种边界
经验：测试用例数不能替代"域的全覆盖"——除非域本身有限且已被穷举
```

## 证据强度

- **计算**：240/65/175 由枚举得出，可复现
- **公开经验**：边界优先、有限域可穷举
- **推断**：真实系统中"域"常常不可枚举，穷举退化为抽样

## 不适用的情况

- 无限域（所有自然数、所有请求）：穷举不成立，只能证明反例
- 命题本身含模糊词（"更快""更稳"）：先定义才能判定

## 常见错法

- **把"没找到反例"当成"命题成立"**
- **穷举时漏掉空集与单元素**
- **域取得太大，跑不完却以为跑完了**

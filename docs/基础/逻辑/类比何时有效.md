## 结论

**类比只能用来"提出假设"，不能用来"证明结论"。**
它有效的前提是：**两个事物在关键结构上相似，而不只是在表面相似**。

## 好类比与坏类比的差别

| | 相似的是什么 | 作用 |
| --- | --- | --- |
| 好类比 | 关系结构（A 之于 B 如同 C 之于 D） | 帮助理解、生成假设 |
| 坏类比 | 表面特征（都是圆的、都有名字） | 误导 |

**"结构相似"才是类比的力量来源**：水的流动与电流，共享"压力差驱动流量"的结构。

## 一个检查方法

```text
1. 类比想说明的是什么关系？（不是"像什么"，是"怎么像"）
2. 这个关系在两边都成立吗？
3. 有没有关键差异会让结论失效？
```

**第 3 问最重要**：所有类比都有差异，关键是差异是否影响结论。

## 三个常见的坏用法

```text
1. 用类比当证据："公司就像家庭，所以不能裁员"（家庭不签劳动合同）
2. 忽略规模差异：小团队的做法套到千人组织
3. 忽略约束差异：免费产品套到收费产品
```

**"规模"与"约束"是最常被忽略的两个差异**。

## 什么时候类比特别有用

```text
解释陌生概念（用听众熟悉的领域）
生成新假设（"如果像 X 那样，会不会……"）
发现结构共性（不同领域的同一类问题）
```

**"生成假设"是类比最正当的用途**：它给方向，然后由验证来定真假。

## 一句可操作的规则

```text
类比说"可以这样想"，不说"因此就是这样"。
```

**把类比放在"往下追"的位置**，而不是"结论"的位置。

## 数字与阈值（经验判断）

```text
类比检查：至少找出 1 个关键差异
用途限定：假设生成可用，结论支撑不可用
规模差异：跨 10 倍以上要重新检验
```

## 证据强度

- **公开经验**：结构类比与表面类比的区分、类比的假设生成用途
- **方法**：三问检查属可操作框架
- **推断**："10 倍规模要重新检验"为经验阈值

## 不适用的情况

- 数学同构：结构完全对应，可用于证明
- 严格的形式化建模：不需要类比

## 常见错法

- **用类比代替论证**
- **只挑相似点，不看差异**
- **跨规模直接套用**

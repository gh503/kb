## 结论

**演绎是"全或无"，归纳是"区间宽窄"。比较归纳论证，就是比较区间。**
本机算：观察成功率 80% 时，95% 置信区间在 **n=10 是 ±24.8 个百分点**、**n=100 是 ±7.8**、
**n=1000 是 ±2.5**、**n=10000 是 ±0.8**——**样本量涨 1000 倍，精度只涨 31 倍**（√n 规律）。

## 两种强度

```text
演绎：前提真 → 结论必然真（可判定，只有对错）
归纳：前提真 → 结论大概率真（强度 = 区间宽度 / 证据覆盖）
  → 比"谁更有说服力"，就是比"谁的区间更窄且样本更代表总体"
```

**"数据支持这个结论"** 要问：区间多宽？样本从哪来？

## 本机可复现（已算）

```bash
python3 - <<'PY'
import math
for n in (10,100,1000,10000):
    se=math.sqrt(0.8*0.2/n)
    print(n, round(1.96*se*100,1))
PY
```

本机输出：

```text
n=10   ±24.8 个百分点
n=100  ±7.8
n=1000 ±2.5
n=10000 ±0.8
```

## √n 规律的含义

```text
精度 ∝ 1/√n
  → 要把误差减半，样本要变 4 倍
  → 要把误差减到 1/3，样本要变 9 倍
所以"再测 1000 条"不一定让结论更可靠，可能只是把 ±2.5 变成 ±2.4
```

**"样本越多越好"** 到一定程度就不值了；先看区间是否已够窄。

## 比强度时要问的四件事

```text
1. 样本量（决定区间宽度）
2. 抽样方式（决定能否外推：随机、分层、方便抽样）
3. 是否有对照（同期、同环境）
4. 效应量 vs 区间（效应小于区间宽度 = 分不出）
```

## 数字与阈值（本机计算）

```text
80% 成功率的 95% 区间：n=10 ±24.8｜100 ±7.8｜1000 ±2.5｜10000 ±0.8（百分点）
样本 ×4 → 区间 ÷2（√n）
经验：A/B 实验每组至少几百个转化，否则区间盖住差异
经验：效应量小于区间宽度时，结论应是"分不出"
```

## 证据强度

- **计算**：区间为公式直算（正态近似）
- **公开经验**：√n、效应量与区间比较
- **推断**：真实比例接近 0 或 1 时正态近似失效，要换精确方法

## 不适用的情况

- 全量数据（总体已穷举）：没有抽样误差，区间退化为 0
- 演绎论证：不涉及区间

## 常见错法

- **拿 n=10 的结论去指导全量决策**
- **只看 p 值不看效应量**
- **把"统计显著"当成"重要"**

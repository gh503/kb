# 边界案例

> **深度** 实操 ｜ **类型** 边界 ｜ **链** 定义与分类

## 结论

**定义的真正质量，在边界案例上才看得出来。**
核心成员总能分对；分不清的那一类，才暴露定义缺了什么。

## 三类成员

```text
典型成员：毫无疑问属于（麻雀是鸟）
边缘成员：有争议但多数人认为属于（企鹅是鸟吗）
非成员：毫无疑问不属于（蝙蝠不是鸟）
```

**"边缘成员"是定义的试金石**：它逼你说清"哪条特征才是决定性的"。

## 三种边界形态

| 形态 | 例子 | 处理 |
| --- | --- | --- |
| 连续谱 | 秃头、高矮 | 定阈值，并承认是约定 |
| 多特征交叉 | 什么是"游戏" | 家族相似，列必要不充分特征 |
| 制度约定 | 什么是"成年人" | 按法律，不按生物学 |

**"连续谱"不要假装有本质边界**：说"这是约定阈值"比硬辩更诚实。

## 一个可操作的流程

```text
1. 列出 5–10 个典型成员
2. 列出 5–10 个明显非成员
3. 造 5 个"故意为难"的边界案例
4. 看你的定义能否一致地处理它们
5. 处理不了 → 定义缺条件
```

**"故意为难"是关键**：不要用容易的例子自证。

## 边界案例的两种结论

```text
结论一：定义需要补条件（多数情况）
结论二：这本来就是约定，边界由规则定（阈值类）
```

**分清这两者**，能避免大量无意义的争论。

## 数字与阈值（经验判断）

```text
典型成员：5–10 个
非成员：5–10 个
边界案例：≥ 5 个
争议处理：超过 3 个案例无法一致归类 → 定义需重写
```

## 证据强度

- **公开经验**：典型/边缘/非成员三分、连续谱与家族相似的处理
- **方法**：五步流程属可操作框架
- **推断**："3 个以上归类不一致要重写"为经验阈值

## 不适用的情况

- 数学概念：边界由定义精确决定，不存在模糊
- 法律术语：边界由司法解释确定

## 常见错法

- **只用典型例子验证定义**
- **把约定边界当本质边界**
- **回避边界案例**："这种少见情况不重要"

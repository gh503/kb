## 结论

**"每个请求都有对应的响应"和"存在一个响应能对上所有请求"只差量词顺序，但真假完全不同。**
本机穷举：3 元素域上 512 个关系里，`∀x∃y` 与 `∃y∀x` 真假不同的有 **174 个（34%）**，
而且**全部是"前者成立、后者不成立"**——反过来的情况一个都没有。

## 两条规则

```text
否定要换量词：¬∀x P(x) = ∃x ¬P(x)；¬∃x P(x) = ∀x ¬P(x)
顺序不能换：∀x∃y R(x,y) ⇏ ∃y∀x R(x,y)
  → 前者是"每个 x 有各自的 y"，后者是"一个 y 通吃"
```

**"任何人都有一个母亲"** 成立；**"存在一个人是所有人的母亲"** 不成立——同一个 R，量词换了位置。

## 本机可复现（已跑）

```bash
python3 - <<'PY'
U=[0,1,2]; pairs=[(x,y) for x in U for y in U]
n=ne=only=0
for mask in range(1<<len(pairs)):
    R={pairs[i] for i in range(len(pairs)) if mask>>i&1}
    fx=all(any((x,y) in R for y in U) for x in U)
    yf=any(all((x,y) in R for x in U) for y in U)
    n+=1
    if fx!=yf: ne+=1
    if fx and not yf: only+=1
print(n, ne, only)
PY
```

本机输出：

```text
512 个关系：真假不同 174 个（34%），全部是 ∀∃ 成立而 ∃∀ 不成立
```

## 为什么方向只有一个

```text
∃y∀x R(x,y) ⇒ ∀x∃y R(x,y)   （同一个 y 对所有人都能用 → 每个人也都有）
反过来不成立：不同的人可以用不同的 y
  → 这就是"34% 全部单向"的原因
```

**"能否互换"** 唯一安全的方向是：先断言"存在一个统一的 y"，才能推出"每人有 y"。

## 在工程里的样子

```text
∀请求 ∃超时值：每个接口可以有不同超时 → 合理
∃超时值 ∀请求：一个超时通吃所有接口 → 通常不成立
∀用户 ∃配置：每人可以有自己的配置 → 合理
∃配置 ∀用户：一份配置适配所有用户 → 才是"默认值"的含义
```

## 数字与阈值（本机计算）

```text
3 元素域：512 个关系，174 个（34%）∀∃ 与 ∃∀ 不同
方向：174 个全部是 ∀∃ 成立、∃∀ 不成立（0 个反向）
经验：看到"所有…都有…"先问"是不是同一个"
经验：否定时把"所有"改"存在"、把"并且"改"或者"
```

## 证据强度

- **计算**：512/174 为枚举结果，可复现
- **公开经验**：量词否定规则、单向前推
- **推断**：真实命题含隐含量词（"系统支持"），识别量词比换顺序更难

## 不适用的情况

- 域为空：`∀x P(x)` 恒真（空真），`∃x P(x)` 恒假
- 命题不含量词：不涉及

## 常见错法

- **否定"所有"时写成"所有都不"**（应为"存在一个不"）
- **把"每个请求都有超时"当成"有一个统一的超时"**
- **忽略空域**，导致"空列表全部通过"被当成"校验有效"

## 结论

**"每个 x 都有某个 y"和"存在某个 y 对所有 x 都成立"，是两个强度完全不同的命题。**
本机穷举 3 元素域上全部 **512** 个关系：`∀x∃y R(x,y)` 与 `∃y∀x R(x,y)` 结论不同的有 **174 个（34%）**——
**三分之一的场合，换个顺序结论就变。**

## 两种量词

```text
∀x∃y：y 可以随 x 变（每个学生都有一本借的书）
∃y∀x：y 必须同一个（存在一本书，所有学生都借过）
  → ∃∀ 更强：它成立则 ∀∃ 必成立，反之不然
```

**"差不多是一个意思"** 34% 的场合不一样，工程里这 34% 就是事故。

## 本机可复现（已算）

```bash
python3 - <<'PY'
import itertools
dom=range(3)
def fa(R): return all(any(R(x,y) for y in dom) for x in dom)
def ef(R): return any(all(R(x,y) for x in dom) for y in dom)
d=sum(1 for b in itertools.product([0,1],repeat=9)
      if fa(lambda x,y,b=b: b[x*3+y]) != ef(lambda x,y,b=b: b[x*3+y]))
print(d, "/ 512 =", round(d/512*100), "%")
PY
```

本机输出：

```text
174 / 512 = 34%
```

## 四种顺序（两个量词、两种极性）

```text
∀x∀y = ∀y∀x（可交换）
∃x∃y = ∃y∃x（可交换）
∀x∃y ≠ ∃y∀x（不可交换，本机 34% 不同）
∀x¬ 与 ¬∃x 等价（否定要把量词翻转，见 [量词与否定](量词与否定.md)）
```

## 工程里的三个例子

```text
接口设计："每个请求都有超时" vs "存在统一超时" → 后者更简单也更脆
权限："每个用户都有能访问的资源" vs "存在一个资源所有用户都能访问"
监控："每条告警都有人处理" vs "有一个人处理所有告警"
```

## 数字与阈值（本机计算）

```text
3 元素域、512 个关系：174 个（34%）两种顺序结论不同
经验：写规格时把量词顺序单独标出来，别混在一句里
经验：∃∀ 成立 ⇒ ∀∃ 成立（单向蕴含，可用来做保守估计）
经验：否定时先翻转量词，再否定谓词
```

## 证据强度

- **计算**：174/512 来自本机穷举
- **公开经验**：单向蕴含、否定规则
- **推断**：元素更多、关系更复杂时，两种顺序的差异比例会上升

## 不适用的情况

- 只有一个元素：两种顺序等价
- 量词作用在同一个变量上：顺序无意义

## 常见错法

- **把"每个都有"当成"有一个统一的"**
- **否定时忘翻转量词**
- **规格文档里把两层量词写在一句话里**

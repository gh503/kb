# 高等数学

> 这一科只回答一件事：**数值算出来的东西，能信几位。**
> 不讲证明，讲误差从哪来、阶数怎么验、步长怎么选——每页都有本机实测。

## 收什么

- 导数的两种差分近似与误差阶
- 为什么 h 不能取太小（U 形误差曲线）
- 泰勒展开的收敛半径与"能信几项"
- 浮点误差的三个来源
- 数值积分的阶数、梯度下降的步长边界

## 不收什么

- 严格的 ε-δ 证明
- 微分方程数值解（Runge-Kutta 等）
- 测度与实分析

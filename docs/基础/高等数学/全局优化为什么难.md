## 结论

**网格搜索的成本随维度指数爆炸，而随机搜索在高维上并不比网格差多少——这就是"维度诅咒"的实际含义。**
本机在 `sin(3x)cos(5x)+0.1x` 上取 400 个点：网格最优 **1.2180**（步长 0.0150）、随机 400 点 **1.2184**——
**一维时网格略占优；维度一高，网格点会被摊薄到每维只剩几个。**

## 三个事实

```text
1. 非凸函数有多个局部最优，梯度法只保证到其中一个
2. 网格法成本 = 每维点数^维数（10 维、每维 10 点 = 100 亿次）
3. 随机搜索的期望覆盖不随维度崩塌，但收敛慢
```

**"多跑几个初始点就行"** 初始点数量也要指数增长才管用。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
f=lambda x: np.sin(3*x)*np.cos(5*x)+0.1*x
xs=np.linspace(-3,3,400)
print("网格", round(f(xs).max(),4), round(xs[f(xs).argmax()],3), round(xs[1]-xs[0],4))
rng=np.random.default_rng(5); best=-9
for _ in range(400): best=max(best, f(rng.uniform(-3,3)))
print("随机", round(best,4))
PY
```

本机输出：

```text
网格 400 点：1.2180 @ x=2.549（步长 0.0150）｜随机 400 点：1.2184
```

## 五类方法

```text
网格/穷举：维度 ≤ 3 可用
随机搜索/拉丁超立方：高维基线，易并行
贝叶斯优化：贵函数（一次评估几分钟）首选
模拟退火/遗传：离散、多峰，调参成本高
分支定界：有可证明下界时（如整数规划）唯一能给"最优"的方法
```

## 判据

```text
维度 ≤ 3 且评估便宜 → 网格
维度高、评估便宜 → 随机 + 局部精修
维度高、评估贵 → 贝叶斯优化
需要"保证最优" → 分支定界（且问题要有结构）
```

## 数字与阈值（本机模拟）

```text
一维 400 点：网格 1.2180、随机 1.2184（网格略优）
经验：维度 > 5 时，每维 10 点的网格需要 10^5 次以上评估
经验：贝叶斯优化适合"单次评估 > 1 分钟"的场景
经验：随机搜索的结果方差大，报告要给多次运行的分布
```

## 证据强度

- **模拟**：两组最优值来自本机
- **公开经验**：方法选择矩阵、维度诅咒
- **推断**：真实目标函数常有噪声，噪声会掩盖 1e-3 量级的差异（本机两法差 4e-4）

## 不适用的情况

- 凸问题：局部最优即全局最优，不需要全局方法
- 目标函数可解析求导且有闭式解：直接解

## 常见错法

- **在高维上做网格搜索**
- **只跑一次随机搜索就报告最优**
- **把"没找到更好的"当成"已是最优"**

## 结论

**导数是"局部斜率"，用差分近似时，前向差分的误差 ∝ h，中心差分 ∝ h²。**
本机实测：h=1e-4 时，前向误差 4.2e-5，中心误差 9.0e-10——**差四个数量级**。

## 定义与两种近似

```text
f'(x) = lim (f(x+h)-f(x))/h
前向： (f(x+h)-f(x))/h          误差 ∝ h
中心： (f(x+h)-f(x-h))/(2h)     误差 ∝ h²
```

**"中心差分"多算一次函数值，换来一阶精度提升**，几乎总是值得。

## 本机可复现（已实测）

```python
f  = lambda x: np.sin(x)
df = lambda x: np.cos(x)
for h in (1e-2, 1e-4, 1e-6, 1e-8, 1e-12):
    fwd = (f(1+h)-f(1))/h
    ctr = (f(1+h)-f(1-h))/(2*h)
    print(h, abs(fwd-df(1)), abs(ctr-df(1)))
```

本机输出（numpy 1.21.5，x=1）：

```text
         h      前向误差      中心误差
     1e-02   4.216e-03   9.005e-06
     1e-04   4.207e-05   9.004e-10
     1e-06   4.207e-07   2.772e-11
     1e-08   2.970e-09   2.581e-09
     1e-12   4.324e-05   1.227e-05
```

**看两列怎么变**：前向每缩小 10 倍误差降 10 倍（∝h），中心降 100 倍（∝h²）。
**但 h=1e-12 时两者都变差**——那是浮点误差接管了（下一节）。

## 导数在工程里的三个用法

| 用法 | 说明 |
| --- | --- |
| 优化 | 梯度方向决定往哪走 |
| 灵敏度 | "参数变 1% 结果变多少" |
| 线性化 | 小扰动下把非线性当线性 |

**"灵敏度分析"是最被低估的用法**：它比跑一遍实验便宜得多。

## 数字与阈值（本机实测 + 公式）

```text
前向差分误差 ≈ |f''|·h/2 ｜ 中心差分 ≈ |f'''|·h²/6
本机：h=1e-4 时 4.2e-5 vs 9.0e-10
最优 h 量级：前向 √ε≈1e-8，中心 ε^(1/3)≈6e-6
```

## 证据强度

- **实测**：五行误差为本机输出
- **公式**：两种差分的截断误差阶
- **推断**："最优 h"按截断误差与舍入误差平衡推的

## 不适用的情况

- 函数不可导/有噪声：差分会被噪声放大，要先平滑
- 高维：逐维差分成本 O(n)，应改用自动微分

## 常见错法

- **用前向差分还抱怨精度低**
- **把 h 取到 1e-15 求更准**
- **在有噪声的数据上直接差分**

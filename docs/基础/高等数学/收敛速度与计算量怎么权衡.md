## 结论

**"收敛快"要按总代价算，不是按迭代次数算。** 牛顿法步数少但每步要解线性方程组；
条件数 100 时梯度下降要 709 步，牛顿法通常 5–10 步，但每步 O(n³)。

## 三种方法的账

| 方法 | 步数 | 每步代价 | 适用 |
| --- | --- | --- | --- |
| 梯度下降 | ∝ κ·log(1/ε) | O(n) | 大规模、简单 |
| 牛顿法 | ≈ log log(1/ε) | O(n³) | 中小规模、要精度 |
| 拟牛顿（BFGS） | 介于两者 | O(n²) | 中等规模 |

**"步数 × 每步代价"** 才是可比的口径。

## 本机可复现（已实测）

```python
# 条件数 100 的二次问题，最优步长 2/(λmax+λmin)
# 梯度下降：709 步到 1e-6（见上一节）
# 牛顿法：一步到位（二次函数）
```

本机输出（条件数 2/10/100 的梯度下降步数）：

```text
条件数    2: 13 步
条件数   10: 71 步
条件数  100: 709 步
```

**二次函数上牛顿法 1 步**，但每步要算 Hessian 并求逆。

## 什么时候该换方法

```text
n 小（< 1000）且要高精度 → 牛顿/拟牛顿
n 大（> 1e6）→ 梯度下降/SGD/Adam
条件数大 → 先预条件/标准化，再谈方法
```

**"先降条件数，再选算法"** 的顺序不能反。

## 精度与代价的边界

```text
双精度下，迭代到 1e-12 之后基本是噪声
数值积分到 1e-8 之后加段数没意义
蒙特卡洛要 1e-6 精度需要 1e12 样本 → 不可行
```

**"精度有天花板"**：每种方法都有自己的极限，超过就是浪费算力。

## 数字与阈值（本机实测 + 经验）

```text
梯度下降步数：κ=2/10/100 → 13/71/709
牛顿法：二次函数 1 步；一般问题 5–10 步到高精度
每步代价：GD O(n)｜BFGS O(n²)｜牛顿 O(n³)
经验：n<1e3 可考虑二阶；n>1e6 只用一阶
经验：迭代到 1e-12 以下通常无意义
```

## 证据强度

- **实测**：三档步数为本机输出
- **公式**：GD 步数 ∝ κ、牛顿法二次收敛
- **公开经验**：规模与方法的选择阈值

## 不适用的情况

- 非凸/随机目标：牛顿法的假设不成立
- 约束优化：要换成内点法/投影梯度

## 常见错法

- **只看迭代次数不看每步代价**
- **在小规模问题上用 SGD**
- **追求超过浮点精度的收敛**

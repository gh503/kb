## 结论

**步长必须小于 2/最大特征值。** 本机实测（特征值 1 与 10，阈值 2/10=0.2）：
lr=0.19 收敛，**lr=0.2 正好卡在边界、来回振荡不下降**，lr=0.21 缓慢发散，lr=0.3 五步就爆到 1e6。

## 为什么是 2/λmax

```text
每步：x ← x - lr·A·x = (I - lr·A)x
收敛要求所有 |1 - lr·λᵢ| < 1
→ 0 < lr < 2/λmax
```

**"边界值 2/λmax 不收敛"**：此时某个方向的因子正好是 -1，永远在两端跳。

## 本机可复现（已实测）

```python
A = np.diag([1.0, 10.0])      # 特征值 1 与 10 → 阈值 0.2
x = np.array([1.0, 1.0])
for _ in range(50):
    x = x - lr * (A @ x)
```

本机输出（50 步后）：

```text
lr=0.01  收敛  末步 6.050e-01
lr=0.1   收敛  末步 5.154e-03
lr=0.19  收敛  末步 5.154e-03
lr=0.2   不收敛 末步 1.000e+00   ← 卡在边界，来回振荡
lr=0.21  发散  末步 1.174e+02
lr=0.3   发散  末步 1.049e+06
```

**lr=0.2 的末步正好是 1.0**：x 在 (1,1) 与 (-1,1) 之间来回跳，范数不变。

## 条件数决定要多少步

```text
条件数 κ = λmax/λmin
最优步长 lr = 2/(λmax+λmin)
所需步数 ≈ (κ/2)·log(1/ε)
```

本机实测（目标 1e-6）：

```text
条件数    2: 最优步长 0.6667，13 步
条件数   10: 最优步长 0.1818，71 步
条件数  100: 最优步长 0.0198，709 步
```

**条件数 ×10，步数也 ×10**——这就是"病态问题慢"的定量版本。

## 实务上怎么办

```text
1. 标准化特征（降条件数）
2. 用自适应步长（Adam/线搜索）
3. 用二阶信息（牛顿法，步数少但每步贵）
4. 预条件（把问题变换成条件数小的等价问题）
```

**"标准化"最便宜**：把特征缩放到同一量级，条件数立刻下降。

## 数字与阈值（本机实测）

```text
特征值 1/10：收敛上界 lr=0.2
lr=0.19 收敛；0.2 振荡；0.21 发散；0.3 爆到 1e6
条件数 2/10/100 → 13/71/709 步（到 1e-6）
经验：lr 从 1/λmax 的 1/10 起调
```

## 证据强度

- **实测**：六行末步与三行步数均为本机输出
- **公式**：收敛条件 0<lr<2/λmax、步数 ≈ κ/2·log(1/ε)
- **公开经验**：标准化与预条件

## 不适用的情况

- 非凸问题：没有全局 λmax，只能局部讨论
- 随机梯度：噪声会让"边界"变得模糊

## 常见错法

- **把 lr 调大到"刚好不报错"**
- **不标准化特征就调 lr**
- **以为"loss 不降"是模型问题**（可能是发散）

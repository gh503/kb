## 结论

**泰勒展开只在收敛半径内可信，且误差随 x 增大迅速变差。**
本机实测：`e^x` 在 x=1 时 n=10 误差 2.7e-8，**在 x=10 时 n=20 误差还有 35**。

## 展开式与误差

```text
e^x = 1 + x + x²/2! + x³/3! + …
误差 ≈ 下一个被丢掉的项
```

**"误差 ≈ 第一个省略项"** 是判断该取几项的最快办法。

## 本机可复现（已实测）

```python
def exp_taylor(x, n):
    s, term = 0.0, 1.0
    for k in range(n+1):
        s += term; term *= x/(k+1)
    return s
for x in (1.0, 5.0, -5.0, 10.0):
    print(x, abs(exp_taylor(x,10)-math.exp(x)))
```

本机输出（numpy 1.21.5）：

```text
x=  1.0: n=5 1.62e-03 ｜ n=10 2.73e-08 ｜ n=20 4.44e-16
x=  5.0: n=5 5.70e+01 ｜ n=10 2.03e+00 ｜ n=20 1.20e-05
x= -5.0: n=5 1.23e+01 ｜ n=10 8.57e-01 ｜ n=20 7.59e-06
x= 10.0: n=5 2.05e+04 ｜ n=10 9.18e+03 ｜ n=20 3.50e+01
```

**x=10 时取 20 项误差还有 35**：这一项是 10²¹/21! 级别，看起来小，但前面已经加到了 e¹⁰ ≈ 22026。

## 收敛半径是什么

```text
幂级数 Σ aₙxⁿ 只在 |x| < R 内收敛
R 由最近的奇点决定
例：1/(1-x) 的 R=1，x=1.1 时发散
```

本机验证（`1/(1-x)` 在 x=1.1 展开）：

```text
前 0 项和 0.000e+00   真值 -10
前 10 项和 1.594e+01
前 20 项和 5.727e+01
前 30 项和 1.645e+02   ← 越加越远
```

**"越加越远离真值"** 就是发散的典型表现，和"误差缓慢下降"完全不同。

## 实务上怎么用

```text
1. 先算 |x| 与收敛半径的关系
2. 用"第一个省略项"估误差
3. 超过半径就换方法（缩小自变量、用其他展开、数值求解）
```

**"缩小自变量"最实用**：`e^10 = (e^1)^10`，先在小范围内展开再乘方。

## 数字与阈值（本机实测）

```text
e^x 在 x=1：n=10 → 2.7e-8；n=20 → 4.4e-16（机器精度）
e^x 在 x=5：n=20 → 1.2e-5
e^x 在 x=10：n=20 → 35
几何级数在 x=1.1（R=1）：发散
经验：|x| < R/2 时前 10 项通常够用
```

## 证据强度

- **实测**：exp 三档与几何级数发散为本机输出
- **公式**：截断误差 ≈ 首个省略项、收敛半径由奇点决定
- **推断**："|x|<R/2 前 10 项够用"是经验判据

## 不适用的情况

- 非解析函数（含 |x|、分段）：泰勒展开不成立
- 需要严格误差上界：要算余项，不能只看首项

## 常见错法

- **不管收敛半径直接展开**
- **用"项数多"代替"误差小"**
- **在 x 很大时还硬用泰勒**

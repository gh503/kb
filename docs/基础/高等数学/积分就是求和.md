## 结论

**定积分是"把面积切成无数细条再相加"，数值积分就是"切有限条"。**
本机实测：∫₀^π sin x dx 用 n=10 的梯形法误差 1.6e-2，n=160 时降到 6.4e-5。

## 三种"求和"

```text
左/右矩形：每段取端点值     误差 ∝ h
梯形：每段用两端平均         误差 ∝ h²
辛普森：每段用抛物线拟合     误差 ∝ h⁴
```

**"精度阶"就是误差随 n 下降的速度**，下一节用数据验证。

## 本机可复现（已实测）

```python
g = lambda x: np.sin(x)
np.trapz(g(np.linspace(0, np.pi, n+1)), np.linspace(0, np.pi, n+1))
# 真值 ∫0^π sin = 2
```

本机输出（numpy 1.21.5）：

```text
n=  10  梯形误差 1.648e-02
n=  20  梯形误差 4.114e-03
n=  40  梯形误差 1.028e-03
n=  80  梯形误差 2.570e-04
n= 160  梯形误差 6.426e-05
```

**n 每翻倍，误差降到 1/4** —— 这就是二阶精度。

## 积分在工程里的样子

| 场景 | "积分"是什么 |
| --- | --- |
| 概率 | 密度函数下的面积 = 概率 |
| 功耗 | 功率对时间积分 = 电量 |
| 流量 | 速率对时间积分 = 总量 |
| 损失 | 逐样本损失求和 = 经验风险 |

**"求和即积分"**：数据是离散的，但含义是连续的。

## 数字与阈值（本机实测 + 公式）

```text
∫0^π sin = 2
梯形误差：n=10 时 1.6e-2；n=160 时 6.4e-5（每翻倍 /4）
辛普森误差：n=10 时 1.1e-4；n=160 时 1.7e-9（每翻倍 /16）
经验：要 1e-6 精度，梯形约需 1e4 段，辛普森约需 300 段
```

## 证据强度

- **实测**：梯形五行误差为本机输出
- **公式**：梯形 O(h²)、辛普森 O(h⁴)
- **推断**："1e-6 所需段数"由误差阶反推

## 不适用的情况

- 被积函数有奇点：要先做变量替换
- 高维积分：网格法维度灾难，改用蒙特卡洛

## 常见错法

- **段数太少就下结论**
- **对有尖峰的関数用均匀网格**
- **把"求和"当"积分"却忘了乘步长**

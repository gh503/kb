## 结论

**迭代法的收敛速度可以事先算出来，而且算得很准。**
本机 1D Poisson（n=64）、Jacobi 迭代：**2,000 步后相对误差 9.66e-2**；
理论谱半径 `ρ = cos(πh) = 0.998832`，`ρ^2000 = 9.66e-2`——**两行数学就预测了 2,000 步的结果。**

## 三个概念

```text
稀疏：矩阵里绝大多数是 0（本机 64×64 三对角，非零只占 4.6%）
迭代：不分解矩阵，反复用"上一步 × 矩阵"逼近解
收敛率：误差每步乘一个因子 ρ（谱半径），ρ 越接近 1 越慢
```

**"迭代总比直接解慢"** 稀疏大矩阵上，直接分解会填满成稠密矩阵。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np, math
n=64; h=1/(n+1)
A=(np.diag(2*np.ones(n))-np.diag(np.ones(n-1),1)-np.diag(np.ones(n-1),-1))/h**2
b=np.ones(n); x=np.zeros(n); ex=np.linalg.solve(A,b)
for k in range(1,2001):
    x=x+(b-A@x)/(2/h**2)
    if k in (100,1000,2000): print(k, "%.2e" % (np.linalg.norm(x-ex)/np.linalg.norm(ex)))
print("rho", "%.6f" % math.cos(math.pi*h), "rho^2000", "%.2e" % (math.cos(math.pi*h)**2000))
PY
```

本机输出：

```text
100 步 8.89e-01 ｜1,000 步 3.11e-01 ｜2,000 步 9.66e-02
ρ = 0.998832 ｜ρ^2000 = 9.66e-02（与实测一致）
```

## 判据：什么时候能用

```text
矩阵稀疏（非零 < 5%）：迭代法是首选
条件数大（病态）：Jacobi 会慢到不可用，需要预条件
精度要求 1e-6：本机 ρ=0.9988 时需要约 ln(1e-6)/ln(ρ) ≈ 1.2 万步
```

**"多迭代几次就好了"** 步数随 1/(1−ρ) 增长，ρ=0.999 时要十万步量级。

## 加速的四条路

```text
1. 换方法：共轭梯度（对称正定）、GMRES（一般矩阵）
2. 预条件：把谱半径拉离 1（对角/ILU/多重网格）
3. 多重网格：误差的低频部分用粗网格解 → 接近 O(n)
4. 更松的精度 + 外层迭代
```

## 数字与阈值（本机模拟）

```text
n=64：ρ=0.998832 ｜2,000 步误差 9.66e-2
经验：ρ > 0.99 时，达到 1e-6 需要上万步
经验：共轭梯度通常比 Jacobi 快一个量级
经验：预条件的选择比"多迭代"重要得多
```

## 证据强度

- **模拟**：误差与理论值完全一致（本机）
- **公开经验**：方法选择、预条件
- **推断**：真实三维问题 ρ 更接近 1，必须用多重网格或预条件

## 不适用的情况

- 小规模稠密矩阵：直接分解更快更稳
- 非对称/非正定且条件数极大：需要专门方法（GMRES + 预条件）

## 常见错法

- **不估计 ρ 就设迭代上限**
- **病态问题硬用 Jacobi**
- **精度设 1e-12 却不知道要多少步**

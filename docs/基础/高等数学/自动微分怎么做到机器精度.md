## 结论

**差分是"估"导数，自动微分是"算"导数。**
本机实测 f(x)=sin(x)eˣ/x 在 x=1.5：
**双数 AD 误差 4.44e-16（机器精度），中心差分最好也只有 4.37e-10，且 h 取小了反而更差。**

## 三条路的本质

```text
数值差分：(f(x+h)−f(x−h))/2h
  → 截断误差 O(h²) + 舍入误差 O(eps/h) → 存在最优 h，且不可消除
符号微分：把表达式变成新表达式
  → 精确，但表达式会爆炸（链式法则展开后长度指数增长）
自动微分：对每个基本运算同时携带"值"和"导数"
  → 精确到浮点舍入，代价是常数倍时间/内存
```

**"AD 不是符号微分也不是差分"**：它是把链式法则作用在计算图上。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import math
def f(x): return math.sin(x)*math.exp(x)/x
def analytic(x):
    return (math.cos(x)*math.exp(x)/x + math.sin(x)*math.exp(x)/x
            - math.sin(x)*math.exp(x)/x**2)
class Dual:
    def __init__(s, v, d=0.0): s.v, s.d = v, d
    def __add__(s, o):
        o = o if isinstance(o, Dual) else Dual(o); return Dual(s.v+o.v, s.d+o.d)
    def __sub__(s, o):
        o = o if isinstance(o, Dual) else Dual(o); return Dual(s.v-o.v, s.d-o.d)
    def __mul__(s, o):
        o = o if isinstance(o, Dual) else Dual(o)
        return Dual(s.v*o.v, s.d*o.v + s.v*o.d)
    def __truediv__(s, o):
        o = o if isinstance(o, Dual) else Dual(o)
        return Dual(s.v/o.v, (s.d*o.v - s.v*o.d)/o.v**2)
def sin(d): return Dual(math.sin(d.v), math.cos(d.v)*d.d)
def exp(d): return Dual(math.exp(d.v), math.exp(d.v)*d.d)
x = 1.5; exact = analytic(x)
ad = (sin(Dual(x,1.0))*exp(Dual(x,1.0))/Dual(x,1.0)).d
print(f"解析 {exact:.15f} ｜ AD {ad:.15f} ｜ 误差 {abs(ad-exact):.2e}")
for h in (1e-4, 1e-6, 1e-8, 1e-10, 1e-12):
    print(f"中心差分 h={h:.0e}: 误差 {abs((f(x+h)-f(x-h))/(2*h)-exact):.2e}")
PY
```

本机输出：

```text
解析 1.204784179982608 ｜ AD 1.204784179982608 ｜ 误差 4.44e-16
h=1e-04: 误差 5.28e-09
h=1e-06: 误差 4.37e-10
h=1e-08: 误差 1.87e-08
h=1e-10: 误差 9.81e-07
h=1e-12: 误差 2.98e-05
```

## 那条 U 形曲线

```text
h 太大 → 截断误差（曲线不够直）
h 太小 → 两个几乎相同的数相减，有效位被吃掉（灾难性抵消）
最优 h ≈ (eps)^(1/3) ≈ 6e-6（中心差分）
  → 本机实测最优就在 1e-6 附近，误差 4.37e-10
```

**"把 h 取更小会更准"** 是数值微分最经典的错误。

## 什么时候用哪个

```text
AD：训练神经网络、要精确梯度、函数由基本运算构成
差分：黑盒函数、只想粗查、实现成本敏感
符号微分：要公式本身（出版、推导）、表达式不大
```

**"AD 的内存代价"** 反向模式要保存前向的计算图，显存是变量数的常数倍。

## 数字与阈值（本机实测）

```text
AD 误差 4.44e-16 ｜ 中心差分最优 4.37e-10（h=1e-6）
h=1e-12 时误差涨到 2.98e-05
经验：差分步长 h ≈ eps^(1/3)·max(1,|x|)
经验：AD 的误差只来自浮点舍入，与 h 无关
经验：反向模式内存 ≈ 前向计算的 2–4 倍
```

## 证据强度

- **实测**：六组误差来自本机 Python
- **公开经验**：最优 h 的量级与 AD 的两种模式
- **推断**：不同框架的 AD 实现细节不同，精度结论一致

## 不适用的情况

- 函数含不可微操作（取整、比较）：AD 给不出有意义的梯度
- 只需要方向导数、维度极高：前向模式更省

## 常见错法

- **数值微分把 h 取到 1e-12**
- **以为 AD 是"符号求导的加速版"**
- **对含 `max`/`abs` 的不可微点求梯度而不检查**

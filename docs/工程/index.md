# 工程

> 把东西做出来，并让它持续跑。

和[智能](../智能/index.md)、[网络](../网络/index.md)的分界：这里管**做出来的软件本身**，
那边管「让机器动」和「让机器连」。

前四个学科对应一件东西的四个阶段：**设计**（长什么样）→ **开发**（做出来）→ **测试**（证明它行）→ **运维**（一直行）。同一个问题常常横跨两科，用链接互指，不要复制两份。

后四个是**机器层**：程序在机器上怎么跑（计算机）、数据怎么组织（算法与数据结构）、进程与文件怎么被系统管（操作系统）、数据怎么存与查（数据库）。它们全部由本机实测支撑，数字可复现。

| 学科 | 收什么 |
| --- | --- |
| [设计](设计/index.md) | 信息架构、交互流程、视觉规则、可用性检查 |
| [开发](开发/index.md) | 踩坑与修法、工具链配置、技术选型取舍 |
| [测试](测试/index.md) | 用例设计、自动化策略、质量门禁、回归清单 |
| [运维](运维/index.md) | 部署、监控、备份、故障处置 |
| [计算机](计算机/index.md) | 编译链接、内存、系统调用、存储与缓存（8 条，全部实测） |
| [算法与数据结构](算法与数据结构/index.md) | 复杂度、结构选择、二分/排序/判重的真实代价（8 条，全部实测） |
| [操作系统](操作系统/index.md) | 进程、切换、内存压力、页缓存与 fsync、排障（8 条，全部实测） |
| [数据库](数据库/index.md) | 执行计划、索引失效、事务与 WAL、崩溃恢复（8 条，全部实测） |

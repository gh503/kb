# 操作系统

> 这一科只回答一件事：**为什么我这个服务，跑着跑着就慢/卡/起不来。**
> 不讲内核源码，讲你能用 `ps`、`df`、`lsof`、`strace` 解释清楚的那部分。

## 收什么

- 进程从哪来、切换贵在哪、僵尸怎么来的
- 内存不够时到底发生什么（overcommit、OOM、swap）
- 写文件的三个落点：页缓存、fsync、O_DIRECT
- 磁盘满/文件删了不释放/小文件拖垮系统这类排障常识

## 不收什么

- 内核模块、驱动开发
- 调度器算法细节（CFS 的红黑树实现）
- 具体发行版的包管理差异

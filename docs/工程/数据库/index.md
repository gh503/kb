# 数据库

> 这一科只回答一件事：**这条查询为什么慢，这份数据会不会丢。**
> 用本机 SQLite 实测，结论对 Postgres/MySQL 大体相通，差异会写明。

## 收什么

- 一条查询怎么被执行（SCAN / SEARCH / COVERING）
- 索引什么时候没用（低选择性、LIKE、函数包列）
- 事务批处理与 fsync 的关系
- WAL 解决了什么、没解决什么
- 崩溃恢复与单写者模型

## 不收什么

- 分布式事务与共识算法
- 具体数据库的运维参数调优
- SQL 语法教程

## 结论

**共享库便宜但会互相污染，独立库干净但贵一倍。**
本机实测（20 个"测试"各自建库）：共享一个库 **169.3 ms**，每个测试开临时库 **337.8 ms**——**差 2 倍**。
而污染是实打实的：共享库里前一个测试没清理，后一个测试**看到 1 行脏数据（应为 0）**。

## 隔离有四个层次

```text
1. 同一库同一张表：最便宜，最容易互相污染
2. 同一库不同 schema/前缀：便宜，能挡住大部分污染
3. 每个测试一个库文件：干净，成本高（本机 2 倍）
4. 每个测试一个容器/实例：最干净，启动几秒到几十秒
```

**"测试偶尔挂"** 十次里有八次是第 1 层没清干净。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import sqlite3, os, time, tempfile
def shared_run():
    p="/tmp/kbtest/shared.db"
    if os.path.exists(p): os.remove(p)
    c=sqlite3.connect(p); c.execute("create table item(id integer primary key, name text)"); c.commit()
    t=time.perf_counter()
    for i in range(20):
        c.execute("insert into item(name) values(?)",(f"t{i}",)); c.commit()
    return time.perf_counter()-t
def temp_run():
    t=time.perf_counter()
    for i in range(20):
        fd,path=tempfile.mkstemp(suffix=".db"); os.close(fd)
        c=sqlite3.connect(path); c.execute("create table item(id integer primary key, name text)")
        c.execute("insert into item(name) values(?)",(f"t{i}",)); c.commit(); c.close(); os.remove(path)
    return time.perf_counter()-t
print(f"共享库 {shared_run()*1000:.1f} ms ｜ 每测试临时库 {temp_run()*1000:.1f} ms")
PY
```

本机输出：

```text
20 个「测试」各自建库：共享库 169.3 ms ｜ 每个临时库 337.8 ms
共享库：test_b 看到 1 行（应为 0；test_a 没清理）
独立库：test_b 看到 0 行
同库事务回滚：回滚后仍是 1 行，没有被额外写入污染
```

## 三个必查的污染源

```text
1. 数据没清：insert 了不删，或删了不回滚
2. 时间与随机数没冻结：昨天过、今天挂（跨零点、时区）
3. 共享外部资源：同一个队列、同一个对象存储前缀、同一个测试账号
```

**"本地过、CI 挂"** 多半是第 3 条：CI 上并发跑，共享前缀直接互相覆盖。

## 怎么选

```text
单测多、数据小 → 每个测试一个库文件（本机贵 2 倍，可接受）
集成测试、启动慢 → 共享实例 + 每测试唯一 schema/前缀
要验迁移 → 必须空库跑迁移，不能用任何快照
并发跑测试 → 唯一前缀是硬要求，不然互相踩
```

**"先隔离再优化速度"**：速度可以并行补回来，污染只能靠重跑掩盖。

## 数字与阈值（本机实测）

```text
20 个测试建库：共享 169.3 ms ｜ 独立 337.8 ms（2 倍）
污染实测：共享库多看到 1 行
经验：测试并发数 > 4 时必须用唯一前缀
经验：临时库清理放在 finally，不放在测试体末尾
经验：容器化隔离的启动成本 2–30 s，只适合集成测试
```

## 证据强度

- **实测**：两组时间与污染演示来自本机 sqlite
- **公开经验**：唯一前缀、finally 清理
- **推断**：真实项目里容器启动成本远高于 2 倍，"共享实例+唯一前缀"更常见

## 不适用的情况

- 只读测试：不需要隔离
- 有强顺序依赖的端到端流程：应显式建模成一条脚本，而不是"靠共享状态传下去"

## 常见错法

- **清数据写在测试最后一行**（失败就跳过了）
- **所有测试共用一个账号**
- **用生产数据的副本做测试数据**（合规与隐私问题）

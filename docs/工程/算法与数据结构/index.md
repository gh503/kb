# 算法与数据结构

> 这一科只回答一件事：**这段代码的数据量涨十倍，会不会崩。**
> 不讲竞赛题，讲你在代码里真会写错的那几处。

## 收什么

- 复杂度怎么从代码看出来（含"循环里的查找"这类隐蔽 O(n²)）
- 常见结构怎么按访问模式选
- 排序、二分、去重的实际代价（本机实测）
- 平均与最坏差多远，什么时候必须按最坏设计

## 不收什么

- 竞赛算法（网络流、计算几何、字符串高级算法）
- 具体语言的容器实现细节
- 题目解法与刷题套路

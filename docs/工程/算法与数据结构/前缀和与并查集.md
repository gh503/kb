## 结论

**这两样都属于"预处理一次，之后每次查询几乎免费"。**
本机实测：100 万元素上做 1 万次长度 1000 的区间和，
**前缀和 5.5 ms，每次现算 74.9 ms——13.6 倍**；
并查集合并 100 万条边 **975 ms**，均摊到每条边约 **1 µs**。

## 前缀和：把 O(n) 查询变成 O(1)

```text
预计算 p[i] = a[0]+…+a[i-1]      一次性 O(n)
区间 [l, r) 的和 = p[r] - p[l]    每次 O(1)
代价：多一份 n+1 的数组（空间换时间）
```

**"静态数组 + 大量区间查询"** 是它唯一的主场；一旦有修改，前缀和就要重建（这时该用树状数组/线段树）。

## 并查集：只回答"是不是同一伙"

```text
find(x)：找根，带路径压缩
union(a,b)：把两个根连起来
均摊复杂度接近 O(1)（反阿克曼函数）
不支持：删除、拆分、查询"有哪些元素"
```

**"它只维护连通性"**：要回答"路径是什么"就得用 BFS/DFS，要支持删除就得用更重的结构。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
import random, time
random.seed(3)
big = [random.randrange(100) for _ in range(1_000_000)]
p = [0] * (len(big) + 1)
for i, v in enumerate(big): p[i+1] = p[i] + v
qs = [(random.randrange(0, len(big) - 1000), 1000) for _ in range(10000)]
t = time.perf_counter()
for a, l in qs: _ = p[a+l] - p[a]
print(f"前缀和 1 万次长度 1000 区间和: {(time.perf_counter()-t)*1000:.1f} ms")
t = time.perf_counter()
for a, l in qs: _ = sum(big[a:a+l])
print(f"切片求和 1 万次: {(time.perf_counter()-t)*1000:.1f} ms")

def dsu(n, edges):
    pa = list(range(n))
    def find(x):
        while pa[x] != x:
            pa[x] = pa[pa[x]]; x = pa[x]
        return x
    for a, b in edges:
        ra, rb = find(a), find(b)
        if ra != rb: pa[ra] = rb
N = 1_000_000
edges = [(i, (i * 7919) % N) for i in range(1, N)]
t = time.perf_counter(); dsu(N, edges)
print(f"并查集 {N} 条边: {(time.perf_counter()-t)*1000:.0f} ms")
PY
```

本机输出：

```text
前缀和 1 万次长度 1000 区间和: 5.5 ms
切片求和 1 万次: 74.9 ms
并查集 1000000 条边: 975 ms
```

## 什么时候反而更慢

```text
1. 查询次数很少（< 10）：预处理的成本摊不回来
2. 数据频繁修改：前缀和每次都要重建
3. 并查集里大量"查路径"需求：它答不了，只能再跑一遍图
4. Python 里对 1 元素切片求和：`sum(a[i:i+1])` 比 `a[i]` 慢 100 倍（多建了列表）
```

**"结构性优化要看调用次数"**：一次查询不值得预处理。

## 数字与阈值（本机实测）

```text
前缀和 1 万次区间和 5.5 ms（每次 0.55 µs）｜ 现算 74.9 ms（每次 7.5 µs）
并查集 100 万条边 975 ms（每条约 1 µs，含建表）
经验：查询次数 > 100 且区间长度 > 100 时，前缀和开始明显划算
经验：并查集适合"连通性判定、Kruskal、账户合并"这类只增不删的场景
经验：Python 里用 list 切片求和的隐性成本常被低估
```

## 证据强度

- **实测**：三组耗时来自本机 Python 3.10
- **公开经验**：前缀和/并查集的复杂度与限制
- **推断**：C 实现的前缀和查询会更快，但 13 倍的比例关系来自算法而非语言

## 不适用的情况

- 数据带更新：需要树状数组/线段树
- 需要回答"连通分量里有哪些节点"：并查集不维护成员

## 常见错法

- **一次性查询也去建前缀和**
- **并查集忘了路径压缩，链退化成一条线**
- **用并查集做"删除节点"**

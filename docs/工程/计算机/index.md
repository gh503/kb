# 计算机

> 这一科讲**程序跑起来时机器里到底发生了什么**。
> 不教语言语法，教你判断"这段代码为什么慢、为什么占内存、为什么会崩"。

## 收什么

- 从源码到进程的链路：编译、链接、加载
- 内存怎么分：栈、堆、静态区、代码段
- 系统调用的真实代价（本机可复现的测量）
- 进程与线程的取舍，什么时候用哪个
- 数据在内存与磁盘上的布局，为什么影响速度

## 不收什么

- 具体语言的语法与框架用法（那是[开发](../开发/index.md)的事）
- 算法题解法（不在这一科）
- 硬件电路与芯片设计
- 操作系统内核源码分析

# 设计

> 东西长什么样、怎么分层，人才知道下一步点哪。

## 收什么

- 信息架构：一屏放几个东西、优先级怎么排、导航怎么分
- 交互流程：用户从进入到完成，中间有几步、哪一步会掉人
- 视觉规则：间距、层级、色彩、字号，写成可执行的数值而不是形容词
- 可用性检查清单：上线前逐条过一遍的那种

## 不收什么

- 纯美术作品欣赏——归[文化](../../人文/文化/index.md)或[娱乐](../../日常/娱乐/index.md)
- 没有依据的审美偏好（"我觉得这样好看"）

## 条目

还没有条目。第一条建议写**一个你反复改了三版才对的界面**，以及前两版错在哪。

## 结论

**对比度是可以算的，不是"看起来清楚"。**
本站调色板实测（`--kb-paper: #fbfaf7`）：正文墨色 **15.51:1**、次要色 **7.29:1**、弱化色 **5.43:1**、强调色 **5.24:1**。
AA 门槛 4.5:1（正文）、AAA 7:1——**四个颜色全部过 AA，两个过 AAA，弱化色 5.43 过 AA 但不过 AAA**。

## 一条公式

```text
相对亮度 L = 0.2126R + 0.7152G + 0.0722B（先做 sRGB 反伽马）
对比度 = (L1 + 0.05) / (L2 + 0.05)，L1 是较亮的一方
门槛：正文 4.5:1（AA）、7:1（AAA）；大字（≥24px 或 ≥19px 粗体）3:1
```

**"灰色不够灰，层次感出不来"** 与 "灰色看不清" 之间的界线就是 4.5:1。

## 本机可复现（已测量）

```bash
python3 - <<'PY'
def lum(h):
    h=h.lstrip('#'); c=[int(h[i:i+2],16)/255 for i in (0,2,4)]
    c=[v/12.92 if v<=0.03928 else ((v+0.055)/1.055)**2.4 for v in c]
    return 0.2126*c[0]+0.7152*c[1]+0.0722*c[2]
def ratio(a,b):
    l1,l2=lum(a),lum(b); return (max(l1,l2)+0.05)/(min(l1,l2)+0.05)
for n,c in (("ink","#1c2128"),("ink-soft","#4a5560"),("ink-mute","#5d6875"),("accent","#0f766e")):
    print(n, round(ratio(c,"#fbfaf7"),2))
PY
```

本机输出：

```text
ink #1c2128 → 15.51:1 ｜ ink-soft #4a5560 → 7.29:1
ink-mute #5d6875 → 5.43:1 ｜ accent #0f766e → 5.24:1
暗色主题：ink #dde3ea on #16191d → 13.65:1 ｜ ink-soft #aab4c0 → 8.40:1
```

## 三个最容易踩的坑

```text
1. 半透明文字：rgba(0,0,0,.87) 看起来很深，但叠在彩色背景上会掉到 3:1 以下
2. 占位符文字（placeholder）：常用 60% 灰，几乎必然不过 AA
3. 状态色（红/绿）配浅底：色盲用户靠亮度分辨，红绿对比度接近时完全失效
```

**"设计师说太深了不好看"** 可以降对比度，但要降到有下限：正文 4.5:1 是底线。

## 怎么调而不破坏层次

```text
1. 正文用最深一档（≥7:1），次要信息 4.5–7:1，装饰 3:1 以下但不用来承载信息
2. 用字号与字重制造层次，而不是只靠灰度
3. 状态不只靠颜色，加图标或文字
```

## 数字与阈值（本机实测）

```text
ink 15.51 ｜ ink-soft 7.29 ｜ ink-mute 5.43 ｜ accent 5.24（对 #fbfaf7）
暗色：ink 13.65 ｜ ink-soft 8.40（对 #16191d）
门槛：正文 AA 4.5 / AAA 7 ｜ 大字 3 ｜ 非文本（边框、图标）3
经验：placeholder 至少 4.5:1，否则等于没提示
经验：状态色要配图标，不单靠红绿
```

## 证据强度

- **实测**：五个比值由本站 CSS 变量直算
- **公开经验**：AA/AAA 门槛、placeholder 与状态色问题
- **推断**：真实设备屏幕亮度与环境光会进一步压低可读性

## 不适用的情况

- 纯装饰元素（分割线、背景纹理）：不承载信息，不受门槛约束
- 打印输出：纸张对比度与屏幕不同，按印刷标准

## 常见错法

- **只测主色，不测 placeholder 与禁用态**
- **半透明叠加后不重算**
- **用颜色单独表示成功/失败**

## 结论

**先查六项就能挡掉大多数硬伤，它们都能机器验，不靠感觉。**
本机对本站 6 个页面实测：**语言属性 `zh` 全部正确、每页恰好 1 个 `h1`、图片无缺失 `alt`、标题层级无跳级、390 px 宽无横向滚动**；
但一项没过：**正文链接的点击高度最小 9 px，17/20 小于 24 px**。

## 六项硬检查

```text
1. 语言：<html lang> 有值且正确
2. 标题：每页一个 h1，层级不跳（h2 → h4 不行）
3. 图片：有意义的图必须有 alt，装饰图 alt=""
4. 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1
5. 键盘：Tab 能到所有可操作元素，聚焦有可见轮廓
6. 缩放：390 px 宽不出现横向滚动，200% 缩放不丢内容
```

**"加了 aria-label 就算无障碍"** 语义标签只是其中一项。

## 本机可复现（已实测）

```bash
python3 - <<'PY'
from playwright.sync_api import sync_playwright
import pathlib
root=pathlib.Path("site").resolve()
pages=["","工程/开发/","关于/全站索引/","网络/TCP-IP/MTU与分片/"]
with sync_playwright() as p:
    b=p.chromium.launch(channel="chrome"); pg=b.new_page()
    for u in pages:
        pg.goto((root/u/"index.html").as_uri(), wait_until="domcontentloaded")
        print(u or "/", pg.evaluate("""() => ({
          lang:document.documentElement.lang,
          h1:document.querySelectorAll('h1').length,
          noalt:[...document.images].filter(i=>!i.hasAttribute('alt')).length,
          hscroll:document.documentElement.scrollWidth-window.innerWidth})"""))
    b.close()
PY
```

本机输出：

```text
6 页：lang=zh、h1=1、noalt=0、hskip=0、hscroll=0 —— 全过
正文链接：20 个里 19 个 < 44 px，17 个 < 24 px，最小 9 px —— 没过
对比度（前一次实测）：#fbfaf7 上 ink 15.51:1、ink-soft 7.29:1、ink-mute 5.43:1、accent 5.24:1
焦点：12 个 Tab 站里 11 个有可见轮廓，搜索框 outline 为 none
```

## 为什么"点击高度 9 px"是真问题

```text
正文里的行内链接，其高度等于文字行高的一部分
  → 手指点不中（44 px 才够），只能靠放大页面
  → 这是文字链接的通病：不是不能点，是难点的概率高
可行的修法：给正文链接加 padding（会改变行高）、或让链接在手机上变成块级
```

**"正文链接本来就这样"** 是的，但移动端占比高时它就是主要交互。

## 检查顺序

```text
1. 先跑机器能查的（语言/标题/alt/对比度/键盘/缩放）——几分钟
2. 再人工过一遍"只用键盘能不能走完主流程"
3. 最后才做语义增强（landmark、aria-describedby）
```

## 数字与阈值（本机实测）

```text
6 页：lang/h1/alt/层级/横向滚动全过
正文链接 20 个：19 个 < 44 px、17 个 < 24 px、最小 9 px
对比度：15.51 / 7.29 / 5.43 / 5.24（阈值 4.5:1，大字 3:1）
焦点：11/12 个 Tab 站有 outline，搜索框为 none
经验：正文链接的高度问题在移动端最明显
经验：机器检查覆盖 80% 的硬伤，剩下的靠键盘走查
```

## 证据强度

- **实测**：五组数字来自本机构建产物与 playwright
- **公开经验**：六项硬检查、4.5:1 阈值
- **推断**：真实用户的辅助技术组合多样，本文只覆盖最常见的几项

## 不适用的情况

- 纯图片海报页：文字即图片，alt 要写全
- 内部工具：仍建议过 1、2、4 三项（成本极低）

## 常见错法

- **只加 aria 不改结构**
- **用颜色单独表意**（红=错）
- **`outline: none` 去掉焦点框却不给替代样式**

# 运维

> 让它一直跑：部署、监控、备份、出事怎么办。

## 收什么

- 部署流程：从提交到线上，中间有几步、每步怎么回滚
- 监控指标与阈值：看哪几个数、超过多少要动手
- 备份与恢复：备份了什么、多久一次、**真的恢复过一次吗**
- 故障处置顺序：先止血还是先定位，谁通知谁

## 不收什么

- 与具体机器强绑定的临时命令——除非写清前提、影响范围和回滚方式
- 只有"配置好了"没有配置内容的记录

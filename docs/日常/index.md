# 日常

> 不为了产出，为了过日子。

这一域和"工作"最不一样：**标准是你自己舒服**，不是效率最高。所以这里的条目多是流程和清单，不是方法论。

## 先看这三个

- [速查：日常要用的数字](速查.md) —— 查数。五科的数字压成一页
- [清单：出门前后能直接勾的表](清单.md) —— 做事。看病、租房、搬家、旅行、买大件、混清洁剂
- [薄弱处：日常知识哪里可能错](薄弱处.md) —— 五处不放心的判断，附自查

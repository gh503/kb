# 七天无理由到底包什么

> **深度** 入门 ｜ **类型** 边界 ｜ **链** 退换货与维权

## 结论

**"七天无理由"只适用于网络等远程购物，且有一批商品被排除。**
更重要的是：**"拆封"通常不等于"影响二次销售"**，但"用过了"通常算。

## 三个前提缺一不可

```text
1. 渠道：网络、电视、电话、邮购等远程方式（线下门店不强制适用）
2. 时间：收到商品之日起 7 日内提出退货
3. 状态：商品完好、不影响二次销售
```

**第 3 条是争议焦点**：拆开外包装检查、试穿一下，一般不算影响二次销售；
**洗过、用过、剪了吊牌、留下使用痕迹**，通常就算。

## 常见的"不适用"商品

| 类型 | 说明 |
| --- | --- |
| 定作/定制商品 | 按你的要求做的 |
| 鲜活易腐 | 生鲜、鲜花 |
| 在线下载或拆封的音像/软件 | 数字化商品 |
| 交付的报纸期刊 | — |
| 其他根据商品性质不宜退货且**经你确认**的 | 商家必须在下单时明示 |

**最后一行是关键**：商家要在你购买时**显著提示并让你确认**，不能事后才说"这个不退"。

## 运费谁出

```text
无理由退货：运费一般由消费者承担（除非商家承诺包退运费）
质量问题退货：运费由商家承担
```

**买之前看清有没有"退货运费险"**，这决定了你退货的实际成本。

## 怎么做才不容易被拒

1. **保留原包装、吊牌、配件**，别丢
2. **只做必要检查**，不要使用
3. **在平台内发起退货**，形成记录，不要只私下沟通
4. **拍照留证**：商品状态、包装、快递单

## 数字与阈值（经验判断）

```text
期限：收到之日起 7 日（自然日）
退款到账：常见 1–7 个工作日，原路退回
运费险：常见赔付 8–15 元
商家确认时限：平台规则通常 1–3 天
```

## 证据强度

- **公开经验**：7 日无理由退货的适用条件与除外情形，是消费者权益保护的通行规定
- **数值**：期限与到账时间来自法规与平台规则，**具体以现行法规和平台规则为准**
- **推断**："拆封≠影响二次销售"是按常见判定口径推的，个案仍可能不同
- **重要**：本文不是法律意见；金额较大或争议复杂时，以监管部门与司法认定为准

## 不适用的情况

- 线下门店购买：除非商家自愿承诺，不强制适用
- 二手平台个人交易：多不适用，按平台规则

## 常见错法

- **剪了吊牌再退货**：容易被判定影响二次销售
- **只和客服私聊**：没走平台流程，事后难举证
- **以为所有东西都能退**：定制、生鲜、数字化商品通常不行

# 上门维修怎么不被坑

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 请人上门怎么不被坑

## 结论

**先问清"上门费 + 检测费 + 报价方式"，再让人进门。**
绝大多数纠纷不是修坏了，是**报价在拆开之后翻倍**，而你已经不好拒绝了。

## 电话里问清五句

```text
1. 上门费多少？修不成收不收？
2. 检测费单独收吗？能不能抵扣维修费？
3. 报价是修前给，还是拆开后才给？
4. 配件是原厂还是通用？保修多久？
5. 能不能先看照片/视频判断？
```

**第 3 句最关键**：拆开后才报价，你就失去了议价空间。

## 拆开前的三个动作

1. **拍下原始状态**（设备型号、故障现象、拆前外观）
2. **要求先报价再动手**，写清"不修是否收费"
3. **不接受"先拆开看看"**：拆开就是既成事实

## 常见加价话术与应对

| 话术 | 应对 |
| --- | --- |
| "主板烧了，得换" | 要求看旧件，问能否只换元件 |
| "这个型号配件停产了" | 让对方给两个方案与报价 |
| "先修好再说钱" | 拒绝，先书面报价 |
| "别人修过，情况复杂" | 价格按最初报价谈，不加项 |

**"要求看旧件"** 是最有效的自保：换下来的件要留给你。

## 数字与阈值（经验判断）

```text
上门费：常见 30–100 元，可抵扣维修费
检测费：常见 50–150 元
保修：维修后常见 90 天
报价有效期：当天
加价上限：超过初报 30% 应重新确认
```

## 证据强度

- **公开经验**：上门费、检测费与"拆开才报价"是家电维修投诉的常见问题
- **金额**：为常见区间，地区差异大
- **推断**："先报价再动手"按议价地位推的
- **范围**：具体收费以商家公示与事前约定为准

## 不适用的情况

- 品牌官方售后：流程规范，按官方价目
- 紧急情况（漏水、漏电）：先处置安全，价格事后核

## 常见错法

- **只问"修一下多少钱"**：对方会说"看了才知道"
- **不留旧件**：无法确认是否真换了
- **口头约定保修**：要写在单据上

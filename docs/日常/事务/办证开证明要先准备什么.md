# 办证开证明要先准备什么

> **深度** 入门 ｜ **类型** 清单 ｜ **链** 证件与合同

## 结论

**先确认"办哪一项、要什么、去哪办"，再出门。**
白跑一趟的原因九成是这三件事没问清，而不是材料不全——**材料可以补，跑错的窗口不行**。

## 出门前三问

```text
1. 办的是哪一项？名称要精确（"居住证明"和"居住登记"是两件事）
2. 需要哪些材料？原件还是复印件、几份、要不要盖章
3. 去哪办？具体到窗口/网点，以及是否需要预约
```

**第 1 条最常见**：名称差一个字，窗口就办不了。

## 通用材料清单

| 类别 | 常见材料 |
| --- | --- |
| 身份 | 身份证、户口本（首页 + 本人页） |
| 居住 | 居住证、租房合同、房东身份证复印件、房产证复印件 |
| 工作 | 在职证明、劳动合同、社保缴纳记录 |
| 照片 | 一寸/二寸，白底/蓝底（**问清底色**） |
| 其他 | 委托书（他人代办）、申请表（现场领或官网下载） |

**复印件按"2 份起"准备**：临时找复印店常要排队。

## 时间与费用

```text
预约：多数政务大厅支持线上预约，能省 1–2 小时排队
办理时长：即办件当场，承诺件常见 3–15 个工作日
费用：多数证明类免费，证件类按工本费
领取：现场取或邮寄（邮寄要留准确地址与电话）
```

## 一次办成的四个习惯

1. **把材料拍照存手机**：缺一份时能给窗口看
2. **记下经办人姓名与窗口号**：后续查询有依据
3. **要一张回执或受理单**：写明承诺办结日期
4. **问清"还需要什么"再走**：不要等回家才发现

## 数字与阈值（经验判断）

```text
承诺办结：常见 3–15 个工作日
预约：提前 1–3 天
复印件：2 份起
照片：一次拍 8 张（够用很久）
回执保存：至少保留到办结后 1 年
```

## 证据强度

- **公开经验**：材料清单与预约、回执的做法，是政务办事的常见经验
- **时限**：**各地差异很大，以受理单承诺时间为准**
- **推断**："先问清三项再出门"按返工成本排的
- **重要**：各地要求不同，**办前请查当地政务服务平台或电话确认**

## 不适用的情况

- 紧急事项（临时身份证明）：走加急或现场说明
- 需要公证、认证的事项：另需公证处环节

## 常见错法

- **按网上旧攻略准备**：材料要求会调整
- **不带户口本首页**：只带本人页常不够
- **不预约直接去**：热门窗口排队很久

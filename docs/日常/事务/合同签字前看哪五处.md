# 合同签字前看哪五处

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 证件与合同

## 结论

**看五处：跟谁签、多少钱、什么时候、违约怎么办、怎么退出。**
其余条款可以粗看，这五处一旦含糊，后面全是麻烦。

## 五处逐条

| # | 看什么 | 要写到什么程度 |
| --- | --- | --- |
| 1 | 主体 | 对方全称与证件号/统一社会信用代码，与签字人一致 |
| 2 | 金额 | 总价、含税与否、付款节点与方式 |
| 3 | 时间 | 开始、交付、验收、付款各自的具体日期或天数 |
| 4 | 违约 | 逾期怎么算、上限多少、什么情况免责 |
| 5 | 解除 | 什么情况可解除、提前多久通知、已付款怎么退 |

**第 1 处最容易被跳过**：跟个人签还是跟公司签，决定你以后找谁。

## 三个必须问清的点

```text
1. 签字人有没有授权？（不是法人/产权人 → 要委托书）
2. 附件算不算合同一部分？（报价单、清单、聊天记录）
3. 争议怎么解决？（协商、仲裁、诉讼，选哪个法院/仲裁机构）
```

**"附件算不算"很关键**：口头承诺不写进附件，等于没有。

## 可以接受与不能接受

| 情形 | 判断 |
| --- | --- |
| 违约金比例对等 | 可接受 |
| 只约束一方 | 要求对等 |
| "最终解释权归甲方" | 无效条款，但说明对方风格 |
| 空白处未划掉 | 要求划掉或写明"以下空白" |
| 只给复印件不让细看 | 不要签 |

**"以下空白"** 这个小动作能防止事后添加内容。

## 签字时的三个动作

1. **逐页签名或盖骑缝章**（防止换页）
2. **当场拿一份原件**（不是"回头给你"）
3. **拍照留存**（含签字页与附件）

## 数字与阈值（经验判断）

```text
审阅时间：金额超过月收入 1 倍，至少留 24 小时看
违约金：常见不超过合同总额的 20%–30%
定金：不超过主合同标的额的 20%
保存：合同与附件至少保存到履行完毕后 2 年
```

## 证据强度

- **公开经验**：主体、金额、期限、违约、解除，是合同审查的通行要点
- **比例**：定金 20%、违约金 20%–30% 来自常见规则与惯例，**以现行法律与具体条款为准**
- **推断**："空白处划掉"按事后篡改风险推的
- **重要**：本文不是法律意见；金额较大或条款复杂时，请咨询律师

## 不适用的情况

- 标准格式合同（租房平台、运营商）：可改空间小，重点看解除与违约金
- 劳动合同：另有法定必备条款，按劳动法判断

## 常见错法

- **只看金额**：违约与解除条款才是纠纷来源
- **不留原件**：举证困难
- **相信"我们都是这么签的"**：模板不等于合理

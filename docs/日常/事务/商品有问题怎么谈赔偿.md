# 商品有问题怎么谈赔偿

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 退换货与维权

## 结论

**先按"修、换、退"的顺序主张，再谈赔偿。** 直接要钱容易被拖，
按规则走反而快——因为对方知道你在按规则来。

## 先分清两种问题

| 类型 | 例子 | 适用 |
| --- | --- | --- |
| 质量问题 | 开裂、不工作、与描述不符 | 三包/质量责任 |
| 非质量问题 | 不喜欢、尺寸不合 | 只能走"七天无理由"（如适用） |

**"与描述不符"属于质量问题**，很多人误当成"不喜欢"，白白放弃权利。

## 三包的顺序

```text
1. 修理（在保修期内，通常免费）
2. 更换（修不好，或多次维修仍不能正常使用）
3. 退货（换不了，或不满足使用要求）
```

**不要一上来就要退货退款**：先主张修/换，通常更快；对方拒绝时再升级。

## 谈的时候说这几句

```text
"这个故障属于质量问题，我要求按三包处理。"
"请在 X 个工作日内给我处理方案。"
"如果无法解决，我会向平台/12315 投诉。"
```

**给出时限**是關鍵：没有时限的沟通会无限拖。

## 留什么证据

```text
1. 订单截图（含商品页描述）
2. 故障照片/视频（能看出问题）
3. 沟通记录（平台内，不要只打电话）
4. 维修单/检测报告（如有）
5. 快递单与签收时间
```

**"商品页描述"最容易被忽略**：它决定了"是否与描述不符"。

## 数字与阈值（经验判断）

```text
响应时限：给对方 3–7 个工作日
三包期限：按品类不同，常见 7 日退货 / 15 日换货 / 1–3 年保修
检测：争议大时可要求第三方检测
投诉时效：越早越好，多数渠道要求 1 年内
```

## 证据强度

- **公开经验**：修换退的顺序与三包期限是通行规则
- **数值**：期限按品类差异大，**以商品三包凭证与现行规定为准**
- **推断**："先主张修换再谈赔偿"是按对方处理成本推的策略
- **重要**：本文不是法律意见

## 不适用的情况

- 人为损坏：不在保修范围
- 超出三包期：只能协商或走质量责任的其他途径

## 常见错法

- **只打电话**：没有文字记录
- **接受"补偿优惠券"**：可能放弃后续权利
- **自己拆机维修**：多数保修条款因此失效

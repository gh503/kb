# 安装与维修验收看什么

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 请人上门怎么不被坑

## 结论

**验收不是"看起来好了"，是"当场试一遍 + 拿到凭证"。**
装空调、热水器、洗衣机、灯具，最容易出问题的地方都在你看不到的一侧。

## 验收六步

```text
1. 当场通电/通水，自己操作一遍（不是看师傅操作）
2. 看接口：水管接头、燃气管接头、电线端子
3. 试极端情况：最高档、最低档、连续运行 10 分钟
4. 检查固定：支架、膨胀螺丝、是否水平
5. 清理现场：包装、碎屑、墙面划痕
6. 拿凭证：保修卡、收费明细、旧件
```

**第 1 条最关键**：师傅操作正常、你操作不正常，说明有隐藏问题。

## 分设备的重点

| 设备 | 重点看 |
| --- | --- |
| 空调 | 排水是否顺畅（试运行 20 分钟看是否滴水）、外机固定、抽真空时间 |
| 热水器 | 燃气接口用肥皂水查漏、排烟管是否通向室外 |
| 洗衣机 | 进水/排水是否漏、调平（甩干不晃） |
| 灯具 | 开关、亮度、接线盒是否封闭 |
| 家具 | 抽屉滑轨、门缝、是否晃动 |

**"抽真空时间"常被压缩**：变频空调安装若抽真空不足，制冷效果与寿命都受影响。

## 一定要拿的三样

1. **收费明细**（材料费、人工费分开）
2. **保修凭证**（保修范围与期限，写清）
3. **旧件**（换下来的部件）

**旧件不留，事后无法判断是否真换了。**

## 数字与阈值（经验判断）

```text
空调抽真空：常见 15–30 分钟（按机型与管路长度）
试运行：空调 20 分钟看排水；热水器 10 分钟看水温稳定
保修：安装质量常见 1 年，设备按厂家
返工窗口：发现问题当场提，事后责任难界定
```

## 证据强度

- **公开经验**：抽真空、接口查漏、调平等验收点是安装行业的常见要求
- **时长**：为常见区间，**以厂家安装规范为准**
- **推断**："自己操作一遍"按隐蔽问题的暴露概率推的
- **范围**：涉及燃气、电气的最终验收，应以厂家或物业检查为准

## 不适用的情况

- 简单安装（挂画、置物架）：按承重与水平检查即可
- 品牌方统一安装：按官方验收单逐项核对

## 常见错法

- **只看外观**：漏水、漏气都在接口
- **当场不试**：事后报修要等
- **不要收费明细**：材料费常是加价空间

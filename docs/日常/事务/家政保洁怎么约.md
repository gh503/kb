# 家政保洁怎么约

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 请人上门怎么不被坑

## 结论

**按"小时"还是按"面积"计价，决定了你会不会被催。**
按小时计费，做得慢你多付；按面积或按次，做得快她吃亏。**日常保洁选按次/按面积，深度保洁选按小时并约定范围。**

## 先分清两种保洁

| 类型 | 适合 | 计价 |
| --- | --- | --- |
| 日常保洁 | 每周/每两周一次 | 按次或按面积 |
| 深度保洁 | 入住前、年末、装修后 | 按小时或按面积，含擦玻璃、油烟机 |
| 开荒保洁 | 装修后第一次 | 按面积，价格最高 |

**"开荒"和"深度"不是一回事**：装修后的粉尘与胶，普通深度保洁做不掉。

## 预约时说清的五件事

```text
1. 面积与房型（几室几卫）
2. 内容清单（是否含擦玻璃、油烟机、冰箱内部、阳台）
3. 时长与人数（一人 3 小时 vs 两人 1.5 小时）
4. 工具与耗材谁提供
5. 不满意怎么处理（返工？扣款？）
```

**第 2 项最容易扯皮**：不说"含油烟机"，现场就会说"这个另算"。

## 钱怎么付更安全

```text
建议：平台下单（有记录与售后），不私下转账
验收后确认完成，再放款
贵重物品提前收好（不是信任问题，是避免误会）
```

## 数字与阈值（经验判断）

```text
日常保洁：2–4 小时/次（80–120 平米）
深度保洁：4–8 小时，或按面积 8–15 元/平米
开荒保洁：按面积 15–30 元/平米
频次：每两周一次较常见；有宠物可每周
```

## 证据强度

- **公开经验**：计价方式与内容清单是家政服务的常见争议点
- **金额与时长**：为常见区间，**城市差异很大，以平台报价为准**
- **推断**："按次比按小时省心"按激励方向推的
- **未验证**：我没有具体城市的行情数据

## 不适用的情况

- 需要专业技能（除甲醛、家电深度拆洗）：另找专门服务
- 长期住家保姆：属雇佣关系，另当别论

## 常见错法

- **只看单价**：低价常不含玻璃与油烟机
- **不验收就付款**：发现问题已无法追
- **不提前收好物品**：打碎或误扔的纠纷最多

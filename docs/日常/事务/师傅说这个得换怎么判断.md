# 师傅说这个得换怎么判断

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 请人上门怎么不被坑

## 结论

**要三样东西：旧件、故障解释、两个方案。** 给不出这三样，"必须换"就只是一句话，
不是判断。真正的更换通常能说清"哪个部件、为什么坏、不换会怎样"。

## 三个追问

```text
1. "坏的是哪个件？能给我看吗？"（要旧件）
2. "不换会有什么后果？还能用多久？"（要具体，不要"很危险"）
3. "只修这个件行不行？多少钱？"（要两个方案对比）
```

**第 3 句能过滤掉大部分"整机更换"的建议**：能单换的件，通常也能报价。

## 该换的信号

| 信号 | 说明 |
| --- | --- |
| 部件已停产 | 确实无法更换 |
| 多处同时损坏 | 整体老化，修不划算 |
| 安全隐患（漏电、漏气、外壳变形） | 不应继续使用 |
| 维修价 > 新价 50% | 经济上不划算 |

## 不必急着换的信号

- 只说了"用了太久""该换了"，没有具体故障
- 拒绝让你看旧件
- 报价明显高于网上同型号配件价
- 催你当场决定（"今天不定明天涨价"）

## 一个交叉验证的办法

```text
搜"设备型号 + 故障现象" → 看是否有同款常见故障与维修价
问第二家：只说现象，不说第一家结论
对比：两家结论一致 → 可信度上升
```

**"只说现象不说结论"** 是避免被带着走的关键。

## 数字与阈值（经验判断）

```text
更换判断：维修价 > 新价 50% 且过半寿命
第二意见：金额超过 500 元建议问第二家
决策时间：给自己至少 24 小时，不当场定
配件价：可查同型号网上售价作为参考
```

## 证据强度

- **公开经验**："要旧件、要解释、要比价"是家电维修消费维权的常见建议
- **阈值**：50% 与 24 小时来自经验
- **推断**："两个方案对比"按信息不对称推的
- **范围**：涉及安全的判断（漏电、漏气）以专业检查为准，不要自行处置

## 不适用的情况

- 安全隐患明确（闻到燃气、看到冒烟）：先停用、先撤离，不要比价
- 保修期内：优先走官方售后

## 常见错法

- **当场答应**：失去比价与思考时间
- **不要旧件**：无法核实
- **只信一家**：结论可能被报价驱动

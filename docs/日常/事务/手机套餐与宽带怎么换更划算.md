# 手机套餐与宽带怎么换更划算

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 证件与合同

## 结论

**先算"每月真实用量"，再看合约期与违约金；能转网就先转网，不要先续约。**
换套餐最常见的亏，是**在合约期内改套餐被收违约金**，或者新套餐带 24 个月锁定期。

## 先查三个数

```text
1. 每月流量实际用量（看运营商 App 的近 3 个月账单）
2. 每月通话时长
3. 当前合约还剩几个月、违约金多少
```

**"实际用量"常远低于套餐**：很多人用着 60G 套餐，实际每月 8G。

## 换之前先做三件事

| 动作 | 目的 |
| --- | --- |
| 查合约期与违约金 | 决定"现在换"还是"等到期" |
| 查是否有宽带绑定 | 手机与宽带常捆绑，改一个影响另一个 |
| 查携号转网资格 | 有未到期合约、欠费、靓号协议时不能转 |

**"宽带绑定"最容易漏**：手机套餐一改，家里的宽带可能同时失效或涨价。

## 携号转网怎么走

```text
1. 发短信查资格（编辑 SQXZ#姓名#证件号 发送到 10086/10010/10000）
2. 有资格 → 去转入方营业厅办理，带身份证
3. 授权码有效期短（常见 1 小时内），当场用
4. 转网后原积分、部分权益可能清零
```

**"授权码有效期很短"** 是常见卡点：先到营业厅，再申请授权码。

## 宽带怎么选

- **看上行速度**，不只看下行：上传慢会影响视频会议与备份
- **问是否共享带宽**：老小区高峰时段可能明显变慢
- **问安装费与设备押金**：有些低价套餐靠这两项找回来
- **问到期后价格**：首年优惠、次年恢复原价是常态

## 数字与阈值（经验判断）

```text
流量：实际用量 ≈ 账单流量的 30%–50% 很常见
合约期：常见 12–24 个月
违约金：按剩余月份折算，常见每月 10–30 元
携号转网：授权码有效期常见 60 分钟内
宽带：100M 够日常，300M 以上看多人 4K 与办公
```

## 证据强度

- **公开经验**：合约期、违约金折算、携号转网流程，是运营商业务的常见规则
- **数值**：**各地各运营商差异大，以合同与客服口径为准**
- **推断**："先转网再续约"按议价空间推的
- **重要**：办理前请以运营商官方渠道与合同条款为准

## 不适用的情况

- 企业/政企套餐：规则不同，走客户经理
- 融合套餐（手机+宽带+电视）：拆分会失去整体优惠

## 常见错法

- **看到"首年便宜"就签**：第二年恢复原价
- **合约期内改套餐**：可能收违约金
- **不查绑定关系**：改了手机，宽带跟着变

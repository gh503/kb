# 搬家怎么少踩坑

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 办事少跑一趟

## 结论

**搬家的问题七成出在"报价"和"清单"上，不在搬的过程。** 报价按"车 + 楼层 + 距离"报，
到了现场再按"东西比说得多"加钱——这是最常见的套路。

## 报价要问清的五句

```text
1. 这个价包含几车、几人、几个小时？
2. 超出时间怎么算（每小时多少）？
3. 楼层费、电梯费、拆装家具、超大件（冰箱/钢琴）另收吗？
4. 有没有起步价、夜间费、远距离费？
5. 东西多了怎么加价，能不能先看照片报价？
```

**"先发照片/视频报价"能过滤掉大部分临时加价。** 愿意看的，通常比较靠谱。

## 打包清单（按顺序）

| 顺序 | 做什么 |
| --- | --- |
| 1 | 提前 3 天：清掉不搬的东西（送人、卖、扔） |
| 2 | 提前 2 天：装箱，**每箱写房间 + 内容** |
| 3 | 提前 1 天：打包"第一天要用的"单独一箱 |
| 4 | 当天：贵重与证件自己带 |

**"第一天要用的"那一箱**：洗漱、换洗、充电器、常用药、纸巾、拖鞋。
搬完当天找不到牙刷，比丢一件家具更让人崩溃。

## 容易坏的三类东西

```text
1. 屏幕类：显示器、电视 → 原箱最好，否则用硬纸板 + 气泡膜立着放
2. 玻璃/瓷器：单独包，箱内不要留空隙
3. 液体：拧紧 + 套袋，绝不与衣物同箱
```

## 搬完当天做的两件事

1. **清点大件**，对着清单核一遍
2. **检查墙面、地板、门框**（退租时要交房，有磕碰当场记录）

## 数字与阈值（经验判断）

```text
预约提前量：周末搬家提前 5–7 天
时间预留：打包按"实际估计 × 1.5"算
超时费：常见每小时 100–200 元/车
小费：视情况，非必须
```

## 证据强度

- **公开经验**：报价结构与加价点是搬家行业的常见问题
- **区间**：超时费与提前量来自经验，城市差异大
- **推断**："照片报价能过滤不靠谱的"是按信息透明度推的

## 不适用的情况

- 跨城搬家：按立方/重量计费，规则完全不同
- 公司报销的搬迁：走公司指定服务商，价格不是主要变量

## 常见错法

- **只比总价**：低价往往在楼层费和超时费上找回来
- **不写箱内清单**：到了新家开十几个一样的箱子
- **当天才打包**：手忙脚乱，最容易丢东西

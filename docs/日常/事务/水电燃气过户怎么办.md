## 结论

**过户的核心是"结清旧账 + 换户名"，顺序不能反：先过户后结账，欠费会跟着房子走。**
三家的办理渠道、材料、时限都不同，但共同点是**必须有一次现场或实名的核验**。

## 三家的差别

```text
电：多数地区支持 App 线上过户（需上传房产证明 + 身份证）
水：常需到营业厅或线上提交，部分地区要求新户到场
燃气：最严格，通常要现场安检 + 表具核对（安全原因）
```

**"一家办完其他自动跟着变"** 三家系统不互通，必须分别办。

## 通用材料清单

```text
1. 新户主身份证（原件）
2. 房产证明（不动产权证/购房合同/租赁合同+房东授权）
3. 近期缴费凭证或户号
4. 表具读数照片（过户当天拍，防扯皮）
5. 委托办理时：授权书 + 双方身份证
```

## 操作顺序

```text
1. 抄表拍照（水、电、燃气各一张，含表号与读数）
2. 查欠费：App/营业厅打印"欠费清单"
3. 结清欠费（或与卖家书面约定由谁承担）
4. 提交过户（线上或营业厅），拿受理单号
5. 3–7 天后复核：户名是否已变、账单是否寄到新户
```

## 数字与阈值（公开经验）

```text
办理时限：线上 1–3 个工作日、营业厅当场或 3–7 个工作日
燃气安检：多数地区要求过户时同步安检，周期 1 年 1 次
经验：过户前必须抄表拍照，否则历史欠费容易算到新户头上
经验：租赁场景下"过户"通常不办，改为"变更缴费人/代扣"
经验：燃气不同步过户，可能影响后续开通与安检
```

## 证据强度

- **公开经验**：三家渠道差异、材料清单、时限
- **推断**：各地细则差异大，以当地营业厅公示为准
- **计算**：3 个月欠费 × 月均 200 元 = 600 元，足以让"谁承担"变成争议

## 不适用的情况

- 租房：一般不变更户名，只变更缴费人/代扣账户
- 新建房首次开户：是"开户"不是"过户"，材料不同

## 常见错法

- **先结账后过户，结果旧户主又产生新欠费**
- **不拍表具读数**
- **只办电，忘了水和燃气**

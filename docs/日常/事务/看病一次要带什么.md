# 看病一次要带什么

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 办事少跑一趟

## 结论

**带"身份、钱、记录"三样，按顺序装一个袋子。** 跑第二趟的原因通常不是没号，
而是**没带卡、没带上次的报告、或者不知道要空腹**。

## 必带清单

```text
证件类：身份证、医保卡/电子医保、就诊卡（如有）
支付类：手机够付挂号与药费（部分窗口不支持扫码，带点现金更稳）
记录类：上次的报告/片子、正在吃的药（拍盒子照片即可）、过敏史
其他：水杯、纸巾、陪人（需要签字或行动不便时）
```

**"正在吃的药拍照"是最省事的一招**——说不清药名时直接给医生看照片。

## 去之前的三个确认

| 确认什么 | 为什么 |
| --- | --- |
| 是否需要空腹 | 抽血、腹部超声常需空腹 8–12 小时 |
| 是否要提前预约 | 专家号常需提前 1–7 天 |
| 该去哪个院区/科室 | 大医院分院区多，跑错很常见 |

## 报销要留住的东西

```text
1. 发票（原件，别折）
2. 费用清单（明细）
3. 病历/诊断证明
4. 检查报告
5. 医保卡结算单（如有）
```

**报销时限常见 3–12 个月**，过期不补。商业保险通常要求更早（30–90 天）。

## 数字与阈值（经验判断）

```text
空腹要求：8–12 小时（可少量饮水）
预约提前量：专家号 1–7 天，普通号当天
报销时限：医保 3–12 个月；商保 30–90 天
复诊间隔：慢病常见 1–3 个月
```

## 证据强度

- **公开经验**：就诊材料与报销凭证属于流程常识
- **区间**：时限来自各地医保与商保的常见规定，**地区差异大，以当地为准**
- **推断**："按身份/钱/记录装袋"是按漏带概率排的顺序

## 不适用的情况

- 急诊：先救治，材料后补
- 异地就医：需先备案，规则与本地不同

## 常见错法

- **只带手机不带卡**：部分医院仍需实体卡
- **发票揉成一团**：报销时可能被退回
- **不复述病史**：每次换医生都从头讲，容易漏

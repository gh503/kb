## 结论

**押金纠纷九成输在"没有入住时的证据"，而不是法律不保护你。**
法律上押金是"履约担保"，退租时**只能扣：欠租、欠费、以及你造成的损坏**；正常使用磨损不能扣。

## 法律依据（公开条文）

```text
民法典第 703 条起：租赁合同的基本义务（出租人交付、承租人按约定使用）
第 710 条：承租人按约定方法使用致损耗的，不承担赔偿责任
第 713 条：维修义务在出租人（除约定由承租人维修）
第 733 条：租期届满，承租人应返还租赁物
  → 押金不是"违约金"，扣减要有依据与凭证
```

**"合同写了不退就不退"** 与法律强制性规定冲突的条款无效（如"任何情况不退"）。

## 入住就要留的证据

```text
1. 交房视频：逐间拍摄，含墙面、地板、家电运行、水电表读数
2. 交接单：双方签字，写明已有瑕疵（划痕、裂缝、家电状态）
3. 缴费记录：押金转账备注"押金"、租金转账按月
4. 沟通留痕：微信文字确认，不用语音
```

## 退租时的顺序

```text
1. 提前按合同通知（常见 30 天）
2. 约验收时间，双方到场，当场抄表
3. 列出扣款项，要求出具凭证（维修发票/欠费单）
4. 无异议 → 约定退款日期（常见 7 日内）
5. 有异议 → 书面提出，保留钥匙交接凭证
```

## 数字与阈值（公开经验）

```text
押金惯例：1 个月租金（常见）到 3 个月（整租/高价值装修）
扣减举证责任：出租人主张损坏，由其举证
经验：诉讼时效 3 年（民法典第 188 条），别拖
经验：金额 < 1 万元可走小额诉讼，程序更快
经验：调解优先（社区/街道调解委员会），成本低于起诉
```

## 证据强度

- **公开经验**：条文编号、时效、押金惯例
- **推断**：各地法院对"正常磨损"的认定有差异
- **计算**：押金 1 个月 3,000 元，起诉成本（时间 + 诉讼费 50 元级）与收益要权衡

## 不适用的情况

- 短租/民宿：适用平台规则与订单条款，流程不同
- 合租二房东：先确认转租是否经房东同意，否则合同效力存疑

## 常见错法

- **入住不拍视频**
- **押金转账不写备注**
- **退租当天交钥匙却不签交接单**

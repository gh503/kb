# 租房签约要看清什么

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 办事少跑一趟

## 结论

**先确认"跟谁签"，再确认"退的时候怎么算"。** 押金纠纷九成出在这两处：
对方不是产权人，或者退租条款写得含糊。

## 签约前必须核实的三件事

```text
1. 产权：房产证（或不动产登记）上的名字，与出租人身份证是否一致
2. 授权：不是产权人本人 → 要有委托书 + 产权人证件复印件
3. 状态：房子有没有被抵押、是否在租（可要求看最近的水电账单）
```

**"二房东"不是不能签，但要看他的转租授权与原合同期限。**
原合同只剩 3 个月，你签一年就有风险。

## 合同里必须写清的六项

| 项 | 写什么 |
| --- | --- |
| 租金与涨幅 | 金额、支付方式、续租时涨幅上限 |
| 押金 | 金额、退还条件与时限（如退租后 7 日内） |
| 维修责任 | 哪些由房东修（结构、家电老化）、哪些自负 |
| 费用 | 水电气网物业取暖谁付，抄表数字写进合同 |
| 退租 | 提前多久通知、违约金怎么算 |
| 物品清单 | 家电家具现状，附照片 |

**"抄表数字"这一项最实用**：入住当天记下水电气读数并写进合同，
能避免退租时被扣一笔。

## 看房时顺手做的四件事

```text
1. 打开水龙头看水压，冲一次马桶
2. 开空调/热水器，听噪音
3. 手机信号与网速（有些房子信号很差）
4. 晚上再来一次，看噪音与采光
```

第 4 条最容易被跳过，也最影响住得舒不舒服。

## 数字与阈值（经验判断）

```text
押金：常见 1 个月租金，超过 2 个月要问清原因
退押时限：合同写 7–15 日内
提前退租：常见提前 30 天通知
涨幅：续租涨幅写进合同，常见不超过 5%
```

## 证据强度

- **公开经验**：产权核实、押金与维修条款是租房纠纷的高频点
- **区间**：押金与时限来自常见做法，城市差异大
- **推断**："先确认跟谁签"是按纠纷归因排的顺序

## 不适用的情况

- 与熟人合租：仍建议写一页简单约定，避免口头
- 短租/民宿：以平台规则为准，合同条款空间小

## 常见错法

- **只看照片就付定金**：实地与照片差距常很大
- **不拍入住照片**：退租时说不清是谁弄坏的
- **接受"押金退房时再说"**：没有时限就等于没有约定

# 老人独居要提前办哪些事

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 证件与合同

## 结论

**先做"出事时能被找到、能被送医、能被代办"这三件事，再谈其他。**
独居最大的风险不是没人照顾，是**出事之后没人知道、没人有权处理**。

## 三件必办

```text
1. 紧急联系人与信息卡：贴在冰箱/门后，写清联系人、病史、用药、过敏
2. 医疗授权与意愿：谁能签字、是否接受抢救（按当地可行方式办理）
3. 代办授权：养老金、医保、银行业务，需要时可代办
```

**第 3 项最容易被拖**：真到需要时，没有授权就什么都办不了。

## 居家安全改造（低成本优先）

| 改造 | 作用 |
| --- | --- |
| 卫生间扶手、防滑垫 | 跌倒最高发的位置 |
| 夜灯（走廊、床边） | 起夜看不清 |
| 去掉门槛与地毯边 | 绊倒 |
| 常用物品放腰部高度 | 减少登高与弯腰 |
| 燃气报警/定时关火 | 忘关火 |

**"卫生间扶手"是投入产出比最高的一项。**

## 每天一个"报平安"

```text
固定时间（如早上 9 点）互发一条消息
超过约定时间没消息 → 打电话 → 联系邻居/物业
```

**机制比关心更有用**：有约定才有发现异常的可能。

## 需要谨慎的两件事

1. **保健品与"免费体检"推销**：独居老人是主要目标
2. **大额转账与"投资"**：约定"超过 X 元先跟家人说"

## 数字与阈值（经验判断）

```text
报平安：每天 1 次固定时间
访视：独居老人建议每周至少 1 次见面或视频
改造预算：扶手+防滑+夜灯常见 300–1000 元
转账阈值：超过 2000–5000 元先与家人确认（按家庭约定）
```

## 证据强度

- **公开经验**：紧急联系人、居家防跌改造、每日联络，是独居老人照护的常见做法
- **金额**：改造费用为常见区间，**以当地报价为准**
- **推断**："代办授权要提前办"按办事需要授权的现实推的
- **重要**：涉及监护、财产与医疗意愿，**须按当地法律规定办理，建议咨询法律与医疗专业人士**

## 不适用的情况

- 有同住家属：重点转为防跌与用药管理
- 认知功能下降：需评估监护与照护安排，不宜独居

## 常见错法

- **只买设备不改造**：扶手比手环更直接
- **不设报平安机制**：出事几天才被发现
- **把决定权全交给"以后再说"**：关键时刻无人可签

# 体检报告怎么看

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 体检与日常健康

## 结论

**先看箭头，再看趋势，最后才看单个数字。** 一份体检表上十几个箭头，多数不需要处理；
真正要行动的是**连续两年往同一方向走**的那几项。

## 三步读法

```text
第一步：找红色/箭头项，圈出来（不急着查）
第二步：和去年、前年的同一项对比（趋势比单点重要）
第三步：只有同时满足"超范围 + 连续变差 + 有症状"，才需要挂号
```

**单次轻微超标，多数是当天的状态**：前一晚没睡好、抽血前没空腹、前一天剧烈运动，
都会让肝酶、血脂、血糖偏高。

## 常见项的粗读

| 项目 | 常见偏移原因 | 什么时候要查 |
| --- | --- | --- |
| 转氨酶（ALT/AST） | 熬夜、饮酒、剧烈运动、脂肪肝 | 超过上限 2 倍，或连续升高 |
| 血脂（LDL） | 饮食、遗传 | 持续偏高 + 有家族史/血压高 |
| 空腹血糖 | 前一晚吃太晚、压力 | ≥ 6.1 需复查，≥ 7.0 要就诊 |
| 尿酸 | 海鲜啤酒、脱水 | 有痛风发作史则要管 |
| 甲状腺（TSH） | 压力、药物 | 偏离参考区间明显才查 |
| 血常规白细胞 | 当天有感染 | 伴发热或持续异常 |

**参考区间是"95% 的人落在里面"，不是"健康线"。** 略超不等于病。

## 必须去医院的几种情况

- 任何一项**超过上限 2 倍**
- 同一项**连续两年上升**且已超范围
- 报告上写着"建议复查/进一步检查"
- 伴随明显症状（消瘦、持续疼痛、异常出血）

## 数字与阈值（经验判断）

```text
复查间隔：轻微超标 3 个月后复查一次
需就诊：超上限 2 倍，或连续两年恶化
体检频率：20–39 岁 1–2 年一次；40 岁以上每年一次
```

## 证据强度

- **公开经验**：参考区间的含义与常见偏移原因属于体检科普常识
- **阈值**：2 倍、3 个月复查等来自临床常规说法
- **推断**："三步读法"是按误判成本设计的阅读顺序
- **重要**：这不是医疗建议，具体判断以医生为准

## 不适用的情况

- 已有确诊疾病：按医嘱复查，不适用"观察"策略
- 孕产期、儿童：参考区间不同

## 常见错法

- **看到箭头就上网查病**：越查越像
- **只看今年不看去年**：趋势被忽略
- **体检完不做任何改变**：报告的价值在于接下来的行动

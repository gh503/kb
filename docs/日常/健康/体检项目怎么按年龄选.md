## 结论

**体检的价值在"按风险筛"，不在"项目多"；同一个套餐对 30 岁和 60 岁的收益完全不同。**
基础项人人做，附加项按**年龄、性别、家族史、吸烟史**四件事加。

## 三层结构

```text
人人都做：血压、身高体重腰围、血常规、肝肾功能、血脂、血糖、尿常规、心电图
按年龄加：30+ 甲状腺超声；40+ 胃肠镜（高危）/乳腺与宫颈（女性）；50+ 肠癌筛查、骨密度（女性）
按风险加：吸烟者低剂量 CT、乙肝携带者肝脏超声+甲胎蛋白、家族史对应的专项
```

**"越贵越全面"** 无指征的全身 CT/PET 收益低、辐射与假阳性代价高。

## 按年龄的一张表

| 年龄 | 重点加项 |
| --- | --- |
| 20–30 | 基础项 + 乙肝两对半、甲状腺功能（有症状时） |
| 30–40 | 加甲状腺超声、女性宫颈筛查（按指南起始年龄） |
| 40–50 | 加胃肠镜（高危或按指南）、乳腺钼靶（女性按指南） |
| 50–65 | 加肠癌筛查、骨密度（女性）、眼底 |
| 65+ | 加认知与跌倒风险评估、疫苗评估、用药梳理 |

## 数字与阈值（公开经验）

```text
血压 ≥ 140/90 mmHg 需复测评估 ｜空腹血糖 ≥ 7.0 mmol/L 需复查
肠镜：一般风险人群 45–50 岁起，每 10 年（或按指南）
宫颈筛查：21–29 岁每 3 年细胞学；30–65 岁每 5 年 HPV 联合
经验：体检异常里最常见的是血脂、尿酸、脂肪肝、甲状腺结节（多为良性）
经验：一次体检的假阳性会带来一串复查，附加项要按风险加
```

## 证据强度

- **公开经验**：分层结构与筛查间隔
- **推断**：各指南起始年龄略有差异，以本地指南与医生建议为准
- **计算**：45 岁起每 10 年肠镜 ≈ 一生 4 次，收益高于每年肿瘤标志物

## 不适用的情况

- 已有明确疾病：按专科随访计划，不用常规体检套餐
- 妊娠期：项目需重新选择（禁放射性检查）

## 常见错法

- **只看套餐价格不看项目**
- **用肿瘤标志物替代影像/内镜筛查**
- **查出小结节就频繁复查**

# 保健品要不要吃

> **深度** 实操 ｜ **类型** 取舍 ｜ **链** 吃与喝

## 结论

**先看饮食缺不缺，再谈补不补；能靠吃解决的，不要靠买。**
真正有明确缺乏人群的只有几种（维生素 D、叶酸、B12、铁），其余多数"吃了没坏处，也没明显用处"。

## 什么情况值得补

| 情况 | 常见建议 |
| --- | --- |
| 很少晒太阳、室内工作 | 维生素 D |
| 备孕/孕早期 | 叶酸 |
| 严格素食 | 维生素 B12 |
| 确诊缺铁性贫血 | 铁剂（需医生指导） |
| 老年人、吸收不良 | 按检查结果 |

**共同点：有明确缺乏原因或检查结果。** 不是"感觉最近累"就补。

## 常见宣称与证据

| 宣称 | 证据情况 |
| --- | --- |
| 叶黄素护眼 | 对特定眼病有研究，对普通人"防疲劳"证据弱 |
| 蓝莓/花青素抗氧化 | 食物里吃有好处，浓缩补充剂证据不足 |
| 胶原蛋白美容 | 口服后分解为氨基酸，效果缺乏一致证据 |
| 益生菌调理肠胃 | 特定菌株对特定情况有研究，产品差异极大 |
| 复合维生素 | 饮食均衡者收益很小 |

**"缺乏证据"不是"有害"，而是"不值得为此花钱"。**

## 买之前问四句

```text
1. 我缺的是什么？有没有检查结果或明确原因？
2. 食物能不能解决？（一周吃几次鱼、蛋、奶、深色蔬菜）
3. 这个剂量在安全范围内吗？（看营养成分表，不是看广告）
4. 停掉之后，我怎么知道有没有用？
```

**第 4 句最实用**：说不出判断标准，就别开始。

## 数字与阈值（经验判断）

```text
维生素 D：常见补充 400–800 IU/天（缺乏者按医嘱加量）
叶酸：备孕常见 400μg/天
B12：素食者常见 2.4μg/天（强化食品或补充剂）
判断期：任何补充剂，3 个月看不出差别就停
花费线：每月超过一顿饭钱，先想想值不值
```

## 证据强度

- **公开经验**：维生素 D、叶酸、B12、铁的缺乏人群与补充建议，属于营养学通行结论
- **宣称部分**：多数保健品的效果研究结论不一致，**本文按"证据不足"处理**
- **推断**："3 个月看不到差别就停"是按可判断性设计的
- **重要**：本文不是医疗建议；服用任何补充剂前，尤其在与药物同服时，请咨询医生或药师

## 不适用的情况

- 已确诊缺乏症：按医嘱剂量，不适用"食补优先"
- 孕妇、慢性病患者、服药者：需专业评估，避免相互作用

## 常见错法

- **按广告买**：宣称与证据常不匹配
- **同时吃多种**：某些成分叠加会超量（如维生素 A、铁）
- **用保健品替代治疗**：耽误正规处理

# 咖啡能喝多少

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 吃与喝

## 结论

**健康成人每天咖啡因 400mg 以内是常见安全线**，大约 3–4 杯美式。
比"喝几杯"更重要的是**最后一杯的时间**——午后 2 点后喝，晚上大概率受影响。

## 常见饮品的咖啡因量

| 饮品 | 咖啡因（约） |
| --- | --- |
| 美式（中杯） | 120–200mg |
| 拿铁（中杯） | 75–150mg |
| 速溶（一杯） | 60–100mg |
| 浓缩（一份） | 60–80mg |
| 红茶（一杯） | 40–70mg |
| 可乐（330ml） | 30–40mg |
| 能量饮料（250ml） | 80mg（部分更高） |
| 无咖啡因咖啡 | 2–15mg |

**茶、可乐、巧克力都算**：一天几杯茶加一瓶可乐，很容易接近上限。

## 时间比总量更影响睡眠

```text
咖啡因半衰期：约 5 小时（个体差异 3–7 小时）
下午 2 点喝的 200mg → 晚上 8 点还剩约 100mg
建议：睡前 8 小时内不摄入
```

**"我喝了照样睡"** 常见于长期耐受，但深睡比例可能已经下降。

## 谁要更少

- 孕期：常见建议控制在 200mg 以内
- 心律不齐、焦虑、胃食管反流：减量或避免
- 正在服药（部分抗生素、支气管扩张剂）：问医生

## 数字与阈值（经验判断）

```text
成人上限：400mg/天
孕期：200mg/天
单次：不超过 200mg
截止时间：睡前 8 小时
```

## 证据强度

- **公开经验**：400mg 上限与孕期 200mg 是各国膳食指南的常见建议
- **含量**：为常见区间，**以产品标注为准**（现制咖啡差异很大）
- **推断**："时间比总量更重要"按半衰期推的
- **未验证**：个体代谢差异大，CYP1A2 基因型会影响

## 不适用的情况

- 已确诊焦虑、心律失常、严重胃病：按医生建议
- 儿童青少年：不建议

## 常见错法

- **只算咖啡不算茶**：总量容易超
- **用咖啡代替睡眠**：掩盖欠睡，不解决
- **空腹大量喝**：胃部不适

# 外卖怎么点

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 吃与喝

## 结论

**看"烹饪方式"而不是"菜名"。** 同样是鸡肉，蒸、炖、白灼和油炸、干锅、糖醋，
热量与油盐能差一倍以上。点单时先选做法，再看配菜。

## 一个点单顺序

```text
1. 先定蛋白质：蒸/炖/白灼的鱼、鸡、豆腐、蛋
2. 再定蔬菜：清炒、白灼、凉拌（注意酱料另放）
3. 主食减半或换粗粮
4. 饮料换水或无糖茶
```

**"酱料另放"这一条最有效**：一份沙拉酱或糖醋汁，常含 10–20 克油或糖。

## 常见做法的差别

| 做法 | 相对负担 |
| --- | --- |
| 蒸、白灼、炖、卤（少汁） | 低 |
| 清炒、快炒 | 中 |
| 红烧、糖醋、干锅、水煮（红油） | 高 |
| 油炸、酥炸、裹粉 | 最高 |

**"水煮"系列常是油最多的**：名字里有水，端上来一层红油。

## 三个实用技巧

1. **主食单独点**：饭量大时自己控制分量，不被动吃一份炒饭
2. **汤另装**：汤里盐和油都不少，别把菜泡在里面
3. **一份菜分两顿**：外卖份量常偏大，倒出来分装比硬吃完好

## 数字与阈值（经验判断）

```text
单餐热量：600–800 kcal 属常见合理区间（视体型与活动量）
油：单餐 15–25 克已不少
盐：成人每日建议 < 5 克，一份外卖常占一半以上
频率：每周 3 次以内更容易控制总量
蔬菜：一份外卖的蔬菜常不足 200 克，需要额外补
```

## 证据强度

- **公开经验**：烹饪方式对油盐与热量的影响，属于营养常识
- **区间**：热量与油盐为常见估算，**不同商家差异很大**
- **推断**："先定做法再看菜名"是按可控性排的顺序
- **未验证**：我没有具体商家的营养成分数据

## 不适用的情况

- 有特殊饮食要求（糖尿病、肾病、过敏）：需按医嘱与配料表
- 高强度体力劳动：热量需求更高，不必压缩

## 常见错法

- **只吃沙拉**：酱料热量常超过主食
- **以为"轻食"就低卡**：看配料，很多加了坚果酱与蜂蜜
- **不看份量**：一份两人份的菜当一人吃

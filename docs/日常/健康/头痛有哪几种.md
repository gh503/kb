## 结论

**绝大多数头痛是"原发性"的（没有结构病变），但有五类"红旗"必须查。**
判据不是"疼得多厉害"，而是**突然性、伴随症状、年龄、变化趋势**。

## 常见的三类原发性头痛

```text
紧张型：双侧、压迫感、轻中度、活动不加重（最常见）
偏头痛：单侧、搏动、中重度、活动加重、怕光怕吵、可伴恶心
丛集性：一侧眼眶周围、剧烈、定时发作、伴流泪流涕
```

**"疼得厉害就是大病"** 紧张型可以很疼，而蛛网膜下腔出血的"雷击样"疼痛常被描述为"从没这么疼过"。

## 五条红旗（出现任一条去做检查）

```text
1. 雷击样：几秒到一分钟达到峰值（警惕出血）
2. 伴神经症状：说话不清、肢体无力、视物成双、抽搐
3. 伴发热与颈项强直（警惕感染）
4. 50 岁后新发，或原有头痛性质明显改变
5. 咳嗽/用力/体位改变时明显加重，或夜间痛醒
```

## 该看哪个科

```text
首次剧烈或伴神经症状 → 急诊
反复发作、模式稳定 → 神经内科
伴鼻塞流脓、视力下降 → 耳鼻喉/眼科
与药物过量有关（每月用止痛药 > 10–15 天）→ 神经内科（药物过度使用性头痛）
```

## 数字与阈值（公开经验）

```text
偏头痛患病率约 10%–15%（女性更高）｜紧张型终身患病率可达 30%–70%
经验：每月止痛药使用 ≥ 10 天（含复方）要警惕药物过度使用性头痛
经验：50 岁以上新发头痛，影像检查门槛应更低
经验：记录头痛日记（时间、诱因、用药）比"回忆"可靠得多
```

## 证据强度

- **公开经验**：分类、红旗、患病率区间
- **推断**：个体差异大，阈值只用于决定"要不要查"，不用于自我诊断
- **计算**：每月 15 天用药 × 6 个月 = 90 天暴露，是药物过度使用的常见门槛

## 不适用的情况

- 已知病因的继发性头痛（如高血压、鼻窦炎）：按原发病处理
- 儿童头痛：红旗标准与成人不同，需儿科评估

## 常见错法

- **只按疼痛程度判断要不要就医**
- **长期靠止痛药压着，不记录频率**
- **把"以前也这样"当成安全信号（性质改变才是关键）**

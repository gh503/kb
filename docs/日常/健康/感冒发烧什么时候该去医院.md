# 感冒发烧什么时候该去医院

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 体检与日常健康

## 结论

**普通感冒不需要去，但有几条线一旦越过就要去。** 判断依据不是"烧到多少度"，
而是**持续时间、精神状态、以及有没有危险信号**。

## 必须就医的五种情况

```text
1. 发热超过 3 天不退，或退后又反复
2. 呼吸困难、胸口痛、意识模糊、脖子僵硬
3. 持续呕吐、无法进水、尿量明显减少
4. 剧烈头痛、皮疹、皮肤出现瘀点
5. 婴幼儿、孕妇、老人、有基础病者症状明显
```

**第 2、4 条不要等**——这几项提示的可能不是普通感冒。

## 一般感冒的居家处理

| 做法 | 说明 |
| --- | --- |
| 多喝水、休息 | 最主要的两件事 |
| 退烧药按说明书 | 不要叠加多种含同成分的复方药 |
| 不滥用抗生素 | 病毒性感冒抗生素无效 |
| 症状记录 | 体温、时间、用药，就诊时有用 |

## 一个容易搞错的点

**"烧得高"不等于"病得重"。** 体温高低与病情严重程度不成正比，
精神状态（能不能正常说话、反应是否清楚）更值得看。

## 数字与阈值（经验判断）

```text
成人发热：38.5℃ 以上或明显不适可用退烧药
就诊线：发热 > 3 天，或退后 24 小时内再升
补水：尿色接近淡黄说明够
复诊：症状 5–7 天无改善
```

## 证据强度

- **公开经验**：危险信号清单与退热原则属于常见医学常识
- **阈值**：3 天、38.5℃ 等是通行参考值
- **推断**："精神状态比体温更重要"是按危险信号优先级推的
- **重要**：这不是医疗建议，拿不准就去医院

## 不适用的情况

- 已知慢性病（哮喘、糖尿病、免疫抑制）：阈值要更低
- 儿童：精神状态与进食情况比体温更关键，且变化更快

## 常见错法

- **硬扛到第三天**：危险信号是等不起的
- **同时吃多种感冒药**：常含同一成分，容易过量
- **退烧就停药返工**：休息不足容易反复

# 感冒药止痛药能不能一起吃

> **深度** 入门 ｜ **类型** 边界 ｜ **链** 日常小毛病与用药

## 结论

**多数情况不能——因为很多感冒药里已经含了对乙酰氨基酚。**
叠加服用会超过安全剂量，伤的是肝，而且早期没有明显感觉。

## 先看成分，不看商品名

```text
常见复方感冒药多含：对乙酰氨基酚（退热镇痛）
常见止痛药：对乙酰氨基酚 或 布洛芬
同时吃 → 对乙酰氨基酚可能翻倍
```

**判断方法：把两盒药的成分表逐项对比，有同名成分就不能同服。**

## 安全剂量大概在哪

| 成分 | 成人单次 | 24 小时上限 |
| --- | --- | --- |
| 对乙酰氨基酚 | 325–650mg | 不超过 2g（保守）至 3g（说明书常见） |
| 布洛芬 | 200–400mg | 不超过 1.2g（非处方用法） |

**上限取"说明书"与"保守值"里更小的那个**，尤其饮酒、肝功能不好、体重偏低的人。

## 什么情况可以同服

```text
可以：对乙酰氨基酚（退热）+ 布洛芬（抗炎镇痛），错开时间，各自不超量
可以：感冒药 + 止咳药（成分不重叠）
不可以：两种复方感冒药同服
不可以：感冒药 + 单方对乙酰氨基酚
不可以：感冒药 + 含同成分的"夜间感冒药"
```

**"错开时间"不是"各减半"**：每种药仍按自己的上限算。

## 三个高风险动作

1. **一次吃两种感冒药"加强效果"**：最常见也最危险
2. **感冒药配酒**：加重肝损伤
3. **连续吃超过 3–5 天不停**：退热药只缓解症状，不治病因

## 数字与阈值（经验判断）

```text
对乙酰氨基酚：间隔 ≥ 4–6 小时，24 小时 ≤ 4 次
布洛芬：间隔 6–8 小时，饭后服
退热药使用：不超过 3 天（无改善需就诊）
饮酒者：对乙酰氨基酚上限应更低
```

## 证据强度

- **公开经验**：复方感冒药含对乙酰氨基酚、叠加导致过量伤肝，是药品监管与药学科普反复提示的内容
- **剂量**：为常见说明书范围，**以你手上那盒药的说明书为准**
- **推断**："上限取更小值"按安全边际推的
- **重要**：本文不是用药建议；儿童、孕妇、肝肾功能异常、正在服其他药者，请咨询医生或药师

## 不适用的情况

- 儿童：按体重计算剂量，不能用成人量折算
- 慢性肝病、长期饮酒：需医生指导
- 正在服用抗凝药：布洛芬等可能增加出血风险

## 常见错法

- **按商品名判断**：不同品牌成分可能相同
- **"中成药就安全"**：部分中成药也含对乙酰氨基酚
- **症状反复就加量**：应先看是否需要就诊

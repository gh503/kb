# 眼睛干涩怎么办

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 日常小毛病与用药

## 结论

**先改三件事：眨眼、屏幕高度、环境湿度；再谈滴眼液。**
干涩的核心机制常是**盯着屏幕时眨眼次数下降**，而不是"眼睛缺水需要补水"。

## 先做三件事（不花钱）

```text
1. 20-20-20：每 20 分钟，看 20 英尺（约 6 米）外 20 秒
2. 屏幕略低于视线：减少眼裂暴露面积，泪液蒸发慢
3. 有意识地完整眨眼：屏幕前的人常只眨"半下"
```

**"完整眨眼"最容易被忽略**：很多人眨眼时上下眼睑没接触，泪膜没铺开。

## 环境与习惯

| 因素 | 做法 |
| --- | --- |
| 空调/暖气 | 加湿，湿度 40%–60% |
| 风扇直吹脸 | 避开 |
| 隐形眼镜 | 每天不超过 8–10 小时，干涩时改框架 |
| 睡眠不足 | 直接影响泪液分泌 |

## 滴眼液怎么选

```text
首选：不含防腐剂的人工泪液（单支装）
可临时用：含玻璃酸钠的润眼液
避免：长期用"去红血丝"类（血管收缩剂，停用反弹）
频率：每天 > 4 次建议用无防腐剂型
```

**"去红血丝"不等于"治干涩"**：它让血管收缩，看起来白了，原因还在。

## 什么时候要去医院

```text
1. 视力下降、看东西模糊持续不缓解
2. 眼痛、畏光、明显异物感
3. 单眼突然流泪不止或分泌物增多
4. 干涩持续 2 周以上，用人工泪液无改善
```

**第 4 条是分界**：两周无改善，说明可能不是单纯的环境性干眼。

## 数字与阈值（经验判断）

```text
20-20-20：每 20 分钟，20 秒，6 米外
湿度：40%–60%
隐形眼镜：每天 ≤ 8–10 小时
人工泪液：每天 > 4 次用无防腐剂型
就诊线：2 周无改善
```

## 证据强度

- **公开经验**：20-20-20 法则、眨眼与泪膜的关系，是眼科与视光科普的通行内容
- **数值**：时长与湿度来自经验
- **推断**："先改习惯再用药"按成因顺序排的
- **重要**：本文不是诊断；持续眼痛、视力变化、畏光请及时就诊

## 不适用的情况

- 已确诊干眼症、睑板腺功能障碍：需专门治疗（热敷、睑缘清洁、处方药）
- 术后恢复期：按医嘱

## 常见错法

- **一直滴、不改习惯**：滴完继续盯屏幕，很快又干
- **用含防腐剂的滴眼液很频繁**：反而刺激
- **揉眼睛**：加重角膜刺激

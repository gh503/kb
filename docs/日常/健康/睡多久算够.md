# 睡多久算够

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 体检与日常健康

## 结论

**看白天状态，不看睡了几个小时。** 成人常见区间是 7–9 小时，
但真正的判据是：**早上不用闹钟也能起、下午不靠咖啡撑、周末不需要补觉。**

## 三个自测问题

```text
1. 周末比工作日多睡 2 小时以上？ → 平时欠睡
2. 下午 2–4 点必须靠咖啡/糖撑？ → 睡眠质量或时长不足
3. 躺下 30 分钟内能睡着？ → 超过说明入睡困难，不是"睡得少"
```

三条里中两条，先按"欠睡"处理，别急着买助眠产品。

## 时长与人群

| 人群 | 常见需要 |
| --- | --- |
| 青少年 | 8–10 小时 |
| 成年人 | 7–9 小时 |
| 65 岁以上 | 7–8 小时，夜间易醒属正常 |

**"我睡 5 小时也精神"多数是适应了疲劳**，不是真的不需要——表现为情绪波动、
注意力下降、容易感冒。

## 比时长更影响效果的四个变量

1. **固定起床时间**（比固定睡觉时间更有效）
2. **睡前一小时不看强光屏幕**
3. **卧室温度偏低**（18–22℃）
4. **下午之后不摄入咖啡因**（半衰期约 5 小时）

## 数字与阈值（经验判断）

```text
入睡时间：躺下 15–30 分钟内睡着属正常
咖啡因：午后 2 点后不喝，多数人受益
补觉：周末多睡 1 小时以内，多了会打乱节律
连续欠睡：一周每天少 1 小时，等于欠一整晚
```

## 证据强度

- **公开经验**：成人 7–9 小时与固定起床的建议属于睡眠卫生常识
- **区间**：时长来自人群统计，个体差异大
- **推断**："看白天状态而非时长"是按个体差异推的判据
- **未验证**：我没有你的睡眠监测数据

## 不适用的情况

- 轮班、跨时区：固定起床时间难以执行，改用"睡够一个完整周期"
- 打鼾严重伴白天嗜睡：可能是睡眠呼吸暂停，需要就医而不是调作息

## 常见错法

- **追求"深度睡眠"百分比**：手环数据误差大
- **周末狂补觉**：节律被打乱，周一更累
- **靠褪黑素解决入睡困难**：先查是不是咖啡因和光线的问题

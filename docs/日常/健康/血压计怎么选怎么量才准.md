# 血压计怎么选怎么量才准

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 日常小毛病与用药

## 结论

**买上臂式电子血压计，不买腕式；量之前静坐 5 分钟，测两次取平均。**
家用血压计最大的误差来源不是机器，是**姿势、时间和刚喝完咖啡**。

## 怎么选

| 类型 | 建议 |
| --- | --- |
| 上臂式电子 | **首选**，误差小、易操作 |
| 腕式 | 便携，但对姿势敏感，不推荐作为主要设备 |
| 手指式 | 不建议 |
| 水银柱 | 家用不合适（需专业操作与处置） |

**袖带尺寸要匹配臂围**：袖带太小会测出偏高的值，这是最常见的系统性误差。

## 量的六个要点

```text
1. 静坐 5 分钟，背靠椅背，双脚平放
2. 手臂放在桌上，与心脏同高
3. 袖带下缘在肘窝上 2–3 厘米，松紧能塞进两指
4. 不说话、不看手机
5. 测两次，间隔 1 分钟，取平均
6. 固定在早晨（起床后 1 小时内、排尿后、服药前）或晚上
```

**"固定时间"比"测得准"更重要**：趋势才有意义。

## 记录什么

```text
日期、时间、收缩压/舒张压、心率
当时的特殊情况：刚运动、没睡好、喝了咖啡、情绪激动
```

**记异常比记正常更有用**：就诊时医生要的是"什么时候高"。

## 数字与阈值（经验判断）

```text
家庭自测参考：< 135/85 mmHg 视为正常范围
诊室血压：< 140/90 mmHg
连续 7 天，家庭平均值 ≥ 135/85 → 就诊
单次偏高：不急于判断，先看 7 天平均
```

**"白大衣高血压"与"隐匿性高血压"都存在**，所以家庭自测比诊室单次更有参考价值。

## 证据强度

- **公开经验**：上臂式优于腕式、静坐与手臂同高、测两次取平均，是高血压家庭管理的通行建议
- **阈值**：135/85 来自家庭血压的常见界值，**以现行指南为准**
- **推断**："固定时间比测得准重要"按趋势判断的需要推的
- **重要**：本文不是诊断标准；确诊与用药必须由医生判断

## 不适用的情况

- 心律失常（房颤）：家用电子血压计可能不准，需医生评估
- 儿童、孕妇：标准不同

## 常见错法

- **刚爬完楼就测**：偏高
- **袖带套在厚衣服上**：偏高
- **只测一次就下结论**：波动大
- **买腕式图方便**：姿势稍偏误差就大

# 一个人吃饭怎么不尴尬

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 一个人怎么玩

## 结论

**尴尬不是来自一个人，是来自"坐在那里没什么可做"。** 给手找点事、选对座位和时段，
一个人吃饭比跟不熟的人吃饭自在得多。

## 三个选择决定体验

| 选择 | 建议 | 为什么 |
| --- | --- | --- |
| 时段 | 避开 12:00–13:00 与 18:30–20:00 | 不用抢位，也不会被"翻台"催 |
| 座位 | 靠墙、吧台、窗边 | 不用面对过道 |
| 类型 | 面、饭、定食、火锅（单人锅） | 出餐快、不需要共享 |

**吧台的发明就是给一个人的**，很多店有单人就餐区，只是没写出来。

## 给手找点事

```text
可以：带本书、看纪录片、写点东西、听播客（戴一只耳机）
不必：为了"显得有事做"而一直刷手机
```

**刷手机反而更显眼**：低头两小时，比抬头慢慢吃更不自在。

## 点单的建议

- 主食 + 一个菜，别点三个（吃不完会想快点走）
- 想试新店：选午市，价格低、心理压力小
- 想吃好的：一个人更容易订到吧台位

## 数字与阈值（经验判断）

```text
时段：避开 12:00–13:00、18:30–20:00
用餐时长：40–60 分钟，不必吃完就走
单人消费：午市常见比晚市低 20%–40%
频率：每周 1–2 次独食，多数人会觉得舒服
```

## 证据强度

- **公开经验**：单人用餐的座位与时段选择，是城市生活类内容的常见建议
- **区间**：数值来自经验
- **推断**："尴尬来自无事可做"是按社交压力来源推的
- **未验证**：个体差异大，有人确实不喜欢独食

## 不适用的情况

- 需要多人分享的菜式（烤鱼、大锅火锅）：一个人点不划算
- 商务场合：独食反而不合适

## 常见错法

- **硬等两人桌**：一个人更容易被安排到好位置
- **点太多怕浪费**：吃不完打包，比硬撑好
- **全程低头刷手机**：反而更累

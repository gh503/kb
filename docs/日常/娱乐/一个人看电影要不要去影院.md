## 结论

**一个人去影院的真正成本是"通勤 + 场次约束"，收益是"大银幕 + 不被打断"；值不值取决于你看重哪一项。**
如果片子是视效/音效驱动，影院收益大；如果是对话/剧情驱动，家里看几乎不损失。

## 三个成本

```text
时间：往返 + 等场 + 广告 ≈ 2.5–3 小时（片长 2 小时）
钱：票 + 交通 + 可能的餐饮
约束：场次固定，不能暂停、不能回看
```

## 三个收益

```text
画面与声音：大银幕 + 环绕声，视效片差距最大
专注：黑暗环境 + 不能暂停，天然防打断
仪式感：一个人去看一场电影，本身就是一段完整的时间
```

## 怎么选（四问）

```text
1. 这片子靠画面/音效吗？（是 → 影院）
2. 我需要暂停/回看吗？（需要 → 家里）
3. 最近有没有"整块两小时"？（没有 → 家里）
4. 我想不想出门走走？（想 → 影院，顺带解决散步）
```

## 一个人去的实用细节

```text
选边座或最后一排：进出方便、少被打扰
场次选工作日下午：人少，票也便宜
提前 10 分钟到：广告长，不用赶
```

## 数字与阈值（公开经验）

```text
经验：往返 1 小时以内，影院的时间成本才划算
经验：视效片在手机/电脑上看，损失的最大项是"画面尺寸"
经验：一个人看电影的尴尬感，多数在开场 5 分钟内消失
经验：影院窗口期通常 30–90 天，之后上流媒体
```

## 证据强度

- **公开经验**：成本项、窗口期区间
- **推断**：通勤时间因城市差异极大，需按自己情况折算
- **计算**：2 小时片 + 1 小时间隔 = 3 小时，占一个工作日晚上的全部余量

## 不适用的情况

- 需要讨论/教学的片子：家里可暂停更适合
- 带孩子的场景：影院约束反而增加成本

## 常见错法

- **为了"不浪费票"看一部不感兴趣的片**
- **选中间座位却频繁进出**
- **把"一个人"当成需要克服的事**

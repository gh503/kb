# 一次旅行怎么规划才不赶

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 怎么玩才不亏时间

## 结论

**一天最多放两个"需要专程去"的点，其余留白。** 赶的根源不是行程少，
是**把交通时间当成了零**——两个景点之间常常要 40 分钟，一天来回就吃掉两小时。

## 一个能用的日程模板

```text
上午：一个主要目的地（9:00–12:00）
中午：吃饭 + 休息（12:00–14:00，不安排景点）
下午：一个次要目的地 或 随便走走（14:00–17:00）
晚上：吃饭、回住处，不排"必须去"的项目
```

**每天只留一个"错过会遗憾"的点**，其余都可以舍弃——这样即使堵车、下雨，也不至于全乱。

## 规划的四个动作

1. **先定住宿，再定行程**：住哪决定你每天要花多少时间在路上
2. **查交通时间，不查距离**：3 公里可能 40 分钟
3. **当天只排一条主线**：其余按体力和天气调整
4. **留一个"什么都不做"的半天**：旅行里最贵的不是门票，是赶

## 出发前值得做的三件事

```text
1. 把证件、订单、保险截图存到手机本地（不要只存云端）
2. 查目的地当天的天气与闭馆日（很多博物馆周一闭馆）
3. 记下住处地址的中文/当地语言写法，打车时用
```

## 数字与阈值（经验判断）

```text
每日主力点：1–2 个
交通占比：一天里交通超过 3 小时，就算"赶"
行程密度：住 4 晚以上，至少留 1 个不安排的一天
单程通勤：超过 90 分钟的目的地，值得单独安排一天
```

## 证据强度

- **公开经验**：行程密度与交通时间的关系是旅行经验的常见总结
- **区间**：数值来自经验，城市与交通方式差异大
- **推断**："每天只留一个遗憾点"是按容错率推的

## 不适用的情况

- 跟团/包车：路线由组织方定，留白空间小
- 专程打卡型旅行（演唱会、赛事）：本来就以单点为核心

## 常见错法

- **一天塞四个景点**：照片有了，什么都没看清
- **住得便宜但很远**：省下的房费花在路上
- **不查闭馆日**：白跑一趟
- **把行程排满当作"会玩"**：回来比上班还累

# 一部电影值不值得看

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 怎么玩才不亏时间

## 结论

**用"20 分钟法则"决定要不要继续：20 分钟还没被抓住，就关掉。**
两小时的片子，试错成本从 120 分钟降到 20 分钟——这是最划算的一条娱乐规则。

## 评分怎么读

| 分数 | 含义 |
| --- | --- |
| 8.5+ 且评分人数多 | 大概率不会差，但可能不合你的口味 |
| 7–8.5 | 类型片主力区，看题材对不对 |
| 6–7 | 有硬伤，但可能有你喜欢的元素 |
| < 6 | 除非有明确理由（导演、演员、猎奇），别花时间 |

**评分高 ≠ 你会喜欢。** 先看"和你口味接近的人"怎么评，比自己瞎猜准。

## 20 分钟法则怎么用

```text
第 0–5 分钟：看有没有钩子（人物、悬念、画面）
第 5–20 分钟：能不能说出"接下来我想知道什么"
说不出 → 关掉，不欠它
```

**"都看了半小时了"是最典型的沉没成本。** 已经花掉的时间，关掉不会退回来，但继续看会再花 100 分钟。

## 三个比评分更有用的信号

1. **导演/编剧的上一部**你看得下去吗
2. **类型是不是你今晚想要的**（累的时候看烧脑片，多半看不进去）
3. **片长与时段**（明天上班，2.5 小时的片子本来就不合适）

## 数字与阈值（经验判断）

```text
试看窗口：20 分钟
单片时长：> 150 分钟建议分两次看
每周观影量：3–5 部以上，容易变成"刷完就忘"
选片耗时：超过 20 分钟，随便挑一部比继续挑更划算
```

## 证据强度

- **公开经验**：评分分布与类型片区间是观影社区的常见观察
- **推断**："20 分钟法则"是按试错成本设计的，非实测
- **未验证**：我没有你的观影偏好数据

## 不适用的情况

- 慢热型文艺片：前 20 分钟本就没有钩子，可以放宽到 40 分钟
- 陪人看：决定权不在你

## 常见错法

- **因为"评分高"硬看完**：口碑是平均值，不是你的口味
- **边看边刷手机**：两小时什么都没得到
- **选片比看片久**：选择成本超过内容本身

# 拍照怎么从随手拍变成能看

> **深度** 取舍 ｜ **类型** 方法 ｜ **链** 追剧与防坑

## 结论

**只改三件事：光线、主体、留白。** 手机够用，不需要先买相机。
多数"不好看"的照片，问题都在**逆光、主体不明、画面塞满**。

## 三件事，按顺序

```text
1. 光线：让光从侧面或正面照到主体，不要背光
2. 主体：一张照片只说一件事，画面里别有第二个抢眼的东西
3. 留白：主体不放在正中央，留出一侧空间
```

**"侧光"最容易出效果**：它能显出质感与立体感，正面光则平。

## 手机上的三个开关

| 设置 | 用法 |
| --- | --- |
| 网格线 | 打开，用三分法放主体 |
| 曝光补偿 | 点屏幕后上下滑动，暗了往上调 |
| 人像/大光圈模式 | 拍人和小物件时用，背景虚化 |

**"曝光补偿"最实用**：多数手机默认画面偏暗，点主体后往上拖一点立刻改善。

## 常见场景的做法

- **拍食物**：靠窗、侧光、45° 角，别开闪光灯
- **拍人**：光在脸侧，别让太阳在脑后
- **拍风景**：地平线放三分线上，别放正中
- **拍夜景**：找支撑（栏杆、桌面），别手举

## 拍完只做两件事

```text
1. 裁剪：去掉多余边缘，让主体更明确
2. 调亮/调对比：不要加滤镜，先调基础参数
```

**"先裁剪再调色"**：裁掉一半画面，往往比调色更有效。

## 数字与阈值（经验判断）

```text
网格：三分法（主体在 1/3 线交点）
曝光：暗部提亮 0.3–0.7 档即可
裁剪：常裁掉 20%–40% 边缘
相机预算：先用手上的手机拍 500 张，再考虑买
```

## 证据强度

- **公开经验**：光线方向、三分法、曝光补偿，是摄影入门的通用原则
- **数值**：来自经验
- **推断**："先裁剪再调色"按改善幅度推的
- **未验证**：审美偏好差异大

## 不适用的情况

- 专业输出（印刷、商业）：需要相机与后期
- 纪实/新闻：不裁剪，保留原始信息

## 常见错法

- **先买设备**：手机足够练构图
- **全靠滤镜**：掩盖不了主体不明
- **每张都拍十几遍**：选片成本超过拍摄

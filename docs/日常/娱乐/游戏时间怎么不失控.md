# 游戏时间怎么不失控

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 怎么玩才不亏时间

## 结论

**失控的从来不是"玩多久"，是"停不下来"。** 单机有终点，联机没有——
真正需要设边界的是**没有结束条件的游戏**：排位、日常任务、开箱、无限地图。

## 先分清两类

| 类型 | 结束条件 | 风险 |
| --- | --- | --- |
| 单机/剧情 | 有终点 | 低，但容易"再来一回合" |
| 联机/服务型 | 没有终点 | 高：日活任务、赛季、社交压力 |

**服务型游戏的设计目标就是让你每天都来。** 认清这一点，比靠意志力有用。

## 三条可执行的边界

```text
1. 以"局"为单位，不以"小时"为单位：
   打完这局就停（而不是"再玩一小时"）
2. 关掉所有推送与"每日提醒"
   它不是提醒，是拉回机制
3. 设定"不做"清单：
   不做每日任务、不抽卡、不为了赛季奖励硬肝
```

第 3 条最有效：**放弃"全收集"的执念，游戏立刻变轻。**

## 一个自测

```text
玩完之后：
  放松、想睡觉 → 正常
  空虚、烦躁、还想再来一局 → 已经在被牵着走
  为了"不断签"而上线 → 这是任务，不是娱乐
```

## 数字与阈值（经验判断）

```text
单次时长：60–90 分钟，超过容易影响睡眠
每周：10 小时以内多数人不影响生活
睡前：结束前留 30 分钟缓冲，别玩到躺下
中断成本：一个赛季不玩，损失的只是奖励，不是乐趣
```

## 证据强度

- **公开经验**：服务型游戏的留存设计（每日任务、赛季）是行业公开做法
- **区间**：时长建议来自经验，个体差异大
- **推断**："以局为单位比以小时为单位有效"是按中断点清晰度推的

## 不适用的情况

- 以游戏为职业或副业：目标不同，另算
- 与朋友固定的联机时间：社交价值本身是收益

## 常见错法

- **用"再玩一小时"约束自己**：一小时里可以再开三局
- **保留每日任务**：每天都来，就很难只来一会儿
- **把游戏当解压唯一方式**：压力大时最容易失控

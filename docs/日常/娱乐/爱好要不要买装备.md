# 爱好要不要买装备

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 怎么玩才不亏时间

## 结论

**先玩三次再买装备。** 三次之后还在玩，说明是爱好；三次之后没再打开，说明是想象。
装备会把"想象"变成"沉没成本"，让你更难承认不喜欢。

## 三次法则怎么用

```text
第 1 次：借或用最低配（租、二手、朋友的）
第 2 次：换一个场景再玩（不同时间、不同人、不同地点）
第 3 次：自己主动想去（不是"买了不能浪费"）
三次都成立 → 再考虑买
```

**关键是第 3 次的动机**：如果驱动力是"东西已经买了"，那不是爱好。

## 装备的三档花钱法

| 档 | 买什么 | 花多少 |
| --- | --- | --- |
| 入门 | 能用、便宜、二手 | 不超过一个月可支配零花 |
| 进阶 | 用了半年后，知道缺什么再换 | 卖掉旧的补差价 |
| 发烧 | 明确知道差别在哪才买 | 单独预算，不动应急金 |

**第 2 档的判据**：你能说出"现在这个哪里不够用"。说不出，就是还没到。

## 常见爱好的入门陷阱

- **摄影**：先用手上的手机拍 500 张，再谈镜头
- **露营**：先租一次装备，体验"收帐篷"这一步
- **乐器**：先租或买二手，三个月后还在练再换
- **健身**：先在家练四周，再考虑办卡

## 数字与阈值（经验判断）

```text
试用次数：3 次
入门花费：不超过一个月可支配零花
升级判据：能用一句话说出旧装备的具体不足
回本判断：装备价 ÷ 预计使用次数，超过单次体验价就不值
```

## 证据强度

- **公开经验**："先用最低配验证兴趣"是各类爱好社区的通行的建议
- **推断**："三次法则"是按兴趣衰减规律设计的，非实测
- **未验证**：不同爱好的入门成本差异极大

## 不适用的情况

- 安全相关（攀岩绳、头盔、护具）：不能省，必须买合格的
- 已经有明确长期计划的（报名了比赛）：按计划配置

## 常见错法

- **先买齐再开始**：装备到位了，兴趣没了
- **一步到位买顶配**：还不知道自己要什么
- **把装备当身份**：花钱买的是"我是这种人"的想象

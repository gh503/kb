## 结论

**停不下来不是意志力差，是"可变奖励 + 零成本切换"这两件事一起作用。**
判据很简单：**如果每一条都要你花 5 秒决定要不要看，你早就停了**；自动播放把"决定"这一步删掉了。

## 三个机制

```text
可变奖励：下一条可能好可能差，不可预测 → 多巴胺在"期待"时释放最多
零成本切换：上滑即换，不需要任何决策成本
无终点：没有"看完"的信号（不像一集剧有片尾）
```

**"再看一条就睡"** 正是这套结构设计的落点：永远有"下一条"。

## 有效的四种改法（按效果排）

```text
1. 加摩擦：把 App 放到二级文件夹、退出登录、关掉自动播放
2. 设边界：用系统"应用限时"，到点强制退出（比自律可靠）
3. 换默认：把"打开手机"的默认动作换成别的（读书/播客/走路）
4. 改环境：睡前把手机放在卧室外（物理距离最有效）
```

**"靠意志力少刷"** 在与自动播放对抗时，胜率很低。

## 一个可执行的实验

```text
第 1 周：只记录（每天刷多久、什么时候刷），不改变
第 2 周：只做一件事——关掉自动播放
第 3 周：加一条——睡前手机放客厅
对比三周的时长，选有效的那条保留
```

## 数字与阈值（公开经验）

```text
经验：短视频单条 15–60 秒，一小时的"条数"是 60–240 条
经验：关掉自动播放，多数人使用时长下降 20%–40%
经验：睡前 1 小时不看屏幕，入睡时间平均提前（个体差异大）
经验：把 App 移出首屏，打开率明显下降（摩擦 > 自律）
```

## 证据强度

- **公开经验**：机制描述、下降幅度区间
- **推断**：个体差异大，区间只用于判断方向
- **计算**：每天 1.5 小时 × 365 天 ≈ 547 小时 ≈ 23 个整天

## 不适用的情况

- 工作需要（运营/剪辑）：要区分"工作用"与"消遣用"
- 已经能自控：不需要额外机制

## 常见错法

- **只删 App 不关自动播放（网页版照样刷）**
- **用"看完这条就停"当规则**
- **把责任全归给自己，不改环境**

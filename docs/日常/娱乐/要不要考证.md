# 要不要考证

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 学一样东西

## 结论

**先问"谁会看这个证"——答不出具体的人或场景，就别考。**
证书的价值几乎全部来自**外部要求**（准入、加分、投标资质），很少来自"证明我学过"。

## 三类证书，价值完全不同

| 类型 | 例子 | 价值 |
| --- | --- | --- |
| 准入类 | 驾照、教师资格、执业资格 | 高：没有就不能干 |
| 门槛/加分 | 语言等级、职业资格 | 中：特定场景有用 |
| 兴趣/技能证明 | 各类培训证书 | 低：多数雇主不看 |

**第一类必须考，第二类看场景，第三类通常只是给自己一个截止日期。**

## 判断值不值得的四个问题

```text
1. 有明确的"必须有"的要求吗？（招聘、准入、评职称）
2. 考下来能带来可量化的变化吗？（涨薪、资格、机会）
3. 投入产出比：时间 × 费用 vs 预期收益
4. 有没有替代路径？（作品集、实操经验、内部推荐）
```

**第 4 条最容易被忽略**：很多"考证"的位置，实际用的是作品与经验。

## 什么时候考是有用的

- **给自己设死线**：明知证没用，但你需要一个截止日期来学完
- **跨行敲门**：没有相关经历时，证是"我愿意投入"的证据
- **单位有硬要求**：评职称、投标、资质

**"给自己设死线"是诚实的理由**——但要承认它，别包装成"提升竞争力"。

## 数字与阈值（经验判断）

```text
备考时间：常见 1–6 个月（按难度）
费用：几百到几千，超出一个月结余要慎重
判断期：报名前花 30 分钟查"招聘要求里是否出现"
沉没成本警戒：已投入超过预期 1.5 倍且看不到进展 → 重新评估
```

## 证据强度

- **公开经验**：证书价值取决于外部要求，是职业规划的常见判断
- **区间**：时间与费用为常见范围
- **推断**："先问谁会看"按需求侧推的
- **未验证**：不同行业差异极大，**以目标岗位的实际要求为准**

## 不适用的情况

- 准入类证书：没有讨论空间，必须考
- 单位统一要求：按单位规定

## 常见错法

- **用考证代替实践**：证有了，活还是不会干
- **考一堆"看起来有用"的**：简历上堆叠，反而显得没方向
- **不查招聘要求就报名**：考完发现没人看

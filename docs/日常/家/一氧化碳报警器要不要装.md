# 一氧化碳报警器要不要装

> **深度** 实操 ｜ **类型** 取舍 ｜ **链** 燃气与用电安全

## 结论

**只要家里有燃气热水器、燃气灶、壁炉或烧炭，就应该装。** 一氧化碳无色无味，
**中毒时人不会觉得难受，只会想睡**——这是它最危险的地方。

## 谁最该装

| 情况 | 风险 |
| --- | --- |
| 燃气热水器装在浴室或室内 | 高（最常见的中毒场景） |
| 用炭火取暖/吃火锅（室内） | 高 |
| 车库连着住房、车内长时间怠速 | 中高 |
| 只有电热水器、无燃气 | 低（但仍可装） |

## 装在哪

```text
装在卧室外、通往卧室的走廊，或每层楼至少一个
不要装在灶台正上方（油烟会误报、也会损坏传感器）
不要装在角落或家具后面（气流到不了）
高度：普通报警器天花板下 30cm 内，或按说明书
```

## 中毒是什么感觉

**这是本页最该记住的一段**：

```text
早期：头晕、头痛、恶心、乏力 —— 很像感冒
进展：想睡觉、意识模糊、走路不稳
危险：睡着后不再醒来
```

**关键判据：一家人同时出现类似"感冒"的症状，或离开屋子就好转、回来又犯——高度怀疑一氧化碳。**

## 数字与阈值（经验判断）

```text
报警阈值：常见 30–70 ppm（不同型号不同）
传感器寿命：5–7 年，到期必须整机更换
测试：每月按一次测试键
更换电池：按型号，常见 1 年
```

**"传感器寿命"这条最容易被忽略**：报警器不是装一次管一辈子，过期后它不会报错，只是不再灵敏。

## 证据强度

- **公开经验**：一氧化碳无色无味、症状类似感冒、需装报警器，是各地消防与急救机构的共识
- **阈值与寿命**：来自产品与安全标准，**以说明书和当地标准为准**
- **推断**："装在卧室外"是按睡眠时段风险最高推的
- **重要**：怀疑中毒 → 立刻开窗、撤离、打 120，不要留在室内判断

## 不适用的情况

- 纯电家庭：风险主要来自车库与室外，可按需
- 已有集中烟感/消防系统：确认是否含 CO 检测

## 常见错法

- **装在灶台上方**：油烟导致误报与损坏
- **用十年不换**：传感器早已失效
- **买了不装**：放在柜子里等于没买

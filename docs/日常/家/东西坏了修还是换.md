# 东西坏了修还是换

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 家里那些要命的常识

## 结论

**用一条线判断：维修价超过新价的 50%，且已用超过一半寿命，就换。**
低于这条线先修；但如果修完还会再坏第二次，直接换。

## 三个判断数

```text
1. 维修报价 ÷ 新机价格
   < 30% → 修
   30%–50% → 看剩余寿命
   > 50% → 换

2. 已用年限 ÷ 设计寿命
   > 0.5 且要修 → 倾向换

3. 修完能再用几年？
   小于 1 年 → 不值
```

## 设计寿命参考

| 家电 | 大致寿命 |
| --- | --- |
| 冰箱、洗衣机 | 8–12 年 |
| 空调 | 8–10 年 |
| 热水器 | 6–10 年 |
| 微波炉、电饭煲 | 5–8 年 |
| 手机 | 3–5 年（电池 2–3 年） |

**能效也进账**：10 年老冰箱换成新一级能效，电费差常能抵掉一部分购机款。

## 值得修的信号

- 故障单一、可定位（如排水泵、皮带、密封条）
- 配件能买到、维修有保修（常见 90 天）
- 机器整体状况好，只是某个部件老化

## 该换的信号

- 主板、压缩机、变频模块损坏
- 维修要拆机并影响结构（漏水、锈蚀）
- 厂家已停产、配件断供
- 安全隐患（漏电、燃气类异常）

## 数字与阈值（经验判断）

```text
维修价/新价：< 30% 修；> 50% 换
维修保修：常见 90 天，要问清
上门费：常见 30–100 元，可抵扣维修费
以旧换新：常能抵 5%–15% 新机价
```

## 证据强度

- **公开经验**：50% 法则与设计寿命是家电维修行业的常见参考
- **区间**：寿命与费用来自经验，品牌差异大
- **推断**："修完还会再坏就换"是按重复故障成本推的

## 不适用的情况

- 有情感价值或已停产的物件：价值判断不适用经济账
- 租住房：由房东决定，你只需报修并留记录

## 常见错法

- **只看维修报价不看剩余寿命**：修完第二年又坏
- **不索取维修保修**：同一故障再坏要再付一次
- **忽略能效**：老机器电费长期更高

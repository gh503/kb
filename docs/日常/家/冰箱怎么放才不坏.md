# 冰箱怎么放才不坏

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 家里那些要命的常识

## 结论

**温度、分区、别塞满——三件事决定了食物坏得快不快。**
多数"冰箱不保鲜"不是冰箱的问题，是冷藏室 7℃ 还塞得像仓库。

## 温度怎么设

```text
冷藏：0–4℃（多数冰箱建议 4℃ 以下）
冷冻：-18℃ 及以下
判断：放一个温度计，比看旋钮可靠
```

**旋钮数字不是温度**：机械旋钮上"3"代表档位，不是 3℃。新冰箱建议放个独立温度计。

## 分区摆放

| 位置 | 放什么 | 为什么 |
| --- | --- | --- |
| 上层靠里 | 熟食、剩菜（密封） | 温度最稳定 |
| 中层 | 蛋、奶、豆制品 | 常用且怕温度波动 |
| 下层靠里 | 生肉、海鲜（密封托盘） | 防汁液滴落污染 |
| 抽屉 | 蔬果（分开） | 湿度可调 |
| 门架 | 饮料、调味 | 温度波动最大，别放奶和蛋 |

**生熟分开、上熟下生**是核心，防的是交叉污染。

## 不该放冰箱的

```text
土豆、洋葱、蒜（阴凉干燥即可，冷藏易发芽/变软）
面包（冷藏加速老化，冷冻反而好）
热带水果（香蕉、芒果，低温会黑）
蜂蜜（会结晶，不影响安全但难用）
```

## 三个常见错误

1. **塞满**：冷气不循环，温度不均——留出 20% 空隙
2. **热菜直接放**：结霜、费电、影响其他食物
3. **不封口**：串味、失水、细菌交叉

## 数字与阈值（经验判断）

```text
冷藏温度：0–4℃
冷冻：≤ -18℃
空隙：至少留 20%
剩菜：冷藏不超过 3 天，吃前彻底加热
冷冻肉：猪牛羊 6–12 个月，禽类 9 个月，鱼 3–6 个月（家用冰箱）
```

## 证据强度

- **公开经验**：冷藏 4℃ 以下、冷冻 -18℃ 是通行的食品安全建议
- **区间**：存放时长来自常见指南，家用冰箱开关频繁会缩短
- **推断**："门架温度波动最大"是按结构位置推的

## 不适用的情况

- 药品、婴幼儿食品：按包装说明，可能需要更严的温度
- 特殊食材（生食海鲜）：按商家建议，不宜久存

## 常见错法

- **看旋钮当温度**：差好几度
- **热菜放凉再放**：室温放置超过 2 小时风险更高，应尽快冷藏
- **蔬果全塞一起**：乙烯会催熟旁边的

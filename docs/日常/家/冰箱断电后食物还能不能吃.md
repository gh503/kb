# 冰箱断电后食物还能不能吃

> **深度** 实操 ｜ **类型** 边界 ｜ **链** 漏水断电与虫害

## 结论

**看"断电多久 + 门开没开"，不看食物摸起来凉不凉。**
冷藏室密闭不开门，大致能保温 4 小时；冷冻室装满时能撑 24–48 小时。

## 两条判据

```text
冷藏（目标 0–4℃）：
  ≤ 4 小时且没开过门 → 多数可留
  > 4 小时 或 温度升到 4℃ 以上 → 易腐食物丢弃

冷冻（目标 -18℃）：
  半满 → 约 24 小时
  装满 → 约 48 小时
  仍在 -18℃ 或表面有冰晶 → 可再冻（品质下降）
```

**"摸起来还凉"不可靠**：食物内部升温比表面慢，细菌已经在繁殖。

## 该扔与可留

| 该扔 | 可留 |
| --- | --- |
| 肉类、海鲜、熟食、豆制品 | 硬质奶酪、黄油 |
| 切开的水果、剩菜 | 完整蔬果（短期） |
| 牛奶、酸奶、开封酱料 | 未开封饮料、调味品 |
| 已解冻且升温的冷冻肉 | 仍带冰晶的冷冻食品（需尽快吃完） |

**判据是"易腐"而不是"贵不贵"**：一盒剩饭比一块黄油危险得多。

## 怎么判断能不能再冻

```text
仍坚硬、表面有冰晶 → 可再冻，但口感会变差，尽快吃完
已软化但仍在 4℃ 以下 → 可熟制后食用，不要再冻生食
已升温到室温 → 丢弃
```

## 减少损失的做法

1. **断电时少开门**（每开一次，冷气损失明显）
2. **冷冻室放几瓶冻水**：断电时可延长保温
3. **提前知道会停电**：把冷冻温度调低、集中放置
4. **断电超过 4 小时**：借冰块或保温箱转移易腐食物

## 数字与阈值（经验判断）

```text
冷藏保温：约 4 小时（不开门）
冷冻保温：半满 24 小时，装满 48 小时
危险温区：4–60℃
冷藏温度：0–4℃
解冻后再冻：仅在仍带冰晶时
```

## 证据强度

- **公开经验**：4 小时/24–48 小时与"危险温区"是食品安全领域的通行建议
- **时间**：为常见区间，**与环境温度、冰箱型号、装载量有关**
- **推断**："摸起来凉不可靠"按热传导与细菌繁殖速率推的
- **重要**：不确定就丢弃；食源性疾病对老人、儿童、孕妇风险更高

## 不适用的情况

- 断电时环境温度很高（夏季无空调）：保温时间明显缩短
- 特殊食品（婴幼儿配方、医用冷藏药品）：按各自要求处理

## 常见错法

- **反复开冰箱查看**：加快升温
- **闻味道判断**：致病菌不一定产味
- **把解冻又冻的肉再冻一次**：品质与安全都下降

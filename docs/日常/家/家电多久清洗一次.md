# 家电多久清洗一次

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 家里那些要命的常识

## 结论

**不用记十几种家电，只要记住三个频率：每月、每季、每年。**
真正影响健康和电费的只有四样：空调滤网、洗衣机内筒、油烟机、热水器。

## 四样必做

| 家电 | 频率 | 做法 |
| --- | --- | --- |
| 空调滤网 | 每 1–2 个月（用季） | 拆下清水冲洗，阴干再装 |
| 洗衣机内筒 | 每 1–3 个月 | 筒清洁程序 + 专用清洁剂，洗完开门晾 |
| 油烟机滤网 | 每 1–3 个月 | 热水 + 碱性清洁剂浸泡 |
| 热水器 | 每 1–2 年 | 除垢（硬水地区更勤） |

**空调滤网是最划算的一项**：五分钟，直接影响制冷效率与电费。

## 三个被忽略的地方

```text
1. 洗衣机橡胶圈：霉斑藏在这里，擦干比清洗更重要
2. 冰箱排水孔：堵了会积水、异味
3. 空调出风口/蒸发器：滤网干净但吹出来有味，说明里面该洗了
```

## 花钱请人的两类

- **空调深度清洗**：内部蒸发器，自己拆容易装不回去
- **热水器除垢**：涉及水电与压力，建议专业

其余（滤网、筒清洁、油烟机滤网）自己做就够。

## 数字与阈值（经验判断）

```text
空调滤网：1–2 个月；深度清洗 1–2 年一次
洗衣机筒清洁：1–3 个月；橡胶圈每次洗完擦干
油烟机：滤网 1–3 个月；内部 1 年一次
热水器：1–2 年除垢（水质硬的地区 1 年）
冰箱：每季度清空擦一次，排水孔每半年通一次
```

## 证据强度

- **公开经验**：这些频率来自家电厂商与家政行业的常见建议
- **区间**：使用强度差异大，做饭多、养宠物要更勤
- **推断**："四样必做"是按健康与能耗影响排的优先级
- **未验证**：我没有你家电的实际使用数据

## 不适用的情况

- 出租房/短期居住：以安全和异味为主，不必做深度保养
- 有过敏或婴幼儿：清洗频率应更高

## 常见错法

- **只洗滤网不洗内筒**：异味来源常在内部
- **洗完立刻关门**：潮湿环境下霉长得更快
- **用强酸强碱洗铝制部件**：会腐蚀

# 家里该备哪些急救物品

> **深度** 入门 ｜ **类型** 清单 ｜ **链** 家里该备什么

## 结论

**分两层备：处理小伤的（创可贴、消毒、纱布）+ 处理意外的（止血、烧伤、烫伤）。**
一次买齐，放在**知道在哪、拿得到**的地方——不是塞在柜子最里面。

## 第一层：小伤够用

```text
清洁：生理盐水、碘伏（不是酒精，伤口更疼）
覆盖：创可贴（多种尺寸）、无菌纱布、医用胶带
工具：小剪刀、镊子、体温计、一次性手套
其他：冰袋（可冷冻那种）、棉签
```

**碘伏比酒精好**：刺激性小，可用于黏膜附近（酒精不行）。

## 第二层：意外够用

| 场景 | 要备什么 |
| --- | --- |
| 出血 | 无菌纱布、弹性绷带、止血带（会用才备） |
| 烧伤烫伤 | 流动水冲 15–20 分钟，不要涂牙膏/酱油；备无菌敷料 |
| 扭伤 | 冰袋、弹性绷带 |
| 过敏 | 抗组胺药（按说明书，儿童按体重） |
| 噎住 | 会用海姆立克比备东西重要 |

**"冲 15–20 分钟"是最常被跳过的步骤**：冲得够久，比涂什么药都重要。

## 存放三条

1. **固定位置**：全家人都知道，且小孩拿不到
2. **干燥避光**：浴室柜不适合存药（潮湿）
3. **每半年清一次**：过期药单独装袋，不随意丢进下水道

## 数字与阈值（经验判断）

```text
碘伏有效期：开封后常见 1–3 个月（看说明）
纱布/创可贴：按包装有效期，受潮即换
清理频率：每 6 个月一次
体温计：电子式常见 3–5 年
```

## 证据强度

- **公开经验**：急救物品清单与"烧伤先冲水"是急救培训的通行内容
- **有效期**：来自产品说明，**以包装标注为准**
- **推断**："分两层"按使用频率与紧急度排的
- **重要**：这是备物清单，不是急救教程；严重出血、无呼吸、大面积烧伤，立刻打 120

## 不适用的情况

- 有慢性病或过敏史：需按医生建议增加专用药（如肾上腺素笔）
- 有婴幼儿：另备儿童剂型与剂量表

## 常见错法

- **只买创可贴**：出血和烫伤处理不了
- **用酒精处理开放伤口**：刺激大、影响愈合
- **药箱放在浴室**：潮湿加速变质

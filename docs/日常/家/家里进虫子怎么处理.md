# 家里进虫子怎么处理

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 漏水断电与虫害

## 结论

**先认种类，再决定"自己清"还是"请人"。**
多数偶见的虫子只需断掉来源（食物、水、缝隙）；**蟑螂、白蚁、臭虫要按流程处理，不能只喷药**。

## 常见种类与对策

| 虫子 | 信号 | 自己能不能处理 |
| --- | --- | --- |
| 果蝇/小飞虫 | 厨房垃圾桶、下水口 | 能：清垃圾、烫下水口、放诱捕 |
| 蚂蚁 | 沿墙成线、找甜食 | 能：封缝隙、用胶饵（不要喷，会分散） |
| 蟑螂 | 夜间出没、粪便黑点 | 能：胶饵 + 封缝隙，持续 2–4 周 |
| 衣蛾/皮蠹 | 衣柜、羊毛制品小洞 | 能：清洗+密封+樟脑类 |
| 白蚁 | 木屑粉、泥线、空鼓 | **不能**：请专业，不要喷药惊动 |
| 臭虫 | 床垫缝、成串咬痕 | **不能**：请专业，自行处理易扩散 |
| 马蜂/蜂窝 | 阳台、空调外机 | **不能**：联系物业/专业 |

**"白蚁不能喷"最重要**：喷药会让它们转移扩散，反而扩大范围。

## 处理三步

```text
1. 断来源：食物密封、垃圾不过夜、下水口盖住、缝隙封堵
2. 断通路：门缝条、纱窗、管道孔洞封堵
3. 再用药：胶饵 > 喷雾（喷雾会让蟑螂/蚂蚁分散）
```

**"先断来源再用药"是顺序问题**：不解决食物与缝隙，喷完还会回来。

## 用药安全

- 有儿童、宠物：优先物理方法，胶饵放在够不到的位置
- 不在厨房台面、餐具附近喷洒
- 用后通风，按说明书剂量
- 不混用多种杀虫剂

## 数字与阈值（经验判断）

```text
蟑螂胶饵：持续用 2–4 周才见效
果蝇：清垃圾 + 烫下水口，3–5 天明显减少
白蚁：发现后 24 小时内联系专业
纱窗：目数 ≥ 18 目可挡小飞虫
垃圾：每天清，不留过夜厨余
```

## 证据强度

- **公开经验**：按虫种分策略、胶饵优于喷雾、白蚁需专业处理，是害虫防治的通行做法
- **时长**：来自经验
- **推断**："先断来源再用药"按复发原因推的
- **重要**：白蚁、臭虫、马蜂请专业机构处理；使用杀虫剂请遵循说明书与安全提示

## 不适用的情况

- 整栋楼出现白蚁：需物业统一防治
- 有婴幼儿/宠物/呼吸道疾病：优先物理与环境治理

## 常见错法

- **见虫就喷**：蟑螂蚂蚁会扩散，更难根除
- **只杀虫不断来源**：两周后又回来
- **自己处理白蚁/臭虫**：扩散风险高

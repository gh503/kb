# 常用药怎么存

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 家里该备什么

## 结论

**分三处存：常用药（易拿）、急救药（固定）、过期药（待处理）。**
最常见的错误不是买错，是**需要的时候发现过期了，或者全家没人记得放在哪**。

## 备什么（按症状，不按药名）

| 症状 | 备什么 |
| --- | --- |
| 发热/疼痛 | 对乙酰氨基酚 或 布洛芬（二选一，别叠加） |
| 感冒鼻塞 | 生理性海盐水喷鼻 |
| 腹泻 | 口服补液盐（比止泻药更重要） |
| 过敏 | 抗组胺药（氯雷他定等） |
| 皮肤小伤 | 碘伏、创可贴 |
| 胃部不适 | 按需，不必常备 |

**"二选一"很重要**：很多复方感冒药已含对乙酰氨基酚，再叠加会超量伤肝。

## 存放四条

```text
1. 干燥避光：不要放浴室、不要放窗台
2. 原包装保存：说明书与有效期一起留着
3. 分开存放：外用药与内服药分盒；成人药与儿童药分开
4. 高处或上锁：小孩拿不到
```

**"原包装"是硬要求**：拆散后看不出有效期与剂量。

## 每半年做一次清点

```text
1. 检查有效期（近 3 个月内到期的标注出来）
2. 检查外观（变色、潮解、胶囊粘连 → 丢弃）
3. 补齐用完的（尤其是补液盐、退烧药）
4. 过期药单独装袋：多数城市有回收点，不要倒进下水道
```

## 数字与阈值（经验判断）

```text
清点频率：每 6 个月
口服液/糖浆：开封后常见 1 个月内用完（看说明）
眼药水：开封后 4 周内
退烧药：单次间隔 ≥ 4–6 小时，24 小时不超过 4 次
```

## 证据强度

- **公开经验**：按症状备药、原包装保存、定期清点，是药学与家庭医生科普的常见建议
- **有效期**：开封后期限来自产品说明，**以说明书为准**
- **推断**："分三处存"按使用场景紧急度排的
- **重要**：本文不是用药建议；儿童、孕妇、有肝肾疾病或正在服药者，用药前请咨询医生或药师

## 不适用的情况

- 慢性病长期用药：按医嘱单独管理，不放入家庭药箱
- 有儿童的 family：需备儿童剂型与体重剂量表，不能用成人量折算

## 常见错法

- **多种感冒药一起吃**：重复成分，伤肝
- **药箱放浴室**：受潮变质
- **过期药继续吃**：有效成分下降，部分会分解出有害物

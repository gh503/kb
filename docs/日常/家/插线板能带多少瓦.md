# 插线板能带多少瓦

> **深度** 入门 ｜ **类型** 量级 ｜ **链** 燃气与用电安全

## 结论

**普通插线板撑 2500W 左右，取暖器、电水壶、电磁炉这类单独占一个。**
烧插座、熔电线，几乎都是"大功率电器共用一个插线板"造成的。

## 先认三个数

```text
家用电压：220V
普通插线板：10A → 220 × 10 = 2200W，标称常写 2500W
空调/大功率专用：16A → 220 × 16 = 3520W，标称常写 4000W
```

**插线板的额定功率写在背面或底部**，先看它，再看电器。

## 常见电器功率（大致）

| 电器 | 功率 |
| --- | --- |
| 手机充电器、路由器 | 5–30W |
| 台灯（LED） | 5–15W |
| 电视 | 80–200W |
| 电脑 | 100–300W |
| 电风扇 | 40–60W |
| 电饭煲 | 400–800W |
| 微波炉 | 700–1200W |
| 电水壶 | 1500–2000W |
| 电暖器/小太阳 | 1000–2000W |
| 电磁炉 | 1800–2200W |
| 空调（1.5 匹） | 1000–1500W（启动瞬间更高） |

## 一条实用规则

```text
同一个插线板上：
  小功率（充电器、台灯、电视、电脑）可以叠加，总数别超过额定的一半
  大功率（水壶、取暖器、电磁炉、微波炉、吹风机）一次只用一个
  两个大功率同时用 → 必跳闸，或者更糟：插座发热
```

**"一半"这条留的是余量**：标 2500W 不等于可以长期跑 2500W。

## 数字与阈值（经验判断）

```text
10A 插线板：2200–2500W
16A 插线板：3500–4000W
长期负载：不超过额定的 50%–80%
线径：10A 用 1.0–1.5mm²，16A 用 2.5mm²
```

## 证据强度

- **公开经验**：功率 = 电压 × 电流，以及插线板额定值标注方式，属于电学常识与产品标识规范
- **功率表**：为常见区间，不同型号差异大，**以铭牌为准**
- **推断**："长期负载不超过 50%–80%"是留余量的经验做法
- **重要**：涉及线路改造、跳闸频繁、闻到焦味，请找持证电工，不要自己拆

## 不适用的情况

- 大功率固定电器（空调、热水器、烤箱）：应走专线与专用插座
- 老旧房屋铝线：承载能力低于同规格铜线，需电工评估

## 常见错法

- **串联多个插线板**：等于把限额叠在一起，风险倍增
- **把插线板放在地毯下或被压住**：散热差
- **只看插头能插进去**：10A 和 16A 插头形状不同，硬插会接触不良

# 摔倒了怎么判断要不要去医院

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 家里该备什么

## 结论

**先别扶起来，先问三句、看三处。** 跌倒后最怕的是**二次伤害**——
盲目拉起可能让骨折移位，或者掩盖了更严重的问题。

## 先做的三件事

```text
1. 不要立刻扶起（除非环境危险：马路、火源、水边）
2. 问三句：哪里疼？头晕吗？记得怎么摔的吗？
3. 看三处：头有没有磕碰、髋部能不能动、手脚有没有变形
```

**"记得怎么摔的"很关键**：记不清，可能是晕厥或脑血管问题，不是单纯摔倒。

## 必须去医院的信号

| 信号 | 可能 |
| --- | --- |
| 髋部/大腿根部疼痛、不能站立 | 髋部骨折（老年人高发） |
| 头部磕碰后呕吐、嗜睡、意识变化 | 颅内出血 |
| 记不清摔倒过程、伴头晕心慌 | 晕厥/心律问题 |
| 手脚变形、异常角度 | 骨折/脱位 |
| 服用抗凝药（华法林等）后摔倒 | 出血风险高，需评估 |

**第一条最容易被低估**：老人摔倒后说"能走一点"，仍可能是骨折。

## 可以先观察的情况

```text
意识清楚、能准确回忆
只有局部淤青或轻微疼痛
能正常活动、负重不加重疼痛
无头部磕碰、无服药影响
```

**观察 24 小时**：疼痛加重、出现新症状，仍要去医院。

## 现场怎么处理

1. **冷敷**淤青处（隔布，15–20 分钟）
2. **不要揉**（可能加重出血）
3. **不要热敷**（急性期 48 小时内）
4. 记录时间与情况，就诊时说明

## 数字与阈值（经验判断）

```text
冷敷：48 小时内，每次 15–20 分钟
观察期：24 小时
头部磕碰：观察 24–48 小时（尤其服抗凝药者）
跌倒后再跌倒：一年内再次跌倒风险显著升高，需查原因
```

## 证据强度

- **公开经验**：跌倒后不急于搬动、髋部与头部为重点检查部位，是急救与老年医学的通行做法
- **阈值**：观察时间来经验，**抗凝药相关判断以医生为准**
- **推断**："记不清过程提示晕厥"按鉴别诊断逻辑推的
- **重要**：本文不是诊断；老人跌倒、头部磕碰、服抗凝药者，建议直接就医评估

## 不适用的情况

- 高处坠落、车祸：按创伤处理，直接打 120
- 明确意识丧失过：即使醒了也要就医

## 常见错法

- **马上扶起来**：可能加重骨折
- **"能走就没事"**：髋部骨折有时仍能勉强行走
- **头部磕碰后让其睡觉**：需观察意识变化，不能一睡了之

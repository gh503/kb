# 清洁剂不能混用

> **深度** 入门 ｜ **类型** 边界 ｜ **链** 家里那些要命的常识

## 结论

**含氯的（84、漂白水）绝对不能和酸性或含氨的混用。** 混了会产生氯气——
轻则咳嗽流泪，重则送医。这一条是家里唯一"会出人命"的清洁常识。

## 四组危险组合

| 组合 | 产生什么 | 常见场景 |
| --- | --- | --- |
| 84 / 漂白水 + 洁厕灵（酸性） | 氯气 | 先刷马桶再倒消毒液 |
| 84 + 含氨玻璃水 | 氯胺气体 | 擦完玻璃再消毒 |
| 84 + 酒精 | 氯仿等刺激性物质 | "双重消毒" |
| 双氧水 + 白醋 | 过氧乙酸，刺激性强 | 混着擦台面 |

**判断口诀：瓶身写"次氯酸钠"的，只能单独用、只兑水。**

## 打翻了怎么办

```text
1. 立刻离开，开窗通风（不要开关电器、不要开抽风机）
2. 至少通风 15–30 分钟再进
3. 出现持续咳嗽、胸闷、呼吸困难 → 就医，说明混了什么
4. 眼睛溅到 → 大量清水冲 15 分钟，再去医院
```

**"开抽风机"是错的**：开关会产生火花，也可能把气体抽到其他房间。

## 安全的替代做法

- 要消毒：84 按说明稀释（常见 1:100），**单独用，用完清水擦一遍**
- 要去水垢：柠檬酸或白醋，**用完后通风，别紧接着用含氯产品**
- 要除油：碱性清洁剂（小苏打、油污净），不与酸性混用

## 数字与阈值（经验判断）

```text
84 稀释：常见 1:100（500mg/L），按瓶身标注为准
通风：混用后至少 15–30 分钟
冲洗眼睛：持续 15 分钟
间隔：含氯与酸性产品，至少间隔到前一种完全擦净并通风
```

## 证据强度

- **公开经验**：含氯消毒剂与酸性物质混用产生氯气，是各地疾控与消防反复提示的安全常识
- **稀释比例**：以产品标签为准，不同浓度差别很大
- **推断**："不要开抽风机"基于开关火花风险，保守起见建议不用
- **重要**：涉及中毒请直接联系急救/中毒咨询，不要只依赖本文

## 不适用的情况

- 工业/商用清洁剂：成分更复杂，必须按 SDS（安全说明）操作
- 家有呼吸道疾病患者或宠物：即使正确使用也应加强通风

## 常见错法

- **为了"更干净"叠加两种**：效果不会更好，风险显著上升
- **把 84 装进饮料瓶**：误服是另一类高频事故
- **不戴手套**：含氯产品长期接触伤皮肤

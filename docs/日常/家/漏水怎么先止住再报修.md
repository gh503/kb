# 漏水怎么先止住再报修

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 漏水断电与虫害

## 结论

**先关阀、再断电、后拍照，最后才打电话。**
漏水的损失九成来自"先打电话、等师傅"的那半小时——**水一直在流**。

## 正确顺序

```text
1. 关进水总阀（厨房或卫生间，多数在表后）
2. 断开受影响区域的电源（别湿手拔插头，去配电箱拉闸）
3. 接水、垫毛巾，把水引向地漏
4. 拍照/录像留证（漏水点、受损物品、水表读数）
5. 打电话：物业、楼上业主、维修
```

**"先关阀"这一步要在平时就找到位置**：真漏水时再找，会浪费十分钟。

## 先判断漏源

| 现象 | 可能来源 | 先找谁 |
| --- | --- | --- |
| 天花板渗水、沿墙流下 | 楼上 | 物业 + 楼上业主 |
| 水表不用水也在转 | 自家管道 | 物业/维修 |
| 只在用水时漏 | 排水管、龙头、软管 | 自己换软管或找人 |
| 外墙渗水、窗边 | 建筑外墙/防水 | 物业 |

**"水表在转"是最快的自测**：关掉所有龙头，看水表是否还走。

## 留证要留什么

```text
漏水点照片（远近各一张）
受损物品清单与照片
水表读数与时间
与物业/邻里的沟通记录
维修单与费用票据
```

**水表读数**最容易被忽略：它能量化漏水量，是索赔依据。

## 责任怎么分

- **楼上漏水**：先协商，物业协调；协商不成可走调解或诉讼
- **公共管道**：通常由物业/维修资金处理
- **自家管道**：自己承担
- **装修导致**：找施工方，保留合同

## 数字与阈值（经验判断）

```text
关阀到止水：应在 2 分钟内（提前确认阀门位置）
报修响应：物业常见 30 分钟–2 小时到场
理赔时效：向保险公司报案常见 48 小时内
软管寿命：橡胶软管 2–3 年更换
```

## 证据强度

- **公开经验**：关阀、断电、留证的顺序，是家庭漏水处置的常见做法
- **时限**：来自经验与常见条款，**以物业与保险合同为准**
- **推断**："先关阀再打电话"按损失速率推的
- **重要**：涉及电路进水，**不要自己处理，先断电再找人**

## 不适用的情况

- 燃气管道漏水/漏气：先撤离，见[闻到燃气味先做什么](闻到燃气味先做什么.md)
- 大面积进水（爆管）：先拉总闸、通知邻居，再报修

## 常见错法

- **先打电话等师傅**：水继续流
- **湿手拔插头**：触电风险
- **不留水表读数**：说不清漏了多少

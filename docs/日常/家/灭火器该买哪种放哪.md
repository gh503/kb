# 灭火器该买哪种放哪

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 家里该备什么

## 结论

**家庭买干粉（ABC）或水基型，一个放在厨房出口附近。**
更重要的判断是：**什么时候不该灭、直接跑**。

## 先分清能灭什么

| 类型 | 适用 | 家庭 |
| --- | --- | --- |
| 干粉 ABC | 固体、液体、气体、电器 | 通用，最常见 |
| 水基型 | 固体、液体（可扑救电器但需断电） | 适合厨房、卧室 |
| 二氧化碳 | 电器、精密设备 | 家庭少用 |
| 灭火毯 | 油锅、身上着火 | 厨房强烈建议备 |

**厨房首选灭火毯**：油锅起火盖毯子或锅盖，**绝对不能用水**。

## 放哪

```text
厨房：出口附近（不是灶台旁，着火时你过不去）
卧室：门口或走廊
位置：离地 1–1.5 米，看得见、拿得到
不要：塞进柜子、放在阳台、放在灶台正上方
```

**"放在出口附近"是核心**：灭火器的用途是"边退边灭"，不是"冲进去救"。

## 什么时候直接跑

```text
1. 火已经高过膝盖、或蔓延到墙面/天花板
2. 房间开始充满烟（烟比火更致命）
3. 灭火器喷完仍未灭
4. 你不知道里面烧的是什么（可能有化学品）
```

**四条任一成立，立刻撤离并打 119，不要返回。**

## 会用比有更重要

```text
拔（保险销）→ 握（喷管对准根部）→ 压（手柄）→ 扫（左右扫射）
站在上风口，背对出口
```

**要对准火焰根部**，不是对着火苗顶端。

## 数字与阈值（经验判断）

```text
家庭配置：至少 1 个 2–4kg 干粉 或 1 条灭火毯
压力检查：每月看压力表指针是否在绿区
更换/维修：出厂满 5 年需检验，10 年报废
灭火毯：一次性使用后更换
```

## 证据强度

- **公开经验**：ABC 干粉的适用范围、灭火器"边退边灭"原则，是消防宣传的标准内容
- **年限**：来自消防产品维护规定，**以现行规定与产品标注为准**
- **推断**："厨房放出口附近"按撤离路径推的
- **重要**：本文只用于判断"买什么、放哪、什么时候跑"，不替代消防培训

## 不适用的情况

- 燃气泄漏引发的火：先关阀再判断，若无法关闭立即撤离
- 锂电池起火（电动车、充电宝）：普通灭火器效果有限，撤离为主

## 常见错法

- **用水灭油锅**：会爆燃
- **放在灶台边**：着火时够不到
- **过期不换**：压力不足等于没有

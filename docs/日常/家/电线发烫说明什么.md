# 电线发烫说明什么

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 燃气与用电安全

## 结论

**发烫只有三种原因：过载、接触不良、线太细（或老化）。**
这三种都不是"忍一忍就好"——**发热是火灾的前兆，不是小毛病**。

## 三种原因怎么分

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 整条线都温 | 过载（接的电器太多） | 减少负载，换更大规格 |
| 只有插头/插座烫 | 接触不良（松动、氧化） | 换插座/插头，别继续用 |
| 老房子、铝线、线径细 | 线径不足或老化 | 找电工评估换线 |

**"只有插头烫"最容易被忽视**：接触电阻大，局部温度能到很高，是常见起火点。

## 三个危险信号

```text
1. 闻到塑料烧焦味（不是灰尘烧的味）
2. 插座面板变色、变形
3. 空开频繁跳闸（不是偶尔一次）
```

出现任一，**先断电，再找人**。不要"再用用看"。

## 自己能做的与不能做的

**能做**：
- 摸插头/插座温度（断电后摸更安全）
- 减少同一插线板上的大功率电器
- 换掉松动、发黄的插座

**不能做**：
- 自己换线、接线（尤其铝线）
- 用胶布缠发热的接头
- 把空开换大一号来"解决跳闸"

**最后一条最常见也最危险**：跳闸是保护动作，换大空开等于拆掉保险。

## 数字与阈值（经验判断）

```text
插座温升：正常接近室温；明显温热（>40℃）就要查
空开跳闸：一个月超过 2 次，必须查原因
线径：10A 用 1.0–1.5mm²，16A 用 2.5mm²
插座寿命：10–15 年，老旧发黄应更换
```

## 证据强度

- **公开经验**：过载/接触不良/线径不足是电气火灾的常见成因，属于消防常识
- **阈值**：温度与跳闸次数来自经验
- **推断**："换大空开等于拆保险"是按保护逻辑推的
- **重要**：涉及线路本体的问题，请持证电工处理；本文只用于判断"要不要找人"

## 不适用的情况

- 大功率设备（空调、热水器）正常工作时插头微温属正常，看是否"明显烫手"
- 新装的线路发热：可能是接线端子没拧紧，应让施工方复查

## 常见错法

- **用排插延长再延长**：负载叠加，线径不够
- **把线压在门缝/地毯下**：散热差 + 磨损
- **跳闸就换大空开**：把保护去掉

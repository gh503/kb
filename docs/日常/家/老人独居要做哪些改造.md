## 结论

**改造的优先级是"防摔 > 求救 > 好找"，而不是"看起来适老"。**
跌倒是最主要的失能原因，所以**扶手、照明、地面防滑**三项的收益远高于换一套家具。

## 三档改造（按性价比）

```text
零成本/几十元：清走地面电线与地毯边、夜灯、常用物品降到腰部高度
几百元：浴室扶手、防滑垫、马桶加高圈、床边扶手、感应灯
几千元以上：淋浴改坐浴/装座椅、地面找平去门槛、紧急呼叫按钮
```

**"先买一堆适老产品"** 不如先把地面清空、把灯换亮。

## 关键尺寸（公开经验）

```text
扶手高度：距地 80–90 cm（坐着起身最省力）
马桶加高：座面 42–45 cm（原座面通常 38–40 cm）
夜灯照度：走道 5–20 lux，起夜不刺眼
门槛高差：≤ 2 cm，超过就要做坡或去掉
```

## 求救与联络

```text
一键呼叫（手环/按钮）+ 至少 1 个邻居电话（贴在墙上）
手机设置紧急联系人 + 医疗急救卡（锁屏可看）
燃气报警与烟感：厨房必装，报警声要 > 75 dB
```

## 数字与阈值（公开经验）

```text
扶手 80–90 cm ｜马桶座面 42–45 cm ｜门槛 ≤ 2 cm ｜报警声 > 75 dB
经验：夜间起夜是跌倒高发时段，走道夜灯最划算
经验：浴室是最危险房间，防滑与扶手优先装
经验：独居老人每天至少一次"报平安"（电话/门磁/水表）
```

## 证据强度

- **公开经验**：尺寸、优先级、报警声阈值
- **推断**：具体尺寸要按身高调整（扶手可按"站立时手腕高度"微调）
- **计算**：扶手 2 根 + 防滑垫 + 夜灯 ≈ 300 元级，远低于一次跌倒的医疗成本

## 不适用的情况

- 与家人同住：求救项的优先级下降，防摔仍是第一
- 认知障碍：需要额外防走失措施（门磁、定位），本文未覆盖

## 常见错法

- **只买产品不清理通道**
- **装扶手但高度不合适**
- **把"能打电话"当成求救方案（摔倒后可能拿不到手机）**

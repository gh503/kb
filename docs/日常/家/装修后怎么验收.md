## 结论

**验收的关键是"在隐蔽前验"，一旦封板封砖，水电与防水就只能靠拆。**
顺序：**水电（打压、通水）→ 防水（闭水）→ 瓦工（空鼓）→ 木工/油漆 → 收口**。

## 水电验收

```text
打压：给水管打压 0.8–1.0 MPa，稳压 30 分钟，压降 ≤ 0.05 MPa
排水：通水试验，看是否返味、是否积水
电路：逐路通电 + 漏保测试（按试验按钮应跳闸）
线径：照明 1.5 mm²、插座 2.5 mm²、空调/厨房 4 mm²（常见做法）
```

## 防水与闭水

```text
闭水：蓄水 2–5 cm，24–48 小时，到楼下看有无渗漏
重点：卫生间、厨房、阳台、管根与阴角
涂刷：墙面返高 ≥ 30 cm（淋浴区 ≥ 180 cm）
```

## 空鼓怎么查

```text
工具：空鼓锤（或螺丝刀柄）逐块轻敲
判据：单块空鼓面积 ≤ 5%（常见标准），整面空鼓率要更低
重点：窗台、阳角、管道背后
```

## 数字与阈值（公开经验）

```text
打压 0.8–1.0 MPa / 30 分钟 / 压降 ≤ 0.05 MPa
闭水 24–48 小时 ｜墙面返高 30 cm（淋浴 180 cm）
空鼓 ≤ 5%/块 ｜地砖空鼓率常见要求 ≤ 5%
经验：验收要在"封板/贴砖"之前做水电与防水
经验：拍照留证（管线路由、打压表读数、闭水水位）
```

## 证据强度

- **公开经验**：打压与闭水参数、空鼓判据
- **推断**：各地标准与合同约定不同，以合同与当地规范为准
- **计算**：闭水 48 小时 ≈ 2 天，比事后拆砖返工（数周）便宜得多

## 不适用的情况

- 老房局部翻新：只验改动区域，但要检查原有管线
- 精装交付：重点转为"设备运行 + 收口"，水电压测由开发商完成

## 常见错法

- **封板后才想起来打压**
- **闭水只看自己家，不去楼下看**
- **空鼓只敲中间，不敲边角**

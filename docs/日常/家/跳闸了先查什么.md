# 跳闸了先查什么

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 漏水断电与虫害

## 结论

**先看是哪种开关跳了，再决定能不能复位。**
漏电保护器（带"T"测试键的）跳闸，说明可能有漏电——**直接复位而不排查，是在拆掉保护**。

## 三种跳闸，三种含义

| 开关类型 | 跳闸含义 | 能不能直接复位 |
| --- | --- | --- |
| 空气开关（过载/短路） | 用电太多或短路 | 拔掉大功率后可试一次 |
| 漏电保护器 | 有漏电 | **先拔掉所有插头再试**，仍跳则查线路 |
| 总闸 | 全屋过载或进线问题 | 谨慎，先分离负载 |

**"带 T 键/复位按钮的"就是漏电保护**：跳闸后有些需要先按下复位钮才能合闸。

## 排查顺序

```text
1. 拔掉/关掉这一路上的所有电器
2. 合闸：能合上 → 逐个插回，找出触发的那一个
3. 合不上（立刻再跳）→ 该回路有短路或线路问题，找电工
4. 漏电保护跳且合不上 → 不要反复试，找电工
```

**"逐个插回"是最有效的定位法**：二分法更快——先插一半。

## 绝对不能做

```text
✗ 换一个更大电流的空开（等于拆掉保险）
✗ 用铜丝/铁丝替代保险丝
✗ 反复合闸十几次
✗ 湿手操作配电箱
```

**"换大空开"是家庭电气火灾的常见成因。**

## 什么情况直接找电工

- 合闸后立刻又跳（短路）
- 闻到焦味、看到插座变色
- 配电箱有嗡嗡声或发烫
- 老房子铝线、多年未检修
- 漏电保护频繁动作

## 数字与阈值（经验判断）

```text
复位次数：同一回路最多试 2 次
跳闸频率：一个月超过 2 次必须排查
空开寿命：机械寿命长，但频繁跳闸后灵敏度会下降
配电箱温度：明显发烫即异常
```

## 证据强度

- **公开经验**：空开与漏电保护的区分、逐个插回定位法，是家庭用电的常见常识
- **数值**：来自经验
- **推断**："不要换大空开"按保护逻辑推的
- **重要**：涉及线路本体的排查必须由持证电工完成，本文只用于判断"要不要找人"

## 不适用的情况

- 老旧铝线住宅：负载能力低，需整体评估
- 商用/多户共用配电：由物业电工处理

## 常见错法

- **直接复位不排查**：漏电保护反复失效
- **同时插回所有电器**：无法定位
- **自己换空开**：规格选错更危险

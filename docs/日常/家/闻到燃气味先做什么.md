# 闻到燃气味先做什么

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 燃气与用电安全

## 结论

**关阀、开窗、走人、在外面打电话。** 顺序不能变——
**在屋里不要开灯、不要打火、不要拔插头、不要打手机**，这些都可能是点火源。

## 正确顺序

```text
1. 关燃气总阀（如果顺手能摸到，且不需要开灯）
2. 开窗通风（推拉窗，别去开排风扇）
3. 离开屋子，走到室外
4. 在室外打电话：燃气公司抢修 / 物业 / 119
5. 不要回去，直到专业人员说可以
```

**第 4 步必须在室外**：在屋里打电话，手机产生的微小电火花也可能引燃。

## 绝对不要做的

| 不要 | 为什么 |
| --- | --- |
| 开灯、关灯 | 开关瞬间有电弧 |
| 打火机试漏 | 直接点燃 |
| 开抽油烟机/排风扇 | 电机与开关可能打火 |
| 在室内打电话 | 同上 |
| 用明火找漏点 | 最危险的做法 |

## 怎么判断是不是漏气

**闻到味道就够了，不要去找漏点。** 想确认的话，用肥皂水涂在接头处看有没有气泡——
但**这是在"味道很淡、且已开窗通风"的前提下**，不确定就直接撤离。

## 日常预防

- 燃气软管：橡胶管 2 年更换，金属波纹管更耐久
- 灶具：带熄火保护
- 睡前/出门前：关灶前阀
- 一年一次：请燃气公司安检（多数地区免费）

## 数字与阈值（经验判断）

```text
橡胶软管：2 年更换（部分地区要求 1.5 年）
金属波纹管：8–10 年
安检：每年 1 次
报警器：天然气装在高处（比空气轻），液化气装在低处（比空气重）
```

**报警器位置这条最容易装错**：天然气往上飘，探测器要装高；液化石油气往下沉，要装低。

## 证据强度

- **公开经验**：关阀、通风、撤离、室外报警的顺序，是各地燃气公司与消防反复宣传的标准做法
- **更换周期**：来自燃气行业通行建议，**以当地燃气公司规定为准**
- **推断**："不要开抽风机"基于电机与开关可能产生火花，保守起见建议不用
- **重要**：真怀疑泄漏，任何判断都不如先撤离

## 不适用的情况

- 管道燃气与瓶装液化气：气味与扩散方向不同，但处置顺序一致
- 一氧化碳（无味）：闻不到，靠报警器与通风，见[一氧化碳报警器要不要装](一氧化碳报警器要不要装.md)

## 常见错法

- **先找漏点**：把时间花在危险动作上
- **开窗后回去拿东西**：浓度可能仍在危险区间
- **以为"味道淡就没事"**：泄漏量会变化

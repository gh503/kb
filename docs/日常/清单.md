# 清单：出门前后能直接勾的表

> 六张表，对应六件容易漏东西的事。**任何一项没过，先别出门/别签/别买。**

## 一、看病前

出处：[看病一次要带什么](事务/看病一次要带什么.md)

| # | 检查 | 标准 |
| --- | --- | --- |
| 1 | 证件 | 身份证 + 医保卡（或电子医保） |
| 2 | 记录 | 上次报告、正在吃的药（拍照即可） |
| 3 | 空腹 | 确认是否需空腹 8–12 小时 |
| 4 | 院区科室 | 确认去哪个院区，别跑错 |
| 5 | 支付 | 手机能付 + 少量现金 |

**最容易漏：第 3 项。** 吃了早饭去抽血，等于白跑。

## 二、租房签约前

出处：[租房签约要看清什么](事务/租房签约要看清什么.md)

| # | 检查 | 标准 |
| --- | --- | --- |
| 1 | 产权人 | 房产证名字 = 出租人身份证 |
| 2 | 二房东 | 有委托书 + 原合同剩余期限够长 |
| 3 | 押金条款 | 金额 + 退还时限（7–15 日内）写进合同 |
| 4 | 维修责任 | 结构/家电老化归房东 |
| 5 | 水电读数 | **入住当天抄表并写进合同** |
| 6 | 物品清单 | 拍照，列进合同附件 |

**第 5 项最省钱**：没抄表，退租时容易被扣一笔。

## 三、搬家前三天

出处：[搬家怎么少踩坑](事务/搬家怎么少踩坑.md)

| # | 检查 | 标准 |
| --- | --- | --- |
| 1 | 报价 | 问清几车几人几小时、超时费、楼层费 |
| 2 | 照片报价 | 先发照片/视频让对方报价 |
| 3 | 断舍离 | 提前 3 天清掉不搬的 |
| 4 | 每箱标注 | 写房间 + 内容 |
| 5 | 第一天箱 | 洗漱、换洗、充电器、常用药、纸巾 |
| 6 | 贵重物品 | 证件与贵重自己带 |

## 四、旅行出发前

出处：[一次旅行怎么规划才不赶](娱乐/一次旅行怎么规划才不赶.md)

| # | 检查 | 标准 |
| --- | --- | --- |
| 1 | 行程密度 | 每天 ≤ 2 个"专程去"的点 |
| 2 | 交通时间 | 已查实际耗时（不是距离） |
| 3 | 闭馆日 | 已查博物馆/景点当天开放 |
| 4 | 离线资料 | 证件、订单、保险截图存本地 |
| 5 | 住址写法 | 有当地语言/中文地址，打车用 |
| 6 | 留白 | 至少留半个"什么都不做"的时段 |

## 五、买大件前

出处：[大额消费前问什么](钱/大额消费前问什么.md) · [爱好要不要买装备](娱乐/爱好要不要买装备.md)

| # | 检查 | 标准 |
| --- | --- | --- |
| 1 | 每次使用成本 | 价格 ÷ 预计使用次数 |
| 2 | 替代方案 | 借/租/二手/先用旧的 |
| 3 | 三个月后还用吗 | 想不清就先不买 |
| 4 | 动了应急金吗 | 动了就不买 |
| 5 | 分期真实年化 | > 10% 要慎重 |
| 6 | 安全类例外 | 头盔、绳索不能省 |

## 六、混清洁剂之前

出处：[清洁剂不能混用](家/清洁剂不能混用.md)

| # | 检查 |
| --- | --- |
| 1 | 瓶身是否含"次氯酸钠"（84/漂白水） |
| 2 | 另一种是否酸性（洁厕灵、白醋、柠檬酸）或含氨 |
| 3 | 含氯的只单独用、只兑水 |
| 4 | 混过之后立刻离开、开窗通风 15–30 分钟 |
| 5 | **不要开抽风机、不要开关电器** |

**这张表没有"差不多"，只有"能混"和"不能混"。**

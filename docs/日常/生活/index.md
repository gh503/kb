## 这一域怎么写的

每页固定给四样东西：

1. **结论**：先说要做什么，一句话
2. **数字与阈值**：能代入的数（几个月、多少元、几次）
3. **证据强度**：标明是公开经验还是推断——日常知识里"我就是这么做的"太多了，必须区分
4. **不适用的情况**：什么条件下这条不成立

## 一条底线

**不写"应该多运动""要早睡"这种正确但没用的话。**
要么给出可执行的步骤和数字，要么不写。

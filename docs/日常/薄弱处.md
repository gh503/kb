# 薄弱处：日常知识哪里可能错

> 日常内容最容易犯的错不是算错，是**把"大家都这么说"当成"验证过"**。
> 这一页把 20 条里我不放心的挑出来，写清错在哪、什么能推翻它。

## 每一条怎么自查

### 1. 睡眠时长

```text
判据不是小时数，是白天状态：
  早上不用闹钟能起 + 下午不靠咖啡 + 周末不需要补觉
三条都成立 → 你的时长就是够的，不用管别人睡几小时
```

### 2. 体检阈值

```text
"超 2 倍"适用于转氨酶这类波动大的指标。
血糖、血压、甲功等不适用——它们有明确诊断标准，按医生判断。
看到报告写"建议复查"，就不要用本文的"观察"策略。
```

### 3. 快递赔付

```text
先看承运商条款（下单页面/官网），再看本页
协商空间常在：包装不当、未按约定投递、代收点未授权
金额较大时，走平台介入或申诉比打客服更有效
```

### 4. 家电清洗

```text
做饭油烟大、养宠物、临街 → 按上限或更勤
几乎不开火、少开空调 → 可以放宽
唯一硬标准：有异味、制冷变差、皮肤过敏加重 → 立刻洗
```

### 5. 弃剧时机

```text
慢热型（文艺片、群像剧）：放宽到 40–60 分钟
类型片、商业片：20 分钟足够
如果是为了"陪人看"或"补经典"，本来就不是效率问题
```

## 还有一类没标出来的

**所有"常识"都带着出处模糊的问题。** 这一页只挑了五处最明显的，
但严格说，「多喝水」「早点睡」这类建议在细节上都有争议。

判断一个日常建议能不能信，问三句：

1. 它是**生理/物理机制**（如氯气会中毒）还是**统计相关**（如睡 7 小时的人更健康）？
2. 说的是**平均值**还是**对所有人都成立**？
3. 我自己的情况**属于哪一类**？

第 1 类可以照做，第 2 类只能当参考。

# 速查：日常要用的数字

> 20 条日常条目里的数都在这一页。左边是"该是多少"，右边是"越线了会怎样"。

## 一、钱

| 要算的 | 数 | 说明 |
| --- | --- | --- |
| 应急金 | 3–6 个月**必要支出** | 不是工资；单收入/有房贷取上限 |
| 固定支出占收入 | < 50% 较稳 | > 60% 抗风险能力差 |
| 储蓄率 | 10% 是底线 | 20%–30% 属良好 |
| 保费占年收入 | 5%–10% | 超 15% 要重新审视 |
| 订阅合计 | > 月收入 3% 就该清理 | 十几个小额最容易漏 |
| 大额消费门槛 | 月结余的 3 倍 | 超过就等 7 天再决定 |
| 收入不稳时基准 | 过去 12 个月**最低**那个月 | 用它排固定支出，不超 50% |
| 税与淡季预扣 | 25%–35%（按自己税率调） | 到账当天就转走 |
| 自由职业在手现金 | ≥ 3 个月必要支出 + 2 倍垫资 | 账期 30–90 天常见 |
| 接单沟通+返工 | 沟通 15%–30%，返工 10%–30% | 算到手时薪时都要计入 |

## 二、健康

| 指标 | 数 | 说明 |
| --- | --- | --- |
| 睡眠 | 成人 7–9 小时 | 判据是白天状态 |
| 入睡时间 | 15–30 分钟 | 超过是入睡困难 |
| 咖啡因截止 | 午后 2 点 | 半衰期约 5 小时 |
| 运动 | 每周 150 分钟中等强度 | 能说话但不能唱歌 |
| 打断久坐 | 每 45–60 分钟起身 2–3 分钟 | 频率比单次时长重要 |
| 体检复查线 | 超上限 2 倍 / 连续两年恶化 | 否则观察即可 |
| 发热就诊线 | > 3 天，或退后 24 小时再升 | 危险信号不等 |
| 腰痛观察窗 | 4–6 周（无红旗） | 有红旗直接就医 |
| 屏幕高度 | 上沿 ≈ 眼睛高度，距离 50–70cm | 笔记本直接放桌上必然低头 |
| 疼痛判据 | 看"能不能完成动作" | 不看 0–10 分数 |
| 饮水 | 直接喝 1.2–2 升 | 看尿色，淡黄为目标 |
| 咖啡因 | 400mg/天，孕期 200mg | 睡前 8 小时截止 |
| 补充剂判断期 | 3 个月 | 看不出差别就停 |

## 三、事务

| 事 | 时限/倍数 | 说明 |
| --- | --- | --- |
| 抽血空腹 | 8–12 小时 | 可少量饮水 |
| 医保报销 | 3–12 个月 | 商保 30–90 天，过期不补 |
| 租房押金 | 常见 1 个月租金 | 退押写 7–15 日内 |
| 提前退租 | 提前 30 天通知 | 违约金写进合同 |
| 搬家超时费 | 100–200 元/车/小时 | 报价要问清 |
| 快递未保价赔付 | 运费的 3–7 倍 | 价值 > 运费 10 倍就该保价 |
| 七天无理由 | 收到之日起 7 日 | 仅远程购物，且商品完好 |
| 给对方答复时限 | 3–7 个工作日 | 没有时限就会被无限拖 |
| 升级间隔 | 每级 7 天 | 当天连续升级会被转回 |
| 放弃线 | 追回金额 < 时间成本 × 3 | 算一下时薪再决定 |
| 上门费 | 30–100 元，可抵扣 | 修不成是否收费要问清 |
| 维修保修 | 常见 90 天 | 旧件要留下 |
| 保洁计价 | 日常按次 / 深度按小时 | 内容清单要写清 |
| 空调抽真空 | 15–30 分钟 | 时间被压缩会影响效果 |

## 关于这些数

- **算术**（应急金、每次使用成本、维修比例）：可直接套
- **经验区间**（睡眠、运动量、清洗频率）：人群平均，个体差异大
- **条款类**（报销时限、赔付倍数）：**各地各商家不同，以合同/条款为准**
- **实测**：一条都没有——我没有你的数据

逐条列在[薄弱处](薄弱处.md)：哪些是常识、哪些是我的推断、什么证据能推翻它。

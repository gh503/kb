# 保险之外的理财按什么顺序

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 订阅与日常开销怎么清理

## 结论

**顺序是：还高息债 → 应急金 → 保障 → 再谈投资。**
顺序错了，收益再高也白搭——**用借来的钱投资，是最常见的返贫路径**。

## 五步顺序

```text
第 1 步：还清高息负债（信用卡分期、消费贷）
第 2 步：攒 3–6 个月必要支出（应急金）
第 3 步：补齐保障（医保 → 医疗 → 意外 → 定寿）
第 4 步：做低风险配置（存款、货基、国债）
第 5 步：才考虑风险资产（基金、股票等）
```

**每一步没过，不要跳到下一步。**

## 为什么高息债优先

```text
信用卡分期真实年化：常见 13%–18%
消费贷：常见 7%–24%
理财长期年化：常见 3%–8%（且不保证）
```

**借 15% 的钱去赚 5%，是确定性的亏损。**

## 投资的三个前提

1. **这笔钱 3 年内不用**（否则可能被迫在低点卖出）
2. **亏 30% 不影响生活与睡眠**
3. **能说清自己买的是什么**（说不清就是投机）

三条任一不成立，就不该投。

## 一个简单分配

```text
应急金：3–6 个月必要支出（不动）
保障：年收入 5%–10%
低风险：剩余可投资金的 50%–70%
风险资产：剩余可投资金的 30%–50%（按风险承受力）
```

**比例不是标准答案**，重点是**先有前两层，再谈后两层**。

## 数字与阈值（经验判断）

```text
高息债线：年化 > 8%–10% 视为优先偿还
应急金：3–6 个月必要支出
投资期限：3 年以上不用
单一资产上限：不超过可投资金的 20%–30%
```

## 证据强度

- **公开经验**：先还高息债、再建应急金、再投资的顺序，是个人理财的通行框架
- **利率区间**：来自常见产品，**以实际合同为准**
- **推断**："3 年不用"按波动恢复期推的
- **重要**：本文不是投资建议；任何具体产品都需自行判断风险

## 不适用的情况

- 有极稳定现金流与充足保障：可适当提高风险资产比例
- 退休临近：应降低风险资产比例

## 常见错法

- **一边还分期一边买基金**：两头付费
- **把应急金投入市场**：急用时被迫卖出
- **听消息买不懂的东西**：说不清就不该买

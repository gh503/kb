# 保险先买哪一种

> **深度** 实操 ｜ **类型** 取舍 ｜ **链** 先攒一笔能用的钱

## 结论

**先买"出事会毁掉生活"的保障，不买"到期返钱"的产品。**
顺序是：医保 → 百万医疗 → 意外 → 定期寿险（有家庭责任才需要）。

## 为什么是这个顺序

| 险种 | 解决什么 | 一年大致花费 |
| --- | --- | --- |
| 医保（含居民/职工） | 基础报销，必须不断缴 | 数百到数千 |
| 百万医疗 | 大额住院自费部分 | 数百（年龄越大越贵） |
| 意外险 | 意外身故/伤残/医疗 | 一百到数百 |
| 定期寿险 | 家庭支柱身故后的收入替代 | 数百到一千 |
| 重疾险 | 患病期间收入中断 | 数千（贵，优先级低于上面） |
| 返还型/理财型 | 附带储蓄功能 | 很贵，保障杠杆低 |

**前四项一年的总花费，常低于一份返还型产品的保费。**

## 保额怎么定

```text
寿险保额 ≈ 年收入 × 5–10，或"未还贷款 + 子女教育 + 3 年家庭支出"
医疗险：看报销上限与免赔额，百万医疗通常有 1 万免赔额
意外险：保额至少 50 万，看是否含意外医疗
```

**免赔额 1 万的意思是：1 万以下自己付。** 这不是坑，是保费便宜的原因。

## 三个必看的条款细节

1. **健康告知**：问到的病必须如实说，隐瞒会拒赔
2. **等待期**：通常 30–90 天，等待期内出险不赔
3. **续保条件**：医疗险要看"是否保证续保"，几年期、到期会不会因理赔拒保

## 数字与阈值（经验判断）

```text
保费占年收入：5%–10% 属合理；超过 15% 要重新审视
医疗险免赔额：常见 1 万
等待期：30–90 天
缴费期：越长越能触发豁免条款，但总保费更高
```

## 证据强度

- **公开经验**：险种优先级与保费占比是保险科普的常见框架
- **区间**：保费与保额比来自经验，产品差异极大
- **推断**："先保障后理财"是按杠杆率推的
- **未验证**：我没有具体产品的费率与理赔数据

## 不适用的情况

- 已有单位补充医疗：先看覆盖范围，避免重复购买
- 无家庭责任（单身、无负债、父母有养老金）：寿险可以缓

## 常见错法

- **给孩子买一堆，大人裸奔**：家庭收入来源才是最该保的
- **买返还型**：多交的钱如果自己存，通常更划算
- **只在网上比价不看告知**：便宜的产品往往健康告知更严

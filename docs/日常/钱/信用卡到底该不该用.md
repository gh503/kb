# 信用卡到底该不该用

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 社保与长期准备

## 结论

**能全额还款就用，不能就别用。** 信用卡本身不贵，"最低还款"和"分期"才贵——
真实年化常在 13%–18%，是所有日常负债里最贵的一类。

## 三种用法，三种结果

| 用法 | 成本 | 判断 |
| --- | --- | --- |
| 全额还款 | 0（还有免息期） | 可以，且能积累信用记录 |
| 最低还款 | 循环利息，年化常见 13%–18% | 不要 |
| 分期 | 手续费折年化常见 13%–18% | 只在免息且无手续费时考虑 |

**"最低还款"是最贵的选项**：它让你以为压力变小，实际利息按全额计。

## 免息期怎么算

```text
账单日 → 还款日之间通常 20 天左右
在账单日次日消费，免息期最长（可达 50 天左右）
在账单日当天消费，免息期最短
```

**这不是技巧，是常识**：知道账单日，才知道钱什么时候真的要走。

## 该用的三个理由

1. **现金流错配**：工资 15 号发，房租 5 号交
2. **建立信用记录**：以后贷款、租房可能用到
3. **消费保障与争议处理**：比现金多一层

## 不该用的信号

- 需要"最低还款"才能周转
- 用 A 卡还 B 卡
- 分期买消费品（手机、衣服）
- 说不清这个月账单怎么来的

## 数字与阈值（经验判断）

```text
免息期：20–50 天（按账单日与消费日）
循环利息：日息万分之五，年化约 18%
分期手续费：折算年化常见 13%–18%
额度使用率：建议 < 50%（影响征信评分）
```

## 证据强度

- **公开经验**：全额还款免息、最低还款利息高，是信用卡的基本规则
- **利率**：为常见区间，**以发卡行合同与费率表为准**
- **推断**："额度使用率 < 50%"按征信评分的常见建议推的
- **重要**：本文不是金融建议；负债管理有困难时，优先处理高息部分并寻求正规渠道帮助

## 不适用的情况

- 已有分期余额且利率较高：优先还清，不再新增
- 收入不稳：减少依赖，避免到期无钱还

## 常见错法

- **只看最低还款额**：利息按全额算
- **把额度当收入**：可用额度不是可花金额
- **多卡循环**：越滚越大

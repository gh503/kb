# 借钱给朋友之前想什么

> **深度** 实操 ｜ **类型** 边界 ｜ **链** 订阅与日常开销怎么清理

## 结论

**只借"送出去也不影响生活"的金额，并把它当礼物预期。**
这不是悲观，是**把关系和钱分开**——借出去的钱一旦变成"他欠我"，关系就已经变了。

## 借之前问三句

```text
1. 这笔钱如果收不回来，我受影响吗？
2. 他借钱的原因是什么？（急事 vs 周转 vs 消费）
3. 我能不能用别的方式帮？（代付、介绍工作、陪他跑一趟）
```

**第 3 句常能解决问题**：很多"借钱"其实是"需要有人帮一把"。

## 金额怎么定

| 情况 | 建议 |
| --- | --- |
| 急病、事故 | 可在能力内借，写好凭证 |
| 周转（有明确还款来源） | 借，但要写时间与方式 |
| 消费、还债、投资 | 慎重，能不借就不借 |
| 你已经不宽裕 | 直接说没有，不必解释太多 |

**判据：借款金额 ≤ 你的"可损失金额"**（不影响应急金、不影响当月生活的部分）。

## 要不要写凭证

**要。** 而且不要因为"关系好"就跳过：

```text
写清：金额、日期、用途、还款时间、方式
方式：微信文字确认也算（保留记录）
大额：转账备注"借款"，不用现金
```

**"转账备注"最实用**：不写备注，日后很难证明是借款而不是赠与。

## 怎么拒绝

```text
"这个数我拿不出来，我能帮的是 ___。"
"我自己的钱都在定期/应急里，动不了。"
"我先借你 ___，剩下的你再想想办法。"
```

**给一个具体的小额 + 一个替代帮助**，比"我再想想"更体面，也更有效。

## 数字与阈值（经验判断）

```text
可损失金额：不超过月结余的 1–2 倍
单笔上限：不超过应急金的 20%
凭证：超过 1000 元建议留文字记录
催款节奏：约定日 +7 天提醒，+30 天再谈
```

## 证据强度

- **公开经验**："只借可损失的钱、写凭证、不因关系好而跳过"是借贷与人际关系的常见建议
- **比例**：来自经验
- **推断**："借钱会改变关系"按角色转变推的
- **重要**：本文不是法律意见；金额较大时应咨询专业人士并保留完整证据

## 不适用的情况

- 家人重大疾病等紧急情况：另当别论，但仍建议留记录
- 职业放贷：属金融行为，不适用本文

## 常见错法

- **借出应急金**：自己反而陷入风险
- **现金交易无记录**：事后难以主张
- **用"借"来维持关系**：关系反而更容易坏

# 年终奖与一次性收入怎么安排

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 社保与长期准备

## 结论

**先把这笔钱分四份，再决定花什么；顺序是：补应急金 → 还高息债 → 预留税与必要支出 → 剩下才谈消费。**
一次性收入最容易犯的错，是被当成"多了的钱"而不是"提前到的钱"。

## 四份怎么分

```text
第 1 份：补应急金到 3–6 个月必要支出（如果不足）
第 2 份：还高息负债（信用卡分期、消费贷）
第 3 份：预留接下来的必要支出（房租、保险年缴、学费）
第 4 份：剩下的才是可自由支配
```

**第 3 份最容易被忽略**：年终奖常在年初到账，而保险、学费、房租年付都在后面几个月。

## 一个例子

```text
年终奖 60,000
应急金缺口 20,000 → 补
信用卡分期余额 12,000（年化约 15%）→ 还清
全年保险 8,000 + 房租押金预留 6,000 → 留出
剩余 14,000 → 可自由支配（含犒劳自己的一部分）
```

**给自己留一笔"随便花"的**（如 10%–20%）：完全不留，容易在别处破功。

## 税务上要留意

```text
单独计税还是并入综合所得：两种算法结果可能差不少
一次性奖金政策有适用期限与条件，以现行规定为准
```

**别自己拍脑袋算**：金额较大时，用官方个税 App 试算，或咨询专业人士。

## 三件不要做

1. **当场决定大额消费**（车、装修）：先放 7 天
2. **全部投入风险资产**：这笔钱往往有明确用途
3. **借给"正好需要"的人**：见[借钱给朋友之前想什么](借钱给朋友之前想什么.md)

## 数字与阈值（经验判断）

```text
犒劳比例：10%–20%（完全不留容易破功）
应急金优先：不足 3 个月先补
高息债线：年化 > 8%–10% 先还
冷静期：大额消费等 7 天
```

## 证据强度

- **公开经验**：一次性收入按"补缺口 → 还债 → 预留 → 消费"分配，是个人财务规划的常见顺序
- **比例**：10%–20% 来自经验
- **推断**："先预留后消费"按支出时点推的
- **重要**：税务部分**以现行税法与官方试算工具为准**，本文不构成税务意见

## 不适用的情况

- 收入本身不稳（自由职业）：这笔钱应优先补足 6–12 个月缓冲
- 有明确大额计划（首付）：直接进入专项账户

## 常见错法

- **当成"意外之财"**：一个季度就花完
- **忘了后续年缴支出**：几个月后现金紧张
- **一次性还清低息贷款**：低息债不必急还，先补应急金

# 应急金到底要存多少

> **深度** 入门 ｜ **类型** 量级 ｜ **链** 先攒一笔能用的钱

## 结论

**存 3–6 个月的"必要支出"，不是 3–6 个月的工资。** 差额常常有一倍——
因为工资里含着你失业后立刻会砍掉的那部分（外卖、打车、娱乐、置装）。

## 先算"必要支出"

```text
必要支出 = 房租/房贷 + 水电燃气网 + 吃饭（在家做为主）+ 通勤 + 保险
         + 还款（房贷外的贷款）+ 必要的药费/学费

不含：外卖、娱乐、旅行、买衣服、订阅、人情往来
```

一个具体例子：

```text
房租 3500 + 水电燃气 300 + 吃饭 1500 + 通勤 300 + 保险均摊 400 + 还款 500
= 每月必要支出 6500
应急金目标 = 6500 × 4（取中位）= 26,000
```

## 为什么是 3–6 个月

| 你的情况 | 建议月数 |
| --- | --- |
| 单身、技能好找活 | 3 个月 |
| 有房贷或家庭单一收入 | 6 个月 |
| 行业波动大、年龄偏大 | 9–12 个月 |
| 双职工、无负债 | 3 个月 |

**判断依据是"重新找到同等收入要多久"，不是"心里没底要存多少"。**

**收入本身不稳的人（自由职业、提成制）按另一条链算**：底数 6 个月，波动大取 9–12 个月，
见[收入不稳怎么排预算](收入不稳怎么排预算.md)。两条不冲突——3–6 个月针对"有稳定工资"，6–12 个月针对"工资本身会断"。

## 放在哪

```text
要求：随时能取、不亏本、不与日常消费混在一起
合适：货币基金、银行活期+、短期存款
不合适：股票、基金（要用时可能正亏）、定期（取不出）、
        与工资同一张卡（会不知不觉花掉）
```

## 数字与阈值（经验判断）

```text
应急金：3–6 个月必要支出（波动大或单收入取上限）
存放：单列一个账户，不绑支付
动用：只用于失业、大病、意外，不用于旅游和换手机
补充：动用后 3 个月内补回
```

## 证据强度

- **公开经验**：3–6 个月必要支出是个人理财里的常见建议
- **区间**：月数来自经验，无统一标准
- **推断**："用必要支出而非工资计算"是按失业后支出结构推的

## 不适用的情况

- 有稳定且高覆盖的保障（如体制内、家庭多份收入）：可少一些
- 高息负债未还清：先还债，再攒应急金（利息高于存款收益）

## 常见错法

- **按工资算**：算出来的目标偏大，容易放弃
- **和日常账户混在一起**：看着有钱，其实攒不住
- **攒够了就挪去投资**：应急金的作用是"不用在低点卖出"

# 换城市工作的成本怎么算

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 订阅与日常开销怎么清理

## 结论

**只看"工资涨多少"会算错，要算一次性成本 + 每月净差额 + 回本周期。**
很多人换城市后名义涨薪 20%，实际可支配收入没变甚至更低。

## 三类成本

```text
一次性：搬家、押金（新租）、中介费、家具家电重置、往返面试
每月固定：房租差额、通勤、吃饭、水电
隐性：社保公积金基数变化、探亲交通、原城市的人脉与副业机会
```

**"公积金基数"常被忽略**：不同城市上限差异大，实际到手差很多。

## 一个算法

```text
一次性成本合计 = A
每月净差额 = 新城市可支配 − 原城市可支配
回本周期（月）= A ÷ 每月净差额
```

**判断线**：回本周期 > 18 个月，说明这次搬迁的经济账不成立
（除非有非经济理由：家庭、健康、长期机会）。

## 一个例子

```text
一次性成本：搬家 3000 + 押金 6000 + 中介 3000 + 家具 5000 = 17,000
月薪：原 12,000 → 新 15,000（+3,000）
房租：原 3,500 → 新 5,000（+1,500）
通勤：原 300 → 新 600（+300）
吃饭：原 1,800 → 新 2,200（+400）
每月净差额 ≈ 3,000 − 1,500 − 300 − 400 = 800
回本周期 = 17,000 ÷ 800 ≈ 21 个月 → 这笔账不划算
```

## 别忘的几项

- **社保/公积金转移**：有办理周期，可能影响买房资格
- **试用期工资**：新工作前 1–3 个月可能打折
- **探亲成本**：一年几次往返，常被低估
- **配偶/家庭**：另一半的收入变化要一起算

## 数字与阈值（经验判断）

```text
回本周期：< 12 个月划算；12–18 个月可接受；> 18 个月慎重
搬家成本：同城 500–3000 元，跨城 3000–10000 元
中介费：常见 1 个月租金
应急金：换城市后应保留 3 个月以上
```

## 证据强度

- **公开经验**：一次性成本 + 月净差额 + 回本周期，是搬迁决策的常见算法
- **金额**：为常见区间，**城市差异很大，以实际报价为准**
- **推断**："18 个月"是按可接受回收期推的
- **未验证**：我没有你的实际报价

## 不适用的情况

- 公司承担搬迁费用：一次性成本大幅降低，重点转为月差额
- 有非经济理由（照顾家人、健康）：经济账不是唯一标准

## 常见错法

- **只比月薪**：不看房租与通勤
- **忘记试用期**：前几个月收入更低
- **低估探亲**：一年四次往返就是一笔钱

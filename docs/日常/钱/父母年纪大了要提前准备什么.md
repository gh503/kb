# 父母年纪大了要提前准备什么

> **深度** 实操 ｜ **类型** 清单 ｜ **链** 社保与长期准备

## 结论

**提前做四件事：摸清保障、整理病历、明确意愿、留下应急联系方式。**
这四件都在"没出事"的时候做，出事时才有用——临时找材料是最常见的困境。

## 一、摸清保障

```text
医保：职工还是居民？报销比例、起付线、是否异地就医备案
商保：有没有买过？保单在哪？保额多少？
养老金：每月多少，发到哪张卡
长期护理：当地是否有长护险，怎么申请
```

**"异地就医备案"最实用**：父母在外地、你在另一个城市，没备案就要先垫付再回原地报。

## 二、整理病历

| 准备什么 | 为什么 |
| --- | --- |
| 慢病诊断与用药清单 | 急诊时医生第一时间要知道 |
| 过敏史 | 用药安全 |
| 近一次体检/检查报告 | 对比用 |
| 就诊卡与医保卡 | 直接能挂号 |

**建议拍照存手机**：纸质材料在急诊时往往找不到。

## 三、明确意愿

```text
抢救意愿（是否接受插管、心肺复苏）
是否愿意住养老机构
财产与证件放在哪、谁能取
```

**这类话题难开口，但比事后争执便宜得多。** 不需要一次谈完，分几次问也行。

## 四、留下应急联系方式

```text
父母手机里存：你、就近亲属、社区/物业、常去的医院
你的手机里存：父母的主治医生、社区、邻居
```

## 数字与阈值（经验判断）

```text
体检：60 岁以上每年 1 次
用药清单：每 3 个月更新一次
异地备案：长期居住地变更后 1 个月内办理
长护险：多数城市要求失能评估达到一定等级
```

## 证据强度

- **公开经验**：保障梳理、病历整理、意愿沟通，是老年照护准备的常见框架
- **数值**：频率与时限为经验，**政策类以当地为准**
- **推断**："先摸清保障再谈照护"按费用来源的优先级排的
- **重要**：涉及医疗决策与财产，建议同时咨询医生与法律专业人士

## 不适用的情况

- 父母身体状况良好且自理：先做第一、四项即可
- 已有完善的家族安排：按现有结构补充

## 常见错法

- **等出事才找保单**：找不到就等于没有
- **不谈意愿**：关键时刻由别人替你做决定
- **不备案异地就医**：报销比例低、流程长

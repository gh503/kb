# 自由职业的现金流怎么管

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 收入不稳怎么办

## 结论

**看"钱到账的日子"，而不是"活干完的日子"。** 自由职业最常见的死法不是没活，
是**活都干完了，钱还没到，下一笔垫资已经出去了**。

## 三个数先算清

```text
1. 平均账期 = 从交付到收款的天数（按客户分别算）
2. 垫资额 = 一个项目里你要先付出去的钱（外包、材料、软件）
3. 在手现金 = 能随时动用的钱（不含预扣的税）
```

**判断标准**：在手现金 ≥ 垫资额 × 2，且 ≥ 3 个月必要支出。

## 账期怎么谈短

| 做法 | 效果 |
| --- | --- |
| 合同写"分期：预付 30%–50%" | 立刻减少垫资 |
| 写清"逾期可暂停/可计息" | 提高对方优先级 |
| 每月固定一天统一开票 | 减少"忘了开票"导致的延迟 |
| 对大客户单独跟踪 | 大客户流程长，要提前催 |

**"统一开票日"这一条最实用**：很多人不是收不到钱，是发票一直没开。

## 坏账要提前留

```text
坏账准备 = 年收入 × 1%–5%（客户越集中，比例越高）
触发动作：逾期 30 天提醒、60 天书面催告、90 天决定是否放弃
```

**逾期 90 天还没动静的，继续投入时间的回报通常很低。**

## 一个简单的现金看板

```text
本月到账（已确定）：
本月应到账（可能延后）：
本月要付出去：
在手现金：
缺口（如有）：
```

每周看一次，比月底看一次好——月底才发现缺口，已经来不及。

## 数字与阈值（经验判断）

```text
账期：常见 30–90 天，大客户更长
预付：30%–50%
坏账准备：年收入 1%–5%
在手现金：≥ 3 个月必要支出 + 2 倍垫资
逾期处理：30 / 60 / 90 天三档
```

## 证据强度

- **公开经验**：账期、垫资与坏账准备是自由职业现金流管理的常见框架
- **区间**：比例来自经验，行业差异大
- **推断**："在手现金 ≥ 2 倍垫资"按最大单项目风险推的
- **未验证**：我没有你的账期数据

## 不适用的情况

- 平台结算（按周/按月打款）：账期由平台定，重点转为垫资与结算周期匹配
- 预收为主（订阅、年付）：现金流反而好，问题在交付能力

## 常见错法

- **同时接三个需要垫资的单**：现金立刻紧
- **不追小额欠款**：累积起来不小，且教会对方可以拖
- **把税钱当现金**：账面有，实际不能用

# 要不要接这单

> **深度** 取舍 ｜ **类型** 边界 ｜ **链** 收入不稳怎么办

## 结论

**算"到手时薪"，不算"总价"。** 一个 2 万的项目干两个月，不如一个 8 千的项目干两周——
但人往往被总价吸引，忽略了时间、沟通、返工与账期。

## 一个能算的公式

```text
到手时薪 =（报价 − 直接成本 − 返工预留）÷（干活小时 + 沟通小时 + 返工小时）
```

**三个最容易漏的项**：

| 项 | 常见比例 |
| --- | --- |
| 沟通与会议 | 占总工时的 15%–30% |
| 返工与修改 | 占 10%–30%（甲方越不专业，越高） |
| 账期成本 | 60 天账期 ≈ 报价的 3%–5%（按资金成本估） |

## 四个该拒绝的信号

```text
1. 需求说不清，但要求"先做起来看看"
2. 预算明显低于你的成本线，却要求"长期合作"
3. 决策人不在场，只有中间人传话
4. 要求先出方案/比稿，且不付费用
```

**第 1 条最危险**：需求不清意味着返工无限，而报价是按"一次做对"算的。

## 什么时候该接

- 能复用已有成果（边际成本低）
- 能带来后续稳定合作或案例
- 客户专业、决策链短、付款记录好
- 你在练一项新能力，且愿意为此让价

**"愿意让价"要是明确的战略选择，不是被压出来的。**

## 数字与阈值（经验判断）

```text
沟通占比：15%–30%
返工预留：10%–30%
账期成本：60 天约 3%–5%
最低时薪线：不低于你上一份工作的时薪
```

## 证据强度

- **公开经验**："到手时薪"与隐性成本核算，是自由职业报价的常见方法
- **比例**：来自经验，项目类型差异大
- **推断**："需求不清等于返工无限"按变更成本推的
- **未验证**：我没有你的实际项目数据

## 不适用的情况

- 长期雇佣性质的合作：按人月计价，另当别论
- 战略客户（进入某个行业）：短期亏，长期有明确收益

## 常见错法

- **只看总价**：时间拉长后时薪可能低于最低工资
- **不为返工留余量**：改五版等于白干
- **不好意思谈预付**：账期越拖越久

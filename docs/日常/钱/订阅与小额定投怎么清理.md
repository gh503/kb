# 订阅与小额定投怎么清理

> **深度** 入门 ｜ **类型** 方法 ｜ **链** 订阅与日常开销怎么清理

## 结论

**先把它们列出来，再决定留几个。** 单笔 15–30 元的订阅最危险的地方不是贵，
是**你根本不知道自己在付**——一年十几笔，加起来常常是一个月房租。

## 第一步：找出所有自动扣款

```text
查三处：
1. 支付宝/微信 → 自动扣款/免密支付
2. 银行卡 → 近 3 个月流水里重复出现的金额
3. 手机订阅 → App Store / 应用商店的订阅管理
```

**第 2 处最容易被漏**：绑卡订阅不会出现在 App 的订阅列表里。

## 第二步：每笔问一句

```text
"过去 30 天我用过它吗？"
用过 → 留
没用过但还是想要 → 降级（年付改月付、高级版改基础版）
没用过也不心疼 → 取消
```

**"想留着以后用"是最贵的回答**：它让每一笔都留下来。

## 第三步：算总账

```text
月合计 = 各笔之和
年合计 = 月合计 × 12
占比 = 年合计 ÷ 年收入
```

**超过月收入 3% 就该处理**；超过 5% 通常有明显可砍空间。

## 常见的隐形订阅

| 类型 | 为什么被忘 |
| --- | --- |
| 视频/音乐会员 | 自动续费，不提醒 |
| 云存储 | 免费额度用完自动升级 |
| 软件高级版 | 试用期结束自动转付费 |
| 健身/课程 | 买了没去 |
| 小额定投 | 每月自动扣，金额小不心疼 |

**小额定投不是"订阅"，但机制一样**：不看就一直在扣。定投本身没问题，问题是不清楚自己在投什么。

## 数字与阈值（经验判断）

```text
清理频率：每季度一次（20 分钟）
警戒线：订阅年合计 > 年收入 3%
保留上限：常用 3–5 个（视频、音乐、云、工具、学习）
取消后：确认"服务在到期日停止"而不是立即失效
```

## 证据强度

- **公开经验**：按"过去 30 天是否使用"清理订阅，是个人财务整理的常见方法
- **比例**：3%–5% 来自经验
- **推断**："先列出再决定"按可见性对决策的影响推的
- **未验证**：我没有你的订阅清单

## 不适用的情况

- 工作需要（软件、工具）：按报销与效率算，不适用"用没用过"
- 家庭共享账号：取消会影响他人，需先沟通

## 常见错法

- **只查 App 订阅列表**：漏掉绑卡扣款
- **全部取消图省事**：常用的再买回来更贵
- **取消后不确认**：有的要提前 30 天

# 记账记到什么程度才有用

> **深度** 实操 ｜ **类型** 方法 ｜ **链** 先攒一笔能用的钱

## 结论

**记到能回答"哪一类钱在失控"就够了，不需要每一笔都记。**
记了三个月还在记流水、却说不出去年哪项超支，那是记账的仪式，不是记账。

## 三个层级，按需选

| 层级 | 记什么 | 适合 |
| --- | --- | --- |
| 粗记 | 每月只看三五个大类总额 | 大多数人 |
| 中记 | 固定支出 + 单笔超 200 元 | 想找漏洞的人 |
| 细记 | 每一笔 | 正在还债、或收入不稳定 |

**多数人从"中记"开始最划算**：小额高频的支出记账成本高，收益低。

## 只看四个数

```text
1. 固定支出占收入比   → 超过 50% 就很脆
2. 储蓄率             → 收入 − 支出，占收入的比例
3. 单类异常           → 某类比上月高 30% 以上
4. 订阅与小额定投      → 每月自动扣款的合计
```

第 4 项最容易被忽略：十几个每月 15–30 元的订阅，一年就是几千。

## 一个能坚持的格式

```text
每月一次，10 分钟：
收入合计：
固定支出：房租 / 还款 / 保险 / 订阅
变动支出：吃饭 / 交通 / 其他
结余：
本月异常（哪一类超了、为什么）：
下月只改一件事：
```

**"下月只改一件事"是关键**——一次改五项，一项都改不掉。

## 数字与阈值（经验判断）

```text
固定支出占收入：< 50% 较稳；> 60% 抗风险能力差
储蓄率：10% 是底线，20%–30% 属良好
订阅合计：超过月收入 3% 值得逐个清理
记账耗时：每月 10–30 分钟，超过就说明记得太细
```

## 证据强度

- **公开经验**：储蓄率与固定支出占比是个人财务健康的常用指标
- **区间**：比例来自经验，城市与家庭结构差异大
- **推断**："中记最划算"是按记账成本与收益推的

## 不适用的情况

- 收入极不规律（自由职业）：需要逐笔记，否则无法预测
- 已严重超支：先做"只记支出不记收入"的极简版，别追求完整

## 常见错法

- **记了不看**：数据不产生任何决定
- **分类过细**：二十个科目，最后自己都记不清
- **追求零误差**：差几块钱就放弃整月记录

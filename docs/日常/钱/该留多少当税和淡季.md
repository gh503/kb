# 该留多少当税和淡季

> **深度** 实操 ｜ **类型** 量级 ｜ **链** 收入不稳怎么办

## 结论

**每笔收入到账，先扣 25%–35% 进"不可动"账户。** 这笔钱不是储蓄，
是**已经属于别人（税）和未来的自己（淡季）**的钱。

## 为什么是 25%–35%

```text
税款：按你的实际税率，常见综合负担 10%–30%（视收入与扣除）
淡季：留 1–2 个月的必要支出，摊到全年约 8%–16%
合计：常见 25%–35%
```

**具体比例要自己算一次**：拿去年实际缴的税 ÷ 去年总收入，得到你的真实税率，再加淡季份额。

## 怎么执行

```text
1. 单独开一个账户（不与日常、缓冲混用）
2. 每笔收入到账当天，转出约定比例
3. 每季度核一次：账户余额是否够覆盖"应缴未缴 + 淡季缺口"
4. 缴税/淡季取用后，回到比例继续转
```

**"到账当天就转"是关键**：放两天就会花掉。

## 三个容易算错的地方

| 容易错 | 说明 |
| --- | --- |
| 只算个税 | 还有社保、附加税费（视身份与地区） |
| 用毛利算税率 | 应按应税所得，不是流水 |
| 忘记预缴 | 部分收入需要按次或按季预缴，逾期有滞纳金 |

## 数字与阈值（经验判断）

```text
预扣比例：25%–35%（按个人税率调整）
缓冲目标：6 个月必要支出（波动大取 9–12）
核对频率：每季度一次
补缴提醒：每年固定一个月做全年测算
```

## 证据强度

- **公开经验**："收入到账先扣税与淡季"是自由职业与个体经营的常见做法
- **比例**：25%–35% 为经验区间，**真实税率请按当地税法与自己情况测算**
- **推断**："到账当天就转"按行为习惯推的
- **重要**：本文不构成税务意见；具体申报请咨询税务专业人士

## 不适用的情况

- 有代扣代缴的雇员：主要留淡季部分即可
- 收入极低（未达起征点）：先确认是否需要申报

## 常见错法

- **年底才想起税**：一次性拿不出
- **把预扣的钱借给朋友**：等于把税钱花掉
- **按流水算税率**：算出来偏低，缴税时补不上

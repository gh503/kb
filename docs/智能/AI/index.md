# AI

> 模型怎么工作、怎么用、什么时候不该信它。

## 收什么

- 能力边界与失败模式：它在哪类问题上稳定出错，错得像不像对的
- 提示与上下文：什么样的输入结构能稳定拿到结果，什么写法只是碰运气
- 评测：用一批固定样本判断「这次改动是不是真的变好了」
- 部署与成本：本地/自托管的显存、量化、吞吐，以及 API 的延迟与价格

## 不收什么

- 论文复述——需要时给链接
- 没有评测依据的「效果更好」
- 「AI 会取代一切」这类判断（要写就写清依据和反例）

## 结论

**模型输出的是"最像答案的文本"，不是"查证过的结论"。**
所以它会在没有依据时也给出通顺、自信、格式正确的回答——这不是 bug，是生成方式决定的。

## 三个来源

```text
1. 训练数据里没有：它没见过，但仍然按语言规律"续写"出一个像样的答案
2. 训练数据里有错：学到了错误事实，且无法自知
3. 上下文缺失：你问的细节不在输入里，它用自己的先验补全
```

**第 3 条最容易被忽略**：你把关键信息漏在提示外，它就会编一个补上。

## 哪些问题最容易幻觉

| 类型 | 风险 | 原因 |
| --- | --- | --- |
| 具体数字（年份、金额、比例） | 高 | 细节多、易混淆 |
| 人名 + 作品/职位对应 | 高 | 组合空间大 |
| 引用与链接 | 高 | 格式对、内容可能是拼的 |
| 冷门领域细节 | 高 | 训练数据稀疏 |
| 通用推理与改写 | 低 | 不依赖具体事实 |

**"引用和链接"最危险**：它看起来最像证据，实际最容易是编的。

## 四条验证手段（按成本排序）

```text
1. 要求给出来源，并逐条点开核对（最有效）
2. 换一种问法再问一次，看结论是否一致（成本低，只能发现不稳定）
3. 把关键事实拆成"是/否"问题逐个确认（比开放问答可靠）
4. 用你已有的资料库做交叉检索（最可靠，但要成本）
```

**"点开来路"是唯一能真正排除幻觉的手段**：不点开就等于相信。

## 数字与阈值（经验判断）

```text
验证强度：涉及金额/日期/人名/法条 → 必须逐条核对
一致性检查：同一问题问 3 次，答案不一致 → 不可用
抽样核对：批量生成内容抽 10%–20% 人工核对
可接受幻觉率：对外发布 0（必须核对），内部草稿可放宽
```

## 证据强度

- **公开经验**：幻觉的成因分类、高风险问题类型，是模型评测与应用的常见结论
- **数字**：抽样比例与问 3 次属经验做法
- **未验证**：具体模型的具体幻觉率随版本变化，**本文不给任何模型的数字**
- **推断**："要求来源并点开"按可核查性推的最有效手段

## 不适用的情况

- 创意写作、头脑风暴：不需要事实正确性
- 有确定性数据库可查的问题：直接查库，不要问模型

## 常见错法

- **看它说得流畅就信**：流畅度与正确性无关
- **只问一次就发布**：不一致性没被发现
- **要求"给出来源"但不点开**：等于没验

# 机器人

> 让机器在物理世界里感知、决策、动作。

## 收什么

- 坐标系与变换：TF 树、手眼标定、单位与朝向约定踩过的坑
- 传感器：噪声、延迟、标定方法，以及「看起来正常其实漂了」怎么识别
- 运动控制与规划：实际能达到的精度、速度、关节限位，和仿真里的差距
- 仿真与实机不一致：差在哪、怎么二分定位
- 安全联锁：急停、限速、围栏，测试时怎么不伤人

## 不收什么

- 产品参数对比和厂家宣传
- 没有实机验证的「理论上可以」

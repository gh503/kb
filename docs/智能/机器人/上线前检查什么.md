## 结论

**上线检查不是"功能演示一遍"，而是"故意制造故障，看它是否安全"。**
功能正常是底线，**故障时的行为才是要检查的东西**。

## 六组检查

```text
1. 停止：急停、断通信、断主控、断电，各试一次
2. 感知：遮挡、反光、强光、动态障碍、传感器拔线
3. 边界：地图边缘、坡道、门槛、窄通道
4. 负载：满载、偏载、急停时负载是否稳定
5. 交互：人突然出现、人挡路、人推它
6. 恢复：故障后如何复位、是否需要人工确认
```

**"故意制造故障"是这页的核心**：不试故障，就不知道故障时会怎样。

## 每一项怎么算通过

```text
不是"没出事"，而是"按设计进入安全状态"
例：拔掉激光 → 应在 1 秒内停下并报警，而不是继续走
```

**"没出事"不等于"通过"**：可能只是这次运气好。

## 一份可执行的顺序

```text
先静止测试（急停、断电）→ 再低速（限速、避障）
→ 再正常速度（制动距离）→ 最后人群场景（最危险，放最后）
```

**"从慢到快、从空到有人"** 是唯一安全的顺序。

## 记录什么

```text
每个测试项：现象、是否进入安全状态、耗时
失败项：必须修复后重测，不能"下次注意"
遗留风险：明确写出来，由谁接受
```

**"遗留风险"要有人签字**：不是技术团队自己说"应该没事"。

## 数字与阈值（经验判断）

```text
急停响应：按下到停止 ≤ 数百毫秒
断通信停机：≤ 1 秒
测试项：≥ 20 项，覆盖上述六组
重测：任何安全相关改动后全量重测
试运行：≥ 1 周有人值守，再无人值守
```

## 证据强度

- **公开经验**：以"制造故障"为核心的验收思路、六组检查项
- **数字**：响应时间为实践值，**不构成合规结论**
- **推断**："从慢到快"按风险递增排序

## 不适用的情况

- 隔离围栏内的固定作业：检查项可简化，仍需急停与断电测试
- 已认证的标准产品：按厂商手册与认证范围

## 常见错法

- **只演示正常流程**
- **故障测试用"模拟信号"代替真拔线**
- **失败项记录为"已知问题"就上线**

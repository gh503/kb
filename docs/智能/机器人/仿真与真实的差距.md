## 结论

**仿真里调好的控制器，加到真机上最常坏的不是精度，是稳定裕度。**
本机模拟（PD 跟踪 1 m 位移）：同一组参数 kp=8、kd=5.6，在"纯仿真"里稳态误差 **0.01 cm**；
加上 **30 ms 延迟 + 0.1 的摩擦** 后变成 **1.26 cm**（差 100 倍），超调从 −0.0% 变成 −1.3%。

## 仿真缺的四样东西

```text
1. 延迟：传感器采样、通信、执行器响应，加起来 10–100 ms
2. 摩擦与间隙：干摩擦、齿轮背隙，低速时最明显
3. 饱和：电机扭矩/转速有上限，仿真里常被写成无穷
4. 噪声与漂移：编码器量化、IMU 零偏
```

**"仿真里收敛"** 只证明了理想模型下收敛，没证明真机收敛。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
def sim(delay_ms, kp, kd, friction=0.0, dt=1e-3, T=4.0, target=1.0):
    d=int(round(delay_ms/1000/dt)); x=v=0.0; buf=[0.0]*max(1,d); xs=[]
    for _ in range(int(T/dt)):
        u = kp*(target-x) - kd*v
        if d>0: buf.append(u); u=buf.pop(0)
        a = u - (friction*np.sign(v) if abs(v)>1e-3 else 0.0)
        v += a*dt; x += v*dt; xs.append(x)
    xs=np.array(xs)
    return xs.max()-target, abs(xs[-1]-target)
for name,(dl,fr) in (("仿真",(0,0.0)),("真实",(30,0.10))):
    ov,er=sim(dl,8.0,5.6,fr)
    print(f"{name}：超调 {ov*100:.1f}% ｜ 末态误差 {er*100:.2f} cm")
print("延迟越大，能用的 kp 上限越低（超调 > 20% 视为不可用）：")
for dl in (0,30,50):
    print("  延迟 %2d ms：" % dl + " ｜ ".join(
        f"kp={kp}→{sim(dl,kp,5.6)[0]*100:.0f}%" for kp in (4,8,16,32,64)))
PY
```

本机输出：

```text
仿真：超调 -0.0% ｜ 末态误差 0.01 cm
真实：超调 -1.3% ｜ 末态误差 1.26 cm
延迟  0 ms：kp=4→-4% ｜ kp=8→-0% ｜ kp=16→5% ｜ kp=32→17% ｜ kp=64→31%
延迟 30 ms：kp=4→-4% ｜ kp=8→-0% ｜ kp=16→5% ｜ kp=32→21% ｜ kp=64→46%
延迟 50 ms：kp=4→-4% ｜ kp=8→-0% ｜ kp=16→5% ｜ kp=32→27% ｜ kp=64→64%
```

## 为什么延迟会吃掉裕度

```text
控制器看到的是"30 ms 之前"的位置
  → 相当于在反馈环里串了一个滞后
  → 相位裕度下降，kp 一大就振荡
仿真里 kp=64 才 31% 超调；加 50 ms 延迟变成 64%
```

**"真机抖"** 常常是"增益按无延迟调出来的"。

## 缩小差距的三件事

```text
1. 把延迟建模进仿真：哪怕只加一个常数延迟，也比没有强
2. 加摩擦与饱和：低速段的行为最依赖它们
3. 真机上先降增益再逐级升：以仿真参数为上限，现场往下调
```

**"系统辨识"** 比"更精细的仿真引擎"更有效：参数对了，简单模型也准。

## 数字与阈值（本机模拟）

```text
仿真 0.01 cm → 真实 1.26 cm（100 倍）；超调 −0.0% → −1.3%
kp=64：无延迟 31% → 30 ms 46% → 50 ms 64%
经验：控制环延迟每增加 10 ms，可用带宽大致下降 10%–20%
经验：真机先以仿真增益的 50%–70% 起步
经验：低速（< 0.05 m/s）时摩擦主导，仿真误差最大
```

## 证据强度

- **模拟**：数值来自本机二阶模型（延迟用队列、摩擦用库仑项）
- **公开经验**：延迟与带宽的关系、降增益起步
- **推断**：真实系统的延迟是分布式的，等效常数延迟只是近似

## 不适用的情况

- 纯规划/学习任务，不闭环控制：延迟影响小
- 高刚度直驱、延迟 < 1 ms：差距主要来自摩擦与标定

## 常见错法

- **仿真里把电机写成理想力矩源**
- **用仿真参数直接上真机、不做降增益**
- **只对比终点误差，不看超调与振荡**

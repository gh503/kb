## 结论

**安全的第一道防线是"能停下来"，第二道才是"看得见人"。**
所以先做急停与限速，再谈感知——**停不下来的机器人，感知再好也不该上线**。

## 三级停止

| 级别 | 行为 | 触发 |
| --- | --- | --- |
| 急停（E-stop） | 切断动力，机械制动 | 人按下、安全回路断开 |
| 保护性停止 | 受控减速后停 | 安全传感器触发 |
| 暂停/待机 | 保持位置，可恢复 | 软件指令 |

**"急停要切断动力"**：只发软件指令不算急停，软件可能已经卡死。

## 限速的三种约束

```text
1. 绝对值：最高速度不超过 X（按场景与人机距离定）
2. 区域：靠近人时降速，进入危险区停
3. 状态：负载重、坡度大、电量低时自动降速
```

**"按区域降速"是最有效的一条**：它不依赖"识别到人"，只依赖"进入某区域"。

## 急停按钮要满足什么

```text
物理按钮（不是触摸屏）
位置可达（操作员与旁观者都能按到）
按下即锁定（需手动复位）
独立于主控（不经过可能死机的应用层）
```

**"独立于主控"最常被忽略**：急停走主控软件，主控一死就按不动。

## 一个能自查的顺序

```text
1. 按下急停 → 动力是否真的切断？多久停住？
2. 急停复位后 → 是否需要人工确认才恢复？
3. 主控断电 → 机器人是否停下（而不是保持最后指令）？
4. 通信中断 → 是停还是继续跑？（必须停）
```

**"通信中断后继续跑"** 是最危险的默认行为之一。

## 数字与阈值（经验判断/需按标准核对）

```text
急停响应：按下到动力切断 ≤ 数百毫秒
停止距离：按速度与减速度算（见[人机共存的间距](人机共存的间距.md)）
通信中断判定：≤ 1 秒（心跳丢失即停）
限速区间：靠近人 0.25–0.5 m/s（常见实践，需按标准与场景核定）
急停复位：必须手动，且需确认现场无障碍
```

**具体数值必须以现行安全标准与风险评估为准**，本文不给合规结论。

## 证据强度

- **公开经验**：三级停止、急停需物理且独立于主控、通信中断必须停
- **数字**：响应与限速为常见实践区间，**不构成合规依据**
- **推断**："停不下来就不该上线"按风险不可接受性推的

## 不适用的情况

- 完全隔离的围栏内作业：可按围栏方案设计，仍需急停
- 非移动设备（固定机械臂）：互锁逻辑不同

## 常见错法

- **用软件按钮当急停**
- **急停经过主控软件**
- **复位后自动恢复运行**
- **通信中断后保持最后指令**

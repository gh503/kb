## 结论

**抓得住靠摩擦，不靠夹得紧；而所需夹紧力与摩擦系数成反比。**
本机算例（两指平行夹持）：0.5 kg、μ=0.5 → 单指最小 **4.91 N**，取 2 倍安全系数 **9.81 N**；
**同样的物体，μ 从 0.5 降到 0.2，单指力从 4.91 N 涨到 12.26 N（2.5 倍）**——湿滑表面会让轻物体变得很难抓。

## 基本算式

```text
两指平行夹持：F ≥ m·g / (2μ)（每指），再乘安全系数 1.5–2
  → m=0.5 kg、μ=0.5：F ≥ 4.91 N，取 9.81 N
加速度 a 要另加：F ≥ m·(g+a) / (2μ)
  → 急停/快速搬运时，力要按 (g+a) 重算
```

**"夹得越紧越稳"** 超过物体屈服强度就夹坏了（软包装、果蔬尤其）。

## 本机可复现（已算）

```bash
python3 - <<'PY'
g=9.81
for m,mu in ((0.5,0.5),(2.0,0.5),(0.5,0.2)):
    F=m*g/(2*mu); print(m, mu, round(F,2), round(2*F,2))
PY
```

本机输出：

```text
0.5 kg / μ0.5 → 4.91 N（×2 = 9.81）｜2.0 kg → 19.62 N（×2 = 39.24）｜0.5 kg / μ0.2 → 12.26 N（×2 = 24.52）
```

## 力控的三个层次

```text
位置控制：只控位置，力由"卡住"决定 → 易过载（最便宜）
电流环限力：按电流估力，响应快但摩擦/温漂大（常见）
力/力矩传感器闭环：直接测力，精度高、成本高（装配类必需）
```

## 判据

```text
物体硬、重、摩擦大 → 位置控制 + 限力就够
物体软、滑、易碎 → 必须力闭环 + 低安全系数
需要"插/拧/压" → 力控是必需，不是加分项
```

## 数字与阈值（本机计算）

```text
0.5 kg / μ0.5：单指 4.91 N（×2 = 9.81）｜μ0.2：12.26 N（×2 = 24.52）
2.0 kg / μ0.5：19.62 N（×2 = 39.24）
经验：安全系数 1.5–2（越快越大）
经验：加速度按 (g+a) 计入，急停时 a 可能 > g
经验：μ 对湿度极敏感，油污场景按 μ=0.2 保守算
```

## 证据强度

- **计算**：三组力值由公式算出
- **公开经验**：安全系数、力控三层次
- **推断**：真实夹爪的力分布不均（点接触、倾斜），实际需要比理论值更大

## 不适用的情况

- 真空吸盘/磁吸：靠负压/磁力，不适用摩擦公式
- 完全包覆的柔性夹爪：接触面积大，模型不同

## 常见错法

- **只按重量算力，忘了加速度**
- **μ 用干燥表面的值去抓油污件**
- **安全系数取 1.1 就上线**

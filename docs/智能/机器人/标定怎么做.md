## 结论

**标定不是"求出参数"，是"把误差压到你的任务能接受"。**
本机模拟（3 参数、输入噪声 0.01）：
**4 组样本参数误差 0.0131、末端偏差 0.5 cm；10 组降到 0.0030 / 0.1 cm；200 组 0.0005 / 0.0 cm。**
——但把输入噪声从 0.01 提到 0.05，200 组也只能到 0.0046，**比 10 组干净数据还差**。

## 标定在解什么

```text
已知：一组"我让它去哪"和"它实际到了哪"
求解：外参（相机/工具/底座之间的变换）+ 内参（焦距、轮径、尺度）
方法：最小二乘 / 非线性优化
判断标准：残差、参数误差、以及对末端任务的实际影响
```

**"残差小"不等于"参数对"**：参数之间可能互相补偿（共线性），残差小但预测新位姿会错。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
rng=np.random.default_rng(0)
true=np.array([1.0,0.3,0.2]); J=np.array([[0.6,0.1,0.8]])
for n in (4,10,50,200):
    A=rng.normal(size=(n*2,3)); y=A@true
    An=A+rng.normal(scale=0.01,size=A.shape); yn=y+rng.normal(scale=0.005,size=y.shape)
    est,*_=np.linalg.lstsq(An,yn,rcond=None)
    print(f"样本 {n:>3}：参数误差 {np.linalg.norm(est-true):.4f} ｜ 末端偏差 {np.linalg.norm(J@(est-true))*100:.1f} cm")
for n,noise in ((50,0.02),(200,0.02),(200,0.05)):
    A=rng.normal(size=(n*2,3)); y=A@true
    An=A+rng.normal(scale=noise,size=A.shape); yn=y+rng.normal(scale=0.005,size=y.shape)
    est,*_=np.linalg.lstsq(An,yn,rcond=None)
    print(f"样本 {n:>3}、输入噪声 {noise:.2f}：参数误差 {np.linalg.norm(est-true):.4f}")
PY
```

本机输出：

```text
样本   4：参数误差 0.0131 ｜ 末端偏差 0.5 cm
样本  10：参数误差 0.0030 ｜ 末端偏差 0.1 cm
样本  50：参数误差 0.0016 ｜ 末端偏差 0.1 cm
样本 200：参数误差 0.0005 ｜ 末端偏差 0.0 cm
样本  50、输入噪声 0.02：参数误差 0.0035
样本 200、输入噪声 0.02：参数误差 0.0025
样本 200、输入噪声 0.05：参数误差 0.0046
```

## 三条实操结论

```text
1. 样本要多，但"数据质量"权重更高：200 组脏数据不如 10 组干净数据
2. 样本要覆盖工作空间：全挤在一个角落，外推区域误差会放大
3. 标定完要验证：留出 20% 样本不参与拟合，看它们在验证集上的残差
```

**"训练集残差 0.1 mm"** 是最容易自欺的指标：过拟合也能做到。

## 误差怎么传到末端

```text
末端偏差 ≈ J · 参数误差
  J 是雅可比：参数误差被放大还是缩小，取决于位形
  → 同一个标定，在工作空间边缘可能差 3–5 倍
```

**"中心区很准"** 不代表边缘也准；抓取点通常在边缘。

## 数字与阈值（本机模拟）

```text
4 组样本 → 0.5 cm 末端偏差；10 组 → 0.1 cm；200 组 → 0.0 cm
输入噪声 0.05 时，200 组只到 0.0046（比 10 组干净数据差）
经验：验证集残差应是训练集的 1–2 倍，超过 3 倍就是过拟合
经验：标定点覆盖 80% 的工作空间，剩下的靠验证
经验：温度变化会让外参漂移，精密场景要定期重标
```

## 证据强度

- **模拟**：六组参数误差来自本机最小二乘（非真机标定）
- **公开经验**：验证集比例、雅可比放大
- **推断**：真实噪声不是高斯的，重尾噪声下单次标定可能被个别点带偏

## 不适用的情况

- 任务精度要求低于标定误差：不必标定
- 每次任务都重标（如在位测量）：静态标定的意义下降

## 常见错法

- **只看残差，不看验证集**
- **标定点全挤在中心**
- **标定一次用一年，不查漂移**

## 结论

**续航 = 可用能量 ÷ 平均功率，而"平均"里最容易被低估的是待机与传感器，不是电机。**
本机实测一块电池：**2,944,000 µAh × 17.045 V ≈ 50.2 Wh**（满电、循环 0 次）。
按 80% 可用、整机 50 W 算 → **0.8 小时**；20 W → **2.0 小时**；100 W → **0.4 小时**。

## 三笔账

```text
可用能量：标称 Wh × 0.8（留 20% 不深放）
平均功率：电机（峰值高、占空比低）+ 计算 + 传感器 + 待机
效率：电机/驱动/减速器合计损耗，按 0.7–0.85 折算
  → 续航 = 可用能量 × 效率 / 平均功率
```

**"电池 50 Wh、机器 50 W，所以 1 小时"** 忘了效率和 20% 余量，实际约 0.7 小时。

## 本机可复现（已实测）

```bash
cat /sys/class/power_supply/BAT0/charge_full /sys/class/power_supply/BAT0/voltage_now
python3 - <<'PY'
wh=2_944_000/1e6*17.045/1e6
for p in (20,50,100): print(p, round(wh/p,2), round(wh*0.8/p,2))
PY
```

本机输出：

```text
50.2 Wh ｜20 W → 2.5 h（0.8 折算 2.0 h）｜50 W → 1.0 h（0.8）｜100 W → 0.5 h（0.4）
```

## 功率怎么估

```text
电机：额定功率 × 占空比（本机这类设备通常占空比 0.3–0.6）
计算：主板 + 加速器（满载可能 10–30 W）
传感器：激光雷达 5–15 W、相机 1–3 W、IMU < 0.1 W
待机：整机 2–8 W（不能忽略，8 小时待机就能吃掉 1/4 电量）
```

## 判据

```text
续航需求 > 4 h → 要么换电池，要么降占空比/换低功耗计算
峰值功率 > 电池放电能力 → 需要并联电池或超级电容
低温环境 → 可用容量按 0.7 折算
```

## 数字与阈值（本机实测）

```text
电池 50.2 Wh（2,944,000 µAh × 17.045 V）｜循环 0 次
20/50/100 W → 2.0/0.8/0.4 h（含 80% 可用）
经验：可用能量按 80%，效率按 0.75–0.85
经验：待机功率按整机 2–8 W 计入
经验：低温按 0.7 折算可用容量
```

## 证据强度

- **实测**：电池容量与电压来自本机
- **公开经验**：80% 可用、效率折算、低温系数
- **推断**：真实机器人的峰值功率远高于平均，电池放电倍率常是隐藏瓶颈

## 不适用的情况

- 有线供电/换电模式：续航不是约束，改看换电时间
- 短时任务（< 10 分钟）：按峰值功率选电池即可

## 常见错法

- **按标称容量算满续航**
- **忽略待机与传感器功耗**
- **只看平均功率不看放电倍率**

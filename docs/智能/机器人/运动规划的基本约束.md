## 结论

**给机器人一条"从 A 到 B"的路径不够，速度与加速度也得规划，否则电机和结构先受不了。**
本机模拟 1 m 位移（同一 PD 跟踪器）：
**阶跃指令 0.867 s 到达，但峰值指令加速度 100 m/s²、加加速度 50,000 m/s³；
梯形速度 1.750 s、2.0 m/s²、1,020 m/s³；S 曲线 1.768 s、2.0 m/s²、99 m/s³。**

## 三层约束

```text
速度上限：电机转速、轮子线速度
加速度上限：扭矩、抓地力（超过就打滑）
加加速度上限（jerk）：结构冲击、振动、寿命
  → 只限加速度，冲击仍然存在；限 jerk 才平滑
```

**"慢了 1%，冲击降 10 倍"** 是 S 曲线的典型交易：用 1.768 s 换 99 m/s³。

## 本机可复现（已模拟）

```bash
python3 - <<'PY'
import numpy as np
dt=1e-3
def run(kind,T=2.5,d=1.0,amax=2.0,vmax=0.8,lag=0.02):
    n=int(T/dt); t=np.arange(n)*dt; x=v=0.0; a_cmd=0.0; xd_s=vd_s=0.0
    xs=[]; us=[]
    for i in range(n):
        s=t[i]-0.2
        if kind=='step':
            xd,vd,ad=(d if s>=0 else 0.0),0.0,0.0
        elif kind=='trap':
            ta=vmax/amax; da=0.5*amax*ta**2; tc=(d-2*da)/vmax
            if s<0: xd,vd,ad=0,0,0
            elif s<ta: xd,vd,ad=0.5*amax*s*s,amax*s,amax
            elif s<ta+tc: xd,vd,ad=da+vmax*(s-ta),vmax,0
            elif s<2*ta+tc:
                u=2*ta+tc-s; xd,vd,ad=d-0.5*amax*u*u,amax*u,-amax
            else: xd,vd,ad=d,0,0
        else:
            ta=vmax/amax; da=0.5*amax*ta**2; tc=(d-2*da)/vmax
            target = amax if 0<=s<ta else (0.0 if s<ta+tc else (-amax if s<2*ta+tc else 0.0))
            a_cmd += (target-a_cmd)*min(1,dt/lag)
            vd_s=max(0.0,min(vmax,vd_s+a_cmd*dt)); xd_s=min(d,xd_s+vd_s*dt)
            xd,vd,ad=xd_s,vd_s,a_cmd
        u=ad+20.0*(vd-v)+100.0*(xd-x)
        v+=u*dt; x+=v*dt; xs.append(x); us.append(u)
    xs=np.array(xs); us=np.array(us)
    ok=np.where(np.abs(xs-d)<=0.01*d)[0]
    return t[ok[0]] if len(ok) else float('nan'), np.max(np.abs(us)), np.max(np.abs(np.gradient(us,dt)))
for k in ('step','trap','scurve'):
    r,a,j=run(k); print(f"{k:<7} 到达 ±1% {r:.3f} s ｜ 峰值指令加速度 {a:.1f} m/s² ｜ 峰值加加速度 {j:.0f} m/s³")
PY
```

本机输出：

```text
step    到达 ±1% 0.867 s ｜ 峰值指令加速度 100.0 m/s² ｜ 峰值加加速度 50000 m/s³
trap    到达 ±1% 1.750 s ｜ 峰值指令加速度 2.0 m/s² ｜ 峰值加加速度 1020 m/s³
scurve  到达 ±1% 1.768 s ｜ 峰值指令加速度 2.0 m/s² ｜ 峰值加加速度 99 m/s³
```

## 为什么阶跃最危险

```text
阶跃 = 位置突变 → 误差项 kp·1m = 100 m/s² 的指令
真实电机给不出 → 饱和 → 实际响应变成"最大扭矩冲一下"
  → 皮带打滑、减速器受冲击、轮子空转
```

**"能到就行"** 在仿真里成立，在真机上会先坏机械件。

## 数字与阈值（本机模拟）

```text
阶跃：0.867 s / 100 m/s² / 50,000 m/s³
梯形：1.750 s / 2.0 m/s² / 1,020 m/s³
S 曲线：1.768 s / 2.0 m/s² / 99 m/s³（慢 1%，jerk 低 10 倍）
经验：jerk 上限取加速度上限的 5–10 倍（本机模拟用 2.0 / 10）
经验：移动机器人常见 0.3–1.0 m/s、0.5–2.0 m/s²
经验：超过 5 m/s² 的指令，多数轮式底盘会打滑
```

## 证据强度

- **模拟**：三个剖面来自本机数值积分（非真机）
- **公开经验**：常见速度/加速度范围、jerk 取 5–10 倍
- **推断**：真机的饱和、打滑与延迟会显著改变曲线形状

## 不适用的情况

- 需要"撞一下就走"的接触任务：故意用冲击，另说
- 慢速精密定位：jerk 影响小于伺服带宽

## 常见错法

- **只规划路径，不规划速度剖面**
- **把加速度设到电机极限，没有余量**
- **在仿真里用理想执行器调参，直接上真机**

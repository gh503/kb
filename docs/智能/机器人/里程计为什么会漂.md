## 结论

**里程计靠"累加自身运动"推算位置，误差会一路累加，且不会自愈。**
它不是"测不准"，而是**误差随距离单调增长**——这是所有航位推算的共同命运。

## 误差从哪来

```text
1. 轮径与轴距标定不准（最常见）
2. 轮子打滑（地面、急转、加速）
3. 编码器分辨率与量化误差
4. 地面不平、轮胎形变
5. 时间戳不同步（两轮采样不同时刻）
```

**"标定"是第一嫌疑**：轮径差 1%，走 100 米就差 1 米。

## 误差怎么长

```text
位置误差 ≈ 相对误差 × 行驶距离
角度误差 ≈ 相对误差 × 转向角度
```

例：轮径误差 2%，走 50 米 → 约 1 米位置误差；转 10 圈 → 角度误差累积可观。

**"角度误差比位置误差更致命"**：角度偏一点，之后走的每一米都朝错的方向。

## 现场怎么判断是里程计的问题

```text
走直线回原点：回不到 → 轮径/轴距标定或打滑
原地转 360°：朝向偏了 → 轴距参数错
只在特定地面出错：打滑（地毯、瓷砖、坡道）
```

**"三个测试"能在十分钟内定位方向**，不用拆机器。

## 怎么缓解

| 手段 | 作用 |
| --- | --- |
| 精细标定（走 10 米测偏差） | 消掉系统性误差 |
| 融合外部参考（激光、视觉、UWB） | 用绝对观测纠正累积 |
| 回环检测 | 认出"来过这里"，把漂移拉回 |
| 降低速度/减少急转 | 减少打滑 |

**"融合外部参考"是唯一能真正消除累积误差的办法**：光靠里程计做不到。

## 数字与阈值（经验判断）

```text
轮径标定误差：目标 < 0.5%
里程计漂移：常见 1%–5% 行驶距离（未融合时）
角度漂移：常见 1°–5°/米（差速底盘，未标定）
打滑场景：地毯、湿滑地面、急加速
标定距离：直线 5–10 米，转 5–10 圈
```

## 证据强度

- **公开经验**：里程计误差随距离累积、轮径/轴距标定是首要误差源
- **数字**：漂移比例为常见区间，**随底盘与地面差异很大**
- **未验证**：**未在任何实机上实测**，数字仅作数量级参考
- **推断**："角度误差更致命"按误差传播方向推的

## 不适用的情况

- 全向轮/麦轮：运动学模型不同，标定项更多
- 足式机器人：以腿部里程计与 IMU 融合为主

## 常见错法

- **只调参数不标定**：参数掩盖了系统性误差
- **用一次测试下结论**：地面与速度都会影响
- **忽略时间同步**：两轮采样不同步会引入假转向

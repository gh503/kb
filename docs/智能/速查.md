# 速查：智能这一域的判断与数

> AI 与机器人两科 16 条的关键数字。这一域最容易出问题的地方是**把"看起来对"当成"验证过"**。
> 所以这一页的数字全部标了来源；**没有任何一条是在模型上实测得到的**。

## 一、验证模型输出

| 项 | 数 | 说明 |
| --- | --- | --- |
| 一致性检查 | 同一问题问 3 次 | 答案不一致 → 不可用 |
| 抽样核对 | 批量内容抽 10%–20% | 对外发布要 100% |
| 可接受幻觉率 | 对外发布 0 | 内部草稿可放宽 |
| 必须逐条核对 | 金额、日期、人名、法条 | 高风险类型 |
| 评测集起步 | 30–50 条 | 含 10–20 条反例 |
| 评测集配比 | 常见 ≥ 60%，边界 ≥ 20%，拒答 ≥ 20% | 反例最能暴露问题 |
| 检索评测集 | 20–50 条"问题 + 正确出处" | 自己建，别人数字不适用 |
| 分块大小 | 300–800 字 | 按文档结构调整 |

## 二、提示与约束

| 项 | 数 | 说明 |
| --- | --- | --- |
| 结构化五段 | 角色、输入、步骤、格式、边界 | 缺输入分隔最容易出问题 |
| 步骤数 | ≤ 7 步 | 再多就拆调用 |
| 输出字段 | ≤ 10 个 | 再多容易漏字段 |
| 枚举值 | ≤ 10 个 | 开放分类结果无法聚合 |
| 示例数 | 1–3 个（≤ 5） | 必须含 1 个拒答例 |
| 单示例长度 | ≤ 200 字 | 太长挤占上下文 |
| 校验耗时 | < 50 ms | 本地解析 + 业务校验 |

## 三、重试与降级

| 项 | 数 | 说明 |
| --- | --- | --- |
| 格式类重试 | 1–2 次 | 必须带校验错误信息 |
| 可用性类重试 | 2–3 次 | 指数退避 + 抖动 |
| 退避 | 1s → 2s → 4s，±30% 抖动 | 避免同时打 |
| 总预算 | 交互式 ≤ 10 秒 | 超了直接降级 |
| 不重试 | 内容被拒、4xx 参数错、用户已取消 | 白花钱 |
| 交互延迟预算 | ≤ 2 秒（含调用） | 超了用户会走 |

## 四、机器人定位

| 项 | 数 | 说明 |
| --- | --- | --- |
| 轮径标定误差 | 目标 < 0.5% | 首要误差源 |
| 里程计漂移 | 1%–5% 行驶距离 | 未融合外部参考时 |
| 角度误差换算 | 1° → 每 100 米横偏约 1.7 米 | 三角函数直接算 |
| 纯 IMU 可用时长 | 数十秒 | 零偏 0.1–1°/s 时 |
| 时间同步误差 | 目标 < 10 ms | 1 m/s 下 10 ms = 1 cm |
| 外参标定 | 平移 < 1 cm，旋转 < 1° | 静止时多传感器观测要一致 |
| 激光 SLAM 闭环误差 | 常见 < 1% 行驶距离 | 有回环时 |
| 视觉 SLAM | 常见 1%–5% | 取决于纹理与运动 |
| 建图分辨率 | 栅格 5 cm 级 | 室内 |
| 重定位时间 | 目标 < 5 秒 | 重启后能否认出现场 |
| 异常值剔除 | 连续 3 帧偏离 > 3σ | 动态物体/反光 |

## 五、机器人安全

| 项 | 数 | 说明 |
| --- | --- | --- |
| 停止距离 | v·t + v²/(2a) | 已核验 |
| 0.5 m/s, a=2 | 0.21 m | 含 0.3 秒反应 |
| 1.0 m/s, a=2 | 0.55 m | 速度翻倍距离变 3 倍以上 |
| 2.0 m/s, a=2 | 1.60 m | 2.0/1.0 → 2.6/0.8 m |
| 反应时间 | 0.2–0.5 秒 | 含检测与系统响应 |
| 安全余量 | 停止距离的 20%–50% | 按风险评估 |
| 急停响应 | ≤ 数百毫秒 | 按现行标准核定 |
| 断通信停机 | ≤ 1 秒 | 心跳丢失即停 |
| 传感器超时 | 3 个控制周期 | 判"还活着吗" |
| 人机共存速度 | 0.25–0.5 m/s 常见实践 | 不构成合规结论 |
| 试运行 | ≥ 1 周有人值守 | 再无人值守 |

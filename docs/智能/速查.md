# 速查：智能这一域的判断与数

> 这一域最容易出问题的地方是**把"看起来对"当成"验证过"**。
> 所以这一页的数字全部标了来源；**没有任何一条是在模型上实测得到的**。

## 一、验证模型输出

| 项 | 数 | 说明 |
| --- | --- | --- |
| 一致性检查 | 同一问题问 3 次 | 答案不一致 → 不可用 |
| 抽样核对 | 批量内容抽 10%–20% | 对外发布要 100% |
| 可接受幻觉率 | 对外发布 0 | 内部草稿可放宽 |
| 必须逐条核对 | 金额、日期、人名、法条 | 高风险类型 |
| 评测集起步 | 30–50 条 | 含 10–20 条反例 |
| 评测集配比 | 常见 ≥ 60%，边界 ≥ 20%，拒答 ≥ 20% | 反例最能暴露问题 |
| 检索评测集 | 20–50 条"问题 + 正确出处" | 自己建，别人数字不适用 |
| 分块大小 | 300–800 字 | 按文档结构调整 |

## 二、提示与约束

| 项 | 数 | 说明 |
| --- | --- | --- |
| 结构化五段 | 角色、输入、步骤、格式、边界 | 缺输入分隔最容易出问题 |
| 步骤数 | ≤ 7 步 | 再多就拆调用 |
| 输出字段 | ≤ 10 个 | 再多容易漏字段 |
| 枚举值 | ≤ 10 个 | 开放分类结果无法聚合 |
| 示例数 | 1–3 个（≤ 5） | 必须含 1 个拒答例 |
| 单示例长度 | ≤ 200 字 | 太长挤占上下文 |
| 校验耗时 | < 50 ms | 本地解析 + 业务校验 |

## 三、重试与降级

| 项 | 数 | 说明 |
| --- | --- | --- |
| 格式类重试 | 1–2 次 | 必须带校验错误信息 |
| 可用性类重试 | 2–3 次 | 指数退避 + 抖动 |
| 退避 | 1s → 2s → 4s，±30% 抖动 | 避免同时打 |
| 总预算 | 交互式 ≤ 10 秒 | 超了直接降级 |
| 不重试 | 内容被拒、4xx 参数错、用户已取消 | 白花钱 |
| 交互延迟预算 | ≤ 2 秒（含调用） | 超了用户会走 |

## 关于这些数

- **公式/推导**：重试退避序列、评测集配比（可自行调整）
- **公开经验**：一致性检查、抽样比例、示例数、步骤数上限
- **推断**：分块大小、延迟预算
- **实测**：**一条都没有**。本文没有在任何模型或资料库上跑过评测，
  所有效果类结论都必须由你在自己的数据上验证。
- **会变的**：模型的上下文长度、延迟、成本随版本与供应商变化，引用前请核对当期文档

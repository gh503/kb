# TCP/IP

> 协议栈每一层做了什么，出错时该看哪里。

## 收什么

- 连接生命周期：三次握手、四次挥手、TIME_WAIT 堆积的真实后果
- 重传与拥塞：什么现象说明在丢包，怎么从抓包里看出来
- MTU 与分片：为什么大包过不去、小包没事
- 名字到地址：DNS 解析路径、缓存、失败时的表现
- 常用判读：`ss`、`tcpdump`、`traceroute` 的输出怎么读

## 不收什么

- 协议头逐字段背诵——除非排障时真用到了
- 教材式分层图

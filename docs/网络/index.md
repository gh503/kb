# 网络

> 两台机器怎么连上、连上之后协议怎么跑、以及怎么不被人打进来。

前四科是一条线：**网络通信**管「能不能通」，**TCP/IP** 管「通了之后每一层在做什么、出错看哪里」，**安全**管原则与响应。

后三科把「安全」拆开落到具体层：**软件安全**管程序自己有多脆，**主机安全**管这台机器上别人能做到什么，**硬件安全**管软件之下那层能不能被信。三科都只写判断与自查命令。

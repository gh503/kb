# 主机安全

> 这一科只回答一件事：**这台机器上，别人能做到什么。**
> 全是自查命令与盘点结果，不写入侵手法。数字都来自本机（Ubuntu 22.04 / 内核 6.8）。

## 收什么

- 暴露面：监听端口、运行服务、SUID 文件
- 权限基线：关键文件权限、umask
- 内核参数这层闸门
- 账号与提权路径
- 登录审计、补丁窗口、按数据分级的投入

## 不收什么

- 入侵与横向移动手法（不写）
- 具体 CVE 的利用细节
- 主机防护产品的选型

## 结论

**提权面 = 能变成 root 的所有路径。** 本机实测：**23 个 SUID/SGID 文件**、`/etc/sudoers` 440、
用户会话 **1 个**——数量都不大，但每一项都要知道"为什么存在"。

## 四条提权路径

```text
1. SUID 程序（以 root 身份运行）
2. sudo 规则（允许以 root 执行某命令）
3. 可写的系统文件/目录（改配置、改库）
4. 内核漏洞（本地提权）
```

**"第四条最难防"**：它不依赖配置错误，只看版本。

## 本机可复现（已实测）

```bash
find /usr -xdev -perm /6000 -type f | wc -l     # 23
stat -c '%a %U:%G' /etc/sudoers                 # 440 root:root
who | wc -l                                     # 1
getent passwd | awk -F: '$3>=1000 && $3<65534' | wc -l   # 普通用户数
```

本机输出：

```text
SUID/SGID: 23
/etc/sudoers: 440 root:root
当前会话: 1
```

## sudo 规则怎么读

```bash
sudo -l            # 当前用户能执行什么
```

**"能执行 vim/less/find 就等于能拿 root"**：这些程序能起 shell 或读写任意文件。
**"允许 NOPASSWD 的脚本"** 更是直接等于 root。

## 该定期核对的四项

| 项 | 命令 | 关注点 |
| --- | --- | --- |
| SUID | `find / -xdev -perm /6000 -type f` | 新增的、来源不明的 |
| sudo | `sudo -l` | NOPASSWD、可起 shell 的程序 |
| 可写系统路径 | `find / -xdev -writable -type d` | /etc、/usr 下的异常 |
| 空口令账号 | `awk -F: '$2==""' /etc/shadow` | 需要 root 读 |

**"空口令账号"是老问题但仍在**：容器镜像里尤其常见。

## 数字与阈值（本机实测）

```text
SUID/SGID 23 ｜ sudoers 440 ｜ 会话 1
经验：SUID > 50 要逐个核对来源
经验：sudo 允许 vim/less/find/python 等于 root
经验：普通用户数应与实际使用者一致
```

## 证据强度

- **实测**：三个计数为本机输出
- **公开经验**：SUID/sudo 的提权等价关系
- **推断**："23 个都必要"未逐个审计

## 不适用的情况

- 单用户桌面：提权面等于"我自己"，风险主要是恶意软件
- 无 sudo 的容器：提权路径另算（capabilities、挂载）

## 常见错法

- **给普通用户 NOPASSWD: ALL**
- **把 SUID 当"普通权限位"**
- **从不清理离职账号**

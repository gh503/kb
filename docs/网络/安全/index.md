# 安全

> 攻击面在哪、防线怎么搭、出事之后怎么收。

## 收什么

- 威胁建模：谁想进来、图什么、从哪个入口进
- 认证与授权：会话、令牌、密钥怎么存、怎么轮换
- 加固清单：主机、网络、依赖供应链，逐条可执行
- 事件响应：发现、隔离、取证、恢复的顺序，以及每一步的代价
- 真实事故复盘：入口、横向移动、什么时候才被发现

## 不收什么

- 工具参数手册
- 猎奇式的「黑客技术」
- 没有授权范围的渗透测试记录

!!! warning "公开仓库的边界"
    这个站点是公开的。**不要写**真实内网拓扑、口令、密钥、未修复漏洞的细节。
    要记就记「方法」和「已经修复的东西」。

# 硬件安全

> 这一科只回答一件事：**软件之下的那层，能不能被信。**
> 全部基于本机 `/sys`、`/proc`、`lsblk` 的只读观测；不做漏洞利用。

## 收什么

- 侧信道与推测执行：为什么"权限检查正确"也会泄漏
- 缓解措施怎么读、代价是什么
- 微码与固件更新
- Secure Boot、TPM、IOMMU 各自挡住什么
- 信任链到哪一环为止

## 不收什么

- 漏洞利用与 PoC
- 具体硬件的破解手法（不写）
- 芯片设计层面的细节

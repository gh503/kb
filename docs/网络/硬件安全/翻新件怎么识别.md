## 结论

**翻新件的破绽都在"计数器和身份"上：通电时长、写入量、序列号、固件版本。**
本机实测两块盘：`SanDisk SD8SNAT-128G`（SSD，119 GB）与 `HGST HTS721010A9E630`（HDD，931 GB），
SMART 详情需要 root——**这就是检的第一道门槛：能读计数器，才有判断依据。**

## 四个可查的量

```text
1. 通电时长（Power_On_Hours）：新盘应是个位数小时
2. 写入量（Data_Units_Written / Total_LBAs_Written）：换算成 TB
3. 重映射扇区（Reallocated_Sector_Ct）：新的应为 0
4. 身份：型号、序列号、固件版本是否与卖家声明一致
```

**"看外观有没有划痕"** 是最不可靠的一条。

## 本机可复现（已实测）

```bash
lsblk -d -o NAME,SIZE,ROTA,MODEL
cat /sys/class/nvme/nvme0/model 2>/dev/null
sudo smartctl -A /dev/sda | grep -E 'Power_On_Hours|Reallocated'
```

本机输出：

```text
sda 119.2G SSD SanDisk SD8SNAT-128G-1006 ｜ sdb 931.5G HDD HGST HTS721010A9E630
SMART 详情需 root（本机未提权）
```

## 判据

```text
通电 < 50 小时、写入 < 1 TB、重映射 = 0 → 基本可判新
通电 > 500 小时 → 不是全新（无论卖家怎么说）
重映射 > 0 或 待映射扇区 > 0 → 已有损伤
固件版本与厂商官网最新版差多个大版本 → 可能是库存/翻新
```

## 还有一个更硬的证据

```text
品牌厂商的序列号查询（部分支持）：序列号能查到出厂日期与保修起始
  → 保修起始早于购买半年以上，基本可判非新
  → 序列号在厂商系统里查不到，可能是工程件/OEM 件
```

## 数字与阈值（本机实测）

```text
两块盘：SSD 119.2 GB（SanDisk）、HDD 931.5 GB（HGST）
经验：新盘通电 < 50 h、写入 < 1 TB、重映射 0
经验：SSD 的"健康度"看 Percentage_Used，不看通电时长
经验：SMART 读不到时，至少核对型号/序列号/固件版本
```

## 证据强度

- **实测**：两块盘的型号与容量来自本机 `lsblk`
- **公开经验**：50 h / 1 TB / 重映射 0 的判据
- **推断**：翻新商可重置 SMART 计数器，需结合保修起始日期交叉验证

## 不适用的情况

- 企业采购（有资产标签与保修合同）：以合同与厂商记录为准
- 二手设备：本来就不是全新，判据换成"剩余寿命"

## 常见错法

- **只看外观与包装**
- **把"能点亮"当"是新的"**
- **不记录序列号，出问题无法追溯**

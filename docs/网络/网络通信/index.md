# 网络通信

> 两台机器怎么把数据可靠地送过去。

## 收什么

- 链路与组网：有线还是无线、拓扑怎么布、什么场景会掉线
- 带宽、延迟、丢包：怎么测，测出来多少算正常
- NAT、代理、防火墙：为什么「我这边能通，他那边不通」
- 定位顺序：从物理层往上逐层排除，而不是先怀疑应用

## 不收什么

- 协议字段逐条罗列——归 [TCP/IP](../TCP-IP/index.md)
- 厂商设备手册的复述

## 条目

还没有条目。第一条建议写**一次「时通时不通」**：现象、抓到的证据、最后定位到哪一层。

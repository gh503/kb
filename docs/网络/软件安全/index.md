# 软件安全

> 这一科只回答一件事：**这个程序被攻破的成本有多高。**
> 只写判断与自查命令，**不写攻击步骤**。每条结论都配本机可复现的检查。

## 收什么

- 一个二进制的四项基线加固（PIE / canary / RELRO / NX）
- ASLR 挡住了什么、挡不住什么
- 依赖链为什么是最长的攻击面
- 拼接字符串为什么必然出事
- 密钥与日志的泄漏面

## 不收什么

- 漏洞利用与武器化（不写，也不该写）
- 具体产品的漏洞细节
- 渗透测试流程

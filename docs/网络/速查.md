# 速查：网络里那些能算的数

> 三科 32 条的关键数字。这一页只放**能算的**与**能测的**。能算的给公式，能测的给命令——**数字自己跑一遍比记住更可靠**。

## 一、握手与往返

| 项 | 数 | 说明 |
| --- | --- | --- |
| TCP 建立连接 | 1 RTT（3 个包） | 关闭 1–2 RTT |
| TLS 1.3 | ≥ 1 RTT | 0-RTT 重连有重放风险 |
| TLS 1.2 | 2 RTT | 需等 ServerHello 再发密钥材料 |
| 首次页面加载 | ≥ 4 RTT | DNS + TCP + TLS + 请求 |
| 跨洋 RTT | 150–250 ms | 光纤里光速约 20 万 km/s，这是物理下限 |
| 同城 RTT | 1–10 ms | CDN 的价值就在这 |

## 二、吞吐

| 项 | 公式/数 | 说明 |
| --- | --- | --- |
| 带宽延迟积 | BDP = 带宽 × RTT | 决定"要多少数据在途" |
| 实际吞吐 | ≈ 窗口 / RTT | 窗口小于 BDP 就跑不满 |
| 100 Mbps + 150 ms | BDP ≈ 1.9 MB | 窗口不到就跑不到 100 Mbps |
| 256 KB 窗口 + 150 ms | ≈ 13.6 Mbps | 标称 100 Mbps 时的真实值 |
| 1% 丢包 | HTTP/2 吞吐降 20%–50% | 窗口减半 + 重新爬坡 |

## 三、HTTP 与压缩

| 项 | 数 | 说明 |
| --- | --- | --- |
| HTTP/1.1 同域连接 | 6（浏览器惯例） | 域名分片是 1.1 时代技巧 |
| HTTP/2 并发流 | 常见 100+ | 但 TCP 层仍有队头阻塞 |
| 文本压缩 | 常见压到 15%–30% | 本机实测一页：77,515 → 11,571 字节（14.9%） |
| 连接复用收益 | 省 2–3 个 RTT | 本机实测：1.52 s → 0.11 s |

## 四、排查命令（可直接复制）

```bash
# 各阶段耗时（一定要看 remote_ip，走代理时测的不是服务器）
curl -o /dev/null -w 'dns=%{time_namelookup} tcp=%{time_connect} tls=%{time_appconnect} ttfb=%{time_starttransfer} total=%{time_total} ip=%{remote_ip} ver=%{http_version}\n' https://example.com/

# TLS 协商结果
openssl s_client -connect example.com:443 -servername example.com -brief

# 证书有效期
echo | openssl s_client -connect example.com:443 -servername example.com 2>/dev/null | openssl x509 -noout -dates -subject

# 是否读 hosts（与 dig 结果对比即可看出差异）
getent hosts example.com

# TCP 重传与拥塞窗口
ss -ti dst :443

# 压缩比
curl -s -o /dev/null -w 'raw=%{size_download}\n' https://example.com/
curl -s -H 'Accept-Encoding: gzip' -o /dev/null -w 'gzip=%{size_download}\n' https://example.com/
```

## 五、长连接与重连

| 项 | 数 | 说明 |
| --- | --- | --- |
| 空闲超时（链路） | NAT 30–120 秒，负载均衡常见 60 秒 | 心跳要小于它 |
| 心跳周期 | 20–30 秒（移动端 15–30） | 取最短超时的 1/2–1/3 |
| 心跳超时 | 2–3 个周期 | 容忍一次丢包 |
| 断线检测目标 | ≤ 90 秒 | 超了用户会以为消息没发出去 |
| 退避基数 | 1 秒 | 指数增长 |
| 退避上限 | 30–60 秒 | 必须设 |
| 抖动范围 | ±20%–50% | 防重连风暴的关键 |
| 重连上限 | 5–10 次后转手动 | 无限重试耗电且无意义 |
| 补拉窗口 | 服务端留 5–30 分钟消息 | 断线期间不能出空洞 |
| SSE 浏览器默认重连 | 3 秒（可用 retry: 改） | 少见于文档但很实用 |

## 六、HTTPS 与证书

| 项 | 数 | 说明 |
| --- | --- | --- |
| 公开 CA 证书有效期 | 常见 ≤ 398 天（趋短） | 到期预警提前 30 天 |
| HSTS 初始 max-age | 300 秒 | 先短后长，否则无法回退 |
| HSTS 稳定值 | ≥ 6 个月，常见 1 年 | 31536000 秒 |
| preload 撤销 | 需等浏览器版本更新，可能数月 | 慎用 |
| 通配符证书 | 只覆盖一级子域 | `*.a.com` 不含 `x.y.a.com` |
| 跳转状态码 | 301/308 | 不用 JS 跳转（明文已发出） |

## 关于这些数

- **公式**（BDP、吞吐 ≈ 窗口/RTT、RTT 次数）：可直接算
- **实测**：共 **6 处**，全部标了环境（Ubuntu 22.04 + 本地代理）：DNS 计时、curl 分阶段耗时、连接复用、gzip 压缩比、TLS 协商结果、证书链验证
- **警告**：本机实测的绝对耗时受代理影响，**不可外推**；能外推的是"复用与否差一个数量级"这类相对结论
- **公开经验**：各地 RTT 区间、丢包影响区间

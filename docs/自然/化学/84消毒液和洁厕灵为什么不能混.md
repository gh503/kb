# 84 消毒液和洁厕灵为什么不能混

> **学段** 小学–初中 ｜ **类型** 机制（安全） ｜ **链** 含氯消毒剂

## 结论

84 是次氯酸钠（碱性），洁厕灵是盐酸（酸性）。两者一混，立刻发生归中反应放出**氯气**——
黄绿色、比空气重、有强烈刺激性，吸进去会灼伤呼吸道。**这是居家最危险的一类混用。**

## 机制

```text
NaClO + 2 HCl → NaCl + Cl₂↑ + H₂O
```

氯在次氯酸根里是 +1 价，在盐酸里是 −1 价，相遇后都变成 0 价的氯气。
这类"同一元素的高价与低价碰成中间价"的反应叫**归中反应**，通常很快，不需要加热。

现象：立刻冒黄绿色气体、有刺鼻味、眼睛辣、嗓子痒。

## 边界

- **酸越强、温度越高、浓度越大，放气越快**。所以用热水兑、在密闭卫生间里用，最危险
- 不只是洁厕灵：**含氨的清洁剂**（部分玻璃水、霉菌清除剂）混 84 会生成氯胺，同样有毒；
  混酒精会产生氯仿等副产物
- 稀释后的 84 仍会反应，只是慢一些——"稀释过就没事"是错的

## 用得上（出事怎么办）

1. 立刻离开，开窗通风，向**上风向**撤
2. 眼睛或皮肤溅到，用大量清水冲至少 15 分钟
3. 出现持续咳嗽、胸闷、呼吸困难，直接就医，并说明吸入了氯气
4. **不要**为了"中和"再倒别的东西进去

# 化学

> 物质之间怎么反应，以及为什么有些组合危险。

## 收什么

- 反应原理：为什么这个和那个会反应，条件是什么
- 安全事项：混用会出事的生活化学品，以及出事后的处理
- 生活实例：清洁、烹饪、材料老化里的化学

## 不收什么

- 元素周期表背诵
- 没做过的实验步骤——照抄容易出事

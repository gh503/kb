# pH 到底是什么意思

> **学段** 初中–高中 ｜ **类型** 量级 ｜ **链** 酸碱

## 结论

pH 是**氢离子浓度的负对数**：`pH = −log₁₀[H⁺]`。
所以 pH 每差 1，H⁺ 浓度就差 **10 倍**——这个"对数"是理解酸碱最关键的一点。

## 怎么算

```text
[H⁺] = 10⁻³ mol/L  →  pH = 3
[H⁺] = 10⁻⁶ mol/L  →  pH = 6
pH 从 6 降到 5，H⁺ 浓度变成原来的 10 倍
```

## 常见数值

| 物质 | 大致 pH |
| --- | --- |
| 胃酸 | 1.5–3.5 |
| 柠檬汁 | 2–3 |
| 食醋 | 2.5–3.5 |
| 咖啡 | 5 |
| 纯水（25℃） | 7 |
| 血液 | 7.35–7.45 |
| 肥皂水 | 9–10 |
| 漂白水 | 12–13 |

## 边界

- pH 7 只在 25℃ 附近代表"中性"；温度变了，中性点也变
- pH 是**强度**指标，不是"总量"：少量强酸和大量弱酸可以有同样 pH
- 强酸稀释 10 倍，pH 升约 1；但弱酸稀释时 pH 变化小（缓冲）
- 检测：pH 试纸只能粗测，精确测量用 pH 计

## 误解

- **"pH 是酸的程度，线性刻度"**——是对数刻度
- **"pH 越低越危险"**——还要看量、接触时间、酸的类型

## 用得上

- 游泳池、鱼缸、土壤都要测 pH
- 皮肤 pH 偏酸（约 4.5–5.5），所以碱性皂会"紧绷"

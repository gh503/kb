# 不锈钢为什么不锈

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 铁与腐蚀

## 结论

因为铬。含铬超过约 10.5% 时，钢表面会形成一层**几个纳米厚的氧化铬钝化膜**，
致密、不溶解、还能自我修复——它把铁和水、氧隔开了。

## 机制

1. 铬比铁更容易氧化，优先在表面生成 Cr₂O₃
2. 这层膜只有 1–3 nm，但极其致密，几乎不导电、不溶
3. 被划伤后，暴露的铬立刻重新氧化，膜**自修复**
4. 所以不锈钢不是"不锈"，是"锈得极慢且能自愈"

## 边界

- **氯离子是钝化膜的克星**：海水、盐雾、含氯清洁剂会局部破坏膜，引发点蚀
- 不锈钢怕**缝隙**和** stagnant 水**：缝隙里氧不足，膜无法修复，反而锈得厉害
- 不同牌号差别很大：304 怕氯，316 加了钼，抗氯离子点蚀更强
- 高温、强酸也会破坏钝化膜

## 量级

```text
钝化膜厚度 ≈ 1–3 nm，约十几个原子层
铬含量门槛 ≈ 10.5%（质量分数）
```

## 用得上

- 海边、泳池边选 316 而不是 304
- 不锈钢锅不要长时间装盐水、醋
- 不锈钢"生锈"多半是表面附着铁屑（外来锈），不是本体锈

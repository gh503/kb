# 为什么代糖也甜

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 糖与甜味剂

## 结论

因为甜味受体不"认"特定分子，只认**形状和电荷的匹配**。
只要分子某个局部能嵌进受体、把它激活，就有甜味——哪怕结构和糖完全无关。

## 机制

1. 甜味受体有一个"结合口袋"，能容纳特定空间结构
2. 蔗糖靠多个羟基形成氢键
3. 阿斯巴甜靠苯环 + 羧基 + 氨基的不同排布
4. 三氯蔗糖是把蔗糖的羟基换成氯，甜度提高几百倍
5. 结构不同，但只要"钥匙"对得上，就能开锁

## 常见代糖

| 名称 | 相对甜度 | 特点 |
| --- | --- | --- |
| 阿斯巴甜 | 约 200 | 含苯丙氨酸，苯丙酮尿症患者慎用 |
| 三氯蔗糖 | 约 600 | 耐热，常用于烘焙 |
| 糖精 | 约 300 | 有金属后味 |
| 甜菊糖 | 约 200–300 | 天然来源，有草本味 |
| 赤藓糖醇 | 约 0.7 | 糖醇，几乎不升血糖 |

## 边界

- 甜度是相对值，随浓度、温度、介质变化
- 代糖往往有"后味"或"苦味"，因为也激活了其他受体
- 糖醇吃多会腹泻（渗透性）
- 天然 ≠ 更安全，人工 ≠ 更有害，要看剂量与证据

## 用得上

- 看配料表认名字：阿斯巴甜、安赛蜜、三氯蔗糖、甜菊糖苷
- 烘焙用糖不只提供甜味，还影响结构和上色

## 误解

- **"代糖是化学合成的所以有毒"**——毒性看剂量与证据
- **"代糖没有热量所以随便吃"**——部分糖醇有热量

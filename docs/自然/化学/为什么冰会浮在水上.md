# 为什么冰会浮在水上

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 水

## 结论

因为水结冰时，氢键把分子排成**六方空架结构**，分子间的空隙变大，密度反而**变小**。
所以冰（0.92）比水（1.00）轻，会浮起来——这是自然界少见的"固态比液态轻"。

## 机制

1. 液态水里，分子靠氢键不断断裂重组，排列较紧密
2. 结冰时，每个水分子与四个邻居形成氢键，排成六方晶格
3. 这种结构中间留出空腔，体积膨胀约 9%
4. 密度下降 → 冰浮在水面
5. 冰层隔热，让下面的水不易结冰，鱼才能过冬

## 量级

```text
水 4℃ 时密度最大：约 1.000 g/cm³
冰 0℃ 密度：约 0.917 g/cm³
结冰体积膨胀：约 9%
```

## 边界

- 水在 4℃ 时密度最大，所以湖泊是从表面开始结冰
- 结冰膨胀会产生巨大压力，冻裂水管、风化岩石
- 高压下冰会有其他晶型（如冰 VI、冰 VII），密度可比水大
- 不是所有物质都这样：多数物质固态比液态密度大

## 用得上

- 冬天水管要保温或放空，防冻裂
- 冰浮在水面，才形成"冰下过冬"的生态
- 冰箱冷冻要注意容器留空间

## 误解

- **"冰浮是因为它轻"**——是同质量下体积更大，密度小
- **"水结冰体积不变"**——膨胀约 9%

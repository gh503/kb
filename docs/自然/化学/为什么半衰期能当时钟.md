# 为什么半衰期能当时钟

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 放射性

## 结论

因为放射性衰变的速度**不受温度、压力、化学状态影响**，只由原子核决定。
所以只要测出样品里还剩多少放射性同位素，就能反推它"埋了多久"。

## 机制

1. 放射性核素按固定概率衰变，半衰期是常数
2. 生物活着时不断与环境交换碳，¹⁴C 比例稳定
3. 生物死亡后不再摄入，¹⁴C 按半衰期减少
4. 测剩余比例 → 用 `N = N₀·(1/2)^(t/T)` 算年龄
5. 不同同位素适用不同时间尺度

## 常用"时钟"

| 同位素 | 半衰期 | 适用范围 |
| --- | --- | --- |
| 碳-14 | 约 5730 年 | 几百年到 5 万年 |
| 钾-40/氩-40 | 约 12.5 亿年 | 火山岩、百万年级 |
| 铀-238/铅-206 | 约 44.7 亿年 | 地球年龄、数十亿年 |
| 铷-锶 | 约 488 亿年 | 古老岩石 |

## 边界

- 碳-14 需要校准曲线（大气¹⁴C 浓度历史上有变化）
- 样品污染会严重干扰结果
- 超出适用范围就测不准（太老或太新）
- 不同方法交叉验证才可靠

## 用得上

- 考古断代、古气候研究都靠这套方法
- 放射性药物、核医学也利用半衰期选择同位素

## 误解

- **"半衰期到了就全没了"**——是剩一半，再半衰期再剩一半
- **"衰变受环境影响"**——核过程基本不受化学环境左右

# 为什么古代铁比金贵

> **学段** 初中–高中 ｜ **类型** 对比 ｜ **链** 金属与冶炼

## 结论

因为**金在自然界以单质存在**，淘洗、捡拾就能得到；铁在自然界几乎都以氧化物存在，
要从矿石里"抢"出铁，需要**高温 + 还原剂**——这是技术门槛。

## 机制

1. 金化学性质稳定，不被氧化，常以金块、金砂形式存在
2. 铁活泼，自然界主要是 Fe₂O₃、Fe₃O₄ 等氧化物
3. 炼铁需要把矿石加热到约 1200℃ 以上，用碳（木炭）还原
4. 需要耐火炉、鼓风设备、足够燃料
5. 技术没到位时，铁的产量极低，反而比金稀有

## 边界

- 这个"铁比金贵"主要出现在早期铁器时代的部分地区，不是所有文明、所有时期
- 中国在春秋战国就掌握了生铁冶炼，铁器普及较早
- 铝在 19 世纪也曾比银贵，逻辑相同：提炼难
- 稀有程度由**提炼难度 + 丰度**共同决定，不只看地壳含量

## 量级

```text
地壳丰度：铁约 5%（第 4 位），金约 0.0000004%（极低）
但古代铁的产量受冶炼技术限制，价格可以高于金
```

## 用得上

- 判断材料"贵不贵"：看提炼能耗与工艺，不只看储量
- 铝、钛、稀土都经历过"技术解锁后降价"

## 误解

- **"贵是因为少"**——铝、铁都不少，贵在提炼
- **"古代一直铁比金贵"**——技术普及后铁就便宜了

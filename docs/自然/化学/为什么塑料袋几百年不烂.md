# 为什么塑料袋几百年不烂

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 塑料

## 结论

因为塑料的主链是**碳—碳单键**，非常稳定，自然界几乎没有微生物进化出能"剪断"它的酶。
它在环境里主要不是"腐烂"，而是被紫外线和机械力**碎成越来越小的颗粒**——变成微塑料。

## 机制

1. C–C 键键能高，不易被水解、氧化
2. 微生物降解需要特定的酶，而塑料出现只有几十年，进化来不及
3. 阳光中的紫外线能打断部分化学键（光氧化），使塑料变脆
4. 风浪、摩擦把它磨碎，但**分子并没有消失**，只是变成微米、纳米级颗粒
5. 所以"降解"和"破碎"是两回事：破碎不等于消失

## 量级

```text
常见估算（差异极大，仅供参考）：
塑料袋 10–1000 年
PET 饮料瓶 约 450 年
渔网、尼龙 数百年
```

这些数字多来自加速老化实验外推，不是实测。

## 边界

- 光照、温度、氧气会加速老化，但产物仍是碎片
- 埋在缺氧、无光的填埋场里，降解更慢
- 有些塑料（如 PLA）在特定条件下可被微生物利用，见下一条
- "可降解"标签常指工业堆肥条件，不是自然环境

## 用得上

- 减少一次性塑料，比"等它降解"实在
- 塑料不要焚烧（可能产生二噁英等），要按当地分类处理
- 厨余里的塑料袋会污染堆肥

## 误解

- **"塑料袋埋在土里会自己消失"**——多数只是碎成微塑料
- **"纸袋一定比塑料袋环保"**——要看使用次数与生产能耗，纸袋需要重复使用很多次才划算

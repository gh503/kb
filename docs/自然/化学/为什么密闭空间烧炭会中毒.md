# 为什么密闭空间烧炭会中毒

> **学段** 大学–研究生 ｜ **类型** 机制（安全） ｜ **链** 燃烧

## 结论

因为碳不完全燃烧会产生**一氧化碳**：无色、无味、比空气略轻。
它和血红蛋白的结合力是氧的**两百多倍**，一旦结合就很难解开，血液失去运氧能力。

## 机制

```text
2 C + O₂ → 2 CO      （缺氧、高温时）
CO + 血红蛋白 → 碳氧血红蛋白（HbCO）
```

1. 密闭空间氧气逐渐耗尽，燃烧从完全转向不完全，CO 大量生成
2. CO 与血红蛋白的亲和力约为氧的 200–250 倍
3. HbCO 一旦形成，解离极慢，血红蛋白无法再运氧
4. 组织缺氧，最先受影响的是大脑和心脏
5. 中毒者可能先头痛、乏力、恶心，然后嗜睡、昏迷——**在睡眠中死亡是典型情形**

## 边界

- CO 比空气略轻（分子量 28 vs 29），在密闭空间里会混合分布，不会只沉在低处
- 浓度与时间共同决定后果：低浓度长时间同样危险
- 孕妇、心血管病人、儿童更敏感
- **没有气味不代表没有 CO**：报警器是唯一可靠手段

## 量级

```text
HbCO 10%：头痛、乏力
HbCO 20–30%：恶心、眩晕、判断力下降
HbCO > 50%：昏迷、抽搐、死亡风险高
```

## 用得上

- 炭火取暖、烧烤、发电机，**绝不在密闭室内使用**
- 装一氧化碳报警器，比"开点窗"可靠
- 发现中毒：先开窗通风、把人移到空气流通处、立即叫急救；不要在现场开灯或点火

## 误解

- **"闻不到味道就安全"**——CO 无色无味
- **"放盆水能吸 CO"**——CO 难溶于水，没用

## 到此为止

再往下问"为什么亲和力这么高"，是**配位化学与血红素结构**；
问"为什么缺氧会致死"，是细胞呼吸链——到这一层是生物化学的具体机制。

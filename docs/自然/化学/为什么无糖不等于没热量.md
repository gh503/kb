# 为什么"无糖"不等于没热量

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 糖与甜味剂

## 结论

因为"无糖"是**法规定义**（每 100 g/mL 含糖 ≤ 0.5 g），不是"零热量"。
糖醇有热量（约 2.4 kcal/g），淀粉、脂肪、蛋白质也会贡献热量。

## 机制

1. "无糖"只限制**糖**（单糖、双糖），不限制淀粉、脂肪
2. 糖醇（赤藓糖醇、木糖醇、山梨糖醇）有不同热量：
   - 赤藓糖醇约 0.2 kcal/g
   - 木糖醇约 2.4 kcal/g
   - 山梨糖醇约 2.6 kcal/g
3. "无蔗糖"可能含果糖、麦芽糖浆
4. "0 糖 0 卡"通常指每份低于阈值，不代表绝对为零
5. 代糖饮料的酸、色素、咖啡因也会影响健康

## 量级

```text
"无糖"标准：糖 ≤ 0.5 g/100 g(mL)
"低糖"：糖 ≤ 5 g/100 g(mL)
赤藓糖醇热量：约 0.2 kcal/g（几乎可忽略）
木糖醇：约 2.4 kcal/g（接近蔗糖的 60%）
```

## 边界

- 不同国家/地区的"无糖"定义略有差异
- 无糖食品可能高脂、高淀粉，热量并不低
- 糖醇过量会引起腹胀、腹泻
- "无糖"不等于"对牙齿无害"（酸性饮料仍腐蚀牙釉质）

## 用得上

- 看营养成分表的**能量**，不只看"无糖"标识
- 无糖饼干、无糖糕点常含大量淀粉和油
- 代糖饮料可以偶尔喝，但别当水喝

## 误解

- **"无糖就是零卡"**——不是
- **"无蔗糖就是无糖"**——可能含其他糖

## 到此为止

这一层是**法规 + 营养学**：标签定义与真实热量是两套东西。
读标签要看"能量"和"配料表"，不能只看正面宣传。

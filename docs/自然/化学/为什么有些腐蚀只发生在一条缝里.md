# 为什么有些腐蚀只发生在一条缝里

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 铁与腐蚀

## 结论

因为腐蚀不是均匀发生的，它**挑地方**：缝隙、划痕、夹杂物、应力集中处。
这些局部位置一旦形成"小阳极 + 大阴极"，腐蚀会以远高于平均速率的**局部穿透**方式推进。

## 机制

1. **缝隙腐蚀**：缝里氧进不去，氧浓度低的地方成为阳极，被优先溶解
2. **点蚀**：氯离子局部击穿钝化膜，形成小坑；坑内酸化、自催化，越蚀越深
3. **电偶腐蚀**：两种不同金属接触，活泼的那个被牺牲
4. **应力腐蚀开裂**：拉应力 + 腐蚀环境共同作用，裂纹快速扩展

## 边界

- **平均腐蚀速率会骗人**：一个每年 0.01 mm 的平均值，可能掩盖某处每年 1 mm 的点蚀
- 局部腐蚀的萌生有**随机性**，与夹杂物、表面缺陷、残余应力相关
- 实验室加速试验与真实环境常对不上，标准试验通过不代表现场安全

## 未解与争议

- 点蚀**萌生**的预测仍是概率问题：什么时候、在哪个位置开始，缺乏可靠模型
- 应力腐蚀开裂的裂纹扩展速率，对材料与环境的组合极其敏感，数据分散
- 工业上靠**定期检测 + 保守设计余量**，而不是靠精确预测

## 到此为止

这一层是**工程判断**而非公理：局部腐蚀的物理化学机制清楚，
但"哪一点先坏"由微观缺陷的随机分布决定，本库标为**未解**。

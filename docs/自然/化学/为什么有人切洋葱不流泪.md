# 为什么有人切洋葱不流泪

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 洋葱

## 结论

至少四个来源叠加：**催泪因子的产量**（品种、储存）、**受体敏感度**（TRPA1 的个体差异）、
**习惯化**（长期暴露后反应减弱）、以及**切菜方式**。没有单一解释。

## 机制与证据

- **产量**：含硫底物含量随品种、土壤硫供应、储存时间变化，能差几倍
- **受体**：TRPA1 是离子通道，人群中存在功能差异的单核苷酸多态性，
  对芥末、洋葱、辣椒素的敏感度因此不同
- **习惯化**：反复暴露后，三叉神经通路的反应会下调——厨师普遍不流泪，不全是技巧
- **行为**：刀法、通风、是否冷藏，直接改变到达眼睛的浓度

## 边界

- 这些因素各自只解释一部分方差，**没有"不流泪基因"这种单一原因**
- 戴隐形眼镜的人常觉得更明显：镜片让泪液分布改变，挥发物停留更久
- 用嘴呼吸、开窗，都能改变到达角膜的浓度

## 未解与争议

- TRPA1 多态性对洋葱敏感度的**定量贡献**没有可靠估计，样本量普遍偏小
- "习惯化"是受体下调还是行为适应（比如学会屏息、侧头），实验上没分开
- 品种间的催泪因子产率缺乏标准化测量，农业上也没把它当育种指标

## 到此为止

再往下问"TRPA1 为什么被这个分子激活"，是**结构生物学**（配体结合口袋与构象变化）；
问"为什么通道打开会产生电信号"，是神经生理学的**基本事实**——本库在此标为**公理层**。

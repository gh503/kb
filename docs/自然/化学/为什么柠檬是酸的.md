# 为什么柠檬是酸的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 酸碱

## 结论

因为柠檬里含**柠檬酸**，溶在水里会放出氢离子（H⁺）。
舌头上的酸味受体对 H⁺ 敏感，H⁺ 越多就越酸——**酸的本质是"能给出 H⁺"**。

## 机制

1. 酸溶于水，解离出 H⁺（严格说是 H₃O⁺，水合氢离子）
2. H⁺ 刺激味蕾上的酸敏通道，产生酸味
3. 酸还能和金属、碳酸盐反应，所以酸会腐蚀铁、能除水垢
4. 酸越容易解离（越"强"），同样浓度下 H⁺ 越多，越酸

## 边界

- **强酸和弱酸不是"浓度高低"**：盐酸是强酸（几乎完全解离），醋酸是弱酸（只解离一部分）
- 酸味强弱不只取决于酸，还受糖、盐、温度影响
- 有些酸不"酸"：硼酸、硅酸很弱，几乎尝不出
- 酸性和腐蚀性不是一回事：浓硫酸的腐蚀更多来自脱水性

## 用得上

- 柠檬汁去腥、腌肉变嫩：酸让蛋白质变性
- 醋除水垢：酸溶解碳酸钙
- 酸味食物不要长时间泡在金属容器里

## 误解

- **"酸的都是危险的"**——醋酸、柠檬酸、碳酸都在日常食物里
- **"酸味越强酸性越强"**——味觉只是粗略指标，pH 才是定量

# 为什么氡气是室内主要辐射源

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 放射性

## 结论

因为土壤和建材里的**铀、镭**会衰变出**氡气**。氡是气体，能从地基缝隙渗进室内，
密闭空间里越积越浓——它是普通人受到的**最大辐射来源**。

## 机制

1. 铀-238 衰变链中产生镭-226
2. 镭-226 衰变成氡-222（半衰期约 3.8 天）
3. 氡是惰性气体，从土壤、岩石、建材中逸出
4. 通过地基裂缝、管道缝隙进入室内
5. 氡继续衰变出 α 粒子，被吸入后作用于肺组织

## 量级

```text
室外氡浓度：通常几 Bq/m³
室内：可达几十到几百 Bq/m³
参考水平：多数国家建议室内年均 < 100–300 Bq/m³
氡是肺癌的第二大危险因素（仅次于吸烟）
```

## 边界

- 地下室、一层、通风差的房间浓度更高
- 花岗岩建材可能贡献，但通常不如土壤
- 吸烟 + 氡有协同效应，风险不是简单相加
- 检测便宜，治理主要是通风与密封

## 用得上

- 新房、地下室可做氡检测
- 多通风是最简单的降氡手段
- 装修选材看检测报告，别只看"天然"

## 误解

- **"天然石材都危险"**——要看放射性比活度，多数合格
- **"闻不到就没问题"**——氡无色无味

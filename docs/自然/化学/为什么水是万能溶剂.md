# 为什么水是万能溶剂

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 水

## 结论

因为水分子是**极性分子**：一头带正电、一头带负电。它能把盐、糖这类物质的分子或离子
"拽开"并包围起来，让它们散到水里——这叫溶解。

## 机制

1. 水分子中氧偏负、氢偏正，形成电偶极
2. 遇到离子（如 Na⁺、Cl⁻），水分子用相反的一端把它围住（水合）
3. 水合力削弱离子间的静电吸引，晶体就散开
4. 对糖这类极性分子，水通过氢键把它"拉"进溶液
5. 汽油、油脂是非极性的，水"抓不住"，所以不溶

## 边界

- "万能"是夸张：油、塑料、多数气体在水里溶得很少
- 水的介电常数很高（约 80），能大幅削弱离子间的吸引力
- 温度升高一般溶解加快，但气体溶解度反而下降
- "相似相溶"：极性溶极性，非极性溶非极性

## 用得上

- 洗衣服：水溶盐和糖，油污要靠表面活性剂
- 泡茶、冲咖啡：萃取的是水溶性成分
- 不要用水擦电子产品，因为水会溶出离子、导电

## 误解

- **"水能溶解一切"**——只溶极性和离子型物质
- **"溶解就是消失"**——物质还在，只是分散成分子/离子

# 为什么水能灭火

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 燃烧

## 结论

水干了两件事：**吸热降温**，以及变成水蒸气后**排开氧气**。
但水不是万能的——油火、电火、金属火用水反而更危险。

## 机制

1. 水的比热容大（4.2 kJ/(kg·K)），汽化潜热更高（2260 kJ/kg）
2. 浇上去先吸走大量热，把温度压到燃点以下
3. 水变成蒸汽，体积膨胀约 1700 倍，把空气（氧气）挤开
4. 两个效应叠加，火就断了"燃料—氧气—热量"三角

## 边界

见这张表比背口诀有用：

| 火情 | 能不能用水 | 为什么 |
| --- | --- | --- |
| 木材、纸张、织物 | 可以 | 常规冷却 |
| 食用油 | **不行** | 水瞬间汽化，把燃烧的油溅开，火势扩大 |
| 电器（未断电） | **不行** | 导电，触电风险 |
| 金属（镁、钠） | **不行** | 与水反应放氢，甚至爆炸 |
| 汽油 | **不行** | 油浮在水面继续烧 |

## 量级

```text
1 kg 水从 20℃ 到 100℃ 吸热 ≈ 335 kJ
再汽化吸热 ≈ 2260 kJ
合计约 2.6 MJ，相当于烧掉约 60 g 木材的热量
```

## 用得上

- 厨房油锅起火：盖锅盖、关火，**不要泼水**
- 电器起火：先断电，再用干粉或二氧化碳灭火器
- 家里备一个干粉灭火器，比知道一堆口诀实在

## 误解

- **"水灭火是因为水是湿的"**——是吸热 + 隔氧
- **"任何火都能用水"**——油、电、金属三类都不行

# 为什么水能调节气候

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 水

## 结论

因为水的**比热容特别大**（4.18 kJ/(kg·K)），吸热升温慢、放热降温也慢。
海洋像一个巨大的"热库"，把昼夜和季节的温差抹平。

## 机制

1. 比热容大 → 同样吸热，水温变化小
2. 海水混合、洋流把热量从低纬带到高纬
3. 蒸发吸热（汽化潜热 2260 kJ/kg）进一步缓冲温度
4. 沿海地区年温差、日温差都比内陆小
5. 水汽输送也把热量带到内陆

## 量级

```text
水：4.18 kJ/(kg·K)
沙石/土壤：约 0.8–1.0 kJ/(kg·K)
同质量吸同样的热，水的升温只有沙土的约 1/4–1/5
```

## 边界

- 海洋性气候温差小，大陆性气候温差大
- 水体面积、深度、洋流决定调节能力
- 蒸发在干燥地区降温更明显
- 城市水体（湖、河）只能局部调节

## 用得上

- 沿海城市夏天不那么热、冬天不那么冷
- 同一纬度，内陆昼夜温差大，要注意保暖
- 农业上，水体附近可减轻霜冻

## 误解

- **"水多所以凉快"**——是吸热慢、蒸发吸热，不是"水本身冷"
- **"海洋调节只影响海边"**——通过水汽和风影响更远

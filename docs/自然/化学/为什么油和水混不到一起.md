# 为什么油和水混不到一起

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 表面活性剂

## 结论

因为水是**极性**的，油是**非极性**的，两者分子间作用力不匹配；
混合会大幅增加界面面积，能量上不划算，所以它们自动分开、把界面缩到最小。

## 机制

1. 水分子之间有强氢键，油分子之间只有弱色散力
2. 油分子挤进水会破坏氢键网络 → 能量升高
3. 系统倾向于减少接触面积 → 油聚成球滴
4. 这叫"疏水效应"，是熵与能量共同作用的结果
5. 加入表面活性剂，界面被"包住"，就能暂时混匀（乳化）

## 量级

```text
水的表面张力：约 72 mN/m（20℃）
油水界面张力：约 20–50 mN/m
加表面活性剂后可降到 1 mN/m 以下
```

## 边界

- "混不到一起"是热力学倾向，不是绝对不可能
- 剧烈搅拌能形成暂时乳液，但会分层
- 乳化剂让乳液稳定，但不是"真溶液"
- 酒精这类"两亲"溶剂可以互溶

## 用得上

- 油污清洗要靠表面活性剂
- 沙拉酱是水包油乳液，放久了会分层
- 油锅着火不能用水浇（水会瞬间汽化把油溅开）

## 误解

- **"油比水轻所以分层"**——密度只是分层方向，不是不相溶的原因
- **"用力摇就能溶"**——只是暂时分散

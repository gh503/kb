# 为什么泡沫会破

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 表面活性剂

## 结论

泡沫是**液膜包着气体**。液膜里的液体不断往下排、变薄，薄到一定程度就破裂；
小气泡还会并成大气泡（奥斯特瓦尔德熟化），让泡沫整体"塌陷"。

## 机制

1. 表面活性剂吸附在气液界面，降低表面张力，稳住液膜
2. 重力让液膜中的液体下排，膜变薄（排液）
3. 膜薄到纳米级，热涨落就能击穿它 → 破裂
4. 小气泡内压更高，气体通过液膜扩散进大气泡 → 小泡消失、大泡变大
5. 消泡剂就是反过来破坏液膜稳定性的东西

## 量级

```text
液膜厚度：从微米级排液到几十纳米才破
泡沫寿命：几秒到几小时（取决于配方）
```

## 边界

- 纯水几乎不起泡，因为没有表面活性剂稳膜
- 蛋白（如蛋清）能形成很稳定的泡沫
- 温度升高、pH 变化会影响稳定性
- 消泡剂（如硅油）靠"局部破膜"起作用

## 用得上

- 煮豆浆、煮面条溢锅，可以滴油或调小火
- 啤酒泡沫的持久性与蛋白质、苦味物质有关
- 工业上要区分"需要泡沫"（浮选）和"需要消泡"（发酵）

## 误解

- **"泡沫多说明去污力强"**——两者不直接相关
- **"泡沫是空气溶在水里"**——是气液界面膜，不是溶解

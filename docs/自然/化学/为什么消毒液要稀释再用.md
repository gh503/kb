# 为什么消毒液要稀释再用

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 含氯消毒剂

## 结论

因为浓度太高**既伤人也伤物**：刺激性更强、腐蚀更快，而且并不能"更杀菌"。
消毒需要的是**足够的有效浓度 + 足够的接触时间**，不是越浓越好。

## 机制

1. 有效氯靠氧化破坏微生物的蛋白质与核酸
2. 浓度过高时，氯会优先与污物、有机物反应，被"白白消耗"
3. 高浓度对皮肤、呼吸道黏膜刺激更强，腐蚀金属与织物
4. 稀释到推荐浓度，配合足够接触时间（常需几分钟到半小时）
5. 有机物（血迹、油污）会大幅削弱消毒效果，要先清洁再消毒

## 量级

```text
常见 84 消毒液原液有效氯：约 4%–6%
物体表面消毒常用浓度：约 250–500 mg/L 有效氯
按 5% 原液算，稀释约 100–200 倍
```

## 边界

- 不同用途浓度不同：地面、织物、污染物处理各有推荐值
- 稀释后不稳定，要现配现用
- 不是所有表面都耐氯：金属会锈、有色织物会褪色
- 含氯消毒剂不能与酸性清洁剂混用（会放氯气）

## 用得上

- 看标签上的"有效氯含量"和推荐稀释比例
- 先清洁、再消毒、后冲洗
- 配好后开窗通风，戴手套

## 误解

- **"越浓越干净"**——高浓度反而浪费、伤物、刺激
- **"喷一下就行"**——需要接触时间

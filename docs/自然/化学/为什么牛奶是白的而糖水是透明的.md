# 为什么牛奶是白的而糖水是透明的

> **学段** 大学–研究生 ｜ **类型** 对比 ｜ **链** 表面活性剂

## 结论

因为牛奶是**胶体**：脂肪球和酪蛋白颗粒的尺寸（约 0.1–1 μm）与可见光波长相当，
会强烈散射光，看起来就是乳白色；糖水是真溶液，分子太小，几乎不散射。

## 机制

1. 真溶液：溶质以分子/离子分散（< 1 nm），光几乎直接穿过
2. 胶体：颗粒 1 nm–1 μm，与可见光波长（400–700 nm）相当 → 散射强
3. 散射强度对粒径与波长敏感，短波散射更强（所以略偏蓝白）
4. 牛奶中的脂肪球、酪蛋白胶束就是散射源
5. 静置后脂肪上浮，但均质化把脂肪球打小，延缓分层

## 量级

```text
可见光波长：400–700 nm
牛奶脂肪球：约 0.1–10 μm（均质后约 0.5 μm 以下）
酪蛋白胶束：约 50–300 nm
糖分子：约 1 nm
```

## 边界

- 胶体不是"溶解"，放置久了可能聚沉或分层
- 丁达尔效应可用来区分胶体与真溶液
- 脱脂奶也会白，因为酪蛋白仍在
- 胶体的稳定性靠电荷排斥与空间位阻（DLVO 理论）

## 争议与未解

- 食品胶体的"口感"与微观结构的关系，仍以经验为主
- 均质化对消化吸收的影响，研究结论不完全一致

## 到此为止

这一层是**尺寸决定光学性质**：同样是"混在水里"，
分子级透明、胶体级乳白、粗分散级浑浊，取决于颗粒尺度。

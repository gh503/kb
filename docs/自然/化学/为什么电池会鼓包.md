# 为什么电池会鼓包

> **学段** 初中–高中 ｜ **类型** 机制（安全） ｜ **链** 电池

## 结论

鼓包是**电池内部产生了气体**，把外壳顶起来了。气体来自电解液分解等副反应，
常见诱因是过充、过放、高温和长期满电存放。**鼓包不等于马上会炸，但必须停用。**

## 机制

1. 正常充放电时，锂离子在正负极之间来回嵌入脱出
2. 过充时正极被"榨"得太狠、电解液在高电位下氧化分解，产生 CO₂、CO、烃类等气体
3. 过放（用到很低电压还继续放电）会让铜集流体溶解，再充电时析出枝晶
4. 气体越积越多，内部压力升高，软包电池就鼓起来；圆柱电池则可能顶开安全阀
5. 如果温度和压力继续上升，隔膜收缩、内短路，进入**热失控**——这时会冒烟、起火

## 边界

- 鼓包**早期**通常还能测出电压，看起来"还能用"，但结构已经受损，不能再用
- 低温快充更容易析锂（长枝晶），这是另一个独立的风险路径
- 铅酸电池鼓包多为过充析氢；原理不同，现象一样

## 用得上（怎么办）

1. 停止充电、停止使用，别再按压或戳破
2. 移到远离可燃物、通风的地方，别放在卧室
3. 送回收点，不要扔进生活垃圾
4. 充电时摸外壳发烫、闻到甜味/刺鼻味，立即断电

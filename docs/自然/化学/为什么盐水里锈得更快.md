# 为什么盐水里锈得更快

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 铁与腐蚀

## 结论

因为铁生锈本质上是**电化学过程**：铁、水和氧构成了无数个微小的"电池"。
盐水是电解质，让离子跑得动，这些微电池的内阻变小、电流变大，腐蚀就快得多。

## 机制

1. 铁的表面上，不同区域电位不同，形成微阳极和微阴极
2. **阳极**：铁失去电子，溶解成 Fe²⁺
3. **阴极**：氧气在水里得到电子，生成 OH⁻
4. 电子在铁内部走，离子在水膜里走——一个闭合回路就成立了
5. 盐水提高导电性，回路更通畅 → 腐蚀更快；酸性更强时，阴极反应换成析氢，更快

## 边界

- **纯水**里也会腐蚀，只是慢；**海水**（约 3.5% 盐）显著加速
- 盐雾环境（海边、沿海公路）比内陆快几倍
- 温度升高加速反应，所以热盐水更凶
- 有些环境反而减缓：强碱中钢铁会钝化，所以混凝土里的钢筋不容易锈（除非氯离子进去）

## 量级

```text
碳钢在干燥室内：每年约 0.01 mm
碳钢在海洋大气：每年约 0.1 mm 量级
差 10 倍，主要来自湿度与盐分
```

## 用得上

- 冬天撒融雪盐的路面，车底盘锈得最快——用完冲洗底盘是有效的
- 船体用**牺牲阳极**（锌块）保护，定期更换的是锌，不是钢
- 海边的不锈钢也要选高牌号，氯离子会破坏钝化膜

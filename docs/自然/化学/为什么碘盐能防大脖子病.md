# 为什么碘盐能防大脖子病

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 人体需要的元素

## 结论

因为碘是**甲状腺激素**的原料。缺碘时甲状腺造不出足够的激素，
垂体就不断刺激甲状腺增生，脖子前面肿起来——这就是"大脖子病"（地方性甲状腺肿）。

## 机制

1. 甲状腺用碘和酪氨酸合成 T3、T4
2. 缺碘 → 激素不足 → 垂体分泌更多 TSH
3. TSH 刺激甲状腺细胞增生、体积增大，试图"多抓一点碘"
4. 长期缺碘还会影响胎儿脑发育（克汀病）
5. 食盐加碘是最便宜的补碘方式，因为盐是每日必需品

## 量级

```text
中国食盐加碘量：约 20–30 mg/kg（以碘计，各地略有差异）
成人每日碘推荐量：约 120 μg
孕妇需要更多（约 230 μg）
```

## 边界

- 补碘不是越多越好：长期过量也可能引起甲状腺功能异常
- 沿海地区、常吃海产品的人，碘摄入可能已足够
- 甲状腺疾病患者（如甲亢、桥本）要按医嘱调整，不是一律忌碘或补碘
- 碘盐要避光、密封、出锅前放，碘容易挥发损失

## 用得上

- 买盐看"加碘"标识，存放在阴凉干燥处
- 炒菜快出锅时放盐，减少碘损失
- 孕期、哺乳期要保证碘摄入

## 误解

- **"大脖子病是喝水少"**——主因是缺碘
- **"碘盐吃多了会得甲状腺癌"**——证据不足，常规摄入量下风险很低

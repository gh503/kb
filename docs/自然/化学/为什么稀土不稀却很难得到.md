# 为什么稀土不稀却很难得到

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 金属与冶炼

## 结论

因为"稀土"指的不是储量稀少，而是**化学性质太相似、分离太难**。
它们在地壳里并不罕见（铈比铜还多），但 17 种元素性质接近，要把它们一个个分开，
需要上百级萃取。

## 机制

1. 稀土包括镧系 15 种 + 钪、钇，共 17 种
2. 它们化学性质高度相似，常共生在同一矿物里
3. 分离靠**溶剂萃取**：利用极微小的分配系数差异，反复多级萃取
4. 单一元素提纯可能需要几百个萃取级
5. 过程产生大量废液，环保成本高

## 量级

```text
地壳丰度：铈约 60 ppm（比铜约 60 ppm 相当），钕约 33 ppm
单一稀土分离：常需数百级萃取
```

## 边界

- "稀土"不等于"稀有金属"，也不等于"战略资源一定短缺"
- 真正稀缺的是**重稀土**（如镝、铽）和**高纯分离能力**
- 中国在冶炼分离环节占主导，矿源分布更分散
- 回收（磁体、荧光粉）是重要补充，但规模有限

## 争议与未解

- 供应链集中的风险，与"资源枯竭"是两回事
- 替代材料（少用重稀土的磁体）进展有限
- 分离过程的环境成本如何内部化，缺乏统一标准

## 到此为止

这一层是**工程 + 供应链**：化学原理清楚（性质相似→多级分离），
但"谁能稳定供应、成本多少"是产业问题，不是单一科学结论。

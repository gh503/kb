# 为什么糖是甜的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 糖与甜味剂

## 结论

因为糖分子能**嵌进舌头上的甜味受体**，像钥匙插进锁孔一样把它激活，
受体把信号传给大脑，你就尝到了甜。

## 机制

1. 舌头味蕾上有甜味受体（T1R2 与 T1R3 组成的二聚体）
2. 糖分子上的羟基与受体形成氢键，形状互补
3. 受体被激活 → 细胞内信号级联 → 神经冲动
4. 大脑把信号解释为"甜"
5. 不同糖的甜度不同，因为与受体的结合能力不同

## 相对甜度

```text
蔗糖 = 1（基准）
果糖 ≈ 1.2–1.8
葡萄糖 ≈ 0.7
麦芽糖 ≈ 0.3–0.5
乳糖 ≈ 0.2
```

## 边界

- 甜味不只来自糖：氨基酸、甜味蛋白、糖醇、人工甜味剂都能激活受体
- 温度、pH、其他味道会改变甜感
- "甜"是主观感受，个体差异存在
- 糖的甜与"热量"没有必然对应

## 用得上

- 想减糖：用少量果糖/甜菊糖替代部分蔗糖
- 别被"不甜就没糖"骗：淀粉不甜，但会分解成葡萄糖
- 儿童早期口味会影响长期偏好

## 误解

- **"甜的东西都含糖"**——代糖也甜
- **"不甜的东西不含糖"**——淀粉、多糖不甜

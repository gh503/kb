# 为什么胃药能中和胃酸

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 酸碱

## 结论

因为胃药是**碱**，能和盐酸发生中和反应，把 pH 拉回来。
但它们不是"把酸杀光"，而是把 pH 从 1.5 附近往 3–4 抬——
胃里本来就需要酸来消化和杀菌。

## 机制

```text
CaCO₃ + 2 HCl → CaCl₂ + CO₂↑ + H₂O
Mg(OH)₂ + 2 HCl → MgCl₂ + 2 H₂O
```

1. 胃壁细胞分泌盐酸，胃内 pH 约 1.5–3.5
2. 抗酸剂直接中和已分泌的酸，起效快
3. 另一类药（质子泵抑制剂）抑制分泌，起效慢但持久
4. 中和产生的 CO₂ 会打嗝，镁盐可能腹泻、铝盐可能便秘

## 边界

- 胃酸不是"敌人"：它帮助消化蛋白、吸收铁和钙、杀灭细菌
- 长期过度抑酸会增加肠道感染风险、影响营养吸收
- 抗酸剂只能缓解症状，不能治溃疡或反流的病因
- 与某些药物同服会影响吸收（如某些抗生素、铁剂）

## 量级

```text
胃液 pH ≈ 1.5–3.5，对应 [H⁺] ≈ 3×10⁻² 至 3×10⁻⁴ mol/L
一片常见抗酸剂可中和约 10–20 mmol 的酸
```

## 用得上

- 抗酸剂嚼碎、饭后和睡前用，效果更好
- 反复胃痛、反酸超过两周，要查原因而不是一直吃药
- 幽门螺杆菌相关溃疡需要抗菌治疗，光吃胃药不够

## 误解

- **"胃药能养胃"**——它只是中和或抑制酸，不修复黏膜
- **"胃酸越少越好"**——胃酸太少会影响消化和防御

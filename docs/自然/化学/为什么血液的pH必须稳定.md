# 为什么血液的 pH 必须稳定

> **学段** 大学–研究生 ｜ **类型** 机制 ｜ **链** 酸碱

## 结论

因为血液 pH 被**缓冲体系**死死锁在 7.35–7.45。偏离 0.1 就可能出问题，偏离 0.4 可能致命。
主角是**碳酸氢盐缓冲对**（H₂CO₃ / HCO₃⁻），配合呼吸和肾脏两套调节。

## 机制

```text
CO₂ + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻
```

1. 代谢不断产生 CO₂ 和酸，缓冲对把它们"吸收"掉
2. **呼吸**调 CO₂：通气加快 → CO₂ 排出 → 平衡左移 → pH 上升
3. **肾脏**调 HCO₃⁻：重吸收或排出碳酸氢盐，慢但持久
4. 蛋白质、磷酸盐缓冲对也在参与
5. Henderson–Hasselbalch：`pH = 6.1 + log([HCO₃⁻]/[CO₂溶解])`

## 边界

- **呼吸性酸中毒**：通气不足 → CO₂ 潴留
- **代谢性酸中毒**：糖尿病酮症、乳酸堆积、肾衰
- **呼吸性碱中毒**：过度通气（焦虑、高热）
- **代谢性碱中毒**：呕吐丢酸、利尿剂
- 代偿需要时间：呼吸代偿几分钟，肾代偿要几天

## 量级

```text
正常 pH：7.35–7.45
[H⁺] 约 36–45 nmol/L
pH 7.0 已属危重，7.8 以上常致命
```

## 用得上

- 血气分析同时看 pH、PaCO₂、HCO₃⁻，才能判断是呼吸性还是代谢性
- 糖尿病患者的"烂苹果味"呼吸是酮症酸中毒的线索

## 到此为止

再往下问"为什么蛋白质对 pH 这么敏感"，是**酶的最适 pH 与构象**；
问"为什么 H⁺ 能改变构象"，是氨基酸侧链的质子化——到这一层是生物化学细节。

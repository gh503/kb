# 为什么补钙要配维生素 D

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 人体需要的元素

## 结论

因为钙要靠**维生素 D** 才能在肠道被有效吸收。没有维生素 D，
吃进去的钙大部分随粪便排掉——补了个"心理安慰"。

## 机制

1. 皮肤经紫外线照射合成维生素 D₃（主要来源）
2. 肝脏、肾脏把它活化成 1,25-(OH)₂D₃
3. 活性维生素 D 促进肠道合成钙结合蛋白，主动吸收钙
4. 它还参与骨钙沉积与释放的调节
5. 缺乏时：儿童佝偻病、成人骨软化、骨质疏松风险升高

## 量级

```text
成人每日钙推荐：约 800 mg
成人每日维生素 D 推荐：约 400–800 IU（随年龄、日照变化）
日照不足者、老年人、深肤色人群更容易缺 D
```

## 边界

- 维生素 D 是脂溶性的，过量会中毒（高钙血症），不是越多越好
- 隔着玻璃晒太阳，紫外线被挡，合成效率大降
- 防晒霜会减少合成，但短时间暴露通常够用
- 钙的来源：奶制品、豆制品、绿叶菜；吸收率受草酸、植酸影响

## 用得上

- 补钙同时保证维生素 D，或适当晒太阳（避开正午暴晒）
- 老年人、室内工作者可检测 25(OH)D 水平
- 菠菜等含草酸高的菜，焯水后食用可减少对钙吸收的影响

## 误解

- **"多喝骨头汤能补钙"**——汤里钙很少，脂肪倒不少
- **"补钙越多骨头越硬"**——过量补钙不增加骨密度，还可能增加结石风险

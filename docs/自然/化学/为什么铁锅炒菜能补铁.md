# 为什么铁锅炒菜能补铁

> **学段** 小学–初中 ｜ **类型** 边界 ｜ **链** 人体需要的元素

## 结论

铁锅确实会**溶出一点铁**进到食物里，但那是**无机铁**，人体吸收率只有百分之几。
它能"锦上添花"，不能当补铁主力——真想补铁，靠红肉、动物血、肝脏里的**血红素铁**更有效。

## 机制

1. 炒菜时，食物中的酸（醋、番茄）和盐会腐蚀铁锅表面
2. 少量铁以 Fe²⁺/Fe³⁺ 形式进入食物
3. 无机铁在肠道需要维生素 C 等帮助还原，吸收率约 1%–5%
4. 血红素铁（来自动物性食物）吸收率约 15%–35%
5. 所以"铁锅补铁"的量级，远小于一份瘦肉的贡献

## 量级

```text
用铁锅炒一份酸性菜，溶出的铁大致在几毫克量级
成人每日铁推荐摄入：男性约 12 mg，女性约 20 mg
吸收率 1%–5% → 实际吸收可能不到 0.1–0.5 mg
```

## 边界

- 新锅、酸性食物、长时间炖煮会溶出更多铁
- 铁锅溶出的铁可能带来金属味，也可能改变菜色
- 缺铁性贫血要靠诊断和规范补铁，不能靠换锅
- 铁过量也有害（血色病、铁负荷过高），不是越多越好

## 用得上

- 补铁：红肉、动物血、肝脏 + 维生素 C（促吸收）
- 茶、咖啡里的多酚会抑制铁吸收，别和补铁餐同服
- 铁锅用完要擦干，防锈

## 误解

- **"铁锅炒菜能治贫血"**——量级不够，只能算微量补充
- **"铁锅溶出的铁和肉里的铁一样"**——形式不同，吸收率差一个数量级

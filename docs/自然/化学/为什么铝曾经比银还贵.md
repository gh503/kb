# 为什么铝曾经比银还贵

> **学段** 高中–大学 ｜ **类型** 机制（技术史） ｜ **链** 金属与冶炼

## 结论

因为铝和氧结合得太牢，**用碳还原不了**，只能用更贵的方法（钠还原）。
直到 1886 年霍尔和埃鲁发明**电解法**，铝的价格才一落千丈。

## 机制

1. 铝的氧化物非常稳定，碳还原需要极高温度，工业上不划算
2. 早期用钠还原氯化铝，钠本身也贵 → 铝比银贵
3. 1886 年，霍尔（美）和埃鲁（法）各自发明冰晶石熔盐电解法
4. 电解 Al₂O₃ 需要大量电，但电价可控、规模可放大
5. 铝从此成为廉价大宗金属

## 量级

```text
电解铝耗电：约 13,000–15,000 kWh/吨（现代）
19 世纪铝价曾与银相当甚至更高
```

## 边界

- 电解法依赖**廉价电力**，所以铝厂常建在水电站附近
- 铝的回收只需原铝生产约 5% 的能量
- 铝土矿 → 氧化铝 → 电解铝，产业链长
- 中国是全球最大铝生产国

## 用得上

- 理解"电价决定铝价"
- 铝罐回收价值高，因为省电

## 误解

- **"铝很稀有"**——地壳中铝含量约 8%，比铁还多
- **"铝便宜是因为储量大"**——是因为电解法 + 规模

# 为什么铝比铁活泼却更耐腐蚀

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 金属与冶炼

## 结论

因为铝表面会生成一层**致密、牢固的氧化铝薄膜**，把里面的铝封住；
铁锈却是**疏松多孔**的，挡不住水和氧，反而让锈往里面钻。

## 机制

1. 铝很活泼，一接触空气就迅速氧化
2. 生成的 Al₂O₃ 膜只有几纳米厚，但致密、与基体结合牢
3. 膜一旦被刮破，会立刻重新生成（自修复）
4. 铁锈（水合氧化铁）体积膨胀、结构疏松，容易剥落
5. 于是铁"越锈越深"，铝"锈一层就停"

## 量级

```text
自然氧化铝膜厚度：约 2–10 nm
阳极氧化可做到几十微米，用于耐磨、着色
铁锈层：疏松，厚度可达毫米级且不断增厚
```

## 边界

- 铝不耐强酸强碱：酸碱会溶解氧化膜
- 铝不能盛放咸的、酸性食物过久（会溶出铝）
- 不锈钢靠的是铬形成的钝化膜，机制类似
- 铁在干燥环境或完全浸没缺氧水中，锈得慢

## 用得上

- 铝锅不要长时间煮酸菜、番茄
- 铁锅用完擦干、涂层油，防锈
- 铝合金门窗、航空材料，靠的就是这层膜

## 误解

- **"铝不活泼"**——铝很活泼，只是被膜保护了
- **"不锈钢不生锈是因为不含铁"**——含铁，靠铬的钝化膜

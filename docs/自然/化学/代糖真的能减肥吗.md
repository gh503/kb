# 代糖真的能减肥吗

> **学段** 高中–大学 ｜ **类型** 边界（证据强度） ｜ **链** 糖与甜味剂

## 结论

**用它替代含糖饮料，能小幅减少热量摄入、可能有小幅减重效果；
但"靠代糖减肥"证据不强。** 2023 年 WHO 的建议是不建议用非糖甜味剂来控制体重，
依据是**低确定性证据**。

## 证据分层

| 结论 | 强度 |
| --- | --- |
| 代糖替代含糖饮料 → 短期热量摄入减少 | 中等（RCT） |
| 长期减重效果 | 弱到中等，差异很小 |
| 代糖导致代谢紊乱 | 证据不足、结论不一致 |
| 代糖影响肠道菌群 → 健康后果 | 机制推测，人体证据有限 |
| 代糖增加食欲/甜食偏好 | 研究结果矛盾 |

## 机制

1. 代糖提供甜味但少热量，理论上可减少总能量
2. 但"甜味 → 胰岛素预备反应"的假说，证据不一致
3. 心理补偿：有人会"用代糖省下的热量"吃更多
4. 肠道菌群的影响在动物实验中有信号，人体结果不稳定

## 边界

- 观察性研究混杂多（喝代糖的人可能本来就更关注体重）
- RCT 时间短、样本有限
- "减重"与"健康结局"是两回事
- 个体差异大，不能一概而论

## 争议与未解

- 阿斯巴甜的致癌性争议：JECFA/EFSA 认为在允许量内安全，
  2023 年 IARC 将其列为"可能致癌（2B）"，但**未改变每日允许摄入量**
- "2B"意味着证据有限，不等于"确认致癌"
- 代糖对菌群与代谢的长期影响，仍无定论

## 到此为止

这一层是**证据低确定性**：替代含糖饮料是合理的减糖手段，
但"代糖=减肥神器"或"代糖=毒药"都超出证据。

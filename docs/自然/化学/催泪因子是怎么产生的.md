# 催泪因子是怎么产生的

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 洋葱

## 结论

三步：**细胞破裂 → 蒜氨酸酶水解含硫底物 → 次磺酸重排成催泪因子**。
中间产物极不稳定，半衰期以秒计，所以才必须"现切现放"。

## 机制

```text
S-丙基-L-半胱氨酸亚砜  --(蒜氨酸酶)-->  次磺酸  -->  丙硫醛-S-氧化物（催泪因子）
```

1. 底物是水溶性的含硫氨基酸衍生物，储在细胞质里
2. 蒜氨酸酶（alliinase）储在液泡中，需要 Ca²⁺ 和辅因子 PLP
3. 细胞破损后两者相遇，酶切掉氨基，生成**次磺酸**——强亲电、极不稳定
4. 次磺酸经重排（或与另一分子缩合）生成挥发性的**丙硫醛-S-氧化物**，分子量仅 90
5. 它挥发、扩散、溶于泪膜，激活角膜的 TRPA1 通道

## 边界

- 酶是限速环节：**温度、pH、金属离子**都会改变产率
- 大蒜走的是同一套酶系统，但产物是蒜素（allicin），不是催泪因子
- 不同品种的含硫底物含量差异很大，所以"有的洋葱特别辣"
- 冷冻后再解冻，细胞结构已被破坏，反而可能更冲（解冻时酶和底物一起释放）

## 用得上

想少流泪，按"断掉反应链"来选：

| 做法 | 断的是哪一环 |
| --- | --- |
| 冷藏后切 | 降低酶活性 |
| 泡水切 | 溶解挥发的产物 |
| 快刀 | 减少细胞破裂 |
| 先微波 30 秒 | 使酶失活 |
| 开抽油烟机 | 把挥发物抽走 |

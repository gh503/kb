# 切洋葱为什么会流泪

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 洋葱

## 结论

因为刀把洋葱细胞切开了，本来分开放的两样东西混到一起，生成一种**会挥发的催泪物质**。
它飘进眼睛，刺激角膜上的神经，泪腺就开工了。

## 机制

1. 洋葱细胞里存着含硫的化合物，另一处存着把它们的酶（蒜氨酸酶）
2. 细胞完整时两者不碰面，一切开就混了
3. 酶把含硫化合物切开，生成不稳定的中间产物，再重排成**催泪因子**（丙硫醛-S-氧化物）
4. 这东西易挥发，飘到眼睛表面，激活角膜神经上的 TRPA1 受体——就是"芥末受体"
5. 神经发出信号，泪腺分泌泪水，想把它冲走

## 边界

- **加热**过的洋葱不催泪：酶受热失活，反应根本不会发生
- **冷藏**后切会好一些：低温让酶变慢、挥发也变慢
- 泡在水里切，催泪因子溶进水里，飘不到眼睛
- 刀越锋利，压碎的细胞越少，放出的物质也越少

## 误解

- **"催泪物质是硫酸"**——这个说法流传很广，但不准确。主要机制是催泪因子
  直接激活神经受体，不是"酸把眼睛烧了"。水解产物里确实有含硫的酸性物质，但不是主角。

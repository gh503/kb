# 可降解塑料真的可降解吗

> **学段** 高中–大学 ｜ **类型** 边界 ｜ **链** 塑料

## 结论

**看条件。** PLA、PBAT 这类"可降解塑料"需要**工业堆肥**的高温（约 58–60℃）和特定微生物，
在土壤、海水、家里堆肥桶里往往几个月到几年都降解不了多少。**"可降解"三个字不等于"扔哪都烂"。**

## 机制

1. 可降解塑料的分子设计让主链更容易被水解或酶解
2. PLA 水解需要温度和水，工业堆肥条件下降解快
3. 自然环境温度低、微生物少，降解速率大幅下降
4. "可堆肥"（compostable）有明确标准（如 EN 13432），要求在特定条件下
   90% 以上转化为 CO₂、水和生物质
5. "可降解"（biodegradable）没有统一定义，容易被滥用

## 边界

- **可堆肥 ≠ 可在自然环境降解**：认证只在工业堆肥条件下成立
- 生物基 ≠ 可降解：生物基 PE 与普通 PE 化学上相同
- 可降解塑料混进普通塑料回收流，会污染再生料
- 海水中的降解速率通常最慢

## 用得上

- 看标识：认"可堆肥"认证（如 EN 13432、AS 4736），不认模糊的"环保"
- 可降解餐具不要扔进普通垃圾桶指望它消失
- 真正的减量是自带杯、袋，不是换一种一次性

## 误解

- **"可降解塑料扔土里就化掉"**——多数需要工业条件
- **"可降解 = 可回收"**——两者是不同路径，混投反而有害

# 塑料到底是什么

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 塑料

## 结论

塑料是**高分子**：把很多小分子（单体）连成一条很长的链。
链长、链之间怎么缠、怎么交联，决定了它是软的、硬的、透明的还是耐热的。

## 机制

1. 单体（如乙烯、丙烯、苯乙烯）在催化剂作用下连成聚合物
2. 一条链可以有几千到几十万个重复单元
3. 链与链之间靠范德华力缠在一起，加热可以流动 → 热塑性（可反复熔融）
4. 若链之间发生化学交联，就变成热固性（一次成型，不能回收重熔）
5. 添加剂（增塑剂、稳定剂、颜料）改变性能

## 常见几种

| 塑料 | 单体 | 常见用途 | 特点 |
| --- | --- | --- | --- |
| PE | 乙烯 | 塑料袋、瓶 | 软、耐化学 |
| PP | 丙烯 | 餐盒、吸管 | 耐热 |
| PET | 乙二醇 + 对苯二甲酸 | 饮料瓶 | 透明、可回收 |
| PVC | 氯乙烯 | 管材、地板 | 需增塑剂 |
| PS | 苯乙烯 | 泡沫箱 | 轻、脆 |

## 边界

- 塑料不是一种物质，是一大类材料
- 热塑性与热固性回收方式完全不同
- 回收标识（1–7）只表示材质类别，不代表"可回收"
- 生物基塑料不等于可降解（如生物基 PE）

## 误解

- **"塑料都是石油做的"**——多数是，但也有生物基（玉米、甘蔗）
- **"塑料有毒"**——取决于单体和添加剂，食品级 PET 与含增塑剂的 PVC 差别很大

# 微塑料到底有没有害

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 塑料

## 结论

**我们能测到微塑料，但"对人体健康的因果影响"证据不足。**
已在血液、胎盘、肺组织里检出，但检出 ≠ 致病；剂量、粒径、长期效应都还不清楚。

## 已知

- 微塑料（< 5 mm）和纳米塑料广泛存在于水、空气、食物、人体组织中
- 实验室里，高浓度微塑料可引发细胞炎症、氧化应激
- 动物实验显示高剂量暴露有生殖与代谢影响
- WHO 2019 年对饮用水的评估：风险低，但数据有限，需要更多研究

## 边界

- 检测方法不统一：不同研究测的粒径范围、计数方式差别很大
- 暴露剂量与实验剂量差几个数量级，不能直接外推
- "检出"依赖仪器灵敏度，灵敏度提高，检出率就上升
- 纳米塑料最难测，也最可能穿过生物屏障

## 争议与未解

- **因果方向**：是微塑料导致炎症，还是炎症组织更容易富集微塑料？
- **剂量—反应关系**：人体实际暴露量到底多少，缺乏标准化数据
- **长期效应**：几十年尺度的影响无法用短期实验代替
- **归因困难**：微塑料与其他污染物（添加剂、重金属）共存，难以分离

## 到此为止

这一层是**未解 + 证据强度不足**：暴露确凿，危害未定。
写这类条目要区分"检测到"、"相关"、"因果"三级，不能一步跳到"有毒"。

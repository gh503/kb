# 怎么切洋葱才不流泪

> **学段** 初中–高中 ｜ **类型** 边界（方法） ｜ **链** 洋葱

## 结论

关键是**减少催泪气体飘到眼睛**：降温、快刀、少破坏细胞、加强通风。
这些办法的作用都是"少放气"或"快排走"，而不是"让眼睛不怕"。

## 原理回顾

1. 切洋葱破坏细胞，酶把含硫化合物转成**丙硫醛-S-氧化物**（催泪因子）
2. 气体扩散到眼睛，遇水生成稀硫酸，刺激神经
3. 眼泪反射性分泌，想把它冲掉
4. 所以：任何减少"气体生成量"或"到达眼睛量"的办法都有效

## 有效的方法

| 方法 | 为什么有用 |
| --- | --- |
| 冷藏 30 分钟再切 | 低温降低酶活性与挥发速度 |
| 快刀、少压 | 破坏的细胞少，释放少 |
| 开抽油烟机/通风 | 把气体排走 |
| 切时靠近水 | 气体溶于水，减少扩散 |
| 先切根部最后切 | 根部含硫化合物最集中 |

## 边界

- 戴隐形眼镜更难受：镜片会吸附气体、延长接触
- 湿口罩效果有限，但比不戴好
- 冷冻太久会改变口感
- 洋葱品种不同，辣度差别很大

## 用得上

- 冷藏 + 快刀 + 开抽油烟机，是最省事的组合
- 切完不要揉眼睛

## 误解

- **"泡水切就不辣"**——泡水会损失风味，且效果有限
- **"点蜡烛能防流泪"**——缺乏可靠依据

# 氯气为什么有毒

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 含氯消毒剂

## 结论

氯气本身不是最终的伤害源。它溶在呼吸道表面的水膜里，生成**盐酸和次氯酸**，
靠强氧化性破坏黏膜蛋白和细胞膜，并引发炎症与渗出——严重时肺里灌满液体（肺水肿）。

## 机制

1. 氯气遇水迅速水解

```text
Cl₂ + H₂O ⇌ HCl + HClO
```

2. 盐酸直接造成酸性灼伤；次氯酸（HClO）是强氧化剂，能氧化蛋白质的巯基、
   破坏细胞膜脂质，使上皮细胞死亡、脱落
3. 受损的上皮引发炎症：血管通透性升高，血浆渗进肺泡——这就是肺水肿
4. 因为氯气比空气重（分子量 71，约为空气的 2.5 倍），它会**沉在低处**，
   地漏、浴缸、蹲便器附近浓度最高

## 边界

- 伤害程度由**浓度 × 时间**决定，不是"闻到了就有事"。低浓度短时间通常只是刺激
- 迟发：轻症当时缓解，几小时后可能出现迟发性肺水肿，所以暴露后要观察
- 哮喘、慢阻肺人群阈值更低
- 氯气有强烈气味不等于浓度高——嗅觉会疲劳，闻不到不代表安全

## 到此为止

再往下问"次氯酸为什么能氧化蛋白质"，答案是**氧化还原电位**：
HClO/Cl⁻ 的标准电极电位约 +1.5 V，足以氧化多数生物分子。

再问"电位差为什么能驱动反应"，就落到**热力学**（吉布斯自由能）——本库在这里标为
**公理层**：热力学第二定律不接受更深的"为什么"。

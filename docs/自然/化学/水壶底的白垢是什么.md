# 水壶底的白垢是什么

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 硬水与水垢

## 结论

主要是**碳酸钙**和**氢氧化镁**。水里溶解着钙、镁的碳酸氢盐，一加热就分解，
变成不溶于水的白色沉淀，结在壶底和加热管上。

## 机制

```text
Ca(HCO₃)₂  --加热-->  CaCO₃↓ + CO₂↑ + H₂O
```

1. 地下水经过石灰岩时溶解了钙、镁的碳酸氢盐（这叫"暂时硬度"）
2. 加热后碳酸氢盐不稳定，分解成碳酸盐沉淀
3. 沉淀附着在受热面上，形成白色硬垢
4. 水中硫酸盐、氯化物多时，还会形成硫酸钙等更难溶的垢

## 边界

- **软水**（雨水、纯净水）几乎不结垢
- 水垢主要在**加热**的设备里：壶、热水器、锅炉
- 管道里也会结垢，但多是缓慢的薄层
- 水垢不是"脏"，是溶解的矿物析出

## 量级

```text
硬水（约 300 mg/L 碳酸钙当量）烧 1 吨水，理论上能析出约 300 g 垢
```

所以热水器、锅炉要定期除垢，不只是"不卫生"。

## 误解

- **"白垢是水脏"**——多数是钙镁析出，水本身可能很干净
- **"水垢有毒"**——碳酸钙本身无害，它是补钙片的原料之一

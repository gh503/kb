# 火到底是什么

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 燃烧

## 结论

火不是一种物质，是**剧烈的氧化反应**：可燃物和氧气反应，放出热和光。
你看到的火焰，是**气体在燃烧**——固体和液体先变成蒸气，才能在火焰里烧。

## 机制

1. 加热让可燃物变成气体（或挥发成蒸气）
2. 气体与氧气混合，达到一定温度后发生链式反应
3. 反应放出大量热，维持自身继续燃烧（不需要继续点火）
4. 高温气体发出可见光，形成火焰
5. 氧气用完或温度降下来，反应停止

## 边界

- **没有气体就没有火焰**：木炭烧的时候几乎没焰，因为它不产生可燃气体
- 有些物质不需要空气中的氧：镁能在二氧化碳里烧，钠能在水里烧
- 火焰有温度梯度：外焰温度最高，内焰最低
- 燃烧不一定是"明火"：铁生锈、呼吸作用都是缓慢氧化

## 误解

- **"火是元素"**——燃素说早已被推翻，火是过程不是物质
- **"火焰是等离子体"**——普通火焰主要是高温气体，等离子体成分很少

## 用得上

- 想让火烧旺：增大接触面积（柴劈细）、供氧（扇风）、预热
- 想让火灭：断氧、降温、移走燃料，三招之一即可

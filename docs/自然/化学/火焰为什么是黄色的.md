# 火焰为什么是黄色的

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 燃烧

## 结论

蜡烛和木材的黄焰，主要来自**炽热的碳颗粒**：不完全燃烧产生的小碳粒被加热到一千多度，
像烧红的铁一样发出连续光谱——所以是黄白色。
而蓝色火焰来自**完全燃烧时的化学发光**，温度更高但几乎不产生碳粒。

## 机制

1. **黄焰（扩散焰）**：燃料与空气混合不充分，部分碳没烧完，形成纳米碳粒
2. 碳粒被火焰加热到约 1000–1400℃，发出黑体辐射，峰值在黄橙区
3. **蓝焰（预混焰）**：燃料与空气预先混合充分，燃烧完全，几乎无碳粒
4. 蓝光来自激发态分子（CH、C₂）的化学发光，不是黑体辐射
5. **焰色反应**：钠发黄、钾发紫、铜发绿——这是金属原子的电子跃迁，与碳粒无关

## 边界

- 本生灯调风门：空气多→蓝焰，空气少→黄焰
- 温度与颜色不是简单的"越蓝越热"：蓝焰温度高，但黄焰的辐射更强
- 钠的黄光会掩盖其他焰色，做焰色试验要用铂丝或镍铬丝

## 用得上

- 燃气灶黄焰 = 燃烧不充分，既浪费气又产生更多一氧化碳，要调风门或清理火盖
- 打火机蓝焰、蜡烛黄焰，差别就在混合方式

## 误解

- **"黄色是火焰的本色"**——黄来自碳粒，不是火焰的"天然颜色"
- **"焰色反应是燃烧"**——是原子被激发后发光，不需要燃烧

# 电池为什么能存电

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 电池

## 结论

电池不"发"电，它把**化学能**存在两种物质的"想要互相反应"里。
一接上电路，反应分两半：一半在负极放电子，一半在正极收电子，电子只好走外电路——
这股被逼着走的电子流就是电流。

## 机制

1. 电池有两个电极，一个容易失电子（负极），一个容易得电子（正极）
2. 中间的电解液只让离子通过，**不让电子通过**
3. 于是电子被逼着从外电路走：负极 → 导线 → 正极，路上做了功（点亮灯、转动电机）
4. 离子在电解液里同步移动，保持电荷平衡
5. 反应物耗尽，电池就没电了。**充电是反过来，用外部电源把反应推回去**

## 边界

- 一次电池（干电池、纽扣电池）反应不可逆，充不回去
- 二次电池（锂离子、铅酸、镍氢）可以反复充放，但每次都有损耗
- 电池的电压由**化学体系**决定，不是"电量越多电压越高"：一节锂离子约 3.7 V，无论大小
- 串联升压、并联增容——这是电池包的基本拼法

## 误解

- **"电池存的是电子"**——不是。存的是化学能，电子在导线里跑，数量并没有变多
- **"电池不用也会漏电"**——自放电确实存在，锂离子约每月几个百分点
- **"新电池要充 12 小时激活"**——镍镉时代的老规矩，锂离子出厂已激活

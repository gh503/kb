# 硬水为什么洗不干净

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 硬水与水垢

## 结论

因为钙、镁离子会和肥皂里的脂肪酸根结合，生成**不溶于水的皂垢**。
肥皂被消耗掉了，泡沫起不来，衣服和皮肤上还留下一层滑腻的沉淀。

## 机制

1. 肥皂的主要成分是脂肪酸钠（RCOONa），起作用的是脂肪酸根离子
2. 遇到 Ca²⁺、Mg²⁺，生成脂肪酸钙/镁沉淀——这就是"皂垢"
3. 皂垢不溶于水，会附着在织物、皮肤、浴缸上
4. 于是要更多肥皂才能起泡，形成"越洗越费"的循环

## 边界

- **合成洗涤剂**受影响小：它们用磺酸盐，钙镁盐溶解度高，还会加螯合剂（如 EDTA、柠檬酸钠）
- 洗衣粉里的"软水剂"就是专门对付这个的
- 硬水洗脸会觉得"涩"或"滑"，取决于皂的种类和残留

## 量级

```text
硬度 300 mg/L 的水，每用 100 L 就带来约 30 g 钙镁（以碳酸钙计）
按皂的用量算，可能要多消耗几倍
```

## 用得上

- 硬水区洗衣服：选"抗硬水"配方，或加软水盐
- 热水器、洗衣机定期除垢，能省电、延长寿命
- 肥皂 vs 沐浴露：硬水里沐浴露通常更"好冲"

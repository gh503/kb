# 肥皂为什么能洗掉油

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 表面活性剂

## 结论

因为肥皂分子一头"亲水"、一头"亲油"。亲油的那头扎进油滴，亲水的那头留在水里，
油滴被一圈肥皂分子包住，就能跟着水一起被冲走。

## 机制

1. 肥皂分子有一个长碳链（亲油）和一个极性头（亲水）
2. 亲油端插入油污，亲水端伸向水
3. 油滴被包成"胶束"，表面变成亲水，不再贴回衣物
4. 搓洗、水流把油滴带走
5. 表面张力降低，水更容易渗进纤维缝隙

## 量级

```text
肥皂分子长度：约 2 nm 量级
胶束尺寸：几纳米
临界胶束浓度（CMC）：约 10⁻³–10⁻² mol/L（因种类而异）
```

## 边界

- 硬水里的钙镁离子会消耗肥皂，生成皂垢（见硬水那条）
- 合成洗涤剂用磺酸盐，耐硬水
- 肥皂在酸性水中效果差（脂肪酸析出）
- 油太多、水太少时，胶束不够用

## 用得上

- 洗手要搓出泡沫并持续 20 秒以上
- 水温适中即可，太烫伤手又浪费
- 硬水地区选合成洗涤剂更省

## 误解

- **"肥皂能溶解油"**——是把油"包起来带走"，不是溶解
- **"泡沫越多洗得越干净"**——泡沫与去污力不直接相关

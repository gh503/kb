# 辐射离我们有多远

> **学段** 小学–初中 ｜ **类型** 量级 ｜ **链** 放射性

## 结论

辐射**一直都在**，躲不掉也不需要躲。全球人均本底辐射约 **每年 3 mSv**，
其中氡气贡献最大；拍一次胸片约 0.1 mSv，做一次 CT 约 7 mSv。

## 剂量对比

| 项目 | 大致剂量 |
| --- | --- |
| 全球人均本底（每年） | 约 3 mSv |
| 拍一次胸片 | 约 0.1 mSv |
| 做一次胸部 CT | 约 7 mSv |
| 一次跨洋飞行 | 约 0.05–0.1 mSv |
| 职业照射年限值 | 20 mSv/年（五年平均） |
| 一次急性 1 Sv | 会出现急性辐射病 |

## 机制

1. 本底辐射来自宇宙射线、土壤岩石中的铀钍钾、以及氡气
2. 医疗照射是人造辐射中最大的来源
3. 剂量单位是希沃特（Sv），常用毫希（mSv）
4. 不同射线伤害不同：α 粒子体外易挡，吸入体内危害大
5. 剂量与风险不是"有或没有"，是"多少"

## 边界

- "辐射"包括电磁辐射（手机、Wi-Fi）和电离辐射（X 光、γ 射线），性质完全不同
- 手机、微波炉是非电离辐射，能量不足以打断化学键
- 一次 CT 的收益常大于风险，但要避免不必要的检查
- 儿童对辐射更敏感

## 用得上

- 不必"谈辐色变"，也不要做无指征的 CT
- 装修后通风，降低氡浓度
- 乘机多、职业暴露者要关注累积剂量

## 误解

- **"有辐射就危险"**——剂量决定风险
- **"手机辐射会致癌"**——非电离辐射，证据不足

# 醋为什么能除水垢

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 硬水与水垢

## 结论

因为碳酸钙是碱性的盐，遇到酸会反应，生成可溶的钙盐和二氧化碳：

```text
CaCO₃ + 2 CH₃COOH → Ca(CH₃COO)₂ + CO₂↑ + H₂O
```

醋酸酸性弱、对金属腐蚀性小，所以适合家用；换成盐酸除得快，但会伤不锈钢和铝。

## 机制

1. 醋酸提供 H⁺，把碳酸钙溶解成醋酸钙（可溶）
2. 生成的 CO₂ 就是除垢时看到的气泡
3. 醋酸是弱酸，反应慢但温和，不会像强酸那样快速腐蚀金属
4. 加热能加速反应，所以温水泡更有效

## 边界

- **铝壶、铝锅不要长时间泡酸**：铝是两性金属，会被酸溶解
- 不锈钢耐弱酸，但长时间高浓度也可能点蚀
- 硫酸钙类硬垢对醋酸不敏感，需要更强的螯合剂（如柠檬酸）
- 除完要彻底冲洗，否则残留酸继续腐蚀

## 量级

```text
家用白醋约 5% 醋酸
1 mm 厚的水垢，泡几小时到一天可软化脱落
```

## 用得上

- 电水壶：白醋兑水 1:1，烧开后静置 30 分钟，再冲洗
- 花洒、龙头的水垢用柠檬酸溶液更方便，味道也小
- 咖啡机除垢用专用柠檬酸，不要用醋（残留味道影响口感）

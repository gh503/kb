# 铁为什么会生锈

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 铁与腐蚀

## 结论

铁遇到**氧气和水**就会慢慢变成铁的氧化物——铁锈。
危险的地方在于，铁锈是**疏松多孔**的，不像铝的氧化膜那样能封住表面，所以锈会一直往里长。

## 机制

1. 铁表面的铁原子失去电子，变成亚铁离子
2. 这些离子与水、氧继续反应，生成水合氧化铁（Fe₂O₃·nH₂O，也含 FeOOH）
3. 产物体积比原来的铁大，结构疏松，会**起皮、开裂**
4. 裂缝让水和氧继续进去，反应一路向内，所以锈是"越锈越深"

## 边界

- **干燥**环境几乎不生锈：沙漠里的铁器能放很久
- **完全浸没在无氧水中**也慢：腐蚀需要氧（或别的氧化剂）
- 铝、不锈钢靠**致密的氧化膜**保护内部，铁没有这个本事
- 锈不一定红：水下、缺氧环境里形成的锈偏黑或绿

## 用得上

- 防锈三招对应三个环节：**隔绝水**（油漆、油脂）、**隔绝氧**（镀层）、**改变材料**（不锈钢、镀锌）
- 镀锌比刷漆更耐用：锌先腐蚀，牺牲自己保护铁（牺牲阳极）
- 自行车链条、菜刀、铁锅：用完擦干，比涂任何东西都有效

## 误解

- **"铁锈是铁变脆了"**——锈层本身是脆的，但它还会让体积膨胀，把周围撑裂
- **"不锈钢永远不锈"**——只是不容易锈，见[不锈钢为什么不锈](不锈钢为什么不锈.md)

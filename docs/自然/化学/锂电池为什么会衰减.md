# 锂电池为什么会衰减

> **学段** 大学–研究生 ｜ **类型** 机制（含未解） ｜ **链** 电池

## 结论

衰减不是"电用完了"，是**锂和活性材料被一点点锁死**：SEI 膜不断增厚、
正极结构退化、电解液分解。典型锂离子电池循环 500–1000 次后容量降到 80%。

## 机制

1. **SEI 增厚**：负极表面的钝化膜每次充放电都长一点，消耗锂和电解液，
   这是不可逆的容量损失
2. **正极退化**：反复脱嵌导致颗粒开裂、相变、过渡金属溶出
3. **析锂**：低温或快充时锂来不及嵌入石墨，直接在表面析出，形成枝晶并部分失活
4. **电解液分解与产气**：高温、高电压下持续发生
5. **日历老化**：不用也会衰减，满电、高温存放最伤

## 边界

- 80% 容量是行业"寿命终点"的定义，不是突然坏掉
- **温度**和**荷电状态**是两大加速器：长期满电 + 高温，衰减快数倍
- 浅充浅放（20–80%）能显著延长寿命；但偶尔满充有利于 BMS 校准电量
- 快充的代价取决于温度管理和电芯设计，"快充一定伤电池"过于绝对

## 未解与前沿

- **锂枝晶**的生长与刺穿机制仍未完全可控，这是快充与固态电池的核心障碍
- 固态电解质的界面阻抗、循环中的体积变化，仍是工程难题
- "多快算安全快充"没有普适边界，取决于电芯、温度、荷电状态三者组合

## 到此为止

再往下问"SEI 为什么长"，是界面电化学与热力学（自由能驱动）；
问"锂为什么能嵌入石墨层间"，是层状材料的晶体结构与离子半径——
到这一层已经是材料科学的具体计算，不再是"常识解释"。

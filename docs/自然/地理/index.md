# 地理

> 地方在哪、为什么长这样、人怎么用它。

## 收什么

- 地形与气候的成因：为什么这座山在这、为什么这里多雨
- 区域对比：两地条件差在哪，导致什么不同
- 人文地理：人口、交通、产业怎么被地形约束（与[历史](../../人文/历史/index.md)、[文化](../../人文/文化/index.md)交叉）

## 不收什么

- 旅游攻略——归[娱乐](../../日常/娱乐/index.md)
- 单纯的地名罗列

## 条目

还没有条目。第一条建议写**一个你去过、和想象不一样的地方**：差在哪、为什么。

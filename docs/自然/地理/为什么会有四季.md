# 为什么会有四季

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 四季

## 结论

因为地轴相对公转轨道面倾斜约 23.4°，一年里太阳直射点在南北回归线之间来回移动。
**决定冷热的是阳光照射的角度和一天照多久，不是地球离太阳的远近。**

## 机制

1. 地球绕太阳转，地轴始终指向北极星附近，倾斜方向整年不变
2. 于是半年北半球朝向太阳（夏），半年背向（冬）
3. 朝向时：阳光更接近垂直射向地面，同一束光摊在更小的面积上；白天也更长
4. 背向时反过来：斜射 + 白天短

## 边界

- **赤道附近**：全年太阳高度角变化小，昼夜都约 12 小时，没有明显的四季，只有干湿季
- **极地**：有极昼和极夜，四季被压缩成"有太阳 / 没太阳"
- 南北半球季节相反：你这边过夏天时，南半球在过冬
- **最热不在夏至**：地表和海洋有热惯性，最热通常滞后一个月左右

## 误解

- **"夏天热是因为地球离太阳近"** — 恰恰相反。北半球冬天（1 月初）地球离太阳最近，约 1.47 亿公里；夏天（7 月初）最远，约 1.52 亿公里。距离只差约 3%，而太阳高度角带来的能量差可以到几倍。
- **"四季是南北半球同时到来的"** — 相反。而且赤道全年没有明显的季节可分。

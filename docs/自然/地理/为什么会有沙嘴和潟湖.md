# 为什么会有沙嘴和潟湖

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 海岸与海岛

## 结论

因为**沿岸流**把沙沿着海岸斜着推，遇到海湾口或岬角，流速降低，沙就堆下来，
伸出长长的"沙嘴"；沙嘴把海湾一封，里面就变成**潟湖**。

## 机制

1. 波浪斜着冲向海岸，产生沿岸流（longshore drift）
2. 沙沿"之字形"路线被推动
3. 到海湾口、河口，水流变缓 → 沙沉积
4. 沙嘴不断伸长，可能横封湾口
5. 被封住的水体与外海交换受限 → 潟湖（咸化或淡化）

## 边界

- 潟湖可能因蒸发变咸（如某些潟湖盐度很高），也可能因淡水注入变淡
- 沙嘴会被风暴切开，也可能重新闭合
- 沿岸流方向决定沙嘴往哪边长
- 沙坝、障壁岛是同类机制的不同规模表现

## 用得上

- 潟湖是重要养殖区与湿地，但水体交换差，易污染
- 沙嘴移动会影响航道，需要疏浚

## 误解

- **"沙嘴是人工堆的"**——自然形成，人工工程可能改变它
- **"潟湖是湖"**——是被沙坝半封闭的海湾水体

# 为什么会有沙漠

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 洋流与气候

## 结论

沙漠不是"天气热"造成的，是**缺雨**。四个常见原因：
副热带高压下沉、雨影、深居内陆、沿岸寒流——各自对应不同的沙漠。

## 机制

| 成因 | 机制 | 例子 |
| --- | --- | --- |
| 副热带高压 | 空气下沉增温，不易成云致雨 | 撒哈拉、阿拉伯、澳洲中部 |
| 雨影 | 山脉挡住水汽，背风坡下沉增温 | 巴塔哥尼亚、美国西部 |
| 深居内陆 | 距海远，水汽到不了 | 塔克拉玛干、戈壁 |
| 沿岸寒流 | 冷海面抑制对流，空气稳定 | 阿塔卡马、纳米布 |

## 边界

- 沙漠可以很冷：南极是极地荒漠，塔克拉玛干冬季零下
- "热"是副热带沙漠的特征，不是沙漠的定义
- 有些沙漠在扩张（沙漠化），有些在收缩，与降水和人为活动有关
- 沙漠边缘的过渡带最脆弱

## 用得上

- 判断一个地方为什么干旱：先看纬度（副高）、再看地形（雨影）、再看距海、最后看洋流
- 沙漠里的雾可以供水：纳米布甲虫靠雾取水

## 误解

- **"沙漠是因为太阳晒得太多"**——日照强不等于不下雨
- **"沙漠里没有生命"**——有，只是稀疏且适应性强

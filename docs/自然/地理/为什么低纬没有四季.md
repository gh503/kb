# 为什么低纬没有四季

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 四季

## 结论

因为低纬地区**太阳高度角的年变化很小**：赤道正午太阳高度全年在 66.5°–90° 之间摆动，
不像中纬那样从很低到很高。辐射输入稳定，温度年较差就小。

## 机制

1. 太阳高度角决定单位面积接收的辐射量（∝ sin h）
2. 赤道全年正午高度角约 66.5°–90°，sin 值变化不到 10%
3. 中纬（如北纬 40°）正午高度角在约 26.5°–73.5° 之间，sin 值差 2 倍以上
4. 所以低纬接收的能量全年接近恒定
5. 低纬的"季节"更多由**降水**（干季/雨季）划分，而不是温度

## 量级

```text
赤道气温年较差：常小于 3℃
北纬 40° 内陆：年较差可达 25–30℃
赤道正午太阳高度：66.5°–90°
北纬 40° 正午太阳高度：26.5°–73.5°
```

## 边界

- 低纬并非"没有季节"，是温度季节不明显、降水季节明显
- 高原低纬地区（如青藏）因海拔高，气温年较差反而可能较大
- 海洋性气候也会削弱年较差
- 热带气旋、季风会带来显著的季节差异

## 用得上

- 理解"热带只有旱季雨季"的说法
- 农业上，低纬更依赖降水节律而不是积温

## 误解

- **"赤道最热所以没有季节"**——是高度角变化小，不是"最热"
- **"低纬没有温差"**——昼夜温差可以很大

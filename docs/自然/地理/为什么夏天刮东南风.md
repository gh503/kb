# 为什么夏天刮东南风

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 季风

## 结论

因为夏天**陆地比海洋热得快**。陆地上空气受热上升，形成低压；海上相对凉，是高压。
风就从海洋吹向陆地——在中国东南沿海，这就是东南季风。

## 机制

1. 水的比热容比陆地大得多，同样晒一天，陆地升温快、降得也快
2. 夏季陆地成了"热源"，空气上升，近地面形成低压
3. 海洋相对是"冷源"，近地面是高压
4. 空气从高压流向低压：**海 → 陆**，就是夏季风
5. 冬季反过来：陆地冷、形成高压，风从陆地吹向海洋

## 边界

- 这只是**海陆热力差异**这一半；另一半是行星风带的季节移动（赤道低压带北移）
- 南亚季风还强烈受**青藏高原加热**影响，比单纯的"海陆风"复杂
- 季风不只带来风，更带来**水汽**：夏季风从海上带来大量水汽，才形成雨季
- 沿海的"海陆风"是日变化，季风是年变化，两者叠加

## 用得上

- 中国降水集中在夏季，根源就是夏季风带来的水汽
- 同纬度对比：西欧是西风带 + 海洋性气候，东亚是季风气候，雨季集中
- 农业上的"雨热同期"，是季风给的

## 误解

- **"季风就是刮半年的风"**——关键不是风本身，是**风向反转 + 水汽输送**的配合
- **"夏天都刮东南风"**——各地不同，南亚是西南季风，东亚是东南季风

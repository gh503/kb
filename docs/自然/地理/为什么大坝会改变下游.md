# 为什么大坝会改变下游

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 河流地貌

## 结论

因为大坝把**泥沙拦在库区**，下泄的是"清水"。清水会反过来冲刷河床，
导致河床下切、岸坡失稳；同时到达河口的泥沙减少，三角洲萎缩、海岸后退。

## 机制

1. 水库流速低，泥沙沉降，出库水含沙量大幅下降
2. 清水下游"饥饿"，会冲刷河床与河岸补充泥沙
3. 河床下切 → 水位下降 → 取水口、堤防基础受影响
4. 河口泥沙减少 → 三角洲堆积 < 沉降/海浪侵蚀 → 后退
5. 营养盐也被截留，影响河口生态与渔业

## 案例与量级

```text
阿斯旺大坝后，尼罗河三角洲部分岸段后退
密西西比河三角洲因泥沙减少与沉降，湿地持续损失
中国部分水库下游观测到河床下切数米
```

## 边界

- 影响程度取决于泥沙截留率、下游地质、海岸动力
- 排沙调度、鱼道、生态泄流可以缓解部分影响
- 大坝也带来防洪、发电、供水效益，不能只看一面
- "拆坝"不是通用解，要具体评估

## 争议与未解

- 三角洲萎缩中，**泥沙减少、地面沉降、海平面上升**各占多少，难以分离
- 生态影响的长期预测不确定性大
- 水库寿命（淤积）与效益的权衡，缺乏统一标准

## 到此为止

这一层是**机制清楚 + 归因困难**：泥沙截留必然发生，
但"下游会变成什么样、多久"取决于多种因素，难以精确预测。

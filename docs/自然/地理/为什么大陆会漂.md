# 为什么大陆会漂

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 板块与地震

## 结论

因为地球最外层不是一整块，而是被切成几块**岩石板块**，它们驮着大陆在地幔上慢慢移动，
每年几厘米——和指甲生长的速度差不多。**大陆"漂"是板块动的结果，不是大陆自己在划水。**

## 机制

1. 岩石圈（地壳 + 上地幔顶部）破裂成若干板块
2. 地幔对流、板块下沉的重力拖曳等驱动板块运动
3. 板块边界有三种：**分离**（洋中脊）、**汇聚**（俯冲带、碰撞带）、**错动**（转换断层）
4. 大陆驮在板块上，所以会跟着走、撞在一起、裂开

## 证据

- **海岸线拼合**：南美东岸与非洲西岸形状吻合
- **化石**：相同的古生物化石出现在隔海相望的大陆
- **古地磁**：岩石记录的地磁方向与纬度，显示大陆曾经在别处
- **GPS**：直接测到板块每年移动几厘米

## 量级

```text
典型板块速度：每年 2–10 厘米
大西洋：约 2–3 厘米/年张开
印度板块：曾经每年 15 厘米以上，撞出喜马拉雅
```

## 边界

- "大陆漂移"是结果，"板块构造"是机制——后者能解释前者解释不了的海底扩张
- 地震、火山主要集中在板块边界，板块内部相对稳定
- 板块运动不是匀速的，会变速、转向

## 误解

- **"大陆是浮在岩浆上的"**——板块是固体岩石，靠地幔的塑性流动"托着"移动
- **"漂移是被潮汐或风推的"**——驱动力来自地幔对流与板片重力

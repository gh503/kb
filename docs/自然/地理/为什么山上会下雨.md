# 为什么山上会下雨

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 山与雨

## 结论

因为湿空气被山挡住了去路，只能**往上爬**。上升时气压变低、空气膨胀、温度下降，
水汽凝成云滴；云滴互相碰撞长大，重到飘不住，就落下来成雨。

## 机制

1. 风把含有水汽的空气推向山坡
2. 迎风坡迫使空气抬升——这是关键，**不抬升就没有雨**
3. 每升高 100 米，气温大约降 0.6℃（有凝结时叫湿绝热递减率）
4. 温度降到露点，水汽开始凝结，放出的潜热让降温变慢
5. 云滴碰并长大，形成降水

## 边界

- **山不够高**：抬升不到凝结高度，就只有云没有雨
- **空气本来就干**：没有水汽可凝结，山再高也不下雨
- **风向变了**：同一座山，雨季和旱季的迎风坡可能不同
- 降水多在山腰而不是山顶：水汽到高处已经掉得差不多了

## 用得上

- 为什么一座山两边的植被完全不同：一边是森林，一边是草坡
- 为什么水库、水电站常修在山麓：那里是降水与径流集中的地方
- 为什么山区午后容易雷阵雨：白天坡面受热，抬升更强

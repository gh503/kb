# 为什么山坡上的土会往下跑

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 土壤

## 结论

因为重力 + 雨水。坡度越陡，雨水越难下渗、流速越快，土壤颗粒被冲刷带走；
没有植被固定，这个过程会加速几十倍。

## 机制

1. 雨滴打在裸露地表，把土粒溅起（击溅侵蚀）
2. 坡面径流把土粒往下搬（面蚀）
3. 小沟汇成大沟（沟蚀），甚至滑坡、泥石流
4. 坡度、坡长、降雨强度、植被覆盖、土壤可蚀性共同决定侵蚀量
5. 通用土壤流失方程（USLE）：`A = R × K × LS × C × P`

## 量级

```text
自然侵蚀速率：约 0.01–1 mm/年
耕作/裸露地：可达每年数毫米到数厘米
陡坡 + 暴雨 + 无植被：短时间可流失数厘米表土
```

## 边界

- 侵蚀不等于"土消失了"：土被搬到低处，但**表土和养分**损失了
- 梯田、等高种植、留茬覆盖能显著减少侵蚀
- 坡顶侵蚀最强，坡脚堆积
- 植被根系固土，但深根也可能促进裂隙

## 用得上

- 坡地种植要顺等高线，不要顺坡
- 裸露地要覆盖（秸秆、草皮、地膜）
- 修路、建房后要及时护坡

## 误解

- **"种树就能完全防侵蚀"**——要看覆盖度和根系类型
- **"土被冲走只是少一点土"**——损失的是最肥的表土，恢复极慢

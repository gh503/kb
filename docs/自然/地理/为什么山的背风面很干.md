# 为什么山的背风面很干

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 山与雨

## 结论

因为空气在迎风坡已经把水汽掉得差不多了；翻过山脊往下沉时，空气被**压缩增温**，
相对湿度进一步下降。所以背风坡又干又晴，这叫**雨影**。

## 机制

1. 迎风坡：抬升 → 冷却 → 凝结 → 降水，水汽大量损失
2. 越过山脊后，空气开始下沉
3. 下沉时气压升高、空气被压缩，温度按**干绝热**约 1℃/100 米上升
4. 温度升高而水汽没增加，相对湿度大幅下降，云也散开
5. 结果：背风坡降水少、日照多、蒸发强

## 边界

- 雨影不是"绝对不下雨"：仍有锋面雨、对流雨等其他机制
- 需要持续的水汽来源和稳定的风向，雨影才明显
- 季风区里，雨影的位置会随季节移动
- 内陆盆地的干旱常是"雨影 + 距海远"叠加，不能只归因于山

## 例子

- **秦岭**：南坡接纳来自南方的暖湿气流，北坡（关中）明显更干
- **内华达山脉**：西坡湿润，东坡是死谷与荒漠
- **安第斯山南段**：西风带的雨影让巴塔哥尼亚长期干旱

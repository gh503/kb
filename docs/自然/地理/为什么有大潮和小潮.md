# 为什么有大潮和小潮

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 潮汐

## 结论

因为太阳和月亮的引潮力会**叠加或抵消**。新月和满月时，日月在一条线上，两个鼓包同向相加，
就是**大潮**；上下弦时成 90°，一拉一压，就是**小潮**。

## 机制

1. 太阳也产生引潮力，大小约为月球的 46%（虽然太阳质量大得多，但距离远得多）
2. **朔（新月）、望（满月）**：日、地、月近似一线，两股引潮力同向 → 潮差最大
3. **上弦、下弦**：日月与地球约成直角，两股力互相削弱 → 潮差最小
4. 所以潮差按半个月为周期起伏，而不是按天

## 量级

```text
月球引潮力 : 太阳引潮力 ≈ 1 : 0.46
大潮潮差 ≈ 小潮潮差的 1.5 倍左右（随地形差别很大）
```

引潮力按距离的**三次方**衰减，所以近的月亮赢过大的太阳。

## 边界

- 大潮小潮是**天文**因素；实际潮差还受地形、水深、风暴增水影响，
  某些海湾（如芬迪湾）潮差能到十几米
- 风暴潮叠加天文大潮最危险——"赶上涨潮"不是修辞
- 潮差最大的时候不总在朔望当天，常有 1–2 天的滞后

## 用得上

- 赶海、钓鱼要看潮汐表，大潮日退得最远，露出的滩涂最多
- 沿海施工、进港要靠潮位窗口

# 为什么欧洲比同纬度暖

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 洋流与气候

## 结论

因为**北大西洋暖流**把低纬度的热量往东北方向送，再加上西风把海洋上的暖湿空气吹上陆地。
伦敦比同纬度的拉布拉多暖和十几度，差的就是这条"热水管"。

## 机制

1. 信风和西风带动大西洋表层海水向北流
2. 墨西哥湾暖流沿北美东岸北上，延伸到欧洲西岸
3. 暖流把热量从低纬带到高纬，海面温度比同纬度海域高
4. 西风带把海洋的热量和湿气吹向欧洲内陆
5. 结果：西欧冬季温和、降水均匀，形成温带海洋性气候

## 量级

```text
同纬度对比（约北纬 50°）：
伦敦 1 月均温约 5℃
拉布拉多同纬度 1 月均温约 −10℃ 甚至更低
差 15℃ 左右
```

## 边界

- 洋流不是唯一原因：西风带、海陆分布、地形都参与
- 同纬度暖不代表"不受寒潮影响"：一旦风向转东，欧洲也会骤冷
- 北大西洋暖流不是"一条河"，是宽几百公里的流动水团

## 误解

- **"欧洲暖是因为离海近"**——离海近解释湿度，暖主要来自暖流
- **"暖流是墨西哥湾来的热水，一路不变凉"**——沿途不断向大气散热，到达北欧时已弱很多

## 用得上

- 理解为什么同纬度城市气候差别巨大：先看洋流，再看风带
- 葡萄酒产区、港口不冻，很多与暖流有关

# 为什么河口会堆出三角洲

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 河流地貌

## 结论

因为河流到河口时**流速骤降**，搬运能力下降，泥沙卸货堆积。
如果堆积速度超过海浪、潮汐的搬走速度，就长成三角洲。

## 机制

1. 河流搬运泥沙的能力随流速下降而急剧减小（约与流速的高次方相关）
2. 入海（湖）后水面变宽、坡度变缓 → 流速降低
3. 泥沙沉降，先形成沙嘴、沙洲，再连成三角洲
4. 河流分汊、改道，形成不同形态
5. 堆积 > 侵蚀 → 三角洲推进；反之 → 后退

## 形态

| 类型 | 特征 | 例子 |
| --- | --- | --- |
| 鸟足状 | 河道分汊明显，泥沙细 | 密西西比河 |
| 扇形 | 河口宽阔，波浪作用强 | 尼罗河 |
| 潮汐型 | 潮沟发育 | 恒河—布拉马普特拉 |

## 边界

- 三角洲需要"泥沙供应 + 沉积空间 + 较弱的海浪/潮汐"
- 泥沙被大坝截留后，三角洲会萎缩（见下一条）
- 三角洲地势低平，易受海平面上升与地面沉降影响
- 三角洲土壤肥沃，人口密集，风险也集中

## 用得上

- 三角洲是农业与城市密集区，也是防洪重点
- 河口湿地是重要生态屏障

## 误解

- **"三角洲都是三角形"**——形态多样，名字来自希腊字母 Δ
- **"泥沙越多越好"**——过多会淤塞航道

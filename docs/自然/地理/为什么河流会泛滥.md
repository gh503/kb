# 为什么河流会泛滥

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 河流地貌

## 结论

因为来水超过河道的**过流能力**。暴雨、融雪、溃坝都会让水位超过堤岸，
水漫进**洪泛区**——而洪泛区本来就是河流历史上一再淹过的地方。

## 机制

1. 流域降雨 → 汇流 → 河道流量增大
2. 流量超过河道容量，水位上涨
3. 超过堤顶或堤防溃决 → 漫溢
4. 洪泛区地势低平，是河流长期沉积形成的
5. 城市化让地表硬化，汇流更快，洪峰更高

## 重现期

```text
"100 年一遇" = 任意一年发生概率约 1%
不是"100 年才发生一次"
```

连续两年发生 100 年一遇，在概率上并不矛盾。

## 边界

- 堤防能防小洪水，但可能抬高洪水位、增加溃决风险（"风险转移"）
- 蓄洪区、湿地、海绵城市是"给洪水空间"的思路
- 山洪与内涝机制不同：山洪是山区暴涨，内涝是排水不畅
- 洪水也有生态作用：补给地下水、输送泥沙

## 用得上

- 住在洪泛区要了解历史洪水位与撤离路线
- 洪水来时不要涉水行车，30 cm 深的水就能冲走汽车
- 城市内涝时远离地下空间

## 误解

- **"堤修得越高越安全"**——可能只是把风险推给下游或抬高水位
- **"100 年一遇就是 100 年一次"**——是年概率

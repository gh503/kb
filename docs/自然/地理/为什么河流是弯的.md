# 为什么河流是弯的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 河曲

## 结论

因为只要有一点点弯，**弯外侧的水就流得快、弯内侧的水就流得慢**：
外侧被冲刷，内侧沉积泥沙。弯就越来越弯——河流是被自己"放大"成弯的。

## 机制

1. 河流很难保持笔直：地形、泥沙、水流的一点扰动就会造成微小弯曲
2. 进入弯道后，水受离心作用偏向**凹岸**（外侧），外侧水面略高、流速更快
3. 快水冲刷凹岸，把泥沙带走；内侧（凸岸）流速慢，泥沙沉积下来
4. 结果：外侧越退越远，内侧越长越宽，弯度被放大

## 边界

- **山区河流**多为直的、陡的：坡降大、下切强，弯曲不容易发展
- **平原河流**最容易弯：坡缓、泥沙多、侧向侵蚀强
- 河弯的间距有规律，大致是河宽的十几倍
- 人工渠化、护岸会把弯曲"冻住"，但也可能让下游冲刷加剧

## 用得上

- 河湾外侧水深、内侧浅：行船走外侧，游泳别在水流急的外侧
- 河边修堤、建房子要避开凹岸，那里一直在退
- 弯道内侧淤积，容易形成滩地、河漫滩

## 误解

- **"河流天然就是弯的"**——是"微小扰动 + 正反馈"的结果，不是设计
- **"弯道水流慢"**——外侧反而更快，内侧才慢

# 为什么河流能切开山

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 河流地貌

## 结论

因为河流带着**沙石当"砂纸"**，长期磨蚀河床；地壳抬升又让河流不断下切，
两者配合，几百万年就能切出深谷。

## 机制

1. 流水本身能溶解、冲刷岩石（溶蚀、磨蚀）
2. 搬运的沙砾像砂纸一样磨损河床
3. 地壳抬升 → 河流落差增大 → 下切加快
4. 河流向下侵蚀的极限是**基准面**（通常是海平面）
5. 峡谷就是这样"边抬升、边下切"形成的

## 边界

- 峡谷需要"抬升 + 下切"同时进行，光有水流切不深
- 岩性影响形态：硬岩成陡崖，软岩成缓坡
- 上游以下切为主，下游以堆积为主
- 喀斯特地区是溶蚀为主，形态不同（溶洞、峰林）

## 用得上

- 峡谷地区水能资源丰富（落差大）
- 水库选址常在峡谷口，因为坝短、库容大
- 峡谷也是地质灾害（滑坡、落石）高发区

## 误解

- **"河流是先有河道再切下去"**——是河流沿构造薄弱带发育，边切边成形
- **"峡谷是地震裂开的"**——主因是长期侵蚀，地震只是触发局部崩塌

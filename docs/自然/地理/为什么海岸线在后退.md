# 为什么海岸线在后退

> **学段** 大学–研究生 ｜ **类型** 边界（归因） ｜ **链** 海岸与海岛

## 结论

三个原因叠加：**海平面上升、泥沙供应减少、地面沉降**。
它们同时作用，所以"某段海岸为什么退"很难归因到单一因素。

## 机制

1. **海平面上升**：热膨胀 + 冰川融化，全球平均约 3.4 mm/年（近年更快）
2. **泥沙减少**：大坝截留、采砂，让海滩"补给"不足
3. **地面沉降**：抽取地下水、油气，或沉积物压实
4. 波浪与风暴侵蚀把沙搬走
5. 人工硬防护（海堤）可能加剧邻近岸段的侵蚀

## 量级

```text
全球平均海平面：约 +3.4 mm/年（1993–2022 卫星测高）
部分三角洲：地面沉降可达每年数厘米
局部岸段后退：每年数十厘米到数米
```

## 边界

- 有些海岸在前进（三角洲淤积、构造抬升），不是全部后退
- 局地沉降可能远大于全球海平面上升
- 沙滩有季节性变化（冬夏剖面不同），不等于长期后退
- 归因需要长期观测，短期数据容易误判

## 争议与未解

- 海平面上升的**区域差异**（某些地区更快）机制复杂
- 泥沙减少与沉降各占多少，缺乏统一量化
- 海岸防护的长期效果与副作用，仍有争论

## 到此为止

这一层是**三个机制叠加 + 归因困难**：趋势清楚，
但"这一段为什么退"需要具体观测，不能一概而论。

# 为什么海边晚上风从陆地吹来

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 海陆风

## 结论

因为夜里陆地**降温更快**：陆地变冷、空气下沉形成高压，海面相对暖、是低压。
风就从陆地吹向海洋，这叫**陆风**。海风和陆风合起来，就是"海陆风环流"。

## 机制

1. 日落后陆地迅速散热，海水降温慢，海面反而比陆地暖
2. 陆地近地面空气冷却下沉 → 高压；海面空气上升 → 低压
3. 风从陆地吹向海洋，就是陆风
4. 白天和夜里风向反转，构成一个闭合的日变化环流
5. 转换通常发生在上午（转海风）和傍晚（转陆风），中间有一段静风期

## 边界

- **陆风通常比海风弱**：夜间海陆温差小，而且陆地上有摩擦和地形阻挡
- 陆风把陆地上的污染物、水汽带向海面，影响近岸空气质量
- 强背景风（如季风）会盖过海陆风，日变化就看不出来
- 转换时刻的"静风"对帆船、滑翔伞是重要窗口

## 量级

```text
海风风速：几米每秒（典型 3–7 m/s）
陆风风速：常常不到海风的一半
```

## 用得上

- 海边夜钓、露营：夜里风从陆地来，湿度可能下降，体感比想象中凉
- 沿海城市的污染物夜间容易在近岸堆积
- 白天海风、夜里陆风，是沿海气候"温和"的原因之一

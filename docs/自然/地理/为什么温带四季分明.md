# 为什么温带四季分明

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 气候带

## 结论

因为中纬度一年里**太阳高度角变化大**，加上**西风带和气旋活动**频繁，
冷暖气团交替控制——所以四季分明，而且天气变化快。

## 机制

1. 中纬度太阳高度角在一年里变化幅度大（不像赤道终年接近直射）
2. 西风带把海洋的水汽和热量带到陆地
3. 冷暖气团在此交汇，形成锋面与气旋，带来降水和大风
4. 气旋一个接一个过境，所以"天气"变化明显，而不只是"季节"变化
5. 大陆性与海洋性差异：离海远的地方升温快、降温也快

## 量级

```text
同纬度两地年温差对比：
海洋性气候（如伦敦）年温差约 13℃
大陆性气候（如莫斯科）年温差可超过 25℃
```

## 边界

- "四季分明"主要指中纬度，热带和极地没有这种过渡
- 温带也分多种：温带海洋性、温带大陆性、温带季风
- 季风区的四季由季风环流主导，与西风带型不同
- 城市热岛会改变局地季节感

## 用得上

- 同纬度旅行要查"大陆性还是海洋性"，不能只看纬度
- 农业上的无霜期、积温，都受这个差异影响

## 误解

- **"同纬度气候就一样"**——海陆位置和洋流差别巨大
- **"四季分明是因为地球离太阳远近变化"**——主因还是地轴倾角

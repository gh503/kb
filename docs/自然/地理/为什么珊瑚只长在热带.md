# 为什么珊瑚只长在热带

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 海岸与海岛

## 结论

因为造礁珊瑚体内住着**虫黄藻**，它靠光合作用给珊瑚供能。
虫黄藻需要**温暖、明亮、清澈、低营养**的水——所以珊瑚礁集中在热带浅海。

## 机制

1. 造礁珊瑚与虫黄藻共生：藻光合供能，珊瑚提供庇护与养分
2. 水温需约 18–30℃，太冷太热都不行
3. 需要光照，一般在 50 m 以浅
4. 需要清澈、低营养的海水（浑浊会挡光，营养多会助长藻类竞争）
5. 珊瑚分泌碳酸钙骨骼，逐渐堆积成礁

## 量级

```text
适宜温度：约 18–30℃（最适 23–29℃）
深度上限：约 50–150 m（取决于透明度）
白化阈值：持续高于约 30–32℃ 数周
```

## 边界

- 珊瑚礁只占海洋面积不到 1%，却养育约 25% 的海洋物种
- 深海冷水珊瑚也存在，但不形成典型礁体
- 白化是珊瑚排出虫黄藻，短期可恢复，长期会死亡
- 酸化会降低钙化速率

## 用得上

- 潜水不要触碰珊瑚
- 防晒霜中的某些成分对珊瑚有害，选"reef-safe"
- 珊瑚白化是气候变暖的直接指标之一

## 误解

- **"珊瑚是石头"**——是动物，礁是它分泌的骨骼
- **"珊瑚到处都能长"**——受温度、光照、水质严格限制

# 为什么赤道多雨而沙漠在回归线附近

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 气候带

## 结论

因为**空气在赤道上升、在南北纬 30° 附近下沉**。
上升 → 冷却 → 成云致雨；下沉 → 增温 → 不易成云。一个多雨，一个干旱，正好对应雨林和沙漠。

## 机制

1. 赤道太阳直射，地面受热强，空气受热上升
2. 上升时膨胀冷却，水汽凝结成云，形成对流雨（**赤道低压带 / 赤道辐合带**）
3. 上升到高空后向南北流动，在南北纬 30° 附近下沉
4. 下沉空气被压缩增温，相对湿度降低，很难成云（**副热带高压**）
5. 于是 30° 附近成为地球主要的沙漠带

## 量级

```text
赤道附近年降水：常超过 2000 mm
副热带沙漠：常低于 250 mm
同一环流圈的两端，差一个量级
```

## 边界

- 副高位置随季节移动，所以沙漠边缘有干湿季
- 不是所有 30° 都是沙漠：季风、洋流、地形会改变结果（如中国东南沿海）
- 赤道也不全是雨林：东非高原、赤道上的沙漠（如索马里）也有例外

## 用得上

- 看地图先找赤道和回归线，能大致预测哪里多雨、哪里干旱
- 副高控制区晴热少雨，是夏季高温伏旱的成因

## 误解

- **"沙漠是因为离赤道远"**——是下沉气流，不是距离
- **"赤道最热所以一定最干"**——赤道多雨，干燥在 30°

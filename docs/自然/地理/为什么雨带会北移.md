# 为什么雨带会北移

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 季风

## 结论

因为夏季风带着水汽一路向北推进，而**副热带高压**的位置也在北跳。
两者相遇的地方就是雨带，它随季节从华南推到江淮、再到华北，形成"雨带季节性北移"。

## 机制

1. 夏季风从海洋带来暖湿空气
2. 副热带高压（简称"副高"）是下沉气流区，它北侧边缘是冷暖空气交汇的锋面
3. 副高随季节北跳，雨带跟着北移：
   - 5 月前后：华南前汛期
   - 6 月中—7 月上：江淮梅雨
   - 7 下—8 月：华北、东北
4. 副高南退时，雨带又南撤

## 边界

- 雨带位置每年差异很大，"梅雨"长短、有无都不同
- 台风也会打断雨带，带来另一种降水
- 北方雨季短而集中，南方雨季长；不是"雨带均匀扫过"

## 用得上

- 防汛要看的不只是雨量，还有**雨带停在哪、停多久**
- 长江中下游的梅雨，本质是雨带在此停滞
- 华南前汛期与台风季是两套机制

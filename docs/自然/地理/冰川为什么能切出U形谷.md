# 冰川为什么能切出 U 形谷

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 风与冰川地貌

## 结论

因为冰川不是"水在流"，而是**整块冰带着碎石在磨**。它从山顶往下推，
把谷底磨宽、谷壁磨陡，切出**U 形**（横剖面像字母 U），而河流切的是窄深的 V 形。

## 机制

1. 冰川底部冻结着岩屑，像砂纸一样磨蚀谷底和谷壁（磨蚀）
2. 冰体冻结岩石后移动，把岩块"拔"下来（拔蚀）
3. 冰川在谷底和两侧同时作用，把 V 形谷拓宽成 U 形
4. 支冰川汇入主冰川处，常形成"悬谷"
5. 冰川退去后留下冰碛、漂砾、羊背石

## 形态对比

| | 河流谷 | 冰川谷 |
| --- | --- | --- |
| 横剖面 | V 形，窄深 | U 形，宽平底 |
| 谷壁 | 曲折 | 较直、陡 |
| 谷底 | 有河床 | 平坦，可有湖 |
| 支流 | 自然汇入 | 常成悬谷 |

## 边界

- U 形谷是"冰蚀"证据，但要结合冰碛、擦痕一起判断
- 冰川也堆积：终碛、侧碛、冰碛丘
- 现代冰川退缩后，会露出新鲜磨光面
- 不是所有宽谷都是冰川成因，河流侧蚀也能拓宽

## 用得上

- 登山、徒步时认 U 形谷，能判断是否曾有过冰川
- 冰川谷常成湖（如峡湾、冰蚀湖）

## 误解

- **"冰川是流动的水"**——是固态冰在重力下塑性流动
- **"U 形谷是水冲出来的"**——是冰磨出来的

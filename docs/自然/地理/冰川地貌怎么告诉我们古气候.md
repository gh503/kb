# 冰川地貌怎么告诉我们古气候

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 风与冰川地貌

## 结论

因为冰川留下了**可定年的痕迹**：冰芯里的气泡封存了古代大气，
冰碛与漂砾记录了冰进冰退的年代，氧同位素记录了温度。
把它们拼起来，就能重建几十万年的气候。

## 方法

1. **冰芯**：气泡中的 CO₂、CH₄ 直接反映古代大气成分
2. **氧同位素（δ¹⁸O）**：与温度、冰量相关
3. **冰碛与漂砾定年**：宇宙成因核素（如 ¹⁰Be）测暴露年龄
4. **冰进冰退序列**：终碛位置指示冰川范围
5. **黄土—古土壤序列**：与冰期—间冰期对应

## 经典结论

```text
过去 80 万年：约 10 万年一个冰期旋回
冰期 CO₂ 约 180 ppm，间冰期约 280 ppm
末次冰盛期全球平均温度比现在低约 5–6℃
```

## 边界

- 冰芯只存在于极地和高山，空间覆盖有限
- 定年有误差，不同方法可能不一致
- 冰碛容易被后来的冰川破坏，"记录不完整"
- 区域气候与全球平均不是一回事

## 争议与未解

- 冰期旋回的**驱动机制**（米兰科维奇循环）能解释周期，但解释不了幅度
- "100 kyr 问题"：为什么主导周期是 10 万年而非 4.1 万年，仍无定论
- 冰芯气泡的年龄差（气体与冰的时差）需要校正

## 到此为止

这一层是**记录清楚 + 机制未闭合**：气候变化的序列可靠，
但"为什么会这样变"仍有争议。

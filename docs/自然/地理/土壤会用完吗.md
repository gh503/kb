# 土壤会用完吗

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 土壤

## 结论

**局部会，全球不会"用光"，但肥力退化是真实且严重的。**
土壤形成速率比侵蚀速率慢一到两个数量级，所以"用掉"的速度远快于"长回来"的速度。

## 量级

```text
成土速率：约 0.01–0.1 mm/年
耕作侵蚀：约 0.1–1 mm/年（高强度区可更高）
差 10–100 倍
```

按这个速度，几十厘米厚的表土在强侵蚀下几百年内可显著变薄，
而成土需要几千年。

## 边界

- "土壤流失"与"土地占用"是两件事：城市化把土盖住，比侵蚀更难逆转
- 全球估计差异大：不同研究给出的退化面积相差数倍
- 保护性耕作、免耕、覆盖作物能显著降低侵蚀
- 土壤也有"更新"途径：淤积、火山灰、有机质输入

## 争议与未解

- **全球土壤退化速率的估计**高度不确定，缺乏统一监测
- "土壤能否在百年尺度内恢复"取决于管理方式，模型分歧大
- "土壤碳汇"的潜力与稳定性，是当前研究热点，也是争议点
- 粮食需求、气候、政策交织，难以做单一归因

## 到此为止

这一层是**量级清楚 + 全球估计不确定**：形成慢于流失是硬的，
"全球还剩多少年"这类说法缺乏可靠依据。

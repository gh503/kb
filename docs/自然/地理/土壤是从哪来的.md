# 土壤是从哪来的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 土壤

## 结论

土壤是**岩石碎屑 + 有机质 + 空气 + 水**的混合物。
它由母岩风化而来，再靠植物、微生物、蚯蚓把有机物掺进去，需要**很长时间**才能长成。

## 机制

1. **物理风化**：温度变化、冻融、风沙把岩石崩成碎屑
2. **化学风化**：水、氧气、二氧化碳让矿物分解、溶解
3. **生物作用**：植物根系撑裂岩石，微生物分解有机物
4. 有机质与矿物颗粒混合，形成有结构的土壤
5. 影响成土的因素：母质、气候、生物、地形、时间（"五大成土因素"）

## 量级

```text
形成 1 厘米厚的土壤：可能需要几十到几百年
（不同气候下差别极大）
```

## 边界

- 土壤不是"土"，它有分层（腐殖质层、淋溶层、淀积层、母质层）
- 热带土壤不一定肥沃：高温高湿让有机质分解快，养分留不住
- 土壤质地分砂土、壤土、黏土，保水保肥能力不同
- 城市里的"土"很多是回填土，不是自然土壤

## 用得上

- 种花用"营养土"而不是随便挖的土，因为结构不同
- 土壤板结、盐碱化都会影响作物
- 蚯蚓多的地方，土壤结构通常更好

## 误解

- **"土壤就是碎石头"**——有机质和生物才是关键
- **"有土就能种"**——还要看酸碱度、养分、排水

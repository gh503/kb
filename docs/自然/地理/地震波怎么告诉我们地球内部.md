# 地震波怎么告诉我们地球内部

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 板块与地震

## 结论

因为地震波穿过地球时会被**折射、反射、改变速度**，用全球台站记录到的走时和波形，
就能反推出内部的圈层结构——**人类从未钻到地幔，却知道地核是液态的**。

## 机制

1. **P 波**（纵波）能穿过固体和液体，速度约 6–8 km/s
2. **S 波**（横波）只能穿固体，速度约 3.5–4.5 km/s
3. S 波在约 2900 公里深处**完全消失** → 外核是液态
4. P 波速度在莫霍面（约 30–50 km）和古登堡面（2900 km）突变 → 圈层界面
5. 地震波走时反演（层析成像）能给出三维速度结构

## 结构

| 圈层 | 深度 | 关键证据 |
| --- | --- | --- |
| 地壳 | 0–约 35 km | 莫霍面速度跳变 |
| 地幔 | 35–2900 km | P/S 波速度梯度 |
| 外核（液态） | 2900–5150 km | S 波不能通过 |
| 内核（固态） | 5150–6371 km | P 波速度回升 |

## 边界

- 反演是**非唯一**的：不同模型可以拟合同样的走时数据
- 分辨率有限：横向几百公里、纵向几十公里量级
- 地核的轻元素成分仍未确定

## 用得上

- 地震预警利用 P 波比 S 波快：先到几秒，就能自动停电梯、停列车
- 石油勘探、核试验监测用的也是同一套波传播原理

# 季风为什么会失灵

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 季风

## 结论

季风每年强弱不同，主要由大尺度海气信号调制：**厄尔尼诺—南方涛动（ENSO）**、
**印度洋偶极子（IOD）**、副高位置等。但这些信号只能解释一部分方差，
**季风的年际预测仍是世界性难题**。

## 机制

1. ENSO 改变热带太平洋的海温分布，进而改变沃克环流与副高位置
2. IOD 改变印度洋东西温差，影响水汽输送
3. 青藏高原的加热、欧亚积雪、北极海冰也会远程影响季风
4. 多个信号相互叠加、非线性的作用，使预测难度陡增

## 边界

- 季风"失灵"通常指**雨季推迟、降水偏少或集中爆发**，不是"完全不刮风"
- 不同区域对同一信号的响应可能相反
- 气候变化下的季风降水预估，模式之间分歧很大：有的报增多，有的报减少

## 未解与争议

- **年际预测**：目前对季风降水的季节预测技巧有限，尤其是区域尺度
- **气候变化的响应**：变暖会增加大气持水能力，但环流怎么变不清楚，
  东亚季风降水"北旱南涝"还是"整体增强"仍无定论
- 观测记录长度不足、模式参数化差异，都是误差来源

## 到此为止

这一层是**未解**：机制候选清楚（ENSO、IOD、高原加热），
但把它们组合成可靠的预报，目前做不到。本库不给"预测方法"，只给"为什么难"。

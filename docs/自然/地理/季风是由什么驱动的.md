# 季风是由什么驱动的

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 季风

## 结论

主因是**海陆热力差异**的季节反转，再加上**青藏高原**的加热与阻挡、
以及**赤道辐合带（ITCZ）**的季节移动。三者叠加，才有亚洲这样强的季风。

## 机制

1. 夏季大陆升温快 → 形成低压 → 海洋暖湿气流深入内陆
2. 冬季大陆冷 → 高压 → 干冷气流吹向海洋
3. 青藏高原抬升加热大气，强化海陆温差（"高原热源"效应）
4. ITCZ 随季节南北移动，带来雨带推进
5. 季风"爆发"表现为风向突变 + 持续性强降水

## 量级

```text
亚洲季风区降水：占全球热带降水很大比例
季风爆发时间：南海约 5 月中下旬，印度约 6 月
季风指数：用海平面气压差或风场定义，不同指数不完全可比
年际变化：与 ENSO、印度洋偶极子等有关
```

## 边界

- "季风"不只是"夏天刮东南风"，是**大尺度环流的季节反转**
- 季风指数定义不同，结论可能不一致
- 季风降水不等于"整个夏天都在下雨"，有活跃期与中断期
- 全球变暖对季风的影响，区域差异大

## 用得上

- 农业播种、水库调度依赖季风预报
- 理解"雨带北移"与"南涝北旱"的年际差异

## 误解

- **"季风就是海风"**——尺度差几个数量级，机制也不同
- **"季风只影响南亚"**——东亚、澳洲、非洲、美洲都有季风系统

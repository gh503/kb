# 柯本气候分类是怎么分的

> **学段** 高中–大学 ｜ **类型** 边界 ｜ **链** 气候带

## 结论

柯本分类用**温度和降水的季节组合**来划分气候：
先按温度分出 A（热带）、C（温带）、D（大陆性）、E（极地），
再按降水季节分出子类，B 单独表示干旱。**它是一套"看数字就能归类"的规则**。

## 机制

1. 用最冷月/最热月平均气温、年降水量、降水季节分配作为指标
2. 主要组：
   - **A 热带**：最冷月 ≥ 18℃
   - **B 干旱**：降水不足以支撑植被
   - **C 温带**：最冷月 0–18℃，最热月 > 10℃
   - **D 大陆性**：最冷月 < 0℃，最热月 > 10℃
   - **E 极地**：最热月 < 10℃
3. 第二、第三字母表示降水季节与强度，如 Af（热带雨林）、BWh（热沙漠）
4. 结果是一张全球气候类型图

## 边界

- 柯本是**经验分类**，不是成因分类：它描述"气候像什么"，不解释"为什么"
- 阈值是人为选的（如 18℃、10℃），边界附近会有争议
- 高地气候（H）单列，因为海拔改变了温度
- 城市气候、微气候不在分类尺度内
- 气候变化会让某些站点"跨类"，但分类本身不自动更新

## 用得上

- 看气候图先认字母，比背地名快
- 农业引种、建筑规范常用柯本类型做参考
- 但做工程要查具体气象数据，不能只看类型

## 误解

- **"柯本分类是按纬度分的"**——是按温度降水指标，纬度只是间接相关
- **"同一类型气候完全一样"**——类型内部差异可能很大

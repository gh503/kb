# 沙丘为什么是弯月形

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 风与冰川地貌

## 结论

因为沙被风推着走，遇到障碍或沙量不足时，**两翼比中间跑得快**，
于是中间堆积、两翼向前伸，形成"弯月"——新月形沙丘的尖角指向**下风方向**。

## 机制

1. 风把沙粒沿地面滚动、跳跃（跃移）搬运
2. 迎风坡较缓，沙被吹上去
3. 到坡顶后风速降低，沙在背风坡堆积
4. 背风坡陡，坡度接近沙的**休止角**（约 32°–34°）
5. 两翼沙层薄、移动快，向前伸出成"角"

## 用得上（读沙丘）

- 缓坡朝风、陡坡背风：能判断**主导风向**
- 尖角指向下风：沙丘在向下风移动
- 沙丘移动会埋路、埋田，需要固沙（草方格、防护林）

## 边界

- 沙量充足、风向多变时，会形成网格状、星状沙丘
- 有植被固定时，沙丘形态被"锁住"
- 沙丘不是"沙漠专属"，海边、河滩也有
- 沙丘移动速度与风速、沙量、湿度有关

## 误解

- **"沙丘是风吹出来的土堆"**——是沙粒搬运—堆积形成的有规律形态
- **"尖角指向上风"**——尖角指向下风

# 沙滩的沙从哪来

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 海岸与海岛

## 结论

沙是**岩石被磨碎的产物 + 生物留下的碎屑**，由河流、海浪搬到岸边堆积。
所以你脚下的沙，可能是山上的一块花岗岩，也可能是珊瑚、贝壳的碎片。

## 机制

1. **河流搬运**：河流把上游的沙石带到河口，海浪再沿岸搬运
2. **海岸侵蚀**：海浪拍打崖壁，把岩石磨碎
3. **生物碎屑**：珊瑚、贝壳、海藻钙化后破碎（热带沙滩常见）
4. **风化**：温差、盐结晶让岩石崩解
5. 波浪筛选颗粒，粗砂留在大浪处，细砂沉在平静处

## 沙的"身份证"

| 颜色 | 常见成分 |
| --- | --- |
| 白色 | 珊瑚、贝壳碎屑（热带） |
| 黄色/褐色 | 石英、长石 |
| 黑色 | 火山岩碎屑（如黑沙滩） |
| 粉色 | 有孔虫壳 + 珊瑚 |

## 边界

- 沙不是"取之不尽"：河流输沙减少，沙滩会变窄
- 采沙会破坏沙滩与生态
- 沙的粒径影响坡度与渗水
- 人工补沙只是短期缓解

## 误解

- **"沙是泥土变干的"**——主要是岩石碎屑和生物碎屑
- **"沙滩永远在那儿"**——是动态平衡，会被侵蚀或淤积

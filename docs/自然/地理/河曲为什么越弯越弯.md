# 河曲为什么越弯越弯

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 河曲

## 结论

因为弯道里形成了**横向环流**：表层水冲向凹岸，底层水带着泥沙回到凸岸。
上冲下回，把外侧的土搬到内侧，弯道就越长越弯，最后可能被"剪断"成牛轭湖。

## 机制

1. 弯道中，离心力让上层水向外侧（凹岸）堆积
2. 为保持连续，底层水必须向内（凸岸）回流——形成螺旋状的横向环流
3. 表层清水冲向凹岸 → 冲刷；底层浑水回到凸岸 → 沉积
4. 剖面越来越不对称：凹岸陡、凸岸缓（点坝）
5. 弯到极限，两个弯之间的颈部被冲穿，河道截弯取直，旧弯道留下**牛轭湖**

## 边界

- 环流强度随弯度增大，但到一定程度会被洪水打断
- 泥沙粒径决定沉积位置：粗砂在凸岸，细泥在河漫滩
- 洪水期河道可能"抄近路"，整段河曲被废弃
- 北方平原、长江中下游都是典型曲流区

## 量级

```text
曲流波长 ≈ 10–14 倍河宽
例：河宽 100 m 的河，相邻两个弯之间约 1–1.4 km
```

## 用得上

- 牛轭湖、废弃河道是找古河道的线索，也是湿地
- 护岸要护**凹岸**，不是整条河
- 航道疏浚多在凸岸侧，因为那里淤积

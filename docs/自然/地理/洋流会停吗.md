# 洋流会停吗

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 洋流与气候

## 结论

**大西洋经向翻转环流（AMOC）在减弱，但"会不会崩溃、什么时候"没有定论。**
观测只有二十来年，模式之间分歧大，这是当前气候科学最受关注的**未解**之一。

## 机制

1. AMOC 把暖的表层水送到北大西洋，冷却下沉后沿深层南流
2. 格陵兰冰盖融化、降水增加 → 表层水变淡 → 密度下降 → 下沉减弱
3. 下沉减弱 → 整个翻转环流变慢 → 向北的热输送减少
4. 反馈：北大西洋变冷 → 可能进一步改变风场与降水

## 证据

- **观测**：RAPID 阵列（2004 年起）显示 AMOC 有减弱趋势，但年际波动很大
- **代用指标**：沉积物、冰芯重建显示末次冰期有过多次突变
- **模式**：多数气候模式预估本世纪减弱，但"崩溃"只在少数情景中出现

## 边界

- 减弱 ≠ 崩溃：崩溃意味着不可逆的突变，需要更强证据
- 观测序列太短，趋势与自然变率难以分离
- 区域影响（欧洲冬季、季风、海平面）比"全球平均"更显著也更不确定

## 争议与未解

- IPCC 对"21 世纪 AMOC 崩溃"的评估是**低信度**（不太可能，但不能排除）
- 临界点是否存在、在什么升温水平触发，模型之间差别很大
- 电影《后天》式的"几天内冰封"是艺术夸张，不是科学结论

## 到此为止

这一层是**争议 + 未解**：机制清楚（淡水输入 → 密度下降 → 翻转减弱），
但"何时、是否可逆"缺乏观测与共识。

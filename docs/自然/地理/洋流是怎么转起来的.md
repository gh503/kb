# 洋流是怎么转起来的

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 洋流与气候

## 结论

两套驱动：**风**把表层水推着走（风生环流），**密度差**让深层水下沉、上升（温盐环流）。
地球自转的科里奥利力把这两套流动都"拧"成了环流，并且让西边界流又窄又急。

## 机制

1. 信风和西风持续吹，靠摩擦力带动表层海水
2. 科里奥利力让运动偏转：北半球向右、南半球向左
3. 偏转 + 海岸阻挡 → 形成大洋环流（如北太平洋副热带环流）
4. **西边界流强化**：同一环流西侧又窄又快（黑潮、湾流），东侧宽而慢
5. 高纬表层水变冷变咸、密度增大而下沉，在深层回流，形成温盐环流

## 量级

```text
湾流：宽约 100 km，流速可达 2 m/s
黑潮：流速 1–2 m/s
大洋深层水：流速常低于 0.01 m/s，慢得多
```

## 边界

- 风生环流主要在表层几百米；温盐环流涉及整个深度
- "温盐环流"的驱动力不只是温度和盐度，风也间接参与
- 洋流受海底地形影响，会被海峡、海岭改变路径
- 厄尔尼诺会改变赤道太平洋的流场与风向

## 用得上

- 航运走顺流航线更省油，历史上"帆船航线"就是照着洋流画的
- 表层洋流影响渔业：上升流带来营养盐，形成渔场

## 误解

- **"洋流是被月亮拉动的"**——潮汐流是另一回事，主洋流靠风和密度差
- **"深层海水不动"**——在动，只是慢

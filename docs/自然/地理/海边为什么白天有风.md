# 海边为什么白天有风

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 海陆风

## 结论

因为白天**陆地比海水热得快**。陆地上的空气受热上升，形成低压；海上相对凉，是高压。
风就从海上吹向陆地，这就是**海风**——所以海边白天总比内陆凉快、风大。

## 机制

1. 太阳照下来，陆地升温快、海水升温慢（水的比热容大）
2. 陆地空气受热膨胀上升，近地面形成低压
3. 海面较凉，空气下沉，近地面是高压
4. 空气从高压流向低压：海 → 陆，就是海风
5. 海风带来凉爽湿润的空气，还会把海上的水汽送进来

## 边界

- 海风一般**下午最强**，因为午后海陆温差最大
- 海风能深入内陆几十公里，形成"海风锋"，有时会触发雷阵雨
- 阴天、大风天，海陆温差小，海风就不明显
- 大湖、大江边也有同样的效应，只是弱一些

## 用得上

- 夏天海边下午最舒服：风大、气温低、湿度高
- 海风锋过境时可能突然起风、下雨，海边活动要注意
- 城市里"滨水区"的降温效果，靠的就是这个

## 误解

- **"海边凉是因为水凉"**——主要是海风把凉空气送过来，不只是水温
- **"海风一天到晚都吹"**——夜里会反转，见[为什么海边晚上风从陆地吹来](为什么海边晚上风从陆地吹来.md)

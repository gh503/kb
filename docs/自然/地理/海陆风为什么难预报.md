# 海陆风为什么难预报

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 海陆风

## 结论

因为海陆风是**局地环流**，尺度只有几十公里，强弱取决于海岸线形状、地形、城市热岛、
背景风——数值模式的分辨率往往不够，参数化又高度依赖经验。**提前一两天的准确预报仍然困难。**

## 机制

1. 海陆风的驱动力来自**很小的温差**（几度），容易被大尺度天气系统淹没
2. 海岸线弯曲、海湾、岛屿会改变局地环流，模式网格常常"抹平"这些细节
3. 城市热岛与海风叠加，形成复杂的辐合线，触发对流的时机难以把握
4. 边界层湍流、海面粗糙度的参数化，对不同模式差别很大

## 边界

- 大尺度天气晴朗、背景风弱时，海陆风最明显，也最可预报
- 有强天气系统时，海陆风几乎可以忽略
- 海风锋的**位置**几十公里误差很常见，而降水就发生在锋面附近

## 未解与争议

- 海风锋触发对流的**临界条件**，在不同海岸、不同季节差别很大，缺乏统一判据
- 城市热岛对海风的增强还是削弱，研究结论不一致
- 高分辨率模式能改善结果，但计算成本高，业务化仍受限

## 到此为止

这一层是**未解 + 工程取舍**：机制清楚（温差驱动），但局地细节和触发时机无法准确预测，
业务预报只能给概率和趋势。

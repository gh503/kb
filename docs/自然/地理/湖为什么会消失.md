# 湖为什么会消失

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 湖泊与湿地

## 结论

两个方向：**被填满**（泥沙、生物残体不断沉积）和**被抽干**（来水减少、蒸发大于补给）。
前者是自然过程，后者多与人类用水有关。

## 机制

1. 河流带入泥沙，在湖底一层层沉积
2. 水草、藻类残体堆积，形成有机沉积
3. 沉积使湖变浅 → 更易长水生植物 → 沉积更快（正反馈）
4. 内流湖（无出口）靠蒸发平衡，来水减少就萎缩
5. 构造下沉可以让湖"续命"，抬升则加速消亡

## 量级

```text
自然充填速率：每千年几厘米到几十厘米（差异极大）
富营养浅水湖：可能几百年就变沼泽
内流湖萎缩：取决于入湖水量与蒸发
```

## 边界

- 湖消失不等于"水没了"，可能变成沼泽、湿地、盐碱地
- 构造活动可以创造新湖（断陷湖）
- 气候变化与人类引水常叠加作用
- 冰川湖、火山口湖的演化路径不同

## 用得上

- 湖泊变浅、水草蔓延，是"沼泽化"的早期信号
- 内陆湖周边的大规模引水，要评估湖泊存续

## 误解

- **"湖消失都是气候变化"**——灌溉引水常是主因
- **"湖会自己变干净"**——沉积是不可逆的

# 湖水为什么会变绿

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 湖泊与湿地

## 结论

因为水里**藻类爆发**了。氮、磷太多（生活污水、农田化肥），藻类疯长，水就变绿、变浑浊；
藻死后分解又耗掉氧气，鱼就缺氧浮头。

## 机制

1. 氮磷是藻类的"肥料"，浓度高 → 藻类快速繁殖
2. 叶绿素让水体呈绿色，透明度骤降
3. 藻类死亡后被细菌分解，消耗大量溶解氧
4. 缺氧 → 鱼虾死亡、底泥释放更多磷（恶性循环）
5. 有些蓝藻还会产生毒素，影响饮水安全

## 量级

```text
叶绿素 a 浓度：> 10 μg/L 通常已是富营养
总磷参考：> 0.02–0.1 mg/L 就可能富营养化
蓝藻水华时：水面可形成明显"绿漆"层
```

## 边界

- 水变绿不一定是污染：春季硅藻繁殖也会让水变褐绿
- 透明度、叶绿素、总磷要一起看，不能只看颜色
- 流动快的水体不易爆发
- 水温高、光照足时更容易爆发

## 用得上

- 少用含磷洗涤剂，减少面源污染
- 湖边不要乱倒污水
- 看见"绿漆"别下水，蓝藻毒素可致皮肤与肝脏损伤

## 误解

- **"水绿是水草多"**——常是浮游藻类
- **"换水就能解决"**——不控源，很快复发

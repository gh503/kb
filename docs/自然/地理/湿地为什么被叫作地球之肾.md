# 湿地为什么被叫作地球之肾

> **学段** 高中–大学 ｜ **类型** 边界（比喻的限度） ｜ **链** 湖泊与湿地

## 结论

因为湿地能**滞留泥沙、吸收氮磷、蓄洪削峰、储存碳**——功能上像"过滤+缓冲"。
但"肾"是比喻，湿地不能无限净化，也不能替代污水处理厂。

## 机制

1. **净化**：水流变慢，泥沙沉降；植物与微生物吸收/转化氮磷
2. **蓄洪**：湿地像海绵，汛期蓄水、枯期释放
3. **碳汇**：积水缺氧，有机质分解慢，泥炭不断积累
4. **生物栖息**：浅水与挺水植物提供繁殖场所
5. **地下水补给**：部分湿地与含水层连通

## 量级

```text
泥炭地：约占陆地面积 3%，却储存约 30% 的土壤碳
氮去除率：人工湿地可达 30%–70%（随负荷、停留时间变化）
蓄洪能力：取决于面积与调蓄容积
```

## 边界

- 净化能力有上限，超负荷会变成污染源
- 湿地在厌氧条件下可能产生甲烷，碳账要算清楚
- 不同湿地类型（沼泽、滩涂、人工湿地）功能差别大
- "肾"的比喻容易让人以为它可以无限"排毒"

## 用得上

- 保护湿地比事后修复便宜得多
- 人工湿地可作为尾水深度处理，但要按负荷设计

## 误解

- **"湿地能净化一切污染"**——能力有限，且可能二次释放
- **"填埋湿地影响不大"**——蓄洪与碳汇功能会一起消失

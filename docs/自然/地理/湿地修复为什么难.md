# 湿地修复为什么难

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 湖泊与湿地

## 结论

因为湿地的核心是**水文情势**——水位、淹水时长、季节节律。水回不来，种什么草都活不好；
而泥炭一旦氧化，几百年积累的碳与结构很难"长回来"。

## 为什么难

1. **水文**：修复首先要恢复水位与淹水节律，涉及流域取水、排水工程
2. **泥炭**：排水后泥炭氧化沉降，是不可逆的物理损失
3. **种子库**：长期耕作后本土植物种子库耗尽
4. **营养负荷**：周边农田的氮磷持续输入，修复后仍会富营养
5. **时间尺度**：自然湿地形成以百年计，修复往往只有几年预算

## 量级

```text
泥炭沉积速率：约每年 0.1–1 mm
排水后泥炭氧化沉降：可达每年数厘米
恢复"接近自然"的湿地：常需数十年
```

## 争议与未解

- **"修复"的定义**：是恢复结构与功能，还是只要"有水有草"？
- 人工湿地的碳汇与甲烷排放，净效应可能为负，取决于设计
- 补偿性修复（"占一补一"）的有效性，缺乏长期评估
- 修复成功的判据（物种、水文、碳）尚无统一标准

## 到此为止

这一层是**水文优先 + 不可逆损失**：能修一部分，
但"把湿地修回原样"在多数情况下做不到。

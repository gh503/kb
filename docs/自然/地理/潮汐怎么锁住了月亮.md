# 潮汐怎么锁住了月亮

> **学段** 大学–研究生 ｜ **类型** 机制（含未解） ｜ **链** 潮汐

## 结论

潮汐摩擦把地球的自转角动量一点点转给月球的轨道运动：
**地球越转越慢，月球越退越远**，同时月球的自转被锁成与公转同步——所以我们永远只看到它的同一面。

## 机制

1. 地球自转比月球公转快，潮汐鼓包被地球拖着"跑在月亮前面"
2. 鼓包对月球的引力有一个**向前的分量**，把月球往外推
3. 反过来，月球对鼓包的引力拖慢地球自转——地球一天在变长
4. 月球自身也被地球的潮汐拉变形，久而久之自转被摩擦锁死（自转周期 = 公转周期）

## 量级

```text
月球每年远离约 3.8 cm
地球自转每世纪变慢约 1.7 毫秒（需用古生物化石与天文记录校正）
```

## 边界

- 潮汐锁定是**长期演化的结果**，不是"月亮本来就不转"
- 距离越远，引潮力按三次方衰减，所以远离过程会逐渐变慢（但不会停）
- 太阳也有贡献，但远小于月球
- 同样的机制在系外行星上决定了"宜居带内是否有潮汐加热"

## 未解与前沿

- **潮汐加热**：木卫一（Io）被木星潮汐揉搓，内部持续生热，是全球最活跃的火山天体；
  但潮汐耗散在冰壳、岩浆洋里如何分配，至今没有定论
- 系外行星的潮汐演化会改变轨道与自转，直接影响"是否宜居"的判断，
  但耗散因子 Q 的取值不确定性极大
- 古代潮汐记录（沉积层、贝壳生长纹）能反推地球自转史，但分辨率很粗

## 到此为止

再往下问"为什么潮汐摩擦会把角动量转走"，是**角动量守恒**；
问"为什么角动量要守恒"，是空间旋转对称性（诺特定理）——本库在此标为**公理层**。

# 潮汐是怎么被算出来的

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 潮汐

## 结论

靠**调和分析**：把实测潮位曲线拆成许多条已知周期的"分潮"（月球、太阳的各周期项），
求出各自振幅与相位，再叠加外推——所以潮汐表能提前几年算准。

## 机制

1. 引潮力可以展开成一系列周期项（分潮）
2. 最大的一项是 **M2**（太阴半日分潮），周期约 12.42 小时
3. 还有 S2（太阳半日）、K1、O1（日潮）等
4. 用长期实测数据拟合各分潮的振幅和相位
5. 叠加所有分潮 → 预测未来任意时刻的潮位

## 量级

```text
M2 分潮周期：12 小时 25 分（12.42 h）
半日潮涨落周期：约 12 h 25 min，两次高潮间隔约 12.4 h
主要分潮数量：常用十多个，精细预报可上百个
预报精度：多数港口可达厘米到分米级
```

## 边界

- 这是**经验统计**方法，"分潮"不是真实存在的独立波
- 浅水区潮波变形，需要加入浅水分潮
- 风暴潮、海啸是叠加在潮汐上的"非周期"事件，不能靠调和分析预测
- 需要足够长的实测数据（通常至少一年）

## 用得上

- 潮汐表、航海、赶海都依赖这套预报
- 理解"为什么潮汐表能算得很准，天气却只能报几天"

## 误解

- **"潮汐预报靠算引力"**——实用预报靠实测拟合
- **"分潮是真实的水波"**——是数学分解出的成分

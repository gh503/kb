# 黄土高原的土从哪来

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 风与冰川地貌

## 结论

黄土是**风吹来的**：冰期时西北的沙漠、戈壁提供大量粉砂，被西北风搬运到黄土高原堆积，
几十万年一层层积成几十到几百米厚。

## 机制

1. 冰期气候干冷，风力强，沙漠扩张
2. 细颗粒（粉砂级）被风带到高空，长距离搬运
3. 遇到高原、山脉阻挡，风速降低，粉尘沉降
4. 粉尘堆积后，被雨水、生物作用固结成黄土
5. 冰期—间冰期交替，形成"黄土—古土壤"互层

## 证据

- 黄土颗粒从西北向东南**逐渐变细**（风力分选）
- 矿物成分与西北沙漠一致
- 黄土中有陆生蜗牛化石，说明是陆相堆积
- 厚层黄土记录了古气候旋回

## 量级

```text
黄土高原厚度：一般 50–100 m，最厚超过 300 m
堆积速率：约每千年几厘米到几十厘米
```

## 边界

- 黄土不是"河水冲来的"，河流只负责再搬运
- 黄土疏松、垂直节理发育，容易水土流失和崩塌
- 黄土高原的水土流失是自然 + 人为叠加
- 不是所有黄土都来自同一物源，不同区域有差异

## 用得上

- 黄土适合挖窑洞（直立性好），但遇水易崩
- 水土保持（梯田、淤地坝、退耕还林）是当地核心问题

## 误解

- **"黄土是河流沉积"**——主体是风成
- **"黄土高原一直是这样"**——是长期堆积 + 侵蚀塑形

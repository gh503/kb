# 天文

> 天上的事，其实大多能用地上已经学过的规律解释——引力、辐射、等离子体。

这一科回答的是：**为什么天上是这个样子**。只收能纠正误解、能定量估算、能解释日常可见天象的部分。

## 收什么

- 天象成因：月相、日食、极光、为什么星星会闪
- 尺度与量级：多远、多大、多久
- 误解纠正：为什么潮汐不是"月亮吸水"、为什么星座和命运无关

## 不收什么

- 占星、星座运势
- 未经验证的"宇宙玄学"
- 需要专业天文台才能验证的细节

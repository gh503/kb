# 为什么不是每个月都有日食

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 日食与月食

## 结论

因为月球的轨道（白道）和地球的轨道（黄道）**有约 5° 的夹角**。
大多数朔望时，月球在黄道上方或下方，影子错开，投不到对方身上。

## 机制

1. 白道与黄道交角约 **5.1°**
2. 两个轨道面的交线叫"交点线"，交点是黄白交点
3. 只有太阳、地球、月球接近一条线，且月球在**交点附近**时才可能发生食
4. 太阳每年经过交点两次 → 每年有两个"食季"
5. 食季里可能发生日食、月食；错过就要等半年

## 量级

```text
黄白交角：约 5.1°
月球轨道半径：约 38 万 km
5° 的偏差在 38 万 km 处约对应 3.3 万 km 的错位
——远大于地球直径（1.27 万 km），所以大多数朔望不成食
```

## 边界

- 交点线会缓慢进动（约 18.6 年一周），所以食季每年略微提前
- 一个食季可能连着发生日食和月食
- 每年日食至少 2 次，最多 5 次；月食 0–3 次
- 沙罗周期（约 18 年 11 天）可用来预测相似的食

## 用得上

- 查日食：找"食季"和"全食带"，不是每个月都等
- 沙罗周期能粗略预测下一次类似日食

## 误解

- **"每个月十五就该有月食"**——要交点对齐才行
- **"日食很罕见"**——全球每年都有几次，只是全食带窄

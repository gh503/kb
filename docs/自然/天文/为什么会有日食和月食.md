# 为什么会有日食和月食

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 日食与月食

## 结论

因为太阳、地球、月球排成一条线时，**影子落在谁身上**：
月球挡住太阳、影子落在地球上 → **日食**；地球挡住太阳、影子落在月球上 → **月食**。

## 机制

1. 太阳照地球和月球，各自在背光面形成长长的影子
2. **朔（新月）**时月球在太阳和地球之间，如果正好对齐，月影落在地面 → 日食
3. **望（满月）**时地球在太阳和月球之间，地影落在月面 → 月食
4. 影子分为本影（完全挡光）和半影（部分挡光）
5. 日食只在影子扫过的窄带上可见；月食在夜半球都能看到

## 边界

- 日食一定发生在朔，但朔不一定有日食（见下一条：轨道倾角）
- 月食时月亮不是全黑，而是暗红色（地球大气折射红光）
- 日食有全食、环食、偏食；月食有全食、偏食、半影食
- 日食观测必须戴专业滤光镜，不能用肉眼或普通墨镜

## 用得上

- 日食带很窄（全食带通常几十到几百公里宽），要提前查路径
- 月食不需要设备，肉眼可见，适合科普
- 日食时气温会短暂下降，动物行为可能异常

## 误解

- **"日食是月亮把太阳吃掉了"**——是影子投射
- **"月食是因为地球挡住了月光，所以月亮看不见"**——月亮还在，只是变暗变红

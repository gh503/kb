# 为什么会有极光

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 极光

## 结论

太阳一直在往外吹带电粒子（太阳风）。这些粒子被地球磁场引导，从**南北两极附近**钻进大气，
撞上高空的气体原子，把它们的电子撞到高能级；电子落回低能级时发光——这就是极光。

## 机制

1. 太阳风是高速运动的电子和质子，速度可达每秒几百公里
2. 地球磁场像一把伞，把大部分粒子挡在外面
3. 但磁力线在两极附近收拢，粒子沿着磁力线"漏"进大气
4. 在 80–500 公里的高空，粒子撞击氧、氮原子和分子
5. 原子被激发，退激时放出特定波长的光——氧发绿光和红光，氮发紫红光

## 边界

- 极光主要在**磁纬 65°–70°** 的环带（极光卵）上，不是"正北极点"
- 太阳活动强的年份，极光卵会向南扩张，中纬度也能看到
- 极光出现在**高空**，最低约 80 公里，比飞机巡航高度高得多
- 白天也在发生，只是被阳光盖住了

## 误解

- **"极光是雪反射的光"**——是大气自身发光
- **"只有冬天才有极光"**——季节影响的是黑夜长度和天气，不是成因
- **"极光会发出声音"**——极光本身在几十公里以上，声音传不下来

## 用得上

- 想看极光：高纬地区 + 冬季 + 晴朗无月光 + 太阳活动活跃期
- 极光预报看 Kp 指数，Kp 越大，可见范围越靠南
- 用相机长曝光比肉眼更容易看到颜色（肉眼常看成灰白）

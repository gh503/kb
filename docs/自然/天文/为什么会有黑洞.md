# 为什么会有黑洞

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 黑洞与引力波

## 结论

因为质量够大的天体，**逃逸速度会超过光速**。光都跑不掉，
于是没有任何东西能离开它周围的某个边界——这个边界就是"视界"，里面就是黑洞。

## 机制

1. 逃逸速度随天体质量和半径变化：质量越大、半径越小，逃逸速度越高
2. 当逃逸速度达到光速，连光都出不来
3. 这个临界半径叫**史瓦西半径**：`r_s = 2GM/c²`
4. 恒星坍缩到视界以内，就形成恒星级黑洞
5. 视界不是"实体表面"，是"有去无回"的边界

## 量级

```text
把太阳压成黑洞：r_s ≈ 3 km
把地球压成黑洞：r_s ≈ 9 mm
恒星级黑洞：几倍到几十倍太阳质量，r_s 几十公里
星系中心超大质量黑洞：百万到十亿倍太阳质量
```

## 边界

- 黑洞不是"宇宙吸尘器"：远处引力与同质量天体一样
- 视界内物理我们无法观测，"奇点"是理论外推
- 黑洞会因霍金辐射缓慢蒸发（极慢）
- 恒星级黑洞来自大质量恒星坍缩，不是"恒星烧完变成黑洞"那么简单

## 误解

- **"黑洞把周围一切吸进去"**——只有靠得很近才会
- **"黑洞是个洞"**——是质量高度集中的天体

# 为什么内行星是岩石，外行星是气态

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 太阳系

## 结论

因为太阳附近太热，**冰留不住**。靠近太阳只有岩石和金属能凝结；
在外侧"雪线"之外，水冰、氨、甲烷能冻结成固体，吸积出更大的核心，再抓住大量气体。

## 机制

1. 原行星盘内温度高，水、氨、甲烷都是气态，只有岩石/金属能凝固
2. 内区固体材料少 → 行星核心小 → 抓不住厚大气
3. 雪线（约 2–3 AU）之外，冰凝结成固体，固体量大幅增加
4. 大核心引力强，能吸积氢、氦
5. 年轻太阳的强辐射和太阳风把内区气体吹走

## 量级

```text
雪线位置：约 2.7 AU（火星与木星之间）
内行星：水星、金星、地球、火星（岩石为主）
外行星：木星、土星（气态巨行星）、天王星、海王星（冰巨星）
```

## 边界

- "气态巨行星"其实有岩石/冰核心，只是大气占比极大
- 系外行星里有很多"热木星"，说明迁移普遍存在
- 冰巨星与气态巨行星的界限在成分比例，不完全清楚
- 太阳系不是唯一模板，其他系统差异很大

## 用得上

- 判断"宜居带"：液态水可能存在的距离范围
- 理解为什么火星小、木星大

## 误解

- **"外行星没有固体表面所以不存在"**——有核心
- **"内行星一定小"**——是固体材料少，不是必然

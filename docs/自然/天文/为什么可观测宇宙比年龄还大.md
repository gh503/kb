# 为什么可观测宇宙比年龄还大

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 闪烁的星空

## 结论

因为宇宙在膨胀：光出发时那些星系离我们更近，**在路上走的这段时间里空间本身还在拉长**，
所以今天它们已经退到约 465 亿光年外——比"138 亿年 × 光速"大得多。

## 机制

1. 光以有限速度传播，138 亿年前发出的光现在才到
2. 但这 138 亿年里，空间一直在膨胀
3. 光走过的"共动距离"不等于"现在的物理距离"
4. 用标准宇宙学模型（ΛCDM）积分，得到可观测宇宙半径约 **465 亿光年**
5. 所以"可观测宇宙直径 930 亿光年"与"宇宙年龄 138 亿年"并不矛盾

## 边界

- 可观测宇宙的边界不是"宇宙的边缘"，只是"光还没到我们这里"的范围
- 边界外的天体现在与我们没有因果联系
- 数值依赖宇宙学参数（哈勃常数、暗能量密度），有百分之几的不确定度
- 哈勃常数本身存在"测量分歧"（哈勃张力），仍待解决

## 用得上

- 理解"看到的是过去"：越远的天体，我们看到的是越早的宇宙
- 判断科普说法：把"930 亿光年"和"138 亿年"并列不是矛盾，是膨胀

## 误解

- **"宇宙年龄 138 亿年，所以半径 138 亿光年"**——忽略了膨胀
- **"超光速膨胀违反相对论"**——空间膨胀不是物体在空间中运动

## 未解与争议

- **哈勃张力**：早期宇宙与晚期宇宙测出的膨胀速率不一致，可能暗示新物理
- 暗能量的本质、宇宙最终的命运，仍无定论

## 到此为止

这一层依赖 **ΛCDM 标准模型**：它是目前拟合数据最好的模型，
但暗物质、暗能量的本质未明——本库把"模型内计算"与"模型本身是否正确"分开标注。

# 为什么土星有环

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 太阳系

## 结论

因为靠得太近的物质会被**潮汐力撕碎**，碎块没法聚成卫星，只能散成一圈。
这个"撕碎距离"叫**洛希极限**——环就位于洛希极限以内。

## 机制

1. 卫星不同部位受到的引力不同（近端强、远端弱）
2. 靠得越近，潮汐力越强
3. 当潮汐力超过卫星自身的引力结合力，卫星被撕碎
4. 碎块在轨道上摊开，形成环
5. 环粒子各自独立绕行，不聚合成团

## 量级

```text
土星环宽度：约 28 万 km
土星环厚度：多数区域仅约 10–100 m
主要成分：水冰颗粒（从微米到米级）
洛希极限（流体）：约 2.44 倍行星半径
```

## 边界

- 木星、天王星、海王星也有环，只是暗弱
- 环的年龄有争议：可能很年轻（千万年量级），也可能是古老环的"翻新"
- 环在缓慢"下雨"落向行星，理论上会消失
- 环的缝隙由卫星的共振"清理"出来（如卡西尼缝）

## 用得上

- 理解"洛希极限"：为什么彗星接近太阳或大行星会被撕碎
- 1994 年苏梅克—列维 9 号彗星撞木星，就是被潮汐撕裂的例子

## 误解

- **"环是固体圆盘"**——是无数独立粒子
- **"环很厚"**——极薄，宽厚比惊人

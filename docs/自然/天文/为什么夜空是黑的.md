# 为什么夜空是黑的

> **学段** 高中–大学 ｜ **类型** 机制（佯谬） ｜ **链** 闪烁的星空

## 结论

如果宇宙**无限大、无限老、静止不动**，那么每个方向上都该有一颗星，
夜空应该像太阳表面一样亮——这就是**奥伯斯佯谬**。
实际夜空是黑的，说明上面三个前提至少有一个不成立：**宇宙有年龄、而且在膨胀**。

## 机制

1. 假设宇宙无限、恒星均匀分布、永恒存在
2. 那么视线无论指向哪，最终都会落到一颗恒星表面
3. 亮度按距离平方衰减，但恒星数量按距离平方增加——两者抵消
4. 结论：整个天空应该和恒星表面一样亮（约 6000 K 的黑体辐射）
5. 现实不是，所以前提错了

## 为什么不是"被尘埃挡住了"

尘埃确实会挡光，但尘埃吸收能量后会**再辐射**，最终还是会亮起来。
所以"尘埃遮挡"不能解决佯谬。

## 真正的答案

- **宇宙有年龄**：约 138 亿年，光来不及从无限远的地方到达
- **宇宙在膨胀**：远处星系的红移让光子能量降低、亮度下降
- 两者叠加，夜空才是黑的

## 量级

```text
宇宙年龄：约 138 亿年
可观测宇宙直径：约 930 亿光年（膨胀使"视界"大于年龄 × 光速）
```

## 边界

- 夜空不是"绝对黑"：有宇宙微波背景（2.7 K）、黄道光、气辉
- 光污染让"黑"变成了橙色，与宇宙学无关
- 佯谬的解决不需要"宇宙有限"，只需要"有年龄 + 在膨胀"

## 误解

- **"夜空黑是因为星星太少"**——数量不是关键，是年龄和膨胀
- **"奥伯斯佯谬证明了宇宙有限"**——证明的是宇宙不是"无限老 + 静止"

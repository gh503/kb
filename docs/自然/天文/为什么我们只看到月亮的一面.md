# 为什么我们只看到月亮的一面

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 月相

## 结论

因为月亮的**自转周期等于公转周期**（潮汐锁定），它转一圈正好也绕地球一圈，
所以永远同一面朝着我们。**它不是"不转"，是转得刚刚好。**

## 机制

1. 地球对月亮的潮汐力把月亮拉成椭球
2. 月亮自转时，这个隆起被地球引力拽着，产生摩擦，自转逐渐变慢
3. 最终自转周期被锁定成与公转周期相同（约 27.32 天）
4. 于是"同一面朝地球"成为稳定状态

这条链的完整版在地理：[潮汐怎么锁住了月亮](../地理/潮汐怎么锁住了月亮.md)。

## 边界

- 锁定不是"完全不动"：还有**天平动**，因为轨道是椭圆、自转轴略倾斜，
  我们实际能看到约 59% 的月面
- 月球背面不是"永远黑暗"，它同样有昼夜
- 其他卫星也普遍被锁定（木卫、土卫大多如此）

## 用得上

- 月球背面没有"外星基地"，只是我们看不到
- 嫦娥四号在背面着陆需要中继卫星，就是因为**无线电也被挡住了**

## 误解

- **"月亮不自转"**——它自转，只是和公转同步
- **"背面是暗的"**——背面有正常的昼夜交替

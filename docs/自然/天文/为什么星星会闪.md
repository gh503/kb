# 为什么星星会闪

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 闪烁的星空

## 结论

因为星光穿过地球大气时，被**密度不均匀、不断流动的空气**反复折射和偏折，
到达你眼睛的方向一直在抖——所以看起来在"眨眼"。

## 机制

1. 大气里到处是湍流：暖空气上升、冷空气下沉，密度忽高忽低
2. 光在密度变化的介质中会偏折，路径随之弯曲
3. 不同时刻、不同位置的光线偏折不同 → 星像位置抖动、亮度闪烁
4. 这个效应叫**视宁度**（seeing），是地面天文观测的主要限制之一
5. 星星越低（靠近地平线），穿过的大气越厚，闪得越厉害

## 边界

- 高空（飞机上、太空里）几乎不闪——没有大气
- 行星通常不闪，见下一条
- 大气稳定、透明度高的夜晚，星星"稳"，视宁度好
- 城市里光污染会让暗星看不见，但闪烁本身与光污染无关

## 用得上

- 天文台选址在高山、海岛、沙漠：海拔高、空气稳
- 用望远镜看行星比看恒星更"清楚"，部分原因就是行星不闪
- 想拍星星：需要短曝光"定格"，或自适应光学

## 误解

- **"星星在眨眼是因为它自己有明暗变化"**——多数是大气造成的
- **"闪得厉害说明天气好"**——闪得厉害往往说明大气湍流强，视宁度差

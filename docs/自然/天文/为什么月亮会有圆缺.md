# 为什么月亮会有圆缺

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 月相

## 结论

因为月亮自己不发光，**永远只有被太阳照亮的那一半是亮的**。
月亮绕地球转，我们从不同角度看到这半个亮面，就出现了月牙、半月、满月。

## 机制

1. 太阳照月亮，总有一半是亮的（和地球的昼夜一样）
2. 月亮绕地球走一圈约 29.5 天
3. 当月亮在太阳和地球之间：亮面背对我们 → **新月（朔）**
4. 当地球在太阳和月亮之间：亮面正对我们 → **满月（望）**
5. 中间的位置，我们看到亮面的一部分 → 上弦、下弦

## 边界

- 月相是**全球同时**的，不是"这个城市看到半月、那个城市看到满月"
- 南北半球看到的月牙方向相反（南半球是反的）
- 月相和月食不是一回事：月食是地球影子挡住月亮，只在满月发生
- 月亮刚升起时看起来大，是"月球错觉"，与月相无关

## 用得上

- 农历初一看不到月亮，十五前后最亮——农历就是按月相定的
- 满月时最适合夜行、看星空反而吃亏（太亮）
- 想拍银河，避开满月前后

## 误解

- **"月亮的阴影是地球的影子"**——月相和地球影子无关，那是月食
- **"月牙是被云遮住的"**——是亮面朝向的问题

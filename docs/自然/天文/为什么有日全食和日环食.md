# 为什么有日全食和日环食

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 日食与月食

## 结论

因为月球到地球的距离在变，**月球的视直径有时比太阳大、有时比太阳小**。
大的时候能把太阳完全挡住（全食），小的时候挡不满，边缘留一圈亮环（环食）。

## 机制

1. 月球轨道是椭圆，近地点约 36 万 km，远地点约 40 万 km
2. 月球视直径在约 29.4′–33.5′ 之间变化
3. 太阳视直径约 31.5′–32.5′（地球轨道也有偏心率）
4. 月视直径 > 日视直径 → 本影到达地面 → **全食**
5. 月视直径 < 日视直径 → 伪本影到达地面 → **环食**

## 边界

- 全食带窄、持续时间短（几分钟），环食带稍宽
- 全食时能看到日冕、日珥、色球，这是研究太阳大气的窗口
- 混合食（全环食）发生在临界距离，同一场食不同地点看到不同结果
- 月球正在缓慢远离地球（约 3.8 cm/年），遥远未来全食会变少

## 用得上

- 看日全食要提前到全食带中心，边缘只能看到偏食
- 全食阶段（太阳完全被挡）可以摘掉滤光镜看日冕，但**食既前后必须戴**
- 日环食全程都要戴滤光镜

## 误解

- **"日食分全食和环食是因为月亮大小不同"**——月亮大小不变，是距离在变
- **"环食不如全食值得看"**——环食也有独特的"金环"景观

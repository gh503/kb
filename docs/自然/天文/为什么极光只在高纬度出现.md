# 为什么极光只在高纬度出现

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 极光

## 结论

因为带电粒子只能**沿着磁力线**运动。地球的磁力线在两极附近收拢并垂直扎入大气，
粒子顺着磁力线走，自然就集中到高纬，形成一个环带——**极光卵**。

## 机制

1. 带电粒子在磁场中做螺旋运动，绕着磁力线转
2. 磁力线从地球内部出来，在两极附近收拢、几乎垂直地面
3. 太阳风压缩磁层，把粒子加速并注入磁尾
4. 粒子沿磁力线沉降，进入极区大气
5. 于是能量沉积集中在磁纬 65°–70° 的环带，而不是均匀分布

## 边界

- 极光卵的**纬度**随太阳活动变化：地磁暴时可扩展到中纬度
- 磁极与地理极不重合（磁偏角），所以"磁纬"和"地理纬度"要分开
- 极光卵在背阳面（夜侧）更亮、更靠低纬
- 木星、土星也有极光，机制类似，但粒子来源不同（如木卫一的火山物质）

## 量级

```text
典型极光卵：磁纬 65°–70°
强地磁暴时：可扩展到磁纬 45°–50°
```

## 用得上

- 判断"我这儿能不能看到"：查**磁纬**，不是地理纬度
- Kp 指数 5 以上，中纬度才有机会

## 误解

- **"极光在北极点最强"**——在极光卵上最强，极点反而少
- **"越北越好"**——超出极光卵再往北，反而看不到

# 为什么行星不闪

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 闪烁的星空

## 结论

因为行星离我们近，看起来是一个**有面积的圆面**，不是一个点。
圆面上各处被大气抖动的影响**互相平均**，闪烁就被抹平了；恒星太远，永远是"点"，抖一下就看得出。

## 机制

1. 恒星距离远到望远镜也分不出圆面，是**点光源**：一个方向的抖动直接表现为闪烁
2. 行星（如金星、木星）视直径可达几角秒到几十角秒，是**扩展源**
3. 扩展源上每一点都在抖，但抖动方向随机，叠加后总体亮度变化小
4. 于是行星看起来"稳"，成为辨认行星的一个简易办法

## 量级

```text
典型视直径：
木星 ≈ 40 角秒
金星 ≈ 10–60 角秒（随距离变化）
恒星：远小于望远镜分辨极限（毫角秒以下）
```

## 边界

- 行星极低空时也会闪（大气太厚）
- 双星、密集星场里的"看起来像行星"要小心
- 视宁度极差时，行星的像也会"沸腾"

## 用得上

- 夜空中"不闪的亮星"很可能是行星——金星、木星、火星、土星
- 用手机拍星空时，行星更容易拍实

## 误解

- **"不闪的就是行星"**——卫星、飞机、极亮的恒星在视宁度好时也会显得稳
- **"行星自己发光很稳"**——行星是反射太阳光，本身没有"稳定"的属性

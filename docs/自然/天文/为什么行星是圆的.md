# 为什么行星是圆的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 太阳系

## 结论

因为**自引力**把物质往中心拉。够大的天体，引力会把自身压成"流体静力平衡"的形状，
也就是接近球形——哪个方向离中心远，就被拉回来。

## 机制

1. 天体形成时，物质在引力下向质心聚集
2. 天体越大，引力越强，能把岩石压得"像流体一样"变形
3. 达到静力平衡时，形状接近球（同时因自转略扁）
4. 太小的小行星引力不够，保持不规则形状
5. 分界线大致在直径几百公里（依成分不同）

## 量级

```text
地球扁率：约 1/298（赤道半径比极半径长约 21 km）
月球：接近球形
灶神星（直径约 525 km）：已接近球形
多数小行星（几公里到几十公里）：不规则
```

## 边界

- "圆"不等于"完美球"：自转会造成扁率
- 行星还可以有"赤道隆起"，木星、土星尤其明显
- 定义上，"行星"要求能清空轨道附近，不只是形状
- 矮行星（如冥王星）也是圆的，但没清空轨道

## 用得上

- 看天体照片：圆形 + 清晰边缘，多半是够大的天体
- 土豆状的小天体，说明引力不足以塑形

## 误解

- **"行星是转圆的"**——主因是引力，自转只造成扁率
- **"圆就是行星"**——还要看轨道与清空能力

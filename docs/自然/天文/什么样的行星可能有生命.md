# 什么样的行星可能有生命

> **学段** 高中–大学 ｜ **类型** 边界 ｜ **链** 系外行星

## 结论

最常说的条件是：**液态水、合适的温度、稳定的大气、足够的能量**。
但"宜居"是必要条件，不是充分条件——我们只有地球一个样本。

## 常见判据

1. **宜居带**：距离恒星适中，表面可能有液态水
2. **恒星类型**：太亮、太暗、耀斑太强的恒星都不利
3. **行星质量**：太小留不住大气，太大会变成气态巨行星
4. **大气**：要有温室效应保温，又不能失控
5. **磁场**：可能有助于抵挡恒星风（但不是必需，争议中）

## 边界

- 宜居带不是"一定有水"：还要看大气、反照率、自转
- 红矮星的宜居带很近，行星容易被潮汐锁定
- 潮汐锁定行星的昼半球/夜半球温差极大
- 冰卫星的"地下海洋"也可能宜居（如欧罗巴、土卫二）

## 用得上

- 判断"宜居"要看一组条件，不是只看距离
- "超级地球"不等于"宜居"

## 误解

- **"宜居带内就有生命"**——只是"可能有液态水"
- **"必须像地球才行"**——这是"碳基中心主义"的假设

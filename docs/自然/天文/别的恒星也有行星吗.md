# 别的恒星也有行星吗

> **学段** 小学–初中 ｜ **类型** 量级 ｜ **链** 系外行星

## 结论

**有，而且非常多。** 到 2020 年代，已确认的系外行星超过 5000 颗。
统计估计：银河系里几乎每颗恒星都可能有行星。

## 机制：怎么"看见"看不见的行星

1. **凌星法**：行星从恒星前面经过，恒星亮度周期性微降
2. **视向速度法**：行星拉着恒星"晃动"，光谱线周期性移动
3. **直接成像**：遮住恒星的光，直接拍到大行星
4. **微引力透镜**：行星引力短暂放大背景星光
5. 多数发现来自前两种，因为它们适合大规模巡天

## 量级

```text
已确认系外行星：5000+（数量持续增长）
凌星造成的亮度下降：常低于 1%（地球约 0.008%）
视向速度信号：常为每秒几米甚至更低
银河系恒星数：约 1000 亿–4000 亿
```

## 边界

- 凌星法偏向"大行星 + 近轨道"，因为信号大、周期短
- 视向速度法偏向"大质量行星"
- 所以"发现的分布"不等于"真实的分布"
- 类地行星的探测难度最高

## 用得上

- 理解"发现"依赖方法灵敏度，不是"那里有什么就能看到什么"
- 开普勒、TESS 等望远镜的成果，主要来自凌星法

## 误解

- **"系外行星是拍出来的"**——绝大多数是间接推断
- **"太阳系很特殊"**——行星很普遍，但"像太阳系这样"的还不多见

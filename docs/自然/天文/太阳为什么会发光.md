# 太阳为什么会发光

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 恒星的一生

## 结论

因为太阳核心在把**氢聚变成氦**。这个过程中一点点质量变成了能量（E = mc²），
以光和热的形式释放出来。太阳每秒烧掉约 6 亿吨氢——但靠的不是"燃烧"，是**核聚变**。

## 机制

1. 核心温度约 1500 万开尔文，压力极大，氢核（质子）能克服电斥力靠近
2. 通过"质子—质子链"逐步聚变成氦
3. 生成氦核的质量比四个质子略小，差额变成能量
4. 能量以光子形式向外传递，从核心到表面要走十几万年
5. 到达表面后以阳光辐射出去，8 分 20 秒到地球

## 量级

```text
每秒消耗氢：约 6×10⁸ kg
每秒质量亏损：约 4×10⁹ kg
太阳光度：约 3.8×10²⁶ W
地球接收到的：约 1.36 kW/m²（太阳常数）
```

## 边界

- 核聚变不是"烧"，不需要氧气
- 太阳每秒损失的质量听起来多，但相对太阳总质量极小，还能烧约 50 亿年
- 太阳发光主要来自核心，表面（光球）约 5800 K
- 太阳中微子能直接逃出核心，是验证聚变理论的证据

## 误解

- **"太阳在燃烧"**——是核聚变，不是化学燃烧
- **"太阳会很快烧完"**——还能稳定燃烧约 50 亿年

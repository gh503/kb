# 太阳最后会怎样

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 恒星的一生

## 结论

约 50 亿年后，太阳核心氢烧完，膨胀成**红巨星**，吞掉水星、金星，可能烤干地球；
然后外层被吹散成**行星状星云**，留下一个地球大小的**白矮星**，慢慢冷却。
**它不会变成超新星**——质量不够。

## 机制

1. 核心氢耗尽 → 核心收缩、升温 → 外层氢燃烧、膨胀
2. 太阳变成红巨星，半径可涨到地球轨道附近
3. 氦闪、氦聚变，产生碳和氧
4. 外层被抛射，形成行星状星云
5. 核心剩下碳氧白矮星，靠电子简并压支撑

## 量级

```text
红巨星阶段：约 50–70 亿年后
白矮星：质量约 0.5 倍太阳，半径约地球大小
超新星门槛：约 8 倍太阳质量以上
```

## 边界

- 地球会被吞没还是被烤干，取决于太阳质量损失后的轨道变化，模型有不确定性
- 白矮星有质量上限（钱德拉塞卡极限约 1.4 M☉），超过会继续坍缩
- 太阳不会变成黑洞
- 行星状星云与"星云假说"里的原始星云不是一回事

## 用得上

- 理解"恒星有寿命"，太阳不是永恒的
- 白矮星、中子星、黑洞的区别，本质是**质量**与**支撑机制**

## 误解

- **"太阳会爆炸成超新星"**——质量不够
- **"红巨星是燃烧更旺"**——是外层膨胀、表面变冷

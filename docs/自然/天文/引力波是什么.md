# 引力波是什么

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 黑洞与引力波

## 结论

引力波是**时空的涟漪**：加速运动的大质量天体扰动时空，扰动以光速向外传播，
经过时会让空间在某个方向上被拉伸、垂直方向被压缩。

## 机制

1. 广义相对论：质量弯曲时空，加速运动的质量会产生时空曲率的波动
2. 最主要的来源是**质量四极矩**的变化（球对称坍缩不辐射）
3. 波通过时，空间产生应变 h = ΔL/L
4. 应变极小，需要用极长的干涉臂放大效应
5. 双星并合、超新星、中子星自转都可能产生

## 量级

```text
LIGO 探测到的应变：约 10⁻²¹
4 km 臂长对应的长度变化：约 4×10⁻¹⁸ m（比质子半径还小）
引力波速度：光速
```

## 边界

- 引力波不是"引力子流"，是时空几何的波动
- 强度极弱，只有剧烈天体事件才可探测
- 频率范围宽：从纳赫兹（脉冲星计时）到千赫兹（并合）
- 引力波不带电，几乎不与物质作用，穿透性极强

## 用得上

- 引力波天文学提供了"听"宇宙的新方式，与电磁波互补
- 多信使观测（引力波 + 光）能定位事件、研究重元素合成

## 误解

- **"引力波是引力"**——是引力的波动，不是引力本身
- **"引力波会把人拉伸"**——应变太小，人体完全感觉不到

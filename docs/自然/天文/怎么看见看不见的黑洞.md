# 怎么看见看不见的黑洞

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 黑洞与引力波

## 结论

靠**它对周围的影响**：物质被吸进去前会绕成吸积盘、发出强 X 射线；
恒星会被它"拽着转"；它还会在背景上投出一个**暗影**。三条路都能"看见"。

## 机制

1. **吸积盘**：气体盘旋下落，摩擦加热到百万度，发出 X 射线
2. **恒星运动**：观测中心恒星的高速绕行，推算中心质量（银河系中心 Sgr A*）
3. **事件视界望远镜**：用全球射电望远镜组网，拍到 M87*、Sgr A* 的"阴影"
4. **引力透镜**：黑洞弯曲背景星光
5. **引力波**：并合时直接探测时空振动

## 量级

```text
M87* 质量：约 65 亿倍太阳质量
Sgr A* 质量：约 400 万倍太阳质量
EHT 分辨率：约 20 微角秒（相当于从地球看清月球上的一个苹果）
```

## 边界

- "阴影"不是黑洞本身，是视界周围光线被弯曲后形成的暗区
- 吸积盘亮度变化剧烈，观测需要多波段配合
- 恒星级黑洞多在 X 射线双星中被发现
- 孤立、不吸积的黑洞很难被发现

## 用得上

- 理解"间接观测"：看不见的东西，靠它对周围的作用来推断
- X 射线天文卫星（如 Chandra）是找黑洞的主要工具

## 误解

- **"照片上的黑圆就是黑洞"**——是阴影，包含视界与光子环
- **"黑洞不发光所以永远找不到"**——吸积盘很亮

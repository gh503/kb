# 怎么知道一颗星球有没有大气

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 系外行星

## 结论

靠**凌星时的透射光谱**：行星经过恒星前面时，一小部分星光穿过它的大气，
不同气体吸收特定波长。比较"有行星挡着"和"没挡着"的光谱，就能读出大气成分。

## 机制

1. 行星凌星时，星光穿过行星大气边缘
2. 大气中的分子吸收特定波长（如 H₂O、CO₂、CH₄、O₂）
3. 比较凌星中与凌星外的光谱，找出吸收特征
4. 也能测热辐射：行星从恒星背后经过时，亮度的变化给出温度
5. 需要极高信噪比，通常要合并多次凌星数据

## 量级

```text
凌星深度变化（大气贡献）：常为百万分之几到万分之一
詹姆斯·韦布空间望远镜（JWST）：擅长这类观测
首次探测到系外行星大气：2002 年（HD 209458b 的钠）
```

## 边界

- 只对"凌星 + 亮星 + 大氣"的行星有效
- 云、霾会"抹平"光谱特征
- 恒星本身的活動会干扰信号
- 探测到分子 ≠ 探测到生命

## 用得上

- 判断"有没有大气"是判断宜居的第一步
- 生物标志气体（如 O₂、CH₄ 共存）是下一步目标

## 误解

- **"看到水就是有生命"**——水很常见，生命是另一回事
- **"光谱能直接拍到表面"**——只能推断大气成分

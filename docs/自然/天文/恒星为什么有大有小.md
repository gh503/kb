# 恒星为什么有大有小

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 恒星的一生

## 结论

因为诞生时**云团的质量不同**。而质量几乎决定了恒星的一切：亮度、温度、寿命、最终结局。
质量越大，烧得越猛，寿命反而越短。

## 机制

1. 分子云在引力下坍缩，中心温度和密度升高
2. 质量够大（约 0.08 倍太阳质量以上）才能点燃氢聚变
3. 质量越大，核心压强和温度越高，聚变越剧烈
4. 光度随质量快速增长（大致 L ∝ M³·⁵）
5. 燃料多但烧得更快，所以大质量恒星寿命短得多

## 量级

```text
太阳：寿命约 100 亿年
10 倍太阳质量：寿命约几千万年
0.2 倍太阳质量：寿命可达上万亿年
```

## 边界

- 质量下限约 0.08 M☉，再小就是褐矮星，点不着火
- 质量上限约 100–300 M☉，再大辐射压会把外层吹散
- 质量决定结局：小质量→白矮星，大质量→中子星或黑洞
- 双星系统会改变演化路径（吸积、并合）

## 用得上

- 看星空：蓝白色星通常年轻、质量大；红色星多是老年的小质量星
- 太阳是"中等质量"，属于比较稳定的类型

## 误解

- **"大的恒星活得久"**——恰恰相反，越大死得越快
- **"恒星大小固定"**——演化过程中体积会剧烈变化（红巨星）

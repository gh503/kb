# 我们找到第二个地球了吗

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 系外行星

## 结论

**还没有。** 我们找到了不少"岩石行星 + 宜居带内"的候选，
但没有一颗被证实同时具备大气、液态水和生命迹象。"地球 2.0"目前是媒体说法，不是科学结论。

## 现状

1. 候选行星数以千计，但多数只能测到半径和质量
2. 真正能测大气的，只有少数"凌星 + 亮星"目标
3. 生物标志气体（O₂ + CH₄ 共存）尚未在任何系外行星上确认
4. JWST 正在观测几颗最有希望的岩石行星（如 TRAPPIST-1 系统）

## 为什么难

- 岩石行星信号极小，需要多次凌星叠加
- 恒星活动（黑子、耀斑）会伪装成大气信号
- "宜居带"只是距离条件，大气可以完全失控（如金星）
- 我们只有一个"已知有生命"的样本，无法校准判据

## 争议与未解

- **"地球相似指数"**之类指标，权重主观，不能等同于"宜居"
- 红矮星行星是否真能被宜居，取决于耀斑与大气逃逸，仍无定论
- 生物标志气体的**假阳性**（非生物过程也能产生）难以排除
- 即使探测到 O₂，也不能直接断言"有生命"

## 到此为止

这一层是**候选很多 + 确认极少**：说"找到了第二个地球"要有大气与生命证据，
目前没有一颗达到。

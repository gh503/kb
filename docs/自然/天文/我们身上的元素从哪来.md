# 我们身上的元素从哪来

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 恒星的一生

## 结论

**氢、氦来自大爆炸；碳、氧、氮、硅等来自恒星内部的核合成；铁以上的重元素来自超新星爆发
和中子星并合。** 你身体里的碳、氧、铁，都曾是某颗恒星的一部分。

## 机制

1. **大爆炸核合成**：产生氢、氦和少量锂（约 3 分钟窗口）
2. **恒星核合成**：氢→氦→碳→氧→氖→硅→铁，越往后越重
3. **铁**是聚变能量收支的拐点，再聚变要吸收能量
4. **s 过程**（慢中子俘获）：在 AGB 星中生成部分重元素
5. **r 过程**（快中子俘获）：超新星或中子星并合中生成金、铂、铀等

## 证据

- 光谱中的元素丰度与模型吻合
- 2017 年中子星并合事件（GW170817）观测到重元素合成的迹象
- 陨石中的同位素比值提供太阳系形成前的"配料表"

## 边界

- 不同元素的"产地"比例仍有不确定性
- r 过程的**主要站点**（超新星 vs 中子星并合）仍在争论
- 锂的问题：模型预测与大爆炸锂丰度对不上（"宇宙锂问题"）

## 争议与未解

- **r 过程站点**：普通超新星、磁旋转超新星、中子星并合，各贡献多少没有定论
- **宇宙锂问题**：观测到的锂比理论少约 3 倍，原因不明
- 元素丰度的观测误差与核反应速率的不确定性，都影响结论

## 到此为止

这一层是**框架清楚 + 细节未定**：元素来自恒星核合成是确定的，
但"某种元素具体由哪类天体造出来"仍有争议。

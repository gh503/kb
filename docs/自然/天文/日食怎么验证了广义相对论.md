# 日食怎么验证了广义相对论

> **学段** 大学–研究生 ｜ **类型** 机制（科学史） ｜ **链** 日食与月食

## 结论

因为日全食时太阳被挡住，能看到太阳边缘附近的恒星。
广义相对论预测星光经过太阳会被**偏折 1.75 角秒**，牛顿引力（把光当粒子）只给一半。
1919 年的观测结果支持了爱因斯坦。

## 机制

1. 太阳的质量弯曲周围时空，光线沿测地线传播
2. 偏折角 α ≈ 4GM/(c²R)，在太阳边缘约 **1.75″**
3. 牛顿式"光有质量被吸引"只给出约 0.87″
4. 日全食时，太阳附近的亮星可见，可测量其位置偏移
5. 与半年后（太阳不在该天区）的同一些恒星位置对比

## 1919 年观测

- 爱丁顿率队到普林西比岛，另一队到巴西索布拉尔
- 报告结果接近 1.75″，被广泛解读为支持广义相对论
- **历史争议**：原始底片质量、系统误差、数据处理方式后来被重新审视，
  有学者认为证据没有当时宣传的那么强

## 现代验证

- 射电干涉测量把精度提高到万分之一角秒量级
- 引力透镜、脉冲星计时、引力波观测都独立支持广义相对论
- 所以"1919 年一锤定音"是简化叙事，真正的确认来自后续几十年的多手段检验

## 到此为止

这一层是**科学史 + 观测方法**：偏折公式来自广义相对论（公理层），
1919 年观测是第一次检验，但不是唯一证据。

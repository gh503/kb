# 极光为什么是绿色的

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 极光

## 结论

因为最常见的极光来自**氧原子的一条特定跃迁**：从 ¹S 态回到 ¹D 态，放出 **557.7 纳米**的光，
正好落在人眼最敏感的绿区。更高的红色来自另一条跃迁，紫蓝色则来自氮分子离子。

## 机制

1. 高速粒子把氧原子的电子撞到高能级（¹S）
2. 电子落回 ¹D 时发光，波长 557.7 nm → 绿色
3. ¹D 再落回基态时发 630 nm → 红色，但这条跃迁很慢，原子容易先被撞掉能量，
   所以红色只出现在**更高、更稀薄**的大气里（200–400 km）
4. 氮分子离子（N₂⁺）在更低高度发 427.8 nm 等谱线 → 蓝紫色，常在极光底部

## 量级

```text
绿色 557.7 nm：高度约 100–150 km
红色 630 nm：高度约 200–400 km
紫色/蓝色：约 90–100 km，出现在极光下缘
```

颜色分层，本质上是**高度分层**——不同高度的大气成分和密度不同。

## 边界

- 人眼在暗处对颜色不敏感，很多极光肉眼看是灰白，照片才显绿
- 红色极光需要强扰动，平时较少见
- 极光颜色还会被大气中的氧、氮比例和碰撞频率影响

## 误解

- **"极光的颜色是滤镜调出来的"**——真实存在，只是相机长曝光更容易记录
- **"绿色是氧、红色是氮"**——红色也主要来自氧，氮主要贡献紫蓝色

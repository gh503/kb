# 极光会干扰什么

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 极光

## 结论

极光本身无害，但它标志的**地磁暴**会干扰技术系统：电网感应电流、卫星轨道与电子设备、
GPS 定位、高频通信。**空间天气的预报精度仍然有限**，这是本库标注的**未解**之一。

## 机制

1. 地磁暴时，电离层电流体系变化，在地面诱发电场
2. 长距离输电线、管道相当于天线，感应出直流电流（GIC）
3. 变压器半波饱和、过热，严重时烧毁（1989 年魁北克大停电是典型案例）
4. 高层大气受热膨胀，卫星阻力增大，轨道衰减加快
5. 电离层扰动改变无线电传播，GPS 单频定位误差增大

## 边界

- 影响程度取决于**电网结构、纬度、持续时间**，不是"有极光就停电"
- 现代电网有防护措施，但极端事件的余量有限
- 卫星可以通过轨道调整和关机规避，代价是服务中断
- 航空极区航线会改道，避开通信与辐射风险

## 未解与争议

- **太阳风的到达时间与耦合效率**预测仍有较大误差，尤其是日冕物质抛射的方向
- 极端地磁暴的**重现期**估计，依赖历史记录与冰芯、树轮等替代指标，不确定性大
- 电网级联失效的建模，涉及工程与社会因素，难以验证

## 到此为止

这一层是**未解 + 工程取舍**：物理机制清楚（磁层—电离层—地面耦合），
但"下一次大事件有多强、什么时候来"无法准确预报。

# 物理

> 物质和能量怎么运转。

## 收什么

- 直觉解释：一个现象为什么这样，不用公式也能讲通
- 常见误解纠正：比如"重的先落地""真空里没有重力"
- 量级估算：先估个数，判断某方案是否离谱

## 不收什么

- 公式推导教材
- 用玄学类比代替机制（"量子"不是万能形容词）

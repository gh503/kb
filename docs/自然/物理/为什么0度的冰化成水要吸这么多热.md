# 为什么 0℃ 的冰化成水要吸这么多热

> **学段** 大学–研究生 ｜ **类型** 机制（含未解） ｜ **链** 蒸发与相变

## 结论

熔化潜热约 **334 kJ/kg**：化 1 kg 冰要的热量，够把 1 kg 水从 0℃ 烧到 80℃。
而且这个过程**温度不上升**——能量全用在拆开氢键网络上，没有变成分子动能。

## 机制

1. 冰里水分子靠氢键排成有序结构，要让它变成能流动的液体，必须把这些键拆开
2. 拆键要能量，这部分能量不体现为温度升高，所以冰水共存时温度**恒定在 0℃**
3. 这就是为什么冰镇饮料能稳定停在 0℃：加多少热都先去化冰，温度不动
4. 反过来，水结冰要**放出**同样的热量——所以结冰的湖面能保护下面的水不继续冻

## 边界

- 相变平台只存在于**纯净物、定压**的条件下；混合物（如盐水）在一定的温度区间内逐渐融化
- 纯净的水可以**过冷**到约 −40℃ 还不结冰——它缺一个"成核点"，不是在等温度
- 撒盐化冰不是"加热"，是降低熔点，让冰在更低温度就能化（同时吸热）

## 争议与未解

- **冰的成核**至今是大气科学里最不确定的环节之一：云里到底靠哪些粒子（冰核）开始结冰，
  直接决定云的生命期和降水，也影响气候模型的云反馈
- 均相成核理论（经典成核理论）能给出量级，但对复杂冰核的预测仍偏差很大
- 所以"云什么时候结冰"是本库标注为**未解**的一类问题，不是公理

## 到此为止

再往下问"氢键为什么有这么大的能量"，就落到**分子间作用力与量子化学**；
问"能量为什么守恒"，是热力学第一定律——本库在此标为**公理层**。

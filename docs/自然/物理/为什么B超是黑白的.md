# 为什么B超是黑白的

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 超声

## 结论

因为图像编码的是**回声强弱**：回声强的地方亮、弱的地方暗、没有回声的地方黑。
这是一张"反射率地图"，不是光学照片，所以本来就没有颜色。

## 机制

1. 两种组织的**声阻抗**差别越大，界面反射越强
2. 反射强的界面（如骨骼、筋膜）→ 亮白
3. 液体（如尿液、羊水）几乎不反射 → 黑（无回声）
4. 软组织之间差别小 → 灰
5. 医生看的是"亮暗对比 + 形态"，不是颜色

## 量级

```text
声阻抗 = 密度 × 声速
软组织：约 1.5–1.7 × 10⁶ Pa·s/m
骨骼：约 4–8 × 10⁶ Pa·s/m（差别大 → 强反射）
空气：约 400 Pa·s/m（与软组织差别极大 → 几乎全反射）
```

## 边界

- "黑白"不等于"落后"，灰阶能分辨很小的阻抗差异
- 彩色多普勒是叠加的**血流信息**，不是"彩色照片"
- 有些设备用伪彩增强对比，但那是后期映射
- 亮度还受增益调节影响，同一结构可以调亮调暗

## 用得上

- 报告上的"高回声/低回声/无回声"就是亮暗的描述
- 结石、钙化常表现为强回声 + 后方声影

## 误解

- **"黑白说明设备差"**——超声本质就是回声强度图
- **"彩色B超更准"**——彩超的彩色是血流方向与速度

# 为什么会有彩虹

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 彩虹

## 结论

因为阳光射进空气中的**小水滴**，进去时被折射（分色），在水滴背面反射一次，出来时再折射一次。
不同颜色的光偏折角度不同，于是被分开成一个**约 42° 的圆锥**——你站在锥顶，就看到了弧。

## 机制

1. 阳光进入水滴，第一次折射：不同颜色偏折角不同（紫比红偏得多）
2. 光在水滴内壁反射一次
3. 出来时再折射一次，颜色被进一步分开
4. 主虹的**红色约在 42°、紫色约在 40°**（相对你与太阳连线的夹角）
5. 所有满足这个角度的水滴构成一个圆锥，你看到的就是一段圆弧

## 用得上（怎么找彩虹）

- **背对太阳**站着，太阳越低，彩虹越高
- 太阳高度超过约 42° 时，彩虹整个在地平线以下，看不到
- 喷泉、瀑布、洒水车旁边最容易人为制造

## 边界

- 彩虹不是"挂在天上"的物体，它是**方向**上的现象：每个人看到的彩虹都不一样
- 水滴越大，颜色越鲜艳；雾滴很小时会变成白色的**雾虹**
- 月光也能造彩虹（月虹），但很暗，肉眼常看成白色

## 误解

- **"彩虹是天空里的一条彩带"**——它是光线方向形成的圆锥，你一动，它跟着动
- **"彩虹有七种颜色"**——连续光谱，分成几色是人定的

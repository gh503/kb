# 为什么会有静电

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 电与磁

## 结论

因为两种不同材料摩擦时，**电子会从一方跑到另一方**，于是两边一个多电子、一个少电子，
带上等量异号的电荷。电荷没有消失，只是重新分配了。

## 机制

1. 原子由带正电的原子核和带负电的电子组成，正常时电量相等
2. 两种材料接触，电子"亲疏"不同，会向一边转移
3. 分开后，失去电子的带正电，得到电子的带负电
4. 绝缘体上电荷不易流走，会积累起来——这就是静电
5. 积累到一定程度，会通过空气放电（火花、噼啪声）

## 边界

- 静电不是"摩擦产生电荷"，是**电荷转移**，总电荷守恒
- 干燥环境更容易积累：潮湿空气导电性稍好，电荷会慢慢跑掉
- 导体上的静电会迅速分布到表面，不容易局部积累
- 静电电压可以很高（上千伏），但电量极小，通常不致命

## 用得上

- 冬天摸门把手被电：先摸一下墙或木桌，把电荷放掉
- 加油站禁止穿脱化纤衣物：静电火花可能点燃油气
- 电子元件怕静电，维修要戴防静电手环

## 误解

- **"摩擦产生了电"**——是电子转移，不是凭空产生
- **"静电电压高就很危险"**——能量小，通常只是"啪"一下

# 为什么会近视

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 视觉与光

## 结论

因为眼的折光系统"太强"或眼球"太长"，远处物体的像**落在视网膜前面**，
到达视网膜时已经散开，所以看远模糊。看近处时像能往后移，所以近处清楚。

## 机制

- **轴性近视**：眼轴过长（最常见），像距不够
- **屈光性近视**：角膜或晶状体折光力过强
1. 平行光（远处物体）经角膜、晶状体后会聚
2. 会聚点落在视网膜之前
3. 到视网膜时已成发散光束 → 模糊
4. 凹透镜先让光发散一点，把会聚点"推后"到视网膜上

## 量级

```text
正常眼轴：约 24 mm
眼轴每增长 1 mm，约对应 −3.00 D 的近视
-3.00 D 大致是"看 33 cm 以外开始模糊"
```

## 边界

- 近视有遗传因素，也有环境因素（近距离用眼、户外时间少）
- 户外光照被认为有保护作用，机制与多巴胺、光照强度有关
- 近视度数高（> −6.00 D）要定期查眼底，视网膜脱离风险升高
- 假性近视是睫状肌痉挛，散瞳后可恢复，不等于真性近视

## 用得上

- 每天户外 2 小时，是目前证据较强的预防措施
- 20-20-20：每 20 分钟看 20 英尺外 20 秒
- 不要在暗处长时间近距离用眼

## 误解

- **"近视是眼睛'太累'造成的"**——是眼轴/屈光结构改变，疲劳是诱因之一
- **"戴眼镜会让度数加深"**——没有证据；不戴反而可能加重疲劳

# 为什么保温杯用久了就不保温了

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 保温

## 结论

因为**真空夹层漏气了**。跌落、碰撞、焊接处疲劳会让夹层进空气，
真空度一掉，气体导热立刻回来，保温性能是断崖式下降，不是慢慢衰减。

## 机制

1. 夹层靠焊接或封接维持真空，机械冲击会造成微裂
2. 不锈钢在反复热循环下，封接处产生应力疲劳
3. 夹层里通常放**吸气剂**（getter）吸收残余气体，吸气剂饱和后就不再兜底
4. 一旦漏气，导热系数从 0.004 跳回 0.02 W/(m·K) 量级

## 边界

- 有些失效是**缓慢**的：吸气剂逐渐饱和，几年内性能下降
- 有些是**突发**的：一次跌落就废
- 真空度无法从外部直接测量，只能靠"摸外壁温度"间接判断

## 未解与前沿

- **真空绝热板（VIP）的寿命预测**是建筑节能领域的难题：气体渗透速率、
  吸气剂容量、环境温湿度共同决定寿命，实验室加速老化与实际使用对不上
- 芯材（气相二氧化硅、玻璃纤维）的长期性能衰减缺乏统一模型
- 所以工程上只能给"设计寿命 + 安全系数"，不能精确预测

## 到此为止

这一层是**工程经验 + 未闭合的模型**：机制清楚（漏气 → 导热回升），
但"什么时候漏、漏多快"依赖材料缺陷的随机性，本库标为**未解**。

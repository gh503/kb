# 为什么保温杯装冰水也保温

> **学段** 高中–大学 ｜ **类型** 边界 ｜ **链** 保温

## 结论

因为保温杯减少的是**热流**，不是"加热"或"制冷"。热总是从高温流向低温，
装冰水时方向反过来：外面的热想进来，真空层同样挡住了它。

## 机制

1. 装热水：热从杯内流向环境
2. 装冰水：热从环境流向杯内
3. 真空层、低发射率内壁对两个方向同样有效
4. 所以"保温"和"保冷"是同一件事的两面

## 边界

- 装冰水时，**杯口和盖子**的漏热占比更大：冷空气下沉、热空气从缝隙进入
- 杯子外壁可能结露，那是环境水汽凝结，不是漏水
- 反复开关盖子，冷量损失远大于保温杯本身的漏热
- 装碳酸饮料要小心：晃动 + 升温会增压

## 用得上

- 夏天带冰水，杯子先预冷（放冰块摇一摇倒掉）效果更好
- 保温杯不适合长期存放牛奶、豆浆：温度合适时细菌繁殖快

## 误解

- **"保温杯只能保热"**——它保的是"温度差"，方向无关
- **"装冰水会损坏真空层"**——不会，热胀冷缩的应力远小于跌落冲击

# 为什么光纤能传信号

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 激光与光

## 结论

因为光从光密介质射向光疏介质时，入射角足够大就会**全反射**——
光被"关"在纤芯里，沿着玻璃丝一路弹着走，几乎不泄漏。

## 机制

1. 光纤由高折射率的纤芯和低折射率的包层组成
2. 光在界面处入射角大于临界角 → 全反射，无折射损失
3. 光在纤芯内反复反射前进
4. 单模光纤纤芯很细（约 9 μm），只允许一种模式传播，色散小
5. 用不同波长（WDM）可同时传多路信号

## 量级

```text
石英光纤衰减：约 0.2 dB/km（1550 nm 窗口）
临界角：由折射率差决定
单模纤芯直径：约 8–10 μm
```

## 边界

- 光纤怕弯折：弯太急会漏光
- 衰减、色散限制传输距离，需要放大与补偿
- 光纤不导电、抗电磁干扰，适合长距离与恶劣环境
- 光纤传感可测温度、应变、振动

## 用得上

- 家庭宽带"光猫"就是把光信号转成电信号
- 光纤入户比铜缆带宽大得多
- 内窥镜、光纤传感器是同一原理的不同应用

## 误解

- **"光纤里光走直线"**——是反复全反射
- **"光纤越粗越好"**——单模光纤细，反而色散小

# 为什么光能夹住东西

> **学段** 大学–研究生 ｜ **类型** 机制 ｜ **链** 激光与光

## 结论

因为光**携带动量**，照射物体时会施加极小的力（光压）。
用高度聚焦的激光，可以在焦点处形成"光镊"，把微米级的颗粒、细胞"夹"住并移动。

## 机制

1. 光子动量 p = E/c，被吸收或偏折时动量改变 → 对物体施力
2. 高斯光束中心强、边缘弱，颗粒被"梯度力"拉向焦点
3. 同时有沿传播方向的"散射力"，两者平衡时可稳定捕获
4. 力很小，但对微米颗粒足够
5. 光镊可在不接触的情况下操纵细胞、DNA、微粒

## 量级

```text
光压：太阳光在地球附近约 4.5 μPa（完全吸收）
光镊力：皮牛（10⁻¹² N）量级
可捕获颗粒：几十纳米到几十微米
```

## 边界

- 光镊力极小，只能操纵微小物体
- 需要高数值孔径物镜聚焦
- 激光加热可能损伤活细胞，要用低吸收波长
- 光镊与激光冷却不同：前者操控位置，后者降低温度

## 用得上

- 生物物理：拉伸 DNA、测分子马达的力
- 2018 年诺贝尔物理学奖授予光镊（Ashkin）
- 激光冷却（1997 年诺奖）用光"刹车"原子

## 误解

- **"光没有质量所以没有力"**——有动量，就有光压
- **"光镊是科幻牵引光束"**——尺度只在微米级

## 到此为止

再往下问"为什么光子有动量"，是**相对论能量—动量关系**；
问"为什么梯度力指向焦点"，是电磁场的偶极相互作用——到这一层是光学与电动力学。

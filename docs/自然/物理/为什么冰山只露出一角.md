# 为什么冰山只露出一角

> **学段** 初中–高中 ｜ **类型** 量级 ｜ **链** 浮力

## 结论

因为冰的密度约 0.92，海水约 1.025，比值约 0.90。
所以冰山有**约九成浸在水下**，只有一成露出来——"冰山一角"是物理事实，不是比喻。

## 怎么算

```text
漂浮条件：ρ冰 × V总 = ρ海水 × V浸没
V浸没 / V总 = ρ冰 / ρ海水 = 0.92 / 1.025 ≈ 0.90
露出比例 ≈ 10%
```

## 边界

- 淡水里的冰山露出更多（ρ淡水 = 1.00，露出约 8%）；海水里露出约 10%
- 冰的密度随温度和气泡含量变化，冰川冰可低到 0.85
- 冰山形状不规则，露出部分不代表整体形状
- 冰山翻转是常事：露出的一角融化后重心改变

## 用得上

- 航行危险：水下的九成比看到的更大、更宽
- 估算冰山体积：看露出部分，乘约 10 倍
- 海平面上升：冰山融化对海平面影响很小（它已经排开了水），陆地冰川融化才是主因

## 误解

- **"冰山露出越多说明冰越轻"**——是密度比决定的
- **"冰山融化会让海平面明显上升"**——漂浮冰融化几乎不改变海平面

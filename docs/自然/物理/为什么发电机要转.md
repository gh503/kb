# 为什么发电机要转

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 电与磁

## 结论

因为**变化的磁场能产生电**（电磁感应）。让磁铁和线圈相对转动，
穿过线圈的磁通量不断变化，就持续产生电动势——转动是"制造变化"的手段。

## 机制

1. 法拉第发现：穿过闭合回路的磁通量变化，会产生感应电动势
2. 公式：ε = −dΦ/dt（负号是楞次定律：感应电流阻碍变化）
3. 发电机让转子（磁极或线圈）旋转，磁通量周期性变化
4. 产生的交流电频率 = 转速 × 极对数
5. 机械能 → 电能，靠的是磁场这个"中介"

## 量级

```text
中国电网频率：50 Hz
四极发电机：转速 1500 rpm 即可输出 50 Hz
（50 Hz × 60 s ÷ 2 对极 = 1500 rpm）
```

## 边界

- 不转也能发电：只要磁通量变化（如变压器、感应炉）
- 水力、风力、燃煤、核电，最终都是"转"——区别只在用什么推动转子
- 光伏发电是例外：光直接激发电子，不经过"转"
- 超导发电机可以做到更高效率，但需低温

## 用得上

- 理解"新能源"：风机、水轮机本质都是原动机 + 发电机
- 电网频率稳定 = 转速稳定，所以频率是电网的"心跳"

## 误解

- **"发电机自己产生电"**——它转换能量，不创造电荷
- **"只要磁铁靠近就有电"**——要**变化**才有持续电流

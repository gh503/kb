# 为什么小虫子能站在水面上

> **学段** 大学–研究生 ｜ **类型** 边界（尺度） ｜ **链** 浮力

## 结论

因为**表面张力**。水面的分子被向内拉，形成一层"绷紧的膜"，能托住很小的重量。
但表面张力随尺寸按**长度**增长，重量按**体积**（长度的三次方）增长——
所以只有很小的生物能靠它站住，放大到人就不行了。

## 机制

1. 水分子之间有氢键，表面分子缺少上方的邻居，能量更高
2. 这层"高能表面"表现为张力，约 72 mN/m（20℃）
3. 水黾的腿有疏水微毛，不会刺破水面，只把水面压出一个小凹坑
4. 凹坑的边缘张力提供向上的合力
5. 尺度放大后，重量增长远快于表面张力，支撑不住

## 量级

```text
表面张力：σ ≈ 0.072 N/m
一根 1 cm 长的接触线，最大支撑力 ≈ σ × L ≈ 7×10⁻⁴ N，
约等于 0.07 克——刚好是一两只水黾的量级
```

用**邦德数**（Bo = ρgL²/σ）可以判断表面张力是否重要：L 越小，Bo 越小，表面力越占主导。

## 边界

- 加肥皂会降低表面张力，水黾立刻"沉"下去——这是课堂经典演示
- 温度升高，表面张力下降
- 大物体（硬币）能被托住，是因为它薄且平，接触线长；一旦倾斜就破
- 表面张力只在小尺度、静止或慢速时显著

## 用得上

- 洗涤剂"润湿"就是降低表面张力，让水钻进织物缝隙
- 农药、涂料里加表面活性剂，改善铺展
- 微流控芯片靠表面张力驱动小液滴

## 到此为止

再往下问"为什么水分子间有氢键"，是**分子间作用力与电负性差**；
问"为什么表面分子能量高"，是热力学——本库在此标为**公理层**。

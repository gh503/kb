# 为什么打雷是轰隆隆的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 声音

## 结论

因为**光跑得比声音快得多**，而且雷不是一个点发出来的：
闪电通道有几公里长，各段的声音到达你耳朵的时间不一样，再加上云层和地面的反射，
就拖成了"轰——隆——隆"。

## 机制

1. 先看到闪电、后听到雷：声音在空气里每秒约 340 米
2. 闪电是一条几公里长的通道，每一小段都在发声
3. 离你近的那段声音先到，远的那段晚到几秒——声音被"拉长"了
4. 声音在云底、地面、山体之间来回反射，又叠了几层回声

## 用得上（数秒估距离）

```text
看到闪电开始数，听到雷声停下：秒数 ÷ 3 ≈ 公里数
3 秒 ≈ 1 公里，9 秒 ≈ 3 公里
```

如果闪电和雷几乎同时到，说明就在头顶，要找地方躲。

## 边界

- **近处的雷是"炸"的一声**，不是隆隆的：通道短、声音几乎同时到达
- 超过二三十公里通常听不到：能量衰减，声线还会被温度分层折射向上
- 雷声的"滚"也和山谷、建筑反射有关，同一场雷在不同地方听起来不一样

## 误解

- **"雷声是云撞在一起发出的"**——是闪电通道瞬间加热空气，空气爆炸性膨胀产生的冲击波
- **"闪电和雷同时发生"**——是同时，只是光先到

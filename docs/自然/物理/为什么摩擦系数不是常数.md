# 为什么摩擦系数不是常数

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 摩擦与热

## 结论

中学课本的 `f = μN` 是**经验近似**。真实的摩擦取决于**真实接触面积、表面粗糙度、
第三体（磨屑、油膜、氧化层）、速度、温度**——所以 μ 会随工况变，**不是材料常数**。

## 机制

1. 两个"平面"实际只在少数微凸体上接触，真实接触面积远小于名义面积
2. 真实接触面积随载荷增大（微凸体塑性变形），这是 `f ∝ N` 的来源
3. 接触点会发生黏着，滑动时要剪断这些黏着点
4. 磨屑、氧化层、吸附水构成"第三体"，它才是实际承载和剪切的对象
5. 速度、温度改变第三体的状态 → μ 变化

## 边界

- **静摩擦 > 动摩擦**：启动要克服黏着，滑动后黏着被不断剪断
- 速度依赖：有些系统摩擦随速度**下降**（导致黏滑、啸叫、地震的"黏滑"模型）
- 温度依赖：高温软化、氧化、润滑剂失效
- 尺度效应：纳米尺度下，摩擦与表面力、毛细力相关
- 超润滑：特定条件下 μ 可低到 10⁻³ 量级

## 量级

```text
干燥金属对金属：μ 约 0.3–0.8
加润滑油：μ 可降到 0.01–0.1
冰对冰：μ 约 0.02–0.1（视温度）
```

## 用得上

- 刹车"热衰退"就是 μ 随温度下降的直接后果
- 机床导轨用油膜，是把"两体接触"换成"流体润滑"
- 地震的黏滑模型，本质就是断层摩擦的速度依赖

## 未解与争议

- 从原子尺度到工程尺度的**跨尺度摩擦定律**仍未建立
- 第三体的力学行为难以原位观测
- 超润滑的稳定性与寿命，距离工程应用还有距离

## 到此为止

这一层是**模型边界**：`f = μN` 在工程上够用，但它不是物理定律，
μ 也不是材料的固有属性。再往下是表面物理与摩擦学，仍在发展中。

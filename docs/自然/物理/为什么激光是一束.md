# 为什么激光是一束

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 激光与光

## 结论

因为激光靠**受激辐射**工作：一个光子"诱导"原子放出**一模一样**的光子，
这些光子频率相同、相位一致、方向相同，于是叠成一束又亮又集中的光。

## 机制

1. 原子吸收能量后处于激发态
2. 一个光子经过，诱导它放出第二个光子，两者完全相同（受激辐射）
3. 用谐振腔让光来回反射，不断放大
4. 需要"粒子数反转"：激发态原子多于基态
5. 输出的是相干光：单色、方向性好、亮度高

## 与普通光的对比

| | 普通光 | 激光 |
| --- | --- | --- |
| 相位 | 随机 | 一致（相干） |
| 频率 | 宽 | 窄（单色） |
| 方向 | 四面八方 | 高度集中 |
| 亮度 | 较低 | 可极高 |

## 边界

- 激光不是"一种新物质"，是光的组织方式不同
- 不同激光器波长不同：红光、绿光、蓝光、红外、紫外
- 激光也会发散，只是发散角很小
- 高功率激光可以切割金属，低功率可用于测距

## 误解

- **"激光是放大的光"**——是受激辐射放大，关键在"相干"
- **"激光一定很危险"**——按功率分级，低功率用于扫码、测距

## 用得上

- 激光笔、扫码枪、光纤通信、激光手术，都是不同功率的激光
- 激光测距、雷达靠的是极短脉冲的时间差

# 为什么热总是从热到冷

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 温度与热

## 结论

因为**熵增**：热量从高温流向低温，会让整个系统的微观状态数变多，也就是更"混乱"。
反向流动不是绝对不可能，而是概率小到在宏观尺度上永远看不到。

## 机制

1. 热力学第二定律：孤立系统的熵不减
2. 统计力学解释：熵 ∝ 微观状态数的对数 `S = k ln W`
3. 能量均匀分布对应的微观状态数远多于"集中在一处"
4. 所以热从热到冷是"从少概率到多概率"
5. 时间之箭就来自这个统计方向

## 量级

```text
一杯水里约有 10²⁵ 个分子
"所有分子同时聚到一半"的概率小到可以忽略
所以宏观上不可逆
```

## 边界

- 第二定律是统计性的，不是绝对禁令
- 局部可以变冷（冰箱、生命），但要消耗更多能量、整体熵仍增
- 引力系统（恒星、黑洞）熵的计算更复杂
- 涨落定理描述了小系统短时间的"逆流"概率

## 用得上

- 冰箱不是"违反第二定律"，是把热搬到外面，代价是电
- 永动机不可能，因为能量耗散不可逆
- 信息处理也有热耗散（见下一条）

## 误解

- **"热不能从冷到热"**——可以，但要付出代价（做功），且整体熵增
- **"熵增就是越来越乱"**——更准确是"微观状态数增加"

# 为什么短波散射更强

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 彩虹

## 结论

因为散射体远小于波长时，散射强度与波长的四次方成反比。
**λ 减半，散射强 16 倍。**

## 机制

1. 入射光的电场让分子内电荷分布偏移，形成一个随光频率振荡的偶极子
2. 振荡偶极子向外辐射电磁波，这就是"二次辐射"，即散射
3. 偶极辐射的功率 ∝ 加速度的平方，而加速度 ∝ ω²（振动越快，加速度越大）
4. 于是功率 ∝ ω⁴ ∝ 1/λ⁴

量纲上也能看出：偶极辐射功率 P ∝ p̈²，偶极矩 p ∝ 极化率 × E，
两次对时间求导各带出一个 ω，平方之后就是 ω⁴。

## 边界

- 只在 **粒子尺度 d ≪ λ** 时成立。d 接近或超过 λ 时进入米氏散射，
  波长依赖急剧变弱，这就是云和雾发白的原因。
- 1/λ⁴ 说的是**散射截面**；你看到的亮度还要再乘太阳光谱和人眼响应。

## 到此为止

再往下问"为什么加速电荷会辐射、为什么功率正比于加速度平方"，
答案就是**麦克斯韦方程组**——拉莫尔公式是它的解。

而"麦克斯韦方程组为什么长这样"，在本库是**终点**：它是当前物理的基本假设与实验总结，
不是从更基本的东西推出来的。这类终点要**标明类型**，否则会被误读成"还没搞懂"。

!!! note "三种终点"
    - **公理 / 定义**：我们这样假设或这样约定（如麦克斯韦方程组、皮亚诺公理）
    - **未解**：确实不知道（如"为什么希格斯场有非零真空期望值"）
    - **尺度极限**：在这个尺度上问题本身失去意义（如"比普朗克长度更小的地方发生了什么"）

    写条目时把终点属于哪一种写清楚，比多写三段推导更有价值。

# 为什么磁铁有磁性

> **学段** 大学–研究生 ｜ **类型** 机制 ｜ **链** 电与磁

## 结论

因为**电子的自旋和轨道运动本身就是微小磁体**。在铁、钴、镍这类材料里，
相邻原子的磁矩会自发平行排列，形成一个个"磁畴"；磁畴整体取向一致时，宏观上就是磁铁。

## 机制

1. 每个电子有自旋磁矩，绕核运动也产生磁矩
2. 在铁磁材料中，量子交换作用让相邻自旋倾向于同向排列
3. 材料分成许多**磁畴**，每个磁畴内部取向一致，但畴间方向不同
4. 外加磁场让磁畴转向、长大 → 材料被磁化
5. 去掉外场后，部分取向保留 → 剩磁，成为永磁体

## 边界

- 加热到**居里温度**以上，热运动破坏有序排列，磁性消失（铁约 770℃）
- 软磁材料（如硅钢）容易磁化也容易退磁，适合做变压器铁芯
- 硬磁材料（如钕铁硼）剩磁强、矫顽力大，适合做永磁体
- 磁单极子至今未被发现，磁场总是"成对"的

## 量级

```text
铁的居里温度：约 770℃
钕铁硼永磁：剩磁可达 1.4 T 量级
地磁场：约 5×10⁻⁵ T（比永磁体弱得多）
```

## 用得上

- 磁铁摔打、加热会退磁：磁畴被打乱
- 硬盘、电机、扬声器、MRI，都依赖磁性材料
- 磁卡不要靠近强磁体，以免数据被改写

## 到此为止

再往下问"为什么自旋会产生磁矩"，是**量子力学与相对论**（自旋是内禀角动量）；
问"为什么交换作用让自旋同向"，是固体物理的多体问题——本库标为**公理层**。

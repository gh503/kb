# 为什么绝对零度达不到

> **学段** 初中–高中 ｜ **类型** 边界 ｜ **链** 温度与热

## 结论

因为降温的本质是**把能量抽走**，而抽得越干净越难抽；而且量子力学要求系统保留**零点能**，
不可能完全静止。热力学第三定律说：**只能无限逼近，不能达到**。

## 机制

1. 温度对应分子运动，降温就是让分子慢下来
2. 常用方法：蒸发冷却、激光冷却、磁冷却
3. 越接近 0 K，能抽走的能量越少，效率越低
4. 量子力学：即使在最低能态，仍有零点振动
5. 第三定律：有限步骤无法把系统降到 0 K

## 量级

```text
实验室最低温度：约 10⁻¹⁰ K 量级（纳开甚至皮开）
宇宙微波背景：2.7 K
自然界最冷的地方：回力棒星云约 1 K
```

## 边界

- "达不到"是原理性的，不是技术不够
- 负温度（某些自旋系统）不是"比绝对零度更冷"，而是更热
- 超流、超导在低温出现，但不需要到 0 K
- 绝对零度附近，经典热力学让位给量子统计

## 用得上

- 低温物理支撑 MRI、超导、量子计算
- 液氦（4 K）是常见低温介质

## 误解

- **"再努力一点就能到 0 K"**——原理上不允许
- **"0 K 时一切静止"**——还有零点能

# 为什么船能浮在水上

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 浮力

## 结论

因为水会从下面往上"顶"——这个向上的力等于**船排开的那部分水的重量**（阿基米德原理）。
只要排开的水比船本身重，船就浮着。

## 机制

1. 物体浸进水里，占据了一块空间，周围的水位被抬高
2. 被排开的水原本要被重力压下去，于是它给物体一个向上的反作用
3. 这个力叫浮力，大小 = 排开液体的重量 = ρ液 × g × V排
4. 船越往下沉，排开的水越多，浮力越大，直到与船重平衡
5. 平衡时，船就稳定在某个吃水深度

## 量级

```text
1 立方米的船体，完全浸没排开 1 吨水
只要船 + 货物 < 1 吨，它就浮着
```

## 边界

- 浮力与物体材质无关，只与**排开液体的体积和密度**有关
- 海水比淡水浮力大，所以船从河里开进海里会略微上浮
- 船翻了、进水了，排开体积变小或进水增重，浮力就不够了
- 温度影响液体密度，热水的浮力略小

## 误解

- **"船浮着是因为木头轻"**——铁船也浮，关键在排水体积
- **"浮力是水往上推，因为水被压"**——是压力差造成的，底部压力大于顶部

## 用得上

- 载重线（吃水线）就是"还能加多少"的物理刻度
- 救生衣靠增大排开体积 + 低密度来提供浮力

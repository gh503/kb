# 为什么近视镜是凹透镜

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 视觉与光

## 结论

因为近视眼的会聚"过头"了，需要先**发散**一点，把像往后推到视网膜上。
凹透镜（中间薄、边缘厚）对光有发散作用，正好抵消过强的折光力。

## 机制

1. 近视眼：平行光会聚在视网膜**前**
2. 凹透镜使入射光先发散，等效于"减弱"眼的折光力
3. 会聚点后移，落到视网膜上
4. 度数用屈光度 D 表示：`D = 1 / f（米）`
5. 凹透镜焦距为负，所以近视镜是**负度数**

## 怎么算

```text
-3.00 D 的镜片：f = 1 / (−3.00) = −0.333 m
意思是：平行光入射后，看上去像是从前方 33 cm 处发出的
```

远点：近视者能看清的最远距离约等于镜片焦距的绝对值（粗略）。

## 边界

- 度数越高，镜片边缘越厚，像差与畸变越明显
- 高度近视建议选高折射率镜片，减小厚度
- 隐形眼镜贴角膜，顶点距离不同，度数换算与框架镜略有差异
- 激光手术是"削平角膜"改变折光力，不是"治好眼轴"

## 用得上

- 配镜要验光，不要按旧度数直接买
- 眼镜不要长期放高温处（车内），镀膜会坏
- 运动时可选树脂镜片，安全

## 误解

- **"凹透镜把像'缩小'所以看得清"**——关键是发散，把焦点后移
- **"度数越高镜片越厚就越好"**——厚是缺点，不是优点

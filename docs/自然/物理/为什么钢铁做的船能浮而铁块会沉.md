# 为什么钢铁做的船能浮而铁块会沉

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 浮力

## 结论

因为决定浮沉的不是材料，而是**整体平均密度**。铁块实心，平均密度 7.8 > 水，沉；
船是空心的，把空气包进去，整体平均密度 < 1，浮。

## 机制

1. 浮力只看**排开水的体积**，与里面装的是铁还是空气无关
2. 空心结构让同样重量的铁占据大得多的体积
3. 平均密度 = 总质量 / 总排水体积
4. 平均密度 < 水的密度 → 浮；> → 沉
5. 船的"稳性"还取决于重心与浮心的相对位置

## 量级

```text
铁的密度 7.8 g/cm³
把铁做成空心壳体，使平均密度 < 1.0 g/cm³ 即可漂浮
一艘 10 万吨的船，排水体积约 10 万立方米
```

## 边界

- 空心但密封不好，进水后平均密度上升，浮力不足
- 稳性与浮力是两件事：能浮的船也可能翻（重心太高）
- 潜艇靠压载水舱改变平均密度，实现下潜与上浮
- 密度不是唯一因素：表面张力对很小的物体也有影响

## 用得上

- 判断"这东西会不会沉"：算平均密度，不要看材料
- 救生衣、浮力材料都是"用低密度填充换取排水体积"

## 误解

- **"铁一定沉"**——铁船、铁皮盒都能浮
- **"浮力大的船更稳"**——浮力与稳性是两回事

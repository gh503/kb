# 为什么镜子只反左右不反上下

> **学段** 小学–初中 ｜ **类型** 误区 ｜ **链** 光与镜面

## 结论

镜子**既不反左右也不反上下**，它只反**前后**——沿着镜面法线把空间翻了个面。
"左右反了"是你把镜中那个像当成"一个面向你的人"来解读造成的错觉。

## 机制

1. 平面镜把每个点映射到镜后的对称位置：`x → −x`（取垂直于镜面的方向）
2. 垂直于镜面的方向（前后）被翻转，平行于镜面的方向（上下、左右）**都不变**
3. 你举右手，镜里的像在**它的**左侧举手——但它的"左"和你的"右"是同一个空间方向
4. 大脑习惯把像当成"另一个面向我的人"，于是自动做了左右互换的翻译

## 一个能自己做的小实验

拿一张纸写上字，对着镜子看：字是反的。
再把纸**上下颠倒**对着镜子看：字还是反的，而且更怪。

这说明镜子翻的不是"左右"或"上下"中的某一个轴，是**整个前后方向**。

## 边界

- 水面、玻璃、金属表面都遵守同一规律
- 两面成 90° 的镜子（角镜）会把像再翻一次，于是字正过来了
- 镜子里的你左右手位置在空间中没变，变的是"朝向"

## 用得上

- 为什么倒车影像/后视镜里的字是反的
- 为什么理发师用两面镜子给你看后脑勺（两次翻转）

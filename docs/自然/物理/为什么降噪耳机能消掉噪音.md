# 为什么降噪耳机能消掉噪音

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 声音与噪声

## 结论

因为声波会**叠加**。耳机用麦克风采集环境噪声，再发出一个**相位相反**的声波，
两者在耳道处相消——这就是主动降噪（ANC）。

## 机制

1. 麦克风拾取环境噪声
2. 电路在毫秒级内生成反相波形
3. 扬声器把它播放出来，与噪声叠加
4. 相位差接近 180° 时，振幅相消
5. 反馈式（麦克风在耳道内侧）补偿更准，前馈式（外侧）响应更快

## 边界

- 对**低频**（如飞机引擎、空调嗡嗡声）效果最好
- 对高频、突发声（说话、喇叭）效果差，因为波长短、相位难对齐
- 降噪 ≠ 隔音：被动隔音靠材料阻挡，主动降噪靠相消
- 强风、走动时麦克风会拾到风噪，反而更吵
- 降噪耳机不能替代护耳器在强噪声环境的作用

## 量级

```text
好的 ANC 耳机对低频可降 20–30 dB
对 1 kHz 以上通常只有几 dB
```

## 用得上

- 坐飞机、地铁，降噪对低频轰鸣最有效
- 走路、骑车别开强降噪，会听不到危险声音
- 想隔绝人声，被动隔音 + 耳塞更有效

## 误解

- **"降噪耳机能消除所有噪音"**——主要对低频有效
- **"降噪耳机伤耳"**——合理音量下不伤，反而能让你开小音量

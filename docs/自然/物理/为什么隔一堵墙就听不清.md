# 为什么隔一堵墙就听不清

> **学段** 高中–大学 ｜ **类型** 边界 ｜ **链** 声音

## 结论

因为墙把大部分声能**反射回去**，只剩一小部分透过去。隔声量随墙的**面密度**和**频率**上升，
所以低音最难隔——这就是为什么隔壁的鼓声传得最远，而说话声听不清。

## 机制

1. 声波打到墙上，一部分反射、一部分被墙吸收、一部分透射
2. 墙越重，越难被声波推动，透射越少——这叫**质量定律**
3. 经验规律：面密度加倍，隔声量约 +6 dB；频率加倍，也约 +6 dB
4. 所以低频（低音炮、鼓、电梯轰鸣）穿透力最强

## 边界

- **缝隙比厚度更致命**：门缝、管道孔、插座盒会形成"声桥"，一条缝能毁掉整面墙的隔声
- 双层墙 + 空腔比同样重量的单层墙好得多（空腔提供额外衰减）
- 撞击声（脚步声、拖椅子）走的是结构传声，靠弹性垫层和浮筑地板，不是靠加厚墙
- 隔声和吸声是两件事：吸音棉减少室内回声，不挡邻居的噪音

## 量级

| 构造 | 隔声量（约） |
| --- | --- |
| 240 mm 砖墙 | 50 dB |
| 轻钢龙骨双层石膏板 + 空腔 | 50–60 dB |
| 普通木门 | 20–25 dB |
| 有缝的门 | 常常不到 15 dB |

## 用得上

- 想安静：先堵缝（密封条），再考虑加质量层，最后才是吸音
- 想隔低音：需要质量 + 空腔 + 断开声桥，薄薄一层吸音棉没用

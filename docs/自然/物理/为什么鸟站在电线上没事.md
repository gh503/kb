# 为什么鸟站在电线上没事

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 触电与用电

## 结论

因为鸟的两只脚都在**同一根电线**上，两脚之间的电压差极小，几乎没有电流通过身体。
**电不是"有电就危险"，而是"有电势差才危险"。**

## 机制

1. 电流从高电位流向低电位
2. 鸟两脚间距只有几厘米，这段电线的电阻很小
3. 两脚之间几乎没有电压差 → 通过鸟身体的电流微乎其微
4. 鸟的身体成了"并联"的一小段，绝大部分电流仍走电线

## 边界

- 鸟如果**同时碰到两根线**，或碰到电线和接地体，立刻触电
- 体型大的鸟（如鹳）翅膀可能同时接触两根线，所以电力公司会加绝缘罩
- 高压线附近还有**电弧**风险，不接触也可能被击穿

## 用得上

- 同理：修高压线的工人穿**等电位服**，让自己和电线同电位
- 判断危险要看"有没有回路"，不是"有没有电"

## 误解

- **"鸟的脚有绝缘层"**——鸟的脚并不绝缘，关键是**没有电势差**
- **"鸟站在一根线上所以不导电"**——电线本身导电，鸟只是没形成回路

# 为什么麦克斯韦妖不能违反第二定律

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 温度与热

## 结论

因为"妖"要**测量**分子、**记住**结果、再**擦除**记忆。测量与擦除都要付出代价，
擦除 1 比特信息至少耗散 `kT ln2` 的能量——这笔账算下来，总熵仍然增加。

## 机制

1. 麦克斯韦设想：一个能分辨快慢分子的小妖，只放快分子到一边，就能"免费"制造温差
2. 但妖需要获取信息（测量），信息要存在记忆里
3. 记忆是有限的，必须不断擦除旧信息
4. **Landauer 原理**：擦除 1 比特至少耗散 `kT ln2` 的热
5. 这笔熵增 ≥ 妖"整理"出来的熵减，第二定律得救

## 量级

```text
kT ln2 在室温（300 K）下约 2.9×10⁻²¹ J
看起来极小，但对单个分子系统是决定性的
```

## 边界

- 信息是物理的：记忆载体有物理状态，擦除有热力学代价
- 实验已在胶体粒子系统中验证 Landauer 原理
- "妖"不违反物理，只是不能"免费"
- 量子信息与热力学的关系仍在研究

## 争议与未解

- 测量本身是否必然耗散，仍有讨论（有的方案把测量代价算进总账）
- 信息与引力的关系（黑洞信息悖论）是另一个未解
- 量子热力学中"麦克斯韦妖"的边界，仍在探索

## 到此为止

这一层是**信息与热力学的交界**：第二定律没有被推翻，
而是被"信息处理有物理代价"补全了。

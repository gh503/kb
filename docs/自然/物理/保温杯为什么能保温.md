# 保温杯为什么能保温

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 保温

## 结论

因为热传递只有三种方式：**导热、对流、辐射**。保温杯一样一样地堵：
双层抽真空堵住导热和对流，内壁镀银或抛光把辐射反射回去。

## 机制

| 传热方式 | 怎么传 | 保温杯怎么堵 |
| --- | --- | --- |
| 导热 | 分子一个传一个 | 抽成真空，没有分子可传 |
| 对流 | 流体流动带走热 | 真空层里没有流体可流动 |
| 辐射 | 电磁波，不需要介质 | 内壁镀银/抛光，把红外反射回去 |

再加上**盖子**——不盖盖子，热气会直接从杯口对流跑掉，真空层再好也没用。

## 边界

- 真空层挡不住辐射，所以便宜的单层不锈钢杯会烫手、也会凉得快
- 杯口、盖子、密封圈是短板：热量主要从那里漏
- 保温杯**也保冷**：它减少的是"热流"，不分方向
- 保温不等于恒温，时间长了还是会变

## 误解

- **"越厚越保温"**——厚只增加一点热阻，真正起作用的是真空层
- **"保温杯只能装热水"**——装冰水同样有效，原理一样

## 用得上

- 判断保温杯好坏：倒满热水，摸外壁；明显发热说明真空层已经失效
- 装热水前先用热水烫一遍，减少杯体吸走的热量

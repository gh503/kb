# 单向玻璃为什么能单向看

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 光与镜面

## 结论

它其实是**半透半反镜**：两边都能透、都能反。所谓"单向"，只是**两边亮度差**造成的错觉——
亮的一侧反射光压过透射光，看起来像镜子；暗的一侧透射光占优，能看见对面。

## 机制

1. 玻璃镀一层很薄的金属膜（半透半反）
2. 亮侧：反射的室内光远强于从暗侧透过来的光 → 像镜子
3. 暗侧：透过的亮侧光强于自身反射光 → 能看清对面
4. 一旦暗侧变亮（开灯），效果立刻失效
5. 所以它是"照明条件"的产物，不是"单向通过"

## 量级

```text
常见透射率：约 10%–50%（视镀膜而定）
亮侧照度需明显高于暗侧（常差数倍以上）
暗侧开灯后，单向效果基本消失
```

## 边界

- 夜间室内开灯、室外黑，从室外反而更容易看清室内
- 贴膜玻璃、镜面玻璃是另一种实现方式
- 隐私不能只靠单向玻璃，要配合照明管理
- 照相机的闪光灯会"反射回来"，破坏效果

## 用得上

- 审讯室、心理咨询室的单向玻璃，靠的是两侧照明差
- 家里用单向膜，晚上要拉窗帘

## 误解

- **"单向玻璃只让光单向通过"**——两边都透，只是亮度不同
- **"贴了膜就绝对隐私"**——照明条件一变就失效

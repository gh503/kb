# 噪音为什么会影响健康

> **学段** 大学–研究生 ｜ **类型** 边界（证据强度） ｜ **链** 声音与噪声

## 结论

噪音不只是"烦"：它会**干扰睡眠、升高血压、增加心血管风险**，还可能影响儿童认知。
但因果强度分层明显——睡眠干扰证据较强，心血管属于"中等"，认知影响"有限但一致"。

## 机制

1. 噪声触发应激反应：交感兴奋、皮质醇升高、心率加快
2. 夜间噪声造成微觉醒，睡眠结构被打断（人可能不记得）
3. 长期应激 → 血压升高、内皮功能受损
4. 认知：噪声下注意力与阅读理解下降，儿童更明显
5. 主观烦恼（annoyance）本身也是健康结局之一

## 证据分层

| 结论 | 强度 |
| --- | --- |
| 夜间噪声干扰睡眠 | 强（实验可重复） |
| 长期交通噪声与高血压相关 | 中等（队列研究，混杂多） |
| 与缺血性心脏病相关 | 中等偏弱 |
| 儿童认知与学习受影响 | 有限但方向一致 |
| "噪音导致精神疾病" | 证据不足 |

## 边界

- 观察性研究难排除社会经济地位、空气污染的混杂
- 个体敏感度差异大，"吵不吵"有主观成分
- 夜间噪声比白天同等声级影响更大
- WHO 指南给出的是基于证据的推荐值，不是"安全线"

## 争议与未解

- 交通噪声与心血管疾病的**剂量—反应曲线**仍有不确定性
- 低水平长期暴露（如 40–50 dB 夜间）的健康影响，研究不足
- 主观烦恼与客观指标之间的换算，缺乏统一标准

## 到此为止

这一层是**证据强度分层**：机制合理，部分结论有队列支持，
但"多少分贝、多久、导致什么病"仍不能精确回答。

# 声速为什么随温度变

> **学段** 大学–研究生 ｜ **类型** 量级（含未解） ｜ **链** 声音

## 结论

气体里的声速由分子的热运动速度和介质的热力学性质决定：

```text
v = √(γRT/M)
```

所以**温度升高，声速变快**。空气大约每升 1℃ 快 0.6 m/s：0℃ 时 331 m/s，20℃ 时 343 m/s。

## 机制

1. 声音靠分子碰撞把扰动传下去，分子跑得越快，传得越快
2. 温度就是分子平均动能的度量，所以 v 随 √T 上升
3. γ 是比热比（空气 1.4），M 是摩尔质量，R 是气体常数
4. 换成水或钢，M 和弹性模量完全不同，声速差一个量级

## 边界

- 湿度会让声速略升（水分子比氮氧轻），湿空气反而传得快一点
- 高空温度低，声速小，声线会向**下**弯——这是远处的声音有时听得格外清楚的原因
- 顺风、逆风会叠加风速，改变实际传播
- 多普勒效应：`f' = f (v ± v_观察者)/(v ∓ v_声源)`，救护车驶过时音调掉下来就是这个

## 未解与前沿

- **大气次声监测**：核爆、火山喷发、流星进入大气都会产生 0.01–1 Hz 的次声，
  全球监测网靠它定位事件，但传播路径受风和温度结构影响，定位误差不小
- 海洋声层析用声速反演海水温度，是少数能大范围测海洋热含量的手段，但反演本身是不适定问题
- 城市噪声预测里，温度分层和湍流对声传播的影响仍难以准确模拟

## 到此为止

再往下问"为什么 γ 和 M 决定声速"，是**气体动理论**与热力学；问"为什么温度是分子平均动能"，
是统计力学的**基本假设**——本库在此标为**公理层**。

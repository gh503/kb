# 声音是怎么传到你耳朵的

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 声音

## 结论

声音是介质的**疏密波**（纵波）：振动把空气一会儿压密、一会儿拉稀，这串变化传到耳膜，
再被耳朵翻译成神经信号。**没有介质就没有声音**——真空里什么也听不见。

## 机制

1. 声源振动，推动旁边的空气：压缩 → 稀疏 → 压缩
2. 空气分子本身几乎不跑远，只是把"挤压"一站站传下去
3. 传到耳膜，引起振动，经中耳三块小骨放大，进入耳蜗
4. 耳蜗里的毛细胞按频率分工，把机械振动变成电信号

三个量对三个感觉：

| 物理量 | 单位 | 你感到的是 |
| --- | --- | --- |
| 频率 | Hz | 音调高低（20–20000 Hz 是人耳范围） |
| 振幅 | dB | 响度（痛阈约 120 dB） |
| 波形 | — | 音色（同样是 440 Hz，吉他和钢琴不同） |

## 边界

- 声速由介质决定：空气约 340 m/s，水约 1500 m/s，钢约 5000 m/s
- 声音**不能在真空传播**——电影里的太空爆炸声是错的
- 频率过高（超声）或过低（次声）都听不见，但能量还在
- 长期暴露在 85 dB 以上会损伤毛细胞，且**不可再生**

## 量级

```text
人耳能听到的最弱声压 ≈ 20 μPa
痛阈 ≈ 20 Pa
相差 100 万倍，所以用对数（dB）表示
```

## 误解

- **"声音是空气在跑"**——是扰动在跑，空气分子只在原地小幅振动
- **"耳朵不好使是耳屎多"**——多数是毛细胞或听神经受损

# 声音有多响

> **学段** 小学–初中 ｜ **类型** 量级 ｜ **链** 声音与噪声

## 结论

响度用**分贝（dB）**表示，它是对数刻度：**每增加 10 dB，声能增加 10 倍**，
主观上大约"响一倍"。所以 90 dB 不是比 80 dB"响一点"，是能量差 10 倍。

## 机制

1. 声波是空气压强的小幅波动，压强变化幅度叫声压
2. 人耳能感受到的声压范围极大（约 10¹² 倍），用线性刻度没法写
3. 于是取对数：`L = 20 log₁₀(p / p₀)`，p₀ = 20 μPa（听阈）
4. 0 dB 是"刚能听见"，不是"没有声音"
5. 每 +10 dB：声压 ×3.16，声能 ×10

## 常见量级

| 场景 | 大致声级 |
| --- | --- |
| 树叶沙沙 | 20–30 dB |
| 安静室内 | 30–40 dB |
| 正常交谈 | 60 dB |
| 繁忙街道 | 70–80 dB |
| 地铁进站 | 90 dB |
| 演唱会前排 | 100–110 dB |
| 喷气机起飞（近距离） | 120–130 dB |

## 边界

- dB 有不同计权：dB(A) 模拟人耳对中频更敏感，dB(C) 更接近线性，读数不同
- 声压级随距离衰减：点声源距离加倍，约降 6 dB
- 多个声源叠加不是简单相加：两个相同的 60 dB 源约 63 dB
- 分贝是"级"，不是绝对能量，必须说明参考量

## 用得上

- 手机分贝 App 只能粗略参考，不能当计量工具
- 判断"吵不吵"：60 dB 以上影响交谈，70 dB 以上开始干扰

## 误解

- **"0 dB 就是没有声音"**——0 dB 是听阈
- **"音量加倍就是分贝加倍"**——能量 ×10 才 +10 dB

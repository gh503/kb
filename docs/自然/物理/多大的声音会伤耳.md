# 多大的声音会伤耳

> **学段** 初中–高中 ｜ **类型** 量级 ｜ **链** 声音与噪声

## 结论

关键是**声级 × 时间**。一般认为 **85 dB(A) 连续 8 小时**是安全上限；
声级每高 3 dB，允许时间减半。100 dB 只允许十几分钟。

## 等能量原则

```text
85 dB   → 8 小时
88 dB   → 4 小时
91 dB   → 2 小时
94 dB   → 1 小时
100 dB  → 约 15 分钟
105 dB  → 约 4 分钟
```

这不是"精确阈值"，是职业卫生的经验规则（3 dB 交换率）。

## 机制

1. 强声让耳蜗内的毛细胞过度弯曲
2. 短暂暴露可恢复（暂时性阈移），长期则毛细胞死亡、不可再生
3. 损伤最先出现在高频（4 kHz 附近），所以早期听不出，晚期才发现
4. 耳机音量过大、持续时间长，是年轻人听力损伤的主因之一

## 边界

- 个体差异大：有人更敏感，有人耐受
- 脉冲噪声（爆炸、枪声）比稳态噪声更伤
- 听力损伤是累积的，不会"适应"
- 耳鸣可能是早期信号，不是"上火"

## 用得上

- 耳机遵守"60/60"：音量不超 60%，每次不超 60 分钟
- 演唱会、KTV 后耳鸣，说明已经过量
- 长期在噪声环境工作，要戴护耳器并定期查听力

## 误解

- **"习惯了就不伤耳"**——适应的是主观感受，损伤还在累积
- **"听不清是因为耳朵堵了"**——高频听力下降常是噪声性损伤

# 天空为什么是蓝的

> **学段** 小学–高中 ｜ **类型** 机制 ｜ **链** 彩虹

## 结论

因为空气把阳光里的短波散射得比长波强得多（约 1/λ⁴），蓝光被散向四面八方，
其中一小部分进了你的眼睛。**天空的蓝是散射光，不是空气的颜色。**

## 机制

1. 阳光包含所有可见波长，进大气前大体是白的
2. 空气分子（N₂、O₂，约 0.3 nm）远小于可见光波长（400–700 nm）
3. 光的电场把分子极化成一个随光频率振荡的偶极子，偶极子再向外辐射
4. 这个二次辐射的强度随频率的四次方上升：**I ∝ 1/λ⁴**

这种由远小于波长的分子造成的散射，叫**瑞利散射**；粒子大到和波长可比时换成米氏散射。

于是 450 nm 的蓝光被散射的效率约是 700 nm 红光的 (700/450)⁴ ≈ 5.9 倍。

## 边界

- **只对远小于波长的粒子成立**。雾滴、云滴是微米级，走米氏散射，
  各波长散射效率接近——所以云是白的，雾是灰白的。
- 天空不是紫色：太阳光谱在紫端本来就弱、高层臭氧吸收一部分紫光、
  人眼视锥对紫不敏感，三者叠加，峰值落在蓝。
- 日落红是同一机制的另一个方向：光程变长，蓝光在半路被散掉，剩下红橙。

## 误解

- "天空反射了海的蓝"——内陆上空一样蓝；海的蓝一半还是反射天空。
- "空气是蓝色的"——空气无色，蓝是光在路上被散射出来的。
- "太空是黑的所以大气没颜色"——对，黑色正是"没有散射"的样子。

# 彩虹为什么是弧形

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 彩虹

## 结论

因为能看到彩虹的方向，是**以你眼睛为顶点、以 42° 为半角的圆锥面**。
圆锥被地平线切掉一半，看起来就是一道弧。**在飞机上、山顶上，能看到完整的圆。**

## 机制

1. 满足"光偏折 42°"的水滴，分布在以你为顶点的圆锥面上
2. 圆锥的半角由水滴的折射率决定，与水滴远近无关
3. 地面挡住下半部分，所以通常只看到上半弧
4. 你往前走，圆锥跟着你走，所以彩虹"追不到"

## 边界

- 太阳高度角决定弧的高度：太阳越低，弧越高
- 太阳高于 42° 时看不到主虹（但可能在很高处看到霓的一部分）
- 从高处看（山顶、飞机）能看到闭合的圆环
- 双彩虹时，两道弧的角半径不同（42° 与 51°）

## 量级

```text
主虹角半径：红 42.4°，紫 40.6°
霓角半径：红 50.4°，紫 53.4°
```

## 误解

- **"彩虹在某个固定位置"**——它依赖观察者，两个人看到的不是同一道
- **"彩虹会跟着车跑"**——是圆锥跟着观察者平移，不是物体在移动

# 彩虹里为什么有多余的条纹

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 彩虹

## 结论

几何光学只给出"42° 处有一条虹"，但实际主虹内侧常有几条**淡色的细条纹**
（附属虹）。它们来自光的**干涉**——水滴尺寸与波长可比时，几何光学失效，
需要**艾里理论**，更严格则要用**米氏散射**。

## 机制

1. 几何光学把光当成射线，预测 42° 处一个锐利的极大
2. 但水滴只有几十微米到几毫米，与波长同一量级，衍射不可忽略
3. **艾里理论**把水滴近似为"可衍射的圆孔"，给出主极大加一系列次极大
4. 次极大就是附属虹，间距随水滴变小而变宽
5. 精确解要用**米氏散射**：把麦克斯韦方程在球面上求解，计算量大但完备

## 边界

- 水滴大（> 1 mm）时，几何光学 + 艾里修正够用；水滴小，条纹更明显
- 附属虹只在主虹**内侧**，而且要求水滴大小比较一致
- 雾虹（小水滴）里几乎没有彩色，全是白色宽弧
- 偏振：彩虹的光是部分偏振的，用偏振片可以看到变化

## 未解与争议

- 真实雨滴有**形变**（下落时被压扁）、有**尺寸分布**，不是完美球体，
  所以精确模拟整条彩虹仍很复杂
- 附属虹的可见条件（水滴谱宽、背景亮度）缺少统一判据
- 这也是"简单模型能解释主要现象，但细节要靠数值计算"的典型例子

## 到此为止

再往下是**麦克斯韦方程组 + 球形边界条件**，本库标为**公理层**：
方程本身不再解释，只求解。

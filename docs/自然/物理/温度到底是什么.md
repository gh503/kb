# 温度到底是什么

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 温度与热

## 结论

温度是**分子平均动能的量度**：分子运动越剧烈，温度越高。
它描述的是"单个分子平均有多活跃"，不是"一共含多少热"。

## 机制

1. 物质由不断运动的分子组成
2. 温度正比于分子的平均平动动能：`(3/2)kT = ½mv²`
3. 分子运动越剧烈，碰撞越有力，宏观上表现为温度高
4. 温度是**强度量**：一杯水和一桶水同温，分子平均动能相同
5. 热量是**能量**，温度是**状态**，两者不是一回事

## 量级

```text
绝对零度：0 K = −273.15℃
室温：约 300 K
人体：约 310 K（37℃）
太阳表面：约 5800 K
```

## 边界

- 温度只对大量分子才有意义，单个分子没有"温度"
- 同温下，不同物质的分子平均动能相同，但比热不同（升温难易不同）
- 相变时温度不变，但热量在进出（潜热）
- 宇宙微波背景约 2.7 K，是"太空的温度"

## 用得上

- 发烧量的是体温，不是"热量"
- 同样 100℃ 的水蒸气比开水烫伤更重，因为还有汽化潜热
- 体感温度受湿度、风影响，不等于气温

## 误解

- **"温度就是热的多少"**——是分子平均动能，不是总热量
- **"0℃ 就没有热了"**——0℃ 仍有分子运动，只是比 100℃ 慢

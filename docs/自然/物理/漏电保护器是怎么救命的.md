# 漏电保护器是怎么救命的

> **学段** 高中–大学 ｜ **类型** 机制（安全） ｜ **链** 触电与用电

## 结论

它同时测量**火线和零线的电流**。正常时两者相等、方向相反，和为零；
一旦有人触电或电器漏电，部分电流经大地跑掉，两者不再相等——
差到 **30 毫安**，它就在 **0.1 秒内**跳闸。

## 机制

1. 火线和零线穿过同一个**零序电流互感器**
2. 正常回路：进多少、出多少，磁通抵消，互感器无输出
3. 漏电时：一部分电流经人体或大地流走，两线电流不等
4. 差值（剩余电流）超过阈值 → 脱扣机构动作，切断电源
5. 它**不检测过载**，那是断路器（空气开关）的活

## 量级

```text
家用漏电保护器：动作电流 30 mA，动作时间 ≤ 0.1 s
30 mA × 0.1 s = 3 mAs，低于心室颤动的危险阈值
```

## 边界

- 漏电保护器**不能替代接地**：它是在事故发生后切断，接地是让故障电流有路可走
- 每月按一次试验按钮，确认还能跳闸
- 它保护的是"对地漏电"，**不保护**两手同时碰火线零线（那种情况电流不经过大地）
- 老旧线路、潮湿环境要选更高防护等级

## 用得上

- 卫生间、厨房、户外插座必须带漏保
- 跳闸后不要直接合上，先查原因
- 漏保 + 接地 + 等电位，三件套才完整

## 误解

- **"装了漏保就绝对安全"**——它只能减少风险，不能消除
- **"漏保跳闸说明电器坏了"**——也可能是线路受潮、插座进水

# 真空为什么能隔热

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 保温

## 结论

因为导热和对流都要靠**分子**传递能量，真空里没有足够多的分子，这两条路就断了。
但**辐射不需要介质**，所以真空隔热必须配低发射率表面（镀银、抛光）。

## 机制

1. 气体导热靠分子碰撞，分子越少，导的热越少
2. 压强降到约 1 Pa 以下，气体导热基本可以忽略
3. 对流需要流体流动，真空里没有
4. 但任何有温度的物体都在辐射红外线，真空挡不住——只能靠**反射**（低发射率）减少净辐射

## 量级

```text
空气导热系数 ≈ 0.026 W/(m·K)
真空绝热板 ≈ 0.004 W/(m·K)
差约 6 倍；再叠加厚度，效果更明显
```

## 边界

- **真空不是绝对零导热**：残余气体、支撑结构、杯口连接处都会传热
- 真空度不够（比如 100 Pa）时，气体导热重新变得显著
- 辐射占比随温度升高而增大，所以装沸水时辐射损失比装温水更大
- 真正的"真空绝热"要靠吸气剂维持真空度

## 用得上

- 保温杯的真空层一旦漏气，性能断崖式下降，不是慢慢变差
- 双层玻璃窗也是同一个思路，但中间是气体不是真空（成本与结构考虑）

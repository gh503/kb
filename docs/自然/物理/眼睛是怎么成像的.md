# 眼睛是怎么成像的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 视觉与光

## 结论

眼睛是一个**可调焦的凸透镜系统**：角膜和晶状体把光会聚，在视网膜上形成**倒立、缩小的实像**，
视网膜把光变成电信号，大脑再把像"翻正"并解释成你看到的世界。

## 机制

1. 角膜提供大部分折光力（约 2/3），晶状体负责**微调**
2. 睫状肌收缩/放松改变晶状体曲率，实现"调焦"（调节）
3. 光线在视网膜上会聚成像——倒立、左右相反
4. 视锥细胞（色觉、强光）和视杆细胞（暗光）把光转为电信号
5. 视神经传到大脑枕叶，被解释成正立的景象

## 边界

- 视网膜上的像是倒的，但"你看到的世界"是大脑加工的结果，不是光学像
- 每只眼有一个**盲点**（视神经出口），大脑会"补"上
- 明适应、暗适应需要时间：视紫红质分解与再生
- 双眼视差提供深度感，单眼靠透视、遮挡、运动视差

## 用得上

- 看近处久了，睫状肌持续紧张 → 视疲劳，要远眺放松
- 暗处看不清颜色：视杆细胞不辨色
- 夜间看东西用"余光"更清楚（视网膜周边视杆细胞多）

## 误解

- **"眼睛像照相机，直接拍下正立的像"**——视网膜上是倒像
- **"看东西是眼睛在工作"**——一半以上是大脑在处理

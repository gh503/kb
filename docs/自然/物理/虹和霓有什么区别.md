# 虹和霓有什么区别

> **学段** 高中–大学 ｜ **类型** 对比 ｜ **链** 彩虹

## 结论

**虹**是光在水滴里反射**一次**，角半径约 42°，外红内紫；
**霓**是反射**两次**，角半径约 51°，颜色**反序**（外紫内红），而且暗得多。

## 机制

1. 每次在水滴内壁反射，都会损失一部分光（透射出去）
2. 二次反射多损失一次，所以霓的亮度只有虹的约十分之一
3. 多一次反射，出射角度变大，颜色顺序也随之翻转
4. 两次反射的光线几乎平行出射，色散被"再展开"一次，方向反过来

## 对比表

| | 主虹（虹） | 次虹（霓） |
| --- | --- | --- |
| 内壁反射次数 | 1 | 2 |
| 角半径 | 约 42° | 约 51° |
| 颜色顺序 | 外红内紫 | 外紫内红 |
| 亮度 | 亮 | 暗（约 1/10） |
| 位置 | 较低 | 较高 |

## 边界

- 霓常因为太暗而看不见，尤其在城市光污染或薄云天气
- 两道虹之间的暗带叫**亚历山大暗带**，是两者都不满足的角度区间
- 三次反射的"三虹"在实验室可见，自然中极罕见，位置在太阳同侧

## 用得上

- 看到双彩虹，数一下颜色顺序就能判断哪道是霓
- 霓的弧更高，太阳较高时先消失的是虹

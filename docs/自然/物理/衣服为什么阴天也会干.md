# 衣服为什么阴天也会干

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 蒸发与相变

## 结论

因为**蒸发在任何温度下都在发生**，只要液体表面的分子拿到足够能量就能跑出去。
跟有没有太阳无关——太阳只是让它快一点。**蒸发不等于沸腾。**

## 机制

1. 液体里的分子速率并不一样，总有一小部分跑得特别快
2. 表面那些快到能挣脱分子间引力的，就跑到空气里去了，这叫蒸发
3. 跑掉的分子带走能量，剩下的平均动能下降——所以蒸发**吸热、致冷**
4. 空气越干、风越大、摊得越开、温度越高，蒸发越快；反过来就慢

## 边界

- 空气**相对湿度到 100%** 时，蒸发和凝结打平，衣服不再变干（"闷着不干"）
- 密闭容器里会很快达到饱和，所以衣柜里要放干燥剂
- 冬天冰冻的衣服也会干：冰直接变成水蒸气，叫**升华**，不需要先化水

## 误解

- **"阴天不干是因为没太阳"**——多数时候是湿度和不通风。晴天但闷热无风，一样不干
- **"水要到 100℃ 才蒸发"**——100℃ 是**沸腾**（内部也汽化），蒸发一直都在
- **"冰箱里不会干"**——冰箱里湿度低、温度低，食物反而更容易失水变干

## 用得上

晾衣服的三要素就这三条，改一条就快一截：

- 摊开（增大表面积）
- 通风（把湿空气换走）
- 升温（提高蒸汽压）

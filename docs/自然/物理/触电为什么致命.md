# 触电为什么致命

> **学段** 大学–研究生 ｜ **类型** 机制 ｜ **链** 触电与用电

## 结论

直接死因通常不是"烧焦"，而是**心室颤动**：电流干扰心肌的电活动，
心脏从规律泵血变成无序抖动，几分钟内脑缺氧。**电流大小、路径、时间、频率**共同决定后果。

## 机制

1. **感知阈值**：约 1 mA，手指发麻
2. **摆脱阈值**：约 10–20 mA，肌肉持续收缩，抓握电极后无法松手
3. **呼吸肌麻痹**：几十 mA，胸廓无法呼吸
4. **心室颤动**：约 50–100 mA 持续一秒以上，最危险
5. **路径**：左手到右脚穿过心脏，最致命；仅手指间通过，只造成局部烧伤

50/60 Hz 的工频电流**最危险**——恰好落在心肌易被干扰的频率范围；
高频电流（如射频）反而更多造成烧伤而非室颤。

## 量级

```text
安全电流（一般认为）：30 mA 以下、短时间
心室颤动阈值：约 50–100 mA（与时间相关）
家用 220 V、潮湿皮肤 1000 Ω → 220 mA，远超阈值
```

## 边界

- 电流通过时间越长，阈值越低（IEC 有电流—时间安全曲线）
- 直流电与交流电的阈值不同，交流更危险
- 个体差异大：心脏病患者、儿童更敏感
- 电击后即使"看起来没事"，也可能出现迟发心律失常

## 用得上

- 触电急救：**先断电**，再判断呼吸心跳，立即 CPR 并取 AED
- 除颤越早越好，每分钟延误存活率下降约 7–10%
- 不要给触电者喂水、不要摇晃

## 误解

- **"触电会把人弹开"**——多数是肌肉痉挛抓住电极，反而"粘住"
- **"被电一下只是麻一下"**——取决于路径和时间，可能当场致命

## 到此为止

再往下问"电流为什么干扰心肌电活动"，是**细胞膜电生理**（钠钾通道与阈电位）；
问"为什么心脏需要协调电活动"，是心肌合胞体的结构——到这一层是生理学细节。

# 超声波怎么能碎结石

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 超声

## 结论

体外碎石靠的是**冲击波**（不是普通成像超声）：把能量在焦点处汇聚，
在结石表面产生极高的应力，把石头"震裂"成小碎块，再随尿排出。

## 机制

1. 冲击波在体外产生，经水/耦合垫传入人体
2. 通过椭球反射或声透镜把能量**聚焦**到结石位置
3. 焦点处压力骤升骤降，产生应力与空化效应
4. 结石表面出现裂纹，逐渐碎裂
5. 碎块小于输尿管可排出的尺寸，就能自行排出

## 量级

```text
冲击波峰值压力：可达数十 MPa
每次治疗冲击次数：数百到数千次
适用结石大小：通常小于 2 cm（因部位而异）
```

## 边界

- 不是所有结石都适合：太硬（如胱氨酸结石）、位置不佳效果差
- 孕妇、凝血障碍、未控制的感染是禁忌
- 碎石后可能绞痛（排石过程）、血尿
- 大结石可能需要多次或改用内镜手术

## 用得上

- 碎石后要多喝水，帮助排石
- 术后疼痛、发热要及时就医
- 结石复发率高，要查代谢原因

## 误解

- **"碎石是无创无痛"**——有不适，排石过程会痛
- **"碎完就一劳永逸"**——结石容易复发

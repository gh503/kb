# 超声波能看见什么

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 超声

## 结论

超声波是**频率高于 2 万赫兹、人耳听不见的声波**。它碰到不同组织的界面会反射回来，
机器根据"回声多久回来、有多强"，画出身体内部的结构——这就是 B 超。

## 机制

1. 探头里的压电晶体通电后振动，发出超声波
2. 声波进入身体，遇到不同密度的组织界面就反射
3. 探头接收回声，按"时间差"算出深度
4. 按"回声强弱"给像素上灰度，拼成图像
5. 换不同频率的探头，看不同深度的结构

## 量级

```text
人耳上限：约 20 kHz
医学超声常用频率：2–15 MHz
软组织声速：约 1540 m/s
探测深度与频率：频率越高越清晰，但穿透越浅
```

## 边界

- 超声波**不能穿过骨头和空气**：所以肺、肠气多的部位看不清
- 孕期超声一般被认为是安全的，但仍遵循"有必要才做"
- 超声不是"拍照"，是实时切面
- 肥胖者穿透差，图像质量下降

## 用得上

- 产检、腹部、心脏、甲状腺都用超声
- 检查前按要求空腹或憋尿，是为了减少气体干扰
- 耦合剂是为了排除探头与皮肤之间的空气

## 误解

- **"超声波有辐射"**——是声波，不是电离辐射
- **"B超能看清一切"**——气体和骨头后面是盲区

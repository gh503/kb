# 金属为什么能反光

> **学段** 大学–研究生 ｜ **类型** 机制 ｜ **链** 光与镜面

## 结论

因为金属里有大量**自由电子**。它们被光电场推着集体振荡，把入射光几乎原样反射回去；
只有频率高于**等离子体频率**的光才能穿透。所以金属对可见光是"镜子"，对紫外和 X 射线就不再是。

## 机制

1. 金属中的价电子可以在晶格里自由移动，形成"电子海"
2. 光的电场让这团电子整体振荡，振荡的电子又辐射，合成反射波
3. 只要光的频率低于等离子体频率 `ω_p = √(n e²/(ε₀ m))`，电子跟得上，光被反射
4. 频率高于 ω_p，电子跟不上，光就穿过去了——大多数金属的 ω_p 在紫外区

## 为什么颜色不一样

- **银、铝**：在整个可见光波段反射都高，所以是"白亮的"
- **铜、金**：自由电子模型不够用，还要算**带间跃迁**——它们吸收蓝紫光，
  剩下的反射光就偏红黄，这就是铜的红色和金的黄色
- **铁、钢**：反射率低一些，看起来"灰亮"，抛光后才是镜面

## 边界

- 反射率还取决于表面粗糙度：粗糙到波长量级就变成漫反射（哑光）
- 金属在空气中会氧化，氧化层改变颜色和反射率（银变黑、铜变绿）
- 真正的镜子是"玻璃 + 镀银/镀铝"，玻璃只是保护层，反光的是金属膜

## 到此为止

再往下问"电子为什么能自由移动"，是**能带理论**（导带与价带的重叠）；
问"为什么会有能带"，是周期性势场中电子的量子力学解——到这一层已经是固体物理的具体计算，
本库把它标为**公理层**（薛定谔方程 + 晶格周期性）。

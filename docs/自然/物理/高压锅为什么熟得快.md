# 高压锅为什么熟得快

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 压强

## 结论

因为它把锅内压强提高到约 **2 个大气压**，水的沸点升到约 **120℃**。
温度高，化学反应（包括蛋白质变性、淀粉糊化）就快得多——大约每升 10℃ 反应速率翻倍。

## 机制

1. 密封 + 限压阀让锅内蒸汽压升高
2. 压强高 → 沸点高（约 2 atm 对应 120℃）
3. 温度升高，食物中的化学反应速率按 Q₁₀ 加快
4. 一般每升高 10℃，速率约翻倍
5. 从 100℃ 到 120℃ 相当于快 4 倍左右，所以炖煮时间明显缩短

## 量级

```text
家用高压锅工作压强：约 1.8–2.0 atm
对应沸点：约 116–120℃
Q₁₀ ≈ 2（每 +10℃ 速率翻倍）
```

## 边界

- 高压锅不是"压熟"的，是"温度高了熟得快"
- 食物量大、块大时，传热时间仍占主导
- 豆类、肉类效果明显；蔬菜过久会烂
- 使用不当（堵阀、超量）有爆炸风险

## 用得上

- 上汽后计时，别一直大火
- 检查限压阀、密封圈
- 不要超最大容量线

## 误解

- **"高压把食物压烂"**——主要是温度效应
- **"压力越高越好"**——温度过高会破坏口感与营养

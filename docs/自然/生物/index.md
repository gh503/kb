# 生物

> 生命怎么运作、怎么演化。

## 收什么

- 机制解释：免疫、代谢、遗传各自怎么工作
- 常见误区：如"基因决定一切""排毒""酸碱体质"
- 健康相关的基础事实，标明证据强度

## 不收什么

- 物种名录
- 养生偏方，以及没有出处的"研究表明"

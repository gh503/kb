# 为什么一年会感冒好几次

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 免疫与感冒

## 结论

因为能引起感冒的病毒**型别太多**（两百多种），而且免疫记忆**不持久、不交叉**。
你只是对"这一种"产生了短期免疫，换一种照样中招。

## 机制

1. 鼻病毒有上百种血清型，冠状病毒、腺病毒、RSV 等也参与
2. 感染后产生抗体，但主要针对**这一型**
3. 呼吸道黏膜的 IgA 抗体维持时间短（数月）
4. 病毒还会变异，逃逸已有免疫
5. 儿童免疫经验少，所以感冒更频繁（每年 6–8 次）

## 量级

```text
成人：每年约 2–4 次感冒
儿童：每年约 6–8 次
鼻病毒：占感冒病因的约 30%–50%
```

## 边界

- "老感冒"不等于免疫力差，可能只是接触机会多（如带孩子、坐地铁）
- 反复"感冒"也可能是过敏性鼻炎、鼻窦炎，被误认为感冒
- 症状持续、反复低热，要排查其他原因
- 睡眠不足、压力大、营养差会增加易感性

## 用得上

- 感冒频率高，先看是否接触环境（人群、通风）
- 过敏体质者，抗过敏治疗可能比"抗感冒"更有效

## 误解

- **"老感冒说明免疫力低下"**——多数是接触和型别问题
- **"感冒一次就免疫了"**——只对这一型、且时间有限

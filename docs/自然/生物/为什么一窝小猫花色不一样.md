# 为什么一窝小猫花色不一样

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 遗传

## 结论

因为父母各自有两个"版本"的每个基因，传给下一代的只是**其中一个**，而且是随机的。
不同的组合凑在一起，同一窝就会出现不同花色——这就是**孟德尔分离与自由组合**。

## 机制

1. 每个基因有两个拷贝（等位基因），分别来自父母
2. 形成生殖细胞时，两个拷贝**只留一个**（分离定律）
3. 不同基因的拷贝独立组合（自由组合定律，前提是基因在不同染色体上或距离远）
4. 显性等位基因会盖住隐性等位基因的表现
5. 两个隐性凑在一起，隐性性状才显现

## 例子

```text
黑猫（Bb）× 黑猫（Bb）
子代：BB 黑 25% ｜ Bb 黑 50% ｜ bb 白 25%
黑:白 = 3:1
```

## 边界

- "一窝花色不同"也可能来自**多个父亲**（猫是多胎、可同期受孕）
- 有些花色基因在性染色体上，遗传比例不同
- 还有嵌合、突变、表观修饰，会让结果更复杂
- 自由组合只在基因不连锁时成立

## 误解

- **"混血就是各取一半特征"**——是随机组合，不是平均混合
- **"隐性基因就是弱的"**——隐性只是"不表现"，不代表功能差

# 为什么会感冒

> **学段** 小学–初中 ｜ **类型** 机制（纠错） ｜ **链** 免疫与感冒

## 结论

感冒是**病毒感染**，不是"着凉"本身。着凉可能让你更容易被感染，
但真正的原因是鼻病毒、冠状病毒等**病原体**进入了呼吸道。

## 机制

1. 病毒通过飞沫、手接触进入鼻腔、咽部
2. 病毒侵入上呼吸道黏膜细胞，复制
3. 免疫系统反应：血管扩张、分泌物增多 → 鼻塞、流涕、咽痛
4. 症状大部分是**免疫反应**造成的，不全是病毒直接破坏
5. 一般 7–10 天自愈，抗生素对病毒无效

## 边界

- 感冒与流感不是一回事：流感症状更重、起病更急、并发症更多
- "着凉"与感冒的关联，更多是**室内聚集、空气干燥、黏膜防御下降**等间接因素
- 感冒不能"一次得完就免疫"——型别太多
- 高热不退、呼吸困难、症状超过 10 天，要就医

## 用得上

- 勤洗手、通风，比"多穿点"更直接
- 感冒药缓解症状，不缩短病程
- 不要自行用抗生素

## 误解

- **"感冒是冻出来的"**——病毒是病因，寒冷是诱因之一
- **"捂汗能治感冒"**——出汗不杀病毒，反而可能脱水

# 为什么会打喷嚏

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 喷嚏与咳嗽

## 结论

因为鼻腔黏膜受到刺激（灰尘、花粉、病毒、冷空气），把信号传给脑干的**喷嚏中枢**，
身体用一股爆发性的气流把刺激物喷出去。**这是反射，不是你想打才打。**

## 机制

1. 鼻黏膜上的感觉神经末梢被刺激
2. 信号沿三叉神经传到脑干的喷嚏中枢
3. 先深吸一口气，声门关闭，肺内压力升高
4. 声门突然打开，气流从口鼻高速冲出，把刺激物带走
5. 同时泪腺分泌、眼睛闭上——整组动作一起发生

## 边界

- 强光（"光喷嚏反射"）在部分人身上会触发，是先天性的神经交叉
- 感冒时喷嚏多，是病毒刺激 + 炎症介质让神经更敏感
- 忍住不打会让压力转向耳咽管，可能不舒服，但一般不会"憋炸"
- 连续打十几个也可能是过敏，不一定是感冒

## 误解

- **"打喷嚏是因为有人想你"**——是刺激物的反射
- **"打喷嚏要捂住嘴"**——用手捂反而把病毒留在手上，正确做法是用**肘部内侧**或纸巾

## 用得上

- 过敏性鼻炎：避开过敏原 + 抗组胺药，比忍喷嚏有效
- 打喷嚏时用肘部遮挡，之后洗手
- 频繁喷嚏伴鼻塞、流清涕超过两周，考虑过敏而非感冒

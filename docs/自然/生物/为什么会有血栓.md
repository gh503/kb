# 为什么会有血栓

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 血液与凝血

## 结论

三个条件凑齐就容易长血栓（Virchow 三要素）：**血流变慢、血管壁受损、血液成分偏"凝"**。
长时间不动（久坐、卧床）主要踩中第一条。

## 机制

1. **血流淤滞**：久坐、卧床、房颤，血液在原地打转
2. **内皮损伤**：动脉粥样硬化、外伤、吸烟
3. **高凝状态**：脱水、妊娠、肿瘤、遗传性易栓症
4. 血小板与凝血因子被激活，在局部形成血块
5. 血块脱落随血流走 → 堵在肺（肺栓塞）或脑（中风）

## 量级

```text
久坐 4 小时以上：下肢静脉血栓风险明显上升
深静脉血栓：常见于小腿深静脉
肺栓塞：可致命，起病可很急
```

## 边界

- 血栓与出血是"跷跷板"，抗凝治疗要权衡
- 动脉血栓（血小板为主）与静脉血栓（纤维蛋白为主）用药不同
- 长途飞行、术后卧床是高危场景
- 血栓症状可能不明显（腿肿、胸闷）

## 用得上

- 长途旅行定时起身活动、勾脚踝
- 术后按医嘱早下床或做预防
- 单侧腿肿痛、突发胸闷气短，尽快就医

## 误解

- **"血栓是老年病"**——年轻人久坐、口服避孕药也可能
- **"多喝水就能防"**——有用但不充分，要加上活动

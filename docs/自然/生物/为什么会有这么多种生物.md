# 为什么会有这么多种生物

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 进化

## 结论

因为生物会**变异**，环境会**筛选**，种群还会被**隔开**。
变异提供材料，选择决定谁留下，隔离让差异越积越大——时间一长，就成了不同的物种。

## 机制

1. **变异**：繁殖时基因会突变、重组，后代彼此不完全一样
2. **选择**：环境资源有限，有些变异更能活下来、留下更多后代
3. **遗传**：有利变异能传给下一代
4. **隔离**：地理隔离（山、海）或生殖隔离，让两个群体不再交换基因
5. 差异累积足够久 → 形成新物种

## 量级

```text
地球已知物种：约 200 万种（估计实际有 800 万–1000 万种）
生命历史：约 38 亿年
物种形成常需：数万到数百万年（差异极大）
```

## 边界

- "进化"不是"进步"，没有高低贵贱，只有"适应当前环境"
- 细菌、病毒进化极快，因为世代短
- 人类活动正在加速物种灭绝，也在创造新的选择压力
- 物种界限有时模糊（环物种、杂交带）

## 用得上

- 理解为什么害虫会产生抗药性、细菌会耐药
- 保护生物多样性，本质是保护"变异的储备"

## 误解

- **"进化是为了适应环境而主动改变"**——是变异在先、选择在后
- **"进化很慢"**——细菌、昆虫可以在几年内明显变化

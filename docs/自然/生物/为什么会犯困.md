# 为什么会犯困

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 睡眠

## 结论

因为身体里有两套系统在同时记账：
**睡眠压力**（一种叫腺苷的代谢产物越积越多）和**昼夜节律**（生物钟告诉你现在该不该睡）。
两者叠加，到点就困。

## 机制

1. 清醒时大脑持续消耗能量，产生**腺苷**，它累积起来就是"睡眠压力"
2. 腺苷作用于睡眠中枢，让人越来越想睡
3. 同时，视交叉上核（生物钟）按光照周期调节全身节律
4. 晚上生物钟发出"该睡了"的信号，加上腺苷已经很高 → 困意最强
5. 睡着后腺苷被清除，早上醒来压力清零

## 边界

- **咖啡因**不是"消除疲劳"，是**阻断腺苷受体**——疲劳还在，只是感觉不到
- 睡眠压力与节律可以"错位"：熬夜后很困，但到了早上节律会把你拉醒
- 午睡能清一部分腺苷，但睡太久会打乱夜间入睡
- 光照是生物钟最强的授时信号，夜里强光会推迟节律

## 误解

- **"困了就是缺觉"**——也可能是节律低谷（下午两三点）、吃太饱、缺氧
- **"喝咖啡就不困了，说明不累"**——腺苷还在，只是被挡住了，咖啡因代谢完后"困意反弹"

## 用得上

- 想早睡：早上多见光、晚上少强光，比"强迫自己躺下"有效
- 下午犯困：短睡 20 分钟或走动，别靠第三杯咖啡

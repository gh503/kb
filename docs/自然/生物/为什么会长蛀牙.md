# 为什么会长蛀牙

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 牙齿与细菌

## 结论

不是"虫子咬的"，是**细菌在牙面上吃糖、产酸，酸把牙釉质溶掉了**。
洞一旦形成就不会自己长好，只会越烂越深。

## 机制

1. 牙面上有一层黏黏的**牙菌斑**，里面住着大量细菌
2. 你吃糖，细菌也吃糖，代谢产生**乳酸**等酸
3. 酸把牙釉质里的矿物质溶出来（脱矿），pH 降到约 5.5 以下就开始
4. 唾液能中和酸、帮助再矿化；但糖吃得太频繁，脱矿就赢过再矿化
5. 釉质被穿透后，细菌进到牙本质，烂得更快，最后到牙髓就疼了

## 边界

- **关键不是吃了多少糖，是吃的频次**：一次吃完，酸只降一次；分十次吃，酸降十次
- 黏性糖（软糖、饼干、含糖饮料）比巧克力更危险，因为停留久
- 睡前不刷牙最伤：夜里唾液分泌少，酸停留时间长
- 氟、窝沟封闭、定期检查，都是在"减慢脱矿"或"提前发现"

## 误解

- **"牙疼才是蛀牙"**——早期龋没有感觉，等到疼往往已经到牙本质或牙髓
- **"乳牙反正要换，不用治"**——乳牙龋会影响恒牙发育和排列
- **"不吃糖就不会蛀"**——淀粉类食物同样能被细菌分解产酸

## 用得上

- 刷牙两分钟、每天两次，用含氟牙膏
- 含糖饮料用吸管、喝完漱口，别含在嘴里慢慢喝
- 孩子第一颗牙萌出后就该开始清洁

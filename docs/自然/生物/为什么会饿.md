# 为什么会饿

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 消化与营养

## 结论

饿不是"胃空了"这么简单，是**激素 + 血糖 + 习惯**共同作用：
胃分泌胃饥饿素（ghrelin），血糖下降，加上"到饭点了"的条件反射。

## 机制

1. 胃排空后，胃壁分泌**胃饥饿素**，作用于下丘脑
2. 血糖下降、胰岛素变化，也参与饥饿信号
3. 脂肪组织分泌**瘦素**，告诉你"能量够了"
4. 看到、闻到食物，也会触发"心理性饥饿"
5. 进食后，胃扩张 + 肠道激素（如 GLP-1）产生饱腹感

## 量级

```text
胃排空时间：混合餐约 3–4 小时
胃饥饿素：餐前升高、餐后下降
```

## 边界

- 饿与"想吃"不同：前者是能量信号，后者常是习惯、情绪、环境
- 睡眠不足会让胃饥饿素升高、瘦素降低 → 更容易饿
- 高蛋白、高纤维食物更抗饿
- 长期节食会让饥饿信号更强（身体在"抗议"）

## 用得上

- 规律进食，减少"报复性饥饿"
- 饿的时候先喝水、吃蛋白质，别直接抓零食
- 睡眠充足，饥饿激素更稳定

## 误解

- **"饿了就是在消耗脂肪"**——不一定，先消耗糖原
- **"不饿就不该吃"**——规律进食比"等饿"更稳

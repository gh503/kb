# 为什么伤口会结痂

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 血液与凝血

## 结论

痂是**纤维蛋白网 + 血细胞 + 干涸的血浆**。它的作用是临时"封条"：
挡住细菌、保持湿润、给下面的细胞修复争取时间。

## 机制

1. 凝血级联最终把纤维蛋白原切成纤维蛋白
2. 纤维蛋白聚成网，网住红细胞和血小板
3. 暴露在空气中，水分蒸发，表面变干变硬 → 痂
4. 痂下的表皮细胞与成纤维细胞开始修复
5. 修复完成后，痂自然脱落

## 凝血级联（简化）

```text
组织损伤 → 组织因子暴露
→ 激活因子 X → 凝血酶原变凝血酶
→ 纤维蛋白原变纤维蛋白
→ 网住血细胞，形成血块
```

## 边界

- 痂不是"越厚越好"，过厚可能妨碍上皮爬行
- 湿性愈合（敷料保湿）通常比"让它干"更快
- 痂下感染会化脓、红肿，需要处理
- 糖尿病、血管病变者愈合明显变慢

## 用得上

- 伤口清洗后保持清洁，不必强行抠痂
- 大面积擦伤可用保湿敷料
- 痂周围红肿热痛，要就医

## 误解

- **"结痂就该抠掉"**——会撕裂新生组织、留疤
- **"伤口要吹干"**——过度干燥反而减慢愈合

# 为什么关节会磨损

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 骨骼与运动

## 结论

因为关节软骨**没有血管、没有神经**，靠滑液扩散营养，**修复能力极差**。
一旦磨损超过修复，就是骨关节炎——目前无法"逆转"，只能延缓。

## 机制

1. 关节软骨是少细胞、无血管的组织，营养靠关节活动时的挤压—扩散
2. 软骨细胞代谢慢，损伤后几乎不增殖
3. 长期负荷、力线异常、外伤 → 软骨磨损
4. 软骨变薄 → 骨面直接摩擦 → 炎症、疼痛、骨赘
5. 滑液有润滑作用（透明质酸、润滑素），但会随年龄和炎症变差

## 量级

```text
正常软骨厚度：约 2–4 mm
骨关节炎：软骨逐渐变薄甚至磨光
关节内摩擦系数：约 0.002–0.01（比冰面还低）
```

## 边界

- 骨关节炎不只是"磨损"，还有炎症与代谢因素
- 肥胖、力线异常（O 型腿）、旧伤是主要风险
- 运动不是敌人：适度负重运动保护关节，久坐反而有害
- 软骨修复技术（自体软骨移植、组织工程）仍有限

## 争议与未解

- "软骨能否再生"仍是开放问题，诱导再生尚无成熟方案
- 补充剂（氨基葡萄糖、软骨素）的疗效证据不一致
- 疼痛与影像学磨损程度常不匹配，机制未完全清楚

## 到此为止

这一层是**机制清楚 + 修复无解**：磨损会发生，但"怎么让它长回来"没有可靠答案。

# 为什么减肥这么难

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 消化与营养

## 结论

因为减重后身体会**下调能量消耗、上调饥饿信号**，形成"代谢适应"。
加上环境、睡眠、压力、菌群等因素，长期维持减重比短期减重难得多。

## 机制

1. 体重下降 → 基础代谢下降、活动能耗降低（代谢适应）
2. 胃饥饿素升高、瘦素下降 → 更饿、更容易囤积
3. 肌肉流失进一步降低消耗
4. 环境：高热量食物易得、份量变大
5. 睡眠不足、压力、某些药物都会推高体重

## 量级

```text
减重后代谢适应：能量消耗可比预测低 10%–15%（个体差异大）
"平台期"常出现在减重 5%–10% 后
```

## 边界

- "设定点"理论有争议：体重有调节倾向，但不是固定数值
- 肠道菌群与肥胖相关，但因果证据有限
- 不同人对同一饮食的反应差异很大
- 药物与手术对重度肥胖有效，但需长期管理

## 争议与未解

- **代谢适应持续多久**：有研究显示可长达数年，但幅度与持续时间仍有争议
- **"设定点" vs "沉降点"**：概念模型不同，预测不同
- **菌群因果**：相关性强，干预效果不稳定
- 长期随机对照的依从性差，难以做"完美实验"

## 到此为止

这一层是**机制清楚 + 个体差异大**：能量平衡是基础，
但"为什么有人更容易胖、减了为什么反弹"没有单一答案。

# 为什么吃饱了还饿

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 消化与营养

## 结论

因为"吃饱"和"吃够"是两套信号。**超加工食品能量密度高、体积小、饱腹信号弱**，
容易吃过量；睡眠不足、蛋白质不够、吃得太快，也会让饱腹信号失灵。

## 机制

1. 饱腹感来自胃扩张、肠道激素、血糖与瘦素
2. 超加工食品：高油高糖、低纤维、口感软 → 吃得快、饱腹弱
3. 液体热量（饮料）几乎不产生饱腹感
4. 睡眠不足 → 胃饥饿素↑、瘦素↓
5. 吃得太快，饱腹信号（约 20 分钟）来不及起作用

## 边界

- "饱腹"与"营养足够"不是一回事：高热量低营养也会饱
- 个体差异大：有人对饱腹信号更敏感
- 情绪性进食不是"意志力差"，有神经机制
- 极端节食会强化饥饿信号，导致反弹

## 用得上

- 先吃蛋白质和蔬菜，再吃主食
- 少喝含糖饮料，多喝水
- 放慢速度，给饱腹信号时间
- 保证睡眠

## 误解

- **"吃饱了还饿是胃有问题"**——多数是食物结构与信号问题
- **"靠意志力就能少吃"**——生理信号会反扑

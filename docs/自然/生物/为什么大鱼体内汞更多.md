# 为什么大鱼体内汞更多

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 生态

## 结论

因为汞在体内**排不出去**，还会沿着食物链**逐级浓缩**。
每一级吃掉的汞都留在体内，吃上一级时又连同它积累的汞一起吃进来——
到大型掠食鱼类，浓度可以比水体高几百万倍。

## 机制

1. 水中的无机汞被微生物转化为**甲基汞**（脂溶性、易吸收）
2. 甲基汞进入生物体后与蛋白质结合，**排出极慢**（半衰期以年计）
3. 每个营养级都保留大部分摄入的汞 → **生物富集**
4. 捕食者吃很多猎物，把猎物一生积累的汞集中到自己身上 → **生物放大**
5. 顶级掠食者（金枪鱼、鲨鱼、大型石斑）浓度最高

## 量级

```text
生物放大倍数：可达 10⁶–10⁷（相对水体）
常见建议：孕妇、儿童少吃大型掠食性鱼类
```

## 边界

- 不同鱼种差别巨大：食物链层级、寿命、体型都影响
- 汞主要影响神经系统发育，胎儿和幼儿最敏感
- 硒等元素可能有一定拮抗作用，但不应作为"放心吃"的理由
- 淡水鱼、养殖鱼的风险通常低于大型海鱼，但要看饲料来源

## 用得上

- 选鱼：小型、短寿命的鱼通常汞更低
- 孕妇、幼儿按当地膳食指南控制大型鱼类摄入
- 不要因为"深海鱼补脑"就天天吃金枪鱼

## 误解

- **"鱼越大越有营养"**——大型掠食者汞更高，风险收益要权衡
- **"煮熟能去掉汞"**——汞与蛋白结合，加热不能去除

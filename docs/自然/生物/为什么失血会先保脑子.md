# 为什么失血会先保脑子

> **学段** 大学–研究生 ｜ **类型** 机制 ｜ **链** 呼吸与循环

## 结论

因为身体有一套**优先级调度**：失血时交感神经兴奋，皮肤、内脏、肌肉的血管收缩，
把有限的血液优先供给**脑和心脏**。所以失血早期人会脸色苍白、手脚冰凉，但意识还清醒。

## 机制

1. 失血 → 回心血量下降 → 每搏输出量下降 → 血压有下降趋势
2. 压力感受器报警 → 交感兴奋 → 心率加快、血管收缩
3. 皮肤、胃肠道、肾脏的血流被"削减"，脑和心脏的灌注被保住
4. 同时肾素—血管紧张素—醛固酮系统启动，保钠保水
5. 失血超过约 30%，代偿失效 → 血压骤降 → 休克

## 量级

```text
成人血量约 5 L（体重的 7%–8%）
失血 < 15%：多可代偿，症状轻微
失血 15%–30%：心率快、脉压小、四肢冷
失血 > 30%：血压下降、意识改变，危及生命
```

## 边界

- "脸色苍白、手脚凉"是代偿的表现，不是"血还够"的证据
- 老年人、运动员、服药者（如 β 受体阻滞剂）代偿表现可能不典型
- 儿童失血比例耐受更差
- 内出血可能没有外见血，只有休克表现

## 用得上

- 怀疑内出血：看意识、脉搏、皮肤温度、尿量，比单看血压早
- 急救：平卧抬腿、保暖、尽快送医，不要喂水
- 献血 400 mL 约占总血量 8%，通常可代偿

## 到此为止

再往下问"为什么脑灌注不能被牺牲"，是**脑对缺氧的耐受极短（几分钟）**；
问"为什么代偿会失效"，是微循环与心肌抑制——到这一层是休克病理生理。

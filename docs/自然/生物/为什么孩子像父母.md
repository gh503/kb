# 为什么孩子像父母

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 遗传

## 结论

因为父母各给孩子**一半**的遗传信息。这些信息写在 DNA 上，DNA 被打包成染色体：
人有 23 对，一半来自父亲，一半来自母亲。**所以孩子是"混合"，不是"复制"。**

## 机制

1. DNA 是由四种碱基组成的长链，序列就是"说明书"
2. 一段能指导合成蛋白质的 DNA 叫**基因**
3. 基因组装在**染色体**上，人有 23 对（46 条）
4. 生殖细胞（精子、卵子）只带 23 条，各来自父方、母方
5. 受精后重新凑成 23 对，于是孩子同时像父母

## 量级

```text
人的基因组约 30 亿个碱基对
已知蛋白质编码基因约 2 万个
亲子之间平均共享约 50% 的遗传变异
```

## 边界

- 身高、体重、性格这类性状由**很多基因 + 环境**共同决定，不遵循"一个基因一个特征"
- 线粒体 DNA 只来自母亲
- 基因相同（同卵双胞胎）也会因环境不同而不同
- 表观遗传修饰能在不改变序列的情况下影响表达

## 误解

- **"孩子一半像爸爸一半像妈妈"**——是基因各一半，不是特征各一半
- **"DNA 决定一切"**——环境、随机发育、表观修饰同样重要

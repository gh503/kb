# 为什么尿会变黄

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 肾脏与排泄

## 结论

因为尿里含有**尿色素**（主要来自血红蛋白分解的胆红素代谢产物）。
喝水少时尿被浓缩，颜色就深；喝多了被稀释，颜色就浅。

## 机制

1. 红细胞衰老后，血红蛋白分解成胆红素
2. 胆红素在肝内处理，随胆汁排入肠道
3. 肠道细菌把它转化为尿胆素原，部分被吸收入血
4. 经肾排出，氧化成尿胆素——就是"黄"的来源
5. 浓缩程度越高，颜色越深（淡黄 → 琥珀）

## 颜色对照

| 颜色 | 常见原因 |
| --- | --- |
| 淡黄透明 | 水分充足 |
| 深黄/琥珀 | 缺水、晨尿浓缩 |
| 亮黄 | B 族维生素（核黄素） |
| 红/褐 | 血尿、肌红蛋白、某些食物药物 |
| 泡沫多 | 蛋白尿可能（需检查） |

## 边界

- 颜色不是唯一指标，气味、泡沫、尿量也要看
- 吃甜菜、火龙果会让尿变红（假性血尿）
- 药物（如利福平）会让尿变橙红
- 持续异常要查尿常规，不要只看颜色自我诊断

## 用得上

- 晨尿偏深是正常浓缩
- 白天尿色持续很深，说明水喝少了
- 出现红色、褐色尿，尽快就医

## 误解

- **"尿黄就是上火"**——多数是浓缩
- **"尿越清越好"**——过度饮水也会稀释电解质

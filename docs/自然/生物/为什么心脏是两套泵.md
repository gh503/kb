# 为什么心脏是两套泵

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 呼吸与循环

## 结论

因为**肺循环和体循环需要的压力差很多**：肺离心脏近、血管短，压力低就够；
全身循环路远、阻力大，需要高压。两套泵串联，各干各的活。

## 机制

1. **右心**把血泵到肺（肺循环），压力低：收缩压约 25 mmHg
2. 血液在肺里换气后回到**左心**
3. **左心**把血泵到全身（体循环），压力高：收缩压约 120 mmHg
4. 两套循环**串联**，血量必须相等，否则一侧会淤血
5. 瓣膜保证单向流动，防止倒流

## 量级

```text
右心室收缩压：约 25 mmHg
左心室收缩压：约 120 mmHg
相差约 5 倍——所以左心室壁明显更厚
心输出量：约 5 L/min（静息）
```

## 边界

- 左心衰 → 肺淤血、呼吸困难；右心衰 → 下肢水肿、颈静脉怒张
- 胎儿期有卵圆孔和动脉导管，出生后闭合；未闭合就是"先天性心脏病"的一种
- 肺循环是**低压低阻**系统，一旦压力升高（肺动脉高压）后果严重
- 心脏自己不靠心腔里的血供氧，靠冠状动脉

## 用得上

- 血压测的是体循环动脉压，反映不了肺循环
- 左心衰的"喘"和肺病的气喘，机制不同
- 胸外按压要压得深、回弹充分，才能产生有效灌注

## 误解

- **"心脏是一个泵，左右只是分区"**——是两个串联的泵，压力等级不同
- **"血压高只是血管问题"**——心脏泵力、血量、阻力都参与

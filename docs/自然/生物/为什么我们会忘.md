# 为什么我们会忘

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 大脑与记忆

## 结论

遗忘不只有"痕迹消退"一种。更常见的是**编码没编好、被别的记忆干扰、或者缺线索提取不出来**。
所以"忘了"往往不是"没了"，而是"找不到"。

## 四种原因

| 原因 | 机制 | 例子 |
| --- | --- | --- |
| 编码失败 | 注意力没在，根本没存进去 | 边看手机边听课 |
| 衰退 | 长时间不用，连接变弱 | 多年不用的外语 |
| 干扰 | 新旧记忆互相覆盖 | 换了新密码忘了旧的 |
| 提取失败 | 线索不对，想不起来 | "话到嘴边" |

## 遗忘曲线

```text
艾宾浩斯（1885）：
学习后 20 分钟忘掉约 40%
1 天后约 70%
之后趋缓
```

这条曲线的形状说明：**遗忘先快后慢**，所以复习要"趁早、分散"。

## 边界

- 遗忘不全是坏事：筛掉无用信息，避免干扰
- 有些"遗忘"是提取问题，给对线索就能想起来
- 情绪、睡眠、压力都会影响遗忘速度
- 病理性的记忆丧失（如阿尔茨海默病）机制不同

## 用得上

- 复习赶在"快忘"之前，效果最好
- 一次学太多相似内容，干扰最强
- 睡觉前复习，减少后续干扰

## 误解

- **"忘了就是没记住"**——可能是提取失败
- **"反复读就能记住"**——被动阅读效果差，提取练习更好

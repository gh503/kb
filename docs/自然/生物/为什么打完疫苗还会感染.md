# 为什么打完疫苗还会感染

> **学段** 初中–高中 ｜ **类型** 机制（含边界） ｜ **链** 疫苗与免疫

## 结论

因为疫苗诱导的免疫**不在病毒进门的地方**，而且会随时间衰减。
肌肉注射主要产生血液里的 IgG 抗体，呼吸道黏膜表面的 IgA 少得多——
病毒先在鼻咽落脚，那里防线薄，就可能"突破感染"。

## 机制

1. 大多数疫苗打在胳膊上，诱导的是**系统性免疫**（血液、淋巴、脾脏）
2. 呼吸道病毒从鼻腔进入，第一道防线是**黏膜免疫**——局部 IgA、组织驻留记忆 T 细胞
3. 肌肉注射对黏膜的覆盖有限，所以能防"病毒扩散到肺"，却未必能防"鼻咽短暂带毒"
4. 抗体水平几个月到一年会下降；病毒变异后，原有抗体可能认不出来

## 边界

- **对重症的保护通常远高于对感染的保护**：防感染 50%，防重症可能 85%以上
- 突破感染不等于疫苗无效：它通常意味着病程更短、病毒载量更低、传染期更短
- 免疫缺陷、老年人、用免疫抑制剂的人，应答本身就更弱
- 变异株的"免疫逃逸"是渐进的，不是全有全无

## 误解

- **"感染了说明疫苗没用"**——要看分母：没接种人群的感染率、重症率是多少
- **"抗体没了就没保护"**——还有记忆 B/T 细胞，再次接触能快速重建
- **"自然感染比疫苗安全"**——见上一条：代价是重症风险

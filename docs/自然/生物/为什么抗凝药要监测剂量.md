# 为什么抗凝药要监测剂量

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 血液与凝血

## 结论

因为抗凝药**治疗窗窄**：少了防不住血栓，多了会大出血。
而且药效受食物、其他药物、肝肾功能影响，所以要靠指标（如 INR）反复调整。

## 机制

1. 华法林抑制维生素 K 依赖的凝血因子合成
2. 起效慢、半衰期长，药效受维生素 K 摄入（绿叶菜）影响
3. INR 衡量凝血时间延长的程度，目标通常在 2.0–3.0
4. 新型口服抗凝药（DOAC）靶点明确、无需常规监测，但肾功能影响大
5. 剂量调整是"个体化"的，不能照搬别人的方案

## 量级

```text
华法林目标 INR：多数适应症 2.0–3.0
机械瓣膜等：可能需 2.5–3.5
INR 过高：出血风险陡增
```

## 边界

- "天然"的维生素 K 会拮抗华法林，饮食要稳定而非完全不吃
- DOAC 不是"绝对安全"，仍有出血风险，且部分无特效拮抗剂
- 抗血小板药（阿司匹林）与抗凝药不是一回事
- 手术、拔牙前要按医嘱停药

## 争议与未解

- DOAC 与华法林在不同人群（机械瓣、严重肾病）中的优劣，仍有争议
- "监测频率怎么定"缺乏统一标准
- 基因多态性影响华法林剂量，常规检测是否值得仍有讨论

## 到此为止

这一层是**窄治疗窗 + 个体差异**：抗凝治疗的本质是在血栓与出血之间找平衡，
不是"吃了就安全"。

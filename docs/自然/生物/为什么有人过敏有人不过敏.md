# 为什么有人过敏有人不过敏

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 过敏

## 结论

**遗传给了倾向，环境决定了要不要发作。** 父母双方都过敏，孩子风险明显更高；
但同卵双胞胎也不是 100% 一致，说明环境因素占很大比重。

## 机制

1. **遗传**：多个基因影响 IgE 产生、屏障功能、免疫调节，不是单基因病
2. **屏障**：皮肤、呼吸道黏膜破损（湿疹、干燥）会让过敏原更容易进入
3. **早期暴露**：婴幼儿期接触的微生物、食物、宠物，会塑造免疫系统的"默认倾向"
4. **环境**：空气污染、烟草、城市生活方式与过敏风险相关

## 边界

- 有遗传倾向不等于一定发病，"过敏体质"不是诊断
- 过敏原检测阳性**不等于**过敏：要结合真实症状判断
- 不同过敏原的规律不一样，食物过敏与花粉过敏的机制细节有差异

## 卫生假说

1989 年提出的观察：家庭孩子越多、越早接触感染，过敏越少。
后来的版本更精确——不是"脏一点好"，而是**微生物多样性**的接触影响免疫发育。
农场长大、养宠物、有兄姐的孩子，过敏率普遍更低。

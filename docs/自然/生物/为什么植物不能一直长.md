# 为什么植物不能一直长

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 光合作用

## 结论

因为光合速率有**上限**：光再强也饱和，还受 CO₂、温度、水分限制；
同时植物自己也在**呼吸消耗**，还要把养分运到根、花果。所以生长速度会被卡住。

## 机制

1. **光饱和点**：超过某个光强，光合速率不再上升
2. **限制因子**：CO₂ 浓度、温度、水分、氮磷供应，谁最少谁卡脖子
3. **净光合 = 总光合 − 呼吸**，夜间只有呼吸，净消耗
4. 养分要在"长叶"与"长根/结果"之间分配
5. 所以施肥不是越多越好，缺什么补什么才有效

## 量级

```text
C3 植物光饱和点：约 800–1500 μmol/(m²·s)（因种而异）
C4 植物：更高，约 1800–2000 以上
净光合在中午高温时可能下降（气孔关闭）
```

## 边界

- 水过多会烂根，缺氧反而抑制生长
- 氮过多会"徒长"，茎叶旺但结果少
- 温度过高时气孔关闭，光合下降
- 不同作物、不同生长期的需求差别很大

## 用得上

- 施肥看"缺什么"，不是"多施"
- 大棚要通风补 CO₂，不是只加温
- 浇水要见干见湿，别积水

## 误解

- **"多施肥就长得好"**——过量会烧根、徒长
- **"光照越强越好"**——超过饱和点没用，还可能灼伤

# 为什么止咳药有的有效有的没用

> **学段** 大学–研究生 ｜ **类型** 边界（证据分层） ｜ **链** 喷嚏与咳嗽

## 结论

因为咳嗽有**不同环节**可下手：感受器、传入神经、中枢、效应肌。
多数非处方止咳药靶点单一、证据弱；真正有效的是针对病因（如哮喘、反流、感染）的治疗。

## 机制

1. 咳嗽反射：气道感受器 → 迷走神经 → 脑干咳嗽中枢 → 声门与呼吸肌
2. 中枢性镇咳药（如右美沙芬）作用于脑干
3. 外周性药物作用于气道感受器
4. 祛痰药改变分泌物性状，让咳嗽更有效
5. 但咳嗽常是"保护性反射"，强行压制未必好

## 证据分层

| 干预 | 证据强度 |
| --- | --- |
| 治疗病因（哮喘、反流、感染） | 强 |
| 蜂蜜（成人、儿童 >1 岁） | 弱到中等 |
| 右美沙芬 | 弱（效果有限） |
| 可待因（儿童） | 不推荐，风险大于收益 |
| 成人复方感冒药 | 弱，且副作用需权衡 |
| 加湿、盐水漱口 | 证据有限，但风险低 |

## 边界

- 儿童用药要特别谨慎，多数止咳药不建议用于幼儿
- 咳嗽超过 8 周属"慢性咳嗽"，要查病因
- 咳血、呼吸困难、体重下降要尽快就医
- 1 岁以下婴儿**不能吃蜂蜜**（肉毒杆菌风险）

## 争议与未解

- 非处方止咳药在儿童中的有效性，长期缺乏高质量证据
- "安慰剂效应"在咳嗽症状评估中占比不小
- 慢性咳嗽的神经敏化机制，仍在研究

## 到此为止

这一层是**靶点多 + 证据弱**：止咳药不是"吃了就不咳"，
先分清病因，再决定要不要压症状。

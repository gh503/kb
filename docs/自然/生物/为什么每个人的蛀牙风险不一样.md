# 为什么每个人的蛀牙风险不一样

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 牙齿与细菌

## 结论

因为龋齿是**多因素**的：菌群组成、唾液流量与缓冲能力、牙面形态、饮食习惯、氟暴露、
遗传与免疫都参与。**目前没有可靠的单一指标能预测"谁会蛀牙"**。

## 机制与证据

- **菌群**：变形链球菌、乳酸杆菌的丰度与龋活跃性相关，但因果方向与个体差异都很大
- **唾液**：流量、缓冲能力、抗菌蛋白影响明显；口干症患者龋齿风险高
- **牙面**：窝沟深、排列拥挤更容易滞留菌斑
- **行为**：吃糖频次、刷牙质量、氟使用，是可改变的部分
- **遗传**：釉质发育相关基因有影响，但效应小、难以单独评估

## 边界

- 风险评估工具（如 CAMBRA）能给出**分层**，但不是预测个体命运的仪器
- 同一个人的风险会随年龄、用药、疾病变化
- 定期检查 + 早期发现，比"预测"更实用

## 未解与争议

- 菌群标志物能否作为**因果**指标，还是只是伴随现象，没有定论
- 深窝沟是否都要封闭，不同指南的推荐阈值不同
- 益生菌、菌群移植在防龋上的效果，证据仍很初步

## 到此为止

这一层是**多因素、无单一预测指标**：机制候选清楚，但组合起来无法精确预测个体。
本库标为**未解**，并强调"可干预因素"比"预测"更有用。

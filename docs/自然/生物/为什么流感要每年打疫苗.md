# 为什么流感要每年打疫苗

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 免疫与感冒

## 结论

因为流感病毒**一直在变**：表面抗原小步突变（抗原漂移），让旧疫苗产生的抗体认不出新毒株。
所以每年要预测流行株、重新配疫苗。

## 机制

1. 流感病毒表面有两种关键蛋白：血凝素（H）和神经氨酸酶（N）
2. 复制时出错率高，H/N 不断积累突变 → **抗原漂移**
3. 旧抗体结合不上新变体 → 免疫逃逸
4. 每年 WHO 根据全球监测推荐疫苗株，厂家据此生产
5. 偶尔发生基因重配（抗原转变），可能引发大流行

## 量级

```text
疫苗效力：通常 40%–60%（随年份、人群变化）
抗体维持：约 6–12 个月下降
```

## 边界

- 疫苗不能防所有呼吸道感染，只针对流感病毒
- 效力不高不等于没用：可降低重症与住院风险
- 接种后约 2 周起效
- 鸡蛋过敏者现在多数也可接种，具体遵医嘱

## 用得上

- 每年秋季接种，尤其是老人、儿童、孕妇、慢病患者
- 疫苗 + 洗手 + 通风，才是完整防护
- "去年打过"不代表今年够用

## 误解

- **"流感就是重感冒"**——流感是特定病毒，并发症风险更高
- **"疫苗会让人得流感"**——灭活疫苗不含活病毒

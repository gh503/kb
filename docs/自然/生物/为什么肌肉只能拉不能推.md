# 为什么肌肉只能拉不能推

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 骨骼与运动

## 结论

因为肌肉收缩的本质是**肌丝相互滑行**，只能让肌肉变短、产生拉力。
它不能主动变长去"推"。所以关节要往两个方向动，就得有**一对拮抗肌**。

## 机制

1. 肌肉由肌纤维组成，里面有肌动蛋白（细丝）和肌球蛋白（粗丝）
2. 神经信号 → 钙离子释放 → 粗丝"抓住"细丝拉动
3. 细丝向中间滑，肌节缩短 → 肌肉变短、产生张力
4. 舒张是被动的：靠拮抗肌拉回或外力
5. 所以屈肌和伸肌必须成对工作

## 例子

| 动作 | 主动肌 | 拮抗肌 |
| --- | --- | --- |
| 屈肘 | 肱二头肌 | 肱三头肌 |
| 伸膝 | 股四头肌 | 腘绳肌 |
| 张嘴 | 下颌舌骨肌等 | 咬肌 |

## 边界

- 心肌、平滑肌的机制与骨骼肌不同，但同样只能收缩
- 肌肉"变长"是被动的，不是主动推
- 等长收缩（长度不变、张力增加）也是收缩
- 肌肉拉伤常发生在离心收缩（边拉长边发力）时

## 用得上

- 训练要练对抗肌群，否则容易失衡、受伤
- 拉伸要在热身之后，冷拉伸易伤
- 力量不平衡（如只练胸不练背）会导致体态问题

## 误解

- **"肌肉能推也能拉"**——只能拉
- **"肌肉越大越灵活"**——柔韧性要单独练

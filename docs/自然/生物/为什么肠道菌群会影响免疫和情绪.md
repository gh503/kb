# 为什么肠道菌群会影响免疫和情绪

> **学段** 高中–大学 ｜ **类型** 边界（证据强度） ｜ **链** 肠道菌群

## 结论

菌群确实参与**免疫训练**和**肠—脑信号**，但两者的证据强度差别很大：
免疫方面有较强机制与实验支持；情绪与行为方面，多数是**相关性证据**。

## 免疫

1. 菌群刺激肠道相关淋巴组织，训练免疫系统"分清敌我"
2. 短链脂肪酸促进调节性 T 细胞，抑制过度炎症
3. 无菌动物实验显示：没有菌群，免疫发育会异常
4. 菌群失调与过敏、炎症性肠病相关（因果方向仍有争议）

## 肠—脑轴

1. 迷走神经连接肠道与大脑
2. 菌群影响 5-羟色胺等神经递质前体（约 90% 的 5-HT 在肠道产生）
3. 菌群代谢物可进入循环，影响炎症与血脑屏障
4. 动物实验显示菌群移植可改变行为
5. **人体证据多为观察性**，因果链未闭合

## 边界

- 动物实验不能直接外推到人
- 情绪、压力本身也会改变菌群（双向）
- "菌群检测 + 个性化饮食"的商业宣称，缺乏硬终点验证
- 粪菌移植（FMT）对艰难梭菌感染证据很强，对其他疾病证据弱

## 争议与未解

- 肠—脑轴的**因果方向**：是菌群影响情绪，还是情绪影响菌群？
- 益生菌对抑郁、焦虑的疗效，研究结果不一致
- "心理益生菌"（psychobiotics）概念有前景，但临床证据不足

## 到此为止

这一层是**机制合理 + 证据分层**：免疫有实验支撑，
情绪方面是"相关 + 动物证据"，还不能说"吃菌能治抑郁"。

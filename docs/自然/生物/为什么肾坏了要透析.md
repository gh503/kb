# 为什么肾坏了要透析

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 肾脏与排泄

## 结论

因为肾衰竭后，**废物排不出去、水盐平衡乱掉**。透析用半透膜把血液里的
小分子废物"洗"到透析液里，代替部分肾功能——但**不能完全替代**。

## 机制

1. 血液流经透析器，与透析液隔着半透膜
2. 小分子（尿素、肌酐、钾）顺浓度差**弥散**过去
3. 多余的水靠**超滤**（压力差）移除
4. 透析液成分可调，纠正酸碱与电解质
5. 一般每周 2–3 次，每次数小时

## 不能替代的部分

| 肾功能 | 透析能否替代 |
| --- | --- |
| 排废物、排水 | 部分可以 |
| 调节电解质酸碱 | 部分可以 |
| 分泌促红细胞生成素 | 不能（需注射） |
| 活化维生素 D | 不能（需补充） |
| 调节血压 | 部分 |

## 边界

- 血液透析与腹膜透析各有优缺点
- 中、大分子毒素清除差，长期并发症仍存在
- 透析不能"治愈"肾衰竭，只能维持
- 肾移植是更接近生理的替代方案

## 用得上

- 保护肾：控血压、控血糖、别乱吃药（尤其止痛药）
- 透析患者要控制饮水与钾、磷摄入

## 误解

- **"透析能把肾治好"**——是替代，不是治愈
- **"透析了就什么都能吃"**——仍需严格饮食管理

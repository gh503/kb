# 为什么肾移植要配型

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 肾脏与排泄

## 结论

因为免疫系统会识别"非己"。移植肾上的 **HLA 抗原**如果和受者差太多，
就会被 T 细胞攻击（排斥）。所以要先配型，再用免疫抑制剂维持。

## 机制

1. HLA（人类白细胞抗原）是细胞表面的"身份证"
2. T 细胞识别外来 HLA → 激活免疫攻击
3. 配型看 HLA 位点匹配程度 + ABO 血型 + 交叉配型
4. 术后用免疫抑制剂（如钙调磷酸酶抑制剂）压低排斥反应
5. 排斥分超急性、急性、慢性，机制不同

## 量级

```text
HLA 基因位于 6 号染色体，位点极多
同胞兄弟姐妹：约 25% 概率全相合
无关人群：全相合概率极低
移植肾 10 年存活率：约 50%–70%（随年代改善）
```

## 边界

- 配型越好，排斥风险越低，但**不是唯一因素**
- 免疫抑制剂有副作用：感染、肾毒性、代谢紊乱
- 活体供肾通常优于尸体供肾
- 儿童、老年人、二次移植的评估更复杂

## 争议与未解

- **异种移植**（基因编辑猪肾）：2020 年代有临床试验个案，短期存活的报道出现，
  但长期效果、感染风险、伦理问题仍在讨论
- "耐受诱导"（让免疫系统接受移植物而不长期用药）仍是研究目标
- 免疫抑制的"最小有效剂量"缺乏统一标准

## 到此为止

这一层是**机制清楚 + 长期未解**：配型与免疫抑制能大幅提高存活，
但"永久耐受"还没有可靠方案。

# 为什么要呼吸

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 呼吸与循环

## 结论

因为细胞要把食物里的能量"取出来"用，这个过程需要**氧气**当"电子接收者"，
并产生二氧化碳。呼吸就是**把氧气运进去、把二氧化碳运出来**的搬运系统。

## 机制

1. 空气进入肺泡，氧气透过肺泡壁进入血液
2. 血红蛋白把氧送到全身组织
3. 细胞内，葡萄糖在氧气参与下被分解，释放能量（合成 ATP）
4. 产生的二氧化碳溶进血液，运回肺部呼出
5. 通气、血液循环、细胞呼吸三步环环相扣

## 量级

```text
成人静息耗氧：约 250 mL/min
一次平静呼吸通气量：约 500 mL
呼吸频率：约 12–20 次/分
```

## 边界

- "呼吸"有两个意思：肺通气（外呼吸）和细胞呼吸（内呼吸），别混
- 缺氧不一定"喘不上气"：一氧化碳中毒者可能毫无感觉
- 通气过度（焦虑、剧烈运动）会把 CO₂ 排太多，反而头晕、手脚麻
- 屏气时间受 CO₂ 驱动，不是"氧气用完"

## 误解

- **"呼吸是为了吸进氧气、呼出二氧化碳"**——更准确说，是为了让细胞获得能量
- **"深呼吸越多越好"**——过度通气会打乱血液 pH

## 用得上

- 运动时呼吸加快，是为了供氧 + 排 CO₂ + 散热
- 心肺复苏要同时做按压和通气，因为两件事都停了

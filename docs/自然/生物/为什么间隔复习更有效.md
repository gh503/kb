# 为什么间隔复习更有效

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 大脑与记忆

## 结论

因为**每次提取都会让记忆更牢，而且"忘了一点再想起来"效果最好**。
集中突击能应付考试，但保持时间短；间隔复习的总时间更少、留存更久。

## 机制

1. **间隔效应**：把学习分散到多天，比一次学完记得久
2. **提取练习**（testing effect）：主动回想比重复阅读有效
3. "适度困难"：快要忘记时努力回想，会强化记忆
4. 每次提取相当于一次"再巩固"，突触连接被加强
5. 睡眠在两次复习之间完成巩固

## 量级

```text
经验间隔（用于长期记忆）：
第 1 次 → 1 天后 → 3 天后 → 1 周后 → 2 周后 → 1 个月后
```

## 边界

- 间隔不是越久越好：要在"快忘但还没全忘"时复习
- 考试前突击对短期有效，对长期保持效果差
- 间隔效应在不同材料、年龄上都成立，但最佳间隔因人和内容而异
- 频繁"重读"会带来"熟悉感"，不等于"记住了"

## 用得上

- 用抽认卡（间隔重复软件）比反复划书有效
- 学完先自己复述一遍，再看答案
- 把复习分散到每天 20 分钟，好过周末突击 3 小时

## 误解

- **"学习时间越长记得越牢"**——分布比总量重要
- **"看懂了就是会了"**——能提取出来才算会

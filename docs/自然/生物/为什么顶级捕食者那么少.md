# 为什么顶级捕食者那么少

> **学段** 初中–高中 ｜ **类型** 量级 ｜ **链** 生态

## 结论

因为能量在每一级传递时**大部分都散失成热**，只有约 **10%** 能被下一级利用。
所以每上升一级，可支撑的生物量就少一个数量级——顶级捕食者注定稀少。

## 机制

1. 植物固定的能量，一部分用于呼吸、一部分变成热散掉
2. 被吃掉的部分也并非全部被吸收（粪便、未消化的部分）
3. 每一级的"传递效率"通常只有 5%–20%，常用 10% 估算
4. 于是能量金字塔每层大约是上一层的十分之一
5. 顶级捕食者个体大、需能量多、数量少，是能量约束的必然结果

## 量级

```text
10000 kg 植物 → 约 1000 kg 草食动物 → 约 100 kg 小型肉食 → 约 10 kg 顶级捕食者
```

## 边界

- 海洋生态系统的传递效率可能更高（浮游生物周转快）
- 个体大小与数量不是简单比例，还受代谢率影响
- "10%"是经验值，不同生态系统差别很大
- 顶级捕食者数量少，也意味着它们最容易灭绝

## 用得上

- 为什么捕食者保护难度大：种群基数小，恢复慢
- 为什么"多养一级"成本高：能量转化损失巨大

## 误解

- **"10% 是精确规律"**——是量级经验值
- **"顶级捕食者少是因为它们打架"**——是能量限制

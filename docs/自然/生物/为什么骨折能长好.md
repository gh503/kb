# 为什么骨折能长好

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 骨骼与运动

## 结论

因为骨有**再生能力**：断端先形成血肿，再长出软骨痂、硬骨痂，最后改建成正常骨结构。
前提是**对位好、血供好、固定稳**。

## 机制

1. **炎症期**（数天）：断端出血形成血肿，炎症细胞清理坏死组织
2. **修复期**（数周）：软骨痂连接断端，再钙化成硬骨痂
3. **塑形期**（数月到数年）：破骨细胞与成骨细胞把骨痂改建成正常骨
4. 整个过程依赖血液供应和稳定的力学环境
5. 所以骨折要复位、固定，必要时手术内固定

## 量级

```text
儿童骨折愈合：约 3–6 周
成人：约 6–12 周
完全塑形：数月到一两年
```

## 边界

- 血供差的部位（如股骨颈）愈合慢，甚至不愈合
- 吸烟、糖尿病、营养不良会延迟愈合
- 固定不稳、感染会导致"骨不连"
- 骨折愈合不等于"完全恢复"，还要康复训练

## 用得上

- 骨折后遵医嘱负重，过早活动可能移位，过晚活动会僵硬
- 戒烟对骨折愈合有实际帮助
- 补钙、蛋白质、维生素 D 支持愈合

## 误解

- **"骨头接上就长好了"**——还要塑形和康复
- **"多喝骨头汤能加速愈合"**——营养支持靠均衡饮食

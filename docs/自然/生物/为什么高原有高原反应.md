# 为什么高原有高原反应

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 呼吸与循环

## 结论

因为海拔越高，**大气压越低，氧分压也跟着降**——空气里氧气比例还是 21%，
但每一口吸进去的氧分子更少。身体一时适应不了，就出现头痛、恶心、失眠、气喘。

## 机制

1. 海平面大气压约 101 kPa，氧分压约 21 kPa
2. 海拔 5000 m，大气压约 54 kPa，氧分压约 11 kPa——差不多减半
3. 肺泡里氧分压下降，血红蛋白"装不满"氧
4. 身体代偿：呼吸加快加深、心率上升、肾脏促红细胞生成素增加
5. 代偿不够或太快上升，就可能发展为高原肺水肿（HAPE）、脑水肿（HACE）——**会致命**

## 量级

```text
海平面：氧分压 ≈ 21 kPa
3000 m：≈ 14 kPa
5000 m：≈ 11 kPa
8000 m：≈ 8 kPa（登山者的"死亡区"）
```

## 边界

- 高原反应与体质强弱**不成正比**，年轻人反而可能更重
- 上升速度是关键：缓慢适应（每天升 300–500 m）能显著降低风险
- 吸氧能缓解，但不能替代适应
- 感冒、脱水、疲劳会加重反应

## 用得上

- 上高原：慢升、多喝水、别剧烈运动、别喝酒
- 出现走路不稳、咳粉红色泡沫痰、意识模糊 → 立即下撤并就医
- 红景天等"预防药"证据有限，不要依赖

## 误解

- **"高原空气里氧气少"**——比例一样，是**分压**低
- **"身体好就不会高反"**——适应能力与体能是两件事

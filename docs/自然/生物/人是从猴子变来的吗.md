# 人是从猴子变来的吗

> **学段** 高中–大学 ｜ **类型** 误区 ｜ **链** 进化

## 结论

**不是。** 人和现代猴子、猩猩是**表亲**，不是祖孙关系。
我们共享一个已经灭绝的共同祖先，然后各自演化了差不多长的时间。

## 机制

1. 演化树是**分支**结构，不是一条"从低到高"的阶梯
2. 人与黑猩猩的最近共同祖先生活在约 600–700 万年前
3. 从那个祖先出发，一支走向人，一支走向黑猩猩
4. 现代猴子、猩猩也在继续演化，不是"停在原地等我们"
5. 分子证据（DNA 序列差异）与化石证据互相支持

## 关键数字

```text
人与黑猩猩基因组差异：约 1%–2%（取决于比较方式）
最近共同祖先：约 600–700 万年前
智人出现：约 30 万年前
```

## 边界

- "共同祖先"是种群，不是某个个体
- 演化不是匀速的，也不是"必然走向智慧"
- 人类不是"演化顶峰"，只是众多分支之一
- 化石记录不完整，细节仍有争论

## 用得上

- 理解"人类只是生物多样性中的一支"
- 医学研究用模式动物，正因为有共同祖先

## 误解

- **"人是猴子变的"**——是共同祖先，分支演化
- **"进化有方向、有终点"**——没有预设方向

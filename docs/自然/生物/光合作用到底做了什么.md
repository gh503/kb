# 光合作用到底做了什么

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 光合作用

## 结论

它用光能把**水和二氧化碳**变成**糖和氧气**：
`6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂`。
本质是把光能存进化学键，同时把氧气"放"出来。

## 两步

1. **光反应**（类囊体膜上）：光能 → ATP 和 NADPH，水被分解，放出氧气
2. **暗反应/卡尔文循环**（基质中）：用 ATP 和 NADPH 把 CO₂ 固定成糖
3. 关键酶是 RuBisCO，地球上量最大的蛋白质
4. 氧气来自**水的分解**，不是二氧化碳
5. 糖一部分 immediate 用掉，一部分运到根、果实储存

## 量级

```text
全球光合固碳：约 100–120 Gt 碳/年（陆地 + 海洋）
光能→生物量效率：自然植被约 1%–2%
理论最大值：约 4.6%–6%（C3 植物，理想条件）
```

## 边界

- 光合作用需要光，但"暗反应"不需要光直接参与，只是依赖光反应产物
- 阴生植物、阳生植物的光饱和点不同
- 光合与呼吸同时进行，测到的是"净光合"
- 海洋浮游植物贡献约一半的全球光合固碳

## 用得上

- 大棚补光、增施 CO₂ 都能提高产量
- 树木固碳是气候讨论的基础，但效率只有百分之一二

## 误解

- **"氧气来自二氧化碳"**——来自水
- **"光合作用只在白天"**——暗反应昼夜都可能在跑，但依赖白天产物

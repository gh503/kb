# 光合作用能人工做到多高效

> **学段** 大学–研究生 ｜ **类型** 边界 ｜ **链** 光合作用

## 结论

自然光合的光能→生物量效率只有**1%–2%**；人工系统（光伏 + 电解）可以到**20% 以上**，
但两者"效率"的定义不同，不能直接比。人工光合（光→燃料）目前仍低于光伏路线。

## 对比

| 路线 | 效率（光→可用能） | 说明 |
| --- | --- | --- |
| 自然光合（生物量） | 约 1%–2% | 受光谱、RuBisCO 限制 |
| 自然光合理论极限 | 约 4.6%–6% | C3 理想条件 |
| 光伏组件 | 约 20%–23% | 商用单晶硅 |
| 光伏 + 电解制氢 | 约 15%–20% | 系统效率 |
| 人工光合（研究） | 通常 < 10% | 稳定性是瓶颈 |

## 为什么自然光合效率低

1. 只吸收部分光谱（绿光浪费）
2. RuBisCO 有加氧副反应（光呼吸），损失能量
3. 植物要投资根、茎、防御，不能全部用于生长
4. 自然选择优化的是"生存"，不是"能量转化率"

## 边界

- 效率高不等于"更好"：光伏要占地、储能、材料
- 生物量还提供粮食、木材、生态服务
- 人工光合的稳定性、成本仍是瓶颈
- 实验室效率与规模化效率差距大

## 争议与未解

- "人工光合能否替代农业"——目前不可能，成本与规模都差很远
- 提高 RuBisCO 效率的改造，进展有限
- 人工光合成燃料的经济性，取决于电价与政策

## 到此为止

这一层是**效率可算 + 可比性有限**：数字能比，但用途不同。
写这类条目要说清"效率定义"，不能只抛一个百分数。

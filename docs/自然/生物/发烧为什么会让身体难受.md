# 发烧为什么会让身体难受

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 发烧

## 结论

因为发烧不是"体温被动升高"，是大脑**主动把"目标温度"调高了**。
身体为了追上这个新目标，先收缩血管、打寒战，所以你会觉得冷；
等体温追上了，又会觉得热、出汗。

## 机制

1. 细菌、病毒或炎症信号让免疫细胞放出致热物质
2. 这些物质作用于下丘脑——身体的"恒温器"，把**调定点**从 37℃ 调到 39℃
3. 此刻你的实际体温还没到 39℃，相对"目标"就是冷的 → 打寒战、缩成一团、手脚冰凉
4. 产热增加、散热减少，体温升到新目标，寒战停止
5. 退烧时调定点回落，身体开始散热 → 出汗、觉得热

**寒战不是病加重，是身体在努力升温。**

## 边界

- 发烧是**症状**，不是病本身；找病因比压温度重要
- 老年人、免疫抑制者可能感染很重却**不发烧**，这不代表没事
- 婴幼儿体温调节不成熟，同样的病体温波动更大

## 误解

- **"发烧会把脑子烧坏"**——只有极高热（通常 41℃ 以上，多为中暑等特殊情况）才可能损伤，
  普通感染性发热不会。热性惊厥也不是"烧坏脑子"
- **"必须马上把体温压到正常"**——退烧的目的是让人舒服，不是把数字修好

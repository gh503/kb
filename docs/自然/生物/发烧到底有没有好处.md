# 发烧到底有没有好处

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 发烧

## 结论

发热**是宿主防御的一部分**，适度升温能增强部分免疫细胞的功能；
但"发烧能缩短病程"在人体上缺乏可靠证据，而高热确实增加代谢负担。
所以临床上退烧的目标是**让人舒服、避免并发症**，不是"帮免疫系统打仗"。

## 证据

- **支持有益**：动物模型里，适度升温提高中性粒细胞与 T 细胞的活性，
  抑制部分病毒复制；用退烧药压低体温的动物感染结局更差
- **人体证据弱**：儿童常见感染的随机试验里，常规使用退烧药**不延长也不缩短**病程
- **代价明确**：体温每升 1℃，代谢率和氧耗增加约 10–13%，
  心肺功能差的人可能扛不住

## 边界

- 收益与代价随**病原、宿主、温度**变化，不存在统一的"该不该退烧"
- 儿童热性惊厥的复发与退烧药使用**没有明确因果关系**
- 严重感染（脓毒症）时，体温反应反而可能被抑制

## 争议与未解

- **"fever phobia"**：家长对发热的过度恐惧导致不必要的用药，这是被反复记录的现象
- 人体上缺少"只控制体温、其他处理相同"的高质量试验，伦理上也难做
- 发热对**适应性免疫**（抗体生成、记忆形成）的净效应，仍不清楚

## 到此为止

这里不是公理，是**证据强度不足的临床判断**：动物实验支持，人体试验有限，
所以指南只给"对症处理"，不给"必须退"或"必须不退"。

# 吃满疗程一定对吗

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 抗生素

## 结论

"必须吃满疗程"是一条**经验法则**，不是定律。它的目的是防复发和防耐药，
但疗程多长取决于感染部位、病原和宿主；近年不少常见感染证明**短疗程同样有效、副作用更少**。

## 证据与机制

- **传统逻辑**：疗程不足 → 残留菌 → 复发，并在残留菌里筛选耐药
- **新证据**：对社区获得性肺炎、部分尿路感染、单纯性皮肤感染，
  多项随机对照试验与荟萃分析显示较短疗程与较长疗程疗效相当，且不良反应更少
- 所以真正重要的不是"天数"，是**足量、按频次、遵医嘱**；疗程长度本身是个变量

## 边界

- **结核、感染性心内膜炎、骨髓炎**等必须长疗程，不能自行缩短
- 免疫抑制患者、深部感染、异物植入，疗程通常更长
- 自行停药和自行延长都不对：延长会增加副作用，也在扩大选择压力

## 争议在哪

- 短疗程证据集中在常见轻中度感染，重症与特殊人群数据不足
- 各国指南并不一致（美国、欧洲、中国的推荐疗程常有差异）
- 这条结论会随证据更新——**这正是知识库要标状态和证据强度的原因**

## 到此为止

这里不是公理，是**仍在演化的临床共识**。写这类条目必须带年份和指南版本，
否则三年后它会悄悄过期，而读者不会知道。

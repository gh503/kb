# 喷嚏能飞多远

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 喷嚏与咳嗽

## 结论

大液滴通常落在**1–2 米**内，但喷嚏喷出的是"气液混合云"：细小的气溶胶能飘到**几米**，
并在空气中悬浮几分钟到更久。**所以"隔一米就安全"不成立，通风比距离更重要。**

## 量级

```text
喷嚏气流出口速度：每秒十几米到几十米
大液滴：直径 > 100 μm，1–2 米内落地
细气溶胶：直径 < 5 μm，可随气流飘数米、悬浮数分钟
一次喷嚏的颗粒数：数万到数十万（个体差异极大）
```

## 机制

1. 高速气流把唾液、黏液打成大小不一的液滴
2. 大液滴受重力快，很快落地
3. 小液滴蒸发后变成**飞沫核**，质量小、沉降慢，能随室内气流走很远
4. 室内通风差时，气溶胶会累积；通风好时浓度迅速下降

## 边界

- 距离和风向都影响，但**换气次数**的影响往往更大
- 口罩能显著减少喷出的颗粒，也能减少吸入
- 咳嗽、说话、呼吸同样产生气溶胶，只是量少

## 用得上

- 打喷嚏用肘部遮挡，之后洗手
- 室内多开窗，比单纯"离远点"更有效
- 医院、电梯等密闭空间，口罩 + 通风双管齐下

## 误解

- **"喷嚏能飞到十几米，所以一定会传染"**——飞得远不等于浓度高、不等于一定致病
- **"捂住嘴就没事"**——用手捂会把颗粒留在手上，摸到门把手就传播了

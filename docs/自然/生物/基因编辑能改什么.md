# 基因编辑能改什么

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 遗传

## 结论

基因编辑能**精确修改 DNA 序列**，已经在镰状细胞病等疾病上取得临床成功。
但它有**脱靶**风险，而且"改体细胞"和"改生殖细胞"是两件性质完全不同的事——
后者会传给后代，目前被普遍禁止。

## 机制

1. **CRISPR-Cas9** 用一段向导 RNA 找到目标序列，Cas9 像剪刀一样切断 DNA
2. 细胞修复断口时，可以敲除基因、插入新序列或做单碱基替换
3. 只改患者体细胞（如造血干细胞）→ 改变不遗传
4. 改受精卵或生殖细胞 → 改变会传给所有后代

## 边界

- 脱靶：可能切到相似序列，造成意外突变，需要全基因组检测
- 递送：怎么把编辑工具送进目标组织，仍是工程难题
- 疗效持久性、免疫反应、长期安全性都需随访
- 多基因性状（身高、智力）**不是**编辑能可靠改变的

## 争议

- 2018 年"基因编辑婴儿"事件被国际科学界广泛谴责，涉事者被判刑
- 生殖系编辑的伦理争议核心：被编辑者无法同意，且影响后代
- 体细胞治疗（如镰状细胞病）争议小得多，因为只影响患者本人

## 未解与前沿

- 长期脱靶效应的**累积风险**，缺乏几十年尺度的数据
- 编辑效率与组织特异性仍不理想
- "治疗"与"增强"的界线由谁划、怎么划，没有共识

## 到此为止

这一层是**技术可行 + 伦理未定**：机制清楚（找序列、切断、修复），
但"该不该做、做到什么程度"不是科学能单独回答的。

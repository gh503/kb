# 多少度算危险

> **学段** 高中–大学 ｜ **类型** 边界 ｜ **链** 发烧

## 结论

**温度数字本身不是唯一标准，年龄、精神状态、持续时间同样重要。**
但有几条硬线：3 个月以下婴儿 ≥38℃ 立刻就医；成人持续 ≥39.5℃ 或超过 3 天要查原因；
≥41℃ 属急症。

## 分级

| 体温（腋下/口腔近似） | 含义 | 怎么办 |
| --- | --- | --- |
| 37.3–38℃ | 低热 | 观察、补水 |
| 38.1–39℃ | 中度发热 | 对症处理，找病因 |
| 39.1–41℃ | 高热 | 就医评估，尤其儿童与老人 |
| >41℃ | 超高热 | 急症，可能损伤器官 |

## 边界

- **3 个月以下婴儿**：38℃ 就要急诊，因为他们免疫反应弱、病情进展快
- **老年人**：可能不发烧，或只有低热，但感染已很重——精神状态变化比体温更可靠
- **热性惊厥**：6 个月到 5 岁常见，多数良性，但首次发作要就医排除其他原因
- **免疫抑制者**（化疗、移植后）：发热阈值要更低、更早处理

## 危险信号（比温度更重要）

- 意识模糊、叫不醒、抽搐
- 呼吸困难、嘴唇发紫
- 皮疹压不褪色
- 尿量明显减少、哭时无泪（脱水）
- 持续呕吐、无法进水

## 误解

- **"烧到 40℃ 就会烧坏脑子"**——感染性发热本身很少造成脑损伤，
  真正危险的是背后的病因（如脑膜炎）
- **"退烧了就是病好了"**——退烧可能只是药物作用，病因没解决

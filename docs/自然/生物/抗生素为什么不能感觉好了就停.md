# 抗生素为什么不能感觉好了就停

> **学段** 小学–高中 ｜ **类型** 机制 ｜ **链** 抗生素

## 结论

症状变轻的时候，体内的细菌通常还没死光。提前停药会让**最能扛的那一小部分**活下来并繁殖，
下次同样的药可能就不灵了。抗生素不是按感觉停的药。

## 机制

1. 抗生素通常不是"一次杀光"，而是按浓度和时间累积起效
2. 细菌群体里天然有差异：有的恰好带一点耐药突变，有的处在低代谢状态（休眠、藏在生物膜里）
3. 提前停药等于把选择压力撤掉一半，正好留下相对耐受的那批
4. 它们繁殖，把耐药基因传下去；有些还能通过质粒把耐药基因转给别的菌种

## 边界

- **抗生素对病毒无效**：普通感冒、流感、大多数咽痛吃抗生素不会好，只会多一份副作用和一次耐药筛选
- 需要"吃够"的是**细菌感染**，而"够"是医生给的疗程，不是自我感觉
- 有些感染现在有短疗程证据，见[吃满疗程一定对吗](吃满疗程一定对吗.md)

## 误解

- **"症状没了就是好了"**——症状消退是免疫反应降下来，不等于细菌清零
- **"抗生素是消炎药"**——它杀细菌，不直接退烧消炎；病毒感染时完全没用
- **"上次剩的接着吃"**——剂量和疗程是按当时那个感染定的，不是通用量

# 抗生素是从哪来的

> **学段** 小学–初中 ｜ **类型** 机制（科学史） ｜ **链** 抗生素

## 结论

大多数天然抗生素来自**微生物自己**——霉菌、放线菌用它们来"抢地盘"。
人类发现后把它提纯、改造，变成药物。青霉素就是青霉菌的"武器"。

## 机制

1. 土壤里微生物密集，彼此竞争养分
2. 有些微生物分泌化学物质抑制邻居——这就是天然抗生素
3. 1928 年弗莱明发现青霉菌能抑制葡萄球菌
4. 1940 年代实现量产，抗生素进入临床
5. 后来的抗生素多从放线菌中筛选，再经半合成改造

## 量级

```text
青霉素发现：1928 年
临床量产：1940 年代
常见来源：青霉菌、链霉菌（放线菌）
```

## 边界

- 不是所有抗生素都来自天然：也有全合成的（如磺胺类）
- "天然"不等于"安全"，青霉素是最常见的过敏原之一
- 新抗生素的发现速度，已明显慢于耐药速度
- 抗生素在养殖业的大量使用，是耐药的重要来源

## 用得上

- 用抗生素要遵医嘱，不自行购买
- 不随意把剩余抗生素"留着下次吃"

## 误解

- **"抗生素是科学家设计出来的"**——多数最初来自微生物
- **"新药会不断出现"**——新抗生素研发管线很薄

# 抗生素是怎么找到细菌的

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 抗生素

## 结论

因为抗生素攻击的是**细菌有、人没有**的结构或通路：细胞壁、细菌核糖体、
细菌特有的酶。找对了靶点，就能"只杀细菌、少伤人体"。

## 常见靶点

| 靶点 | 例子 | 为什么选择性好 |
| --- | --- | --- |
| 细胞壁合成 | 青霉素、头孢 | 人体细胞没有细胞壁 |
| 细菌核糖体 | 四环素、大环内酯 | 与人体核糖体结构不同 |
| 叶酸合成 | 磺胺类 | 细菌自己合成，人靠食物摄取 |
| DNA 复制酶 | 喹诺酮类 | 靶点是细菌特有的酶 |

## 机制

1. 青霉素阻碍细胞壁交联 → 细菌在分裂时"胀破"
2. 这类药只对**正在生长**的细菌有效（所以叫"繁殖期杀菌"）
3. 核糖体抑制剂阻断细菌蛋白质合成
4. 磺胺类竞争性抑制叶酸合成
5. 选择性来自"靶点差异"，不是"毒性大小"

## 边界

- 抗生素对病毒无效（病毒没有细胞壁和核糖体）
- 广谱抗生素会误伤肠道菌群
- 有些药需要"浓度依赖"给药，有些需要"时间依赖"
- 联合用药不是越多越好

## 用得上

- 感冒（病毒）不需要抗生素
- 用药前尽量做病原学检查，避免盲目广谱

## 误解

- **"抗生素是消炎药"**——它杀细菌，不直接"消炎症"
- **"广谱比窄谱好"**——窄谱更少破坏菌群

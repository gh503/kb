# 植物为什么是绿的

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 光合作用

## 结论

因为叶子里的**叶绿素吸收红光和蓝光，却把绿光反射出来**。
你看到的绿色，正是它"不要"的那部分光。

## 机制

1. 阳光是各种颜色光的混合
2. 叶绿素主要吸收蓝紫光（约 430 nm）和红光（约 662 nm）
3. 绿光（约 550 nm）吸收得少，被反射或透过
4. 反射进眼睛的绿光 → 你看到叶子是绿的
5. 秋天叶绿素分解，类胡萝卜素的黄橙色才显出来

## 边界

- 不是所有叶子都绿：紫叶、红叶含花青素
- 深海的红藻、褐藻颜色不同，因为它们利用的光波段不同
- 绿光并非"没用"，只是利用效率低
- 叶子的颜色还受结构色、蜡质层影响

## 用得上

- 秋天变黄，是叶绿素退场、类胡萝卜素登场
- 室内植物缺光会发黄、徒长
- 用红蓝光 LED 补光，比白光更省电

## 误解

- **"叶子是绿的因为光合作用需要绿光"**——恰恰相反，绿光吸收最少
- **"植物只反射绿光"**——也反射其他波长，只是绿光比例高

# 氟为什么能防蛀牙

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 牙齿与细菌

## 结论

氟做了三件事：**把牙釉质换成更抗酸的氟磷灰石、促进再矿化、抑制细菌产酸**。
所以它不是"杀细菌"，而是让"脱矿"更难、"修复"更快。

## 机制

1. 氟离子与羟基磷灰石反应，生成**氟磷灰石**（溶解度更低，临界 pH 更低）
2. 脱矿后的表面有微孔，氟能加速钙磷重新沉积——**再矿化**
3. 氟抑制细菌的烯醇化酶，减少乳酸产生
4. 高浓度局部用氟（如含氟涂料）还能形成氟化钙储备，遇酸释放

## 边界

- **浓度有讲究**：牙膏通常 1000–1500 ppm；饮用水加氟约 0.7 mg/L
- 过量会**氟斑牙**（牙齿出现白垩色或褐色斑），儿童期摄入过量尤其要注意
- 6 岁以下儿童要用豌豆大小、监督漱口，避免吞咽
- 氟不是万能的：已有龋洞无法靠氟修复，只能补

## 量级

```text
牙釉质临界 pH ≈ 5.5（羟基磷灰石）
氟磷灰石临界 pH ≈ 4.5
差 1 个 pH 单位，抗酸能力显著提高
```

## 用得上

- 含氟牙膏是性价比最高的防龋措施，别因为"怕氟"就选无氟
- 高龋风险人群（正畸、口干、频繁吃糖）可加用含氟漱口水
- 儿童用量按年龄，别用成人牙膏挤满牙刷

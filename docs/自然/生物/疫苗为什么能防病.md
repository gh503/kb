# 疫苗为什么能防病

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 疫苗与免疫

## 结论

疫苗不是"把病毒打进去让你得病"，是给免疫系统做一次**预演**：
让它提前认识病原的样子、提前造好武器和记忆细胞。真病原来了，反应又快又准。

## 机制

1. 疫苗里放的是病原的"特征"——灭活的病原、减毒的活病原、一小段蛋白、或者让身体自己造这段蛋白的说明书（mRNA）
2. 免疫系统识别出"外来物"，启动反应：B 细胞产生抗体，T 细胞去清除被感染的细胞
3. 关键产物不是抗体本身，是**记忆细胞**：它们长期存活，下次遇到同样的特征能迅速扩增
4. 这就是"二次应答"：第一次要一两周，第二次常常几天内就压下去，人甚至不觉得生病

## 边界

- 预演用的是**特征**，不是完整病原，所以绝大多数疫苗不会造成感染
- 减毒活疫苗里是活的、但被削弱到不致病——免疫缺陷人群要谨慎
- 疫苗诱导的免疫会随时间下降，所以有些需要加强针
- 疫苗防的是"得病"，很多疫苗对"感染"的保护弱于对"重症"的保护，见[为什么打完还会感染](为什么打完疫苗还会感染.md)

## 误解

- **"打了疫苗就该 100% 不得病"**——没有哪种疫苗是 100%，流感疫苗有效性常在 40–60%
- **"疫苗里有病毒所以会传染给别人"**——灭活、亚单位、mRNA 疫苗都不含能复制的病原
- **"自然感染获得的免疫更好"**——有时更持久，但要先承担重症、后遗症和死亡的风险，不划算

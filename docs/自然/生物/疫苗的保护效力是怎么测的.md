# 疫苗的保护效力是怎么测的

> **学段** 大学–研究生 ｜ **类型** 边界（统计） ｜ **链** 疫苗与免疫

## 结论

效力来自**随机对照试验**：接种组和安慰剂组的发病率之比。
但"相对风险降低 90%"和"绝对风险降低 0.9%"可以是同一个结果——
不看绝对风险，就会把小数变成大话。

## 机制

```text
相对风险降低 RRR = (未接种发病率 − 接种发病率) / 未接种发病率
绝对风险降低 ARR = 未接种发病率 − 接种发病率
需接种人数 NNT = 1 / ARR
```

举例：安慰剂组发病率 1%，疫苗组 0.1%

```text
RRR = (1% − 0.1%) / 1% = 90%
ARR = 0.9%
NNT = 111
```

同一个试验，既可以宣传"降低 90%"，也可以说"要接种 111 人才少 1 例"。
两句都对，但传递的信息完全不同。

## 边界

- **效力（efficacy）** 是试验条件下的数；**效果（effectiveness）** 是真实世界的数，通常更低
- 终点不同结果不同：防感染、防有症状、防住院、防死亡，是四个数
- 观察性研究（队列、病例对照）会受混杂影响，需要校正
- 试验人群（年龄、基础病）决定了结果能外推到谁

## 未解与争议

- **保护 correlates**：中和抗体滴度能部分预测保护，但没有一个通用的"保护阈值"，
  细胞免疫的贡献也难以量化
- 黏膜免疫怎么测、测了算不算数，至今没有公认标准
- 所以"抗体降到多少就需要加强针"仍是经验判断，不是定理

## 到此为止

这一层不是公理，是**统计推断**：它依赖试验设计、终点定义和人群，
换一个终点或人群，数字就变。写条目时把这三样一起写，否则数字会骗人。

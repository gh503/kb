# 睡眠不足到底伤在哪

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 睡眠

## 结论

短期实验证据比较硬：**代谢、免疫、认知、情绪**都会立刻变差。
但"长期睡不够导致糖尿病/心血管病/痴呆"这类结论，主要来自**观察性研究**，
混杂因素很难排除——**相关不等于因果**，这是本库标注的**证据强度不足**。

## 证据分层

| 结论 | 证据强度 |
| --- | --- |
| 急性睡眠剥夺降低胰岛素敏感性、增加食欲 | 短期干预实验，较强 |
| 睡眠不足增加感染风险、削弱疫苗应答 | 实验 + 观察，中等 |
| 长期短睡与肥胖、糖尿病、高血压相关 | 观察性研究，中等但混杂多 |
| 长期短睡导致痴呆 | 观察性研究，弱到中等 |
| "补觉能完全逆转损害" | 证据不足 |

## 机制

1. 代谢：胰岛素敏感性下降、瘦素降低、饥饿素升高
2. 免疫：NK 细胞活性下降、炎症因子升高
3. 心血管：交感神经张力升高、血压夜间不下降
4. 脑：类淋巴系统清除代谢废物主要在睡眠中进行

## 边界

- 个体差异大：短睡者（基因决定的真短睡）是少数
- 剂量与时长有关：偶尔一晚与长期慢性不足不是一回事
- 倒班工作者的研究混杂了社会经济因素
- "8 小时"是人群统计，不是每个人的处方

## 争议与未解

- 因果方向难定：是睡不好导致代谢病，还是代谢病/肥胖导致睡不好？
- 观察性研究靠问卷自报睡眠时长，误差大
- 长期随机对照试验几乎不可能做（伦理与依从性）

## 到此为止

这一层是**证据强度不足**：机制候选清楚，短期实验支持，但长期因果无法用现有设计证明。
写这类条目要写明"观察到相关"与"证明因果"的区别。

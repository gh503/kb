# 糖为什么是龋齿的元凶

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 牙齿与细菌

## 结论

因为蔗糖不只是细菌的"燃料"，还是它们**造黏合剂的原料**：
细菌把蔗糖变成葡聚糖，把自己粘在牙面上，形成越积越厚的菌斑。

## 机制

1. 变形链球菌等细菌分泌**葡糖基转移酶**，把蔗糖切成葡萄糖和果糖
2. 葡萄糖被聚合成**葡聚糖**——黏性多糖，是菌斑的"骨架"
3. 细菌粘在牙面上，越聚越多，形成一个局部封闭的产酸环境
4. 糖被酵解成乳酸，pH 下降；菌斑内部扩散差，酸不容易被唾液冲走
5. 反复的"酸攻击"让脱矿持续发生

## 边界

- **频次 > 总量**：每吃一次糖，菌斑 pH 会低 20–40 分钟；吃的次数决定"酸暴露时间"
- 蔗糖最"坏"：既能产酸又能造葡聚糖；木糖醇等代糖细菌代谢不了
- 淀粉 + 糖的组合（饼干、蛋糕）停留更久，比纯糖水更危险
- 唾液有缓冲和冲洗作用，口干的人风险更高

## 量级

```text
菌斑 pH 静息约 6.5–7.0
吃糖后几分钟内可降到 5.0 以下
牙釉质临界 pH ≈ 5.5
```

## 用得上

- 想吃甜食，**集中吃、吃完漱口**，比"少量多次"更护牙
- 无糖口香糖能刺激唾液，饭后嚼有用
- 含糖饮料慢喝一下午，等于给细菌持续供糖

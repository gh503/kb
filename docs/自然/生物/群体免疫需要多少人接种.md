# 群体免疫需要多少人接种

> **学段** 高中–大学 ｜ **类型** 量级 ｜ **链** 疫苗与免疫

## 结论

需要的接种比例由**基本传染数 R₀** 决定：`H = 1 − 1/R₀`。R₀=3 时约需 67%，
R₀=10 时约需 90%。如果疫苗不是 100% 有效，还要再除以效力：`H = (1 − 1/R₀) / E`。

## 怎么算

```text
R₀ = 2.5  → H = 1 − 1/2.5 = 60%
R₀ = 3    → H = 1 − 1/3   = 66.7%
R₀ = 12   → H = 1 − 1/12  = 91.7%
```

考虑效力 E=0.8、R₀=3：

```text
H = 0.667 / 0.8 = 83%
```

## 常见病原的量级

| 病原 | R₀（量级） | 群体免疫门槛 |
| --- | --- | --- |
| 流感 | 1.3–1.8 | 25–45% |
| 新冠原始株 | 2.5–3 | 60–67% |
| 麻疹 | 12–18 | 92–94% |
| 百日咳 | 12–17 | 92–94% |

麻疹的门槛高得吓人，所以它的接种率一掉，最容易先暴发。

## 边界

- R₀ 是"全易感人群"下的估计，实际传播还受接触模式、人口密度、季节影响
- 疫苗效力 E 对"感染"和"重症"是两个数，算门槛要用防感染的那个
- 免疫会随时间衰减，门槛是动态的，不是一次达标就永久安全
- **达不到门槛不等于白打**：接种率越高，传播链越容易被截断，重症越少

## 用得上

- 判断"还差多少"：先估 R₀，再查疫苗效力，两个数一除
- 判断"为什么要求这么高"：麻疹要求 95% 不是苛刻，是 R₀ 决定的

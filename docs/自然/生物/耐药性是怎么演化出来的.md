# 耐药性是怎么演化出来的

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 抗生素

## 结论

耐药不是"细菌学会了"，是**演化**：突变先随机出现，抗生素把不带突变的杀掉，
带突变的活下来繁殖。药用得越多、越不彻底，这个筛选就越强。

## 机制

1. **突变**：细菌繁殖极快（条件合适时大肠杆菌约 20 分钟一代），复制错误不断产生变异
2. **选择**：抗生素是环境压力，敏感个体死、耐受个体留下——这就是自然选择
3. **扩散**：耐药基因常挂在质粒上，能在不同菌种之间传递（水平基因转移），
   所以一个菌种演化出的耐药，可能跑到另一个菌种身上
4. **温床**：医院和养殖场是高频用药环境，也是耐药菌的"训练场"

## 边界

- 耐药是**相对**的：加大剂量有时仍然有效，但毒性和副作用同时上升
- 有些"耐受"来自生物膜（物理屏障）或休眠状态，不是基因改变，不遗传
- 抗生素滥用中，**畜牧业用量**在全球尺度上长期大于人用，是耐药的重要来源
- 耐药菌不等于"超级细菌"：多数仍可治，只是可选药变少

## 量级

- 2019 年全球估计约 127 万人**直接**死于耐药菌感染（GBD 研究）
- 常被引用的"2050 年每年 1000 万"是**预测**，不是观测值——引用时必须标明这是模型外推

## 到此为止

再往下问"突变为什么会产生"，是 DNA 复制错误与修复机制（分子生物学）；
问"选择为什么有效"，是**演化论**——差异繁殖，本库在此标为**公理层**。

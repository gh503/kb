# 肠道菌群在替我们做什么

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 肠道菌群

## 结论

它们干三件大事：**发酵纤维产生短链脂肪酸**、**合成部分维生素**、
**占据位置挡住病原体**。此外还参与胆汁酸代谢和免疫训练。

## 机制

1. **发酵**：把人体消化不了的纤维发酵成乙酸、丙酸、丁酸
2. 丁酸是肠道上皮细胞的主要"燃料"，维持屏障
3. **合成**：维生素 K、部分 B 族维生素
4. **竞争排斥**：占住空间和养分，让致病菌难以定植
5. **胆汁酸转化**：影响脂肪吸收与代谢信号

## 量级

```text
每天产生的短链脂肪酸：数十克量级（随膳食纤维摄入变化）
丁酸：结肠上皮首选能源
膳食纤维推荐：成人约 25–30 g/天（多数人吃不到）
```

## 边界

- 短链脂肪酸的有益作用有较强证据，但"具体机制链条"仍在研究
- 菌群合成的维生素量通常不足以完全替代饮食
- 菌群作用高度依赖"吃什么"，不是固定功能
- 抗生素后菌群恢复需要数周到数月，且未必完全复原

## 用得上

- 想"养菌"：多吃全谷物、豆类、蔬菜（可发酵纤维）
- 突然大幅改变饮食，菌群也会跟着变
- 长期低纤维饮食，短链脂肪酸产量会下降

## 误解

- **"吃益生菌就能补菌"**——多数益生菌只是路过
- **"纤维只是通便"**——它是菌群的"口粮"

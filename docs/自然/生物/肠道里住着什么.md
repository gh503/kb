# 肠道里住着什么

> **学段** 小学–初中 ｜ **类型** 量级 ｜ **链** 肠道菌群

## 结论

你的肠道里住着**几十万亿个细菌**，数量和你自己的细胞差不多。
它们不是"入侵者"，而是长期共生的居民，帮你消化、合成维生素、训练免疫。

## 机制

1. 婴儿出生时从产道、母乳、环境获得第一批菌
2. 菌群在结肠里定居，以没消化的食物残渣为食
3. 主要门类是拟杆菌门和厚壁菌门
4. 不同人的菌群组成差异很大，像"指纹"
5. 饮食、药物（尤其抗生素）、年龄都会改变组成

## 量级

```text
肠道细菌总数：约 10¹³–10¹⁴ 个
菌种数量：数百到上千种（个体差异大）
菌群基因总数：约为人自身基因的 100 倍以上
结肠内浓度：可达每克内容物 10¹¹–10¹² 个
```

## 边界

- "细菌多"不等于"有害"：绝大多数是共生或中性
- 菌群组成随饮食快速变化（几天内就能测到差异）
- 益生菌、发酵食品只能短暂影响部分菌群
- 菌群检测的商业解读，很多缺乏临床验证

## 用得上

- 多吃膳食纤维，是"喂好菌"最直接的方式
- 抗生素要按医嘱用，别自行滥用
- 别轻信"菌群检测报告"给出的饮食建议

## 误解

- **"细菌都是坏的"**——肠道菌群多数有益或中性
- **"菌群越多样越好"**——多样性是相关指标，不是万能目标

# 脱敏治疗为什么有效

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 过敏

## 结论

因为它**反复、少量地把过敏原送进体内**，慢慢把免疫反应从"IgE 主导的过敏模式"
改写成"IgG 主导的耐受模式"——效应细胞不再轻易被引爆。

## 机制

1. 过敏体质者接触过敏原后，B 细胞产生 **IgE**，结合在肥大细胞表面
2. 再次接触时，过敏原交联 IgE → 肥大细胞脱颗粒 → 组胺释放
3. 脱敏治疗（免疫治疗）长期、递增地给予过敏原
4. B 细胞转向产生 **IgG**（尤其 IgG4），"抢走"过敏原，减少 IgE 交联
5. 调节性 T 细胞增多，抑制过度反应

## 量级

```text
疗程：通常 3–5 年
给药方式：皮下注射（SCIT）或舌下含服（SLIT）
起效时间：数月；停药后疗效可维持数年
```

## 边界

- 对**吸入性过敏原**（尘螨、花粉）证据最好；食物过敏的口服免疫治疗仍在研究
- 需要严格在医院监管下进行，有严重过敏反应风险
- 不是所有过敏都适合，严重哮喘未控制者要谨慎
- 疗效有个体差异

## 用得上

- 过敏性鼻炎、哮喘患者可咨询是否适合
- 脱敏不是"一次治好"，需要长期坚持
- 治疗期间仍要避免大量接触过敏原

## 误解

- **"脱敏就是多接触就会好"**——必须在规范剂量与监管下进行
- **"打一针就根治"**——疗程以年计

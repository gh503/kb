# 自然选择是怎么工作的

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 进化

## 结论

自然选择只需要三个条件：**个体有差异、差异能遗传、差异影响繁殖成功率**。
满足这三条，有利的变异就会在种群中变多——不需要"目标"，也不需要"努力"。

## 三个条件

1. **变异**：种群内个体不完全相同（基因层面）
2. **遗传**：这些差异能传给后代
3. **差异繁殖**：某些变异让个体留下更多后代

满足这三条 → 那些变异的频率会上升。这就是全部机制。

## 常见例子

| 现象 | 选择压力 |
| --- | --- |
| 细菌耐药 | 抗生素杀死敏感菌，耐药菌留下 |
| 工业黑化（桦尺蛾） | 树皮变黑，黑蛾不易被鸟发现 |
| 抗生素、杀虫剂 | 人为制造的强选择压力 |
| 高原人群 | 低氧环境下的血红蛋白差异 |

## 边界

- 选择不是"为了某个目的"，只是统计结果
- 中性变异也会漂变（遗传漂变），小种群尤其明显
- 性选择、人工选择都是选择的特殊形式
- "最适者"指的是"当前环境下繁殖最多"，不是"最强壮"

## 用得上

- 抗生素要按疗程用，减少选择压力
- 害虫防治要轮换药剂，避免单一压力

## 误解

- **"用进废退、获得性遗传"**——拉马克式解释，不被现代遗传学支持
- **"选择让生物变得更完美"**——只是更适应当前环境，环境一变可能就完蛋

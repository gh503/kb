# 血为什么能止住

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 血液与凝血

## 结论

三步一起上：**血管收缩**把口子缩小、**血小板**堵住缺口、**凝血因子**把血液变成凝胶。
三者配合，几分钟内就能封住小伤口。

## 机制

1. 血管破了，管壁立刻收缩，减少血流
2. 血小板黏在伤口处，互相聚集，形成"血小板栓"
3. 同时启动凝血级联，把可溶的纤维蛋白原变成不溶的纤维蛋白网
4. 纤维蛋白网把血细胞网住，形成血凝块（痂）
5. 之后血管修复，血块逐渐溶解吸收

## 量级

```text
血小板正常值：约 100–300 × 10⁹/L
小伤口止血时间：正常约 2–7 分钟
凝血级联涉及的因子：十余种（编号 I–XIII）
```

## 边界

- 血小板太少会出血不止，太多则容易血栓
- 血友病是某一种凝血因子缺失，止血明显变慢
- 阿司匹林会抑制血小板聚集，增加出血倾向
- 大血管破裂靠自身凝血止不住，需要压迫或手术

## 用得上

- 小伤口按压止血，比"吹一吹"有效
- 长期吃抗凝药的人，受伤要延长按压时间
- 经常莫名淤青、牙龈出血，要查血常规

## 误解

- **"伤口结痂就是好了"**——痂下还在修复
- **"血止住是因为血变干"**——是凝血级联形成纤维蛋白网

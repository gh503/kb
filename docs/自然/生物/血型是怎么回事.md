# 血型是怎么回事

> **学段** 高中–大学 ｜ **类型** 机制 ｜ **链** 遗传

## 结论

血型是红细胞表面的**抗原标记**。ABO 系统由一对等位基因决定：
A、B 是显性，O 是"不贴标签"。你的血浆里天然带着**对抗自己没有的那种标记**的抗体。

## 机制

| 血型 | 红细胞抗原 | 血浆抗体 | 能接受的红细胞 |
| --- | --- | --- | --- |
| A | A | 抗 B | A、O |
| B | B | 抗 A | B、O |
| AB | A 和 B | 无 | A、B、AB、O |
| O | 无 | 抗 A、抗 B | O |

1. ABO 基因位于 9 号染色体，A、B 为共显性，O 为无效等位
2. 输血时抗原抗体相遇 → 红细胞凝集、溶血
3. 所以 **O 型是"红细胞万能供者"，AB 型是"万能受者"**——但只对红细胞而言

## 边界

- 血浆输注的规则**反过来**：AB 型血浆可给任何人，O 型血浆只能给 O 型
- **Rh 系统**是另一套：Rh 阴性母亲怀 Rh 阳性胎儿可能发生新生儿溶血
- "万能供血"是应急概念，实际临床仍要求同型输注 + 交叉配血
- 血型与性格、智力无关，这是被反复证伪的

## 量级

```text
中国汉族人群大致：O 约 30%，A 约 28%，B 约 29%，AB 约 12%
Rh 阴性（"熊猫血"）在汉族中不足 1%
```

## 误解

- **"O 型血可以给任何人"**——只在红细胞层面、且应急时
- **"血型决定性格"**——没有任何可靠证据

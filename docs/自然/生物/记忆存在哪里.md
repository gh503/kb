# 记忆存在哪里

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 大脑与记忆

## 结论

记忆不存在"某一个格子"里，而是存在**神经元之间的连接强度**上。
同一段记忆分散储存在很多脑区，海马负责"归档"，皮层负责长期保存。

## 机制

1. 神经元之间通过突触连接，传递信号
2. 反复使用某个通路，突触会变强（长时程增强，LTP）
3. 连接变强 → 同样的刺激更容易被"点亮" → 这就是记忆
4. 海马把不同脑区的信息"绑"在一起，并推动向皮层转移（巩固）
5. 长期记忆分散存放在感觉、运动、语言等相关皮层

## 边界

- 记忆不是"录像带"，没有单一存储位置
- 海马受损（如 H.M. 病例）无法形成新记忆，但旧记忆还在
- 睡眠对巩固很重要（见"深睡和做梦有什么用"）
- 记忆可以被"重新激活"，也会在激活后变得不稳定（再巩固）

## 用得上

- 学新东西：多通道（看、说、写）比单一重复更牢
- 睡眠不足会明显影响记忆巩固
- 情绪强烈的事件记得更牢（杏仁核参与）

## 误解

- **"记忆像文件存在某个文件夹"**——是分布式连接
- **"脑子越大记忆越好"**——连接强度和结构更重要

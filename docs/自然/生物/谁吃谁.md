# 谁吃谁

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 生态

## 结论

生态系统里，能量从**生产者**（植物、藻类）出发，经**消费者**（草食、肉食）一级级传下去，
最后由**分解者**（细菌、真菌）把有机物拆回无机物。这就是食物链。

## 机制

1. **生产者**：靠光合作用把太阳能变成有机物
2. **初级消费者**：吃植物（草食）
3. **次级、三级消费者**：吃动物（肉食）
4. **分解者**：把尸体、排泄物分解成无机盐，回到土壤和水里
5. 实际上很少有"一条线"，多是**食物网**：一个物种常吃好几种，也被好几种吃

## 边界

- 食物链不是固定不变的：季节、年龄、体型都会改变食谱
- 同一物种在不同食物链里可能是不同营养级（杂食）
- 分解者不"低级"，它们把物质循环闭合，没有它们生态系统会停摆
- 寄生、腐食也是食物网的一部分

## 用得上

- 农药、重金属会沿食物链传递，所以"打药"要考虑整条链
- 保护一个物种，常常要保护它吃的和吃它的

## 误解

- **"食物链顶端最厉害，所以最重要"**——每一级都重要，底层消失了上层全崩
- **"食物链是直线"**——是网，不是链

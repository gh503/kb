# 身体怎么把废物排出去

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 肾脏与排泄

## 结论

主要靠**肾脏**：它把血液"筛"一遍，把废物和多余的水变成尿排出去。
肺排二氧化碳，皮肤排汗，肠道排残渣——但"排泄"的主角是肾。

## 机制

1. 肾由约一百万个**肾单位**组成
2. 肾小球像筛子，把水、盐、糖、废物滤出（血细胞和大分子留下）
3. 肾小管把有用的东西（水、葡萄糖、氨基酸）**重吸收**回血
4. 剩下的浓缩成尿，经输尿管到膀胱，再排出
5. 每天过滤约 180 L，最后只排出约 1.5 L 尿

## 量级

```text
每天滤过量：约 180 L
重吸收率：约 99%
每天尿量：约 1–2 L
肾血流量：约占心输出量的 20%–25%
```

## 边界

- 排汗主要调节体温，排泄作用很小
- 肠道排的是"没吸收的残渣"，不算代谢废物
- 肾还参与血压调节、造血、维生素 D 活化
- 尿量受饮水、出汗、激素影响

## 用得上

- 尿少、尿多、泡沫多、颜色异常，都值得查
- 长期高盐、高蛋白会增加肾负担
- 别憋尿，容易引发感染

## 误解

- **"尿就是多余的水"**——含尿素、肌酐、电解质等废物
- **"出汗能排毒"**——汗里主要是水盐，排泄量很小

# 过敏为什么越来越常见

> **学段** 大学–研究生 ｜ **类型** 边界（含未解） ｜ **链** 过敏

## 结论

过去几十年，发达国家和城市化地区的过敏性疾病患病率明显上升。
**"卫生假说"（更准确地说是微生物暴露假说）能解释一部分，但解释不了全部**——
这是本库标注为**未解**的一类问题。

## 证据

- **人群趋势**：多国横断面调查显示儿童哮喘、湿疹、食物过敏的患病率在 20 世纪后叶快速上升，
  且移民到高发地区后风险向当地靠拢——说明环境在起作用
- **农场效应**：从小在农场、接触牲畜与多样微生物的孩子，哮喘和过敏显著更少
- **早期引入**：LEAP 试验（2015）显示，高风险婴儿**早期规律摄入花生**，
  到 5 岁时花生过敏风险下降约 80%——直接改写了喂养指南
- **反面证据**：部分地区的上升趋势在近年趋平甚至下降，单一环境因素解释不了

## 边界

- "卫生假说"不是"越脏越好"：真正相关的是**微生物多样性**与免疫系统的早期"训练"
- 相关性不等于因果：微生物组研究大量是横断面，因果方向难定
- 早期引入过敏原要在医生指导下做，不是让婴儿随便吃

## 未解与争议

- 微生物组**因果链**没有闭合：是菌群改变导致过敏，还是过敏/用药改变了菌群？
- 剖宫产、抗生素使用与过敏的关联，在不同研究里强度差异很大
- "到底该暴露什么、暴露多少、什么时间窗"没有统一答案

## 到此为止

这一层是**未解**：机制候选很多（屏障、菌群、免疫调节），但没有一个能单独解释趋势。
写这类条目要区分"现象确凿"与"机制未定"。

# 过敏到底是怎么回事

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 过敏

## 结论

过敏是免疫系统**把无害的东西当成了敌人**：它给花粉、尘螨、花生这些本来不危险的蛋白
贴了"通缉令"，下次再遇到就立刻放组胺，于是打喷嚏、流鼻涕、起疹子。

## 机制

1. 第一次接触时，免疫系统把这些蛋白当成威胁，产生 **IgE 抗体**
2. IgE 结合在**肥大细胞**表面，像装了引信的炸弹
3. 再次接触同样的蛋白，它把相邻的 IgE 交联起来 → 肥大细胞**脱颗粒**
4. 颗粒里释放**组胺**等物质：血管扩张、渗出增加、平滑肌收缩、神经末梢受刺激
5. 于是出现：鼻塞流涕、眼痒、荨麻疹、哮喘；严重时血压骤降——**过敏性休克**

## 边界

- 过敏和"不耐受"不同：乳糖不耐受是消化酶不足，不涉及 IgE
- 过敏反应**几分钟到两小时**内出现，通常不是"吃了一个月才过敏"
- 严重过敏可致命，肾上腺素是首选急救药，抗组胺药不够快
- 儿童部分食物过敏会随年龄缓解，花生、坚果类更容易持续

## 误解

- **"过敏是因为免疫力太强"**——不是强弱，是"认错了对象"
- **"小时候避开过敏原就不会过敏"**——对花生等，早期少量引入反而降低风险（见下一条）

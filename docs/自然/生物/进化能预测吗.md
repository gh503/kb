# 进化能预测吗

> **学段** 大学–研究生 ｜ **类型** 边界（含争议） ｜ **链** 进化

## 结论

**部分能预测，整体不能。** 在强选择压力、短世代、简单环境下，
进化方向可以相当准确地预测（如耐药性）；但长期、复杂环境下的演化路径，无法预判。

## 可以预测的情形

1. **趋同演化**：相似环境反复演化出相似方案（鱼形、眼睛）
2. **实验进化**：大肠杆菌长期实验，可观察到可重复的适应路径
3. **耐药性**：给定药物，耐药突变位点常可预测
4. **定量遗传**：选择响应可用育种方程估算

## 难以预测的原因

- 突变是随机的，具体哪个突变先出现不可预知
- 环境本身在变，选择压力不稳定
- 历史偶然性（"如果当年没那颗小行星"）
- 种群结构、漂变、基因流都影响结果

## 争议与未解

- **"重放生命录像带"**：古尔德认为结果高度偶然， Conway Morris 认为趋同会重复出现相似结果，
  两种立场都有证据，尚无定论
- 可预测性的**尺度**问题：短期可测，长期不可测
- 演化预测在保护生物学、医学中的应用边界，仍在讨论

## 到此为止

这一层是**部分可预测 + 尺度依赖**：没有"进化必然走向某处"，
但也不是完全随机。

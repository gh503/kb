# 退烧药是怎么起作用的

> **学段** 初中–高中 ｜ **类型** 机制 ｜ **链** 发烧

## 结论

常用退烧药（布洛芬、对乙酰氨基酚）**不是直接给身体降温**，而是抑制前列腺素的合成，
让下丘脑把调定点调回去。身体于是开始散热——出汗、皮肤血管扩张。

## 机制

1. 炎症时，环氧化酶（COX）把花生四烯酸转成前列腺素 E₂
2. PGE₂ 作用于下丘脑，把调定点抬高，这就是发烧
3. **布洛芬**抑制 COX-1 和 COX-2，减少 PGE₂ → 调定点回落
4. **对乙酰氨基酚**主要在中枢起作用，外周抑制弱，所以抗炎效果差、胃肠刺激小
5. 调定点一降，身体发现"超温"了，开始出汗散热

## 边界

- 退烧药**不杀病原**，只改调定点；病因还在，所以可能反复
- 对乙酰氨基酚**过量伤肝**，且很多复方感冒药里都含它，叠加服用最容易中毒
- 布洛芬刺激胃、影响肾功能，脱水或胃病时要慎用
- 两种药不建议常规交替叠加使用，除非医生指导

## 量级

```text
对乙酰氨基酚成人单次 0.5 g，间隔 ≥4–6 小时，24 小时不超过 2 g（保守）～3 g
布洛芬成人单次 0.2–0.4 g，24 小时不超过 1.2 g（非处方）
```

**看说明书上的"每片含量"，不是看片数。**

## 用得上

- 退烧药按体重算（儿童尤其），不是"成人减半"
- 吃了药仍不退、或反复超过 3 天，要就医而不是加量
- 退烧后精神好、能喝水，通常比"温度数字"更能说明问题

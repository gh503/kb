# 食物去哪了

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 消化与营养

## 结论

食物沿消化道走一趟，被**酶**拆成小分子，在小肠被吸收进血液，剩下的排出体外。
**消化是"拆开"，吸收是"运走"，不是"变成能量"那么简单。**

## 机制

1. **口腔**：咀嚼 + 唾液淀粉酶，开始分解淀粉
2. **胃**：胃酸（pH 1.5–3.5）+ 胃蛋白酶，把蛋白质拆开、杀菌
3. **小肠**：主要吸收场所，绒毛把表面积放大几百倍
4. 胰液、胆汁、肠液把小分子进一步分解为葡萄糖、氨基酸、脂肪酸
5. **大肠**：吸收水分和盐，剩下的形成粪便

## 量级

```text
成人小肠长度：约 5–7 m
小肠绒毛 + 微绒毛：表面积放大约 600 倍，约 30 m²
食物通过时间：约 24–72 小时
```

## 边界

- 消化不止"胃"：口腔、小肠、胰、肝胆都参与
- 胃主要消化蛋白质，脂肪主要在小肠消化
- 纤维素人体不能消化，但给肠道菌群当"食物"
- 吸收不良会导致营养不良，即使吃得多

## 用得上

- 细嚼慢咽：减少胃负担，也给饱腹信号时间
- 饭后不要立刻剧烈运动
- 长期胃痛、便血、体重下降，要就医

## 误解

- **"食物在胃里就消化完了"**——主要在小肠
- **"排空越快越好"**——吸收需要时间

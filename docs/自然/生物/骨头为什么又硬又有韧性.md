# 骨头为什么又硬又有韧性

> **学段** 小学–初中 ｜ **类型** 机制 ｜ **链** 骨骼与运动

## 结论

因为骨头是**复合材料**：无机矿物（羟基磷灰石）提供硬度，胶原纤维提供韧性。
两者结合，既抗压又抗拉——单纯硬的东西会脆，单纯韧的东西会软。

## 机制

1. 无机成分约占 65%：羟基磷灰石晶体，硬、抗压
2. 有机成分约占 35%：胶原蛋白纤维，韧、抗拉
3. 胶原纤维像"钢筋"，矿物像"混凝土"，互相交织
4. 骨还有中空结构（长骨），用最少的材料获得最大强度
5. 骨是**活组织**，不断重建（破骨细胞 + 成骨细胞）

## 量级

```text
骨的抗压强度：约 130–170 MPa（接近铸铁）
骨的抗拉强度：约 100 MPa 左右
骨密度：约 1.5–2.0 g/cm³
```

## 边界

- 骨不是"死石头"，有血液供应、会重塑
- 儿童骨有机成分比例高，更韧、不易断但易变形
- 老年人无机比例升高、骨量下降，更易骨折
- 长期缺乏负重运动，骨密度会下降

## 用得上

- 补钙 + 维生素 D + 负重运动，是护骨三件套
- 骨折后固定太久，骨会变脆（废用性骨质疏松）
- 儿童"青枝骨折"就是韧性高的表现

## 误解

- **"骨头是死的"**——是活组织，一直在重建
- **"骨头越硬越好"**——太硬会脆，需要韧性平衡
